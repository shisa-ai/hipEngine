# Recovered router populations: synthetic 1,024-token input

The 48 raw expert-population arrays are recovered in `populations.json`.
They were measured by the model router, not generated by a balanced-count
model. **The input was synthetic token IDs `4000..5023`, not a natural
code-p4096 prompt.**

This corrects the input description in the September 27
[population report](../2026-09-27-moe-gate-up-cost-attribution/README.md) and
[worklog](../../../worklog/entries/20260927T081954.576273Z-lhl-qwen4exp-moe-gate-up-cost-attribution-bfc7e6.md).
The [capture script](../2026-09-27-moe-gate-up-cost-attribution/expert-population.py)
warms with that sequence, resets, then records a second prefill with the same
sequence. Its docstring says code-p4096, but its executable input does not.

The raw file survived at `/tmp/qwen4exp-scope/expert-hist.json`; the earlier
`/tmp/qwen4exp-routing-smoke.json` and category captures were not needed.
The source-file and script hashes are recorded. Runtime source revision,
variant manifest and physical-host identity were not embedded in the raw
capture and cannot be recovered from these arrays. The script's archival
commit is not asserted to be its execution revision.

## Validation

All 48 arrays have 512 nonnegative integer expert counts and sum to 10,240
assignments. Recomputed tile counts agree with every recorded sweep at tile
sizes 1, 2, 4, 8, 16, 32 and 64. The 16-row padded totals agree with all
48 captured engine totals. Mean active experts is 202.9583; mean tile counts
are 772.9167 at 16 rows and 468.8125 at 32 rows, matching the rounded historical
report. These are counts, not throughput measurements.

```bash
python3 benchmarks/results/2026-09-29-qwen4exp-population-recovery/verify.py
```

Use `capture_index` as a capture ordinal, not an independently verified layer
or quant identity. The fixture supports synthetic-input population replay;
it does not qualify natural-task routing, activations, or mixed-quant model
execution. New replay measurements must record their own host, source,
weights and correctness checks. No GPU run or production default changed
as part of this recovery.
