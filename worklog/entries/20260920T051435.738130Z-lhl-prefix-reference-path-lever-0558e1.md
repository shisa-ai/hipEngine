# The reference's own prefill path is the biggest lever: bulk to native cuts mean KL 3-8x, but 127 of 128 state components still differ

## Summary

The reference's own prefix prefill path is the largest single lever found, but it
is not the whole divergence. `session.prefill` picks the generator plugin's
certified **bulk** scheduler for a 1,024-token prompt, while the candidate's
`prefill_batch` takes the **native work batch**. Making the reference use the
native mode cuts mean KL by 3-8x and max KL by 2.6-7.9x, yet **127 of 128 state
components still differ** and one to three flips per 128 rows remain. So
bulk-versus-native is a large contributor, and something further separates
`prefill_batch`'s work batch from `session.prefill` even when both are native.

## Changes

- `scripts/gguf_prefix_reuse_gate.py`: new `--reference-prefill-mode {bulk,native}`
  (default `None`, unchanged behavior) passed as `bulk_attention_mode` to the
  reference `oracle_session.prefill(prefix)` call, so the reference's prefix path
  is selectable for diagnosis. 7 unit tests pass.

## Validation

Three worst scopes, 128 teacher-forced steps each, same commands as the
calibrated packet with `--reference-prefill-mode native`:

| scope | flips / 128 | mean KL | max KL | semantic boundary mismatches | gate `passed` |
| --- | --- | --- | --- | --- | --- |
| `category-general_ja` | 3 | 0.006849 (was 0.022005) | 0.665 (was 1.758) | 127 | True |
| `heldout-code` | 1 | 0.003614 (was 0.024089) | 0.381 (was 3.002) | 127 | True |
| `heldout-general_en` | 0 | 0.000720 (was 0.012082) | 0.043 (was 1.316) | 127 | True |

`heldout-general_en` improves from four flips to none and from failing three
§6.1 bars to passing all of them except the mean (0.000720 is under the `1e-3`
bar, max 0.043 is under the `5e-2` ceiling). `heldout-code`'s max falls from
3.002 to 0.381, still 7.6x the ceiling. `category-general_ja` keeps three flips.

The remaining signal is the asymmetry, and it is sharp: the gate's
`scheduler_chunk_diagnostic`, which builds its prefix with
`prefill_batch_native([prefix], ...)`, matches the candidate **bit-exactly**
(`sched_boundary = True` in all three scopes), while *both* session-based
reference variants differ from the candidate in ~127 of 128 components. The
candidate's prefix path is therefore reproducible by an independent
implementation of its own shape, and the two session-based variants disagree
with it in essentially every component regardless of the session's attention
mode.

The §6.1 calibrated bars are still not met with the native reference: mean KL is
6.8x the `1e-3` bar on `category-general_ja` and max KL is 13x the `5e-2`
ceiling, so the packet would still fail, less severely.
