# Q8 dense wide route: the shipped default, and why the default stays per lane

## Summary

The wide-row Q8_0 dense prefill route is the shipped default on its certified
lane with no caller action: no profile named -> `production` ->
`HIPENGINE_QWEN4_EXP_Q8_DENSE_WIDE=1` at layers 16-47 for `gguf_ud_q4_k_xl`. That
chain was pinned in three separate tests and never as one chain, so this entry
joins it in a single test, corrects the code and status docs that still called
the route default-off, and records why the *general* default stays per lane: the
selector cannot see the lane, and a lane-agnostic default-on would move the
Qwen3.6-35B-A3B lane's prefill to f16 arithmetic at 25 of its 41 layers with no
envelope covering it.

## Changes

- `tests/test_unit_qwen4_exp_profiles.py`: new
  `test_the_shipped_default_routes_the_certified_window_to_the_wide_kernel`. It
  asserts the default resolution (`resolve_default_execution_profile`, no caller
  profile), the production binder's binding, and the selector's decision for the
  certified window, and that layers 0-15 and `rows <= 256` keep the exact parent.
  Removing any one link fails it; the RED state was confirmed by dropping the
  plan registration (fails at `assert requested is ExecutionProfile.PRODUCTION`).
- `hipengine/runtime/gguf_linear.py`: `_q8_dense_wide_dispatch`,
  `_q8_dense_wide_layers`, and `_q8_dense_wide_enabled` docstrings now describe
  the shipped default and the reason the selector's own default stays off
  (fail-safe: an unbound process keeps the exact chain, so a missing binding is a
  slow measurement rather than a silent arithmetic change). No behavior change.
- `scripts/qwen4exp_profile_gap.py`: `--execution-profile {default,strict,production}`
  (default `production`, so existing invocations are unchanged). `default` mirrors
  `hipengine.llm`: it resolves `resolve_default_execution_profile` and errors if
  no certified plan exists. The report now records
  `execution_profile_requested` and `execution_profile`, so an artifact says which
  path produced it.
- `docs/REFACTOR.md`: the wide-route entry no longer opens with "default-off
  selector"; new subsection "The default is per lane, and the route cannot see
  the lane" carries the measured exposure table and the per-lane extension
  trigger.
- `docs/QWEN4EXP-STATUS.md`: the route A/B row's `(opt-in)` label replaced with
  its current status, and section 5 item 2 records the per-lane extension gap.
