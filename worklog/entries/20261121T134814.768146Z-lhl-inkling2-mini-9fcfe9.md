# Widen Inkling NVFP4 expert scales at load time

## Summary

Widen the original NVFP4 block scales exactly to BF16 when loading device expert banks. Leave packed weights and MXFP8 storage unchanged.

## Changes

- Read widened scales directly in the expert kernel. Preserve products, fused multiply-adds, and reduction order. The raw-scale launcher remains available.
- The original checkpoint uses an additional 1,274,019,840 bytes (1.19 GiB) of device memory for scale storage.

## Validation

- `epyc` / Radeon Pro W7900 (`gfx1100`), original `thinkingmachines/Inkling-2-Mini` revision `ed40e7da625f594fc9c4990f5f66be24873c22d7`, `inkling2_mixed`, FP32 KV, single-request ordinary greedy decode. Baseline `634b0e5c4`.
- `bash /tmp/hipengine-inkling2-verify.sh widenedscales`: warm short median 16.4527 to 17.8901 tok/s (five input / 24 output tokens, three warm runs per arm). Synthetic 512 input / 128 output rose from 14.0530 to 15.0842 tok/s (+7.34%), one run per arm; all output IDs matched.
- In the warm trace, NVFP4 projection time fell from 9.341 to 4.233 ms/token; MXFP8 remained at 0.991 ms/token. All 54 focused tests passed, including bitwise raw-versus-widened projections. Public text and single-image packed DSpark preserved output IDs and proposal/acceptance counts. Speculative throughput was not remeasured.
