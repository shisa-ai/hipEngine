# Isolate width-four first-token nonrepeat to packed prefill

## Summary

Public decode-control validation found first-row generated tokens nonrepeatable
at logical width four with packed prefill enabled. Serial prefill removes the
observed failure for the tested short prompts. This is an observed defect to
repair, not missing evidence and not a reason to disable the feature globally.
