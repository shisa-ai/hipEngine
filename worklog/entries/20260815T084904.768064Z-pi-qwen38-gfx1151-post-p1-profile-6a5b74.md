# Select Q5T16 after Qwen3.8 gfx1151 P1 profile

## Summary

The mandatory post-sole-Q4 profile moves Q5 recurrent SSM output to the first
independent compressed owner on gfx1151. At pp512 the 56-call dense-BF16 family
costs 922.230 ms, ahead of Q6T16 at 639.968 ms and GDN core at 177.949 ms. The
512 graph trace assigns 1,768.431 ms to dense BF16 over 128 decode steps, so Q5
is material in both prefill and decode. Qualify Q5T16 before planar Q6, then
re-profile before considering 16K/48V compact-peer GDN.
