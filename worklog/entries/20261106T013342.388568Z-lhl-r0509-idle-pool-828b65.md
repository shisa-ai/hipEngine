# Inventory and trim idle prefix arenas without touching quarantine

## Summary

Add the missing idle/quarantined arena inventory and idle-only byte trim API
for R0509. No runtime retention policy is changed in this prerequisite.

## Changes

- Pool inventory reports idle and quarantined owner allocations once; checked-out
  arenas belong to live snapshot inventories instead.
- Idle trimming frees largest idle arenas until the supplied byte bound is met.
  Quarantined copies are never synchronized, recycled or freed by trimming.
  A close failure leaves that arena in the pool for later cleanup.
