# Bind the f16 WMMA layer scope to its execution owner

## Summary

The f16 WMMA dense-Q8 layer scope is now request-local generator/runner state
instead of the process key `HIPENGINE_QWEN4_EXP_Q8_WMMA_LAYERS`. The historical
key remains only as the direct/unbound fallback; a bound owner never reads it.

`Q8WMMALayerScope` makes the three states distinct and hashable: empty (every
layer, no filter), `frozenset({0})` (a real layer-0 selection), and any other
explicit layer set. The dispatch memo and the runner's weight filter derive from
one typed scope, so a gate arm cannot bind a scope the cache does not see.

The production binder publishes an empty scope on the generator and the runner
it finds, and writes no process key. Runner construction, late cloning, and lane
inheritance carry the decision. A caller's pre-binder ambient value is reported
once and left untouched rather than overwritten.
