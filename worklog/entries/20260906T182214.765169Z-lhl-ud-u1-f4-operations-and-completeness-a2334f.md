## Summary

1. **Operation membership was only checked when the caller volunteered an
   operation set.** `certificate_covers_artifact` checked
   `operations`-membership only for the explicitly passed set; omitted, it
   verified residents but no operations. Reviewer repro (RED before the
   fix): mint an `ar_decode_c1`-only certificate, preflight the same artifact
   for `ar_prefill` (identical planned residents on the plain synthetic
   map), and compare the prefill contract WITHOUT `operations` → True.
   Neighboring counterexample: identical residents likewise covered an
   `ar_decode_native_rows` intent (same contracted BF16 alpha/beta plan) —
   an arbitrary row-operation upgrade through the same residents.
2. **Refused preflight reports could supply authorizing contracts.** The
   preflight appends resident records only for successfully qualified
   slots, and the round-3 self-consistency check only required a nonempty
   record set for full scope, so the comparison accepted any nonempty
   subset of certified records as "full". Reviewer repro (RED before the
   fix): the F32-alpha/beta synthetic map under
   `operations=(ar_decode_native_rows,)` with `contract_f32_linear=True`
   mints a certificate; `contract_f32_linear=False` is refused (alpha/beta
   stay dense F32, omitted from the records); comparing the REFUSED
   report's `plan_contract` to the certificate with the explicit native
   operation returned True. The loader's own `raise_for_errors` path was
   never exposed to this, but the exported helper was wrong.

## Design / invariants (single authorization pathway; no duplicate routes)

- `Qwen35GGUFPlanContract` gains two preflight-enumeration fields:
  `required_plan_slots` (every slot the preflight TRIED to qualify for its
  (operations × slot scope): participating ∪ refused, including
  unknown-role-class slots and unknown `slot_filter` entries) and
  `operation_scope_refusals` (operation-level scope gates, e.g. MTP draft
  on an AR-only preset). `__post_init__` canonicalizes both; `as_dict`
  exports both.
- `Qwen35GGUFPlanContract.is_complete()` is the authorization-capability
  statement: records well-formed/slot-unique/digested (digest still covers
  ONLY successful records — unchanged format, no tag bump), records cover
  EXACTLY `required_plan_slots`, no operation-scope refusals, and a
  filtered scope accounts only in-filter slots. The accounting sets are
  enumeration inputs, not values derived from the successful records, so
  the completeness proof is not circular. Hand-built/legacy/hollow
  contracts default to incomplete and fail closed.
- `certificate()` refuses to mint unless the report is supported AND its
  contract is complete (mint-boundary invariant; for real preflights the
  two are equivalent by construction, every refusal path also marks the
  accounting).
- `certificate_covers_artifact` now requires: identity (unchanged);
  completeness of BOTH the certificate's recorded contract and the intended
  contract (a refused report can never supply an authorizing intended
  contract, no matter how many of its records match); intended operations =
  explicit `operations` (must be NON-EMPTY; empty authorizes nothing) or,
  when omitted, the intended contract's own checked operations, and the
  whole set must be inside the certificate's certified operations, the
  recorded contract's operations, and the intended contract's operations;
  the accepted round-3 slot-scope agreement/nesting/per-slot record
  equality semantics unchanged, plus a named nonempty scope with zero
  verified residents fails closed.
- Preflight: unknown `slot_filter` entries are refused (`scope_refused`)
  and accounted as required-but-unrecorded instead of silently ignored
  (caller error is not a no-op); refused debug reports keep their partial
  contracts for diagnostics — they just cannot authorize.
- Trust boundary unchanged: ordinary engine-internal immutable metadata,
  not adversarial object forgery; the completeness accounting exists so
  honest partial artifacts (refused reports) cannot be mistaken for whole
  qualifications, and hand-built defaults still fail closed.
