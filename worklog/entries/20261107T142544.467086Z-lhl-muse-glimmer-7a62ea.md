# Muse Glimmer Q6 integration assessment

## Summary

Investigated integrating the Q6 ffn_down win (the remaining 4K prefill lever).
The Q6 qmicro_planar WMMA owner is a single-wave (32-thread) kernel — that
structural limit, not activation conversion, is why it runs at 11 TF; an fp16
sibling would not fix it. The existing tiled-K16 rocBLAS route
(gguf_q6_k_t16_qmicro_planar_f16_rocblas_bf16_bf16_out) memory-faults on the
19968->6656 ffn_down shape and is not viable. The measured fix is the full
dequantize-to-F16 + hipBLASLt GEMM (1.58x deployable / 2.04x resident, cosine
0.99999), which needs a dedicated registered prefill route + dispatch selection.
