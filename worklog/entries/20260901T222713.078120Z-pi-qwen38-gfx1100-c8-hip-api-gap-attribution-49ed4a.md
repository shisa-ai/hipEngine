# Attribute retained C8 target HIP API gaps

## Summary

Captured tracked-clean HIP API + kernel + ROCTx tracing for the retained exact
C8/K3 target window. The ~78 ms three-cycle wall-minus-device-union gap is not
free host idle: blocking copies carry required default-stream producer
dependencies, while launch/API submission contributes a smaller bounded share.
A default-off async root-token stage removes one blocking H2D per cycle but does
not improve complete wall and is removed.

## Changes

- Temporarily replaced the per-cycle blocking root-token H2D with same-stream
  `hipMemcpyAsync`; device candidate overlays remained unchanged.
- Removed the branch, capability policy, environment flag, and test after the
  marker comparison. No runtime debt remains.
- Added the first compact retained-path C8 HIP API attribution artifact; no
  benchmark scoreboard row changed.

## Validation

- Tracked-clean `6cf25f7a3` control, cached-only W7900 C8/K3/D12 API profile:
  target wall **522.489 ms**, device union **444.127 ms**, gap **78.361 ms**.
- Across three cycles: blocking `hipMemcpy` **118 calls / 346.557 ms API wall**,
  `hipMemcpyAsync` **1,264 / 4.685 ms**, kernel launches **3,148 / 20.298 ms**,
  device synchronizes **3 / 5.523 ms**. The three largest blocking D2H calls
  are **97.03–108.19 ms** and wait on target producers; initial per-cycle H2D
  dependencies are **7.36–7.84 ms**.
- Async token stage preserves generated IDs and `[3,3,2]` acceptance and moves
  exactly three calls from blocking to async. Target wall improves only
  **522.489→521.166 ms (-0.25%)**, device union is flat **+0.07%**, and complete
  wall regresses **1.2724→1.2757 s (+0.26%)**. Removed before full-suite spend.
- Final source matches `6cf25f7a3`; only this worklog and
