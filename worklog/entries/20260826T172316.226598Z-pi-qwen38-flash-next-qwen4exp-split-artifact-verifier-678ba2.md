# Validate split Qwen4Exp GGUF artifacts

## Summary

Extended the Qwen4Exp artifact verifier to treat split GGUF as one artifact.
This is required for the requested Unsloth UD-Q4_K_XL comparator, whose first
10.9-MB shard carries metadata and zero tensors while three data shards carry
all 1,224 tensors.

## Changes

- Added split-count/part-number/declared-tensor validation, cross-part duplicate
  detection, and aggregate tensor qtype/runtime-role accounting.
- `inspect-gguf` now accepts a directory, scans all top-level GGUF parts, reports
  per-part and total file bytes, and optionally hashes every part plus a stable
  split-artifact identity.
- Added positive aggregation and missing-part/duplicate-tensor RED fixtures.

## Validation

- RED: `uv run pytest -q tests/test_qwen4_exp_artifact.py` -> 4 passed, 2 failed
  because `summarize_qwen4_exp_split_gguf` did not exist.
- GREEN: the same command -> `6 passed`.
- Real partial Unsloth negative control correctly returned exit 1: split count
  4, only part 0 present, 0/1,224 tensors, and no PLE table yet.
