# Drain global KV pool storage close exactly once

## Summary

Global KV storage teardown attempts the descriptor, every pointer table and
every backing chunk even after a free fails. Both the storage closure and pool
become closed after this attempt, preventing retries against released pointers.

## Changes

- Aggregate storage-close errors instead of stopping at the first descriptor or
  table free. Keep VMM arena ownership single-close through its current backing.
- Mark the pool closed in a finally block once storage teardown begins.
- Extend repeated-growth coverage with a failing descriptor free; assert every
  owned allocation is attempted once, repeat close is inert and growth refuses.
