# Surya OCR 2 text-decoder bring-up (milestone 2)

## Summary

Surya's text checkpoint (24-layer causal hybrid: 18 GDN + 6 full attention,
tied head) now runs in a torch-free NumPy CPU reference reusing the
oracle-validated EVIE family math, gated end-to-end against the torch
fp32 oracle fixtures. Weight, geometry, cache, and state paths are proven
before any image or GPU work.

## Changes

- hipengine/kernels/cpu_reference/surya.py: spec-driven SuryaWeights
  (safetensors BF16->fp32) + SuryaSpec; GDN layers parameterized for
  Surya geometry (16x128 q/k/v, ts rank 16, conv 4 over fused 3x2048
  qkv, no q/k head repeat, L2 q/k norms) with state-threaded decode
  (conv window + recurrent state per layer); causal full attention
  (8Q/2KVx256, sigmoid output gate) over a growing KV cache; chunked
  prefill == single pass via shared state container; tied LM head;
  greedy_generate with EOS=2 stopping.

## Validation

- Caught a real bug RED-first: my first causal mask zeroed masked
  scores before softmax, leaking exp(0) mass into every row (layer-3+
  divergence compounding to 26.7 on final hidden while top-1 still
  agreed — the KL-only gate was too loose). Fix: -inf masking; layer
  outputs now match the torch oracle to 2.5e-5 across all 24 layers.
- Measured gates now in the test: prefill logits max|d| 2.6e-5
  (gate 1e-3); full-attn KV cache layers 3/23 max|d| 7.6e-6 (1e-3);
  decode-step logits max|d| 0.24-0.42 with exact top-1 (gate 0.5);
  state self-consistency prefill(39)+step == prefill(40) 3e-7 (1e-5),
  conv window 1.1e-5 (1e-4); chunked prefill == single pass.
- Known documented difference: torch stores the GDN state from the
  CHUNKED delta-rule kernel (fla WY factorization, chunk 64); this
  reference accumulates the equivalent step recurrence. Same math,
  different fp32 path: stored state cos 0.92-0.97, mean|d| 1e-3..5e-3
  (diagnostic gate cos>=0.9, mean<=0.02); decode-step logit diffs
  inherit it. The fla chunked-kernel port is deferred to the GPU
  prefill milestone where it is production-relevant.
- Image-case text side (embedding injection + mRoPE over 64 image
  tokens with spatially compressed positions) matches oracle logits.
