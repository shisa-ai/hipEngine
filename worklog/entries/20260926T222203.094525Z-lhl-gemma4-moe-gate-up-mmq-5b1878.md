# Gemma 4 Q4_K expert gate/up prefill on the int8-dp4a MMQ32 route: 1.27x measured, held off the default path

## Summary

Gemma 4's `Q4_K` expert gate/up prefill can run the int8-dp4a MMQ32 leaf the
Qwen4 experts already use on this backend, reading the artifact's per-expert
fused `gate | up` row block in one launch instead of two fp32 grouped launches.
It measures **1.27x on the campaign's headline prefill row** (512/128: 4.200 ->
3.313 s, 121.9 -> 154.3 tok/s) and 1.19x at 2048/128 (21.80 -> 18.27 s).

It does not become the default path. Against the strict single-kernel arm its
teacher-forced gate passes `kl_mean` (1.438e-04 against 1e-3), `kl_p95`
(1.329e-05 against 5e-3), `kl_p99` (1.489e-04 against 2e-2) and top-1 (1.0000
with zero flips over 1022 rows), and **fails `kl_max` at 6.510e-02 on 2 rows
against the binding 0.05 bar**. That bar is already breached on this chain by
the shipped 4-slice attention split at 1 row (0.055589) and **on the same row**
(row 863: teacher p_top1 0.995465, top-1 unchanged), which
`docs/campaigns/GEMMA4-26B-A4B-OPTIMIZATION.md` records as an open lead decision
about the applicability of an absolute `kl_max` to a peaked reference on a
greedy workload. This change lands inside that decision rather than settling it,
so the route ships implemented, tested and selectable through
`HIPENGINE_GEMMA4_MOE_GATE_UP_MMQ`, and the promotion call is the lead's.

## Decision-stability probes

The gate's 1022 rows report zero top-1 flips, and they are near-one-hot
repeated prose, so three ad-hoc probes through the public runner were run to
find positions where the model is actually uncertain. They are diagnostics, not
a benchmark row: one run each, no repeats.

- A natural English paragraph: **identical** 16-token greedy chains in both
  arms (first-token p_top1 0.5587 incumbent against 0.6281 route).
- A Python snippet: agreement for two tokens, then the route takes 236772 where
  the incumbent takes 20470 and repeats that token fourteen times while the
  incumbent continues with varied tokens.
- A 60-fold repeated sentence: the first greedy token flips (108 against 107) at
  a position where the incumbent's own top-1 is 0.2532 (top four
  0.2532/0.1775/0.1665/0.1328) and the route's is 0.5877, with the top logit
  moving 1.005 -> 14.029. Pinning the attention split to one slice changes none
  of it, because a 721-key context never engages the split.

So the route changes decisions at low-margin positions, and the frozen chain
cannot see that class at all. That is the strongest reason the route stays off
the default path, and it is a measurement for the lead rather than a defect:
the flips sit where the incumbent's own margin is small, and the natural-text
chain agrees exactly.
