# Use normal compiler resolution in GPU correctness gates

## Summary

Resolve R0005 by letting ordinary correctness tests build a missing cache entry
instead of depending on a mutable, implicitly selected temporary version file.

## Changes

- INT8 batch/verify attention tests call the normal builder without forcing
  cached-only execution or reading a hard-coded temporary compiler file.
- Dense-prefill WMMA tests likewise stop preferring a historical temporary
  version file. Keep HIP availability guards and all numerical comparisons.
- Runtime build resolution, explicit user configuration, and cache-only
  benchmark/provenance contracts are unchanged.

## Validation

- Regression first fails because the gate skips before build resolution, then
  passes with the normal builder call. Build-unit tests pass alongside it.
- bg-381 passes the complete INT8 attention GPU file; bg-382 passes the complete
  dense-prefill WMMA GPU file in the ROCm environment, without the implicit
  compiler files. Logs: `/tmp/r0005-gpu.log`, `/tmp/r0005-dense-gpu.log`.
- Census of GPU test modules finds no remaining combination of forced
  `require_cached=True` and temporary/compiler-environment file selection.
  Other inspected compiler-environment users already permit normal builds.
- Documentation, audit and diff checks pass. This tests-only change needs no
  separate product request; the real GPU gates are the changed user surface.
