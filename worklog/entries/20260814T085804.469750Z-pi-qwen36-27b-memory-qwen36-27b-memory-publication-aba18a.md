# Publish dense 27B compact QK memory win

## Summary

Published the clean-commit four-shape RX 7900 XTX result for route-shaped compact peer-GDN Q/K scratch. Tracked peak moves from 15.605/15.720/16.368/16.626 to **15.596/15.699/16.263/16.521 GiB** at 512/1K/4K/8K, exact savings of **9.8125/21.25/107.375/107.375 MiB**. Five-millisecond whole-device sampling measures **16.094/16.305/17.022/17.277 GiB**, saving **1.395/16.297/98.805/108.254 MiB** versus the frozen current baseline.

This is a retained memory improvement, not cross-engine closure. The remaining gaps to the lower llama.cpp Vulkan floors are **0.405/0.605/1.110/1.111 GiB**. hipEngine remains below llama.cpp HIP whole-device peak at 512/1K but above it at 4K and standardized 8K. The residual long-context growth is expected BF16 full-attention KV after the 4096-row scratch cap, not a leak.
