# Reject silent BF16 substitution for explicit INT8 requests

## Summary

Explicit dense INT8 requests now raise a reason-bearing error when capability resolution refuses execution, rather than silently using BF16. The attempted dense-INT8 campaign arm used BF16 throughout and is not an INT8 result. This fixes request semantics, not the historical numerical failure.

## Changes

- Replace silent substitution with a ValueError naming the codec and refusal reason.
- Add a regression reproducing the silent substitution. Preserve the existing diagnostic route for numerical investigation; no arithmetic or quality gate changed.
- Preserve invalid raw outputs under `~/gate-runs/qwen38-edge-cache-verified-20260926/dense-int8/`.
