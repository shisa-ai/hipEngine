# Retain dense Qwen3.6 prefill scratch liveness

## Summary

Retained a model-scoped phase-liveness arena for dense Qwen3.6-27B bulk-prefill
scratch. It omits unreachable MoE/shared-expert buffers and aliases only
route/stage-disjoint linear-attention, full-attention, and dense-FFN fields.
Physical bulk scratch drops 0.589106 -> 0.110693 GiB (-81.210%), tracked peak
16.083275 -> 15.604862 GiB (-2.975%), and standard 512/128 sampled peak delta
16.712402 -> 16.214355 GiB (-2.980%). Prefill/decode remain neutral at
720.818/33.446 tok/s; decode passes, prefill and memory remain open.

## Changes

- Added a gfx1100 package policy keyed only to
  `Qwen3.6-27B/MOSTLY_Q4_K_M`. Other dense models/backends keep dedicated
  scratch until independently gated; the existing MoE plan is unchanged.
- Reused the admitted single-arena planner with 33 active dense fields, omitted
  every `moe_*` owner plus production-inactive F32 temporaries, and retained
  dedicated metadata/split-attention buffers.
- Added a dense-only lifetime map. The shared allocator accepts an explicit
  lifetime map, so the existing MoE and gfx1151 owner-slot associations and
  byte expectations remain unchanged.
- Published
  `benchmarks/results/2026-08-12-qwen36-27b-xtx-dense-prefill-scratch-liveness.json`
  and updated the campaign scorecard, benchmark rollup, and changelog.

## Validation

- RED: the new dense policy test initially observed `dedicated`, as intended.
  The full first alias screen then exposed an invalid inherited handoff:
  `ffn_intermediate` and `ffn_down` shared offset 53,542,912 while the down MM
  still read the complete intermediate. Three PM4 final logits varied
  24.131704/23.928917/24.032139 instead of exact 24.123718; that screen was
  rejected and never committed.
- GREEN repair: dense `ffn_intermediate` lives through stage 13 while down starts
  at stage 12, placing intermediate at 53,542,912 and down at 80,347,136 with
  zero overlap. The MoE map retains its existing stage plan.
- `tests/test_qwen35_gguf_prefill_scratch_liveness.py`: `9 passed`, including
  unchanged gfx1151 short owner-slot bytes and its long-context ceiling.
- Repaired eager 512/1 over three resets is exact: final logit 24.801517 and
  token 9707 each run. Repaired default-PM4 512/128 is exact: final logit
  24.123718 and token 9707 each run, 384 launches, zero fallbacks.
- Repaired 512/128 r3: prefill 697.866/720.818/723.737 tok/s (median 720.818),
  decode 33.473800/33.445591/33.434747 (median 33.445591, 0.060% stdev).
- Bulk physical owner is 118,855,720 bytes vs 398,383,144 active logical bytes;
  alias reuse is 279,527,424 bytes. Tracked peak is 15.604862 GiB; sampled
  absolute peak 16.284668 GiB, before-load 0.070312 GiB, delta 16.214355 GiB;
  tracked bytes after close are zero.
