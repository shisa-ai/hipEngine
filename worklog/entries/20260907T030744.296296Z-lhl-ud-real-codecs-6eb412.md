# Check published UD real rows against independent codec oracles

## Summary

All seven UD CPU decoders match independent C output on first/last full rows
from 20 actual published-model tensors. These fixtures supply representative
weight bytes for the next dense GPU consumer tests, not end-to-end evidence.

## Changes

- Extend the pinned C fixture generator with optional real-row extraction.
  Use the first/last matching tensor for each type in each file and the
  first/last full row of each tensor. Covers dense FFN, attention and Q3_K
  token embedding roles, widths 5120/17408, and row/block boundaries.
- Recompute both complete published payload SHA256 values before extraction.
  K_M: `322e194ff79741c7baa497c240f677f54b201b0efab44ca8e50f122b39123482`;
  K_S: `75bc9c8adba2842e72f0ab5201aaa07133c5010b566305c09187fcbdcd364017`.
  Both match docs/UD-QUANTS-U0-IDENTITY.json. The generator requires this
  external checksum step; its metadata labels the pins as published hashes,
  not hashes independently computed inside the extraction function.
- Add exact F32-bit comparisons and rank-3 dimension-order checks. The donor
  revision/license/source hashes are the same as the preceding synthetic
  fixture unit. `real_rows.json` records each model, tensor, shape and row.
- No runtime changes. RED-first is not applicable to this fixture-only
  extension; the preceding decoder unit already established failing-first
  coverage. GPU accumulation and activation rounding still require leaf gates.
