# Implement single-use F16 staging ownership before native qualification

## Summary

Implemented the bounded DP-5 producer/consumer handoff for the qualified Qwen4Exp HC-down route. The F32 grouped norm producer can publish one caller-owned F16 plane, and the immediate dense-wide consumer consumes that plane without launching a second F32-to-F16 cast. Admission is registry-axis and scope-qualified; all misses fall back to the existing parent chain.

## Changes

- Added `GGUF_DENSE_WIDE_F16_PUBLICATION_POLICIES` for gfx1151 Q8_0 dense-wide HC-down shapes, layer window 13-47, and the registered `gr_grouped_rmsnorm/bf16_f32/f32_f16_publish` producer.
- Added context-local, identity-bound, single-use publication metadata with bounded/disjoint pointer checks, nested-session invalidation, copied-context refusal, and immediate-consumer matching.
- Added `wide_f16_publication_keys()` to replay the relevant raw dispatch rewrites before admitting the loan.
- Replaced the old unconditional Qwen4Exp grouped norm/down call sequence with `_run_qwen4_exp_gr_norm_down()`, preserving the strict parent and IU8 alternatives on every refusal path.
- Added unit RED/GREEN coverage for admission boundaries, env gates, pointer capacity/alias rejection, registration fallback, single-use semantics, and context ownership.
- Added a HIP-gated native integration test covering a non-default stream, repeated enabled/disabled calls, no extra allocation, input immutability, and cast-elision instrumentation.
