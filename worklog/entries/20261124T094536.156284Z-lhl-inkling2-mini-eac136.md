# Add the Inkling residual-stack read and row kernels

## Summary

The four kernels the next step needs are built and tested but not yet wired into a runtime path: row RMS, normalized row, residual add, and the residual-stack read. The host reference session keeps its NumPy expressions, and each device variant has a registered host counterpart.

## Changes

- Add `norm/inkling2_residual.hip`: `row_rms` (per-row normalization, in-place safe), `row_norm_mul` (normalization times a coefficient row), `row_add`, and `residual_read` (softmax of `query . values / sqrt(width)` over the normalized residual rows, then the mix). All four use one fixed reduction tree, so repeated launches are bit-identical.
- Register the device launchers as `inkling2_residual` `row_rms`, `row_norm_mul`, `row_add` and `residual_read`, with `host_row_rms`, `host_row_norm_mul`, `host_row_add` and `host_residual_read` as the strict counterparts that call the reference session's own expressions.
- Nothing selects them yet: the resident block traversal that consumes them is the next unit, so no profile-plan selection is declared.

## Validation

- New `tests/test_gpu_inkling2_residual.py`: the three row kernels match the host expression at `(rows, width)` of `(1, 2304)`, `(3, 2304)`, `(64, 2304)` and `(7, 384)`, including in-place normalization; `residual_read` matches `_mix_residual_rows` at `(rows, blocks, width)` of `(1, 18, 2304)`, `(3, 18, 2304)`, `(3, 2, 2304)` and `(2, 9, 384)`, and reproduces bit-identically on a second launch. Eight cases pass on W7900.
- One defect was caught by the tests and fixed before the commit: the normalization kernels returned the reciprocal root but divided by it, so every row came out scaled by `mean(x * x)`.

## Next

- Wire these into a device-resident block traversal: `h` and the residual stack stay in one arena for the whole 64-token block, the expert chain reads and writes arena pointers instead of staging through the host, and only the final hidden rows come back. The measured baseline to beat is 2.9 s for 575 tokens on W7900, of which about 1.25 s is GPU work and the rest is host math and one host round trip per visit.
