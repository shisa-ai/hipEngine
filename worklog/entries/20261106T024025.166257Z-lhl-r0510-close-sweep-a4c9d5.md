# Sweep all scratch probe sessions on cleanup failure

## Summary

Drain all acquired scratch probe sessions even when one cleanup action raises.

## Changes

- Shared AR/MTP cleanup helper pops every owner before reporting failures in a
  BaseExceptionGroup. Failed probes discard; successful retained probes pool.
- Preserve an original probe exception as the cleanup exception context.

## Validation

- RED: injected first-close failure leaves sibling unclosed;
  `/tmp/r0510-close-red.log`.
- GREEN: all four scratch probe tests pass; `/tmp/r0510-close-green.log`.
  Ordinary failure and KeyboardInterrupt with release/retain remain covered;
  injected close failure confirms both session owners receive close calls.
- This cannot guarantee a failing session.close released its own allocation;
  it guarantees cleanup continues for sibling owners and reports failure.
