# The calibrated packet is the REFACTOR dense27B item's own Next step, and localizes it to the cross-route comparison

## Summary

The running calibrated packet is not an extra check bolted onto the prefix work:
it is the prescribed remedy for `docs/REFACTOR.md`'s first ledger item, executed
as written. Recording the mapping so the packet's result closes that item rather
than adding a parallel number.

`docs/REFACTOR.md` "Dense27B prefix oracle disagreement after prefix/MTP
integration (2026-09-20)" states the defect and the remedy:

> The serial oracle is not numerically equivalent: English and mixed-category mean
> KL exceed the production envelope, and completed-source Japanese fails even the
> outer numerical smoke. Do not call this full production numerical qualification
> or hide it behind the passing clone/ownership checks.
>
> Next: localize the one-shot-prefix versus batched-prefix divergence using matched
> teacher rows and real category/heldout prompts; then run the calibrated
> production envelope and task gate.

The packet matches that remedy term for term: matched teacher rows
(`--teacher-forced-steps 128`), real category prompts *and* heldout prompts (eight
suites: `category-{code,general_en,general_ja,mixed_ja_en}` and
`heldout-{code,general_en,general_ja,mixed_ja_en}` from
`benchmarks/prompts/mtpbench-code-general-ja.jsonl`), and the calibrated
production envelope (the section 6.1 mean/p95/p99/max and top-1 bars, read per
scope from each artifact's `passed`).

The localization is the reference route. `--reference-prefill-mode` defaults to
`packed` (`scripts/gguf_prefix_reuse_gate.py:1235`), and the flag's own help text
names the mechanism: the packed wave and the single-session path persist different
final-state arithmetic, so a single-session prefix makes the numerical comparison a
cross-route comparison. The serial/native oracle was that single-session route, so
the "not numerically equivalent" finding describes the comparison rather than the
candidate. The ledger item already records the corroborating fact that the same
Japanese probe on untouched upstream `1de470e21` reproduces the records exactly,
which is what a comparison artifact looks like and is not what a merge regression
looks like.

Measured so far on the four natural categories, all `passed: true` with zero
semantic-boundary mismatches: `code` mean 0.0001482 / max 0.00187, `general_en`
0.000286 / 0.01442, `general_ja` 0.000194 / 0.00503, `mixed_ja_en` 0.0001811 /
0.00457. The `general_ja` row is the one the ledger and
`benchmarks/CHANGELOG.md` record as failing the envelope at `kl_mean` 0.681121
with top-1 0.75; it is now 0.000194 with top-1 1.00 and no flips.
