# RF7 stream events owner

## Summary

Extracted the reviewed SSE frame projection and stream-accounting block from
`hipengine/server/api.py` into `hipengine/server/stream_events.py`. The owner
turns already-derived stream values into exact OpenAI-compatible SSE frames and
owns token/timing accounting. It does not parse text or tool calls, choose
finish reasons, build error payloads, read requests, or touch the engine,
batcher, application state, or routing.

Live sequencing remains in `api.py`: engine iteration, cancellation,
backpressure, disconnect handling, literal-stop buffering, tool-call parsing,
finish/error policy, and terminal `[DONE]` yields. The owner has no callbacks
into `api.py` and no compatibility aliases were added there.

Done serializers require prebuilt `finish_details`. Tiny `api.py` wrappers
(`_completion_stream_done`, `_chat_stream_done`) retain the old default-finish
construction point; error wrappers retain the old `_error_payload` construction
point. `chat_tool_call` accepts the existing pure `_ParsedToolCall` from
`chat_output`; no parser was duplicated.

## Changes

- `hipengine/server/stream_events.py` (new): `sse_frame`, explicit
  completion and chat serializers for role/delta/tool-call/done/usage/error,
  metadata projection (`_stream_hipengine_payload`, `_choice_hipengine_payload`,
  `_attach_stream_hipengine`, backend timing), `StreamTokenAccounting`,
  `StreamTimingTracker`, `StreamTimingSource`, and the pure chunk helpers
  `stream_chunk_with_phase`, `stream_chunk_backend_timing`,
  `tool_call_argument_chunks`, and `TOOL_CALL_ARGUMENT_STREAM_CHARS`.
- `hipengine/server/api.py`: imports the owner names at their actual consumers
  and removes the moved definitions. `_stream_token_accounting(engine)` resolves
  `engine.count_tokens` and supplies `_safe_count`; the owner receives only the
  already-safe counter. No old helper aliases remain.
- `tests/test_unit_server_stream_events.py` (new): direct owner contract tests
  for frame bytes, accounting, timing mutation order and finish/error projection.
  The unused `sse_done` helper/test were removed in parent review; terminal yields
  remain application-owned.
- `tests/fixtures/server_stream_events_golden.json` (new): old-HEAD byte traces
  for completion and chat role/delta/tool/done/usage/error frames with
  `include_hipengine` on and off, plus failure/mutation order.
- `tests/test_integration_stream_timing.py`: imports/monkeypatches moved to
  `hipengine.server.stream_events`.
- `tests/test_unit_server_pure_owner_consumers.py`: adds `stream_events` to the
  pure-owner inventory and direct-import checks.

Golden provenance: the fixture was captured from the pre-change HEAD
`f2db17d3f4ed47ad71a7121cbd8c3e29f77658d5` by invoking the old private
serializers with a deterministic clock and explicit values. It records exact
emitted strings, including JSON key order, separators, `ensure_ascii=False`, and
timing/accounting mutation order. The new owner is compared against those bytes
with only documented volatile values supplied by the test.
