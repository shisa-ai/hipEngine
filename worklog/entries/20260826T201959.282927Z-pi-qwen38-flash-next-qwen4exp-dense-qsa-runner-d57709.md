# Compose dense-equivalent Qwen4Exp QSA decode

## Summary

Composed the F5 dense-equivalent QSA decode token mixer with persistent BF16
paged K/V under `KVLiveSpans`: Q+gate/K/V projections, interleaved partial RoPE,
K/V append, dense GQA, sigmoid context gate, and output projection.

## Changes

- Added a bounded dense-attention state owner with separate append-position and
  decode-context span views over one identity page table, BF16 caches, exact
  position updates, and reverse close.
- Added F32 Q+gate split, per-head norm/interleaved text RoPE, and F32 sigmoid
  context gate siblings to the QSA kernel family.
- Added reusable QSA scratch and model-neutral projection composition. This path
  is explicitly the <=2,051-token dense-equality route; sparse selection remains
  F6.

## Validation

- First test run failed closed because the inherited parent attention ABI
  requires 256-token pages; the fixture was corrected from block size 4 to the
  normative 256 without changing production code.
- GREEN: dense QSA runner + native QSA + CPU QSA bundle -> `12 passed` on
  Radeon 8060S/gfx1151.
- Three sequential decode positions match the independent logical-position
  interleaved-RoPE/original-KV GQA NumPy oracle within 2e-4 while exercising
  append/decode span metadata and persistent cache state.
