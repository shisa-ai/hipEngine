# Reject Y3 planar Q6 shared-byte pair

## Summary

Implemented and rejected explicit qmicro record-byte sharing across retained
adjacent-column pair decode.

## Changes

- Added an isolated specialization sharing record/base address, low-byte load,
  and high-byte load while retaining separate scale conversion and LDS stores.
- Preserved the rejected patch and scope-reverted all source/export changes.

## Validation

Both actual-weight rows288 planar shapes remain bit-exact with zero mismatches.
Relative to retained pair decode, wide K17408/N5120 regresses
3.642->3.958 ms (+8.67%) and narrow K5120/N1024 regresses
0.343->0.378 ms (+10.18%). The dependent unpack chain outweighs reduced loads.
