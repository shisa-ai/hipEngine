must fail closed, and Q8 peer-backend scope tests must be independent of test order.

  its numerical screen, finiteness, requested native route, or existing
  KL/top-1 repeat-signature comparison. JSON is written for failed verdicts.
- Console passed status is aggregate, not just the first repeat's screen.
- Nonpositive repeats/prompt tokens/limit and empty suites fail before model load.

  whole file failed but its final gfx1151 node passed alone.

  teacher selection, full-logit determinism contract, or serving admission changed.
