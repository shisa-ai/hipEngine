# Definitive 5-pair verdict: layer-2 grouped routing is a regression (rejected)

## Summary

Five counterbalanced baseline/candidate pairs in a single thermal window show
layer-2 grouped routing (`HIPENGINE_QWEN4_EXP_GROUPED_MOE_PREFILL=1`, routes the
Q5_K gate/up through the grouped WMMA body) is a **consistent, statistically
significant ~1% regression**, not a win. Paired mean diff -0.81 tok/s, median
-0.97, t=-5.28 (n=5). The absolute level drifted 88→81 tok/s (warming) but the
paired difference stayed negative every pair. The earlier n=3 "neutral" reading
(20260830T220900) was underpowered; this is the powered verdict. This closes
the P1 layer-2 routing question: the grouped WMMA body does not beat the strict
chain at the real p512 layer-2 active-row distribution; grouped overhead
(count/prefix/scatter) exceeds any WMMA gain. Layer 2 stays on strict.
