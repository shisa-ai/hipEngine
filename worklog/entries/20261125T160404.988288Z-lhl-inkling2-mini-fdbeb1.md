# Record the Strix Halo rows of the wave block attention

## Summary

The profile gate of the Inkling GGUF model ran on the Strix Halo (`strixhalo`, Radeon 8060S,
`gfx1151`) for the first time, from a clean worktree at `832d43611`, mainline `UD-Q4_K_M` (the
same file as the W7900 rows, SHA-256 `78fcedcf93c5...`). The runtime is the TheRock SDK 10.1.0 of
the `therock` environment and its `hipcc` (HIP 7.16). Both flagged arms pass every gate.

On the flagged arms the other gates pass: three bit-stable repeats, 25 of 25 requests bit-identical
in the reversed-order replay, the public route reproducing the captured route, and the 12
known-answer cases with the candidate's generated IDs equal to strict's on all 12. The two arms
give the same numbers, so the graph replays the eager visit bit for bit there as on the W7900. The
arm without flags fails on code prompts as it does on the W7900: KL p90 0.076 on the 48 code rows
and 6 damaged rows.
