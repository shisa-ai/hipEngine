# Harden public GGUF MTP cancellation boundary

## Summary

Added explicit cancellation/deadline checks immediately after both draft proposal paths in the public llama-compatible GGUF MTP loop. Previously a cancellation arriving while draft work was in flight was not observed until the next cycle and could still enter target verify/commit. The failure boundary already freed request-local MTP KV buffers and closed rather than pooled the draft/session; the new checks now reach that cleanup before target state mutation.
