# Install deterministic SPECDEC2 K0 cost policy

## Summary

Replace the server's unstructured automatic-MTP rejection constant with an
immutable, fingerprinted, prompt-independent offline depth policy. Same-host
C1/C2/C4 measurements all fail the >1.10x automatic-cell requirement, while
C3/C5-C32 lack a qualified complete physical frontier. Every automatic cell
therefore selects K0 before provider/target mutation; explicit requests retain
the qualified S4 K1-K3 path.

## Changes

- Add validated immutable depth-cell, policy, and decision records with a
  canonical SHA-256 content fingerprint.
- Install disjoint C1, C2, C3, C4, C5-C8, C9-C17, and C18-C32 cells plus a
  fail-closed outside-range decision.
- Resolve automatic routing from realized concurrency and output horizon only;
  no prompt text/token/category/heldout fields exist in the policy API.
- Report policy cell, selected K, policy reason/fingerprint, and evidence in
  generation route metadata and capability discovery.
- Preserve explicit MTP behavior and automatic true-AR selection.
