# Document general native U4 applicability

## Summary

Generalized the native-IU4 result beyond the rejected tiny-M MTP thesis. The
measured 1.99x arithmetic lane is most applicable to current compute-bound
dense prompt prefill, while packed concurrent linears and sufficiently dense
MoE groups remain secondary candidates. KV-cache use is technically possible
but is primarily a storage/bandwidth and quality thesis rather than a direct
TOPS opportunity.

## Changes

- Added an operation-level applicability checklist and measured-roof crossover
  regimes: BF16/IU8 becomes compute-bound near M63 in the optimistic packed-W4
  model, while IU4 reaches its own compute crossover near M124.
- Ranked current hipEngine surfaces. Dense Qwen3.8 bulk prefill is the first
  candidate; c>N linears require a clean batch control; selected MoE depends on
  per-expert rows; singleton decode and elementwise/state surfaces are deferred.
- Documented a separate K4/V8-first KV-cache path preserving float softmax,
  `KVLiveSpans`, and registered KV storage/backend ownership.
- Added a bounded non-MTP experiment order requiring the current bulk
  F16-WMMA/BF16-boundary owner as control rather than reusing R2's repeated
  decode-rowtile comparison.
