# Retain SPECDEC2-PERF P6 physical Q4 route

## Summary

Retain and default the exact gfx1151 standard-Q4 physical-row route admitted in
P5. Four Q4T16 shapes at rows6/8/12/16 now use the existing exact single-wave
parent instead of the four-wave shared-B owner designed for 256 rows. Narrow V,
wide-K down, all row/shape misses, and peers retain shared-B. No kernel body,
arithmetic, representation, engine, or model ownership changed.

Clean cached R6/R8/R12/R16 profiles improve target wall
**2.35%/2.05%/1.99%/1.74%** and complete cycle
**2.17%/1.86%/1.78%/1.40%**. Clean full-suite C2/C4 staged throughput improves
**5.618→5.718 (+1.77%) / 9.183→9.331 tok/s (+1.61%)**, and every category is
positive. C1, outside selector scope, is exact and +0.37%. Physical SPECDEC2
still loses to true AR because acceptance remains 18.43%, so automatic/product
policy stays K0 even though the scoped projection route is the default.
