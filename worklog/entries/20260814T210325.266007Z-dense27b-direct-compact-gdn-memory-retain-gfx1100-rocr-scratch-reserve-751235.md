# Retain gfx1100 ROCr scratch reserve threshold

## Summary

Retained a homogeneous-gfx1100 process-start default of
`HSA_SCRATCH_SINGLE_LIMIT=33554432`. ROCr 7.2.4 reserves its default 140-MiB
threshold per process/GPU even though the dense prefill attention dispatch uses
300-MiB use-once scratch. Lowering the reserve to 32 MiB removes 106.3-108.9
MiB from clean whole-device peaks without changing tracked hipEngine ownership,
kernel scratch, arithmetic, or throughput. Memory parity remains open.

## Changes

- Added the gfx1100 scratch threshold to backend process metadata applied before
  `libamdhip64` loads. Existing user values win, and mixed recognized arches
  receive no backend-local default.
- Added process-environment tests for default, override, and mixed-arch behavior;
  retained the independent gfx1151 two-queue policy.
- Published
  `benchmarks/results/2026-08-15-gfx1100-rocr-scratch-reserve-retained.json`
  and refreshed the benchmark rollup, changelog, campaign summary, environment
  reference, benchmark protocol, and synchronized root README.

## Validation

- `uv run pytest -q tests/test_gfx1151_backend.py tests/test_hip_runtime.py`:
  **34 passed**; the default is applied before runtime load and explicit/mixed
  policies are preserved.
- Configured compact-peer verify: **3 passed**. Configured routing/liveness
  guard: **77 passed**; the tracked 4K arena remains **372.375 MiB**.
- ROCr `rocm-7.2.4` source defines a 140-MiB reserved threshold and use-once
  scratch above it. Cached `rocprofv3 --kernel-trace --scratch-memory-trace`
  identifies only `attn_fwd` as scratch-bearing: **16 launches**, **3,200
  bytes/thread**, and **16 x 314,572,800-byte allocation/free pairs**. The
  selector-unset and explicit 32-MiB traces retain those records; traced kernel
  sums move only **+0.099%** versus the upstream-default control.
- Clean RX 7900 XTX 512/1K/4K/8K reruns report
  **972.069/1005.877/987.316/820.285 tok/s** prefill and
  **33.525/34.522/31.374/29.362 tok/s** decode. Relative to the fresh paired
  512 rollback and retained same-route controls, throughput moves no more than
  **0.104%**, tracked bytes are identical, and whole-device process deltas fall
  **108.012/108.871/108.852/106.332 MiB**. All logits are finite and IDs are
  3/3 exact.
- Clean W7900 4K/128 moves prefill **883.024 -> 882.470 tok/s (-0.063%)**,
  decode **26.545 -> 26.556 (+0.042%)**, and whole-device process delta
  **16.776783 -> 16.670509 GiB (-108.824 MiB)** with exact IDs. A separate
  Qwen3.6-35B-A3B 512 cached prefill smoke completes at **2535.573 tok/s** and
  tears down cleanly.
