# Audit Q4 T16 rows 2-8 and fail qmicro widths closed

## Summary

Review of the recent physical-row tuning found that commits `76bc14e95` and
`1ec78558b` had extended the standard dense Q4T16 single and pair rowtiles to
rows 5-8, but the strict primitive fixture still covered only rows 2-4 and its
argument test still asserted that row 5 must fail. Expanding the RED gate found
a separate real dispatch bug: the byte-neutral Q4 qmicro layout still has only
rows 2-4 C launch cases, while the generic native dispatcher attempted its
registered rowtile at rows 5-7. That route returned `hipErrorInvalidValue`.
Row 8 happened to miss the dispatcher cap and fall back.

This did not affect the measured W7900 Qwen3.8 artifact because its dense
gate/up residents use standard Q4T16 (`GGUF_DENSE_Q4_QMICRO_T16_GATE_UP=False`),
but it was an unsafe peer-layout route and made the generic `2 <= rows <= 8`
claim false.

The same review closed the dirty Q4 `ROW_TILE=16/32` prototype. Its retained
single-tile diagnostic measured down projection row8 `0.1530 ms`, row16
`0.2744 ms`, and row32 `5.3206 ms`: row16 is only `1.115x` faster than `2x8`
(`0.3060 ms`) and row32 is `8.69x` slower than `4x8` (`0.6120 ms`). The probe
was L3-resident, used per-call synchronization, printed an incorrect
multi-group estimate, and had no correctness/product route. The two tracked
prototype hunks and all six obsolete untracked `tmp_*` probes were discarded;
no measured production path was removed.

## Changes

- `hipengine/runtime/gguf_linear.py`
  - Added a quant-keyed standard-Q4/qmicro rowtile support map: standard Q4T16
    rows 2-8, qmicro rows 2-4.
  - Applied it to both single-linear native dispatch and fused pair+SiLU
    dispatch, so qmicro rows above 4 fail closed to the registered WMMA or
    unfused projection chain instead of launching an unsupported rowtile.
- `hipengine/kernels/hip_gfx1100/quant/gguf_t16_selected_gemv.py`
  - Split the Python argument contract into rows2-8 and rows2-4 checks so
    qmicro, residual, and col4 wrappers reject unsupported widths before HIP.
  - Corrected standard single/pair rowtile docstrings to rows 2-8.
- `tests/test_gguf_t16_selected_gemv_decode.py`
  - Extended the standard Q4T16 single and dual bit-exact gate through every
    row 2-8.
  - Added a 2-4-row chunked pack8 exact oracle for rows 5-8 and retained the
    col4 comparison only inside its supported rows 2-4.
  - Corrected wrapper range assertions and pinned qmicro row 5 rejection.
- `tests/test_gguf_q4_k_t16_dense.py`
  - Walked standard/qmicro single dispatch at every row 2-8.
  - Pinned qmicro pair rowtile only through row 4 and explicit fail-closed
    behavior at rows 5/8.
