# UD-U1 commit 4: native-XL manifest recomputed from actual tensors, UD draft scope refusal

## Summary

Two draft-admission bindings for UD-U1. (1) The `qwen38_native_xl_v2` variant
exception in the NextN validation is now bound to the ACTUAL artifact: the
canonical output-type manifest is recomputed from the file's own tensors
(same form as `scripts/qwen38_mixed_quant_plan.py`:
sha256 of `name=type` lines over the sorted full inventory) and must equal the
claimed metadata digest AND the certified native-XL pin. A foreign artifact
that stamps the variant metadata and the pinned digest while its draft qtypes
merely coincide with the expected map is refused. (2) The NextN draft
materializer refuses artifacts whose admission preset is not MTP-scope
certified BEFORE the strict draft validation, planning, or any allocation, so
AR-only certified UD presets cannot enter draft materialization.

## Changes

- `hipengine/loading/qwen35_gguf_nextn.py`
  (`validate_qwen35_gguf_nextn_tensor_map`): for the native-XL variant,
  recompute the manifest digest from `info.tensors` (hashlib import added);
  emit distinct dtype errors for "claim does not match reality" and "reality
  is not the certified native-XL manifest". Non-native-XL validation is
  untouched (no manifest gate).
- `hipengine/loading/qwen35_gguf_nextn_materialize.py`
  (`materialize_qwen35_gguf_nextn_weights`): resolve the AR artifact preset
  from the same reader (structural NextN map for the fingerprint,
  GGUFModelInfo-guarded for stub-based tests) before the strict map build;
  raise `Qwen35GGUFAdmissionError` with the AR-only/MTP-distinct reason when
  the resolved preset lacks the MTP scope; pass the preset key into the
  packaged hot-vocabulary identity (from commit 3).
- `tests/test_gguf_ud_admission.py`: spoof fixture typed exactly as
  `_EXPECTED_QWEN38_NATIVE_XL_QTYPES` (eh_proj/attn_q/attn_output/ffn Q6_K,
  attn_k/attn_v Q8_0) with the variant + pinned digest stamped — refused with
  both recomputation errors; a truthful foreign digest is still refused by
  the certified-pin comparison; non-native-XL validation unchanged; the real
  UD K_M file's draft materialization is scope-refused before allocation
  (allocation sentinels never fire); the synthetic UD-shaped-but-unpinned
  manifest stays on the plain lane (no preset), pinning that refusals bind to
  pinned manifests, not to "looks like UD".
