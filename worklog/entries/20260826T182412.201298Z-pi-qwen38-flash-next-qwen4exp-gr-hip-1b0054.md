# Add strict Qwen4Exp GR HIP primitives

## Summary

Added the first F4 native unit: strict raw-pointer HIP primitives for Qwen4Exp
grouped residual RMSNorm, gated branch mean, branch injection write, and the
sigmoid-gated GDN output norm. gfx1151 resolves the shared gfx11 bodies through
its peer backend alias registry.

## Changes

- Added one in-tree HIP/C-ABI family; no external kernel body was copied.
- Grouped norm consumes BF16 widened state and direct F32 folded gamma, emitting
  F32; gated mean and GDN norm remain F32; GR write emits BF16 state.
- Registered explicit strict variants; quant projections remain separate
  registered primitives, providing the required unfused GR fallback chain.
