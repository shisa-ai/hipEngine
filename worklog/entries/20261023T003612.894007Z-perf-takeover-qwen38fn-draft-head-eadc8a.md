# Implement request-local MTP subset scoring

## Summary

Implement the authorized request-local MTP subset head after transaction
cleanup `71a2e58f7`. Baseline public outputs and timings are in
`benchmarks/results/2026-10-23-gfx1151-flashnext-mtp-cursors.json` and the raw
`public-final.json` / `suite-final.json` files under
`/tmp/qwen38fn-mtp-state-20261022/`. Keep the same model, host, profile,
prompts, output lengths and sampling controls for the final comparison.

## Changes

- Inspected Gufo `f020bd3a037d58aa42138ca11fa895524e43cdd6` in the read-only
  review checkout `/tmp/gufo-qwen38fn-review-TL2uBy/`, specifically
  `src/models/qwen38_flash_next/draft_vocab.hpp`. Its proposal head scores
  the first 98,304 IDs plus up to 1,024 special/request-used extra rows,
  with a request-local recent-miss rule and full-head fallback.
- A bounded child assignment owns only the CPU policy and its tests in
  `hipengine/speculative/draft_vocab.py` and
  `tests/test_unit_mtp_draft_vocab.py`. The main session owns runtime and
  generation integration, device ID mapping, public checks and commit.
- The current provider uses deterministic proposals, including for sampled
  requests: target draws and match/reject decide the output. Subset scoring
  must leave target probabilities, controls, RNG ownership and verification
  authoritative. Do not import Gufo's sampled-proposal correction into a
  deterministic-proposal provider.
- Added `MTPSubsetHead` reusable request-owned extra-row storage, padded
  projections with valid-score-only argmax, and exact device global-ID mapping.
  Request begin/reset and committed-only catchup are wired into both the
  cooperative provider and mixed scheduler. Full-logit capture keeps the full
  head; unsupported layout, resource limits and recent misses have explicit
  full-head diagnostics. The default compact path uses subset scoring.
- The initial screen found exact prefix logits but changed extra-row logits
  (maximum absolute difference 4.77e-7). Dispatch tracing identified the
  existing narrow pack8 256-thread reduction. Keeping its 128-thread parent
  for extra rows makes selected logits exact. The screen retained all failed
  attempts, including its initial too-small 1K context configuration.
