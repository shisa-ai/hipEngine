# DE-1 promoted: the decode dp4a logical128 linear is the production default

## Summary

Ledger row DE-1 is closed on its first follow-up unit: the decode dp4a
logical128 linear is now the production default for `gguf_ud_q4_k_xl` on
gfx1151, cutting **7.244 ms/step (-13.27%)** from decode kernel time.

The promotion itself is one line. `HIPENGINE_QWEN4_EXP_Q4_DP4A64` was already
set to `"1"` by the base profile at
`hipengine/generation/qwen4_exp_profiles.py:767`; the blanket September 14
arithmetic-recovery sweep was the only thing suppressing it. Moving the flag
into `PRODUCTION_Q8_QSA_RESTORED_FLAGS` restores it through the mechanism the
file already documents.

**The decisive evidence is the per-kernel join, not the wall.** The owner
`gguf_q4_k_selected_dual_silu_logical128_t64` falls **14.155 -> 6.908 ms/step
(2.049x)** and the decode kernel sum falls **54.603 -> 47.359 ms/step**; the
non-owner sum is **40.448 vs 40.451 ms (0.007%)**, so the change is confined to
the kernel it targets. The 2.049x reproduces the shape screen's 2.0x.
