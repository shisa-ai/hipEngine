# coalesce ready default-AR admission cohorts

## Summary

Task #29 now has a RED/GREEN, source-clean benchmark candidate. The server batcher previously recognized independent generation and immediately launched every compatible default-route item as its own asynchronous model call. Each call became a separate EngineService command; the sole driver could poll after the first command before the remaining ready items were admitted, producing the measured C2/C3 native-prefill group race despite a 20 ms frontend window.

The candidate preserves independent semantics by changing only admission publication: all compatible items already ready inside the batch window become one EngineService `submit_many` command. Each prompt still owns its own child state, collector, cancellation token, result handle, completion, failure, backpressure, and reclaim. Dynamic arrivals use free capacity in a later cohort.

## Changes

- Added `EngineService.submit_request_batches`, which splits each frontend request into children, flattens them into one existing `submit_children` command, and reconstructs per-item handle groups.
- Added the internal torch-free `LLM.submit_independent_batches_detailed` seam, preserving each item's `SamplingParams` and cancellation token.
- Default-route batching gathers only currently ready items with the same route/sampling key and within remaining active capacity; other routes, streaming, incompatible items, and engines without the seam retain existing behavior.
- Added per-item asynchronous handle completion and active-capacity release, shared queue-group metadata, isolated errors, and `HIPENGINE_SERVER_DEFAULT_AR_READY_COHORT=0` same-build rollback.
- Added the rollback/removal trigger to `docs/REFACTOR.md`.

## Validation

- RED: atomic EngineService admission method was absent; the batcher never called the ready-cohort seam and timed out waiting for it.
- GREEN focused contracts prove all children are active before first poll, per-item sampling/token identity, fast-before-slow completion, dynamic late arrival, independent active-capacity release, child-failure isolation, and rollback to separate calls.
- Full EngineService plus all server generation-batcher contracts pass 58/58; Python compilation, worklog validation, and diff hygiene pass.
