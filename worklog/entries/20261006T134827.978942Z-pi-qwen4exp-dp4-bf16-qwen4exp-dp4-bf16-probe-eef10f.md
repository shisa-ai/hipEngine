# DP-4 BF16 dense-wide operand screen is rejected on the bounded arm

## Summary

DP-4's bounded BF16 dense-wide operand screen is complete and rejected on cost.
The opt-in `dense_wide256_bf16in_f32_f32_out` sibling keeps the production
128x256 tile and output ABI, consumes pre-rounded BF16 activation bits, rounds
the Q8_0 dequantized weight tile to BF16 in LDS, and uses native gfx11 BF16
WMMA. It has no runtime selector or production binding.

## Changes

- Added the BF16 kernel/export and Python registry surface in
  `hipengine/kernels/hip_gfx1100/quant/gguf_q8_0_dense_wide.{hip,py}`.
- Added `tests/test_unit_qwen4exp_dense_wide_bf16.py` for registry/export,
  BF16-reference agreement, and a finite BF16 input at `2**100` (outside F16's
  finite range).
- Extended `scripts/qwen4exp_dense_wide_tile_sweep.py` and the existing export
  parser test. The route remains diagnostic and opt-in.

## Validation

- `uv run pytest -q tests/test_unit_qwen4exp_dense_wide_f16_activation.py tests/test_unit_qwen4exp_dense_wide_bf16.py tests/test_unit_qwen4exp_dense_wide_dispatch.py tests/test_gpu_gguf_q8_0_dense_wide.py --disable-warnings --maxfail=1` — **62 passed** on gfx1151.
- `/home/lhl/miniforge3/envs/vllm/bin/hipcc --offload-arch=gfx1100 -fsyntax-only -x hip hipengine/kernels/hip_gfx1100/quant/gguf_q8_0_dense_wide.hip` — passed with only an unused `--hip-link` warning.
- Synthetic packet, rows 1024 / K 2560 / N 10240, two warmups and five event-timed repetitions: F16 input **1.3313 ms / 40.33 TFLOP/s**; BF16 input **1.3577 ms / 39.54 TFLOP/s**, **+1.99% slower**. BF16 max absolute difference versus F16 was 0.5444, confirming a distinct arithmetic arm.
- Real Q8_0 `attn_qkv.weight` at layers 16, 22, 34 and 46, rows 1024, reproduced the ordering: F16 medians **1.3147, 1.3164, 1.3189, 1.3187 ms**; BF16 medians **1.3429, 1.3381, 1.3375, 1.3373 ms** (**+1.6% to +2.1%**). The packet compares pre-converted operands, and production already hoists/reuses the F16 conversion, so there is no producer/consumer benefit to offset BF16's slower consumer.
