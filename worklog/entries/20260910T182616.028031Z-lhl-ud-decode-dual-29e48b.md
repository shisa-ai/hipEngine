# Decode lever 1: IQ4_XS gate/up dual local32 + SiLU - bit-exact, +1.0% decode

## Summary

The first decode-backlog lever landed: a fused IQ4_XS gate/up dual + SiLU
local32 decode owner, replacing 40 single launches per token (20 layers x
gate+up, K=5120 -> N=17408) with 20 fused ones and folding the SiLU
multiply. The owner is bit-exact with the unfused
single/single/silu_mul path - proven at kernel level (real-tensor test:
every bf16 output bit identical) and end-to-end (the tokenized category
gate reproduces the archived pre-dual run bit-identically). Measured:
decode 26.20 -> 26.46 tok/s (+1.0%), pure-kernel 35.23 -> 34.92 ms/token,
launches 898 -> 858 per token. The fusion win is real but modest - the
single is weight-bandwidth/latency-bound, so sharing activation reads and
the LUT buys ~13% on the fused group. The bigger local32 lever is a
decode-oriented repacked layout (the single reads 530 GB/s effective vs
the part's ~1.6 TB/s); recorded in the ledger as the follow-on.
