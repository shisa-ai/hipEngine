# Rebuild IU4 candidate core

## Summary

Completed R6, B4, and the R7 dense-prefill speed screen. R6 replaces the
one-accumulator/24-VGPR K16 kernel with paired-K32 aligned loads, a tiny-M DOT8
backfill, and a 16-accumulator-per-wave M256-blocked IU4 WMMA owner. The final
wide object is local128/VGPR192/LDS8192 with 32 reported scratch bytes and an
upper-bound eight VGPR-limited waves/SIMD. M128 executed arithmetic rises
12.54→64.39 TOPS (5.13x) versus R2.

R7 is decisively positive on the actual layer-0 gate/up pair. Operation-complete
current pack8/F16→IU4/S4 is 3.818→1.431 ms at M64 (2.668x), 3.940→1.455 at M128
(2.708x), 4.152→1.534 at M256 (2.707x), and 8.198→2.640 at M512 (3.105x), with
15/15 candidate wins at every shape. The pp512 gate/up-family Amdahl projection
is 40.59% current wall and 1.380x complete prefill, but this is inferred from the
prior 396.09-tok/s Q4_K_S packet rather than a measured complete-model result.

This is not a product retention. S4 still re-quantizes dequantized Q4_K_S at
~15.9% weight NRMSE; no original-weight product, down projection, full-logit
quality, BF16-relative, category/task, sidecar manifest, or runtime route exists.

## Changes

- Reordered both S4 weights and U4 activations from K16/8-byte fragments to
  paired-K32/16-byte fragments. The independent I32 probe and host unpack oracle
  changed with the physical layout; correction/scales/BF16/SiLU math did not.
- Added the tiny-M `u4s4_dot8_rowtile` operation-complete body solely for B4.
  It streams each S4 word once and reuses it across active rows; this does not
  reopen the rejected tiny-M product lane.
- Added `iu4_wmma_bulk_m256`: four waves, two N16 tiles, four M16 tiles/wave,
  16 independent gate/up accumulators, paired-K dwordx4 loads, and one shared
  8-KiB S4 stage per 256 physical rows. Shape checks/wrappers now cover M2-M1024
  without model/layer constants, and the registered qmicro strict fallback is
  unchanged.
- Added a second bulk-shape GPU oracle row (M37), extended artifact
  implementation-quality accounting for DOT8 versus WMMA routes, and added the
  R7 A/B harness plus pure padded-work/Amdahl tests.
- Added compact B4 and R7 artifacts; updated `MTP-IU4.md`, kernel catalog,
  refactor ledger, and benchmark changelog.

No new arithmetic RED was needed: this is a scheduling/physical-layout rewrite
under the existing independent CPU oracle, and R2's one-chain throughput is the
performance RED. The unchanged CPU formula caught every physical-layout edit
through the GPU probe/operation tests.
