# Price retained target and provider checkpoint allocation unions

## Summary

Retained-boundary trimming now prices the union of target and matching provider
owning device allocations, including target arena padding. R0509 remains open.

## Changes

  drops provider checkpoint with target boundary. Idle/quarantined pool storage
  is not a live retained entry and still needs separate resource accounting.
