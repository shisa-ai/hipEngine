# Screen packed Q4 metadata broadcast decode

## Summary

Reject and restore the same-payload packed-metadata specialization for the
retained Q4T16 split-weight gate/up+SiLU owner. Replacing 32 per-lane scale/min
byte loads with eight packed-quartet wave broadcasts changes three actual-layer
medians **1.434625 -> 1.435730 ms (0.99923x, 19/45 wins)**. Layer 8 regresses
0.621%, not all layers are positive, and the post-grouped 4K projection is
**-0.380 ms / -0.0294%** selected kernel wall. Direct standard-T16 metadata
loads remain production.

## Changes

- RED required a missing diagnostic wrapper and failed collection before it
  existed. GREEN instantiated a same-resident 128-thread split-weight body.
- Each eight-lane K32 group loaded four packed scale quartets and four packed
  min quartets once per K256 tile, then exchanged them with eight wave32
  broadcasts. Direct `d/dmin` loads, quant values, Q8_1x2 activation reads,
  dot/FMA order, two-wave reduction per weight, BF16 round trip, and SiLU store
  were unchanged.
- This was materially narrower than the earlier rejected Q5 coefficient path:
  it exchanged eight packed byte words rather than 32 FP32 coefficients and
  retained the already-qualified low-VGPR split-weight geometry.
- Removed all transient kernel, launcher, Python wrapper, and test changes after
  the leaf failed. Production source and tests match base; only durable negative
  evidence remains.
