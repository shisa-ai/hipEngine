# Qualify Qwen3.8 bounded INT8 KV serving

## Summary

Qualified the retained Qwen3.8 pure FP32-scale INT8 KV implementation as an
explicit single-request AR capacity route. The geometry-planned layer-outer
schedule reuses one exact BF16 K/V oracle pair instead of 16, reducing the
32K-capacity tracked peak by `1.613554 GiB` versus the old INT8 route and
`0.589994 GiB` versus BF16. Real RX 7900 XTX server requests complete at
64K/96K/112K; 112K is the highest observed pass, while 96K retains the safer
`1.570 GiB` sampled headroom. BF16 remains supported/default because long pure
INT8 is explicitly gated, graph capture fails closed, and natural B3 MTP is
correct but slower than AR.

## Changes

- Published a compact qualification artifact covering implementation ownership,
  complete and long-context quality, matched performance, server high-water,
  graph safety, natural MTP, exact commands, provenance, and raw hashes.
- Updated the benchmark rollup/changelog and K/V-cache/testing/refactor
  authorities. This does not alter the root public topline or BF16 default.
- Qualified the existing commits rather than changing runtime math in this
  unit: `b3dd9a39f` owns bounded prefill lifetime and `12bdf8c52` carries INT8
  scale metadata into MTP reservations.

## Validation

- Complete pure-INT8 512/8 and 4K/16 suites pass all 11 prompts with no BF16
  mirror: weighted mean/max KL `0.000113/0.002293` and
  `0.000146/0.014308`; minimum-prompt top-1 `100%/94.12%`.
- Bounded W7900 `mixed_v1` 64K/16 passes at mean/max KL
  `0.0000334/0.0004162` and 100% top-1. This is one long-context quality row,
  not a complete 64K category suite.
- Matched RX 7900 XTX 4K/128 BF16 graph versus bounded INT8 eager is
  `979.118/31.701` versus `978.626/33.761 tok/s`: prefill `-0.050%` with
  overlapping sample ranges and decode `+6.499%`. Tracked peak/current falls
  `17.920 -> 17.330/17.204 GiB`; every final ID is 9707 and logits are finite.
- Real one-active-request `/v1/completions` rows pass at 65,536, 98,304, and
  114,688 total context tokens. Peak/headroom is `20.564/3.420`,
  `22.414/1.570`, and `23.322/0.662 GiB`; readiness survives each request and
  teardown returns to baseline. 122,880 fails the configured 1-GiB startup
  guard; 131,072 OOMs allocating the shared oracle during eager warmup.
- Pure-INT8 graph capture rejects with the expected admitted-layout guard.
  Eager AR remains faster than BF16 graph, so the AR transport gate passes.
- Full natural25 B3 serial-exact runs all ten prompts with exact greedy outputs
  and GPU/CPU acceptance agreement. True AR is `34.987 tok/s`; B3 is
  `22.472 tok/s / 0.6423x`, so INT8 MTP is correctness-only and not promoted.
- Existing implementation gates: 58 INT8-policy/prefill-liveness tests and the
  focused repaired nodes pass; the MTP session/e2e registration bundle passes
  10 tests. Artifact evidence/hash recomputation, JSON parsing, worklog
  validation, README export synchronization, and `git diff --check` pass.
