# Close structural c32 optimization lane

## Summary

Closed structural c32 tuning without a new implementation. After the exact Q5
col8 promotion, c32 is already a near-linear four-c8 composition. The remaining
product-SLO gap is repeated operation-complete c8 kernel work, not a wider-owner,
grouping, state-copy, queue, or scheduler cliff.

## Validation

Post-Q5 cache-only profile:

- c8 marker/kernel/uncovered = 136.560/129.854/6.706 ms;
- four c8 = 546.239/519.414/26.825 ms;
- c32 = 549.797/515.889/33.907 ms;
- c32 marker overhead is only 3.557 ms / 0.65%; c32 kernel sum is 3.525 ms /
  0.68% lower than four c8 sums; and
- eliminating all extra uncovered time could recover only 7.083 ms / 1.29% of
  c32 wall, nowhere near product-SLO closure.

The major c8 projection grids independently expose 2,176 Q4 qmicro, 640 Q5
col8, and 31,040 planar-Q6 workgroups on 40 CUs. Multi-group execution therefore
competes for saturated compute/weight-stream resources rather than filling an
idle-grid hole.

Existing measured closures bind:

- native c16 341.46 ms versus two-c8 273.90 ms;
- c17 native 9+8 425.86 ms versus 8+8+1 406.50 ms (+4.76%);
- D2 actual owner/serving regression despite captured-cost prediction;
- direct resident slabs already remove cross-group state copies;
- queues 4/8/unset provide no generic/SLO-qualified win;
- fair burst1 ITL is 4.53 s; and
- eight-wave block merge regresses the target family.

No GPU run was needed beyond the retained post-Q5 profile. JSON, Worklog2, and
diff checks pass.
