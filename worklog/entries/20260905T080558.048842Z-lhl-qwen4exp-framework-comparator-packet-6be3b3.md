# Publish Framework Qwen3.8-Flash-Next comparator packet

## Summary

Revalidated hipEngine production and measured the current upstream llama.cpp
and halo-box master HIP/Vulkan builds on the Framework Desktop with the same
Qwen3.8-Flash-Next exact-token protocol. halo-box HIP/Vulkan and hipEngine are

screening comparison and does not freeze a new closure target.
