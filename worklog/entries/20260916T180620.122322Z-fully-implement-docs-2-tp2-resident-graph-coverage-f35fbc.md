# Optimized resident TP1 graph controls and 903-position teacher probe pass

## Summary

The optimized resident TP1 route is ready for **parent review of a product
baseline measurement**, within the scope below. Both physical GPUs passed
matched graph/eager full-logit controls, exact device position/context checks,
and natural teardown. The complete 18-prompt canonical+heldout comparison
against these optimized resident controls passed the calibrated numerical
limits, three same-schedule repeats on **every arm**, and c1 reset/reuse/
sequential-isolation controls. No performance sweep or promotion occurred.

This is an **extended probe**, not a sustained generated-token/task population.
The product chat builder adds four thinking-suffix tokens per prompt compared
with the old diagnostic renderer: the actual population is **903 positions**
(489 canonical + 414 heldout), not the historical 831. All arms consume the
same product-formatted tokens, with no prompt selection or threshold changes.

Artifact: `benchmarks/results/2026-09-16-tp2-optimized-resident-qualification.json`.

`/tmp/tp2-resident-qualification/`. The artifact binds their SHA-256 identities.

## Changes

- `scripts/tp2_xtx_tp1_eager_stage_probe.py`: optional named profile binding and
  declared capacity; graph capture must preserve the host cursor and seed sample
  and prepare the declared device position/context. Two replays must advance the
  device cursor exactly.
  After graph close, reset/prefill/eager reconstruction must reproduce the
  original seed logits and input position, then each replay is compared with
  eager at the same token/position using the full vocabulary and calibrated
  numerical limits. Natural explicit graph/model close and process exit 0 are
  required; successful commands do **not** pass `--os-exit`.
- `scripts/tp2_resident_control.py`: small factory adapter, not a new runtime
  path. It calls the real optimized bulk prefill once with existing hidden-row
  capture, then the normal resident **c1 output norm/head** for each causal row.
  It does not use verifier-shaped head arithmetic or replace TP1 with a token-
  eager control. The final captured row must match the normal product prefill
  logits exactly. Device token rows and position/context metadata are read back
  and checked. The TP2 subclass checks each rank's actual token and position/
  context before layer execution and validates every output row.
- `scripts/tp2_teacher_coverage_broad.py`: extended the existing session-factory
  seam with fresh-process resident capture and CPU-only report modes; reused its
  suite loading, numerical aggregation, category/scope gates, and teacher
  cross-check. Three sweeps plus reset/neighbor/generation boundaries now cover
  every captured arm. Incremental stage artifacts/control logs survive worker
  timeout. A failed worker terminates without subsequent GPU work; the bounded
  sequential controller never starts another arm after a nonzero exit.
- Evidence loading checks normalized profile and scope-manifest hashes,
  per-array shape/dtype/finiteness/hash, complete per-position input/output
  controls, matching model/source/suite/profile, distinct run identities and
  physical GPUs, and natural teardown before scoring. No timing ratios exist
  in this path.
- CPU tests cover immutable manifest normalization, full-trajectory capture and
  final-row consistency, stop on nonfinite output, invalid evidence rejection,
  device-vs-host graph cursor reads, wrong device cursor, and numerical graph/
  eager mismatch. Existing coverage tests continue to exercise the legacy seam.
- No production engine/kernel changes, default changes, MTP work, GPU resets,
  environment restoration, or edits to user `tp2_d1_boundary_bisect.py`/`epyc/`.
