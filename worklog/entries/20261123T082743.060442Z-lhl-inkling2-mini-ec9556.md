# Reuse completed residual rows in scalar Inkling decode

## Summary

Reuse completed normalized residual rows during scalar decode. One traversal owns its matrix and source references, so staged requests cannot share mutable scratch. The prompt-block path keeps its original arithmetic.

## Changes

- Route depth reads for a scalar traversal through a local reader. A shorter or different prefix invalidates the affected rows; the live partial row is normalized and replaced at each read. Ordinary and staged scalar paths still use the same depth-reduction arithmetic and final score shape.
