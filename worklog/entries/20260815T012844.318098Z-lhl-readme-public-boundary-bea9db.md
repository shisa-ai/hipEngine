# Guard public README benchmark exports

## Summary

Made the root `README.md` boundary explicit and mechanically prevented the synchronized benchmark summary from growing into another implementation diary.

## Changes

- Added an agent-wide rule that the root README is a concise public product page; internal optimization history belongs in immutable worklog entries, benchmark artifacts, the benchmark changelog, or benchmark history.
- Added public-export budgets to `scripts/sync_benchmark_readme.py`: at most 80 exported lines, two prose paragraphs, and 600 prose characters in `README_HIGHLIGHTS`, plus a 325-line limit for the resulting root README.
- Added focused acceptance and rejection tests for concise summaries, worklog-style prose, oversized exported tables, and an oversized root document. Tightened the existing root compactness assertion to the same 325-line ceiling.
