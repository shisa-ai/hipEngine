## Validation

- Current-source attribution completes at 1K, 1537 and 4K. Across 116 instrumented
  MTP cycles, median snapshot is 1.234 ms; 104 target verify calls have median
  75.098 ms. These nested synchronized windows are not additive or throughput.
- Alternating synchronized router API windows on Radeon 8060S, rows 1/2/3/4/8/17/512,
  experts 512, top-k 10, hidden 2560, preserve selection/routing/cast bits exactly.
  At four rows the median changes 17.844 to 16.752 microseconds over 100 samples
  after 10 warmups per arm. This is a local launch-window saving only.
  Command: `bash /tmp/qwen38fn-gufo-20261021/run-hip.sh /tmp/qwen38fn-smallrows-20261023/router_screen.py`.
- New dispatch tests first fail in four default cases; after changing the default,
  all 16 pass, including explicit rollback and rows unrelated to verifier width.
- Eight device tests pass (fusion and complete expert output checks); the unit
  tier passes 16,663 collected, 257 skipped, no failures/errors.
- Public route tracing observes 4,704 fused four-row calls plus widths 1/2/3 and
  varied prefill widths. Six lifecycle cases pass. All 208 matched canonical and
  category/heldout requests preserve output IDs and acceptance results.
- Starting/final pooled decode on Radeon 8060S, Qwen3.8-Flash-Next `UD-Q4_K_XL`
  plus Q8_0 draft, production/BF16 KV, budget 3, one active request:

  | Fresh prompt | AR tok/s | MTP tok/s |
  | --- | ---: | ---: |
  | 1024 | 17.153 → 17.177 | 39.273 → 39.235 |
  | 4096 | 14.694 → 14.714 | 39.063 → 39.041 |

  Four categories, one warmup and three measured repetitions per arm, 64 outputs
  (63 transitions), prefix cache off. Rates pool equal transition counts using
  the harmonic mean. No end-to-end MTP speedup is claimed.
  Baseline: `/tmp/qwen38fn-lookup-20261023/validate.py`; candidate command:
  `bash /tmp/qwen38fn-gufo-20261021/run-hip.sh /tmp/qwen38fn-smallrows-20261023/validate.py`.
  Both run the same canonical and category/heldout drivers.
- Final synchronized AR attribution measures post-mixer graph segments at

  attention at 8.85/12.94/16.83 ms for 1K/1537/4K. The segments include expert

  MTP target verification stays about 75 ms median; snapshot about 1.25 ms.
