# Add GPU external DMS sidecar prediction

## Summary

Implemented the missing GPU-resident schema-v2 external-linear DMS decision
source for RDNA3. The 655,488 raw BF16 parameter bytes are uploaded once; each
layer projects the declared BF16 normalized-hidden device pointer to FP32 logits
and uint8 eviction decisions without reading or mutating Q.

## Changes

- Added `dms_external_linear_decision_kernel` to the existing compact DMS DSO:
  one deterministic 256-thread reduction per `(token, KV head)`.
- Registered `dms_decision_source/bf16/external_linear_sidecar_v1` for
  `hip_gfx1100` and `hip_gfx1151`, retaining the CPU-reference fallback.
- Added `DMSExternalLinearDeviceProjector` with one-time BF16 sidecar residency,
  direct raw-pointer projection, exact-key registration repair, and explicit
  close/free ownership.
- Added production-geometry RED/GREEN tests and extended the cached-only rocprof
  harness to all five DMS kernel entry points.

## Validation

- Focused DMS device/runtime family: 46 passed on gfx1151.
- Synthetic 7-token H5120/4KV gate: GPU logits match BF16 CPU reference within
  rtol/atol `3e-4`; all decisions exact.
- Real retained sidecar over all 128 validation shards / 393,216 decisions:
  **0 mismatches**, max absolute logit delta `1.71661e-05`, elapsed 8.55 s.
  The smallest CPU threshold margin was `1.12057e-05`, so exact observed
  decisions—not margin inference—are the retained evidence.
- Cached-only `rocprofv3 --kernel-trace`: external-linear kernel identity present
  at 19.396 us for 7xH5120x4KV, LDS 1,024 bytes, scratch 0, VGPR 16. All five
  profiler tests pass; trace SHA-256
  `9f8d0da686b3171b9c2ba8004afb57222a5edb332e52c2139a3a02d50c31647c`.
- Ruff, py_compile, worklog, and diff checks pass. Raw profiler output remains
  under `/tmp` and is not committed.
