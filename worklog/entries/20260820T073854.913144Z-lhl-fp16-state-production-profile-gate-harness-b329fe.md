# fp16-state production-profile gate harness

## Summary

Added `scripts/execution_profile_gguf_fp16_state_gate.py`, the calibrated
strict-teacher production-profile gate for the fp16 recurrent-state route
(`HIPENGINE_GGUF_FP16_RECURRENT_STATE`). The strict denominator is the
fp32-state version of the same production route
(`chain_compact_peer_wave32`), because the flag changes only the state storage
dtype, not the route or surrounding arithmetic. Because the flag changes scratch
buffer sizing at session construction, strict and candidate each run in their
own resident session with the flag fixed for the whole session (as in real
deployment), rather than toggled mid-session.

## Changes

- New `scripts/execution_profile_gguf_fp16_state_gate.py`:
  - Two-phase capture: a strict (fp32 state) session records the full-logit
    token trajectory plus a Conv/GDN/KV state checkpoint per prompt; a
    candidate (fp16 state) session records three teacher-forced repeats per
    prompt plus state checkpoints.
  - Evaluates with the calibrated `EvaluationThresholds` envelope via
    `build_candidate_quality` (mean/p95/p99/max KL, top-1 overall and per
    category/shape/transition, repeat determinism) and the c1 route gate's
    `build_state_repeat_gate` (finite, layout-stable, byte-repeatable state).
  - Default prompt suite = `mtpbench-code-general-ja.jsonl` +
    `gdn-prefill-category-heldouts.jsonl` (all four required categories:
    code, general_en, general_ja, mixed_ja_en).
- `measurement_valid` requires tracked cleanliness (the tested code is exactly
  the committed state), full suite, repeat determinism, and the state gate. The
  shared worktree carries unrelated untracked benchmark artifacts from other
  agents (258 files, none tracked-dirty), so untracked dirtiness is recorded as
  an explicit `worktree_note` caveat rather than failing the gate.

## Validation

- `--limit 1 --decode-steps 3 --repeat-runs 3` smoke on gfx1151
  Qwen3.8-27B Q4_K_S: quality `hard_gates_passed=True`
  (kl_max 1.4e-5, top-1 agreement 1.0), repeat determinism passed, state repeat
  gate passed (finite/layout_stable/repeatable). `measurement_valid=False` only
  because the suite was incomplete (`--limit 1`).
