# Make F16 prefill staging session-owned

## Summary

Retire R0399/RF-B2A's F16 staging process override and make nested caller/session
ownership explicit. Production still selects staging and strict/fallback keeps
BF16; kernels, arithmetic, supported shapes and bounded workspaces are unchanged.

## Changes

- Remove `PREFILL_F16_STAGING_ENV` and both environment readers (profile selection
  and per-launch enabled lookup). Keep enum/profile resolution and public callers.
- The context-local flag distinguishes no binding from explicit true/false.
  Disabled nested scopes no longer inherit the default true choice. A resident
  session enters from its own `use_prefill_f16_staging`, never an enabled peer's
  outer context. Context and workspace restoration preserve the outer owner.
- Keep workspace capacity, rows17-1024, T16 Q4/Q5 and source-variant checks plus
  registered BF16 fallback. Dispatch-cache tests now switch explicit scopes.
- The composition diagnostic applies `no_staging`, `no_mmq` and `neither` to
  owned sessions; remove its unused environment context stack. No global setter
  or replacement flag is added. Tests check both choices and unrelated peers.
- Remove the active rollback entry, mark ENVS retired and audit the flag resolved.
  Historical analyzer strings name old input arms/commands rather than execute
  current routes; preserve them with the immutable original artifacts:
  `benchmarks/results/2026-09-02-gfx1151-qwen38-b2-f16-{retained,retention-gates,lifecycle}.json`.
