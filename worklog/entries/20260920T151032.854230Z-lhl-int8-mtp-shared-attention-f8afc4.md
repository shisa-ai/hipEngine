# Add shared-table INT8 verifier attention primitive

## Summary

Implemented the uniform shared-page-table INT8 attention primitive needed by
GGUF MTP verifier rows. This is a strict T0 scheduling extension of the in-tree
INT8 batch producer, with unchanged c1 arithmetic and a registered c1 fallback.
It is not yet a claim of full-model INT8 MTP or DMS support.

## Changes

- `paged_attn_decode.hip`: shared-table template specialization with FP32 and
  FP16 scale exports. Each verifier row reads its own live count, so a later
  speculative suffix is not visible to earlier rows.
- `paged_attn_decode.py`: uniform `verify_chain` wrapper and four-axis registry
  variant `per_token_head_gqa_splitk_gate_bf16_verify_chain_spans`.
- CPU-only registry/validation tests and GPU causal shared-cache coverage for
  four/eight rows crossing page and split boundaries, with reversed physical
  pages and strided gate/output. Both scale dtypes are covered.
- Existing ordinary batch route retained. `docs/KERNELS.md` documents the new
  variant and the independent row fallback.
