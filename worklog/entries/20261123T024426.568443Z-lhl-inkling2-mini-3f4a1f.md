# Fuse Inkling expert activation with Q8 input packing

## Summary

The `fast` GGUF decode path now combines split expert activation and Q8 input packing for supported NVFP4 down projections. It no longer writes the intermediate FP32 activated tensor. Strict, prefill, and the other expert layouts keep their existing paths.

## Changes

- Register the fused down variant for gfx1100 and gfx1151 and declare its scope in the fast manifest. The existing split-activation and Q8 projection composition remains the direct parity control; strict keeps its FP32 projection.
