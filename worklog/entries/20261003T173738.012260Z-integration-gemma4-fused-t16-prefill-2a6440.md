# Recover fused T16 Gemma prefill without duplicate weights

## Summary

The correctness integration is committed in `1b1c141f5`. This follow-up
restores the split-parent T16 WMMA arithmetic on the tiles-only fused expert
slab, with explicit fused expert stride and a transient LDS transpose. Default
public regression validation and independent review are running. Nothing has
been pushed; this checkpoint does not declare task #3 complete.

## Changes

- Add a fused expert-major entry to the existing Q4T16 WMMA family. Read the
  gate and up halves from one primary slab with the full expert stride.
- Coalesce row-major resident weight reads and transpose only the small LDS
  window consumed by the existing K-major decoder. GEMV/MMQ residency does not
  change; no raw or second tiles allocation is introduced.
- Register and select the fused owner by the four-axis key, exact registration
  and supported geometry. Keep narrow calls and pinned modes on their existing
  routes, retain the Q5 down owner, and reuse the 16-row map when possible.
- Add fused-stride GPU parent/CPU tests and capability/geometry unit tests.
  The generic registration sweep now restores the T16 prefill family as well.
