## Changes


- RED added the missing three-plane activation quantizer, T16 consumer, guarded queue, and sparse exact correction contracts. GREEN registers `(hip_gfx1100,activation_quant,q8_1_ds4x3,bf16)`, the direct and guarded `gguf_q4_k_t16_v1` MMQ32 variants, and `(hip_gfx1100,moe_linear_repair,gguf_q4_k_t16_v1,selected_dual_sparse_exact_bf16)`. Plane zero is byte-identical to the retained DS4 pack; planes one and two recursively quantize its BF16 reconstruction residual.
- The local128 MMQ body reuses each resident T16 weight tile for all three activation planes. Its guarded form ballots output values near a BF16 rounding boundary into a bounded queue of 16-column tiles. The local256 repair kernel recomputes only queued tiles using the production exact T16 traversal/reduction order; queue overflow deterministically recomputes every output tile. The forced-all-queued and forced-overflow fixtures are both BF16-bit identical to production direct T16 with a nonidentity producer-row map.
- The residual pack reconstructs its BF16 input at relative L2 `<=5e-5`. On the finite Q4_K CPU fixture, three-plane MMQ reduces projection relative L2 **0.002922 -> 0.001826 (-37.51%)**, passes KL `<=0.05`, and preserves top-1 `>=90%`. An FP32 Q4 metadata cache was also screened, showed no quality benefit on this gate/up fixture, and was removed so the retained one-plane 20-byte cache and LAP-1 evidence stay unchanged.
- Dirty actual layer-1 K3072/N1024 diagnostics use the natural M128/M512 routing replay and include producer packing: `HIPENGINE_HIP_ARCH=gfx1151 GPU_MAX_HW_QUEUES=1 PYTHONPATH=. .venv/bin/python3 -u scripts/laguna_q4_k_mmq_leaf_bench.py --routing-json /tmp/laguna-lap1-routing-all-shapes.json --rows 128,512 --layer 1 --modes retained-direct,t16-mmq32,t16-mmq32-d4x3 --warmups 1 --samples 3 --burst 2 --compiler-version-file /tmp/hipengine-hipcc-version.txt --require-cached-build --output /tmp/laguna-d4x3-fp16dm-screen.json`. Retained/direct-D4x3 medians are M128 **13.668/10.607 ms (1.289x)** and M512 **52.427/20.884 ms (2.510x)**. This is diagnostic, not a retained performance claim; no runtime route or default changes.
- `HIPENGINE_HIP_ARCH=gfx1151 PYTHONPATH=. .venv/bin/python3 -m pytest -q tests/test_gguf_q4_k_q8_1_selected_prefill.py tests/test_laguna_q4_k_mmq_leaf_bench.py` reports **35 passed**; `py_compile` and `git diff --check` pass. A cached-only `rocprofv3 --kernel-trace` of both queue-capacity cases names the D4x3 quantizer, guarded MMQ, and exact correction at plausible tiny-fixture averages **6.292/68.909/15.930 us**. The exact fallback caps launch width at 4,096 blocks and grid-strides on forced overflow. Trace database `/tmp/laguna-repair-trace.eMFRUD/gfx1151/113748_results.db`, SHA-256 `a450508518e74e394dfade3336644f9ed3339c828ed1df7a86ea0f9d7a0a1da1`.
