# Screen C8 Q5 source MMQ geometry

## Summary

Screened both hipEngine raw-Q5 MMQ families and a peer-derived I64/J32 source-MMQ geometry against the actual `blk.0.ssm_out.weight` shape at physical R24/R32. The production raw-MMQ path is a modest standalone win, while the first source-compatible peer geometry preserved its parent's output but remained slower than the incumbent grouped-R6/R8 owner. The candidate is therefore retained only as unregistered source code for follow-up instruction-layout work; strict grouped kernels remain the default and fallback.

## Changes

- Added a non-default `i64_j32_k256_q8_1_ds4` source-MMQ kernel modelled on Laurent's traced Q5 geometry: 128 threads, four waves, I64/J32 ownership, K256 staging, and the existing source-compatible DS4 arithmetic.
- Extended the source-MMQ wrapper/test helper to address named tile variants while deliberately leaving the rejected C8 prototype out of the four-axis registry and runtime dispatch.
- Kept current grouped-R6/R8 registry ownership unchanged.
