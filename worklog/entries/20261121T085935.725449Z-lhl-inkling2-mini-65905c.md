# Stage Inkling attention uploads and append KV on device

## Summary

Upload the current attention inputs together, then append key, value, and position on device before running the unchanged FP32 attention kernel.

## Changes

- Pack query, key, value, relative bias, sink, and row metadata into one reusable input buffer. The KV append consumes the same `KVLiveSpans` as attention; rejected rows still restore the original slot bytes and position.
