# Register the Qwen4Exp GGUF model plugin

## Summary

Registered a distinct torch-free `qwen4_exp_gguf` model plugin for
Qwen3.8-Flash-Next. The plugin freezes the text target's layer/state geometry
and expresses PLE, GR, GDN, QSA, top-10 MoE, and final-head ownership without
adding architecture branches to engine or dispatch code.

## Changes

- Added `hipengine/models/qwen4_exp.py` and exported its singleton/type from the
  model package.
- Registered only GGUF architecture `qwen4exp`, with default quant
  `gguf_q4_k_m`; this does not claim HF-safetensors runtime support.
- Declared the 48-layer `GDN,GDN,GDN,QSA` pattern, zero-based PLE layer 1,
  4x2560 residual state, 262K native context, and dense-equivalent QSA limit.
- Kept vision and MTP capability false until campaign F8/F9 gates pass.
- Added frozen llama.cpp PR #27742 qwen4exp tensor-name templates and explicit
  primitive ownership sequences using `KVLiveSpans` on QSA layers.
