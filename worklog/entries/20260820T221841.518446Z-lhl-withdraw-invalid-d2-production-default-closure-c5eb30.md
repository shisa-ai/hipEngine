# Withdraw invalid D2 production-default closure

## Summary

Withdraw the D2 production-default/#29 closure claimed by superseded worklog
`20260820T214043.290728Z-...d2-production-default-29-gate...`. The new evidence
is useful diagnostic model-step data and a positive composed-lifecycle screen,
but neither satisfies the predeclared actual-server gate. Physical c1-c8 width
promotion remains valid from clean #36; only D2 default promotion is withdrawn.

## Findings

1. `gguf_packed_ar_d2_ceiling_sweep.py` constructs resident sessions directly,
   calls `d2_partition`/`ceiling_partition` itself, and invokes eager
   `step_batch_native`. It does not run HTTP, EngineService, scheduler-owned
   `_step_native_rows`, graph replay, or production route telemetry. Calling it
   “actual-server” was false.
2. The sweep artifact has no canonical command or provenance and no TTFT, ITL,
   dynamic membership, server memory, or final drain. D2 always runs before
   ceiling; the order is not counterbalanced. c1-c23 use p512 while c24-c32 use
   p128.
3. Published goodput used `1_000_000 / wall_ms`, giving values wrong by 1000/c.
   Correct examples are c1 28.823, c9 93.137, and c32 123.255 aggregate decode
   tok/s—not 28,823 / 10,349 / 3,852. Relative percentages happen to survive the
   common scale error.
4. The retained composed-c13 lifecycle artifact has `dirty=true` because its
   D2-aware harness changes were uncommitted. The command/provenance also failed
   to record the inherited D2 artifact setting. It is a positive functional
   observation, not qualification.
5. The default cost-map path was repository-relative under `benchmarks/`; the
   wheel includes `hipengine` and `scripts`, not benchmark artifacts. Thus the
   claimed product default silently became ceiling in an installed package.

## Changes

- Restore explicit-config-only D2; absent configuration uses the ceiling
  planner, while invalid explicit evidence raises.
- Correct the sweep's scope and future goodput formula; mark its retained result
  diagnostic/non-valid and add the missing limitations instead of fabricating
  provenance.
- Replace the 631-KiB raw dirty c13 lifecycle artifact with a compact honest
  diagnostic summary; the raw record remains recoverable from Git.
- Add D2 env provenance to the lifecycle collector for future clean reruns.
- Correct `CONCURRENCY2.md`, `REFACTOR.md`, and the benchmark changelog. The
  public benchmark README already correctly kept D2 non-default/open.

## Validation

- Mechanical audit confirms the sweep lacks `provenance`, `command`, `memory`,
  `ttft`, `itl`, `final_drain`, and owner route telemetry.
- Unit RED/GREEN covers aggregate goodput dimensions (c1/40ms=25 tok/s,
  c10/100ms=100 tok/s) and non-positive inputs.
- Final affected host bundle: 149 tests passed. Focused Ruff, Python
  compilation, both JSON parses, Worklog2 validation, README synchronization,
  and `git diff --check` pass.

## Next

- Keep task #29 open. Use the real server/EngineService and actual owner lowering
  for a clean counterbalanced D2-vs-ceiling c1-c32 matrix. Record authoritative
  compositions, aggregate goodput, TTFT/ITL, dynamic refill/cancel membership,
  memory recovery, and final drain under one matched shape protocol (or clearly
  separated shape lanes). Only that evidence can make D2 default.
