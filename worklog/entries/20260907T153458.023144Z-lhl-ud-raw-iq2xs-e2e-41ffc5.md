# UD raw IQ2_XS residency integration and public c1 E2E validation

## Summary

Integrated raw IQ2_XS model residency into the production K_S loading path and
qualified public c1 generation for both published UD files on zbook/gfx1151.
Rank-2 layer IQ2_XS now plans `LAYOUT_RAW_GGUF` in normal loading, removing the
152,494,080-byte dense-BF16 expansion of `blk.0.ffn_gate.weight` (allocated
weight buffer bytes 20,973,418,496, matching the raw-resident diagnostic). A
20-prompt real category/heldout E2E suite through public `LLM.generate()`
completes on K_M and K_S with three byte-identical fresh-process repeats per
file, torch-free, EOS enabled. Scope decision for this lane: gfx1151 only; the
independent-teacher KL gate grind is parked as blocked with evidence, not
continued.

## Changes

- `hipengine/loading/qwen35_gguf_consumer_surface.py`: added `"IQ2_XS"` to
  `RAW_LINEAR_SOURCE_QUANT_KEYS` (quant key `gguf_iq2_xs`) and to
  `_RAW_LINEAR_OUTPUTS` (`bf16`/`f32`), so certified raw-layout linear records
  derive for IQ2_XS like the other raw IQ/Q3 source types.
- `hipengine/loading/qwen35_gguf_materialize.py`: `_spec_for_tensor` now plans
  rank-2 `layers.*` IQ2_XS to `LAYOUT_RAW_GGUF` with the other dense IQ/Q3
  leaves. Non-layer and rank-3 IQ2_XS keep the dense-BF16 fallback; the
  published K_S file stores no such tensors.
- `tests/test_gguf_ud_ks.py` (new): RED-first campaign tests — layer IQ2_XS
  plans raw with `gguf_iq2_xs`/`("raw",)`, no dense-BF16 layer expansion, the
  production dispatch surface declares raw IQ2_XS linear routes, and AR
  preflight on the published K_S file reports zero refusals.
- `docs/UD-QUANTS.md`: header status, U4 c1 validation item, and U5
  IQ2_XS/refusal items reconciled with landed evidence; gfx1151-only lane and
  gfx1100 deferral (no hardware allocation) recorded.
- `benchmarks/results/2026-09-07-zbook-ud-public-c1-generation.json` (new):
  retained E2E artifact. Also committed the previously untracked
  `benchmarks/results/2026-09-07-zbook-ud-embedding-precision.json`
  (f32-embedding hypothesis falsified: mean KL 0.001382→0.001532, p95
  0.003575→0.008598; bf16 embeddings kept; defaults unchanged).
- No kernel, dispatch, sampler, or default-policy changes; the raw IQ2_XS
  route was already certified end-to-end by the prior process-local diagnostic.
