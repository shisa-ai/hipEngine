# Pack dense 27B decode scratch into one owner

## Summary

Promoted a gfx1100/model/quant-scoped private-c1 arena that exposes the same 188 logical decode-scratch views through one physical HIP owner. The complete XTX 512/1K/4K/8K screen saves **55.98/94.30/97.99/98.02 MiB** of whole-device peak with all prefill/decode movement within **0.279%**. The W7900 512 safeguard saves **55.99 MiB** with throughput within **0.046%**, and the dense NextN transaction gate passes. This is an exact incremental win, not memory-parity closure: remaining Vulkan gaps are **0.339/0.495/0.993/0.994 GiB**.

## Changes

- Added a four-axis backend capability for Qwen3.6-27B `MOSTLY_Q4_K_M` and a model-scoped resolver; c>N, shared-runner, peer-model/backend, explicit disable, and arena-allocation denial retain the dedicated path.
- Added one 256-byte-aligned `_FullStackScratch` owner while preserving allocation order, size, alignment, logical pointers, BF16 KV/state layout, and every kernel ABI. Arena views are non-owning and teardown frees only the owner.
- Added allocation-mode/owner-count telemetry plus RED/GREEN tests for 188-to-one ownership, fallback allocation, policy boundaries, and telemetry.
- Added the temporary disable-only `HIPENGINE_GGUF_PRIVATE_C1_DECODE_SCRATCH_ARENA=0` comparison seam and its removal condition to `docs/REFACTOR.md`.
