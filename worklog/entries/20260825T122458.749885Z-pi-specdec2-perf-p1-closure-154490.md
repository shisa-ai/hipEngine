# Close SPECDEC2-PERF P1 common baseline

## Summary

Closed SPECDEC2-PERF P1 on stable physical host `gfx1151`. The new common
bridge measures true Generation-2 AR, current-source direct dense MTP at C1,
and staged Generation-2 SPECDEC2 with the same prompt/request boundaries,
complete/decode-only windows, strict FP32 recurrent state, and cached source.

Current-source C1 is now a real performance premise: full canonical natural25
K1/K2/K3 staged throughput is **12.502/14.294/13.990 tok/s** versus matched true
AR **10.991/10.991/10.993**, or **1.138x/1.300x/1.273x**. K2 is best and positive
in every category (code/general_en/general_ja/mixed **1.344x/1.304x/1.301x/
1.221x**), while direct K2 remains faster at **17.282 tok/s**. C1/K2 draft
acceptance is **453/501 = 90.42%**.

Physical C2/C4 is not close to promotion. Full K2 is **5.630/9.185 tok/s**
versus true AR **15.686/28.861**, with total wall **2.786x/3.142x AR**. It needs
**67.37%/71.07%** total-wall reduction to reach the 1.10x automatic threshold.
Physical draft acceptance collapses to **18.43%** at both widths, creating many
more expensive target cycles; this is separate from the already-known target
kernel cost.
