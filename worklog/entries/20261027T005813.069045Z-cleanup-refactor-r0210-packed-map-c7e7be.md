# Preserve leased page maps during packed graph replay

## Summary

Keep authoritative non-identity leased block tables intact during packed decode
graph metadata refresh. Identity layouts retain their existing fast path.

## Changes

- For non-rebuildable block tables, preserve the initial host-staged mapping and
  redirect the identity-writing metadata kernel to a graph-owned discard buffer.
- Track the metadata mode and staged bytes; free the discard buffer on failed
  capture and graph close. No kernel arithmetic or page-map admission restriction.
