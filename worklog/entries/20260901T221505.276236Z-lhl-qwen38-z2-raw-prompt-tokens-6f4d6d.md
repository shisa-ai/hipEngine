# Add raw-token MTP prompt contexts

## Summary

Added `--prompt-token-ids ID,ID,...` to `scripts/gguf_mtp_bench.py`. The option
uses the supplied IDs as the complete context and bypasses chat templating and
text tokenization. This prevents decode/re-encode drift in the Laurent-owned
teacher-forced proposal capture. Existing text-prompt behavior is unchanged.
Artifacts now identify the prompt source and hash the exact token sequence.
