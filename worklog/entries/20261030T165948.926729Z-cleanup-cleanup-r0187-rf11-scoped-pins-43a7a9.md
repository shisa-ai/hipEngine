# Replace remaining Laguna whole-file source pins with scoped contracts

## Summary

RF-11's remaining `_POST_MERGE_SOURCE_SHA256` re-baselines are gone. Each pin
was standing in for a semantic owner, and each is now asserted directly:
capability resolution, allocation ownership, the pack-reuse scope boundary, the
compaction-mode resolver, and the coverage the dependent GPU/live REDs still
carry. Unrelated edits to those shared files are accepted; mutations of the
protected policy, dispatch boundary or ownership guard fail by name.

The H7U source/trace test was already RED at 91b27fff0: its whole-file
`laguna_moe.py` pin recorded `b37bc2a1…`, the live file is `127c6ce8…` from the
unrelated H8B pack-reuse landing. That is the failure mode RF-11 removes.

## Changes

- Add `tests/_laguna_source_contracts.py`: AST contracts over source text, so
  formatting, comments and unrelated additions are invisible.
  - `assert_h8a_runner_owner` (`laguna_gguf_runner.py`): the capability has two
    and only two reads, both `backend_package_capability` with a `False`
    default; the session policy assignment comes from
    `resolve_laguna_q5_f32_resident_global_cache(self.backend)`; allocation is
    gated by that bit and `self._owns_weights`, owns one all-or-nothing
    `allocate()` transaction, sets `_owns_q5_f32_resident_cache` only in the
    success branch, and `_close` frees only when that bit is set. The owner
    class keeps its 24-plane guards, device synchronize, free-on-failure and
    `LagunaQ5F32ResidentGlobalCacheAllocationError`.
  - `assert_h8b_shared_pack_scope` (`laguna_moe.py`): one
    `activation_pack_reuse_scope` call, owned by `_launch_laguna_shared_rows`,
    driven by its required parameter; `run_laguna_moe_rows` defaults the bit to
    `False` and both shared launch sites forward it unchanged.
  - `assert_h7u_group_compact_resolver` (`laguna_moe.py`): one
    `LAGUNA_MOE_GROUP_COMPACT_MODE` read defaulting to
    `_BASELINE_GROUP_COMPACT_MODE == "serial"`, the `{serial, parallel}` mode
    set, an optional explicit override, and a `ValueError` fail-closed path.
  - `assert_h8a_gpu_red`, `assert_h8b_unit_red`, `assert_h7u_live_mode_red`:
    the dependent REDs still carry their 24-plane topology, 95-group/107-call
    coverage, required test functions and backend-qualified mode assertions.
- Add `tests/test_unit_laguna_source_contracts.py`: 35 cases (6 live, 6
  unrelated-edit acceptances, 23 protected mutations). Mutations are applied to
  in-memory source text; no file is written. Parent review added RED mutations
  for a capability-value bypass, inverted plane guards, deleted owned release,
  launches outside the reuse scope and an ignored explicit mode request. The
  strengthened contracts reject those changes.
- `tests/test_unit_laguna_h8a_source_default.py`: drop the runner and GPU-RED
  whole-file hashes and the `_POST_MERGE` override dict; keep the artifact
  hash, the campaign-owned Q5 kernel `.py`/`.hip` hashes and the scoped
  `gguf_linear` symbol hashes.
- `tests/test_unit_laguna_h8b_source_default.py`: split the artifact-recorded
  hashes (`_ARTIFACT_SOURCE_SHA256`, immutable evidence) from the campaign-owned
  live hashes (`_LIVE_SOURCE_SHA256`: `activation_pack.py` and the Q5 kernel
  `.py`/`.hip`). The runner, `laguna_moe.py` and the sibling RED are scoped
  contracts now. The artifact's `docs/REFACTOR.md` provenance hash is unchanged.
- `tests/test_gpu_laguna_h7u_parallel_moe_compaction.py`: replace the
  `laguna_moe.py` hash and the normalized `test_live_laguna_moe_gpu.py` hash
  with the resolver and live-mode contracts; remove the dead normalization
  blocks and `_sha256`; assert every artifact source is accounted for.
- No runtime, kernel or existing triage file changed; no pin was refreshed.
  Parent removed RF-11 from `docs/REFACTOR.md` after reviewing and strengthening
  the contracts.
