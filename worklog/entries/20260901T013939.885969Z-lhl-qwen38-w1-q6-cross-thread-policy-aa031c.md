# Expose W1 policy across server thread boundary

## Summary

Runtime tracing showed declared cohort metadata is correct (C6=6, C8=8), but
the leaf context remained false for every Q6 call. The run-owned ContextVar is
set in the harness thread; FastAPI/TestClient executes generation in another
thread whose context was created earlier. This is why prior candidate runs
changed lifecycle overhead but never launched the candidate.

## Changes

Added a temporary default-off environment flag read by the outer policy helper.
The MTP2 adapter still converts it to a transaction-local leaf ContextVar using
the prompt-independent declared cohort. Documented the removal trigger in
`docs/REFACTOR.md`.

## Validation

Wide dispatch: 9 passed. Policy/planner/engine/MTP2 bundles: 126 passed. Diff
check clean. Automatic serving remains K0 and the flag defaults off.

## Next

Run mechanical trace with the env flag. Require C6=0 and C8>0 candidate launches
before full performance.
