# Verify native C1 across every N8 physical slot

## Summary

All eight physical N8 slots pass native C1/K3 ownership diagnostics: 70 cycles
and 267 logical rows over all ten suite prompts per slot. Their actual saved
full-logit arrays are byte-identical at matching contexts. This is storage-slot
isolation evidence, not concurrent-request or strict-teacher qualification.

## Validation

On host `epyc`, GPU0 W7900 `GPU-e282895b62c2b295`, gfx1100, ROCm 7.2.4;
Qwen3.8-27B Q4_K_M, production, BF16 KV, D24, capacity8, K3:

```bash
export HIP_VISIBLE_DEVICES=0 ROCR_VISIBLE_DEVICES=0 GPU_MAX_HW_QUEUES=1 HIPENGINE_HIP_ARCH=gfx1100
for slot in 1 0 2 3 4 5 6 7; do
  .venv/bin/python scripts/qwen38_packed_c1_logits.py capture \
    --directory "/tmp/packed-c1-n8k3-slot${slot}-atomic" \
    --capacity 8 --budget 3 --check-commit --slot "$slot" \
    > "/tmp/packed-c1-n8k3-slot${slot}-atomic.log" 2>&1
done
```

- `bg-87` prints PASS for all eight N8 slots. Each capture is complete, has no
  target errors, and has 70 records across ten distinct prompt IDs.
- Every record passes pre-accept state isolation, selected Conv/GDN commit,
  auxiliary/provider/cursor commit, and page-aware KV commit checks.
- Independent NumPy inspection opened all 560 NPZ files and checked finite
  float32 arrays and recorded SHA256 digests. At each cycle, prompt ID, prefix,
  proposed tokens, position, and logical row count match across slots; array
  shapes and full bytes match too (267 logical rows per slot).
- Capture SHA256 values are in the artifact. Raw arrays/logs remain in `/tmp`.
  No GPU rerun was needed for the comparison.
