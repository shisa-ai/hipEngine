# Screen chunk-parallel Inkling split value reduction

## Summary

A chunk-parallel value pass reduced isolated split-attention time at prepared depths on both GPUs. It was slightly slower at the shortest span and changes accumulation order. Test it through the public route before integration.

## Changes

- Scratch only. Keep the existing score pass. Accumulate a maximum, denominator, and weighted value vector per 64-slot chunk, then merge them with rescaling and the attention sink. Respect explicit offsets, positions, and the eviction mask, including an empty chunk.

Ran `python -u /tmp/hipengine_inkling_chunk_values_trial.py "$backend" "$control_so" "$trial_so"` on W7900 and Strix Halo at `207bef05b` (runtime `fbf605cc6`).
