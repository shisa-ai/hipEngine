# Close supported serving and refresh gfx1151 Qwen38 headlines

## Summary

Close the supported gfx1151 Qwen3.8-27B Q4_K_M greedy serving/MTP scope and
refresh public headlines from clean same-host measurements. Production-default
512/128 is 404.487 prefill / 12.226 decode tok/s. Qualified strict C1/K3 MTP
is 20.985 tok/s, median 1.882x its own matched 11.150 tok/s AR baseline.

## Changes

- Preserve separate current production AR and strict-MTP manifests. Production
  automatic and explicit MTP requests run exact AR; old FP16 certificates are
  not relabeled. Strict MTP requires K3, ordinary EOS/greedy, capacity1/4,
  declared context<=1024, actual context1-67, natural25.
- Add compact serving-closure and headline artifacts containing exact commands,
  raw hashes, same-host identity, sampling/shape scope and measured repetitions.
- Update canonical benchmark table/changelog, synchronize root README, and
  reconcile the transfer checklist, execution-profile notes and PLAN correction.
- The new socket harness needed two protocol corrections, not runtime fixes:
  response-owned SSE terminal IDs are authoritative even without a reclaim-hook
  identity; strict MTP must explicitly request K3 and natural EOS handling.
  K4/ignore_eos diagnostic runs confirm typed exact-AR fallbacks.

## Validation

- Production automatic and explicit MTP: 40/40 exact category/width cells each
  at client C1/C2/C4/C8, zero speculative engagement, zero tracked teardown.
- Real sockets: 45 blocking + 45 SSE production requests exact, three repeats
  per width; SSE telemetry proves physical C2/C4/C8 with 93 decode steps each,
  no serial fallback. Decode/prefill cancellation preserves survivors and
  refill; resident rows and tracked allocation counters drain to zero.
- Strict K3 sockets: 21 blocking + 21 SSE exact requests, C1 engagement,
  cancellation/survivor/refill pass and zero tracked teardown. Concurrent
  clients can form singleton MTP groups; this is not physical C2/C4 MTP proof.
- Preserve the completed blocking run plus the focused repaired SSE run rather
  than repeating unaffected blocking checks after the harness-only failure.
- Three strict C1 category runs: MTP 20.984539/20.974109/20.986839 tok/s;
  all 30 cells exact/engaged/budget-conformed, repeated IDs identical,
  every category faster in every run, throughput CV 0.0323%.
- Public graph/eager preflight: all 18 canonical/heldout D32 trajectories,
  final logits and state fingerprints exact. Three timed 512/1K/4K runs per
  shape after warmup; all finite, timing CV<0.22%.
- Every new published sample matches raw output; all retained raw hashes verify.
  The compact artifact uses linear-interpolated p95 explicitly rather than
  inheriting the legacy raw helper's discrete p95 estimator.
- 102 focused serving/MTP/profile/graph/tier tests pass; README sync passes;
  artifact-provenance check has zero violations. Command-drift check still
  reports 35 violations in four older unrelated W7900/XTX artifacts, none in
  the new packets. Previous full unit runs record 13 unrelated failures;
  this is not full-repository release signoff.
- All GPU jobs and Uvicorn instances started here exited; the clean detached
  benchmark worktree remains for reproduction. Pre-existing docs/superpowers/
