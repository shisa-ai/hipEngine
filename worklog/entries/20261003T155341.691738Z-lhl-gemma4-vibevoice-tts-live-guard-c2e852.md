# Skip missing VibeVoice-TTS checkpoints in live tests

## Summary

The four live VibeVoice-TTS modules resolved the external
`microsoft/VibeVoice-1.5B` checkpoint in fixture setup. Two of them errored
instead of skipping when the checkpoint was absent: `test_live_vibevoice_tts_
session_gpu.py` and `test_live_vibevoice_tts_synthesize.py`. The session module
caught an exception from `resolve_model_path` that never raises, then handed the
unresolved repo id to the loader, which raised `MissingConfigError`. The
synthesize module guarded only on HIP availability and let `LLM(MODEL)` raise the
same error.

A shared guard now owns checkpoint resolution for all four modules. An
unconfigured host skips the checkpoint-dependent tests with a precise message; a
host that explicitly names a checkpoint through
`HIPENGINE_TEST_VIBEVOICE_TTS_MODEL` fails loudly when that path does not exist.
Model-independent tests (FFN dispatch/ULP, registry resolution) still run.

## Changes

- `tests/_vibevoice_tts_guard.py` (new): `resolve_tts_snapshot()` returns the
  explicit `HIPENGINE_TEST_VIBEVOICE_TTS_MODEL` directory (raising
  `FileNotFoundError` when set-but-missing), otherwise the pinned
  `microsoft/VibeVoice-1.5B` local HF snapshot, skipping when that is absent.
- `tests/test_live_vibevoice_tts_decoder_gpu.py`,
  `tests/test_live_vibevoice_tts_diffusion_gpu.py`,
  `tests/test_live_vibevoice_tts_session_gpu.py`,
  `tests/test_live_vibevoice_tts_synthesize.py`: `bundle`/`weights`/`engine`
  fixtures now resolve through the shared guard. The decoder/diffusion broad
  `except (FileNotFoundError, ValueError)` wrapper is removed so a genuine load
  failure is no longer reported as a missing dependency. `synthesize` passes the
  resolved path to `LLM`.
- `tests/test_unit_vibevoice_tts_live_guard.py` (new): CPU coverage for an
  available default snapshot, a missing default snapshot (skip), an explicit
  missing path (`FileNotFoundError`), and an explicit available path overriding
  the default resolver.

No runtime, kernel, or product behavior changed. No numerical or quality
assertions were altered.

## Validation

- Reproduced the prior setup errors on the default host (checkpoint absent):
  `test_live_vibevoice_tts_session_gpu.py` errored with `MissingConfigError` at
  the `weights` fixture, and `test_live_vibevoice_tts_synthesize.py` failed 7
  tests with the same error from `LLM(MODEL)`.
- After repair, the four modules on the default host:
  `7 passed, 35 skipped in 1.47s` (0 errors). Every skip carries
  `VibeVoice-TTS checkpoint 'microsoft/VibeVoice-1.5B' is not in the local HF
  cache; set HIPENGINE_TEST_VIBEVOICE_TTS_MODEL to a local checkpoint directory`.
- Explicit missing config on one test per module:
  `HIPENGINE_TEST_VIBEVOICE_TTS_MODEL=/nonexistent/checkpoint` produced
  `4 errors`, each naming
  `HIPENGINE_TEST_VIBEVOICE_TTS_MODEL='/nonexistent/checkpoint' does not name a
  local VibeVoice-TTS checkpoint directory`.
- New unit guard tests: `4 passed`.
- Collection over the four modules plus the unit guard: `46 tests collected`.
- Available-path resolution checked on CPU against
  `/models/vibevoice/VibeVoice-1.5B` (returns the directory); no GPU tests were
  run for this unit because GPU0 and GPU1 were occupied.
