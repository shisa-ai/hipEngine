# Recover gfx1151 C3 K3 R12 row amortization

## Summary

Open the first physical C3/K3 investigation after production C2/K3/D24 closed.
A clean one-prompt Generation-2 diagnostic forms seven full R12 target batches,
remains self-exact and AR-equal, but reaches only **14.403 versus 20.623 tok/s
(0.6984x AR)**. Clean marker tracing localizes the loss to target projection
ownership rather than host/scheduler wall: steady R12 target is about **399 ms**,
including **194.3 ms Q6** and **129.5 ms strict small-M Q4**, with only about
**10 ms** uncovered.

The bounded candidate decomposes only qualified packed-verifier R12 projections
into contiguous R8+R4 calls to the already-registered row-independent Q4/Q5/Q6
rowtiles. The original R12 physical scope owns admission; an internal child
context cannot independently admit R4. Native batch chunking and all strict
fallbacks remain intact.
