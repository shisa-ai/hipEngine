# Check resident Inkling router coverage on the Loom artifact

## Summary

The resident router probe's NVFP4 geometry covers 44 of the pinned legacy Loom artifact's 48 decoder visits. The other four use Q8_0 and stay on the ordinary path. This is a header and visit-map check, not a runtime test.

## Changes

- No runtime changes. Read the header of the existing lockfile-pinned `UD-Q4_K_XL` on `strixhalo` with `Inkling2GGUFWeights(GGUFReader(path)).mapping`. Count physical layers and visits by gate/up and down shapes, types, scale presence, and `top_k`.

## Validation

- The legacy `inkling2` map has 20 physical NVFP4 layer pairs visited 44 times and four Q8_0 pairs visited once each. Both use `(128, 2304, 2304)` gate/up, `(128, 2304, 1152)` down and top-eight routing. External gate/up and down scale tables are present on each NVFP4 pair and absent on the Q8_0 pairs. The model payload was not read or rehashed for this check.
- The model-level guarded route has only run on W7900 mainline. Strix Halo still had sustained full I/O pressure and less available memory than the pinned file size during the check. No matched timing or new model run was started.
