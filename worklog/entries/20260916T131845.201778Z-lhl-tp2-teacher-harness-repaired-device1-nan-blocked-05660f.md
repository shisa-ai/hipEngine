# TP2 teacher-control harness repaired; device-1 TP1 forward is all-NaN and blocks controls

## Summary

Repaired the AR teacher-control harnesses into a fail-closed unit, then used
them to attempt the three identical 16-position XTX controls. The controls
**failed deterministically**: the TP1 forward on device 1 (RX 7900 XTX)
returns all-NaN logits, so no clean control baseline exists and the three-arm
teacher comparison is blocked. This is a real, reproducible device-1/TP1
failure, not contention (idle windows: load < 1.5, both cards 0-2%, telemetry
available).

Harness repairs (parent + child + coverage), all with focused negative tests:

- **Fresh-process child** (`scripts/tp2_teacher_child.py`): one session per
  process, built and executed on the main thread; build vs execution phase
  markers; full-logits shape `(positions, vocab_size)` and finiteness
  validation; rejects `--calls < 1`; cleanup failure is fail-closed
  (`CHILD_CLEANUP_FAIL`, non-zero exit) even after successful calls; force-exits
  after logical completion because a failed device-1 forward hangs HIP teardown.
- **Deadline parent** (`scripts/tp2_teacher_bisect_parent.py`): SIGTERM then
  SIGKILL and unconditional reap; retains partial flushed output on timeout and
  names the phase; PASS now requires no timeout, rc 0, no `CHILD_FAIL`,
  `CHILD_OK`, `CHILD_CLEANUP_OK`, and exactly the requested call count/indices/
  positions/finite flags; prefix checks require the requested length and
  compare over the shared common length (16→24 progression is consistent);
  case parsing keeps comma-bearing `devices=0,1` and rejects unknown/malformed
  keys; `--repeat-per-case <= 0` and `--timeout <= 0` are rejected;
  `--require-idle` implies `--idle-gate`; missing GPU telemetry is **not**
  treated as idle.
- **Coverage harness** (`scripts/tp2_teacher_coverage_broad.py`): canonical
  `mtpbench-code-general-ja.jsonl` plus heldout-only rows deduplicated by id
  (18 prompts, all four categories, 8 heldout); full trajectories scored
  against expected prompt length and vocab width (identically truncated arms
  fail); NaN metrics fail; determinism requires >= 3 identical sweeps
  (`EXECUTION-PROFILES.md` 6.4); global+canonical scope use the 99% top-1 bar,
  per-category and per-category-within-scope use 97%; suite-completeness gate
  with an explicit `--allow-partial` diagnostic label; reset/reuse boundaries
  labelled as reset/reuse (not warm-state continuation) and include an
  intervening-prompt and a post-`generate()` check; artifact records exact
  command, source revision, dirty flag, model sha256, host identity, device
  identities (name/uuid/PCI bus), and resolved route per arm. Removed the
  undefined `sessions.items()` and the bogus `len(suite)*positions`
  qualification count (now `short_probe`/`extended_probe`, never
  "complete").
- **Tests** (`tests/test_unit_scripts_tp2_teacher_harness.py`): 52 CPU tests,
  including `main()` integration tests with fake sessions that exercise the
  gate wiring, plus negative tests for every gate above.

## Validation

- `python3 -m pytest tests/test_unit_scripts_tp2_teacher_harness.py` -> 52
  passed.
- Three identical controls, fixed parent:
  `python3 scripts/tp2_teacher_bisect_parent.py --case
  positions=16,devices=1,mode=tp1,schedule=eager,calls=1 --repeat-per-case 3
  --timeout 240 --grace 15 --idle-gate --max-load 2.0 --max-gpu 5
  --idle-timeout 120 --json
  benchmarks/results/2026-09-16-w7900-tp2-teacher-controls-d1-blocked.json`
  -> **0/3 PASS**, every case
  `FAIL[returncode=1 | child failure: reason=invalid-logits ... non-finite
  logits ... | no CHILD_OK | call count=0 expected 1]`. Each child:
  `finite=0/3973120 nan=3973120 inf=0`, build ~83-84 s, wall ~85 s, idle=True.
- Contrast TP1 device 0 (same harness):
  `finite=3973120/3973120 nan=0 min=-15.27 max=31.73`, wall 0.58 s.
- Contrast TP2 eager on both devices, 4 positions:
  `finite=993280/993280 nan=0 min=-15.22 max=27.31` — so device 1's compute is
  fine in the TP2 path; the failure is specific to the **full-width TP1 MLP on
  device 1**.
- Basic HIP memory ops (hipMalloc/hipMemset/hipMemcpy) succeed on device 1;
  `rocm-smi --showras` reports no uncorrectable errors; both cards 0% busy and
  ~33-50 C.
- Layer probe on TP1 device 1 (patched `_local_mlp`): layer 0 `post_norm`
  finite 5120/5120, but `ffn_gate` 17378/17408 finite (37 non-finite),
  `ffn_up` 36 non-finite, `mlp_out` 11 non-finite; layers 1+ `post_norm`
  0/5120 (NaN propagated). Non-finite gate/up indices are scattered across
  `ffn_size=17408` (first 286, last 17358), i.e. specific output rows, not a
  contiguous tile tail.
- Pre-head hidden on TP1 device 1 is already all-NaN (`0/5120`), so the NaN
  originates in the layer stack, not the head.
- Post-close HIP teardown on device 1 hangs after the session closes; the child
  now `os._exit`s after logical completion so the parent sees a definite rc.
