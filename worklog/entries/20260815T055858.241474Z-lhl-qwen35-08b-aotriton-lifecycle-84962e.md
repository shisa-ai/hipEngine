# Qwen3.5 0.8B mixed-shape AOTriton abort isolation

## Summary

The benchmark-only pre-reset stream drain retained in `cdb1dabdc` improves
resident-session isolation but does **not** fully close the mixed-shape Q8
failure.  A post-commit retry passed the former p512 failure point, then a
second Q8 current process aborted while entering p4096 after p16..p1024.
System coredumps now localize all five captured aborts to vendored AOTriton v3
`flash::attn_fwd`, not GDN, WMMA, reset itself, or hipEngine's Python layer.
The exception crosses the `extern "C"` wrapper and calls `std::terminate`.

The campaign threshold packet will therefore use one fresh resident-session
process per prompt length.  That preserves every current production route,
including AOTriton from p512, while removing mixed-shape process-lifetime state
from the measurement.  This is a protocol correction, not a production
fallback and not evidence that the AOTriton defect is fixed.

## Changes

- Retained `cdb1dabdc`: synchronize the caller stream before benchmark reset so
  queued work cannot overlap reset bookkeeping.  The synchronization remains
  outside every timed interval and is a useful isolation improvement.
- Corrected the local threshold harness from one p16..p4096 resident process to
  one fresh process per length and repetition.  Raw child artifacts and exact
  commands remain per-length.
- Reclassified the remaining exception-boundary repair as follow-up task 19;
  the 0.8B campaign does not weaken or silently disable its p512 AOTriton route.

## Validation

- Before `cdb1dabdc`, two independent Q8 current-default p16..p4096 processes
  aborted at p512.  Exact-GDN and a purported AOTriton-off control also aborted;
  the latter control is invalid because it used a nonexistent environment
  selector.  No-WMMA, explicit chunk drain, and gdb-perturbed controls passed,
  establishing timing sensitivity but not ownership.
- After `cdb1dabdc`, one exact failing-matrix process completed p16..p4096 and
  the focused benchmark/reset test bundle passed (`22 passed`).  A subsequent
  approved sweep completed all nine Q4 role/block processes and the first Q8
  current/strict block, then aborted in the second Q8 current process at p4096.
- `coredumpctl` backtraces for PIDs `2163653`, `2166019`, `2166461`, `2166729`,
  and `2178111` all terminate through
  `aotriton::v3::flash::attn_fwd` ->
  `hipengine_aotriton_attn_fwd_v3_compact_varlen` -> ctypes.  The newest core is
  preserved locally as `/tmp/d08-review/q8-abort-2178111.bt`; raw cores/logs are
  intentionally untracked.
- The fresh-process threshold protocol explicitly retains
  `--attn-aotriton-min-tokens 512`, `--force-bulk-prefill`, WMMA prefill, GEMV
  decode, cached builds, and the current role selectors.  Its result is recorded
  by the separate threshold evidence unit.
