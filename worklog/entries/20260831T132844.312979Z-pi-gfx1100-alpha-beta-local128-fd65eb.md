# Screen exact gfx1100 alpha beta local128 GEMV

## Summary

Reject the exact gfx1100 dense-F32 alpha/beta G1A local128/virtual256 schedule
on GPU1/RX 7900 XTX. The candidate passes rows1-4 BF16-bit parent parity and
uses 24 VGPR, 512-byte LDS, and zero scratch, but loses all 15/15 paired samples
in hot, 90-MiB rotating, and cache-thrashed regimes. The important production-
oriented 48-pair rotation moves **1.212919 -> 1.410239 ms (+16.268%, 0/15
wins)**. The candidate and its transient probe are removed; no registry,
runtime, or W7900 route changes.

## Changes

- Temporarily added a G1A device body, raw-pointer export, wrapper, and isolated
  `linear_pair/f32/bf16_hidden_bf16_out_virtual256_local128` registry key.
  Four physical waves emulated every retained local256 partition: the register
  pair add reproduced `s=128`, then LDS/shuffle preserved `s=64..1`.
- Added RED/GREEN wrapper, registration, and rows1-4 exactness tests, then
  removed them together with the losing kernel/wrapper/key after measurement.
  The source mechanism was `qingming-gfx1100-gemv@6b2d87e` `split4_kernel`;
  no external code remains in the tree.
- Used a transient torch-free probe to mmap all 96 immutable F32 alpha/beta
  tensors from `/models/gguf/Qwen3.8-27B-Q4_K_M.gguf`, rotate the 48 real
  pairs, time AB/BA arms with HIP events, and classify hot/rotation/thrash
  regimes. The probe was removed with the rejected candidate.
- Added rejection artifact
  `benchmarks/results/2026-08-31-gpu1-gfx1100-dense-f32-alpha-beta-g1a-rejected.json`
  and updated `docs/GFX1100-SHAPE-AWARE-GEMV-CAMPAIGN.md` with the completed
  G1 disposition.
