# PF-2: QSA long-context prefill reuse

## Arithmetic class declaration

Arithmetic class: **T0** (section 6.3) — the goal is to extend the retained
ordered three-pass decode reuse (`strict_ordered_three_pass_spans`) to chunked
prefill without any partial-softmax reassociation, so the prefill arithmetic
stays bit-exact with the strict teacher. If a partial-softmax reassociation
turns out to be unavoidable, the lever becomes T1/T2 and is gated behind the
PF-0-based section 6.2 packet instead.

Registered strict fallback: `strict_spans`
(`qwen4_exp_qsa_sparse_attention_paged_bf16_rows_f32` /
`qwen4_exp_qsa_sparse_attention_paged_bf16_f32` in
`hipengine/kernels/hip_gfx1100/attention/qwen4_exp_qsa.py`), which remains
registered and dispatched for any shape where the new ordered prefill variant
does not apply.
