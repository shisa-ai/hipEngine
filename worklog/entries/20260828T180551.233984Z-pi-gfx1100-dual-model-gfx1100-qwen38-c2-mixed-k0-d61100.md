# Fail mixed physical MTP plans closed before mutation

## Summary

P7's physical C2 D24 telemetry recorded three recoverable
`ValueError:physical accept identities do not align` precommit failures, always
at the C2 -> C1 output tail. Localization found a contract mismatch: the common
`CandidateGraph` correctly retains every due `plan.request_id`, including K0
rows, while `Qwen35GGUFMTP2Adapter` proposal/target ownership contains only
`plan.speculative_request_ids`. The adapter admitted mixed positive-K/K0 plans,
then discovered the identity mismatch only after proposal and target work.

The campaign contract already requires whole-group K0 unless a declared
partition owns both paths. This adapter has no mixed target/result owner, so it
must reject the mixed plan at `claims_fit()` before provider mutation. The
common planner then produces a stable resource-claim K0 plan for the whole due
group.

## Changes

- `Qwen35GGUFMTP2Adapter.claims_fit()` now requires
