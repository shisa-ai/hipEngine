# Bind generic WMMA prefill enablement on the owner

## Summary

Add optional generic WMMA prefill enablement to the Qwen4Exp generator/runner,
without yet changing profile publication or existing diagnostic callers.

## Changes

- Carry optional owner state through constructor arguments and later runner
  inheritance. Bind it around each prefill chunk without environment writes.
- Provide a restoring owner scope for explicit diagnostics. Explicit nonempty
  Q8 WMMA layer scopes still enable their own route; per-call arguments keep
  their existing highest precedence. Unbound callers keep the existing path.
- Add opposite-ambient, exception-restoration, clone and scope-precedence tests,
  plus public generation with actual generic WMMA launches and exact repeats.
