# MR-3 is not actionable either, and the census column it was counted from is not uniformly an experiment

## Summary

A systematic pass over the First-bounded-experiment column of all 23 actionable ledger
rows found the same defect class I had been finding one row at a time: **that column is
not uniformly an experiment.** Two rows carry a column that names no experiment at all -
MR-3's reads "Do not start here", GD-1's reads "Do not re-screen unchanged" - and PL-1's
holds a *state* where an experiment belongs. MR-3's columns agree that it should not be
started, so it is closed; GD-1, PL-1 and X-7 are flagged rather than settled, because in
those three the columns disagree. **Actionable falls 23 -> 22.**

## The reusable finding

Four of the five movements in this census came from **reading a row's own content or
its code**, not from any measurement:

| movement | row | why it moved |
| --- | --- | --- |
| 1 | QA-2 | its own cell cost-gates it (0.22% against a 7.90% premise) |
| 2 | DP-5 | its build is gated on a buffer contract that does not exist |
| 3 | MR-3 | its columns agree it should not be started |
| 4 | (this pass) | the column the count is derived from is not uniformly an experiment |
| 5 | GD-1, PL-1, X-7 | flagged: columns disagree, so the resolution is a decision |

**The count is only as good as the column it is derived from.** That is worth stating
because the census is the campaign's instrument for answering "what is left", and it has
now been shown to over-count by at least three rows - two of them carrying a column
whose literal text is an instruction *not* to run anything.
