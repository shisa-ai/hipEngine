# Gemma attention fails the complete canonical and heldout numerical packet

## Summary

The shipping production attention paths fail the canonical and heldout
strict-teacher packet on zbook Radeon 8060S, Gemma 4 26B-A4B UD-Q4_K_XL,
BF16 KV, single-slot eager. The packet contains 18 prompts and 1,152 aligned
full-vocabulary rows at prompt depths 513, 1031, 2053, 4093 and 8191. The strict
attention fallback supplies the greedy teacher chain; production consumes that
same chain. All numerical bars were fixed from EXECUTION-PROFILES before running.

Global mean/p95/p99/max KL is `0.003226/0.012287/0.061127/0.391478` and top-1
is `98.6111%`; all five global limits fail. Every category has at least one KL
failure. No repeat or single-slot request-isolation check failed: three
production runs are full-logit identical in every case, and replay after an
unrelated request produces identical logits in all 18 cases. Forward position
advancement and output-logit finiteness checks pass.

Exact JSON retrieval task checks are non-inferior case-by-case: 17 cases pass
in both arms, one fails in both. This limited task check does not certify
canonical code execution or open-ended task quality. Free-running canonical
outputs change in 12 cases and require separate review. No aligned full-model
BF16 teacher is available in this packet.

This result compares the complete production WMMA attention selection with the
plain strict fallback. It does not isolate the latest partial-score change
from earlier sliding/full WMMA arithmetic. The product remains runnable; a
numerical finding requires localization and repair, not an identity allowlist
or a missing-evidence admission restriction.
