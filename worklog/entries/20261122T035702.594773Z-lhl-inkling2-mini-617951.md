# Compare interleaved and planar packed NVFP4 routes

## Summary

Neither planar NVFP4 layout beat the current interleaved register-table kernel on Strix Halo in the tested projection shapes. Widening scales to FP16 was faster on W7900 at those shapes but costs additional bank storage. Do not change the packed layout on this evidence.

## Changes

- No product changes. Built scratch variants separating the 32 payload bytes from four unsigned scale bytes, then widening those scales exactly to FP16. Both use the same FP32 dot order and final route scaling as the interleaved control.

## Validation

- `python -u ./hipengine_inkling_nvfp4_planar_probe.py "$backend" "$model"` compared resident synthetically packed weights on Strix Halo Radeon 8060S and Radeon Pro W7900, at eight routes per launch, 32 experts, 16 route sets, `(input, output)` of `(2304, 2304)` and `(1152, 2304)`. Both planar variants matched the committed `37e93978f` control bit-for-bit. Every decoded scale byte value round-tripped through FP16 in the host check.
- On Strix Halo, median HIP-event time per launch across six order permutations of 128 launches was 0.235 / 0.108 ms interleaved, 0.255 / 0.118 ms planar byte scales, and 0.241 / 0.112 ms planar FP16 scales, for the two respective widths. W7900 results were 0.094 / 0.042 ms interleaved, 0.106 / 0.046 ms planar byte scales, and 0.089 / 0.041 ms planar FP16 scales. These are synthetic projection timings, not request timings.
- Both checkpoint layouts contain 11,466,178,560 expert NVFP4 bytes. Widening would add 1,274,019,840 bytes before allocator overhead. At the wider synthetic shape, one eight-expert selection addresses 23,887,872 packed bytes interleaved or with byte scales, and 26,542,080 with FP16 scales; these are logical bytes, not measured memory traffic. On Strix Halo the wide synthetic bank split into two arrays in 0.021 s, and widening added 0.010 s; this excludes file I/O, uploads and request costs. Logs and scratch prototype: `/tmp/kendex-pi-bg/bg-53-1795319795805.log`, `/tmp/kendex-pi-bg/bg-54-1795319795818.log`, `/tmp/hipengine_inkling_nvfp4_planar_probe.{hip,py}`.
