# Add explicit host-byte trimming for provider checkpoints

## Summary

Add an explicit provider host-byte trimming primitive, preserving checkpoint
restore semantics and existing entry count until owner policy is integrated.

## Changes

- Evict LRU checkpoints until reported host bytes fit the supplied bound.
  Zero removes host-backed entries; negative limits fail before mutation.
- Retained entries keep their restore payload and device byte reporting.
  No new environment control or runtime bound is introduced by this primitive.
