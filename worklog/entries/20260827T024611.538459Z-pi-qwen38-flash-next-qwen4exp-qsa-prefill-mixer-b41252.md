# Compose Qwen4Exp QSA prefill mixer

## Summary

Composed a bounded, contiguous Qwen4Exp QSA prompt-chunk mixer across the dense
to sparse selection boundary while preserving shared paged K/V and raw-index
state.

## Changes

- Added persistent prefill metadata for explicit positions/context counts,
  repeated complete block tables, and bounded variable selections. Metadata is
  an owned lifecycle object and supports active-row span slices.
- Added historical-query index selection over already appended raw keys; c1
  `select()` still requires the latest query and remains the fallback.
- Added `run_qwen4_exp_qsa_prefill_token_mixer`: bulk Q/K/V/index projections,
  row norm/RoPE, raw-index append, shared-cache K/V write, dense batch context,
  sparse row context, F32 gate, and bulk output projection.
- Repaired the test download helper to copy the requested host byte count rather
  than the full padded 256-token cache allocation; `PYTHONMALLOC=debug` exposed
  the test-only host overrun before the final gate.

## Validation

- RED: the mixer and metadata did not exist. The first GREEN attempt then found
  the test helper's partial-cache D2H overrun; debug allocator reproduced it and
  the bounded-copy repair removes the crash.
- `uv run pytest -q tests/test_qwen4_exp_runner_qsa.py tests/test_qwen4_exp_qsa_index_state.py tests/test_qwen4_exp_qsa_sparse_hip.py tests/test_qwen4_exp_qsa_hip.py -x`
  -> 12 passed.
- A six-row reduced chunk crosses from five dense-equivalent rows to one native
  sparse row. Outputs match six independent c1 executions at `3e-4`; BF16 K/V,
  FP32 raw index keys, cursor count, and selected logical positions are exact.
  The focused case also passes under `PYTHONMALLOC=debug`.
- Cached gfx1151 trace records row split/index transforms at 2,525/2,124 ns,
  shared K/V write 2,645 ns, dense context 3,927 ns, and sparse context 6,132 ns.
