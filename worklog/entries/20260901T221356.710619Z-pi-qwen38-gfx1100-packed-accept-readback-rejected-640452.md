# Audit and reject packed accept readback

## Summary

Audited the retained C8 target accept/readback ownership and rejected a packed
committed-token readback candidate. The host does require accepted counts,
commit positions, next tokens, and accepted token IDs to update public output
and scheduler state. The only redundancy was D2H API count; eliminating seven
tiny calls did not improve operation-complete wall.

## Changes

- Temporarily added a default-off path that copied the full contiguous committed
  token matrix once instead of copying one bounded slice per request.
- Removed the branch, environment flag, and test after marker rejection. No
  runtime debt remains.
- Added an ownership/timing artifact; no benchmark scoreboard row changed.

## Validation

- Ownership: C8/K3 reads one 8x7 int32 status payload (224 B) and eight accepted
  token slices of at most four int32 values. The first blocking copy is the
  required producer dependency; no global synchronize occurs.
- Corrected telemetry interpretation: the same readback duration is added to
  each request row, so route-level `target_readback_ms` sums are multiplied by
  C8 and mostly represent queued target compute, not transfer time.
- Ready-data micro, 200 alternating pairs: 1+8 bounded copies
  **214.16 µs** versus status + one 1 KiB matrix copy **47.22 µs (4.54x,
  200/200 wins)**.
- Dirty cached-only C8/K3/D12 marker preserves generated IDs and `[3,3,2]`
  acceptance. Target wall is effectively flat **518.708→518.222 ms (-0.09%)**
  while complete wall regresses **1.2644→1.2734 s (+0.71%)**. The candidate's
  small API saving is hidden by required producer wait and does not qualify.
- Final source matches `20f312bb8`; only this worklog and
  `benchmarks/results/2026-09-02-w7900-q4km-k3-packed-accept-readback-rejected.json`
  remain.

## Next

- Do not treat request-multiplied readback telemetry as transferable D2H wall.
  Keep the bounded output slices unless accepted tokens move entirely into an
  already-required compact payload and operation-complete evidence improves.
