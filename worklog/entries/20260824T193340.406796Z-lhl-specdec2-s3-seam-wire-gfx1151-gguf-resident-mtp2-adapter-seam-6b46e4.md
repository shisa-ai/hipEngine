## Summary

Speculative intent is registered before prefill; eligible packed prefill returns
all target hidden seeds; capability remains K0 through the first AR root token;
and the adapter then exposes the retained dense NextN provider and transactional
verifier as prepare/propose/frontier/commit stages. The capability exists only
