# R0471 opt-in native-row resident-scheduler route implemented

## Summary

Implements the R0471 integration: the resident scheduler can now route a compact,
all-greedy physical group through the batch owner's `step_rows_native`
(`ar_decode_native_rows`, the DP4A-capable native-row route) when the generator
requests `native_batch_decode`. The route is opt-in and returns False to fall back
to the packed/serial path whenever it cannot engage, so the default is untouched.
Host ownership tests added RED-first and now pass. Public engaged/unengaged
generation on gfx1100 remains the acceptance gate (next checkpoint).

## Changes

- `hipengine/generation/qwen35_gguf.py`:
  - New `Qwen35GGUFResidentModelRunner._step_native_rows_compact(rows, *,
    physical_rows, active_slot_indices)`. Engages only when
    `generator.native_batch_decode` AND compact lanes (`len(concrete)==width`,
    `active_indices==range(width)`, `width>=2`) AND every row greedy
    (`native_greedy and not native_sampled and not native_sampler`). Resolves the
    batch owner via `_packed_execution_owner`, flushes packed-workspace state with
    `flush_packed_decode_owners_if_chunk_changed`, aligns `owner._position` to
    slot-view 0 (`row_positions` overrides index 0 with this scalar; indices 1+
    are shared through the slot-view scratch views), calls `step_rows_native`
    with `return_logits=False`, records each token via `_record_native_token`
    (which advances `slot.seq_position`), and bumps `native_rows_decode_steps` /
    `native_c{width}_decode_steps`. `NotImplementedError` -> False;
    `MemoryAdmissionRefused` -> `native_rows_workspace_refused` fallback counter
    then False (packed/serial), never a failed request.
  - Dispatch `_step_native_rows`: when `_ar_packed_decode_enabled()` and the group
    is multi-row, tries `_step_native_rows_compact` first iff
    `native_batch_decode`, then falls back to `_step_native_chunk` (packed) and
    the existing serial path. Default (`native_batch_decode=False`) unchanged.
- `tests/test_unit_gguf_native_rows_scheduler.py` (new, host-only): dispatch
  contract (tries route when requested; preserves packed default when not;
  falls back when route declines) + route capability contract (declines
  not-requested / non-greedy / singleton / non-compact / owner lacking
  `step_rows_native`).
