# Screen gfx1151 dense Q4T16 Q8_1 dp4a

## Summary

Activation Q8_1 plus the same-resident Q4T16 integer-dot gate/up+SiLU body is
rejected. It passes every actual-weight leaf and improves counterbalanced
512/128 graph decode 0.670%, but deterministically changes the retained true-AR
trajectory for heldout `general_ja_explain` in all three runs. The full natural
suite correctly fails exactness, so the exact two-projection plus primitive-SiLU
route is restored. No candidate source, dispatch, or test change remains.

## Changes

- Screened actual layer 0/8/63 gate/up pairs. Each pair is 95.625 MiB of source
  and 98.281 MiB of sole-T16 resident bytes, exceeding 2x the 32-MiB MALL.
- Compared two retained local32 Q4T16 projections plus primitive SiLU against
  one BF16-to-Q8_1 quantizer plus the existing dual-Q4T16 dp4a+SiLU body.
- Experiment budget: one 64-thread leaf, one bounded 32-thread geometry check,
  then only the best positive leaf may receive model/graph gates. Advancement
  requires every actual layer positive and >=1% projected complete-request
  saving; retention requires the full natural/repeated-shape correctness and
  all-shape non-regression gates.
- Temporarily integrated a model/backend/geometry/shape-qualified registered
  dense composite using the existing Q4T16 payload and bounded Q8_1 scratch.
  RED/GREEN policy, dispatcher, one-expert ABI, and GPU tests covered the route.
- Restored every candidate source/test hunk after the binding natural failure.
  The exact two-single-plus-SiLU chain remains the sole production owner; no
  resident payload, scratch, flag, fallback, or registry debt remains.
- Preserved the bounded rejection at
  `benchmarks/results/2026-08-15-gfx1151-qwen38-27b-q4-dp4a-rejected.json`.

  1.04048x/1.03287x/1.03111x; call-family aggregate is 1.03482x and projects

  absolute delta 0.001953125, max KL 1.4422e-8, and 3/3 top-1 agreement. BF16

  so an exact-trajectory model gate is mandatory before retention.
- Tracked memory returns exactly 0 -> 0. Raw artifact:
  `/tmp/qwen38-task22-q4-dp4a-leaf/leaf.json`.
- Focused registered-route tests pass **4/4**. Counterbalanced persistent graph
  C3/A3 is **11.84452 -> 11.92390 tok/s** (**+0.67013%**), with all six fixed
