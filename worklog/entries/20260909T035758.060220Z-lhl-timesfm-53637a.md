# TimesFM flash_short + warp-per-head scatter

## Summary

Two more sub-window optimizations for the TimesFM fp16 decode path: (1)
flash_short_kernel for the short-query (AR) attention — 4 wave32s per block
split the kv tiles with LDS-merged softmax statistics; (2) qkv_norm_scatter
rewritten warp-per-head with shuffle reductions and fast __sincosf. Wall
median 0.0913 -> 0.0909s (flat within thermal noise), verified sub-window
wins: AR attention 113 -> 108us/call, prefill scatter 309 -> 246us/call
(8.0 -> 6.3ms per decode total).

## Changes

- `hipengine/kernels/hip_gfx1100/timesfm/timesfm.hip`:
  - `flash_short_kernel`: 128-thread block per (batch*head, q tile); the four
    wave32s each process one kv tile per loop iteration (uniform trip count
    keeps __syncthreads convergent); per-wave online-softmax partials merged
    through LDS with (m == -inf) ? 1 : exp(m - M) chunk weights (uniform-1/S
    all-masked reference behaviour preserved).
  - `qkv_norm_scatter_kernel`: one warp per (b, n, h) head vector —
    warp-shuffle reductions, no __syncthreads (was: 128-thread block with 7
    block-wide sync rounds and 88 idle threads per head), __sincosf.
    Launcher: ceil(B*H*N/8) blocks of 256; D <= 128 guard.

## Measured

- AR attention: 113 -> 107.9us/call (rocprof, n=360).
- qkv_norm_scatter: prefill 309 -> 246us/call, AR 7.5 -> 5.6us; total per
  decode 8.0 -> 6.3ms.
- Wall: 10 runs 0.0884-0.0948, median 0.0909 (thermal noise dominates the
  1.5ms sub-window saving).

## Validation

- `python3 scripts/timesfm_gpu_bench.py --check`: fp32 strict parity +
  fp16 production gate pass (after each kernel change).
- `python3 -m pytest tests/test_timesfm_gpu_decode.py -q`: 3/3.
- First flash_short draft (per-wave trip counts) produced NaN via divergent
  __syncthreads — caught by the guard immediately; fixed with the uniform
  tile loop.
