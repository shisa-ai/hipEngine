# iu8-WMMA GR down promotion (T1 production route)

## Summary

Promoted the GR down leg (10240->320 Q8_0, F32 in/out) to the production
profile. Same dense iu8-WMMA kernel as the promoted up leg; the exact
F32 coltile parent (`gguf_k_prefill_out_coltile_rowbatch_kernel`) stays
the strict fallback and the sub-256-row path.

Packet:

- Operation-complete screen on real `hc_attn_down` weights: 2.55x rows
  1024 / 1.92x rows 512 versus the exact coltile parent; drift ~1 fp32
  ulp (max_abs 1.9e-5, rel p50 = 0, p99 5.7e-7).
- Teacher-forced full-model logits (9 fixture cases, double-run): KL
  versus the incumbent <= 5.5e-8, top-1 agreement 100% everywhere, argmax
  gaps 15-26, bit-deterministic.
- Full-suite same-residency A/B (72 samples, chunk 1024, both arms
  carrying the already-promoted up leg): prefill geo-mean **+2.0%**
  (11/12 cases win, ratios 0.992-1.041), decode neutral.
- Focused tests: 6/6 (shared with the up leg, including the down default
  gating test).

Combined with the up-leg promotion the GR family delivers **+11.3%**
prefill geo-mean over the pre-R5 production default.
