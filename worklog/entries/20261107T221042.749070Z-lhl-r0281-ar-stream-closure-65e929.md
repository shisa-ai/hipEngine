# Close R0281-AR-STREAM stream decode control migration

## Summary

R0281-AR-STREAM is complete. The ambient `HIPENGINE_GGUF_AR_STREAM_DECODE` reader was
retired in `a942bae20`. The resolved comparison control is the owner-bound pair
`LLM(ar_packed_decode=..., ar_stream_decode=...)`, also exposed as server CLI flags
and `ServerModelSpec` fields. Both off is the designated serial oracle. Explicit
`ar_stream_decode=True` without packed decode raises a named capability miss,
because resident slot views share execution and sample buffers. Remaining harness
writers only strip the retired name from child environments; `docs/ENVS.md`
documents it as retired.

## Changes

- Removed R0281-AR-STREAM from `docs/REFACTOR.md`. No code change.
