# Split the audit into a live inventory and an active fix queue

## Summary

Follow-up to `523f99f69` on lead direction. Two corrections.

**The inventory was not actually idempotent.** `ledger` and `candidate` row ids
are content-derived digests, so rewording a `docs/REFACTOR.md` heading or editing
a campaign table row produced a new id and orphaned its decision. That defeats
the whole point: a rescan has to land on the same audit item and carry forward
what was already decided about it.

**Cataloguing recorded debt is only half the job.** The lead also wants a pass
that scans the code itself and queues work that can actually be done, optionally
cross-referencing the inventory.

## Changes

Identity and lifecycle:

- Rows now carry `hints` — a stable `anchor`, the paths and flags the row names,
  and its content words. `core.similarity` scores two rows as the same item from
  those hints, requiring anchor equality so a match can never cross files.
- `core.rebind` re-attaches any decision whose row id moved, records
  `rebound_from`, and reports the similarity it matched on. It runs automatically
  after `inventory` and `scan`. Only rows nothing has decided on are eligible, so
  a rebind can never steal a decision from another item.
- `Triage` gained `expires`, `last_reviewed`, and `hints`. `reconcile` now
  separates `expired` and `resolved` from `triaged`, and `audit.py expiring`
  lists decisions past their review date. Use `--expires` on a `defer` whose
  reasoning depends on a blocker that may lift.
- Added the `wontfix` disposition, distinct from `keep`: `keep` means the thing is
  correct as it stands, `wontfix` means it is a real problem we are deliberately
  not fixing.
- `audit.py orphans` lists decisions that match no row, so they are reviewed
  rather than silently dropped.

The active-fix half:

- New `audit/findings/` store and `audit/hipaudit/checks/`, sharing the one triage
  store so a `wontfix` recorded on either half is honoured everywhere.
- Seven checks: `torch-hot-path`, `axis-branch`, `unguarded-hip-test` (from the
  `AGENTS.md` architectural invariants), `doc-path-drift`, `stub`, `marker`, and
  `ungoverned-flag-branch`, which reads `inventory/flags.json` to find runtime
  branches on flags that are default-off with no recorded removal condition.
- Every finding carries the edit that closes it. `audit.py queue` groups findings
  by shared cause, because one cause usually covers dozens and fixing the cause
  is the unit of work.

## Precision work

Two checks were wrong on the first pass and were re-targeted rather than shipped
noisy, because a noisy check gets ignored:

- `doc-path-drift` first reported 635 hits, most of them MIME types
  (`image/png`), placeholders (`OUTDIR/TAG-NAME.log`), and prose references. It
  now fires only when the named path does not exist **and the file is findable
  elsewhere**, so every finding names the actual location and the fix is a known
  edit. 111 findings from 1,548 paths checked, 1,348 skipped as illustrative.
- `unreachable-branch` was circular: it looked for runtime branches on flags whose
  defining signal was having no runtime read site, so it could only ever return
  zero. Re-targeted as `ungoverned-flag-branch` against the condition that
  actually matters — default-off or split-default, read in `hipengine/`, with no
  `docs/REFACTOR.md` entry. 49 such flags, 95 branches.

## Validation

- `python3 -m unittest discover -s audit/tests -t audit`: 23 tests pass, up from
  12. New coverage: a reworded heading keeps its decision; an unrelated row is not
  claimed; a row that already has a decision is never stolen; a decision without
  hints is not rebound; expiry separates from triaged; `wontfix` validates; a
  finding carries a fix and is re-matchable; a `wontfix` on a finding suppresses
  it like any other row.
- `python3 audit/audit.py check`: exit 0. 2,095 rows (1,623 inventory + 472
  findings), budget recorded across both stores.
- `python3 scripts/docs/check_all.py`: all 4 gates pass.
- No production code touched; `scripts/worklog_port_legacy.py` is another worker's
  and was left alone.

## What the checks found

- **111 documented paths that moved.** Systematic: `kernels/<backend>` and
  `kernels/cpu_reference` are documented as repo-root directories in `AGENTS.md`,
  `docs/BENCHMARK.md`, `docs/KERNELS.md`, and `docs/PLAN.md`, but live at
  `hipengine/kernels/`. `docs/KERNELS.md` alone carries 40.
- **95 runtime branches on 49 ungoverned flags** — default-off or split-default,
  no removal condition. This is the "flag city" surface, now enumerated.
- **59 tests drive the ROCm runtime with no availability guard**, so a no-GPU
  runner fails rather than skips.
- **15 registry-axis branches** in `hipengine/`, against the four-axis invariant;
  `hipengine/core/pm4/transport.py` holds several.
- **192 `NotImplementedError` sites** — expected to be largely legitimate; that
  is what triage is for.
- `torch-hot-path` and `marker` both return zero: the torch-free invariant holds,
  and there are no stray TODO markers in shipped runtime code.
