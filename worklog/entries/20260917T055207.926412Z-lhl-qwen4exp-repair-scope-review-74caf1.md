## Changes

- Corrected `docs/QWEN4EXP-STATUS.md` scope table and conclusions. 12-47 fails
  general_en mean/p95 and has two review-boundary outliers. 8-47 fails the
  global maximum/top-1, with the hard tail on code-p4096 at teacher step 1.
  The common teacher digest is unchanged. Global means increase across three
  points, but general_en decreases from 1.089e-3 to 9.79e-4: this is not a
  monotonic admission boundary or a measured noise interval.
- At 16-47, general_en mean is 5.235e-4, using 52.4% of its 1e-3 limit
  (1.91x headroom), not 40%. The 2.63x ratio belongs to the global mean.
  Neither metric bounds the value of untested selective layer/role scopes.
  Identical 16-47 digests are evidence at that scope, not a proof that every
  untested scope inherits the other route's result. Split-F16 operand work is
  a hypothesis, not the only reopening condition or a measured 2x win.
- Recorded that nearly equal final-prefill logits do not prove prefill state
  is unaffected. The first-decode outlier warrants recurrent/KV/intermediate
  localization. The arithmetic is F16 operands with FP32 accumulation.
- Corrected the activation estimate's actual computation. In
  `scripts/qwen4exp_dense_wide_f16_activation.py`, `aggregate()` ignores the
  measured `composite_ms` and uses standalone `f16in_ms + cast_share * cast_ms`.
  Census-weighted 1024-row totals are 1384.689 ms F32, 830.761 ms measured
  unshared composite, 801.610 ms standalone unshared, and 794.133 ms standalone
  with assumed half-cast sharing. Thus 590.557 ms is an estimate; the measured
  unshared-composite sum instead estimates 553.928 ms recovery. Neither is an
  engine wall result. Assumed sharing contributes only 7.478 ms to the estimate.
- Recommended a simpler first integration: reusable runner-owned scratch,
  per-call cast and same-stream matmul; no general cross-consumer cache required
  to capture the main opportunity. Validate actual inputs, tails, reset and
  graph/request lifetimes; only then measure explicit paired-consumer reuse.
- The activation packet uses normal random activations and sampled real weights,
  not captured activations for every layer. Aggregate agreement with the engine
  is 1.4%, not per-shape agreement. Its `bit_identical` is max-absolute-difference
  equal to zero, not a byte comparison (signed zero is not distinguished), and
  the harness returns success even if a row records a mismatch. Future evidence
  must fail closed on nonfinite/mismatch results and check bytes where claiming
  bit identity. Unit tests pin exports/geometry, not those GPU edge cases.
- Kept the repair saving: 1420.9 -> 1239.8 ms, with identical engine final
  logits digests. The packet corroborates Q4_K/Q5_1 sub-window changes. The
  causal label memory-level parallelism is plausible but not uniquely proven;
  the byte counts are logical estimates and a slower redesign changes more than
  traffic. Incidence is not proved the only remaining lever. A compile-time
  change can in principle be A/B'd using separately named binaries/symbols;
  it is not intrinsically untestable in one process.
- Flagged focused Q8_0 repair coverage: the recorded 58-test bundle covers
  Q4_K/Q5_1/Q5_K and bitmap work, not the changed Q8_0 sparse repair. A same-case
  prefill digest is useful but does not replace queue/overflow/adversarial
  coverage or backend-specific transfer checks for shared kernel source.
- Re-bucketed existing post-unroll analysis with the current mapper: gate/up
  3377.1 ms, down 2229.8 ms, total 5.607 s. Kept the main table explicitly
  pre-unroll instead of silently calling its 2382.3 ms down cost current.
- Exposed both baseline aggregations. Raw samples 34/35 degrade at p512,
  contrary to the unaffected-p512 claim; token/time-weighted TG is 17.43 versus
  mean-of-case-medians 17.70. At p4096 those are 15.42 versus 16.24. Preserve
  slow samples and predeclare the statistic; post-run telemetry does not rule
  out transient causes. Removed uncontrolled historical percent comparisons.
