# Add a disabled-selector ranking harness

## Summary

The production binder disables the fifteen arithmetic selectors as a group and
re-admits five, so the ten that stay off have no individual cost record at the
current HEAD. This harness measures each one alone through the same child, the
same fixture, the same case and the same chunk size, differing only by the flag
under test, and records the child's own effective route environment so a
selector that failed to take effect is visible instead of being read as
neutral. It is the input to "what to requalify first".

## Changes

- `scripts/qwen4exp_disabled_selector_ranking.py`: twelve arms (baseline, one
  per disabled prefill selector, a combined GR arm, and an all-prefill arm),
  each run as a `qwen4exp_profile_gap.py --mode prefill` child with
  `--override`. Writes a JSON report incrementally so a partial sweep is still
  readable, and records `tok_s`, the ratio against the in-run baseline, the
  generated token id, the configuration class and the effective route.
- `tests/test_unit_qwen4exp_disabled_selector_ranking.py`: five guards on the
  part that can be silently wrong - an arm that enables a layer-gated selector
  without its layer companion measures a no-op, so that pairing is asserted;
  the arms must cover every disabled prefill selector; the baseline arm must
  enable nothing.

## Validation

- `.venv/bin/python -m pytest
  tests/test_unit_qwen4exp_disabled_selector_ranking.py` → 5 passed.
- The coverage guard found the tree's own bookkeeping is looser than the
  campaign narrative: of the fifteen `PRODUCTION_ARITHMETIC_RECOVERY_FLAGS`,
  five are re-admitted and **ten** stay off; `PRODUCTION_Q8_QSA_RESTORED_FLAGS`
  has six entries because `Q8_DOWN_VARIANT` is the companion value of one of
  the five rather than a selector of its own. The earlier "six restored, nine
  off" phrasing in the redirect entry is wrong and is corrected here.
- Performance-only: the harness records a token id but evaluates no numerics.
  A faster arm is not a qualified arm.
