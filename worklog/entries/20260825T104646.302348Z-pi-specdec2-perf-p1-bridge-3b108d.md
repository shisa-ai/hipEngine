# Add SPECDEC2 P1 common performance bridge

## Summary

Added the SPECDEC2-PERF P1 common bridge without changing runtime, kernel, or
shared dense-adapter behavior. The harness compares true Generation-2 AR,
current-source direct dense MTP, and staged Generation-2 SPECDEC2 under one
loaded service and one complete-request boundary. It reports both complete wall
and post-activation decode ownership, emits immediate progress, and atomically
checkpoints every completed arm.

Direct dense legacy MTP owns a singleton target session and is therefore an
execution-efficiency control only at C1. The harness explicitly skips it at C2
and C4 rather than presenting request-serial work as physical scaling. True AR
and staged SPECDEC2 remain directly comparable at C1/C2/C4.

## Changes

- Added `scripts/specdec2_perf_bridge.py` with:
  - canonical ten-prompt train/heldout/category loading and prompt hashes;
  - index-only AR/MTP counterbalancing across runs;
  - C1/C2/C4 and K1-K3 selection, warmups, repeated cells, and one loaded service
    per K;
  - complete-wall and decode-only timing plus exact generated-ID comparison;
  - strict timing-owner normalization that rejects duplicate/missing batch
    owners and invalid AR denominators;
  - named host stages for prefill, provider opening/NextN priming, proposal,
    bounded target cycle, packed-owner transition, graph close, AR decode, and
    terminal reclaim;
  - process-local hipEngine allocation-byte deltas, request/route telemetry,
    physical shape counters, manifests, prompt/model/source provenance, and
    final memory state;
  - atomic checkpoints, fail-closed artifact validation, and summary ratios; and
  - cached-build ROCTX leaf mode for final profiler children.
- Added `tests/test_specdec2_perf_bridge.py` covering parsers, canonical prompt
  identity, counterbalancing, timing ownership, dirty provenance, full-grid
  completeness, true-AR denominator integrity, route substitution, generated-ID
  exactness, decode timing, stage wrappers, summary math, and atomic writes.
- Kept implementation out of the gfx1100-shared runtime/adapters; this logical
  unit touches only the new harness, tests, and immutable worklog.
