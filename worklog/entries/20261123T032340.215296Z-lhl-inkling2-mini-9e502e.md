# Fuse attention-gate sigmoid into Inkling fast prefill

## Summary

Inkling GGUF `fast` now evaluates the attention gate inside the existing committed prefill attention kernel, removing the host sigmoid pass. The strict and unnamed profiles, scalar decode, and provisional blocks keep their existing arithmetic.

## Changes

- Register `block_sigmoid` on gfx1100 and gfx1151 and name its committed projected-prefill scope in the execution manifest. Keep `block` as the unfused strict control. Pass raw logits only through the committed block path. KV commit order is unchanged.
