# Boundary-stall fix plan: extend stateless segment graphs to dense and MoE chains

## Summary

Iteration-6 recon re-ranked the boundary-stall fix ladder using the runner's
existing graph machinery. The runner already graph-captures three stateless
segments per layer around the stateful GDN conv/recurrent mixer
(gr_read_attn, gr_write_ffn_read, epilogue),
each captured through a self-validating layer-graph run (eager fallback, out_ptr
digest, out_regions) that rejects non-bit-exact replays. The comment at the
capture site records why the whole-layer decode graph was retired: the mixer's
in-place state hazard. Dense projections and the MoE expert chain (router ->
pack8 experts -> silu -> weighted-sum) recompute from fixed scratch pointers with
no in-place state - the same stateless property the existing segments require -
and the stall pairs (rmsnorm to pack8, scaled_silu to pack8,
gated_mean to dense_gemv, pack8 to dense_gemv) sit exactly at the seams that
additional segments would remove.

## Changes

- No engine change; this unit commits the implementation plan for the next
  build session.
- Plan: extend the per-layer layer_graph.run segments with (1) the MoE expert
  chain as one stateless segment (router read, pack8 expert GEMVs, scaled_silu,
  weighted-sum - all fixed scratch/weight pointers), (2) the dense projection
  chain as a second segment. Both keep the existing self-validation (out_ptr
  digest + out_regions + eager fallback), so a capture that does not replay
  bit-exact is rejected and the plain path runs. Estimated seam removal: the
  52 x ~150 us boundary stalls at p4096 are dominated by exactly these
  transitions; the 5.15 ms/step small-gap floor needs launch-count reduction
  (fusion) or a solved whole-step graph.

## Validation

- Evidence chain for the plan: gap-analysis.json stall decomposition (52
  stalls/step at layer-section boundaries, adjacent-pair attribution at the
  MoE/dense seams); the existing segment captures replay 144/step with no
  reported failures; the mixer hazard note at the capture site explains why
  segment scope - not whole-layer scope - is the proven envelope.

## Next

- Build session: implement the two new segments behind the existing
  layer-graph path with the plain path as registered fallback; qualification
  via natural-input owner gate, full model-state gate and complete-engine A/B
  (same-residency instruments per the thermal protocol); the gap-analysis
  tooling re-measures the stall mass after the change.
