# Reconcile bounded DMS undo and remaining general journal debt

## Summary

Reconcile R0279 with the already-default bounded append-tail undo. Defer only
remaining general eviction/compaction host journal replacement, preserving the
working rollback owners rather than describing a future compact integration.

## Changes

  horizon and reserved capacity on every head. `snapshot_append_tail()` reads

  checkpoints and keeps initial undo through enclosing finalization.

  unused metadata keep the full transaction. General snapshots preserve the
  request's extent capacity, payload/scales, live metadata and extent/ledger
  ownership; a metadata-only undo would be incorrect.

  the bottom. Explicitly reject an unpriced prompt-proportional VRAM shadow;
