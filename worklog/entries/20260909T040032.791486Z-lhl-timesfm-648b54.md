# TimesFM pair-tile prefill flash attention

## Summary

The prefill flash kernel now processes two kv tiles per loop round: the
per-row max/sum shuffle reductions and the LDS P-staging (two
__syncthreads) are amortized over both tiles, halving the per-tile
synchronization and reduction overhead; expf -> __expf. Prefill flash
attention 882 -> 742.6 us/call (-16%, rocprof); wall metric 0.0909 ->
0.0874 s median (-3.8%, MAD 1.0 ms, multiloop HIGH confidence, 10 runs
0.0856-0.0897).

## Changes

- `hipengine/kernels/hip_gfx1100/timesfm/timesfm.hip`:
  `flash_attention_kernel` main loop restructured to 32-key rounds (two
  16-key tiles); `p_stage` extended to `[WAVES][2][16][17]`; masking,
  reductions, and the online-softmax update cover both tiles jointly
  (identical numerics: one max/alpha per round instead of two).

## Validation

- `python3 scripts/timesfm_gpu_bench.py --check`: fp32 strict parity +
  fp16 production gate pass.
- `python3 -m pytest tests/test_timesfm_gpu_decode.py -q`: 3/3.
- rocprof: 120 launches avg 742.6 us (was 881.8).
