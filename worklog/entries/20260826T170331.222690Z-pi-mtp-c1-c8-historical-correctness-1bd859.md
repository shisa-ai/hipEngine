# Add explicit historical MTP self-exact contract

## Summary

Extended the C1-C8 MTP comparison harness with an explicit historical
`mtp_self_exact` correctness contract. The old Qwen3.6-27B MTP route is
`llama_compat`, an accuracy-traded provider policy that may differ from ordinary
AR; requiring AR/MTP ID equality would mislabel a deterministic historical
control as invalid. The strict/default contract remains `ar_exact`.

## Changes

- Added `ar_exact` and `mtp_self_exact` contracts.
- Always report AR self-equality, MTP self-equality, and AR/MTP equality.
- Under `mtp_self_exact`, bind deterministic equality across the concurrent MTP
  rows while retaining AR/MTP difference as a visible diagnostic.
- Added a focused test proving the two contracts differ only in promotion rule.

## Validation

- OLD preflight first proved the current product model lacks the historical
  provider route at that commit; no timing was retained from the failed run.
- Focused harness tests pass 6/6; `py_compile` and diff hygiene pass.
