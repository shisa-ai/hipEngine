# Qwen3.8 standardized Q4 engine comparison

## Summary

Compared hipEngine and five llama.cpp routes on physical host `gfx1151` using
the same 17,106,775,008-byte Qwen3.8-27B `Q4_K_M` file (SHA-256
`7e78da5d7e3ae28d178121f58646953305f3e5bd3cb46f4a75584e8b6c6fe169`),
ten `mtp-bench` prompts, greedy sampling, disabled prompt caching, C1-C8, and a
complete-wall timing boundary. This matrix ranks engines; the separate
source-protocol runs only test whether published claims reproduce.

No engine won every phase and concurrency. Nathan led prefill and AR at C1.
Laurent led prefill at C2 and C6-C8, AR at C2 and C8, and MTP at C1-C3.
hipEngine led AR at C3-C7. Stock llama.cpp HIP led prefill at C3-C5 and MTP at
C6-C8; mainline Vulkan led MTP at C4-C5. Laurent therefore provides the
strongest broad alternate llama.cpp route in this matrix, but its ordinary
built-in MTP result must remain distinct from its unsafe adaptive DFlash2 path.

## Validation

- Decode command family: each llama.cpp server used
  `-m Qwen3.8-27B-Q4_K_M.gguf -ngl 999 -fa on -b 2048 -ub 512 --no-mmap -c 8192 -np 8`;
  AR omitted speculation and MTP used
  `--spec-type draft-mtp --spec-draft-n-max 3 --spec-draft-p-min 0.0`.
- hipEngine command:
  `scripts/gguf_mtp_c1c8_server_bench.py --model Qwen3.8-27B-Q4_K_M.gguf --backend hip_gfx1151 --quant Q4_K_M --execution-profile production --prompts benchmarks/prompts/mtpbench-code-general-ja.jsonl --widths 1,2,3,4,5,6,7,8 --resident-capacity 8 --expected-mtp-widths 1,2,3,4,5,6,7,8 --max-tokens 24 --candidate-budget 3 --batch-window-ms 50 --generation2-diagnostic --correctness-contract mtp_self_exact`.

  prompt tokens divided by barrier-to-last-completion wall time, so every
  engine shares one end-to-end boundary.
- All llama.cpp rows passed character-window and word-trigram repetition
  guards. hipEngine passed its AR/MTP self-exact contract and the separate
  prefill-dominant run passed all cells.
- Parsed the compact artifact with `python3 -m json.tool` and recomputed every
  table cell from raw JSON under
