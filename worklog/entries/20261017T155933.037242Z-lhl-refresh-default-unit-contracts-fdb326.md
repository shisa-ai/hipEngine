# Refresh architecture-portable default unit contracts

## Summary

The default unit suite had stale expectations after the gfx1151 route registry and
Qwen4Exp production composition moved forward. Several micro-dispatch tests also
let the ambient `HIPENGINE_HIP_ARCH` override replace their W7900 fixture
identity, so the same tests failed on a gfx1151 host before reaching their
intended comparison assertions.

## Changes

- Pin the micro-dispatch fixture normalization to its declared gfx1100/W7900
  identity through explicit `hardware_gpu` and `gfx_arch` overrides.
- Update the gfx1151 registration ledger assertion for the current qualified
  DP4A, weighted-sum, GDN, and grouped-norm publication registrations.
- Refresh Qwen4Exp assertions for wide-before-WMMA dispatch, UD F16 row-split
  GDN binding, Q4_K_M multi-column GDN binding, and GR-up hyper-connection role
  attribution.
