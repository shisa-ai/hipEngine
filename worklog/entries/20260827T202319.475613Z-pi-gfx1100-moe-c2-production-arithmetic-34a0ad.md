# Qualify packed MoE C2 production arithmetic

## Summary

Localized the 35B MoE physical-C2 production numerical failure to the packed
linear-attention composite. The incumbent rows6 path fails the binding gate at
mean/p95/p99/max KL `0.001682/0.007716/0.020213/0.111938`, top-1 `98.876%`.
A layer-output oracle on the exact failing `general_en_plan` row showed smooth
BF16 drift through layer 21 and a MoE routing amplification at layer 22. A
layer-major row-exact linear-attention owner makes all 40 layer outputs
bit-identical and the six-prompt code+English gate zero-KL.

This is a correctness fallback, not a promotion-speed result: one-run complete
wall is approximately `0.74-0.87 s/request` versus true AR `0.53-0.56 s`, with
target+accept+provider time `5.20 s / 89 cycles` across the suite. Automatic C2
must remain absent while the same arithmetic is re-batched.

## Changes

- Add a request-local MoE C2 exact-linear scope selected only by the capacity-2
  MoE adapter; C1, Dense, strict, ragged rows, and unsupported widths retain
  their prior owners.
- Execute each R6 linear-attention layer as two transaction-local R3 request
  segments and six scalar attention rows, writing exact Conv/GDN row journals.
- Keep the stateless MoE FFN row-batched after the exact attention rows; this is
  bit-identical and avoids a per-request backbone loop.
- Extend the corrected production gate to capture/replay the exact-linear scope.
