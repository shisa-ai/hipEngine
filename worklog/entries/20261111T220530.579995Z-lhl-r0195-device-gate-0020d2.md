# R0195 permanent gfx1100 physical-target device gate (production/strict exact + C4 miss)

## Summary

Added `tests/test_live_gguf_r0195_physical_target.py`, a permanent HIP-availability +
model-presence guarded device gate for the R0195 physical-target rowtile policy on
gfx1100. It drives public `LLM.generate_detailed()` with `speculative_mtp=True` on the
nextn-bearing `/models/gguf/Qwen3.8-27B-Q4_K_M.gguf` artifact and asserts the device
dispatch attribution and exactness. Each case runs in its own subprocess because the
candidate budget is fixed at adapter construction and accumulating engines in one
process exhausts VRAM. Both tests pass on the W7900.

## Changes

- `tests/test_live_gguf_r0195_physical_target.py` (new): worker/driver in one file;
  `R0195_WORKER=budget:profile` selects subprocess mode. Broad BFS locates the mtp2
  adapter exposing `physical_width_contract()`.
- `docs/REFACTOR.md` R0195: records the gfx1100 device gate and the remaining coverage.
