# Gemma flash decode denominator broadcast

## Summary

The production Gemma gfx1100 flash-decode kernel previously recomputed each slice denominator identically in every thread. The optimization computes one same-order sum per query row and broadcasts through existing shared memory. This reduces redundant device work without changing the strict fallback or public dispatch route.

## Changes

- Updated `hipengine/kernels/hip_gfx1100/gemma4/gemma4_attention.hip` to broadcast slice denominators from one lane per query row.
- Kept the existing per-row accumulation order and flash workspace layout unchanged.

## Validation

- Exact 64K production benchmark: 23.6740 tok/s versus kept 23.6652 tok/s baseline.
- 162 focused Gemma tests passed.
- Public 64K and 512-token campaign paths reported `path parity=True`.
- Candidate accepted by the active performance loop.
