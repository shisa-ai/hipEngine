# Reject packet C1: broad Q8T16 rowtile regresses c2/c4 on W7900

## Summary

Rejected the broad Q8T16 all-projection rowtile transfer (audit packet C1,
`docs/20260905-gfx1100-audit.md`). The same-source W7900 A/B on
Qwen3.6-35B-A3B (candidate differs only by `HIPENGINE_GGUF_Q8_T16_ROWTILE_ALL=1`)
regressed c2 150.481→146.064 tok/s (−2.94%) and c4 216.427→214.188 (−1.04%)
with fully separated sample ranges, and left native_c8 noise-flat
275.244→275.660 (+0.15%, overlapping ranges). The gfx1151 outcome (package
floor 4: c4/c8 retained, c2 rejected) does not transfer — no W7900 width
qualifies a floor, so `GGUF_Q8_T16_DECODE_ROWTILE_MIN_ROWS` stays 0 and the
broad boolean stays off.

The route is reachable on this model (attn_qkv 2048→8192 and attn_gate
2048→4096 match the Qwen3.5-family constants; same model as the gfx1151
C-packet evidence), and widths 2/4/8 stayed exact and repeatable under the
candidate, so the decision is purely the measured regression.

## Changes

- No code change: the A/B was environment-only and the package already
  encodes the rejected outcome (`GGUF_Q8_T16_DECODE_ROWTILE_MIN_ROWS = 0`,
  `GGUF_Q8_T16_DECODE_ROWTILE_ALL = False`).
- Added the compact rejection artifact
  `benchmarks/results/2026-09-05-gfx1100-gguf-q8t16-rowtile-all-rejected.json`.
