# Reuse shared Flash-Next position metadata

## Summary

The lead redirected work from inherited numerical investigation to bounded
performance improvements, with a one-hour checkpoint. The candidate avoids
re-uploading identical QSA positions and context counts across layers. It changes
no arithmetic, selection, sampling or transaction semantics. Inherited quality
findings remain separate; no threshold changes are made.

## Changes

- Cache the last successfully uploaded `(start_position, rows)` pair in the
  owner of the shared QSA prompt metadata. Keep resetting each layer's host
  selection scratch even when its read-only device positions are reusable.
- Invalidate the cached pair before either upload. If the second copy fails,
  retrying even the former pair must upload both planes again.
- Preserve validation before reuse, including owner lifetime and capacity bounds.
  No kernel body, registry selection or environment flag changes.
- Add a RED regression for redundant uploads, plus partial-copy-failure,
  changed-shape, changed-position, reuse and closed-owner checks.

## Rejected investigations

- Stateless expert graph reuse passed four changing-routing GPU tests, ten
  public prompt trajectories and 44 full-logit/hidden/committed-state cases.
  Its matched HTTP MTP decode rates changed by -0.27% at 1K and -0.09% at 4K,
  so it is not kept as a speedup. `comparison.json` binds the exact commands,
  model/host identities, samples and candidate diff.
- A follow-up enabled verifier use of the existing GDN stateless segment cache.
  Eighteen public trajectories and 44 state cases matched, but the engagement
  assertion failed: that backend's layer cache is disabled by its existing
  policy. No performance run followed. The existing ledger records a prior
  decode layer-graph slowdown; this unit does not flip that default.
- A bounded expert diagnostic on captured real verifier inputs found no useful
  gain from replacing grouped projections with selected projections or changing
  the expert-grid setting. This did not change runtime defaults.
- All graph runtime changes and graph-only tests are removed from the candidate.
  Their patch, test sources and logs remain in the temporary evidence directory.

## Next

Ship the metadata reuse on the default path without a new flag. This is a small
measured gain, not closure of the wider Flash-Next performance gap. Graph-only
changes are not included. Future work can examine the per-cycle serving state
snapshot cost, but must preserve its rollback contract; no snapshot bypass is
part of this change.
