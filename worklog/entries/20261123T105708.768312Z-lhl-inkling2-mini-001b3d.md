# Screen device-side Inkling expert routing

## Summary

The device-side router selected the same expert IDs on all captured W7900 rows and finite tie fixtures. Its FP32 mixture weights were not bitwise identical to NumPy. It is not ready to replace the host router.

## Changes

- Scratch only. Replay real scalar router logits with the same optional bias, lower-index tie break, ascending expert order and eight-way normalization. Public generation still uses the original router for all outputs.
