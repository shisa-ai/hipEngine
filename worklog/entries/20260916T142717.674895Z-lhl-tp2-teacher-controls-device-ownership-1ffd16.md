# TP1 device ownership fixed; teacher controls requalified

## Summary

Fixed the TP1 control's missing device owner boundary. `MlpTP2GenerationSession._local_mlp`
ran its full-width gate/up/SiLU/down launches with no `scoped_current_device` and on
`stream=0`. `_enqueue_layer` invokes it in a dict comprehension outside any device scope,
and the preceding scoped attention/add-norm blocks restore the ambient device (usually 0),
so a rank-1 session launched the full-width decode GEMV against device-1 pointers from
device-0's context. On the RX 7900 XTX this was a **silent no-op**: all 17,408 gate and
17,408 up outputs were left unwritten, producing all-NaN logits
(`finite=0/3973120`). The fix wraps the whole chain in
`scoped_current_device(self.runtime, device)` and uses `stream=self._rank_stream(device)`,
matching the sharded route's existing boundary in `shard_exec.py`. No backend/quant
branches were added; no kernel changes were needed.

The harness unit (`ef3d8dac9`) and the sentinel probe unit (`494d2ef86`) are the parent
commits. This unit is the fix plus the broadened control evidence that the fix unblocks.

## Changes

- `hipengine/distributed/tp2_generate.py::_local_mlp` — rank-device scope + rank stream
  for the full TP1 MLP chain. `_local_mlp` is TP1-only, so TP2 arithmetic is unchanged.
- `tests/test_unit_distributed_tp2_generate.py` — 4 new RED/GREEN tests: rank-device
  launches (direct), rank stream, ambient restore on exception, and the full
  `_enqueue_layer`/`generate` path with ambient device 0 and rank 1. RED before the fix:
  3 failed (`[0, 0, 0, 0, ...]` recorded for rank-1 launches; stream 0 not 0xB0).
- `scripts/tp2_fullwidth_gemv_sentinel_probe.py` — corrected the `0x7BFF` comment: as a
  bf16 word it is exponent 0xF7 / mantissa 0x7F (a large finite value), not the FP16
  65504 the same word encodes; added the explicit note that `os._exit` is diagnostic-only.
- `scripts/tp2_teacher_child.py` — `os._exit` comment now states it is diagnostic-only and
  not a teardown qualification.
- `benchmarks/results/2026-09-16-w7900-tp2-teacher-coverage-broad.json` — retained
  broadened 3-arm evidence.
- `benchmarks/README.md`, `benchmarks/CHANGELOG.md` — retained row/rollup + audit note.
