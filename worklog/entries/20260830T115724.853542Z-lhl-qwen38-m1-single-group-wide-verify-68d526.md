# Qwen3.8 M1 single-group wide verify

## Summary

Implemented scaling-campaign M1: the width-4 MTP physical partition is
replaced by one capability-owned, profile-keyed width bound, so one cycle in
the gfx1151 production profile covers all due requests through C8/R32. The
misleading `GGUF_SPECDEC2_MTP2_C4` boolean gate is replaced by
`GGUF_SPECDEC2_MTP2_PHYSICAL` (admission) plus
`GGUF_SPECDEC2_MTP2_PHYSICAL_MAX_REQUESTS` (per-profile bound). gfx1151
production maps to 8; strict (and any unlisted profile) retains the
certified width-4 partition as the registered strict fallback; gfx1100
admits no physical multi-request adapter. GPU binding gates (all-80-cell
exact suite, acceptance parity at 78.894%, C1-C4 non-regression, C5 >= 33 /
C8 >= 45 tok/s targets, rows5-8 proposal-head fallback cost record) are
measured after this mechanism lands; results are appended below before the
unit is closed.
