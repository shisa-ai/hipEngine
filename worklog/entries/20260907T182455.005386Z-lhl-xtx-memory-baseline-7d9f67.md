# Record GPU1 memory-reduction baseline at 72K

## Summary

User-directed memory-reduction work on GPU1 (RX 7900 XTX), extending the
capacity campaign past the exhausted punchlist. First unit: a measured
before-anchor, since the 2026-09-07 sizing review ran no GPU benchmarks and
the source had moved since the edge-capacity artifacts.

Fresh-process C1 DMS INT8 probe (unchanged code) at the requested-ladder
passing point 73,728 prompt tokens, eight decode steps, under the same
whole-card 20 ms sampling protocol: sampled whole-card peak 23.974953 GiB
(peak_delta 23.948845 GiB over a 26.7 MiB baseline), tracked peak
23.186015 GiB, sampled headroom 9.648438 MiB, 268.5 s elapsed, clean return
to baseline, zero tracked allocations after close. The tracked peak is
bit-identical to the prior requested-ladder 73,728 run (24,895,794,136
bytes), reproducing that result on current source; the whole-card peak
differs only by the card baseline offset.

Also recorded deterministic CPU-side placement/arena decision evidence for
the probe's wiring: with the shared runner, token embedding resolves to
`('device', 'shared_runner_device_fallback')` and the small weight arena to
`(False, 'shared_runner_fallback')`; without a shared runner they resolve to
`('host', 'mapped_host_private_c1_auto')` and `(True, 'private_c1_selective')`
(the decode-scratch arena would also engage, but DMS sessions force it off in
`__post_init__` regardless of wiring). This is the target-2 before-state.
