# PN3 selected-expert MoE host-dispatch: measured no-win

## Summary

Closed the selected-expert MoE host-dispatch mechanism for the c1
Qwen3.6-35B-A3B-UD-Q4_K_M gfx1151 decode lane with a measured no-win, per PN8
("a measured no-win/blocker conclusion and the next dominant owner"). The
remaining dispatch host is hidden under GPU execution; the slice is GPU-bound.

## Baseline (2026-08-20, 8060S / gfx1151, sync'd eager, prefill 512)

- complete wall 26.11 ms/tok; selected-expert MoE slice 3.48 ms/tok (~13%).
- selected-expert host wall 1658.5 us/tok over 80 launches/step = 20.7 us/call
  (env-flag reads + quant-key branches + allocation lookups + arg packing).
- GPU kernel portion of the slice ~1.8 ms/tok.

## Decisive A/B (counter-rotated, scripts/pn3_moeselect_dispatch_ab.py)

Memoized the exact default-branch launches for the 3 selected wrappers
(`_launch_selected_raw_gguf_moe_pair_silu` -> dual_silu_gemv,
`_launch_selected_raw_gguf_moe_pair` -> dual_gemv, `_launch_selected_raw_gguf_moe_linear`
-> registry-single), skipping env reads/allocation lookups/branch chain while
reproducing the same kernel fn + args (byte-identical launches by construction):

- old (dispatch): 25.83 / 26.20 -> mean 26.01 ms/tok
- fast (memoized): 26.21 / 26.06 -> mean 26.13 ms/tok
- delta **-120 us/tok (-0.5%)**, within noise -> ~0 wall.

## Cross-references

- `pn4-c1-no-win-close` (20260817): host memoization "not worth it" (model ~94%
  GPU-bound); the recoverable part was the *blocking* library build.
- `pn6-t16-selected-dense-hoist` (20260819): hoisting t16_selected (25 sites,
  host 48.7 -> 23.9 us/call) recovered ~0 wall for the dense slice (GPU-bound).
- `pn4-laq1b-rejected` (20260817): W4 GEMV latency/occupancy-bound at 510-540 vs
  650 GB/s practical L2 ceiling.

## Conclusion

The library-build host cost (the blocking, recoverable part) is already hoisted
tree-wide (PN5/PN6/PN6-t16). The remaining selected-expert dispatch host is
overlapped under GPU execution (measured ~0 wall to remove). The remaining
3.48 ms slice is GPU kernel math (~1.8 ms) + unavoidable dispatch; the W4 GEMV
is near the gfx1151 practical bandwidth ceiling. Host-dispatch mechanisms are
closed for the c1 MoE surface.
