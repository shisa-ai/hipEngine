# gfx1100 rdna3 transfer packet F1 packed-prefill mask retain

## Summary

Audit packet F1 is **retained**: `GGUF_PACKED_PREFILL_FINAL_OUTPUT_MASK`
moves `False` -> `True` on `hip_gfx1100` after independent same-host W7900
qualification. Intermediate slot-fair bounded prefill rounds now skip output
norm, the full Q6 LM head, and sampling; each slot's final tail is still
sampled. The retained result is an exact launch and device sub-window
reduction, **not** a throughput improvement.

## Changes

- `GGUF_PACKED_PREFILL_FINAL_OUTPUT_MASK` `False` -> `True` on
  `hip_gfx1100`, with the capability comment recording the measured W7900
  round structure.
- RED-first test updates: `test_gfx1151_backend.py` gains
  `test_packed_prefill_final_output_mask_is_qualified_on_both_backends`
  (replacing the gfx1100-is-False assertion) and the gfx1100 assertion in
  `test_qwen35_gguf_mtp2_seam.py` now expects `True`. Both were written
  first and failed on the package value before the flip.
- `docs/REFACTOR.md`: the GGUF AR server packed-prefill row no longer says
  gfx1100 keeps the unmasked fallback pending qualification.

## Validation

All runs on the physical W7900, Qwen3.8-27B `Q4_K_M` with BF16 KV, cached
builds, pinned compiler-version file.

- **Reachability** (`scripts/gguf_packed_prefill_slab_probe.py`):
  `bulk_prefill_scratch_rows` 256 and `first_splitting_wave` 8. At the
  canonical 36-token suite encoding widths 1-7 are single-chunk and the mask
  is a no-op; width 8 splits `[256, 32]`. Longer prompts split at every
  width: a C8 512/384 shape plans five rounds whose first three carry no final
  slot at all.
- **State differentials** (`scripts/gguf_packed_ar_state_oracle.py`, arms
  differing only by the package value, compared with
  `scripts/diff_differential_arms.py`):
  - 512/384, five rounds: differs on exactly
    `final_output_mask_enabled`, `output_norm_rows` and
    `lm_head_sample_rows` (**33 -> 8**). Packed token trajectories are
    byte-identical; `tokens_exact` true and `lifecycle_state_exact` true in
    both arms; the `first_divergence` hash pair is identical across arms.
  - 64/48, two rounds: same three fields (**16 -> 8**), trajectories identical.
    Both arms report `tokens_exact` **false** against the strict c1 teacher on
    this short shape. That verdict is present with the mask off and the packed
    trajectories match across arms, so it is the documented pre-existing
    packed-versus-c1 divergence, not an effect of the mask. This was checked
    explicitly because the candidate arm was measured first and the false
    verdict could otherwise have been misread as a regression.
- **Cancellation and admission** (`scripts/gguf_arbitrary_c_lifecycle.py`
  `--rows 8 --cancel-slots 2 5 --prompt-length 384 --compact-after-middle-hole`,
  a multi-round prefill shape): comparator verdict **SAME**.
  `original_tokens_exact` and `newcomer_tokens_exact` true in both arms,
  outputs identical, cancelled sessions reused by newcomers, compaction
  passed, declared widths only, no serial fallback. The KV mismatch **location
  sets** are identical across arms (cancelled 64, newcomers_final 222,
  survivors_final 160, survivors_middle_hole 160, inactive 0); only the
  address-dependent hashes differ, which the comparator excludes by the C2
  precedent.
- **Route trace** (`rocprofv3 --kernel-trace` over
  `scripts/gguf_packed_ar_bench.py` p512 native_c8, one measured run, one
  decode step): the full 248,320-row head
  (`q6_k_t16_qmicro_planar_gemv_rowtile_col8_kernel<float, 8, true>`,
  `grid_x=3973120`) falls **7 -> 2 launches** and **15,621.2 -> 4,659.0 us**
  device time; total dispatches **24,564 -> 24,494** (**70 removed**, matching
  the gfx1151 figure). A p512 C8 prefill plans six rounds: the control samples
  the head once per round plus once for the decode step, the candidate once
  for the final round plus the decode step.
- **Numerical screen**
  (`scripts/execution_profile_gguf_batch_route_gate.py --packed-prefill-candidate`):
  - Mask-engaged widths 4/8 under `q4_selected_pair_candidate` (package
    floor-driven, no candidate env set, so no route confound): 1,050 rows,
    KL mean/p95/p99/max **7.771e-05 / 4.039e-04 / 7.224e-04 / 2.191e-03**,
    top-1 **0.99810**, every shape scope passed (c8 480 rows, top-1 0.997917),
    three deterministic repeats, zero scope failures.
  - Widths 3/5/6/7 under `current_package_direct`: 1,950 rows, all hard gates
    passed, reproducing the pre-flip ledger figures. **These widths are
    single-chunk at the canonical encoding, so this run does not exercise the
    mask** and counts only as route-level non-regression.
  - Both runs report `invalid_or_screen_only` / `measurement_valid: false`
    from the three pre-existing harness blockers already recorded in
    `docs/REFACTOR.md` (evidentiary rather than runtime-profile-resolved route
    manifest, incomplete exact control-plane record schema, no fresh task or
    BF16-relative verdicts). They are harness properties and applied equally
    before this change.
- **Performance** (`scripts/gguf_packed_ar_bench.py` native_c8 p512/d128,
  1 warmup + 3 measured, counterbalanced control/candidate/candidate/control):
  pooled prefill 378.302 -> 377.613 tok/s (-0.182%), decode 132.029 -> 131.811
  (-0.165%), TTFT 10.827 -> 10.847 s (+0.181%). **Flat within drift; no
  throughput is claimed.** The four arms fall monotonically in wall-clock order
  (379.755, 378.043, 377.184, 376.848) regardless of arm, and the two control
  arms differ from each other by **0.77%** on prefill, more than the 0.18%
  pooled candidate-control difference. This matches the gfx1151 precedent,
  which measured 0.033-0.219% pooled prefill wall and retained the capability
  as an exact launch reduction.
- **Tests**: 187 passed across gfx1151 backend, mtp2 seam, packed AR state
  oracle, packed execution manifest, packed prefill grouping probe, slab probe,
  packed AR bench, and packed decode graph.
