# Capacity-64 batched prefill probe exceeds the 5e-3 diagnostic tolerance on a 1-2 ULP row

## Summary

Extending the rank-local batched TP2 MLP prefill probe to the requested rows
63/64/tail coverage (capacity 64) on the real GGUF shard quants shows the
inactive tail is zeroed correctly at every partially filled batch, but the
probe's 5e-3 batch-composition tolerance is exceeded: the batched-vs-serial
per-row relative error is 1.7e-04 for active rows 1-12 and jumps to exactly
5.0505e-03 at active 13, then stays constant to 64. The jump is quantized to
bf16 ULPs, so this is a diagnostic-tolerance calibration issue, not a
control/ownership defect. The probe tolerance is **not** relaxed; the
production decision stays on the calibrated KL/top-1 profile gates.

- Measured: active 1 exact; active 2-12 partial rel <= 3.3e-04; active 13-64
