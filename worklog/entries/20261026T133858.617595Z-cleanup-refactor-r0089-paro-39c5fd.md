# Own PARO runner upload arrays

## Summary

PARO runner synchronous array uploads retain their source owners. R0089
remains open for other array callers.

## Changes

- Migrate synchronous uploads without changing offsets or launch ordering.
  Normalize allocation-helper inputs to contiguous arrays.
- Preserve destination-sized `_copy_zero` semantics explicitly. Parent review
  caught the initially changed default; add an unequal-template regression.
- Update test mocks to owning-array arguments and source-sized defaults.
  Keep raw-pointer and asynchronous copies unchanged.

  zero upload passed on gfx1151.
