# Generalize Qwen4Exp multimodal support

## Summary

Generalized Qwen4Exp multimodal support at <=1K from one 32x32 image to merge-
compatible grids, multiple images, videos, explicit text T/H/W MRoPE, and
bounded PNG OpenAI chat input. Text-only behavior and teardown remain exact.

## Changes

- Reworked the vision runner for dynamic block-major 2x2 grids, align-corners
  position interpolation, up to 256 patches/temporal pair, multiple images,
  paired video frames, and odd-final-frame duplication.
- Added pure typed-placeholder expansion/count gates and Qwen3.5/Qwen4Exp
  compressed 3-axis position construction.
- Added registered single/row MRoPE QSA siblings using interleaved sections
  `[11,11,10]`; scalar text kernels remain unchanged.
- Threaded optional axis-major positions through prompt/decode runners and
  resumed decode at max multimodal position + 1.
- Generalized public media input and added bounded base64 PNG multipart chat,
  `ServerConfig.vision_model`, `--vision-model`, capability-gated legacy errors,
  and explicit unsupported combinations.
- Artifact: `benchmarks/results/2026-08-28-gfx1151-qwen38-flash-next-general-multimodal.json`.

## Validation

- Independent Transformers 32x64 oracle: shape 2x2560, relative L2 1.482e-6,
  cosine 1.0, max absolute error 3.874e-7.
- Public rectangle/two-image/three-frame-video cases return finite two-token
  rows; text IDs before/after are exact.
- Black-vs-pattern 16-token outputs diverge; patterned response begins “Based
  on the image provided”.
- Physical `/v1/chat/completions` PNG request returns HTTP 200; peak tracked
  84,002,567,288 bytes and shutdown returns to zero.
- Complete Qwen4Exp focused bundle: 153 passed.
- Server protocol: initial full run passed through node 554; one capability-
  error regression was repaired, then the failing node and four-node tail pass.
  Existing no-vision `unsupported_content_type` behavior is preserved.
- Cache-only MRoPE trace: `qsa_norm_rope_rows_f32_kernel<true>`, 12,143 ns,
  workgroup 256, grid 512x3, zero scratch; no compiler under profiler.
