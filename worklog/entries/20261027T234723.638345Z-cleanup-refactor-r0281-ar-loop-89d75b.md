  `_generate_ar_serving_slots` sentinel. The test covers blocking two-row packed

  `_step_native_serial()`, not the old whole-batch generator entry. Direct
  `Qwen35GGUFBringupGenerator.generate_detailed()` still calls the old entry.

  `_flush_ar_packed_decode_owners_if_chunk_changed()` and

  group changes, serial transitions and reclaim. Removing the entire old
  source region would break the live owner.

  decision, caller migration and shared-helper extraction sequence. No runtime,
  dispatch, admission, default or arithmetic change. Characterization test is
  already GREEN; no production defect is being repaired, so RED is inapplicable.
