# Build-identity fast read attempted, measured, reverted

## Summary

Iteration 4 targeted the decode host path's per-launch library re-resolution:
`_resolution_environment_identity` was rewritten to read the eight
build-identity variables from the live raw environment mapping
(`os.environ._data`, captured once) instead of the str view - 173 ns/call
against 2,292 ns measured in isolation (13x), projecting ~1.95 ms/step at the
~980 resolutions/step decode rate, with live-change observation preserved
(monkeypatched tests, the `hip_target_arch_environment` scope). The change was
**measured and reverted**: the same-residency decode A/B showed only +0.12%
at p512 (tight, consistent) and an unexplained **-2.7% at p4096** with no
identifiable mechanism (zero memo misses, identical libraries, launch counts
and outputs), on a heat-soaked host after ~40 minutes of sustained load. Per
the loop's acceptance policy the change is not retained without a measured
improvement; the blocker is recorded and the cooled paired re-measurement is
the follow-up.

## Changes

- Attempted (now reverted): `_resolution_environment_identity` raw-mapping fast
  read plus a fallback to the bytes view, in `hipengine/core/build.py`, with a
  live-observation unit test appended to `tests/test_unit_build.py`.
- Committed: `scripts/qwen4exp_build_identity_decode_ab.py` - a same-residency
  decode A/B harness that swaps the identity derivation between arms inside
  one model residency with balanced order (reusable for the cooled re-run).
- Committed: the A/B artifact and probes under
  `benchmarks/results/2026-10-08-qwen4exp-build-identity-fast-read/`.
- `docs/REFACTOR.md`: the per-launch `build_X(load=True)` entry now records the
  attempt, the isolated measurement, the revert and the open follow-up.

## Validation

- Isolated: 173 ns vs 2,292 ns per identity call (timeit, 5-repeat min);
  decoded values match the str path exactly; live set/pop observed through the
  raw mapping; 16 build unit tests green including the new live-observation
  contract.
- Same-residency decode A/B (one process, balanced arms, 6 reps/arm):
  code-p512 slow 6091.2 ms / fast 6083.7 ms for 128 transitions (+0.12%,
  cross-arm outputs exact); code-p4096 slow 7068.6 ms / fast 7261.4 ms
  (-2.7%, cross-arm outputs exact, zero `plan_hip_build` calls in either arm).
- In-situ probe: ~981 identity calls per decode step confirmed; the module
  swap is live at the build_hip call site.
- The p4096 inversion has no mechanism: no memo misses, identical launch
  families, identical outputs. The host was heat-soaked (walls moved 55 -> 61
  -> 97 ms/step across the evening on unchanged code); the measurement
  instrument cannot resolve this effect tonight.
