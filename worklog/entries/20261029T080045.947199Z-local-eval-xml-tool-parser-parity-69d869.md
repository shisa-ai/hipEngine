# Align streaming and final XML tool parsing

## Summary

The recorded `parser_failed=False stream_state=parameter streamed_calls=14
parsed_calls=14` failure does not prove an incomplete model call. The wire log
contains 13 complete translated argument objects and only `{` for call 14, but
not the original generated XML or generation chunk boundaries. A synthetic
14-call response with `<parameter=command >` on its last call reproduces the
baseline counters and wire ending exactly. This establishes a parser defect,
not the historical triggering bytes. No evaluation arm was retried or reclassified.

## Changes

- Streaming strips surrounding function/parameter-name whitespace as the generic
  final parser does. The generic final parser accepts compact envelopes, and the
  stream accepts the same case-insensitive outer tool tags as final discovery.
- Generic final XML parsing rejects duplicate normalized parameter keys instead
  of silently overwriting an earlier argument. Strict model-owned parsers remain
  authoritative; the final schema and argument consistency checks remain active.
- Independent review found that switching from emitted XML calls to buffered
  legacy JSON skipped argument reconciliation and could re-emit earlier calls
  at index zero. The server now reconciles the emitted prefix, fails closed on
  invalid/mismatched tails, and emits remaining calls with continuing indexes.
- Opted-in final tool-stream error replay artifacts include source text chunks.
  Existing hash redaction applies to each chunk; only explicit `none` stores raw
  text. The replay API contract documents the distinction. Earlier generation
  errors are not changed by this scoped capture.
- `docs/testing/20261029-xml-tool-parser-replay.json` records source hashes,
  translated wire accounting, reconstructed completed-call checks, the synthetic
  counterexample, and the inability to recover the original generation.

## Validation

- RED: the initial lexical/duplicate tests failed 15 cases against the baseline;
  both replay-capture tests failed because generated chunks were absent. The
  mixed XML/JSON matrix failed all 12 cases before the reconciliation repair.
- GREEN: 789 tests passed in the affected server/model-parser bundle. Separately,
  all 44 XML parser/stream/constraint unit cases passed. The intentional replay
  format extension required updating one existing hash-redaction expectation;
  its focused repair passed without suppressing the privacy assertions.
- Reconstructed the 13 complete retained calls as canonical XML and compared
  both parser outputs with the original JSON values at widths 1, 2, 7 and 3831.
  These are reconstructed values, not a claim to have replayed missing XML.
- A deliberately disagreeing model parser with equal call counts is rejected.
  Malformed, duplicate, unknown-name and mixed-envelope failure tests forbid any
  successful tool-call finish and verify replay capture where applicable.
- Independent read-only review confirmed the evidence limitation and, after a
  reproduced repair, found no remaining blocker in mixed-envelope handling.
  The matrix was then extended to one and three emitted prefix calls; all 24
  cases passed, including a final prefix shorter than the already-emitted calls.
- The default unit suite and CPU deterministic bundle passed (compileall,
  fixtures, registry/CPU smoke, smoke-add-plan, test tiers and diff whitespace).
  All four documentation gates passed with 46 existing front-matter warnings.
- A natural streamed `report(message="parser-ok")` tool request succeeded through
  the real GPU server with HTTP 200 and `tool_calls` finish. It did not execute
  the tool. Padded names and mixed-format failures were exercised deterministically
  through the HTTP application, not induced by model sampling.
- Normal server `bg-59` runs the final source hashes with 204,800 context and INT8
  KV storage, unchanged from the prior deployment. Startup hashes match disk and
  the public check; replay logging remains off in this normal server. The
  companion JSON records request/response and production-source hashes.
