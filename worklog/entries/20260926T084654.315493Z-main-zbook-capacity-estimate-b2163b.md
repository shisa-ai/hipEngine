# Price serving-capacity workspace leases independently of request KV

## Summary

The estimator prices the eager workspace at serving capacity independently of
elastic per-request KV. Context cache keys include capacity; previously a cached
C1 selection bypassed C4 pricing.

## Changes

- Add optional `workspace_lease_slots` to the breakdown and capacity estimator,
  defaulting to batch size for existing direct callers.
- Pass serving capacity from the generator and update context-cache semantics.
- Add tests at contexts 511, 1025, 5379 and capacities 1, 4, 8 that compare
  estimated pages with the allocator's workspace-page helper.
- Resolve the ledger entry and record its audit disposition.
