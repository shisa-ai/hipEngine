# Add K_S IQ3_XXS and IQ2_S strict dense leaves

## Summary

Add the two K_S-only strict dense projection types. Independent real-row
GPU gates pass on gfx1151; loader and embedding integration remain next.

## Changes

- Extend `gguf_iq_dense.{hip,py}` with Q=4 IQ3_XXS and Q=5 IQ2_S, both
  BF16/F32 outputs and row-batched aliases. Same 128-thread noncontracting
  strict reduction and raw storage as the prior dense leaves, no fused path.
- New table header copies byte-identical in-tree CPU tables. Source:
  llama.cpp@17252c769a63c1cb650ce98ae309cf4de0da7778,
  `ggml/src/ggml-common.h` and `ggml-quants.c`, MIT notice included. The new
  header's SHA256 is part of compiler flags so header changes invalidate the
  JIT cache; the hash is computed once at module import, not each launch.
- Reviewed the in-tree selected `gguf_iq_gemv.hip` and CPU decoder indexing;
  no selected-expert code changed. Narrow lineage command selects no manifest
  entries. No external checkout changed.
