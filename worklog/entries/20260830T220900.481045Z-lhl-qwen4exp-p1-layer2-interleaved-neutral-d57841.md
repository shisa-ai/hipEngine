# Definitive interleaved A/B: layer-2 grouped routing is neutral

## Summary

Three counterbalanced baseline/candidate pairs in a single thermal window
(baseline = layer-2 strict; candidate = `HIPENGINE_QWEN4_EXP_GROUPED_MOE_PREFILL=1`,
which routes layer-2 Q5_K gate/up through the grouped WMMA body and is
byte-identical to layer-2 production admission). Result: layer-2 grouped
routing is **neutral** — paired median diff +0.57 tok/s on ~80 tok/s
(t=0.61, n=3, not significant). This supersedes all earlier
non-counterbalanced readings (the 20260830T212030 +4.8% and 20260830T214806
correction, and any standalone-run numbers). The campaign's P1 expectation
that routing layer 2 would remove a ~300 ms isolated miss is NOT realized on
this host.

## Changes

- Ran 3 interleaved baseline/candidate pairs (warmup 1, rep 1 each) of the
  canonical p512 exact-token bench in one process/thermal window; computed
  paired differences.

## Validation

Same zbook/gfx1151, canonical p512 fixture, deterministic in every run:

| pair | baseline | candidate | cand-base |
| --- | ---: | ---: | ---: |
| 1 | 80.52 | 79.90 | -0.62 |
| 2 | 79.60 | 80.17 | +0.57 |
| 3 | 79.78 | 80.67 | +0.89 |

Mean diff +0.28, median diff +0.57, t=0.61 (n=3) -> within noise. Candidate
and baseline are byte-identical computations for all non-layer-2 layers and
differ only in layer-2 routing; neutral AR means the grouped Q5_K WMMA body is
not faster than the strict selected chain for layer 2 at p512.

Also corrects the p512 production baseline: ~80 tok/s (not the 87.4 outlier in
20260830T212030, which was a hot/quiet-state sample).

## Next

- The layer-2 Q5_K gate/up gap (~19.61x vs llama, 301.5 ms in the frozen
  profile) is NOT a routing problem: both strict and grouped bodies are
  similarly slow. The real win requires optimizing the Q5_K gate/up kernel
  itself (P1/P2 kernel work), not enabling grouped routing. Keep layer 2 on
  strict (no change).
- Re-profile the Q5_K layer-2 kernel to confirm the 301.5 ms is still present
  before investing in a kernel rewrite.
