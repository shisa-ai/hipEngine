# Qualify SPECDEC2 prefix COW and eager fallback

## Summary

Qualify completed-snapshot prefix restore/COW under an explicit speculative API
request. Prefix state/KV reuse remains exact against the independent private full-
prefill oracle. Because prefix admission does not provide every historical target
hidden row required for dense NextN catch-up, SPECDEC2 fails closed to K0 before
provider mutation; it does not silently replay the prefix or corrupt provider
state.

Also expose the actual physical execution route in per-request telemetry and bind
C2/C4 gates to the qualified eager fallback while graph buckets remain uncached.

## Changes

- Add `scripts/specdec2_s4_prefix_gate.py`, which consumes the existing exact
  COW oracle, runs completed-snapshot reuse through `submit_speculative_child`,
  compares source/continuation first tokens, and requires zero MTP/provider
  mutation counters.
- Add route telemetry and require C2/C4 target batches to report eager execution
  when `speculative_graph_available()` is false.
- Add focused prefix row-selection and uncached-graph/eager tests.
