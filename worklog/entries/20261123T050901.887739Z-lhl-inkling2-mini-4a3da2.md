# Share counted Q8 gate weights across Inkling rows

## Summary

The fast Inkling GGUF route can reuse a packed gate/up matrix across two to four simultaneously stepping requests. It uses the same Q8 packing and per-route arithmetic as the single-row path. Activation, down projection, ordered mix and convolution remain independent per request.

## Changes

- Register the counted gate on both HIP backends. Supported NVFP4 banks and eight-route vectors use one gate projection with a packed activation per request. The chain reuses the grouped transfer and separate result slices; it leaves single-row, other shapes, and strict execution on their existing paths.
