# Calibrate exact BF16 sidecar export arithmetic

## Summary

Correct threshold calibration to use the exact BF16 sidecar representation that
runtime loads. The first real run calibrated FP32 training parameters at
`-0.0634965`, while torch-free replay of the rounded BF16 artifact selected
`-0.0638902` for the same CR4 train budget and reached 2.077x rather than the
expected approximately 1.995x total compression.

## Changes

- Materialize a sidecar-only export model by BF16-rounding learned weights and
  biases, then converting those exact values back to FP32 for deterministic
  threshold selection and final validation.
- Export tensors from that same representation and label calibration provenance
  `bfloat16_export`.
- Training/optimizer state remains FP32 and sidecar-only; no base-model state is
  introduced.

## Validation

- Deterministic fixture still reaches its exact train eviction count, exports
  byte-identically across same-seed runs, and passes strict schema-v2 loading.
- Added an explicit representation assertion.
