# Muse Glimmer DFlash drafter long-context fix + short-vs-long DFlash phase sweep

## Summary

DFlash failed outright above ~16K context: the drafter passed the whole
context to the strict Gemma 4 attention kernel, whose resident logits scale
with the key count (64 KiB LDS bound), although the draft attention is SWA
window-2048. It also made draft cost grow with context (17 ms at 512, 69 ms
at 8K). The draft now attends over the window slice only; draft cost is flat
(25-29 ms/cycle from 8K to 126K) and DFlash runs at every context to 126K
with exact greedy IDs == AR.

## Changes

- hipengine/runtime/muse_glimmer_dflash.py `draft_block`: K/V pointers, keep
  mask and row_offset start at `pos - window + 1`; keys = window slice.
- tests/test_live_muse_glimmer_dflash_gpu.py: long-context (~20K) draft vs a
  short-context draft over the same windowed keys (cosine >= 0.999, argmax
  equal per row). RED on the old code (NotImplementedError, 82388 B LDS at
  20069 keys); GREEN with the fix. Oracle test still green.

## Validation

- Phase sweep through the public generator/provider (scratchpad driver;
  coding-agent prompt = repo source + instruction, 256 tokens, ignore_eos,
  greedy, budget 4, r=1, Radeon 8060S/gfx1151, per-phase device syncs add a
  small overhead to DFlash):

  | ctx | AR tok/s | DFlash tok/s | x | tok/cyc | ms/cyc | verify | draft | inject |
  | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
  | 512 | 12.22 | 30.57 | 2.50 | 3.88 | 126.9 | 105.2 | 17.2 | 4.2 |
  | 8K | 11.53 | 20.81 (was 16.06) | 1.80 | 3.05 | 146.4 | 116.8 | 25.2 (was 69.0) | 4.1 |
  | 32K | 10.43 | 15.70 (was crash) | 1.51 | 2.67 | 169.9 | 140.4 | 25.4 | 3.7 |
  | 126K | 7.40 | 9.38 (was crash) | 1.27 | 2.84 | 303.2 | 270.1 | 28.9 | 4.0 |

  exact=True at every context. 512 row is pre-fix (window slice is a no-op
  below 2048 keys).
- Verify is the long-context DFlash cost: it grows 165 ms (512 -> 126K) vs
  53 ms for one AR step, ~3.1x, because each verify row runs the decode
  attention independently (no K/V sharing across rows).
- Drafter prefill inject (16-token chunks) adds 3.2 s at 8K, 12.9 s at 32K,
  52.9 s at 126K to TTFT (126K target prefill 560 s).
