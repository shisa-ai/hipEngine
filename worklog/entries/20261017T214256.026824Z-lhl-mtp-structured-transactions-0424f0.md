# Bind MTP grammar and processors to request transactions

## Summary

The Flash-Next MTP provider now applies request-owned grammar and tokenizer-aware
processors to each consumed target distribution. Resident cycles checkpoint and
restore grammar alongside sampler/RNG, target and draft state. Structured
completion retains its final token without disguising the MTP sampler mode.

This unit implements lower-layer controls, not public HTTP qualification. PS6 /
task 19 remains open. Public `supported_sampling_fields` is unchanged, so HTTP
still guards these controls pending its route/collector integration tests.

## Changes

- Add `GrammarSession.clone()` using llguidance's native `deep_copy()` matcher.
  Preserve `done` and EOS policy without sharing mutable parser state or replaying
  tokens. Direct MTP creates a session per request; resident MTP uses its row's
  existing session and restores a checkpoint on cancelled/failed bounded work.
- Pass the grammar to the existing AR target-selection and finish helpers for
  root, serial/batched verification and K0. Only consumed rows advance grammar,
  sampler/constraint state and RNG. Add thinking-budget metadata to MTP finish
  details using the same helper as AR.
- Allow implemented forced/post-thinking/sequence-completion, JSON-object,
  tool-call and thinking controls in the lower provider. Resident session reuse
  is still rejected before model work. No new experiment flag or GPU arithmetic.
- Scope direct and submit/poll grammar admission to the attached provider's
  `supports_grammar` contract, forwarded as `supports_speculative_grammar` by
  the generator. General AR grammar support alone does not permit MTP grammar.
  Do not advertise the provider flag through public HTTP capabilities yet.
- Determine visible grammar-stop tokens from row grammar completion and explicit
  stop sequence, not sampler-mode strings. EOS and explicit stop filtering remain
  separate. Migrate obsolete rejection tests to unsupported session reuse and
  give the uninitialized fail-closed submission fixture an explicit inner model.
