# Expose exact-role kernels in Qwen4Exp profiles

## Summary

Extended the durable role analyzer with the kernel/API detail needed to explain
an isolated layer rather than treating its whole MoE marker as one opaque
number. The new output can separate layer-2 routing, Q5_K gate/up, activation,
Q8_0 down, and copies using the same ROCTX-to-HIP-correlation chain as the
existing role totals.

## Changes

- Added `exact_role_kernels` to `scripts/qwen4exp_role_analyze.py` as flat rows
  of exact role, kernel symbol, originating HIP API, total milliseconds, and row
  count.
- Added a synthetic trace test covering marker containment, HIP correlation,
  kernel association, ordering, and timing conversion.
- Documented the additional breakdown in the performance campaign profiling
  procedure.

  report lacked `exact_role_kernels`.
