# Re-record the bulk workspace contract and correct its argmax claim

## Summary

Reviewing the retained evidence behind the shipped TP2 bulk prefill found a claim
that the artifact does not support. The 2026-09-25 workspace contract records
`all_checks_passed: false` with `finite: false` and `last_row_argmax: null` at
52 tokens in the prompt-sized variant, has no `oracle_scope` key, and came from a
harness revision that measured an extra repetition when asked for one and did
not check refusal state. The benchmark paragraph that cited it stated that every
length produced finite logits with the correct argmax.

## What was measured

A fresh ladder run at revision `20f84c447` on `epyc` (W7900 device 0 + RX 7900
XTX device 1, Qwen3.8-27B `Q4_K_M`, three repetitions, 52/511/512/513/600/768/
1024 tokens plus a 52-token revisit, three workspace policies) passes every
check, including the ones the earlier harness lacked:

| length | prompt-sized | pinned-512 | pinned-capacity (1027 rows) |
| ---: | ---: | ---: | ---: |
| 52 | 307.7 tok/s (0.169 s) | 153.9 | 101.3 |
| 511 | 963.6 | 962.4 | 724.4 |
| 512 | 1028.1 | 1037.5 | 772.8 |
| 513 | 915.1 | refused | 702.3 |
| 600 | 976.5 | refused | 787.2 |
| 768 | 1051.2 | refused | 945.9 |
| 1024 | 1100.1 | refused | 1090.3 |
| 52 revisit | 0.517 s | 0.336 s | 0.519 s |

`all_checks_passed: true`, `source_dirty: false`, `repeats: 3`. The artifact
states `oracle_scope: finiteness and completion counts only; no
numerical/KL/top-1/argmax oracle`, so it is a memory and state contract: the
recorded argmax (9707 at every length) is not compared against a reference, and
numerical evidence for the route remains the teacher-forced gate.

## Changes

- Re-record the contract as
  `benchmarks/results/2026-09-26-w7900-tp2-bulk-workspace-contract.json`.
- Rewrite the benchmark paragraph to describe what the artifact checks, drop
  the argmax claim, name the superseded artifact and its failing checks, and
  quote the retained ladder's rates.
- Add the dated changelog entry, including the engine fix the run needed.

## Validation

- `uv run python scripts/sync_benchmark_readme.py --check` passes.
- The earlier `finite: false` reading does not reproduce: explicit logits
  instrumentation reports zero non-finite elements in 248,320 at every length
  (`/tmp/probe-logits2.json`), so it is recorded as a harness artifact rather
  than a property of the route.
