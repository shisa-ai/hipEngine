# Add Qwen4Exp context decode profiler

## Summary

Added a durable P6 profiler for identical compact-output decode transitions at
live counts 2,051, 2,052, and 4,097. It uses canonical token IDs,
snapshot/restore between repeats, resident device-token input, exact output and
state checks, marker-scoped roles/API/copies, and lifecycle closure.

## Changes

- Added `scripts/qwen4exp_context_decode_profile.py`.
- Added RED/GREEN tests for fixture/live-count mapping, repeat admission, and
  binding defaults.
- Added one unmeasured transition per context so lazy MoE graph capture cannot
  contaminate marker windows.
- Fail closed unless both the runtime tree and profiler script are tracked.

## Validation

- RED: all three tests failed while the profiler was absent.
- GREEN: 3/3 focused tests pass.
- Dirty-tree GPU preflight at live count 2,051 proves snapshot/restore and
  repeated state/output exactness. Before the warmup fix, repeat 1 exposed 48
  graph captures, 96 hidden readbacks/syncs, and 386.96 ms versus steady
  66.36/67.42 ms. This correctly identified and removed profiler contamination;
  the preflight is diagnostic only and is not retained as performance evidence.
