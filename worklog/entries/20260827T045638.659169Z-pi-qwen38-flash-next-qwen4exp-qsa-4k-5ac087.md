# Qualify real Qwen4Exp QSA at 4K

## Summary

Qualified strict serial and size-2 chunked Qwen4Exp native sparse QSA at a real
4,096-token context against the frozen llama.cpp BF16-KV oracle.

## Changes

- Retained compact evidence at
  `benchmarks/results/2026-08-27-gfx1151-qwen38-flash-next-qsa-4k.json`.
- Advanced campaign/kernel/benchmark rollups from first-transition-only to a
  structural 4K checkpoint without claiming natural retrieval or broad 4K
  product support.

## Validation

- Exact workload: `' a'` repeated 4,096 times, token ID 264 repeated 4,096,
  context and llama batch 4,096, size-2 hipEngine chunks, pinned four-part
  Unsloth UD-Q4_K_XL on physical `zbook` gfx1151. Exact command is retained in
  the artifact.
- Teacher/serial/chunk top-1 are all 264. Teacher→serial KL is 0.00004398,
  teacher→chunk KL 0.00004780, and serial→chunk KL 0.00003193.
- Serial prefill measured 854.982 s and chunked prefill 574.759 s (1.488×,
  32.78% lower wall). This repeated-token checkpoint is diagnostic only.
- Tracked peak was 82,780,790,728 bytes; close returned current bytes and active
  allocations to zero.
