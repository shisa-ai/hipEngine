# Localize the re-entry defect to the residual stack depth

## Summary

The defect is now localized to the residual stack the block carries into the loop re-entry. At that visit the host holds two stack rows and the block restores one, which makes the MLP residual read 8.765 wrong, the MLP input 1.297 wrong, the gate logits 0.94 wrong, and flips the expert routes on 53 of 64 rows. Every downstream number the previous windows measured follows from this single difference.

## Changes

- Added env-gated dumps of the block's MLP residual read, its branch row, its blended MLP input, its gate logits and its restored stack.

## Validation

64 rows, fast profile, `hip_gfx1100`, host and block values captured in one process.

- The branch matches to 7.6e-06, which retires the 3.379 branch reading from the earlier windows and agrees with the substitution bisect in which replacing it changed nothing.
- The chain is monotone: a stack one row short corrupts the read, the read corrupts the blend, the blend corrupts the logits, and a 0.94 logit error flips a top-8 boundary whose minimum gap is 2e-04.
- Three block runs in one process are bit-identical on the blended input and the final rows, so the difference is structural and not contamination.
- Widening the snapshot and the restore from `saved` to `saved + 1` rows left the end-to-end error at exactly 6.065, so the row accounting is not a single off-by-one in those two copies.
