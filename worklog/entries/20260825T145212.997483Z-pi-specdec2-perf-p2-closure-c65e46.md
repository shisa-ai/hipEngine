# Close SPECDEC2-PERF P2 streaming activation

## Summary

Close SPECDEC2-PERF P2 with a scoped retain/reject/K0 verdict. Fresh strict C1
requests now stream target pre-output-norm BF16 chunks directly into NextN,
retain exactly one 10,240-byte carried row, and never construct the prompt-sized
host FP32 hidden slab or post-prefill replay. Provider prompt rows, carried rows,
and request slots are covered by one exact work-item claim before mutation.

The full canonical C1/K2 result is retained: staged throughput improves
**14.294→16.237 tok/s (+13.59%)**, reaches **1.486x true AR**, and every category
improves **10.50%-18.21%**. Staged reaches 94.27% of the current direct exact
control. p128/p512 complete staged activation beats direct control by
**50.4%/17.4%** and carries the same 10 KiB independent of prompt length.

Physical C2/C4 streaming is rejected. It improves aggregate throughput
**+4.01%/+6.24%**, but `general_en` regresses **-11.86%/-10.16%** and physical
acceptance falls **18.43%→16.03%**. Capacity>1 therefore keeps candidate intent
and uses the exact host-replay fallback. Packed/ragged streaming remains an
internal tested capability only.

Exact p4K/p16K eager streaming is also rejected at **1.202x/1.231x direct
wall**. These contexts now select `target_context_k0` before provider acquisition,
sink allocation, or NextN mutation. Automatic/product policy remains K0.
