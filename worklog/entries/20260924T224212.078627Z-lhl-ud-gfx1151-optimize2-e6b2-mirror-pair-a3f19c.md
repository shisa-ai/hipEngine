# UD gfx1151 optimize2 E6b-2: (Q4_K gate, IQ4_XS up) mirror pair lands — bit-exact, 1.03×, −11.63 launches/tok conserved

## Summary

Iteration 13 landed E6 step 2b: the mirror family — ordered (Q4_K gate,
IQ4_XS up), **6 layers** (combo 12/23) — now runs its own fused pair +
SiLU owner. With E6b-1's 7 layers, the two families cover 13 of the 28
mixed gate/up layers.

**The one lever (one family, one structural delta):** the same
`gguf_iq4_q4_pair.hip` body gained a `GATE_IS_Q4` template flag.
Pointer roles never swap — side A keeps the local32 split-K decode
geometry (IQ4 raw bytes), side B keeps the dense Q4T16 single-wave
chain (tiles) — only the epilogue changes which bf16-rounded
accumulator feeds the SiLU gate and which feeds the multiply. A second
extern-C symbol (`hipengine_gguf_q4_iq4_pair_silu`), a second
registered key (`gguf_q4_k_t16_v1+gguf_iq4_xs` /
`q4_iq4_pair_silu_bf16_bf16_out`), a gate-first wrapper (which reorders
to the C geometry ABI: IQ4 pointer passed first internally), and a
second ordered route block (side A = Q4_K dense decode owner, side B =
session-qualified local32 owner, rows==1, in%256, out%16).
