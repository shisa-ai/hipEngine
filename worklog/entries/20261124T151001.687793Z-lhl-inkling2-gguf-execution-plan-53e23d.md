# Campaign step 2 units: router contract, pairs driver, observation-point test

## Summary

Three committed units toward the GGUF execution plan without touching the
in-flight campaign-doc edits (a sibling session owns those; nothing here edits
`docs/campaigns/`).

1. `tests/test_unit_inkling2_router_contract.py` — CPU contract tests for
   `select_expert_routes`: sigmoid ranking with ranking-only bias, lowest-id
   tie-breaking, ascending id output, unbiased mix normalized to `route_scale`,
   saturated logits, determinism, batched rows, 200-case fuzz vs an
   independent reference. These pin the exact semantics any device-side router
   must reproduce.
2. `tests/test_unit_inkling2_reference.py::test_capture_points_are_not_visit_exit_states`
   — the plan's step-1 RED test. Pins that `capture(k, h)` observes visit k's
   *entry* state (after a prelude restore at restart visits; the terminal
   capture is the depth-mixed output, not the raw final residual). This is the
   contract whose violation produced the reported 255.8 "divergence", which was
   traced to comparing `trace[18]` (post-restart entry) against post-visit-17
   residuals from a `limit=18` run. Full matched-boundary comparison across
   host/device/numpy-oracle paths shows <= 1.6e-4 abs everywhere (see
   20261124T143027.342689Z-lhl-inkling2-mini-5d86dc.md).
3. `scripts/inkling2_ordinary_pairs.py` + `tests/test_unit_inkling2_ordinary_pairs.py`
   — step 0 deliverable: in-tree replacement for the off-tree ordinary-pairs
   HTTP driver used for the November Strix Halo comparison. Alternating engine
   order per repetition, warmup excluded from medians, first non-empty
   content/reasoning delta timed to stream close, per-prompt medians grouped
   by engine, per-request failure isolation, JSON report. CPU tests cover the
   SSE parser, delta classification, aggregation, order alternation and the
   timed request path with an injected clock; no sockets in tests.
4. `tests/test_gpu_inkling2_router_gpu.py` — the device half of the router
   question. The gfx1100 `laguna_sigmoid_correction_topk` kernel (already in
   tree for Laguna) reproduces the Inkling 2 host contract at production shape
   (128 experts, top-8, scale 8) on W7900: exact expert-id sets on random,
   exactly-tied and saturated-logit inputs, mix within fp32 noise, zero-bias
   equivalence with the `bias=None` host path. Ids come back in selection
   order (not ascending), so consumers must re-sort if they need the host
   order. Not wired into the resident GGUF path yet: tile construction
   (`build_expert_route_tiles`) still consumes host ids, so the pipeline still
   round-trips logits to the host per visit; this test is the gate for the
   device-selection wiring once that path is built.
