# Enable Gemma assistant MTP on gfx1100 with paired admission

## Summary

Gemma's model-attached assistant provider now resolves for gfx1100 as well as
gfx1151. The provider validates target/assistant compatibility and the runtime's
head geometry before materializing either device owner. This is a public-route
repair, not a performance or model-quality promotion.

## Changes

- Register both implemented HIP backends under the quantization-independent
  provider key. Do not enumerate target artifacts or quantizations.
- Reuse paired GGUF admission and the assistant runtime's geometry validation
  before loading target or assistant weights. Keep injected drafters unchanged.
- Add CPU tests for resolution, rejection-before-allocation, geometry preflight,
  successful cold construction, and cached reuse.
- Add a real public plain/MTP/plain sequence with exact output IDs and explicit
  `gemma4_mtp_batched_exact_verify` telemetry. Import runtime wrappers before
  pytest's collection snapshot so teardown does not erase lazy registrations.
