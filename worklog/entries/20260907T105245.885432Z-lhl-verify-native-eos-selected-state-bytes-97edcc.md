# Verify native EOS selected-state bytes

## Summary

Add independent selected-state verification to the real native EOS diagnostic.
GPU0 N8/N2 pass all ten prompts each; no runtime changes in this unit.

## Changes

- Independent `eos_selected_prefix` walks matching candidate edges until EOS,
  rejection or output room ends. It never calls production EOS limiting.
- `EosStateProbe` snapshots canonical state before packed verification and
  checks unchanged bytes afterwards. Before real selected commit, compare GPU
  accepted count/position to the oracle; hash selected Conv/GDN/hidden sources,
  page-aware KV and auxiliary state, then validate destination bytes.
- Lifecycle `--eos-state` requires `--eos-survivor`, actual native C1 device
  results, checked commits for EOS-bearing C1 cycles, and at least one checked
  terminal EOS cycle per prompt. Logical rows exclude inactive padding.

## Validation

- Eight EOS oracle RED-then-GREEN tests cover every K1–K7 candidate/rejection
  position, horizon, and unreachable suffix. All 45 focused EOS/lifecycle
  tests and `git diff --check` pass.
- `bg-104` runs host epyc W7900 GPU0 N8 then N2:
  `HIP_VISIBLE_DEVICES=0 ROCR_VISIBLE_DEVICES=0 GPU_MAX_HW_QUEUES=1
  HIPENGINE_HIP_ARCH=gfx1100 .venv/bin/python scripts/qwen38_packed_c1_lifecycle.py
  --engine-boundary --eos-survivor --eos-state --capacity N
  --output /tmp/packed-c1-eos-state-nN.json` (same `.log` stem).

- Seven additional probe tests reject precommit state changes, wrong device
  acceptance/position, selected-state byte drift, auxiliary drift and KV drift.
  Wrong metadata fails before the underlying commit; failed byte checks never
  publish passed=true. All 15 EOS-state tests pass (0.44s). No running script
  changes during the GPU run.
