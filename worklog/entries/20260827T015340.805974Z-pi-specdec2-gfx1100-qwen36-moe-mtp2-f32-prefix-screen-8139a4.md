# Add MTP residual-prefix quality screen

## Summary

Added a bounded F32-residual prefix screen for the K2-only 35B MTP production
candidate. The exact K2-only control/task packet passes globally but misses the
`general_ja` mean KL by `0.0000537`; layer capture localizes the dominant
amplification at full-attention layer 27. The screen tests a fixed layer prefix
for all requests, never prompt/token IDs.

## Changes

- Added `HIPENGINE_GGUF_VERIFY_F32_RESIDUAL_LAYER_LIMIT=N`: F32 residual applies
  to layers `[0,N)`, then rejoins the existing BF16 verifier. Default remains
  all layers and the limit is inert unless F32 residual is explicitly enabled.
- Added bounds/default tests and a `docs/REFACTOR.md` removal condition.

## Validation

- K2-only live control smoke completes exactly with a bounded direct-AR tail.
- K2-only full quality screen: 252 rows, mean/p95/p99/max KL
  `0.000446/0.002262/0.006291/0.023325`, 100% top-1; only
  `general_ja` mean fails at `0.001054` while p95/p99/max/top-1 pass.
- Candidate-only full F32 residual+post-norm passes every numerical scope at
  aggregate mean/p95/p99/max
  `0.000469/0.001846/0.009330/0.018213`, top-1 `99.603%`, but its one-run
  performance is only `1.0133x` aggregate and `0.8477x general_ja`; rejected.
- One-row generic-flag screen rejects F32 MoE combine, shows all narrow flags
  no-op/unsupported, and confirms residual as the active mechanism.
- Layer capture shows row-1 mean hidden delta grows from `0.000565` at layer 26
  to `0.003166` at full-attention layer 27.
- Prefix screen on that row: limits 4/20/27 reduce KL `0.023325` to
  `0.002825/0.000390/0.002529`; limit 4 is the lowest-cost candidate.
