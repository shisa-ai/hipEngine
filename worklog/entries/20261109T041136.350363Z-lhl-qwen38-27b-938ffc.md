# DSpine prefix verify fixed: draft full block, verify prefix; 10.81 tok/s (0.95x AR)

## Summary

Task #22 (reviewer §6.3-3, P0). Fixed the invalid DSpine budget sweep: the old
run_dspine_cycle truncated the drafter INPUT block (noise=[bonus]+[mask]*n_drafts)
while the native forward still processed block_size=16 rows and positions stayed
sized for 16 -> garbage rows -> acceptance 0.0 at budgets 3/4. Now the drafter
always drafts the full trained 16-row block; candidate_budget truncates only the
VERIFY prefix (verify [bonus]+drafts[:n_verify]). This is the vendor's dynamic
verification lever and stays near the cheap verify bucket.

- hipengine/speculative/dspine_cycle.py: n_drafts=block_size-1 always; n_verify
