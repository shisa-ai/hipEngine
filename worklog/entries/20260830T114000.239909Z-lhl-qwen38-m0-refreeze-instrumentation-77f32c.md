- Reproducibility: AR/MTP/prefill re-run reproduces the frozen matrix within
  noise (prefill C1 146.83 vs 146.76; AR C8 46.34 vs 45.94; MTP C5 18.74 vs
  18.66; MTP C8 29.04 vs 28.58). 80/80 exact, engaged, budget-conformed;
  acceptance identical 78.894% at every width.
- Partition signature is exactly **2.00 physical target passes per cycle at
  C5-C8** vs 1.00 at C1-C4, with reconstructed pass shapes (124xR16 + 10xR8 +
  8xR12 at C8; tail-shrink passes visible).
- C8 economics: target kernel 2.63 ms/row (40.0 ms/R16 pass) while
  operation-complete costs 34.44 ms/committed-token vs matched AR 21.58 ms/row
  -> the complete-cycle wall is NOT the target kernel: per-cycle member sums
  show the accept interval (107.9 s member sum vs 5.7 s target member sum) and
  proposal interval dominating. A1's per-row cost gap lives in the
  operation-complete cycle (queued-target sync, accept, replay-adjacent
  ownership), not raw target math.
- C1 production-D24 baseline for M3: 7.841 tok/s (127.5 ms/token),
  streaming engaged on 0 requests (policy-table miss confirmed live), direct/
  scalar proposal head, same 78.894% acceptance.
