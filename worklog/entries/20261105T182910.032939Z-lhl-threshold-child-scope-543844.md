# Transport threshold comparisons through scoped child arguments

## Summary

Threshold subprocesses now carry bulk/residual/Q8 diagnostic choices as explicit
child arguments. The wrapper enters a restoring scope around the existing
resident sweep rather than writing these controls into its environment.

## Changes

- Remove inherited legacy diagnostic environment values from child launches.
- Record effective diagnostic fields in each execution result.
- Preserve the existing sweep CLI and benchmark behavior through a thin wrapper.
- This is a staged R0214/R0215/R0378 migration; production readers still exist.

- Threshold environment/child and diagnostic tests pass (20 tests).
- Child success and exception tests assert argument and diagnostic restoration.
- Driver tests inspect actual subprocess arguments and sanitized environment.
- No numerical or performance claim; no GPU kernel changes.
- RED-first was not run for the wrapper; acceptance tests exercise the new
  transport and restoration boundary directly.
