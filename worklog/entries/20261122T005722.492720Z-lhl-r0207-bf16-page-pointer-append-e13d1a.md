# Add page-pointer BF16 KV append primitive

## Summary

Add a registered BF16 append primitive that writes through device page-pointer tables rather than one chunk base. This is an R0207 building block, not a serving migration.

## Changes

- Reuse the existing FP32-to-BF16 conversion and `KVLiveSpans` inputs. Resolve the logical block to a global page ID, then to the key and value plane addresses for that page. The contiguous writer remains unchanged in behavior.

## Validation

- The independently allocated page test failed before registration. It passes on the W7900 at the boundary between two permuted pages and verifies exact BF16 bytes and untouched sentinels throughout both planes.
- `tests/test_gpu_qwen35_paged_kv_head_major.py`: all 15 checks passed on gfx1100. The audit reported the same pre-existing stub, ungoverned flag, and worklog findings.
