# Separate resident state and transaction storage ownership

## Summary

Second unit of the approved runtime cleanup, following prefill planning in `198fba3f8`. Separate canonical state, provisional verifier storage, prefix snapshots and rollback ownership without adding a second speculative journal or implicit-session mixins.

## Changes

- Fixed failure-path defects in verifier block growth, linear-state row growth and packed attention workspace growth: old owners are preserved until a replacement is complete, and partial allocations roll back.
- Resident slot views no longer inherit the root's prefix snapshot arena pool. Their state owners distinguish borrowed canonical scratch from slot-local verifier and rollback buffers.
- RED tests preceded the main implementation. Numerical execution is unchanged; prefix and transaction cursor publication follows successful prerequisite state operations.
