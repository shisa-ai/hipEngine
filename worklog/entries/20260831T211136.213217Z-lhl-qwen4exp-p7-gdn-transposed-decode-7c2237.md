# Add transposed Qwen4Exp GDN decode primitive

## Summary

Added a default-unselected T1 GDN decode primitive over persistent `[head,V,K]`
state. One wave owns each output value, reduces K lanes, updates contiguous
state, and publishes the core before the existing strict sigmoid-gated norm.

## Changes

- Added in-place square-state transpose and wave-per-value recurrence wrappers.
- Registered explicit transposed-state candidate and conversion keys.
- Added actual production-shape strict-envelope test; existing exact conversion
  roundtrip remains the construction/rollback oracle.
- No runner/default changed yet.

## Validation

Actual 16K/48V/128x128 candidate output passes the declared T1 strict envelope;
strict↔transposed conversion remains bit-exact. Focused tests pass. The first
candidate mismatch exposed the strict query-side `1/sqrt(K)` factor omitted by
the reusable prepare primitive; adding that explicit factor restores parity.
