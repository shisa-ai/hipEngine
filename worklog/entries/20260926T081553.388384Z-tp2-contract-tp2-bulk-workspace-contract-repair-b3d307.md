# Repair TP2 bulk workspace contract repeats=1 and refusal evidence

## Summary

Follow-up to `a2fe7d6f7`. Source review found a concrete mismatch the pure
record tests missed: `run_variant` used `range(max(1, repeats - 1))`, so
`--repeats 1` executed one extra measured call while `evaluate_variant_checks`
expected zero. Refusal evidence was also thin: it recorded only the post-attempt
state. This repair makes the run and the verdict agree on total-measured-call
semantics, requires refusals to leave the workspace allocation and session
health unchanged, and makes `exact_command` shell-safe and argv-aware.

## Changes

- `scripts/tp2_bulk_workspace_contract.py`
  - `--repeats` is now documented and implemented as the total measured calls
    per length (first call + `repeats - 1` steady-state repeats). The loop is
    `range(max(0, repeats - 1))`, matching `evaluate_variant_checks`; the
    retained artifact's `repeats=3` -> 2 steady samples is unchanged.
  - Refusal entries now capture `workspace_rows_before`,
    `workspace_allocation_before`, `session_poisoned_before`, and the
    corresponding `_after` fields. `evaluate_variant_checks` adds
    `refusals_preserve_workspace_rows`,
    `refusals_preserve_workspace_allocation`, and
    `refusals_leave_session_healthy`, all fail-closed on missing evidence. The
    later revisit still exercises post-refusal usability.
  - `exact_command` now uses `shlex.join([sys.executable, script, *argv])` via
    `_exact_command(argv)`, honoring an explicit `main(argv)` instead of
    `sys.argv`.
- `tests/test_unit_scripts_tp2_bulk_workspace_contract.py`
  - Fake-session integration tests drive `run_variant` end to end:
    `test_run_variant_repeats_one_measures_only_the_first_call` pins exactly
    three `bulk_prefill` calls (warmup + first + revisit) and empty
    `repeat_outputs`/`steady_samples_s`; and
    `test_run_variant_refusal_preserves_allocation_and_health` pins unchanged
    rows/pointers and a non-poisoned session through an over-pinned refusal.
  - Synthetic tests cover refusal rows/allocation/health failures and missing
    state evidence, plus `_exact_command` argv handling.
