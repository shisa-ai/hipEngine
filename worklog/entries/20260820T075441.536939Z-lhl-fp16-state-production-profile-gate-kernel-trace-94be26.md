# fp16-state production-profile gate + kernel trace

## Summary

Ran the full calibrated strict-teacher production-profile numerical gate and
captured rocprofv3 kernel-trace evidence for the fp16 recurrent-state route
(`HIPENGINE_GGUF_FP16_RECURRENT_STATE`) on gfx1151 Qwen3.8-27B Q4_K_S. The gate
PASSED with a large margin: global KL mean 5.28e-5 / p95 2.80e-4 / p99 5.81e-4 /
max 1.43e-3 (envelope 1e-3/5e-3/2e-2/5e-2) and top-1 agreement 99.78% (>= 99%),
with every category at or above 99% (>= 97%). Three candidate repeats are
bit-stable, the state is finite/layout-stable/byte-repeatable, and the
rocprofv3 trace names the fp16-state (`_Float16`) production instantiations
with plausible durations. The fp16 recurrent-state route is production-qualified
on gfx1151.

## Validation

- **Numerical gate (450 teacher-forced rows, 18 prompts, 24 decode steps, 3
  bit-stable repeats):** global kl_mean/p95/p99/max =
  5.28e-5 / 2.80e-4 / 5.81e-4 / 1.43e-3, top-1 449/450 = 99.78%. Per category:
  code 100%, general_en 100%, general_ja 99%, mixed_ja_en 100%. Per
  shape/transition: prefill_last and prefill_to_c1 exact (KL 0), c1/steady KL
  tiny. `hard_gates_passed`, `eligible_for_automatic_admission`, `finite` all
  true; no outlier review required. The single top-1 mismatch
  (heldout_general_ja_migration) has KL 1.9e-4 with top-k overlap 1.0 and
  strict-top1 rank 2 (near-tie).
- **Repeat determinism:** three candidate runs bit-identical per prompt
  (trajectory sha256 identical); state repeat gate passed (finite,
  layout-stable, byte-repeatable).
- **Kernel trace (`rocprofv3 --kernel-trace`, cached build, 2,899
  dispatches):** `qwen35_gdn_prefill_recurrent_compact_normalized_wave32_xor_kernel<_Float16>`
  48 dispatches (48 GDN layers), median 85.6 us, grid (6144,32,1); and
  `qwen35_gdn_recurrent_rmsnorm_gate_lowp_kernel<unsigned short, true, _Float16>`
  (fused BF16-cast decode gate) 96 dispatches (48 layers x 2 decode steps),
  median 17.2 us, grid (6144,1,1). Both carry the `_Float16` state_t template
  parameter (fp16 storage, fp32 accumulate).
- **BF16-relative non-inferiority:** not directly runnable -- no BF16 Qwen3.8
  teacher exists on this host. The fp16-state change is implementation drift on
  the already-retained Q4_K_S route (state storage dtype only), and this gate
  directly measures the additional quality budget consumed vs the fp32-state
  production route (the binding requirement); the R2 host-side emulation
  (2026-08-18) already bounded fp16-state drift at 0.05x the accepted BF16
  output rounding.
- `measurement_valid` = tracked-clean tree (code at commit f87b98c3c), full
  suite, repeat determinism, state gate; unrelated untracked benchmark
  artifacts (257) are recorded as a `worktree_note` caveat.
