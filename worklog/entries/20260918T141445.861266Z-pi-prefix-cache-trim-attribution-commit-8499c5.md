# prefix-cache trim fix, per-reason attribution, opt-in wide retention

## Summary

Ships the multi-turn prefix-cache mechanism fix and the serving attribution
behavior-neutral. The trim bug: `_capture_prefix_snapshot` trimmed all snapshots
by one count budget (`_prefix_snapshot_limit = max(1, capacity)`), and one
request captures twice (decode boundary + completion prompt boundary), so the
second capture evicted the retained entry that had just served it — every lane
hit at most once. Transient and retained snapshots now trim under separate
budgets, and a request's own capture can never evict a retained boundary. The
wider retained working set is NOT the shipped default: budget-16 measured a
served regression (+11% cumulative-medium_repo, +308% fixture-medium_repo,
artifact `benchmarks/results/2026-09-18-gfx1151-qwen36-gguf-prefix-cache-multiturn-ab.json`),
so the retained count defaults to the pre-fix effective value
`max(1, capacity)` and widens only via the opt-in
`HIPENGINE_GGUF_PREFIX_RETAINED_SNAPSHOTS` /
`HIPENGINE_GGUF_PREFIX_RETAINED_STATE_BYTES` (default 1 GiB). The opt-in exists
to re-measure the wide set once the two recorded blockers land (batched suffix
prefill; paged >=1024 shared admission).

Also ships: per-reason fallback counters (`fallback_reasons`,
`retained_snapshot_evictions_by_reason`, `snapshot_promotions`), the missing
`suffix_prefill` phase counter on the processed-argmax reused route, and the
harness surfacing the engine's exact per-turn `engine_fallback_reasons` instead
of a derived guess.

## Changes

- `hipengine/generation/qwen35_gguf.py`: `_trim_prefix_snapshots` splits
  transient vs retained budgets; `_evict_prefix_snapshot` takes a reason and
  retained evictions are counted per reason; `_note_prefix_fallback` /
  `_note_prefix_admission_fallback` count every fallback by reason;
  `_promote_prefix_snapshots` trims after promoting; observability payload gains
  `fallback_reasons`, retained limit/bytes/promotions fields. New env knobs
  `_gguf_prefix_retained_snapshot_limit(capacity)` (default `max(1, capacity)`)
  and `_gguf_prefix_retained_state_bytes_limit()` (default 1 GiB).
- `scripts/prefix_cache_multiturn_bench.py`: per-turn payload carries the
  engine's `fallback_reasons` and picks the dominant engine reason over the
  derived one.
- `tests/test_unit_gguf_prefix_cache_runner.py`: three mechanism RED tests from
  the fix session (retained survives a later capture, two conversations coexist
  under the opt-in wide set, chain deepens across three turns), per-reason
  counter test, phase-counter test, plus a new test pinning the behavior-neutral
  default (`test_retained_budget_defaults_to_the_pre_fix_effective_value`) and
  the opt-in arm (`monkeypatch.setenv` on the two-conversations test).
- `docs/REFACTOR.md`: records the shipped default/opt-in semantics and the
  promotion condition for the wide set (batched suffix prefill + paged >=1024
  shared admission).
