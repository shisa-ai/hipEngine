# Validate the evidence gate's contents and resolve the admission helper's policy row

## Summary

Both still-open review defects are fixed. The break-even's pre-Packet-3 gate was
satisfied by **any nonempty path list**: a dangling path or a JSON file proving
nothing certified the projection. The admission helper unioned shapes across all
model/quant policy rows and floored odd intermediate sizes.

## Changes

### Evidence gate (scripts/tp_break_even.py)

`_validate_shard_kernel_evidence` now reads each artifact and requires, per file:
under `benchmarks/results/`, parseable as `.json` or `.csv`, and at least one
kernel record with a **name** and a **positive duration** - the same shape
`rocprofv3 --kernel-trace` writes (CSV `Kernel_Name,DurationNs,Calls`) and the
same quantity the kernel gate requires. Each record is named individually in
`withheld_reasons`, so one bad artifact among good ones is attributable. The
results root is injectable (`results_root=`) so tests exercise real file I/O in a
temporary tree instead of fabricating fixtures in the live artifacts directory.

Recalibrated the four tests that passed the fabricated path
`benchmarks/results/shard-kernel-smoke.json` (a file that does not exist): they
now write a real minimal artifact. Eight new tests cover the dangling path, a
kernel-free JSON, a zero duration, an artifact outside `results/`, a genuine JSON
artifact, a genuine CSV trace plus a headerless one, and per-file attribution.

### Admission helper (scripts/tp2_mlp_shard_plan_probe.py)

`fused_path_admission` now resolves the policy row by the same identity
`_gguf_policy_identity` builds for the resident artifact -
`(GGUFModelGeometry, file_type_name)` - and reads the variant from that row only.
Shapes admitted by *other* rows are reported separately and never read as this
artifact's admission. An unknown quant now finds no row, reports no variant, and
does not emit the gap message, because "some other row admits this shape" is not
evidence about this artifact.

Partition validation: a non-integral split **raises** (there is no per-rank width
to report, so any number would be a fabrication - the old floor to 8704 described a
shape nobody launches); a tile-inadmissible split (integral but off the t16 column
contract) is recorded in `partition.error` because that shape does exist and its
layout work is what the execution test investigates. The probe call site passes
the real geometry, `file_type_name` and `world_size`.
