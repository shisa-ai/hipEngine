# Keep Inkling decoder dense weights in native BF16

## Summary

Keep the decoder's original BF16 dense matrices on device while using FP32 activations, accumulation, and output. The strict profile retains FP32 rocBLAS; F32 checkpoint matrices are not rounded.

## Changes

- Use the 64-thread native-BF16-weight kernel for single projections and same-input projection groups. Keep the vocabulary head's separate selection and leave the vision tower and DSpark drafter unchanged.

## Validation

- `epyc` / Radeon Pro W7900 (`gfx1100`), `thinkingmachines/Inkling-2-Mini` revision `ed40e7da625f594fc9c4990f5f66be24873c22d7`, `inkling2_mixed`, FP32 KV, one request, ordinary greedy decode, baseline `f25bf605e`.

In the corresponding `matched` diagnostic (synthetic 512-input / 128-output, one run each), decode improved from 8.3528 to 8.8194 tok/s (+5.59%) with all 128 output IDs unchanged. In the cached HIP trace, total dense projection time fell from 15.83 to 8.87 ms per output token, including the unchanged vocabulary head.
