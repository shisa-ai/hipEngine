# T16 Q5_1 down engine A/B: +9.46% prefill, 12/12 positive

## Summary

The down-leg T16 build's engine A/B (step 4 of the committed spec,
4d94cbbb5 / 5e90c9b9e / bfd5ec470 / 4de7b1221): the same-residency
canonical A/B for the env-gated T16 Q5_1 expert-major down route
(HIPENGINE_QWEN4_EXP_T16_DOWN=1, tile cache populated for all 43 Q5_1
layers).

**Result (one residency, 12 canonical cases, 3 repetitions, balanced
arm order):**

- **Aggregate prefill 343.35 -> 375.82 tok/s, +9.46%; 12/12 cases
  positive, per-case ratios 1.0896-1.1113 (median 1.1021).**
- Client wall 473.49s -> 456.04s (-3.68%).
- Decode unchanged (16.66 -> 16.68 tok/s, within noise - the decode
  path does not use the prefill down branch).
- Within-mode output deterministic in every case and arm; cross-arm
  digests differ on 9/12 cases as expected for an arithmetic-changing
  candidate (F16 WMMA with compensated accumulate), and 3/12 cases
  happen to match exactly.

**Admission state:** this is engine-level performance evidence only.
The candidate changes arithmetic, so promotion requires the full
layer2 production envelope (mean/p95/p99/max KL, top-1 by category,
state/determinism/lifecycle, task review) - and its top-1 scope
includes prefill_last, which is the X-7 decision domain (the F16
compact down sibling was rejected there at top-1 98.667%; the
compensated accumulate is the test of whether T16 clears it). The
complete promotion path parallels the T16 gate/up chain.
