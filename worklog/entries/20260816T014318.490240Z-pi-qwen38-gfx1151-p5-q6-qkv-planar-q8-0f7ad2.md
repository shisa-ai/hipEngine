# Reject gfx1151 planar-Q6 Q8 recurrent QKV

## Summary

Reject the changed-arithmetic planar-Q6 Q8_1/dp4a transfer for Qwen3.8's
standard-Q6 recurrent-QKV role. Full producer+dot improves a three-weight family
**0.615074 -> 0.608502 ms (1.01080x, 14/15 wins)** but projects only
**0.818 ms / 0.0633%** selected 4K graph wall. Even the lower bound that treats
Q8 quantization as free through perfect mixed Q6/Q4 activation reuse projects
only **1.632 ms / 0.1262%**, so no mixed package or model run is warranted.

## Changes

- No production change. Compared the retained exact standard-T16 BF16 QKV c1
  owner against the already-registered planar-qmicro Q8_1/dp4a owner at its
  selected 64-thread geometry.
- Used actual `blk.0`, `blk.28`, and `blk.62` recurrent-QKV weights. Standard and
  planar rotating pools are each **123.047 MiB**, with more than 64 MiB between
  repeats of each role.
- Timed the operation-complete producer+dot route and separately timed the dot
  with precomputed Q8 activations. The latter is a strict optimistic bound for
  any future mixed Q6-QKV/Q4-gate activation-sharing package.
- Preserved evidence at
  `benchmarks/results/2026-08-16-gfx1151-qwen38-27b-q6-qkv-planar-q8-rejected.json`.

## Validation

- Full candidate wins 14/15 counterbalanced family pairs at **1.01080x**;
  precomputed-Q8 dot reaches only **1.02177x**. Clearing 1% selected graph wall
  requires **1.20305x** from the 5.925%-share Q6-QKV family.
- All three outputs are finite, max KL is **9.95e-7**, top-1 agreement is 3/3,
  max absolute difference is **0.01171875**, and tracked ownership returns
  exactly 0 -> 0 bytes.
- Production source remains clean; all kernels/wrappers were existing cached
  gfx1151 routes. The result stops before runtime integration and natural/full-
  model validation under the declared economics gate.

## Next

- Keep standard-Q6 BF16 for recurrent QKV. Do not build mixed Q6/Q4 Q8 sharing:
  its free-quantizer upper bound is still 7.9x below admission. Rerank beyond
  Q6 QKV layout/activation work.
