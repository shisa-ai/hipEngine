# Preserve router controls until profile and diagnostic migration

## Summary

Move router control retirement to bottom `R0281-ROUTER`, with the actual
profile/capture migration dependency. These flags are live implementation of
strict/production routing and counter ownership, not unused experiments.

## Changes

- Runtime predicates both default true. Cooperative c1 routing falls back to
  separate logits/select when disabled or unresolved; F32-hidden post-norm
  routing is independently unfused. Pin disabled and unresolved fallbacks.
- Persistent routing passes the scratch counter; nonpersistent routing selects
  a different registered variant whose host wrapper clears a selected-ID alias
  before launch. Pin unset/on/off selection without pretending this verifies
  GPU counter synchronization or primitive arithmetic.
- gfx1151's MoE strict/production binder already turns both flags off/on. Its
  router manifest names the base `router_logits` family and uses the binder
  to select the actual fused family. Removing readers alone would silently
  remove strict behavior while leaving plausible manifest provenance.
- gfx1100's MoE profile uses a different binder. Preserve both architecture
  policies. The c1/batch route gates, control smoke and lifecycle harness also
  consume the flags; migrate them with any construction-time plan adoption.
- Move the row to the bottom under the existing RF-1 resolved-plan direction.
  Preserve both cooperative variants, exact unfused primitives and recorded
  historical evidence. Correct `docs/ENVS.md` to state true runtime defaults
  and binder/ABI behavior. No runtime, default, profile or kernel changes;
  new tests characterize existing behavior, so RED-first is inapplicable.
