# Profile current MTP and Generation-2 recovery

## Summary

Profile current W7900 Generation-2 AR against the exact old p512/d128 protocol
and join it with the final gfx1100 SPECDEC2 C1 evidence. The suspected raw AR
performance regression is not present: current C1 is `77.176` blocking /
`76.925` SSE tok/s versus old `72.169` (+6.94%/+6.59%), and current native C8
is `161.882` raw tok/s versus old `158.542` (+2.11%).

The native C8 number is nevertheless ineligible under the requested strict
same-engine-C1 contract. Queue1 repeats pass only 16/24 IDs; one prompt differs
at generated index 40 in every run and another differs at index 11 in two runs.
Graph and eager execution produce the same varied-composition divergence. With
independent C1 prefill, packed hidden first differs at decode step 1/layer 0
(33 BF16 elements, max `1.22e-4`) before token divergence. C4 and physical-C2
composition also fail the varied D128 contract; the latter falls to `62.148`
tok/s. Thus this is an unresolved execution-profile/batch-composition boundary,
not scheduler or graph submission overhead and not a safe narrow-width rollback.

SPECDEC2 remains as closed previously: dense C1 K1/K2/K3 beats AR
`1.272x/1.407x/1.439x` but trails direct MTP 2.7%-3.9%; packed PARO production
is `0.979x` AR / `0.960x` direct. Both gfx1100 physical C2/C4 capabilities are
false, so current C>1 traffic is K0 rather than concurrent MTP.
