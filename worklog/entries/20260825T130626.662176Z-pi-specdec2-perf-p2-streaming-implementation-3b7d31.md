# Integrate SPECDEC2 streaming prompt priming

## Summary

Integrated the retained exact OI-3 target-hidden streaming mechanism into
Generation-2 SPECDEC2 prompt activation. Fresh strict C1/C2/C4 requests now
open their NextN provider and request-owned `_StreamingNextNPromptSink` before
target prefill, consume pre-output-norm BF16 target rows on the target stream,
and transfer one carried 10 KiB BF16 hidden row into the staged request state.
The selected path no longer returns prompt-sized FP32 hidden arrays or performs
post-prefill per-token F32→BF16/H2D replay.

No backend-specific arithmetic was added. The integration uses the shared sink,
NextN enqueue ABI, resident target prefill, and staged adapter; gfx1151 and the
independently qualified gfx1100 dense C1 source remain structurally shared while
hardware evidence stays separate.

## Changes

- Add one-time ownership transfer for `_StreamingNextNPromptSink`'s final carried
  row; close still frees it on every non-transferred failure/cancellation path.
- Extend packed prefill with aligned request-owned sinks, request IDs, chunk
  starts, multi-round offset propagation, ragged slot-major hidden scatter, and
  exact finish ownership. Existing callers pass no new kwargs unless streaming
  is actually selected.
- Open one C1 or physical C2/C4 provider group before target prefill, enqueue all
  shifted prompt rows, transfer carried rows atomically into `_MTP2RequestState`,
  and drain host staging/provider/sink owners on failure.
- Publish the logical NextN batch-session cursor after enqueue-only prompt
  mutation. This is required by physical proposal's cursor gate and adds no
  scoring or synchronization.
- Keep `_prompt_hidden_rows`/post-prefill replay only as a strict fallback for
  prefix reuse or providers without the streaming ABI; add its removal trigger
  to `docs/REFACTOR.md`.
- Add request telemetry for selected streaming route, primed rows, carried bytes,
  and fallback reason; the common bridge now marks streaming provider open and
  sink-consume NextN priming separately from the enclosing target prefill.
- Preserve strict capability split: C1 capacity1, C2/C4 capacity4, prefix/K0,
  cancellation, and registered strict target fallback behavior.
