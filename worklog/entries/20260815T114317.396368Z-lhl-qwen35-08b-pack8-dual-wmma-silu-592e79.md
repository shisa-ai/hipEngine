# Attempt operation-complete Q4 pack8 WMMA prefill

## Summary

Human-approved follow-on to the synchronized three-way comparison. Select one
bounded Q4_K_M pp512 architecture attempt: an operation-complete resident-pack8
dense gate/up WMMA+SiLU body derived from the retained in-tree Q4T16 dual-WMMA
mechanism. It adds no resident bytes and preserves the ordinary two-singleton
WMMA plus standalone SiLU fallback.

Current synchronized core prefill is **117.589 ms / 4354.16 tok/s**. Current
marker ownership is dense projections **44.541 ms** plus dense activation
**1.389 ms**; actual-weight leaf evidence puts each of the 48 gate/up singleton
WMMA projections near 0.585 ms. The candidate therefore addresses roughly
29.5 ms of request ownership by loading each activation fragment once for both
matrices, reusing each decoded weight slab across 256 rows, and eliminating
intermediate global writes/reads and the standalone SiLU dispatch.
