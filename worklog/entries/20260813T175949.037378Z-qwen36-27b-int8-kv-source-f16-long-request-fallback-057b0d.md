# Fallback source-F16 prefill beyond scratch rows

## Summary

Long GGUF requests no longer fail when the request-wide source-F16 admission
context is larger than the auto-tuned bulk scratch chunk. Source-F16 is
qualified by complete request rows, so an oversized request now keeps the exact
T16 fallback rather than treating chunk capacity as an arithmetic admission.

## Changes

- Changed `_q6_f16_rocblas_prefill_context()` to reject only non-positive
  request rows and return the exact T16 owner when request rows exceed bulk
  scratch rows.
- Split focused coverage into an oversized-request fallback assertion and a
  non-positive-row rejection assertion.
- This unit changes no qualified source-F16 threshold, projection policy,
  kernel, or short-request route.
