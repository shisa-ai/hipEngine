# Retain gfx1151 packed-prefill final-output mask

## Summary

Retained a gfx1151 package policy that samples each packed-prefill slot only in
the bounded round that reaches the slot's final prompt token. A physical-C8,
512-token-per-row workload uses six bounded rounds; the policy removes 40
intermediate tail samples while preserving final tokens, positions, all FP32
hidden-seed hashes, all Conv/GDN state hashes, and all live BF16 KV hashes.
The unmasked gfx1100 route is unchanged pending W7900 qualification.

The complete-wall result is positive but too small for a standalone throughput
headline. Pooled A/B/B/A prefill wall improves 0.149%/0.219%/0.217%/0.033% at
C5-C8. Matched traces provide the retention basis: the exact Q6 LM-head owner changes
from six launches/34.599 ms to one launch/5.756 ms, and total dispatches fall
24,318 -> 24,248. The final clean candidate revision is
`f691b7edc7d9981ee46d0e9a6f38fff466eafd97`; the control is
`5794ff228affc171e09606d668c7593333c1a584`.

## Changes

- Added `GGUF_PACKED_PREFILL_FINAL_OUTPUT_MASK` as a backend-package capability:
  enabled for gfx1151 and disabled for gfx1100.
- Added per-chunk final-slot ownership to
  `Qwen35GGUFResidentSession.prefill_batch_native()` and allowed single-slab
  prefill to return unsampled hidden rows without invoking output norm,
  LM-head, or argmax.
- Kept all-row FP32 hidden-seed normalization and streamed target-hidden sinks
  independent from user-visible output sampling.
- Added final-slot, package-scope, and telemetry tests.
- Recorded the retained artifact at
  `benchmarks/results/2026-09-05-gfx1151-qwen38-packed-prefill-final-mask-retained.json`
  and updated the benchmark rollup, changelog, refactor ledger, and W7900 audit
  handoff.
