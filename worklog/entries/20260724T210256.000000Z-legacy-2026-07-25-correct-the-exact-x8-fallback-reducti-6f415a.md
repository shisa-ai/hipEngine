# 2026-07-25 — Correct the exact X8 fallback reduction topology

## Summary

## Changes


- The first actual layer-1 c=1/top-10 smoke found **4 / 20,480** BF16 mismatches despite the initial tiny fixture passing. Audit showed that the retained T16 launcher deliberately uses local128/four waves, while the first X8 wrapper used local256/eight waves. This is a test-coverage bug and an exactness rejection of the first schedule, not acceptable numerical tolerance.
- The corrected X8 kernel uses local128, `k=tid+128*n`, and wave-0..3 summation exactly like retained T16. The c=1 fixture is strengthened to K3072 with randomized valid Q4_K metadata/quant bytes so a short, regular K512 tensor cannot hide a reduction-order error. Re-run the actual-weight smoke and cached trace before qualifying performance.
- The corrected direct-X8 body is exact on the actual layer but measures **0.781316 ms** versus **0.166475 ms** T16 at c=1/top-10. Coalesced 2,304-byte raw A/B LDS staging cuts X8 to **0.321674 ms** versus **0.154609 ms**; widening the staged output tile to 16 columns measures **0.357846 ms** versus **0.160797 ms**. These bounded diagnostics reject direct raw addressing, staging alone, and block-count reduction as the missing decode mechanism.
- The retained diagnostic dynamically converts two adjacent X8 packs into one T16-shaped 16-column A/B LDS tile for each K256 interval. It transposes the Q4 nibbles and expands scale/min metadata once, then uses the exact T16 arithmetic/reduction topology. The strengthened synthetic bundle reports **14 passed**, and the actual c=1/top-10 output has zero BF16 mismatches. An 11-sample, burst-10 dirty-tree screen measures **0.174295 ms** versus **0.147801 ms** T16 (**1.17925x**), so the no-sidecar X8 route still fails the <=2% decode gate despite a 4.48x improvement over direct X8.
- Cached actual-weight tracing names the final exact X8 symbol at local128, VGPR176, SGPR128, LDS6144 B, scratch0, with warm dispatches **191.519/191.680 us** versus T16 **180.259/177.293 us**. This is diagnostic evidence, not a retained performance claim; publish the clean four-shape rejection before changing the LAP-1 resident-layout decision.
