# Stream committed SPECDEC2 output through SSE

## Summary

Enable explicit speculative MTP requests on completion/chat SSE. The EngineService
already publishes only committed speculative token/chunk events through its
bounded child collector; the server route previously rejected streaming before
reaching that implementation. Route MTP streams to
`stream_speculative_mtp_detailed()` and advertise the actual Generation-2 C4
frontier capability.

## Changes

- Remove the obsolete explicit-MTP streaming rejection.
- Route `_SPECULATIVE_MTP_BATCH_ROUTE` through the engine's committed speculative
  stream callable; fail closed if an engine advertises MTP but lacks that method.
- Advertise streaming compatibility, Generation-2 target-frontier ownership,
  and max physical width four.
- Replace the old rejection test with completion/chat SSE committed-chunk tests.
