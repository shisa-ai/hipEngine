# Localize dense split on parent trajectory activations

## Summary

A diagnostic collector compares the dense split candidate with the live F32
parent and an independent F64 CPU reference on natural early-layer activations.
It does not publish candidate outputs into the model. It separately reruns the
parent prefill and requires bit-identical full logits with observation enabled.
The full strict numerical failure remains unresolved; this unit localizes it.

## Changes

- Add `scripts/qwen4exp_dense_split_localize.py`: first eligible raw-F32
  projection per slot/case, layer scope, candidate private-buffer repeats,
  eight evenly spaced CPU rows/all columns, optional local NPZ captures, full
  parent-versus-candidate metrics and leak-free observer teardown.
- Add five CPU contract tests for numerical metrics, BF16 boundary counts,
  nonfinite/shape rejection, deterministic sampling, scope/parent eligibility
  and non-intervention call ordering.
- No runtime, registry, math kernel, threshold or default change.
