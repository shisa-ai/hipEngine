# Add explicit runner-owned dense wide prefill policy

## Summary

Add explicit dense-wide enablement/layer ownership and a diagnostic override
surface before removing profile environment transport. Production defaults and
unbound environment semantics are unchanged. R0425/R0426 remain open: the binder
and the three diagnostic scripts still need migration together.

## Changes

- `Q8DenseWidePolicy` holds enabled/layers, with `None` layers meaning every
  layer and layer zero remaining a real selection. A resolver rejects invalid
  bound values and consults environment only for unbound owners.
- An explicit context manager changes generator/runner fields and restores
  prior values or missing attributes after exceptions. A dispatch-only loan
  lends the policy during the runner's existing prefill chunk lifetime.
- The runner resolves the same owner policy for dispatch and F16 staging;
  generator construction/policy copying carries the value to serving runners.
  No new per-method profile context or transaction framework is introduced.
- Keep legacy environment fallback and binder writes until all their readers
  have the replacement. This unit does not retire a selector or change math.

## Validation

- RED: four initial ownership tests fail because the interface is missing.
- GREEN: ownership, nested diagnostic restoration, ambient isolation,
  logical-layer selection and invalid-value tests pass. Existing wide-route,
  F16 staging/tail and profile tests pass (142 tests before three extra selector
  cases; the new seven-test file passes after those additions).
- Initial public probe used capacity 512, which cannot hold QSA's fixed
  512-block selection budget at compression ratio four. Repeat at the existing
  public fixture capacity 4608; this is a workload precondition, not a policy
  failure or a default change.
- Full CPU bundle: 26,197 passed, 274 skipped, no failures
  (`/tmp/r0426-wide-owner-unit.xml`); compilation, fixtures, registry,
  CPU-fixture and add-build-plan smokes pass. Final focused owner/staging/tail
  tests pass after the session type check and unused import cleanup.
- The capacity-corrected public observer mixed decode rows with prefill rows;
  decode does not borrow the prefill policy. Restrict its assertions to rows>1
  and rerun; no runtime behavior change is needed for that test correction.
- The prefill-only probes found no selector calls, including with MMQ/rowtile
  diagnostic stand-downs. Selector calls occur on cache misses only, so they
  cannot prove engagement for repeated requests. The final observer records
  launch variants after cache lookup and requires wide variants only in the
  enabled arm. MMQ/rowtile stand-downs remain scoped to this diagnostic.
- Public final-launch probe passes without skips
  (`/tmp/r0426-wide-owner-public-final-launch.xml`). It repeats each policy,
  checks that wide variants launch only in the enabled arm, checks the borrowed
  policy for every multi-row final launch, verifies finite/exact-repeat captured
  logits within each arm, restores the owner and confirms allocation teardown.
  It does not compare changed-arithmetic policies for equality.
- Documentation, audit, test-tier and whitespace gates pass. The audit reports
  two existing decisions past their review dates but no budget violation.
