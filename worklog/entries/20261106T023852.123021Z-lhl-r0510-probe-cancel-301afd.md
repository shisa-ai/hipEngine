# Discard interrupted GGUF scratch probe sessions

## Summary

Discard interrupted AR/MTP scratch-probe sessions even when the caller asked
to retain successful warmup sessions. Cancellation must not pool partial state.

## Changes

- Treat `BaseException` as a failed probe transaction in both warmup branches,
  closing acquired sessions before re-raising rather than taking success pooling.
- Add ordinary-error and KeyboardInterrupt regressions for release and retain.

## Validation

- RED: interrupted retained probe returns sessions to pool instead of closing;
  `/tmp/r0510-cancel-red.log`.
- GREEN: all four focused scratch-probe tests pass;
  `/tmp/r0510-cancel-green.log`. AR test exercises both failure classes and
  both release modes. MTP branch uses the same exception handling change but
  has not been separately cancellation-injected.
- Public normal release/bounded context validated in bg-613, recorded in
  `20261106T023641.368462Z-lhl-r0510-bounded-context-3d88ff.md`.
