# Clarify launch-library lifetime and environment contract

## Summary

Fix a concrete invalidation hole discovered during R0446: the fast-path cache
could return a stale library after invalidate_build_resolution cleared the other
handle caches. Defer the broader explicit launch-library lifetime decision.

## Changes

- Clear _FAST_PATH_CACHE alongside resolution and loaded handles.
- Add an all-cache regression (RED before fix) and an actual build_hip path
  regression using a fake CDLL loader: warm hits reuse the object, invalidation
  makes the next call load a fresh one.
- Preserve environment-sensitive keys and explicit handles. The future owner
  must define pinning versus live environment observation and variant identity;
  once-per-process resolution is not a safe universal replacement.
- Retire stale historical cost narrative from the live ledger, keeping original
  evidence. No performance claim or kernel change.
