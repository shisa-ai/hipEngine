# Exact ordered-v2 QSA sparse decode (attacks the 16.95 vs 3.16 ms decode owner)

## Summary

Attacked the largest single decode owner: fixed-live4097 QSA decode, measured
16.95 ms/token in the family ledger versus halo-box Vulkan 3.161 ms (5.365x,
75% of the total decode device gap). The production decode route is the
zbook-era exact ordered three-pass (`strict_ordered_three_pass_spans`).
A fresh leaf probe at production geometry (c1, 24 query heads / 2 KV heads /
D=256, paged BF16 block 256, selected 2051 of context 4097) reproduced
1.154 ms/layer and rocprof attributed it: scores 401 us (49,224 tiny
256-thread tree-reduction blocks), coefficients 177 us (24 single-thread
blocks with a fully serial expf-dependent scan), values 533 us (24 blocks
whose coefficient loads sit on the serial weighted-V chain). The wave/quad
single-warp kernels are bit-exact at this geometry but latency-exposed
(2.25/1.83 ms), and even the dense full-context decode kernel is faster
(0.787 ms) than the sparse route despite reading 2x the tokens.

The v2 rewrite keeps the exact three-pass arithmetic and the parent operand
order everywhere: the scores pass reuses the validated eight-coordinates-
per-lane warp tree (order-identical to the 256-thread parent tree, pinned
products); the coefficients pass replaces the serial online-softmax scan with
an exact `fmaxf` block scan (max is associative, no rounding), pointwise
`expf` off the critical path (identical inputs, including NaN -> 1.0/0.0 and
isinf -> 0.0 special cases), and a prefetched serial denominator; the values
pass stages coefficients in shared memory and pipelines the weighted-V chain
with 32-deep register tiles. A decisive isolation experiment showed the
`token < 0 ? 0.0f : load` select around each V load defeats all memory-level
parallelism (406 vs 122 us); clamped unconditional loads with a post-load
select restore it. Result: 0.179 ms/layer - 6.45x over the production route,
bit-exact, and 4.4x faster than the dense kernel. Kernel breakdown after:
scores 32 us, coefficients 14 us, values ~110 us.

Qualification followed the campaign protocol: 14 focused tests (bitwise vs
parent across selected 1..4096 including invalid positions, tail counts and
extreme query scales, plus registration guards); six-case off/on/off state
gate at chunk1024 with full logits, 4 decode steps, state and full KV -
all bit-identical, with 48 sparse decode calls per enabled p4096 arm, zero
in prefill and zero at short contexts; full 12-case chunk1024 A/B at clean
f4e60b712: all 72 trajectories exact, p4096 decode +7.1/+11.0/+11.4/+24.8%
per case (aggregate +16.5%, request wall -4.5%), prefill and p512/p1024
decode neutral (route not engaged). Promoted: production binds
`HIPENGINE_QWEN4_EXP_QSA_ORDERED_DECODE_V2=1`, strict 0.

Projected ledger effect: the decode QSA owner falls from ~16.95 to ~2.1
ms/token across 12 QSA layers, turning the 5.365x owner into roughly parity
with Vulkan's 3.161 ms dense-mask equivalent; the remaining decode gap is
MoE/FFN (1.39x) and linear (1.04x).
