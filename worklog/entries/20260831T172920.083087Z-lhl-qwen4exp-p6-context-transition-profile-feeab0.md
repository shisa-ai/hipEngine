Localized the p1024→p4096 decode cliff to a fixed indexed-QSA sparse-attention
cost. The cost appears immediately at live count 2,052 and remains flat at
4,097; score/top-k and continued context growth are secondary.

## Validation

Clean named-production packet at `d086557d0`, canonical `code-p4096` token IDs,
three snapshot-restored repeats/context:

- live 2,051 dense-equivalent: **66.614 ms** median;
- live 2,052 indexed sparse: **95.880 ms** median;
- live 4,097 indexed sparse: **96.016 ms** median;
- token IDs and complete state hashes exact at all three contexts;
- tracked memory returns to zero.

Cached `rocprofv3` marker windows confirm:

- total kernel time/step: **58.57→89.34→88.93 ms**;
- QSA attention: **8.41→35.88→35.49 ms**;
- QSA score/top-k: **0.06→0.98→0.66 ms**;
- direct launches: **1,100→1,160→1,148** per step;
- graph launches remain 48 and memcpy calls remain 38 per step.

The 2,051→2,052 boundary adds 30.77 ms of kernels, of which sparse attention
accounts for 27.47 ms. At each of 12 QSA layers, the H256 strict sparse kernel
serially processes about 2,048 selected tokens with a 256-thread shared-memory
reduction and barriers for every token, costing about 3.0 ms/layer. The
2,052→4,097 wall delta is only 0.14 ms, consistent with the selected budget
already being saturated.

The profile postprocessor initially failed because the role analyzer accepts
one marker while the profiler emits three repeats. The raw trace was valid; role
attribution was run per exact repeat and aggregated without rerunning the GPU.
