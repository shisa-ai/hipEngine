# Record rowtile caller-to-worker scope transport gap

## Summary

Public caller-thread rowtile comparison scopes are not transported to the
engine-service worker. R0281-ROWTILE-CONTROL remains open.

## Changes

- Existing ContextVar repair isolates execution contexts correctly; it does not
  carry caller context through request submission. The service starts a separate
  driver thread and enqueues request states without a rowtile comparison field.
- Do not replace this with a module-global override or blindly copy all caller
  context into a shared worker: independent queued requests may differ.
