# Served multi-turn prefix cache A/B turns net-positive

## Summary

The served multi-turn A/B that previously measured **+6.4% wall** for
`--prefix-cache radix` now measures **-18.6%**, with the same command, lanes,
host and the identical reuse (16 of 27 lookups, 42,496 of 87,582 prompt
tokens). The sign changed because a hit no longer resumes its suffix one token
at a time. Three latent KV-pool growth defects were found and two fixed while
getting the wide-retention arm to run.

## Changes

- `hipengine/runtime/qwen35_gguf_runner.py`: the pool `before_grow` and
  `on_pressure` callbacks now read `_resident_batch_owner` through `getattr`,
  as every other reader in the file does. A session that owns its own pool
  never has the attribute, so the first grow or pressure event raised
  `AttributeError` from `GlobalDeviceKVPool._ensure_free_pages`.
- `hipengine/runtime/qwen35_gguf_runner.py`: `grow_storage` declares
  `pointer_tables` `nonlocal`. It rebinds the name, which without the
  declaration made it local and turned `old_tables = pointer_tables` into
  `UnboundLocalError` on the first real growth.
- `tests/test_unit_gguf_packed_workspace_stability.py`:
  `test_pool_pressure_callbacks_tolerate_a_session_without_a_batch_owner`.
- `benchmarks/README.md`, `benchmarks/CHANGELOG.md`, and two artifacts under
  `benchmarks/results/`.
- `docs/REFACTOR.md`: the third growth defect, still open.

## Validation

- A/B, zbook / gfx1151, Qwen3.6-35B-A3B `UD-Q4_K_M`, in-process resident loop,
  one process per arm (a second arm in one process faults the GPU; recorded in
  `docs/REFACTOR.md`):

  ```
  uv run python scripts/prefix_cache_multiturn_bench.py --backend hip_gfx1151 \
    --lane-kinds all --repetitions 1 --turn-limit 3 \
    --agentic-workloads small_repo growing_history medium_repo \
    --sharegpt-tokens 96 --sharegpt-long-tokens 384 --code-tokens 128 \
    --max-sequence-length 12288 --modes off --json off.json
  uv run python scripts/prefix_cache_multiturn_bench.py <same flags> \
    --modes radix --baseline-artifact off.json --json radix.json
  ```

  | metric | off | radix | delta |
  | --- | --- | --- | --- |
  | wall | 351,497.7 ms | 285,989.6 ms | **-18.6%** |
  | output rate | 16.933 tok/s | 20.812 tok/s | **+22.9%** |
  | code_cumulative wall | 114,139.1 ms | 69,881.1 ms | **-38.8%** |
  | code_fixture wall | 113,707.8 ms | 90,944.4 ms | **-20.0%** |
  | sharegpt wall | 123,650.8 ms | 125,164.1 ms | +1.2% |

  Reuse: 16 hits of 27 lookups, 42,496 reused tokens; fallback reasons `miss:
  11`, `prompt_too_short: 14`. The ShareGPT lanes are flat because their
  prompts are 30-685 tokens and return `prompt_too_short` before a lookup.
- The prior run of this protocol
  (`benchmarks/results/2026-09-18-gfx1151-qwen36-gguf-prefix-cache-multiturn-ab.json`)
  recorded the same 16/27 lookups and 42,496 reused tokens at **+6.4% wall**,
  so the comparison is like-for-like on reuse. The two runs' `off` baselines
  differ in absolute terms (399.0 s then, 351.5 s now), so the retained claim
  is the in-run A/B delta, not the absolute rate.
- Correctness gate: a hit reproduces a miss bit-for-bit (KL exactly 0, top-1
  100%, same first token) for every shape with a suffix of at least two tokens
  and total context at or below 2,048, across `code`, `general_en`,
  `general_ja` and `mixed_ja_en`. Above 2,048 the vendored AOTriton prefill is
  query-window dependent; that bound is pinned by
  `test_split_prefill_divergence_boundaries_are_unchanged` and is why prefix
  caching stays off by default.
- Unit: the prefix-cache, packed-workspace, packed-verify, kvcache-prefix,
  multiturn-bench, reuse-bench and capacity suites - exit 0, zero failures.

## Next

- The third growth defect is open: a grown pool can hand out an allocation
  spanning two backing chunks, which `validate_bound_blocks` rejects. It blocks
  the `HIPENGINE_GGUF_PREFIX_RETAINED_SNAPSHOTS=16` arm, which is why this A/B
  ran at the shipped default retention.
- Whether to enable `--prefix-cache radix` by default is a product call: the
  win is measured, and the cost is that a hit above 2,048 tokens of context can
  select a different token than a miss.
