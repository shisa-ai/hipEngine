# Gemma 4 verify block dense projections on the one-row GEMV

## Summary

Dense Q8_0 projections of a 2-8 row block (an MTP verify block, or a short
prefill tail) that ship the T16 tiles now run on the one-row T16 GEMV with one
grid row per input row. It is bit-identical to decode and, at Gemma's dense
shapes on W7900, faster than the T16 WMMA prefill and the exact pack8 prefill it
replaces (o_proj five rows 40.6 us vs 103.4 WMMA; cold microbench over all
layers). Production keeps WMMA for >4 rows of an output wider than 4608 (QKV
8192: 95.2 vs 82.6 us at five rows). Production MTP budget 4 1.39x -> 1.45x
(107.7 tok/s), budget 2 1.27x -> 1.43x; strict 1.19x -> 1.29x; production rows
token-identical to plain 22 -> 32 of 36.

The five-row production block only moved 27.8 -> 27.0 ms although its dense
kernel time fell 9.8 -> 5.4 ms: host enqueue for the block ends at 11.2 ms of
26.8 ms wall (GPU-bound), and the dense GeGLU branch overlaps the expert branch
on the MoE stream, so attention plus the expert branch set the length.
