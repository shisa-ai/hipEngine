# Implement SPEC-C2 continuous speculative packing

## Summary

Closed SPEC-C2 host packing and actual-c2 correctness without changing GPU
arithmetic/defaults. Compatible speculative children now enter one driver call
and share one multi-request `VERIFY_CHAIN` WorkItem; incompatible children keep
stable pre-launch boundaries.

## Changes

- Added exact `VerifierCostRecord`/`VerifierCostMap` keyed by C, V, tree shape,
  context, transaction mode, and execution profile; AR-D2 sources are rejected.
- Added bounded packing records/policy for draft rows, verify rows, cycles,
  transaction bytes, work items, deadline guard, fairness, refill, and AR-due
  coexistence.
- Added EngineService batch admission with complete prevalidation/atomic abort.
- Added SubmitPoll compatible multi-prompt MTP packing and shared C/V row maps;
  incompatible requests fall back to separate pre-launch submissions.
- Added RED/GREEN packing, service batch, fairness, pressure, deadline, and
  actual Qwen c2 coverage plus audit/docs/artifact updates.

- Actual W7900 Qwen3.8 c2 p16/d4: both rows 4/4 exact against direct fallback;
  one C=2/V=6/depth3 VERIFY_CHAIN work item, active children/final requests zero.
- Final packing/service/simulator/audit bundle: 37 passed. Ruff, py_compile,
