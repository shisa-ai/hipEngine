# Report the >1.0x gate and the 1.3x aspiration separately

## Summary

The break-even verdict conflated two different thresholds and, in doing so,
recorded a qualified win as a failure. The native arm's projection clears 1.0x in
every fixed-share row (1.33x at 0% down to 1.09x at 30%) yet the artifact listed
"a row projects below the 1.3x target" under `withheld_reasons`, which reads as a
blocker. The design states that **any qualified net improvement counts** and that
1.3x is an aspiration, so the two thresholds now decide different things and are
reported separately.

## Changes

`scripts/tp_break_even.py` gains `BEATS_TP1_SPEEDUP = 1.0` beside
`TARGET_SPEEDUP = 1.3`, and the verdict becomes:

| Field | Meaning | Blocker? |
| --- | --- | --- |
| `beats_faster_tp1_arm` | every row > 1.0x | **yes** - a row at or below 1.0x means the group would not pay for itself |
| `meets_planning_aspiration` | every row >= 1.3x | no - recorded in `aspiration_notes` |
| `passes_target_in_every_row` | unchanged: the aspiration | no - kept so older readers are not silently re-pointed at the gate |
| `optimistic_bound_beats_tp1` | the free-rank-weight bound > 1.0x | **yes** when false: no shard kernel could rescue it |
| `optimistic_bound_clears_target` | the bound >= 1.3x | no |

`certified` now follows the gate plus genuine blockers. The same distinction is
applied to the optimistic bound: a bound below the *gate* is structural and is
withheld, while a bound below the *aspiration* only caps how far the win can go.

The CLI prints both verdicts and separates withheld reasons from aspiration notes.

Current artifact (`benchmarks/results/tp2_break_even_native_staged_exchange.json`):

```
beats the faster TP1 arm in every row = True; meets the 1.3x aspiration = False; certified = False
  withheld: the pre-Packet-3 shard-kernel gate has no recorded evidence
  aspiration: the worst row projects 1.093x, below the 1.3x planning aspiration;
              a qualified net improvement is still retained
```

The single remaining withheld reason is genuine: no shard kernel has been
measured. Nothing about the projection itself is withheld any more.

## Validation

```
uv run python3 scripts/tp_break_even.py --tp1 "W7900=29.575:15.652:8.646:512/128/int8-kv" \
  --tp1 "XTX=35.355:15.652:7.009:512/128/int8-kv" \
  --native-ab-artifact benchmarks/results/2026-09-14-w7900-tp2-staged-exchange-native-ab.json \
  --reduction-points 128 --json benchmarks/results/tp2_break_even_native_staged_exchange.json
uv run pytest tests/test_unit_scripts_tp_break_even.py
```

39 tests pass, including three new ones: a 1.1x-class projection that clears the
gate, misses the aspiration, and is still certified; an unreachable gate withheld
while an unreachable aspiration is only noted; and the corrected reading of the
existing optimistic-bound fixture, whose 1.243x bound clears the gate and so
bounds the win rather than blocking it.

Two test fixtures had to be corrected because they did not exercise what their
names claimed: one used a collective small enough that every row cleared 1.3x, and
another's 1.243x optimistic bound was asserted to be an unreachable gate when it
is an unreachable aspiration. Both are now calibrated against the real baseline
pair.
