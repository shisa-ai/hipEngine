# Add exact Qwen4Exp QSA row transforms

## Summary

Added strict row-bulk Qwen4Exp QSA query/key/gate and index-query transforms as
a prerequisite for bounded prompt chunks.

## Changes

- Added row-major siblings for attention-Q split/gate, Q/K RMSNorm and
  split-half partial RoPE, plus index-query RMSNorm/RoPE.
- Every row consumes its explicit INT64 position; there is no contiguous-
  context shortcut or prompt-conditioned branch.
- Registered `strict_rows` variants while preserving the c1 `strict` primitive
  fallbacks unchanged.

  tensors versus independent c1 launches.

  `qsa_split_norm_rope_rows_f32_kernel` at 2,204 ns and
  `qsa_norm_rope_rows_f32_kernel` at 2,124 ns for the reduced three-row fixture.
