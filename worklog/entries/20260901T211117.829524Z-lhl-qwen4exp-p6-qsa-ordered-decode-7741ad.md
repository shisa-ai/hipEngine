# Promote exact ordered QSA decode

## Summary

Promoted the exact ordered three-pass H256 sparse-QSA c1 decode path for
Qwen3.8-Flash-Next production on gfx1151. Four-category p4096 tg128 improves
93.912 to 80.061 ms/token (1.173x) across 12 counterbalanced pairs. Full logits,
generated IDs, repeat state, and lifecycle remain exact.

## Changes

- Added a T0 sparse-attention owner with parallel strict-order QK score
  production, one global selected-order online-softmax coefficient recurrence,
  and independent output-column weighted-V recurrences.
- Registered `strict_ordered_three_pass_spans` with `strict_spans` fallback and
  bound it only in the named gfx1151 production profile.
- Preallocated the 0.56-MiB score/coefficient scratch before graph use and
  released it through the existing scratch lifecycle.
- Made canonical host metadata record visible GPU
  `power_dpm_force_performance_level` controls; this campaign declares `auto`.
- Updated the campaign queue, kernel catalog, benchmark rollup/changelog, and
  compact artifact.

## Validation

- RED: the new actual-shape 2,051-selection primitive test initially failed on
  the missing wrapper; GREEN is bit-exact to the strict output bytes.
- Leaf median: 2.158 to 1.180 ms (1.829x).
- Same-session whole-model A/B: 12/12 p4096 tg128 category pairs improve;
  aggregate throughput ratio 1.1731, 95% interval 1.1699-1.1762. All route
  repeats, full-logit hashes, and generated IDs match; CV is at most 1.10% and
  teardown is zero.
- Named production `rocprofv3` trace records
  `qsa_sparse_attention_paged_bf16_ordered_{scores,coefficients,values}_f32_kernel`.
  The QSA operation role is 20.913 ms/token with 100% attribution, zero
  measured-window allocations, exact repeated token/state, and clean teardown.
- Focused QSA/runner/profile bundles pass (15 tests), as do compileall and
  `git diff --check`.
