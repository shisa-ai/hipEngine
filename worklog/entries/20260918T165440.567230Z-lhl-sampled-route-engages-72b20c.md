# sampled MTP route engages: the recomputed accept summary must keep the open transaction's identity

## Summary

With provider draft state opened (5c272bb7a), the sampled route reached the
verifier and then failed its first admitted cycle with
`ValueError: prepared GGUF verification is not the open transaction`, which
disabled the request and silently reverted it to autoregressive decoding. The
cause was a mechanical identity break, not a coupling defect: the sampled route
recomputed the accept summary and installed it with `dataclasses.replace`, which
builds a *copy*, while the verifier's `commit`/`rollback` accept only the exact
instance `prepare` returned. Installing the summary on that instance lets the
cycle commit, and the sampled route now runs end to end in serving.

## Changes

- `hipengine/runtime/qwen35_gguf_mtp.py`: adds
  `Qwen35GGUFTransactionalVerifier.adopt_accept_summary(prepared, summary)`,
  which re-checks the open-transaction identity and writes the recomputed
  summary onto the prepared instance (`object.__setattr__`, because the record is
  frozen). Only the accept decision changes; verified rows, buffers, and journal
  stay as prepared.
- `hipengine/generation/qwen35_gguf_mtp2.py`: the sampled branch of
  `execute_target_frontier` calls `adopt_accept_summary` instead of
  `replace(prepared, summary=summary)`, and fails closed with a named error when
  a verifier cannot adopt a recomputed summary.
- `tests/test_unit_qwen35_gguf_mtp_session.py`: adds
  `test_adopt_accept_summary_keeps_the_open_transaction_identity`, which asserts
  the adopted object *is* the prepared object, that the summary changed on it,
  and that a copy is still refused by both `adopt_accept_summary` and
  `_require_open`.
- `hipengine/generation/qwen35_gguf_mtp2.py` also carries the arm's env-gated
  traces in this commit (`[route-debug]`, `[cap-debug]`, `[cap-silent-none]`,
  `[prefill-debug]`, `[cycle-failure]`, all behind
  `HIPENGINE_DEBUG_SAMPLED_ROUTE`). They are what named every gate on this
  route, and they stay until the arm closes; the evidence-row switch in
  `hipengine/models/qwen35.py` remains uncommitted.
