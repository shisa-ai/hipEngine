# The wmma 16-47 baseline change is in-kernel arithmetic, not dispatch

## Summary

Refines `20260930T102145` (qwen4exp-wmma-cert-stale, commit `8e8806833`), which
recorded that the production `wmma` 16-47 numerical certificate no longer

## Validation

**Dispatch and route resolution are provably UNCHANGED.** Every engagement and
selector-state field is identical between the recorded run (`035185fb2`) and the
HEAD run (`f4b12e0c2`):

| field | recorded | HEAD |
| --- | ---: | ---: |
| `candidate.engaged_launches` | 2488860 | 2488860 |
| `teacher.engaged_launches` | 833004 | 833004 |
| `wmma_prefill` candidate / teacher | 0.373585 / 0.0 | 0.373585 / 0.0 |
| `q4k_rowtile` candidate / teacher | 0.996195 / 1.0 | 0.996195 / 1.0 |
| `wmma_route_engaged_candidate_only` | true | true |

Same kernels, same proportions, same selector states - so the differing logits
come from **different arithmetic inside kernels that both runs dispatch
identically**, not from a routing, registration or memoization change.

**Excluded:** `a9a33dd88` (cache key), `b9f73e808` (registration order),
`76dd95d7f` (route removed), `45a8f5690` (documented no-op: it only adds the
default-off `GR_WIDE` to a withdrawal list).

**Leading candidate: `6c3c46b04` (DE-3).** It changes the decode-shaped pack8
GEMV's block width at `out <= 640` - "32 threads per output rather than 16; max
relative divergence 2.6e-7" - as a runtime dispatch parameter in
`hipengine/runtime/gguf_linear.py`, not a kernel swap. The same kernel family
runs, so route-engagement counters are unchanged, while the K-reduction tree
differs. It is a **decode-path** change and the gate runs **128 decode steps per
case**.

**Not excluded:** `3b6497b25` (RT-4 bounded KV reset - device state rather than
dispatch), `5fa2c2da5` (RT-1's chunk default; the gate pins the chunk explicitly
so it should not reach it, but that is reasoning, not measurement).

**None of these is bisected.** The established class is: an in-kernel arithmetic
change on a path both arms share.

Supporting observation: HEAD has **better** top-1 agreement (0.9942 vs 0.9935)
while its max KL is worse (2.341e-2 vs 1.530e-2). Max KL on this fixture is a
tail statistic driven by near-ties, and a small arithmetic perturbation can move
which near-ties flip.
