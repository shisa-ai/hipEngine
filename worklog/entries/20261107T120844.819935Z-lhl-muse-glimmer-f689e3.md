# Muse Glimmer prefill: wide-N config sweep

## Summary

Activation re-reads across column blocks scale as 1/OUT_TILES, so a wider
N-block should cut the L2 traffic that bounds this kernel. Swept shared_b
template configs via a temporary wrapper. The only faster config (<6,4,2>,
6.23 vs 6.69 ms) returns NaN — shared_b is correct only for its validated
<3,4,4> geometry; the wider instantiations are not correct for this shape.
No safe wide-N win. Reverted.

## Changes

- Temporary config-dispatch wrapper (shared_b <O,W,R> instantiations) added
  then reverted; tree clean at 021744c1f.

## Validation

ffn_gate rows=512 (cosine vs launch_gguf_linear default): <3,4,4> 6.69 ms
cos 0.99992; <6,4,2> 6.23 ms cos NaN; <4,4,3> 8.02 ms cos 0.99992; <7,4,1>
6.68 ms cos NaN; <6,4,4> 6.91 ms cos NaN; <4,4,4> 8.33 ms cos 0.99992.
<8,4,1> does not compile (128 cols x 272 x 2 = 69632 B > 65536 LDS limit).

## Next

  measured gain (~7%, within run-to-run noise) does not justify it.
