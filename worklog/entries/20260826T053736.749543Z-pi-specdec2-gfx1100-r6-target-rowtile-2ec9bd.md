# Recover gfx1100 physical R6 target with C1 rowtile arithmetic

## Summary

Profiled the repaired physical C2/K2 R6 target against retained C1/K2 R3 on
W7900 and implemented the highest-value exact target lowering. The current
shared-B Q4T16 owner consumed 1,282.637 ms of 1,802.702 ms measured C2 cycle
wall (71.1%). Five actual rows6 shapes now reuse the registered rowtile whose
BF16 output is bit-identical to two independent C1 R3 owners; the dominant
K5120/N17408 gate/up shape uses the current-bit-exact single-wave sibling.
Shared-B stays registered for every miss.

The maximal six-shape rowtile screen reduced full-suite target/accept 60.1% and
raised C2/AR 0.544x to 0.861x, but failed one heldout strict ID and was narrowed
rather than retained. The hybrid is 10/10 exact, reduces target/accept
17.664->10.889 s (-38.4%), and improves physical C2 throughput
16.974->22.343 tok/s (+31.6%). It remains only 0.714x true AR, so physical
capability and automatic K0 do not change.
