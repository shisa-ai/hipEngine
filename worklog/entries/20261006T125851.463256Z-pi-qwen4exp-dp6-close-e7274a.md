# Close DP-6 as a measured low-ceiling candidate

## Summary

DP-6 is closed without a code change in this environment. The committed
ledger pricing establishes the eligible scope at **85.791 ms, 0.545%** of the
15,741.963 ms prefill kernel union: 58.036 ms SSM causal convolution, 26.122
ms q/k norm plus RoPE, and 1.633 ms KV store. The KV-store portion is only
0.010% and is not a meaningful fusion target.

The current tree has no `ssm_in` GEMM. The real first target is the Qwen4Exp
GDN layer's `attn_qkv` wide F16-input projection followed by fixed-K4 causal
Conv, as recorded in the bounded design entry
`20261006T113709.776876Z-pi-qwen4exp-dp6-fused-gdn-epilogue-db9804.md`. A safe
implementation would require a new fused GEMM+Conv raw-pointer kernel, state
boundary, registry leaf, runtime route, and native production gate. The
existing dense-wide projection is shared by unrelated consumers; editing it in
place would violate the fallback and ABI requirements.

No DP-6 implementation or default change is retained. The existing exact
projection plus exact Conv path remains unchanged.

## Changes

No source change is retained; this entry records the decision and blocker.
