# The rounded add+rmsnorm leaf gets the same fixed-5120 treatment

## Summary

`gguf_rounded_add_rmsnorm_bf16_f32_weight_kernel` was the last norm-family
item in the verifier without a fixed-5120 sibling: 945 calls per 12 steps
(78.75 per step) at 13.38 us each, **12.640 ms over 12 steps = 1.053 ms/step**,
2.9% of the 36.76 ms step. It is one block per row already, but it has the same
defect the plain generic owner had - a runtime-trip-count loop over
`hidden_size` with no register cache, so it reads the residual and the addend
twice and pays the nine-barrier reduction tree.

The fixed-5120 template now carries a second boolean, `kRoundSum`, which makes
both the reduction and the residual output consume
`bf16(bf16(x) + bf16(add))`. The `add+rmsnorm` layer gets a
`rounded_bf16_out_fixed5120_wave256` variant of that template, registered on
gfx1100 and selected by a new `GGUF_ROUNDED_NORM_RESIDUAL_DECODE_POLICIES`
shape table for `2 <= rows <= 8`.

Measured in an interleaved verifier A/B (three baseline runs, two candidate
runs, alternating): the family goes **12.640 -> 5.171 ms over 12 steps
(1.053 -> 0.431 ms/step, -59.1%, 13.38 -> 5.47 us per call)** and the whole
verifier **36.760 -> 36.321 ms/step (-0.44 ms/step, -1.19%)**, with the two
arms' bands not overlapping (baseline 36.6946 / 36.7925 / 36.7925, candidate
36.2715 / 36.3714).

The paired suite moves the way the mechanism predicts: the true-AR denominator
is **flat** because the rounded leaf is not reachable at rows 1 (its declared
envelope is rows 2-8), while MTP B3 rises on both UD artifacts.

## Changes

- `hipengine/kernels/hip_gfx1100/fused/gguf_ops.hip`:
  `gguf_norm_fixed5120_wave256_kernel` takes `template <bool kAddResidual,
  bool kRoundSum = false>`; the load path round-trips the sum through bf16
  before the accumulation and the epilogue when `kRoundSum` is set. New
  `hipengine_gguf_rounded_add_rmsnorm_bf16_f32_weight_fixed5120_wave256` entry
  with the same `2 <= rows <= 8` envelope as the generic rounded owner.
- `hipengine/kernels/hip_gfx1100/fused/gguf_ops.py`: new
  `gguf_rounded_add_rmsnorm_bf16_f32_weight_fixed5120_wave256` wrapper
  (`_prevalidated` aware, like its siblings) and its `KernelKey`
  registration under `("hip_gfx1100", "add+rmsnorm", "gguf_f32_weight",
  "rounded_bf16_out_fixed5120_wave256")`.
- `hipengine/kernels/hip_gfx1100/__init__.py`:
  `GGUF_ROUNDED_NORM_RESIDUAL_DECODE_POLICIES`, the same shape keys as the
  plain table but for rows 2-8 and with an `enabled_env` /
  `enabled_default` bisection switch.
- `hipengine/runtime/qwen35_gguf_runner.py`: `_gguf_norm_residual_decode_kernel`
  gains an optional `fallback` argument, selects its capability table by layer,
  honours `enabled_env` from the environment, and keys its policy memo by layer
  as well as shape so the plain and rounded layers cannot serve each other.
  `_rounded_add_rmsnorm_fn` becomes rows-aware and caches per row count.
- Tests: the wrapper contract and a real-tensor bit-identity test in
  `test_gguf_norm_residual_fixed5120.py`, the resolver and switch tests in
  `test_qwen35_gguf_prefill_scratch_liveness.py`, the capability tables in
  `test_gfx1151_backend.py`, and the stubs in
  `test_qwen36_gguf_rounded_next_rmsnorm.py`.

## Validation

Host `epyc`, AMD Radeon RX 7900 XTX (gfx1100), physical GPU1
(`HIP_VISIBLE_DEVICES=1`).

Bit identity, real tensors, `hidden_size=5120`, rows 2/3/4/5/6/8: the new leaf
and the generic rounded owner produce byte-identical `norm_out` and
`residual_out` at every row count, zero differing elements. The same test also
asserts the rounded residual is *not* the exact f32 sum, so the round-trip is
actually being exercised.

Microbenchmark, 400 launches per measurement, min of 7 rounds, real IQ tensors:
rows 3 **7.59 -> 4.23 us (1.80x)**; rows 2 1.83x, rows 4 1.78x, rows 8 1.83x.

Interleaved verifier A/B, `HIPENGINE_GGUF_ROUNDED_NORM_FIXED5120` = 0 (baseline)
or 1 (candidate), `scripts/gguf_mtp_verifier_rocprof.py --model
/models/gguf/Qwen3.8-27B-UD-Q4_K_M.gguf --quant gguf_ud_q4_k_m --mode
block-verify --block-rows 3 --block-verify-mode native --native-spec-target-cycle
--steps 12 --warmup 3`, same host and session:

| run | arm | avg_kernel_ms | rounded family |
| --- | --- | ---: | --- |
| 1 | baseline | 36.6946 | `gguf_rounded_add_rmsnorm_bf16_f32_weight_kernel`, 945 calls, 13.38 us |
| 2 | candidate | 36.2715 | `gguf_norm_fixed5120_wave256_kernel<true, true>`, 945 calls, 5.47 us |
| 3 | baseline | 36.7925 | generic |
| 4 | candidate | 36.3714 | `<true, true>` |
| 5 | baseline | 36.7925 | generic, 12.640 ms total |

Both arms report 985 kernel calls per step, so no launch was added or removed.
The family delta (-7.469 ms over 12 steps) is larger than the whole-step delta
(-0.44 ms/step = -5.27 ms over 12 steps), which is the expected direction when
a sub-window win is partly absorbed by run-to-run spread elsewhere.

Paired suite, `scripts/ud_mtp_paired.py --runs 2 --device-index 1
--expect-device "7900 XTX"`, against the previous retained row (UD-Q4_K_M MTP
49.371 / AR 32.750; UD-Q4_K_S MTP 48.294 / AR 32.098):

| arm | true AR | MTP B3 | MTP/AR |
| --- | ---: | ---: | ---: |
| UD-Q4_K_M | 32.750 -> 32.705 (-0.14%) | 49.371 -> 50.131 (+1.54%) | 1.5075 -> 1.5328 |
| UD-Q4_K_S | 32.098 -> 32.081 (-0.05%) | 48.294 -> 48.634 (+0.70%) | 1.5046 -> 1.5160 |
| plain-Q4_K_M (control) | 37.905 | 65.288 | 1.7224 |
| plain-Q4_K_S (control) | 41.198 | 70.070 | 1.7008 |

All four arms `binding_passed=True timing_evidence_valid=True`; both UD arms
`complete_exact` 0/20 divergent. The flat AR is the confirmation, not a
disappointment: the rounded leaf's envelope starts at rows 2, so a verifier-only
change must leave the single-row denominator where it was.

Tests: `tests/test_gguf_norm_residual_fixed5120.py`,
`tests/test_qwen35_gguf_prefill_scratch_liveness.py`,
`tests/test_gfx1151_backend.py`, `tests/test_qwen36_gguf_rounded_next_rmsnorm.py`,
`tests/test_gguf_ud_ffn_callers.py`, `tests/test_qwen35_gguf_geometry_policy.py`,
`tests/test_qwen35_gguf_verify_f32_attn_out.py` -> all pass.

The first attempt registered the variant without making the wrapper
`_prevalidated`-aware, and the profiled child died with `TypeError:
gguf_rounded_add_rmsnorm_bf16_f32_weight_fixed5120_wave256() got an unexpected
keyword argument '_prevalidated'`; every kernel reached through
`_gguf_norm_residual_decode_kernel` is called with that flag.
