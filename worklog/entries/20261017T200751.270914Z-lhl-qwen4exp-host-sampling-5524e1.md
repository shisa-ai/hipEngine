# Wire request-owned Flash-Next host sampling and logprobs

## Summary

Direct and resident Flash-Next text AR now use the shared host sampler for
non-greedy requests, processors and logprob collection. Raw greedy requests
keep compact output and device token reuse. Task 17 remains open for live
HTTP qualification and speculative-admission review.

## Changes

- Allocate request-owned RNG/history from `seed`/`row_seeds`; do not mix server
  request IDs or physical slots into an explicit seed. Validate seed-row counts
  before any prefill. Carry forced, thinking, sequence and text constraints in
  the same state rather than maintaining a second greedy processor chain.
- Read logits only for controlled requests, apply grammar before sampling, and
  feed the selected ID into the next model step with resident argmax disabled.
- Emit requested selected/top logprobs in direct/resident outputs and resident
  chunks. Truncate unpublished metadata on cancellation/reclamation. Finish
  mode distinguishes host sampling from greedy or grammar-controlled selection.
- Share direct/resident stop and EOS checks, including alternate EOS, minimum
  token counts and actual forced-token consumption. Zero generation budget
  avoids model work. Direct raw text retains its existing EOS representation.
- Reject unsupported multimodal sampling/logprobs before vision encoding rather
  than accepting a request that later fails response validation. This guard is
  not multimodal feature completion; PS11 owns its implementation/qualification.
- Remove the stale greedy-only unit expectation and update grammar mocks to the
  real mask/consume API. New tests use analytic distributions, not model scores.
