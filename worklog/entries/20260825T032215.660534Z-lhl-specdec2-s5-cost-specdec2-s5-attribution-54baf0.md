# Attribute physical SPECDEC2 accept and commit wall

## Summary

Expose the remaining complete-cycle components required by the S5 cost table.
Physical C2/C4 now separately report target verification, post-target candidate
readback, GPU accept plus strict CPU oracle, selected target-state/KV group
commit, and provider repair. The bounded telemetry also feeds
`SpecCycleTelemetry.accept_commit_seconds` and `scheduler_readback_seconds`.

## Changes

- Add per-request accept, selected-commit, and candidate-readback millisecond
  counters.
- Time physical device candidate materialization, group accept/oracle, and group
  selected state/KV commit separately.
- Preserve target timing as model verification only and provider-update timing
  as provider checkpoint repair only.
- Export every component through final response timing and resident observability.

## Validation

Focused MTP2 seam and strict-gate tests pass, as does Python compilation. A clean
C2/K2 hardware cell follows the implementation commit and must remain exact
while reporting all positive bounded components.
