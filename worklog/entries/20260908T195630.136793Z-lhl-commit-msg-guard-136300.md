# commit-msg guard banning bylines and session-id trailers

## Summary

Two 2026-09-03 commits landed on origin carrying `Co-Authored-By: Claude`
and `Claude-Session: https://claude.ai/code/session_…` trailers (the
session URL leaks a live session identifier — treated as a credential
leak, not style). History was rewritten with `git filter-branch
--msg-filter` over 277 commits (message-only; trees byte-identical) and
force-pushed (`90ffa9cf1` → `92fa0071c`). The trailers came from a
claude.ai web/cloud session, which does not read local
`~/.claude/settings.json`, so client-side settings cannot be the only
defense. This unit adds repo-side enforcement.

## Changes

- `scripts/check_commit_msg.py` — validates a commit message (file or
  stdin) and rejects: `Co-Authored-By:` trailers, `noreply@anthropic.com`,
  `Claude-Session:` trailers, `claude.ai/code/session_` URLs, and
  generated-by footers. Patterns are trailer-scoped so legitimate prose
  (`CLAUDE.md` references, `_session_` code identifiers) does not match.
- `scripts/install_commit_msg_hook.py` — installs `.git/hooks/commit-msg`;
  mirrors the worklog install-hook convention (no `core.hooksPath`, does
  not touch Git LFS hooks, refuses to overwrite an unrelated hook).
- `AGENTS.md` — Commit Messages section now bans session URLs explicitly
  and points at the guard.
- Hook installed in this clone.

## Validation

- Direct checker runs: byline / session-trailer / generated-footer samples
  each exit 1 with the right label; a clean message containing `CLAUDE.md`
  and `_resident_session_wmma_prefill_default` exits 0.
- Hook invoked as git invokes it (`.git/hooks/commit-msg <file>`): dirty
  message exit 1, clean message exit 0.
- Residual scan of full rewritten branch history: 0 matches for
  co-authored / claude-session / claude.ai/code / anthropic / generated
  patterns.

## Next

- Web/cloud Claude Code sessions use account-side settings, not this
  repo's hook; the same attribution settings should be checked there.
- Other clones should run `python3 scripts/install_commit_msg_hook.py`
  after pulling this commit.
