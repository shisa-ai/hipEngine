# Repair host logprob underflow and constrained top-k

## Summary

Task 17's shared-sampler audit found two numerical defects before Flash-Next
integration: finite low-probability forced tokens could raise `math domain
error`, and constrained sampling ignored `top_k` on small candidate pools.
Both now satisfy analytic CPU tests; no GPU kernel changed.

## Changes

- Compute greedy/forced logprob summaries in log space. Finite tail logits
  retain finite logprobs even when their exponentials underflow; masked IDs
  remain absent. Do not invent a probability floor.
- Apply the requested top-k limit in both constrained-candidate search paths,
  preserving lower-token-ID tie ordering.
- Add six regression cases in `tests/test_unit_sampling_probability_edges.py`.
