# Expose staged MTP ownership telemetry in suite

## Summary

Extended the canonical suite harness to capture the staged resident runner's
actual completion metadata and tracked allocator deltas around every arm. This
makes T1.1-T1.3 mechanical: OI-3 streaming rows/carried bytes, physical
proposal/target rows, candidate device handoff/D2H, GPU accept, selected commit,
recovery/failure, fallback reason, and resource ownership come from the runner,
not response labels.

## Changes

- Traverse LLM -> service driver -> resident runner to call
  `observability_snapshot()` and retain only the current arm's completed rows.
- Record memory before/after/delta for total/current bytes and allocation counts.
- Added focused nested-owner/compaction and memory-delta tests.
