# Keep HTTP prefix caching opt-in after the W7900 production check

## Summary

The user requested HTTP prefix caching on by default if qualified. The direct
engine uses `PREFIX_CACHE_DEFAULT = "radix"`, but the server dataclass and CLI
independently default to `off`. The September 19 engine change did not update
these overrides. An attempted alignment passed CPU/server tests, but W7900
production numerical evidence blocks HTTP default-on. The attempted runtime
and public-prose changes were removed; explicit radix opt-in is unchanged.
