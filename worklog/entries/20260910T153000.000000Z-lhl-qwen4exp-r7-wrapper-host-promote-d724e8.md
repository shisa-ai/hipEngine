# R7 wrapper-host route: first decode TG promotion since R2e

## Summary

First decode TG promotion since the R2e seven-promotion state. With the R11 GEMV
pair closed and rejected at gates, R7 screened the wrapper-host route to
attribution and landed a gated candidate: the serving path was issuing 24 x 8-byte
blocking H2D copies per decode step (median 23.1us, ~0.55ms genuine plus overlap
loss), all from `Qwen4ExpAttentionDeviceState.set_position` called per QSA layer,
and all carrying the same value.

The fix uses a shared interleaved [position, context] int64 region (192B): `step()`
prepares all 12 states with ONE H2D and passes `position_prepared=True`, skipping
the per-layer `set_position`. It is bit-exact (identical token digest across all
fixture cases, 3 reps/arm), reduces the copy surface from 27 to 4, and measured TG
A/B median -0.77 ms/token (~1.3%). Promoted default ON with opt-out `=0`.

The v7 retention packet gives new baselines of record: hipEngine TG
20.02/19.53/19.14 tok/s at p512/p1024/p4096 (+1.6/+1.4/+3.6% over
19.70/19.26/18.48).

## Arc

R10's measured result left two decode routes: kernel efficiency (R11 GEMV
pair - closed, rejected at gates) or wrapper host work. R7 ran the
wrapper-host screen to attribution:

1. **API-trace screen** (`18076ed3d`): rocprofv3 hip-api trace around 64
   decode steps. Serving path already uses device-argmax
   (`capture_logits=False` + `token_id_resident=True`); blocking hipMemcpy
   durations are stream-wait dominated, not host cost; per-step surface
   447 kernel launches + 20 graph launches + ~15 copies.

2. **Mechanism identification** (`0c50bc876`): Python-boundary probe with
   traceback. 24 x 8-byte blocking H2D per step (median 23.1us, ~0.55ms
   genuine + overlap loss), all from
   `Qwen4ExpAttentionDeviceState.set_position` called per QSA layer
   (12 layers x position+context, unique state indices - no call-site dedup
   possible). All 24 carry the same value; position advances by 1/step.

3. **Gated candidate** (`82edb5cfd`): shared interleaved [position,context]
   int64 region (192B); `step()` prepares all 12 states with ONE H2D and
   passes `position_prepared=True` (pre-existing mechanism flag) so per-layer
   `set_position` is skipped. Gates: bit-exact (identical token digest, all
   fixture cases, 3 reps/arm); TG A/B median -0.77ms/token (~1.3%); copy
   surface 27 -> 4. Prefill paths unchanged (set_position on views is
   per-slice correct).

4. **Promotion** (`b7e9f19b9`): default ON, opt-out `=0`. First profile
   change since the R2e seven-promotion state.

5. **Post-promotion retention v7** (`e3a13c610`): fresh three-engine packet
   at the promoted default. hipEngine TG 19.70/19.26/18.48 ->
   20.02/19.53/19.14 tok/s (+1.6/+1.4/+3.6%). Packet hipEngine PP dropped
   at p1024/p4096 (-5.8/-9.1%) - discriminated as environmental by a direct
   interleaved same-process PP A/B (all deltas within +/-0.85%, median
   ~0.1%) and comparator corroboration (halo-box-hip, untouched binary,
   dropped PP simultaneously with 21% CV; vulkan stable). halo-box-hip noisy
   PP window recorded as packet caveat.

## Validation

- API-trace screen: the serving path already uses device-argmax
  (`capture_logits=False` + `token_id_resident=True`); blocking hipMemcpy
  durations are stream-wait dominated rather than host cost; the per-step surface
  is 447 kernel launches + 20 graph launches + ~15 copies.
- Mechanism identification: 24 x 8-byte blocking H2D per step (median 23.1us), all
  from `set_position` called per QSA layer (12 layers x position+context, unique
  state indices, so no call-site dedup is possible), all carrying the same value,
  with position advancing by 1 per step.
- Candidate gates: bit-exact (identical token digest, all fixture cases, 3 reps
  per arm); TG A/B median -0.77 ms/token (~1.3%); copy surface 27 -> 4; prefill
  paths unchanged (`set_position` on views is per-slice correct).
- Retention v7 (fresh three-engine packet at the promoted default): hipEngine TG
  19.70/19.26/18.48 -> 20.02/19.53/19.14 tok/s (+1.6/+1.4/+3.6%).
- The packet's hipEngine PP drop at p1024/p4096 (-5.8/-9.1%) was discriminated as
  environmental by a direct interleaved same-process PP A/B (all deltas within
  +/-0.85%, median ~0.1%) plus comparator corroboration (halo-box-hip, untouched
  binary, dropped PP simultaneously with 21% CV; vulkan stable).
- Stated caveat: the halo-box-hip noisy PP window is recorded as a packet caveat.
