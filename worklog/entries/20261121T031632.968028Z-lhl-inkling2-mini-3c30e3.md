# Add Inkling 2 Mini CPU vision inference

## Summary

Expose the original checkpoint's vision tower through `LLM.generate_multimodal_detailed()` on the CPU reference backend.

## Changes

- Prepare one RGB or RGBA image in merge-block order, preserving edge padding. Apply the learned, interpolated position grid and axial rotary embeddings before the vision transformer and projection to text width.
- Render the original chat template for a plain image prompt, or accept an explicitly placed image placeholder in a formatted prompt. Replace exactly one placeholder span with the projected image embeddings and count the expanded span in request context and usage.
- Use the [Transformers release encoder and processor](https://github.com/huggingface/transformers/tree/6173a2f679ff4ed393afc499aefc569da7e68bc1/src/transformers/models/inkling2) as the architecture reference.

## Validation

- All 21 focused Inkling tests passed, including edge padding, patch order, position interpolation, placeholder expansion, and embedding injection.
- Encoded a 40-by-40 image with the original vision weights and confirmed finite output of shape `(1, 2304)`.
- `LLM.generate_multimodal_detailed()` on the original checkpoint produced ` red` (token `150682`) for a red RGB image and the formatted continuation `The color is`. The default CPU suite and fixture and registry checks passed.
