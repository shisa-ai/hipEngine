# Close c8 GDN recurrence attribution

## Summary

Closed #66 by attributing the complete c8 linear-attention state family. The
named segmented kernel fuses recurrent update, Q/K normalization, RMSNorm,
gating, output, and canonical state commit: 7.813 ms across 48 layers. Indexed
Conv is only 0.329 ms. There is no separate multi-ms state-copy/commit bucket.

Exact FP32 state is 48 V heads ×128 K ×128 V = 786,432 elements/request/layer.
The algorithm must read state for the K dot, then read and write it after delta
is known: at least 3.375 GiB across c8×48 layers, ~463.8 GB/s. A 750 GB/s
traffic floor is 4.832 ms, but the 2.981 ms sum gap is diagnostic and not a
complete-wall promise.

## Changes

- Added compact attribution artifact and updated Concurrency2/changelog.
- No kernel/default change. Conv is too small; exact state cannot fit registers/
  LDS, and removing the second traversal changes the recurrence algorithm.

## Validation

- Trace: local128/grid X1024/Y48, VGPR80, scratch0; 158.961/162.881/168.001 us
  min/median/max per layer.
- Focused indexed/segmented exact correctness bundle: 5 passed.
- Existing c1/c4/c8 slope: 0.737/4.891/7.813 ms; c1 uses the scalar owner and
  c4/c8 the segmented owner.
- Evidence: `benchmarks/results/2026-08-22-concurrency2-qwen38-c8-gdn-attribution.json`.
