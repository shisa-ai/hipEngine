# Share Inkling expert weights across four prompt rows

## Summary

Use four-row tiles for prompt expert projections to reuse packed weights beyond pairs. Keep the same accumulation order within each route and write outputs in their original positions.

## Changes

- Generalize the same-expert route table and kernel to compile two- and four-row tiles. The standard prompt path selects four; the one-row decode, short verification, and original grouped fallback do not take the tiled kernel. Incomplete tiles emit only valid routes.
