# My 80ms prefill target was an inference; the cost is inside the WMMA kernel

## Summary

`20260830T153158…` ended with a target: "remove roughly 80 ms of fixed per-request
prefill cost at C1,
**or overlap it** the way grouping already hides it by C4". That target was an inference
I dressed as a
measurement. The campaign already has the cost localized, and it is not host-side
overhead: the small-row
WMMA prefill itself carries a **~252-271 ms fixed cost**
(`benchmarks/results/2026-08-30-w7900-q4km-all-gemv-prefill-arm-rejected.json`). At C1 my measured
admission wall is 302.99 ms for 44.9 prompt tokens, so the kernel accounts for
essentially all of it and
there is little left for overlap to recover.

## Changes

- No code change. Withdraws an unsupported optimization target and redirects #12.

## Reconciliation

- Mine, this session: C1 admission **302.991 ms** at 44.9 prompt tokens, peer equivalent ≈ 223 ms
  (44.9 / 200.946 tok/s), so the gap is 70-80 ms at C1 and 1.47x worst at C2.
- Already measured: WMMA prefill wall **0.2950 s at 42 tokens** and **0.7115 s at 285
  tokens**, with the
  285-token arm reproducing an independent run to **0.13%**. All-GEMV is 1.57x slower at
  42 tokens and
  3.20x at 285, so the route choice is correct and the route lever is closed.
- Putting them together: 295 ms of the 303 ms C1 wall is the prefill kernel. My "~80 ms of
  fixed cost
  that could be removed or overlapped" is therefore a *residual*, not an identified
  overhead, and calling
  it the target invited the next unit to chase wave overlap in a path that is ~97% kernel.
- Correct target: the small-row WMMA prefill's fixed cost, roughly **252-295 ms where peers achieve
  ~223 ms** for the same 44.9 rows. That is kernel work behind a strict RED gate, exactly as the
  all-GEMV artifact concluded. The 16x16 tile wasting 12 of 16 rows at ~45 rows is the
  named mechanism.
- What #12 is not: a route switch (all-GEMV rejected), an overlap gap (kernel-bound at
  C1), or a noise
  artifact (0.734x / 0.681x / 0.892x against 1.1% / 5.2% / 2.9% repeat spread).
