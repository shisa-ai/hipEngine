# Qwen4Exp P10 structural depth census

## Summary

The qualified 4K/16K/64K natural-retrieval artifacts did not retain the structural owner census required by P10. Existing `rocprofv3` evidence measures QSA score/top-k, selected sparse attention, PLE, graph launches, and KV-related work through live 4097 only. This unit adds an opt-in census at each natural retrieval depth; it does not change inference behavior or make a performance claim.

## Changes

- Added `--depth-profile` to `scripts/qwen4_exp_qsa_retrieval_gate.py`.
- The census records score rows, selected-token locality and 4 KiB page coverage, per-layer selected KV row bytes, all-QSA-layer live and allocated KV bytes, PLE table telemetry, and MoE graph-cache counters.
- Added deterministic locality tests, including empty-selection behavior.
- Declared scope: diagnostic instrumentation only. W/C/O/s: no new data movement, copies, overlap, or synchronization in the default route; the opt-in route reads the already-required selection and runtime metadata after prefill. Arithmetic class: exact integer census with descriptive floating-point gap means. Strict fallback: omit `--depth-profile`. Overlap exclusions: model arithmetic, kernel dispatch, retrieval output, and measured throughput.
