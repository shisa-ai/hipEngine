# Close gfx1151 RDNA3 tuning application campaign

## Summary

Closed the gfx1151 application campaign created by the RDNA3 tuning-guide audit.
Three scoped changes are retained: the physical-C8 Q6 LM-head rows-8 owner, an
explicit profile-owned C8/K3 MTP cell that leaves C5-C7 on AR, and a
packed-prefill final-output mask that skips intermediate output heads. The
persistent-worker candidate is rejected because the staged product route does
not construct generation pools and its direct-control A/B is not consistently
positive on complete wall.

Every retained behavior is package/profile scoped, preserves its registered
strict or unoptimized fallback, and has a compact artifact plus benchmark
rollup entry. gfx1100 keeps its independent defaults and has a current transfer
packet rather than copied gfx1151 policy.

## Changes

- Corrected the refactor ledger's two legacy MTP stream rows: they now identify
  direct compatibility/control ownership instead of the staged server and no
  longer recommend a persistent product scheduler from stale evidence.
- Added no runtime changes in this closure unit.
