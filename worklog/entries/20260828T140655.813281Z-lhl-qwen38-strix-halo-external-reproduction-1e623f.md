# Qwen3.8 Strix Halo external reproduction campaign

## Summary

Completed the same-host Qwen3.8-27B Strix Halo external implementation
reproduction campaign on physical host `gfx1151` (Ryzen AI MAX+ 395, Radeon
8060S, 128 GB). Exact source pins and model SHA-256 values are recorded in
`benchmarks/results/2026-08-28-gfx1151-qwen38-external-reproduction-survey.json`.
The public survey now separates claimed speed, local speed, timing boundary,
output validity, and deployability for every route.

The fastest tested route without a lifecycle blocker was `q38rocm` v1.5.2
strict MTP K4: 14.782 AR to 35.575 arithmetic / 32.969 token-weighted decode
tok/s on the ten-prompt category/heldout suite, with 24.294 complete-wall
tok/s and 62.35% acceptance. Laurent adaptive DFlash2 was faster in fresh
processes—56.532 tok/s for complete valid 12-object JSON and 37.752 arithmetic
/ 34.483 token-weighted decode tok/s on the diverse suite—but failed sequential
serving correctness. Its locally observed 66.838 tok/s JSON row repeated prose
from the preceding request; the fork's length-only guard incorrectly passed.
