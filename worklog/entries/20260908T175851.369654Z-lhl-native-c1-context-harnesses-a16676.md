# Add reproducible native C1 context qualification harnesses

## Summary

Investigate whether the August p121/p128 native NaN/sentinel failure persists
after the September 8 scratch/journal repair. Keep production policy at 95
while diagnostic processes explicitly set both native limits to 256.
Original varied-prompt raw files no longer exist, so use recorded exact token
lengths and retain complete deterministic input IDs for the new reproduction.

## Changes

- Add scripts/gguf_native_context_gate.py around the existing dense AR/MTP
  suite. Record process-local overrides, restored prior limits, concrete
  identity, complete prompt IDs, actual native/serial call counts, graph
  submissions/extents, errors and whole-card memory. Fixed-length cyclic
  prompts are correctness diagnostics; performance claims are forced off.
- Add scripts/gguf_native_context_state_gate.py: independent scalar reference
  sharing immutable model weights, exact full-logit and state/KV fingerprints,
  forced reject/partial/full chains, native eager and graph modes, N1 logits
  and N2 accept/commit, rollback after selected-state commit, allocation drain.
  Helpers test unchanged candidate prefixes and cursor/component mismatch.
- Add CPU tests for override restoration, input validation and state helpers.
  No runtime selector, kernel, model or arithmetic changes.
