# DFlash2 QKV projection routed to WMMA dense kernels (acceptance-neutral, exact)

## Summary

First scoped lever of the DFlash2 revival (task #15). rocprof of the DFlash2 B3
cycle showed the block QKV projection used `dflash_qkv_proj_bf16_mixed`, a naive
scalar GEMV (one workgroup per output element, weight row re-read per draft row,
shared-memory tree reduction) running at **5.4 ms/call ≈ 18× the bandwidth floor**
(405 ms over the profiled run, 10.5% of kernel time). The drafter already ships an
efficient WMMA-tiled dense kernel (`dflash_dense_bf16_to_{bf16,f32}_wmma`, weight
read amortized over a 16-row tile). Routed the block Q/K/V through it: Q/K via the
F32 WMMA kernel, V via the BF16 WMMA kernel (same output dtypes as before).

Full mtpbench suite (Q4_K_M, gfx1151 zbook, B3, 3 reps), back-to-back with the
same driver as the task #13 baseline:

| | DFlash2 tok/s | AR tok/s | ratio | acceptance | exact |
| --- | ---: | ---: | ---: | ---: | --- |
| baseline (naive QKV) | 9.50 | 11.20 | 0.848 | 2.319 | all |
| QKV-WMMA | 9.72 | 11.25 | 0.864 | 2.319 | all |

Acceptance IDENTICAL (2.319 tok/cycle), all rows AR-exact. ratio_vs_ar 0.848 →
0.864 (the ratio controls for AR thermal drift; absolute tok/s is thermally
confounded on the zbook). The cycle-level gain is modest because QKV is ~10% of
the cycle; the kernel-level fix removes the 18×-floor scalar GEMV. The draft only
proposes; the exact target verify keeps DFlash2 IDs == true AR.

## Changes

- hipengine/speculative/dflash2_native.py: `_run_attention` block Q/K/V now calls
  dflash_dense_bf16_to_f32_wmma (Q,K) + dflash_dense_bf16_to_bf16_wmma (V) instead
  of dflash_qkv_proj_bf16_mixed. Removed the unused mixed-kernel import. The
  context-projection path and the rest of the drafter are unchanged.
- benchmarks/results/2026-11-08-gfx1151-qwen38-27b-dflash2-qkv-wmma.json:
  full-suite validation artifact (relative/internal, performance_claim false).

## Validation

- Single prompt: DFlash2 vs AR greedy 40/40 agree (1.000); acceptance 2.67.
- Full mtpbench (10 prompts x 3 reps): exact_all_reps=true on every row;
  mean_acceptance 2.319 == baseline; ratio_vs_ar 0.864 vs 0.848.
- py_compile clean. No new kernel (reuses the existing registered WMMA dense
  kernels); the naive mixed kernel remains for any other caller.
