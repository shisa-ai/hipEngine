## Validation

- Canonical 996-row shared-chain envelopes (pair / dual-only / fast-down-only vs
  incumbent): all bars pass (max KL 1.96e-2; flips 7/5/3; both arms
  deterministic).
- Cross-run determinism: bit-identical per-row KL/top-1 across independent
  process runs (4 identical candidate measurements).
- Non-exact state gate: passed 12/12 - graph keys carry the route flags per arm
  (48 captures + 336 replays per arm), `run()` 156/step, exact-tree down never
  engaged, off/on/off/on returns identical bytes per arm.
- Pair vs strict teacher (6.1 definition, 996 rows): above the frozen bars, but
  so is the incumbent control (mean 1.28e-3, max 5.26e-2, top-1 0.98494) - a
  pre-existing production-stack condition, with the R11 delta negligible (mean
  +1%, max lower, top-1 identical).
- Serving-path A/B (same residency, 3 reps/arm, drift mode): +6.5% TG geometric
  mean (by shape +6.8/+6.3/+7.5%), prefill neutral, within-mode deterministic,
  cross-mode output drift in 8/12 cases (expected for a non-exact package).
- **Decisive failure**: the 18-prompt admission task suite (including 8 heldouts)
  failed for all packets - max KL 0.121-0.431 against the 5e-2 ceiling (dual-only
  worst at 0.431, fast-down-only 0.121, pair 0.357), p99 2.4-2.9e-2 against the
  2e-2 bar, and top-10 overlap degrading to 6-7/10. The worst rows are not
  near-ties (decision margins 2-3 with unchanged top-1, i.e. genuine tail-shape
  drift concentrated in mixed_ja_en task text), and per-packet attribution rules
  out promoting the dual leg alone because it carries the largest tail.
- Recording gap, stated: the state gate's numeric state-drift field recorded NaN
  (view arithmetic on non-float buffers), so state drift is evidenced by the
  digest determinism checks rather than by numeric magnitudes.
