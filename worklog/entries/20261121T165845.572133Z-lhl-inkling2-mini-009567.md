# Decode GGUF NVFP4 blocks in the CPU reference

## Summary

Add a CPU reference for decoding GGUF NVFP4 blocks without confusing their split-nibble layout with the adjacent pairs in the original Inkling checkpoint. The decoder operates on the requested byte rows; model-specific outer scales remain the caller's responsibility.

## Changes

- Register NVFP4 with the GGUF CPU dequantizer. Preserve GGML's unsigned scale rules, including its `0x7f` zero and signed output zero from multiplying a negative weight by zero.
- Cover row shape, both nibble streams, per-group scales, subnormals, and zero encodings in the quant layout tests.
