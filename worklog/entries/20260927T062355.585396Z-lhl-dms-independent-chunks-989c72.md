# Screen independent recurrent prefill subchunks

## Summary

Independent recurrent subchunks avoid the full-attention regression of a shared
small-chunk override. The external diagnostic passes an initial cached-output
screen. No production implementation or arithmetic promotion has landed.

## Changes

External `profile-prefill-independent.py` wraps recurrent prefill only, slicing
hidden input/output rows into 256-row subchunks, updating shared scratch metadata
for each call, and restoring outer metadata in `finally`. Full attention keeps
its original partition. The wrapper refuses FP32 hidden buffers and per-row
state captures; it is a bounded diagnostic, not a general implementation.
Scripts and artifacts live under
`~/gate-runs/qwen38-edge-cache-repaired-20260926/`.

## Validation

Physical host `gfx1151`, AMD gfx1151, Qwen3.8-27B Q4_K_M, production, BF16 DMS,
radix, temperature zero. Commands use `bash /tmp/t17-env.sh python` followed by
the script path above. Exact model/sidecar paths and constructors are in scripts.

- Instrumented 4,097-token prompt, eight output-token limit: original recurrent
  layer-method total 10.860 s, candidate 9.490 s; full attention 3.017 s versus
  3.002 s. Baseline `profile-prefill-layers.py`, candidate
  `profile-prefill-independent.py`; artifacts `prefill-layer-profile/layers.json`
  and `prefill-independent-profile/layers.json`. These are single-prompt
  synchronized diagnostic timings, not an end-to-end speedup claim.
- `check-independent-chunks.py` completes eight public MTP requests at
  4,095/4,097/4,100/6,145 prompt tokens with 8/12 output-token limits. Generated
  IDs and reused-prefix counts exactly match the saved pre-change cached arm;
  tracked device allocations return to zero. Artifact:
  `independent-chunks-public.json`. This repetitive-prompt screen is not a
  category/heldout numerical gate.

## Next

Run multi-category teacher-forced logit comparisons and heldouts across lengths
before implementing/promoting partition changes. Account for FP32 hidden planes,
per-row state capture, cache boundaries, and shared scratch metadata explicitly.
Dense INT8 repair and final six-arm results remain open.
