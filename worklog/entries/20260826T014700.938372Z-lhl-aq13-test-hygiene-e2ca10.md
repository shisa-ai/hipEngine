# Repair AQ13 focused baseline test hygiene

## Summary

Repaired the ten deterministic AQ13 focused failures without rerunning the
10,510-node broad suite. Four failures were stale assumptions about whichever
local GGUF happens to be installed; two were pre-Generation-2 fake-session
fixtures; two were a gfx1100-only Laguna strict RED incorrectly executing on
this gfx1151 host; and two were stale Qwen3.5-0.8B intermediate-layer attention
fixtures. The attention work also exposed and fixed one real host-side scratch
allocation bug: the standalone batched full-attention layer probe built RoPE
arrays but did not allocate/upload their device tables.

No kernel arithmetic, dispatch policy, model outputs, or benchmark result was
changed. The Laguna exact-parent RED remains active on its qualified gfx1100
hardware instead of being weakened to a tolerance on gfx1151.

## Changes

- Made the local Qwen3.6 dense capability test inventory-driven. A file without
  one trailing NextN block must advertise no public MTP tensors; a file with one
  validates the actual ignored block ID and required names.
- Made Qwen3.6 MoE materialization compare the target plan with only AR-owned
  tensors. A trailing ignored NextN block is independently owned and must not be
  counted as a target-plan omission. The llama-compat residency test always
  validates target sole ownership and validates a draft census only when the
  installed dense file actually contains NextN.
- Updated the public `LLM.generate()` fake session to the Generation-2 contract:
  shared owner plus slot views, deferred native single-row prefill, position
  tracking, idempotent reset/close, and explicit `LLM.close()`. Importing the
  Qwen GGUF generation module at collection time makes the pytest registry
  baseline complete. `register_builtin_generators()` now also refreshes the
  three idempotent runtime-profile plans after its model modules are loaded, so
  a registry reset between tests cannot make Qwen3.8 strict resolution
  order-dependent.
- Scoped the Laguna local32 fixed-metadata Q5/Q6 exact-parent test to gfx1100,
  matching the only backend where that variant is registered/qualified. On
  gfx1151 it had 31-37% differing F32 words at only about 5e-7 to 1e-6 relative
  error; those numbers are not relabelled as acceptable strict drift. The test
  skips there and remains byte-exact on W7900/gfx1100.
- Fixed `_GGUFFullAttentionPrefillScratch.allocate()` to allocate and upload the
  RoPE cosine/sine tables already computed for the standalone batched layer
  probe. Before the fix, the rows-at-threshold path dereferenced
  `cos_table=None`.
- Kept the Qwen3.5-0.8B full-attention hidden-state allclose and KL <= 0.05
  distribution gates, but removed top-1 assertions made by applying the output
  head to an intermediate layer. That is not a generation boundary and its
  near-tied synthetic winner changed despite the declared hidden/distribution
  gates passing; final-model top-1 remains covered by generation trajectory
  gates. Fixed the first test's `finally: pass` so every external scratch/buffer
  is released even when a numerical assertion fails.
