# Correct the resident block message-row comparison

## Summary

The "message rows disagree by 37" finding in `20261124T110457.886048Z-lhl-inkling2-mini-da3517.md` was a comparison bug, not a kernel result. The host's `_read_blocks` returns `(rows, queries, hidden)` and the arena stores `(queries, rows, hidden)`, so the measurement compared two different axes. No defect in the message read is confirmed.

## Changes

- The restart window's stack entry is exact: the arena's row at `start` matches `_rms` of the host capture at the layer-12 boundary visit to 7.6e-06.
- The restart's partial row matches no single capture index closely: 1.3e+01 against the nearest, while consecutive visits differ by 1.8e+02 to 2.9e+02. The capture trace is an ambiguous oracle across a restart because the restart replaces the hidden state, so the value the host records for that visit is the one the pass discards.
- The block hidden state after 19 visits is 1.5e+00 from the host capture at that index, against a per-visit change of about 1.8e+02. The traversal is therefore close, not the 2.8e+02-off result the earlier entry reported.
