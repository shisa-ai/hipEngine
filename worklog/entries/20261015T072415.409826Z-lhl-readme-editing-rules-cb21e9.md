# Codify root README editing rules and force agents to read them

## Summary

The root README has been degraded repeatedly by agents appending provenance,
methodology caveats, and restated facts to a page the lead had already
tightened. Two cleanup passes in this session removed the damage; this unit
addresses the cause.

New normative document `docs/HOWTO-README.md` states the rules with real
before/after examples drawn from this repository's history, and `AGENTS.md` now
requires reading it before any `README.md` edit.

## Changes

- **`docs/HOWTO-README.md`** (new, `status: normative`). Rule 0 sets the default
  action to not touching the file. Rules 1-9 cover one-fact-one-place, stating
  results rather than measurements, the test for whether a caveat earns its
  place, not repeating headings or table headers, banned internal vocabulary
  (`retained`, `qualified`, `certified plan`, `migration path`, `source-pinned`),
  no navigation sentences duplicating the section below, no cross-section
  restatement, moving removed detail to the report instead of deleting it, and
  the fact that the performance block is generated. Ends with an eight-item
  self-check and the list of gates that enforce it.
- **`AGENTS.md`**: added a scoped-playbook callout at the top of the file,
  alongside the existing `docs/OPTIMIZATION.md` callout, that requires reading
  `docs/HOWTO-README.md` and states the default of not editing the README. Added
  step 4 to "Before Starting" (read the rules in full, run the self-check, grep
  for every fact, confirm removed detail is recorded elsewhere, stop if the
  change was not requested). Added the re-read-against-the-rules step and the
  two README gates to "After Changes". Added a Key Files row.
- **`tests/test_integration_benchmark_readme_sync.py`**: new
  `_assert_no_duplicate_prose_sentences`, which normalizes prose sentences
  (excluding tables, headings, fenced code, and HTML markers) and fails when the
  README states the same sentence twice. Extended the retired-phrase guards with
  `will not silently use PyTorch`, `can still change before 1.0`, and
  `keep a conservative context limit`. Asserts `docs/HOWTO-README.md` exists and
  that `AGENTS.md` references it, so the pointer cannot be dropped silently.
- **`docs/README.md`**: regenerated index (158 documents).

- `uv run pytest tests/test_integration_benchmark_readme_sync.py

  `doc-path-drift` findings. Fixed at the source by writing those four paths
  repo-relative (`hipengine/kernels/...`), which is what the check wants and
  matches the file's existing style; the findings are gone. Remaining untriaged
  rows are pre-existing and were confirmed present on a clean `HEAD` worktree:
  3 `doc-path-drift` from `docs/PLAN.md`, 5 `stub`, 4 `ungoverned-flag-branch`,
  1 `unguarded-hip-test`. The `scan` regeneration was reverted rather than
  committed, because gathering is a separate audit workflow and mixing it into
