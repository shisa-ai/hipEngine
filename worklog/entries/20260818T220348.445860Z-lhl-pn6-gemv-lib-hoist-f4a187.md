# PN6: hoist GEMV library builds — launch_gguf_linear host-bound, +2.59 ms/tok

## Summary

The `launch_gguf_linear` T16 GEMV slice is **host-dispatch-bound**, not
GPU-bound as the PN4 checkpoint concluded. 141 launches/step each re-ran
`build_X(load=True)` (~19-29 us/call of `build_hip` fast-path overhead even on a
loaded-library cache hit — the cost is cache-key construction + env version
resolution, not a compiler probe). Hoisting the library handles for the three
hot families (`gguf_q8_0_t16`, `gguf_q6_k_t16`, `dense_gemv`) into module caches
recovers **+2.59 ms/tok (+8.8%)** on a counter-rotated exact A/B (29.42 -> 26.83
ms/tok); the real-hoist validation run hit 25.69 ms/tok (~+3.7 ms). This is the
largest single-item win of the production-numerics campaign so far, larger than
the PN5 router hoist (+957 us).

## Changes

- `hipengine/core/build.py`: `_resolve_compiler_version` now caches an explicit
  `compiler_version` as the process default for that compiler (skipped under
  `dry_run`), so a later per-call `build_X(load=True)` (which passes
  `compiler_version=None`) resolves to the pinned version and hits
  `_LOADED_LIB_CACHE`. Latent cross-machine reproducibility fix (pinned !=
  installed); on this ZBook the installed hipcc matches the pinned file, so the
  probe and pinned versions already matched and this change is a no-op here.
- `hipengine/kernels/hip_gfx1100/quant/gguf_q8_0_t16_gemv.py`:
  `_q8_0_t16_gemv_library()` memo; 4 per-call `build_gguf_q8_0_t16_gemv(load=True)`
  sites -> memo.
- `hipengine/kernels/hip_gfx1100/quant/gguf_q6_k_t16_gemv.py`:
  `_q6_k_t16_gemv_library()` memo; 5 per-call build sites -> memo.
- `hipengine/kernels/hip_gfx1100/linear/dense_gemv.py`: `_dense_gemv_library()`
  memo; 10 per-call build sites -> memo.
- Memos mirror the PN5 router pattern and only memoize the default-params build;
  callers with custom `cache_root`/`compiler_version`/`profile`/`require_cached`
  still call `build_hip` directly (unchanged).
- `tests/test_build.py`: two new unit tests for the explicit-version ->
  process-default cache behavior (populate on explicit, resolve on None, strip,
  no dry_run side effect).
- `scripts/pn6_gemv_dispatch_audit_probe.py`: audit probe (per-family build cost,
  per-call host time, no-op A/B).
