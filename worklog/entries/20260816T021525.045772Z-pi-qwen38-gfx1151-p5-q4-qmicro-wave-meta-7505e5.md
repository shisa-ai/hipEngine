# Screen wave-shuffled qmicro Q4 decode

## Summary

Reject and remove the wave-shuffled qmicro Q4 gate/up package. The new rows1
consumer is BF16-bit exact and improves three cache-cold actual layers
**1.423808 -> 1.381499 ms (1.03063x, 45/45 wins)** while reducing resident
pair bytes **103,055,360 -> 100,270,080 (-2.70%)**. It projects a material
**1.1518%** selected 4K kernel-wall saving, so it correctly advanced to the
operation-completeness gate.

That gate fails. The sole qmicro payload must also serve native B1-B3 rows and
bulk prefill. Exact rows2/3/4 qmicro rowtiles regress the three-layer median
sums **1.430859 -> 1.828357 ms (0.78259x)**, **1.422347 -> 1.831333 ms
(0.77667x)**, and **1.425364 -> 1.881931 ms (0.75739x)** with **0/135** paired
wins. Exact rows512/1K/4K WMMA consumers also move the aggregate three-layer
boundary **20.323778 -> 20.454539 ms (0.99361x)**, **40.443130 -> 40.569207 ms
(0.99689x)**, and **161.069435 -> 161.123611 ms (0.99966x)**. Retaining only
the c1 win would therefore require the forbidden standard-T16 sidecar or
regress mandatory operation classes.

## Changes

- Added a transient c1 split-weight dataflow in which each eight-lane K32 group
  loads compressed scale/min records once and exchanges decoded quartets with
  wave shuffles. It preserved the retained residual-Q8_1x2 K/FMA/reduction and
  BF16/SiLU boundaries without LDS metadata or per-K256 barriers.
- Advanced the admitted c1 leaf to transient exact qmicro rows2-4 row-reuse and
  rows512/1K/4K dense dual-WMMA consumers. Both used the same sole 2,304-byte
  K256/N16 payload and no standard-T16 sidecar.
- Removed all transient kernels, wrappers, registrations, and RED/GREEN tests
  after the operation gate failed. Runtime dispatch, materialization, graph
  policy, and production residency remain unchanged.
- Preserved compact evidence at
  `benchmarks/results/2026-08-16-gfx1151-qwen38-27b-q4-qmicro-wave-meta-rejected.json`.

## Validation

- RED: focused collection failed because the qmicro native-row and dense-
  prefill wrappers did not exist.
- GREEN: the focused rows2/3/4 and rows512/513-tail fixtures passed **5/5** with
  BF16-bit identity against the retained standard-T16 owners.
- Rows1 actual-weight gate: layers 0/8/63, four warmups, 15 counterbalanced
  pairs/layer, burst four, cached gfx1151 binary, and a **95.625-MiB** source
  pair per layer. Every pair wins; all outputs are BF16-bit exact, KL is zero,
  top-1 is 3/3, and tracked ownership returns to zero.
- Operation gate: the same three actual layers, three warmups and 15
  counterbalanced pairs/layer/row. All **18** case readbacks are BF16-bit exact
  across **270** timed pairs. Native wins **0/135**; prefill wins **44/135** and
  loses each aggregate shape.
- The temporary operation harness raised `AttributeError` on an invalid
  `GGUFReader.close()` only after all 18 measurement/readback rows printed.
  The compact artifact was recovered from complete stdout rather than rerunning
  the expensive gate.
- A scoped reverse patch restores all six transient production/test files to
  committed HEAD before documentation is staged.

## Next

- Keep standard-Q4T16 as the sole gate/up payload and retain its split-weight
  c1 owner. Q4 payload compaction is closed unless a materially new format has
  operation-complete native and prefill consumers, not merely a faster c1
  decoder. Continue P5 from a different post-grouped profile boundary.
