# Qwen4Exp QA-6 raw-index key ring audit

## Summary

Audited QA-6's proposed QSA raw-index-key ring against the current Qwen4Exp
state, allocation planner and tests. The current device owner stores FP32 raw
keys at 6,144 B/token across 12 QSA layers: 1.50 GiB at native 262,144 context.
The complete index owner is 2,035,532,208 bytes (1.896 GiB) before KV,
recurrent-state and scratch owners. Complete-block pooling is already incremental
and cursor rollback restores the logical count and pooled count.

The ring is technically plausible because ordinary scoring reads the pooled bank
after block close, but it changes state/snapshot ownership. Existing tests do not
cover ring wrap, partial-block leftovers, dirty restore destinations, ring
 eviction, or pooled-history ownership under c2. No implementation or promotion
is safe from this audit alone.
