# Probe Q5/Q6-only compact repacking for published UD

## Summary

The model-wide raw-IQ veto prevents existing compact Q5/Q6 residents from
being selected. A diagnostic now tests those formats alone without changing
Q4/Q8 layouts or the independent F32 contraction policy. Production defaults
are unchanged. The four-category diagnostic passes with 12/12 top-1 matches
and maximum KL 0.0005153743 against the current K_M path. This supports a
larger experiment, not promotion or a performance claim.

## Changes

- Temporary diagnostic `/tmp/ud-q56-repack-smoke.py` patches only
  `_spec_for_tensor`: for rank-2 Q5_K/Q6_K tensors, set `decode_repack=True`
  before calling the original function. All backend flags and role/shape
  restrictions remain unchanged. Rank-3 experts and other types are untouched.
- Baseline and candidate use separate processes, the published K_M artifact,
  serial prefill, three output-logit rows per prompt, and the first prompt in
  each of the four mtpbench categories. Candidate consumes baseline greedy IDs.
  Sessions reset between prompts. This is a bounded numerical diagnostic,
  not the full category/heldout suite, task-quality gate, or performance test.

## Diagnostic source

Save as `/tmp/ud-q56-repack-smoke.py` at commit `410704904` to reproduce.
This is an experiment snapshot, not a supported CLI or runtime switch.

```python
import json, sys, time
from pathlib import Path
import numpy as np
from hipengine.loading.gguf import load_gguf_index
from hipengine.tokenization.gguf import Qwen35GGUFTokenizer
from hipengine.runtime.qwen35_gguf_runner import Qwen35GGUFResidentSession
from scripts.gguf_mtp_bench import build_chat_prompt
from scripts.gguf_mtp_category_bench import load_prompt_rows
import hipengine.loading.qwen35_gguf_materialize as materialize

mode=sys.argv[1]
model='/models/gguf/Qwen3.8-27B-UD-Q4_K_M.gguf'
if mode == 'candidate':
    original=materialize._spec_for_tensor
    def candidate(slot_path,tensor,**kwargs):
        if len(tensor.shape)==2 and tensor.ggml_type_name in ('Q5_K','Q6_K'):
            kwargs['decode_repack']=True
        return original(slot_path,tensor,**kwargs)
    materialize._spec_for_tensor=candidate
rows={}
for row in load_prompt_rows(Path('benchmarks/prompts/mtpbench-code-general-ja.jsonl')):
    rows.setdefault(row['category'],row)
tok=Qwen35GGUFTokenizer.from_gguf_info(load_gguf_index(model))
inputs=[list(build_chat_prompt(tok,row['prompt'],reasoning='off')) for row in rows.values()]
teacher=None if mode=='baseline' else np.load('/tmp/ud-q56-baseline.npz')
logits=[]; tokens=[]; timings=[]
print(mode, [(r['id'],len(p)) for r,p in zip(rows.values(),inputs)],flush=True)
with Qwen35GGUFResidentSession(model,backend='hip_gfx1151',max_sequence_length=max(map(len,inputs))+16,compiler_version=Path('/tmp/ud-hipcc-version.txt').read_text()) as session:
    for i,prompt in enumerate(inputs):
        session.reset()
        start=time.perf_counter()
        r=session.prefill(prompt,use_bulk=False,return_logits=True)
        for j in range(3):
            assert np.isfinite(r.logits).all()
            logits.append(r.logits.copy())
            chosen=int(r.token_id) if teacher is None else int(teacher['tokens'][3*i+j])
            tokens.append(chosen)
            if j<2:r=session.step(chosen,return_logits=True)
        timings.append(time.perf_counter()-start)
        print(mode,i,timings[-1],flush=True)
np.savez('/tmp/ud-q56-'+mode+'.npz',logits=np.asarray(logits),tokens=tokens,timings=timings)
if teacher is not None:
    a=teacher['logits'].astype(np.float64); b=np.asarray(logits,dtype=np.float64)
    a=a.reshape(-1,a.shape[-1]);b=b.reshape(a.shape)
    def logsoft(x):
        x=x-x.max(axis=-1,keepdims=True)
        return x-np.log(np.exp(x).sum(axis=-1,keepdims=True))
    la,lb=logsoft(a),logsoft(b)
    print('diagnostic KL',np.sum(np.exp(la)*(la-lb),axis=-1).tolist(),flush=True)
    print('diagnostic top1',np.mean(a.argmax(-1)==b.argmax(-1)),flush=True)
```
