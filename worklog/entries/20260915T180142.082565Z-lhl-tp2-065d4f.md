# tp2 graphed schedule: captured per-layer graphs, -46% decode p50

## Summary

Unit: `hipengine/distributed/tp2_generate.py` + staged-exchange fixed slots.

## What landed

- `MlpTP2GenerationSession` gained a `schedule` knob. The production default
  for tp2 sessions is now `"graphed"`: each (layer, rank) pair's capturable
  segment is recorded into one instantiated HIP graph on a per-rank
  non-blocking stream (capture on the legacy default stream is refused with
  HIP error 900). The segment is: the prior layer's deferred bf16 boundary
  cast + residual add, the replicated attention/GDN segment, add+norm, the
  D2D input copy, and the fused gate/up+SiLU shard chain down to the down
  partial. The transport reduction stays host-driven between graph segments.
- `schedule="eager"` is the explicit opt-out and the matched TP1 control's
  schedule.
- The compiled staged-exchange driver gained `tp2_staged_reduce_at` and
  payload-base/stride accessors; the transport gained `slot=` and
  `payload_ptr(slot)`. Graphed schedules build the shard group with
  `slot_sets=len(layer_types)` so every layer owns one fixed mapped payload
  slot - the stable pointer the captured deferred consumer reads. Eager
  keeps the two-slot alternation.
- Capture flow: one eager warmup token (forces lazy allocations + JIT),
  device sync, state reset, position pinned at the capacity bound (2047),
  then 64x2 graph captures + instantiates. Per token: eager token H2D +
  pinned position/context refresh + embedding, then per layer 2 graph
  launches + the host-driven exchange (D2H submit, one wait per stream,
  compiled f32 sum), then the eager tail cast+add for the last layer and the
  control rank's head/sampling.
- Gate result on the retained protocol (W7900 + RX 7900 XTX, Qwen3.8-27B
  Q4_K_M, 4 prompts, 16 new tokens each + full-logit teacher-forced):
  mean KL 3.945e-04, max KL 2.365e-03, top-1 agreement 100% against both
  per-GPU TP1 controls, TP1 controls bit-identical to each other, repeated
  TP2 run reproduces tokens and logits bit-exactly, greedy tokens identical
  to the eager run on all 4 prompts.
- Walls: decode p50 50.95 -> 27.446 ms/token (-46.1%) at the matched
  composition (W7900 TP1 31.8 ms, RX 7900 XTX TP1 26.3 ms). The recorded
  in-step exchange wall attribution moved 156 -> 367 us p50 because the
  exchange's stream wait now spans the whole layer graph - the loop is
  device-bound, which is the point of the lever.

## Changes

### Bugs found and fixed on the way

- Tail wiring: the graphed tail wrote the unswapped embedding pair's
  destination (hidden_b) instead of the last layer's destination (hidden_a,
  read by the head). Symptom: 100% top-1 agreement with badly wrong soft
  distributions (mean KL 2.66). With the fix, capture-at-bound-8 is
  bit-identical to eager; capture-at-2047 is KL <= 3e-4 per position.
