# Automatic MTP admission is live for both UD artifacts at c1

## Summary

With the U6 pin and the UD serving-evidence rows in place, the **automatic**
route engages for both pinned UD artifacts with no in-process grant, no
diagnostic flag, and no request field.

`scripts/gguf_mtp_c1c8_server_bench.py`, canonical ten prompts, 24 output
tokens, `--candidate-budget 3 --correctness-contract ar_exact`, server
`speculative_mtp_serving=auto`, request omitting `speculative_mtp`:

| Artifact | AR tok/s | MTP tok/s | MTP / AR | engaged | exact | decision reason |
| --- | ---: | ---: | ---: | ---: | ---: | --- |
| `UD-Q4_K_M` | 14.23 | **34.32** | **2.4126x** | 10/10 | 10/10 | `qualified_automatic_ud_c1_k3_d24` |
| `UD-Q4_K_S` | 15.19 | **35.71** | **2.3517x** | 10/10 | 10/10 | `qualified_automatic_ud_c1_k3_d24` |

The per-request route fields confirm it is the qualified path and not a
fallback: `requested_route: speculative_mtp_auto`,
`effective_route: speculative_mtp`, `used: True`, acceptance 0.9444 over six
draft cycles. The explicit arm on the same artifact gives 2.4141x, so the
automatic and opt-in routes now agree.

Before the evidence rows the same automatic command recorded
`effective_route: default`, `used: False`,
`decision_reason: automatic_mtp_scope_not_promoted`; before the pin it was
refused outright for scope. The chain is now complete end to end:
U6 record -> `_UD_MTP_PRESET_FINGERPRINTS` -> `GGUF_PRESET_SCOPE_MTP` ->
`_UD_Q4K_MTP_SERVING_EVIDENCE` -> automatic admission.

## Reading the numbers

These are the **server-path diagnostic denominator**, not the retained paired
rates. The AR arm here is `gguf_packed_ar_server_decode` at 14.2 tok/s, while
the retained paired protocol measures the resident graph-replay leaf at about
31.9 tok/s for the same artifact. The 2.41x here and the retained 1.37x are the
same capability against two denominators, and only the paired number is
retained. Nothing in this entry supersedes
`benchmarks/results/paired-ud-plain-mtp-c1-natural25-b3-phase4.json`.

## Scope

The admission is width c1 and the 4-95 token context bucket, because that is
what was measured. c2 measured 1.0418x, c4 has no production physical width
cell, and c8 runs out of memory at capacity 8 on the default GPU. Above the
1023 sentinel the adapter refuses MTP and the packed verifier drops to a per-row
route, so no wider context is claimed.
