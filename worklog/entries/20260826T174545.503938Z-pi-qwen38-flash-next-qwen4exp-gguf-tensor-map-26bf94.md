# Map Qwen4Exp split GGUF tensors

## Summary

Added the strict 1,224-tensor qwen4exp split-GGUF map with explicit part
ownership, root/GR/GDN/QSA/MoE/PLE slots, exact shapes, duplicate detection,
and fail-closed split coverage. The map validates both an exact local-converter
PLE row count and Unsloth's 90 unreachable padded rows.

## Changes

- Added immutable tensor refs carrying part index/path and tensor metadata;
  model/root/layer maps never materialize payloads.
- Required 5 root tensors, one PLE table, 36x25 GDN slots, 12x26 QSA slots,
  and six extra PLE-compute tensors on layer 1.
- Added exact shape contracts for widened GR, 512/top-10 MoE, GDN, group-12
  full attention, QSA indexer, PLE compute, and untied embedding/head.
- Added missing/unexpected/duplicate/shape/split validation and package exports.

## Validation

- RED: mapping tests failed collection because the tensor-map API did not exist.
- GREEN: `uv run pytest -q tests/test_qwen4_exp_gguf_mapping.py` -> `4 passed`.
- Narrow mapping/config/artifact/Qwen35 compatibility bundle -> `40 passed`.
- Real frozen Unsloth four-part header map (temporary sparse header-only views):
  passed, 1,224/1,224 tensors, 48 layers, root owners on data part 1,
  layer-0 GDN 25 slots, layer-1 GDN+PLE 31, layer-3/47 QSA 26, and PLE
  `IQ4_NL [320001536,160]` with 90 unreachable padded rows.
- Python compilation and `git diff --check` passed. Incomplete payloads were not
  read, hashed, or reported as finalized artifacts.
