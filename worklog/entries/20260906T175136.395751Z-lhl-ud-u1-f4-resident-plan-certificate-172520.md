## Canonical contract definition (what the certificate now binds)

`Qwen35GGUFPlanContract` gains `resident_plan_records` + `resident_plan_digest`:

- one canonical sorted line per checked-and-qualified slot:
  `slot=<path>\tsource=<name>\tshape=<dims>\tsource_type=<ggml>\tlayout=<l>\tquant_key=<q>\tallocations=<names>\tplanned_nbytes=<name:bytes,...>\tsidecars=<layouts>`
  — logical slot, source identity, resident layout, per-tensor quant key,
  allocation names, the exact metadata allocation formula the loader uses
  (which also pins resident element sizing/dtype), and sidecar layouts;
- `qwen35_gguf_planned_weight_digest` = sha256 over the deduplicated sorted
  records with a format tag + length prefix (`qwen35-gguf-resident-plan-v1`);
  no reprs, no hashing of objects, no pointers, no env names, no wall-clock —
  stable across processes and input spelling/order;
- `__post_init__` always re-derives the digest from the stored records, so a
  contract can never carry a digest that disagrees with its own record set;
- records are collected by the preflight from the ACTUAL planned specs
  (`qwen35_gguf_planned_weight_record(spec)` per qualified slot) — pure
  metadata, no GPU, no weight reads.

## Changes

- `certificate_covers_artifact(..., plan_contract)` — `plan_contract` is now a
  REQUIRED keyword. Coverage verifies the intended contract against the
  certificate's recorded plan per slot: full-artifact intent requires a
  full-artifact certificate whose records subsume the intended records;
  subset intent requires the call's `slot_filter` to agree with the intended
  contract's recorded scope, slot-scope nesting (certified None covers any
  subset; a certified subset must contain the intended one), and exact
  per-slot record equality (narrowing preserved, enlargement refused).
  Requested operations must be in BOTH the certificate's and the intended
  contract's checked operation sets. Absent (legacy `plan_contract=None`
  certificate), unknown (malformed record lines), and partial (records not
  covering the claimed slot scope) contracts fail closed.
- NEW `certificate_matches_artifact_identity(certificate, *,
  manifest_fingerprint, backend=None)` — the distinct source-identity-only
  check; documented and tested as never authorizing operations.
- `materialize_qwen35_gguf_weights(..., admission_certificate=None)` — real
  certificate consumer: the supplied certificate is re-verified against the
  fresh admission report (fingerprint, backend, operations, slot scope, and
  the actual planned-resident contract) BEFORE any device allocation;
  fail-closed refusal names the re-run path. Residents carry the minted
  certificate (`Qwen35GGUFResidentWeights.admission_certificate`) for
  downstream re-verification; the runner's host-embedding remap propagates
  it. `as_dict()` exports `resident_plan_digest` + `resident_plan_record_count`.
