# Parse strict Qwen4Exp GGUF metadata

## Summary

Added a strict, torch-free parser for the frozen Qwen3.8-Flash-Next qwen4exp
GGUF metadata contract. It parses the real Unsloth metadata-only first split
without touching tensor payloads and fails closed on architecture, geometry,
QSA, GR, GDN, MoE, PLE/hash, tokenizer, RoPE, or context drift.

## Changes

- Added immutable `Qwen4ExpGGUFConfig` and package exports.
- Preserved the exact 45-bit PLE multipliers, 16 prime head sizes/offsets, PLE
  EOS/image token IDs, and the tokenizer's distinct EOS metadata.
- Derived the 36-GDN/12-QSA layer pattern, 512-block QSA budget, 320,001,446 PLE
  rows, 24,576 BF16 K/V bytes/token, and 768 compressed-index bytes/token.
- Added synthetic positive/negative fixtures and a local real-header gate.
