# q6 planar 4r6 rows>=385 delegation to shared4_gfx1100

## Summary

GUFO campaign iteration 9 (trace-driven). The post-w64 rocprofv3 kernel
trace ranked `q6_k_t16_qmicro_planar_wmma_prefill_shared` #3 at 217.84 ms
per pass (16.9% of the 1288.1 ms prefill kernel total). A temporary
env-gated wrapper trace (`HIPENGINE_Q6_WRAP_TRACE`) proved that at
512/128 **100% of that family flows through a single leaf**,
`gguf_q6_k_t16_qmicro_planar_wmma_prefill_shared4r6_bf16_bf16_out`
(128 calls for shape (17408, 5120) plus 32 for (5120, 1024) across the
four passes). The r6 leaf's row-tile is 384 rows, so the 512-row
production cell runs two row-tiles (`grid.y=2`, confirmed in the trace).

The gfx1151 host router's r6 band admits rows 288..1024 for (17408,
5120) and 288..536 for (5120, 1024), while the four-wave siblings —
`shared4_gfx1100` (four-wave/three-output-tile owner) and
`shared4_row64` — were measured only in gfx1100 FFN-down bands
(`b51b17a35`, "Select row64/shared256 only for measured gfx1100 FFN-down
bands") and never A/B'd on this device. Same fallthrough/sibling pattern
as the iteration-8 w64 keep, one level down.

Four-arm A/B (all arms byte-identical `correctness_sanity`: 66/66
leaves, final_token_id 9707, final_logit 25.461074829101562):

| rows >= 385 owner of the 4r6 leaf | prefill tok/s (mean +- stdev) | vs base | parity |
| --- | --- | --- | --- |
| shared4r6 (stock, 384-row 2-tile) | 395.665 +- 0.221 | reference | reference |
| shared4r9 (576-row 1-tile) | 397.974 +- 0.322 | +0.58% | identical |

Winner: `shared4_gfx1100`. The device's 12-SIMD gfx1151 prefers the
four-wave/three-output-tile structure over both the two-tile r6 path and
the one-tile r9 path; row64's one-rowtile-per-wave balance regresses.
Largest single-iteration gain of the loop so far (+21.05 tok/s).
