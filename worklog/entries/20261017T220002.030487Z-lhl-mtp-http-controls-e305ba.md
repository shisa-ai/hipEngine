# Admit provider-declared structured MTP controls through HTTP

## Summary

The Flash-Next provider declares its implemented stop, EOS, grammar, tool and
thinking controls for explicit HTTP speculation. Both request spellings execute
actual MTP through EngineService in CPU HTTP tests. Automatic selection is not
promoted and resident-session reuse remains rejected. PS6/task 19 remains open
for live GPU qualification.

## Changes

- Extend provider `supported_sampling_fields` with implemented controls; keep
  existing per-provider admission rather than adding model/backend branches.
  Test withdrawn declarations, legacy providers, unsupported session reuse and
  unchanged automatic-selection policy.
- Fix incomplete buffered MTP streams: the root scheduler event had text but
  later speculative token events had none. EngineService saw the root as emitted
  and omitted the remaining terminal text. Honor the provider's existing
  `streaming_mode=buffered_public`: retain canonical token accounting but publish
  only the authoritative terminal output. Other providers' live behavior is
  unchanged. This is not incremental-streaming qualification.
- The no-logprob tool SSE path also omitted compact MTP summary/route metadata
  and discarded backend finish metadata. Forward both through the existing
  parsed-tool adapter. Logprob-buffered and ordinary text paths were already
  covered by earlier repairs.
- Add 160 HTTP cases with real EngineService, SubmitPollTextGenerator, resident
  target/draft transactions, llguidance and analytic CPU logits. Cover both
  request spellings, blocking/SSE, greedy/sampled and logprobs on/off for ASCII
  and Japanese multi-token stops, alternate EOS, ignore-EOS, minimum-token masks,
  schema completion exactly at the output bound, required/automatic XML tools,
  automatic schema answer and hard-thinking plus schema. Require actual verify
  calls/cycles, no AR fallback, exact visible output and selected byte logs.
- Use a byte tokenizer with truthful special-token and reasoning-prompt handling.
  Prompt length is measured from prefill, not assumed from one fixed prompt.
  The real service is essential: the prior sampled HTTP test's adapter called
  the provider through delegation rather than exercising resident collectors.
