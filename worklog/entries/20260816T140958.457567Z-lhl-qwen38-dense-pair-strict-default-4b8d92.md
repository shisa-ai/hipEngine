# Restore exact Qwen3.8 dense-pair default

## Summary

Independently requalified the historical gfx1151 Qwen3.8 rows1
H=5,120/N=17,408 residual-Q8_1x2 split-weight gate/up+SiLU owner rather than
grandfathering its old campaign label. The route is numerically acceptable and
repeat-deterministic, but it loses a current same-session performance A/B to the
registered exact local32 fused fallback. Restored exact local32 as the scoped
serial package default while preserving the native owner; no public
execution-profile qualification or topline is claimed.

- Changed the Qwen3.8 dense model/quant/shape serial policy from
  `dense_dual_q8_1x2_split_weight_dp4a_bf16_bf16_out` to
  `dense_dual_local32_bf16_bf16_out`. Added a package-owned native policy plus
  a generic execution-context query so native B1 continues to select its
  separately qualified non-split Q8_1x2 owner; peer models/shapes, registry
  keys, and fused/unfused fallbacks are unchanged.
- Updated package-policy tests, kernel/current-campaign documentation, the
  production-numerics queue, and the refactor ledger.
- Added compact clean artifacts for the full-logit quality requalification and
  counterbalanced performance decision, and updated the benchmark rollup and
  changelog. The old changed-arithmetic route remains registered only for
  diagnostics/bisection during the recorded removal window.
