# gfx1151 INT8 K/V re-check: 2026-08-15 rejection reproduces exactly on current kernels

## Summary

The gfx1151 native INT8 K/V quality rejection is **representation-owned, not
kernel-owned**, and it is now confirmed rather than assumed. Re-running the
quality gate on current kernels against the same artifact and the same prompt
suite as the 2026-08-15 rejection reproduces that failure to the artifact's full
printed precision, including the identical failing prompt set and the identical
per-prompt mean and max KL.

This supersedes the "launched, result pending" item in the preceding
`gfx1151-gfx1100-gap-review` entry
(`worklog/entries/20260911T202241.955185Z-gfx1151-audit-gfx1151-gfx1100-gap-review-27be8f.md`),
which recorded the review before this measurement landed. That entry's C4 row is
the one this entry closes.

Consequence: INT8 K/V is **not** a gfx1151 lever for this artifact. The
capability gate in `hipengine/models/qwen35.py` is correct as recorded, and this
representation should not be re-run. Nothing in the gfx1151 paged-attention work
landed since August can be expected to clear it.

## Validation

Command shape, run twice (once per shape) on the physical gfx1151 host (Ryzen AI
MAX+ 395 / Radeon 8060S, ROCm `10.0.0`), commit `f3b20c1f2`:

```
python3 scripts/qwen35_native_mixed_kv_suite.py --engine gguf --backend hip_gfx1151 \
  --gguf-model /models/gguf/Qwen3.8-27B-Q4_K_M.gguf --paro-model <PARO snapshot> \
  --prompts benchmarks/prompts/mtpbench-code-general-ja.jsonl \
  --prompt-length {512|1024} --decode-steps 8 \
  --candidate-kv-storage int8_per_token_head --kv-scale-dtype fp32 \
  --kl-threshold 0.05 --top1-threshold 0.9 --max-sequence-length 32786 \
  --require-no-bf16-mirror --diagnostic-kv-capability \
  --expected-bf16-full-layers none --expected-int8-full-layers 0-15 \
  --compiler-version-file /tmp/hip1151-run/hipcc-version-gfx1151.txt \
  --json /tmp/hip1151-run/int8kv-recheck-{512|1024}.json
```

`--diagnostic-kv-capability` was required because the gfx1151 plugin evidence for
this lane is a rejection, so the session would otherwise resolve the request to
`effective_kv_storage="bf16"` without exercising the compact route. The flag
takes the real compact route and records the injection as diagnostic; it is
never a promotion.

Same-artifact, same-suite check: the rejection's recorded `artifact_sha256`
(`7e78da5d7e3ae28d178121f58646953305f3e5bd3cb46f4a75584e8b6c6fe169`,
17,106,775,008 bytes) is the file present on this host, and its recorded
`prompts_sha256` (`fac920be5e691fec2cb70fd8b7eedddab8926b89d6a1627f62ec4f441d86084a`)
is the current suite. 11 prompts, 99 positions, complete-suite selection.

Layout audit passes at both shapes: all 16 full-attention layers INT8, complete
layer partition, zero BF16 mirror bytes, zero retained prefill oracle buffers,
1,099,038,720 total KV bytes (49.21875% of BF16).

| Shape | Status | Mean KL | Max KL | Min top-1 | Failing prompts |
| --- | --- | ---: | ---: | ---: | --- |
| 512/8 | passed | 2.191e-04 | 1.225e-02 | 1.0 | none |
| 1024/8 | rejected | 4.198e-02 | 3.446 | 0.7778 | `mixed_ja_en_review`, `mixed_v1` |

Comparison with the 2026-08-15 artifact:

| Shape | Prior | Now | Reading |
| --- | --- | --- | --- |
| 512/8 | mean KL 1.184e-04, max KL 4.925e-03, top-1 1.0 | mean KL 2.191e-04, max KL 1.225e-02, top-1 1.0 | Still passes; KL roughly doubled but stays ~4x under the per-prompt max-KL gate with perfect top-1 |
| 1024/8 | mean KL 0.041977959056962555, max KL 3.446476164561575, min top-1 0.7777777777777778 | identical to all printed digits | Precision-exact reproduction |

The 1024/8 reproduction spans the gfx1151 paged-attention geometry pins and the
small-row owner work landed since August, and a compiler change from AMD clang
23.0.0git to HIP 7.15.26333. The 512/8 shape moved while 1024/8 did not, so the
two shapes are not on the same code path — consistent with the
`max_live_count >= 1024` guard in
`Qwen35ParoDecodeState.decode_full_attention_context_gate_fp16_batch`, which
takes the batch path at 512/8 and a different route at 1024/8.

Per the inherited stop rule ("stop a representation after the first failed
shape"), 4096/16 was not run.

Localization: nine of eleven prompts pass at 1024/8 with a worst max-KL of
9.37e-04. The whole failure sits in `mixed_ja_en_review` (mean KL 1.64e-04, max
KL 9.37e-04, top-1 0.889) and `mixed_v1` (mean KL 0.4609, max KL 3.446, top-1
0.778). That is a prompt-class-specific divergence, not a general quality
collapse — but it is not clearable by reselecting a layer map, because the
2026-08-15 protocol declares these prompts heldout/control for map selection.
