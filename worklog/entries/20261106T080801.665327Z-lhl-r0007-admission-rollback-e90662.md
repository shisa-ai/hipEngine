# Return pooled admission blocks after setup failure

## Summary

Pooled batch admission leaked reserved KV blocks if index mapping or slot reset
raised before an owner token was published. Restore the provisional reservation
on either failure; a retry resets state before publishing its owner.

## Changes

- Wrap pooled mapping/reset with rollback of the free list, block table and
  per-slot reservation count. Preserve the original setup error.
- Add injected mapping/reset failures, verify no admission is published and all
  blocks return, then successfully admit/release the same slot.
- R0007's broader admission object consolidation remains open.
