# Replace head-major private limits with common admission

## Summary

Replace private token/byte ceilings with common memory admission for contiguous
and gapped head-major scratch. Keep requested-context sizing and rounded gather
allocation, partial-owner cleanup and native resource-denial fallback.

## Changes

  them as ignored for old callers. Keep the independent gather rollback switch.

- Gapped allocation rounds to 4096 tokens and checks actual rounded bytes against
  common headroom before allocating. Existing cached owners survive denial.
