# Coalesce adjacent request-owned DMS snapshot copies

## Summary

DMS verifier profiling identified repeated per-head synchronous snapshot reads.
Copy adjacent owned head ranges together, retaining the per-head snapshot ABI
as disjoint views of the copied planes. Never bridge gaps. Restore and kernel
arithmetic are unchanged; the implementation is on the default path.

## Changes

- Group adjacent ranges in head order for K/V, position, eviction, and INT8
  scale readback. Preserve per-head offsets, shapes, values, and ordering.
- Add CPU fake-device tests for contiguous, gapped, and reordered head ranges
  with BF16 and INT8 payloads. Check copy counts, exact restoration, and no
  reads or writes of unowned slots. Four tests fail on the original copy count;
  all six pass with coalescing.
