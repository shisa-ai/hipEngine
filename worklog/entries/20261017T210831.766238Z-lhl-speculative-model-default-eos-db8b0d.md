# Preserve model-default EOS at the speculative output bound

## Summary

The sampled-MTP HTTP audit found a service normalization defect: model-default
EOS at the output bound became `length`, losing sampler finish metadata. Resolve
the default from the provider's finish details when the request leaves EOS unset;
explicit request EOS and ignore-EOS still govern normalization. This repair
passes CPU service tests. The live replay remains pending and task 17 stays open.

## Changes

- Preserve model-default EOS and finish metadata in
  `EngineService._normalize_speculative_output`. When normalization genuinely
  changes the reason, retain sampler/context metadata while updating EOS, length
  and matched-stop fields rather than constructing an empty finish record.
- Add the full-category/heldout sampled-MTP functional probe, its mock tests and
  compact failed-audit artifact. All 18 prompts have true AR controls; speculative
  tests cover both spellings, buffered SSE, three blocking repeats, changed seed,
  no-logprob routes and late request-neighbor isolation.
- Correct a probe mistake: SSE execution telemetry requires
  `stream_options.include_hipengine`. Add `--replay-report` / `--case` so the
  75 successful requests need not be repeated after the isolated repair.
