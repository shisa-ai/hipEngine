# Reject Y3 shared4r6 producer pipeline

## Summary

Implemented and rejected the first bounded Y3 producer/consumer overlap
prototype without integrating it into policy.

## Changes

- Added an isolated five-wave kernel/export locally: one producer wave, four
  shared4r6 consumer waves, two 16 KiB LDS buffers, atomic ready/done handoff.
- Preserved the rejected patch and scope-reverted both source files.
- Published the exact actual-weight rows288 result.

## Validation

Command (300-second timeout):

`GPU_MAX_HW_QUEUES=2 HIP_VISIBLE_DEVICES=0 ROCR_VISIBLE_DEVICES=0 HIPENGINE_HIP_ARCH=gfx1151 HIPENGINE_GGUF_DECODE_REPACK=1 timeout 300 .venv/bin/python /tmp/y3_q6_shared4r6_pipeline_rows288_smoke.py`

Both physical planar shapes completed and matched the parent bit-for-bit. The
binding K17408/N5120 leaf regressed 3.713->4.748 ms (+27.88%); K5120/N1024
improved 0.350->0.339 ms (2.97%). The wide regression rejects the design.
