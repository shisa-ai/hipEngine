# Implement basic Qwen4Exp image generation

## Summary

Implemented the bounded basic Qwen3-VL vision path for Qwen3.8 at short
context: one exactly 32×32 RGB image becomes four ViT patches and one H2560
image token, then generates through the public `LLM` API. The full embedding
matches independent Transformers at relative L2 1.34e-6.

## Changes

- Converted the official BF16 vision shard with frozen #27742 to a strict
  334-tensor/907.5-MB mmproj and added map/materialization contracts.
- Added FP32 LayerNorm, residual+bias, tanh-GELU, and vision-MRoPE full
  attention kernels with NumPy primitive oracles and cached traces.
- Added the 27-layer H1152/head16/D72/I4304 encoder, learned-position
  interpolation, 2×2 merger, and H2560 projection.
- Added prompt image-placeholder rendering and exact one-row embedding override
  before target prefill. PLE continues hashing token ID 248056.
- Added `LLM.generate_multimodal_detailed(..., vision_model=...)`, truthful
  bounded capability metadata, and text-only non-regression.
- Artifact:
  `benchmarks/results/2026-08-28-gfx1151-qwen38-flash-next-basic-vision.json`.
