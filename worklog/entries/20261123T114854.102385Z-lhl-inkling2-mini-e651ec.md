# Share immutable device convolution taps across Inkling requests

## Summary

Keep read-only device convolution taps alive with the packed GGUF model instead of uploading them for every request. Convolution history, provisional updates, and attention KV state remain session-local.

## Changes

- Give the packed GGUF generator one lazily populated tap owner. Every session borrows the owner's read-only pointers by visit and operation; the first access uploads, and only model teardown frees the shared taps. Other callers retain private tap ownership.
- Add a direct lifetime test for one upload, independent history allocations, continued convolution after the first borrower closes, and rejection after tap teardown. The new test failed before the shared owner was implemented and passed afterward on W7900.
