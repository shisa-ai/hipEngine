# Qualify original-product IU4 full FFN

## Summary

Completed R8 with the immutable original/offline-optimized Kairic FFN product.
The result is a large, complete-wall prefill win and a clear numerical boundary:
keep it as an explicit quality-traded T3 configuration, not as named/omitted
production.

- Actual layer-0 Q4 gate/up + Q5 down full FFN improves
  2.605x/2.613x/3.348x/3.300x at M64/128/256/512 (15/15 each).
- Same-resident complete p512/p1K/p4K prefill improves
  384.70/384.58/359.25 -> 567.92/563.05/518.07 tok/s
  (1.476x/1.464x/1.442x; 5/5 each).
- Five real 4K retrieval/multihop/aggregation/long-doc/code tasks pass in both
  control and candidate arms.
- Q4_K_S promotion fails: a varied p512 teacher trajectory is mean/max KL
  0.02119/0.08754 and 88.89% top-1. The canonical category suite padded to
  p512 is 100% top-1 and p95/p99/max KL 0.004255/0.015595/0.015673, but mean
  KL 0.001124 narrowly exceeds the frozen 0.001 limit.

The explicit `iu4_ffn_pfs_path` route therefore admits only gfx1151 Qwen3.8-27B
Q4_K_S, physical M96-M2048. All shape misses and c1 decode retain the current
exact chain. Omitted/profile behavior is unchanged.

## Changes

- Corrects the preceding parser checkpoint without editing it: canonical
  `PFSIU4F` weight bytes are row-major `[N,K/2]`; the N64/K8-word ordering is
  CK's matrix descriptor/access pattern, not the on-disk layout. Stored sums
  match row-major two's-complement nibbles exactly; R8 updates the parser and
  lossless paired-K32 transpose accordingly.
- Added `iu4_s4_kairic_ffn_v1` product kernels:
  - BF16 block-Hadamard1024 dynamic-U4 packs with frozen gate/down seeds;
  - fused BF16 gate/up -> SwiGLU -> down pack;
  - N64/M256 U4xS4 IU4 WMMA over immutable row-major PFS weights, I32 correction,
    per-row/per-output scales, and BF16 boundaries.
- Added independent NumPy block-Hadamard/U4/correction oracles. Small and bulk
  GPU tests require exact packed words/scales/zeros and exact BF16 linear output.
- Added `IU4FFNProductRuntime`, the fully resident 64-layer product owner. It
  validates the full PFS SHA/table before allocation, owns/frees every buffer,
  records launch/fallback counts, and returns `False` to the existing chain on
  unsupported rows. `session.iu4_ffn_telemetry()` exposes immutable identity,
  admitted M range, and counters without inspecting private fields.
- Added the cold explicit selector to `Qwen35GGUFFullStackRunner` and
  `Qwen35GGUFResidentSession`; gfx1151 package capability admits it and gfx1100
  fails closed. The route reuses existing scratch: concatenated gate/up in
  `ffn_gate_up`, bounded U4 workspace in `ffn_intermediate`, final down in
  `ffn_down`, then the unchanged residual/norm chain.
- Added actual-product full-FFN, full-model numerical/performance, and long-task
  harnesses plus compact artifacts. Updated MTP-IU4, kernel catalog, refactor
  ledger, and benchmark changelog.

Source lineage: read-only `ciru-ai/ROCmFPX@e1da26bb8237fb5642488a2387efc793b141aae5`,
`ggml/src/ggml-cuda/promptforge.cu` and `promptforge_iu4.cuh`, plus the
`composable-kernel-gfx1151-iu4.patch`. Device bodies are in-tree raw-pointer
HIP implementations and do not add CK as a dependency. The public PFS is HF
