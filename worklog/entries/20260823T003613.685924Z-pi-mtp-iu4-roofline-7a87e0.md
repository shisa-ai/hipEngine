# Screen native IU4 for tiny-M verifier roofline

## Summary

Created the `mpt-iu4` research branch, added a direct gfx11 instruction ceiling
screen, and wrote `MTP-IU4.md`. Native U4xS4 IU4 WMMA is mechanically real and
measures 109.715 TOPS median on the Radeon 8060S, 1.981-1.994x the matched
BF16/FP16/U8xS8 WMMA lanes. The important tiny-M finding is negative for the
naive 2x verifier thesis: at M=4, 16-row tile underfill lowers useful IU4 math to
about 27.43 TOPS, approximately the measured 28.25-TOPS DOT4 roof, while the
weight-only 221-GB/s roof is only 3.536 TOPS.

The existing rows-3 qmicro gate/up owner already streams its 100,270,080-byte
actual pair in about 0.463 ms (216.6 GB/s). A clean S4 pair is only 11-12%
smaller, giving an optimistic 1.14x leaf ceiling before activation packing.
Therefore no full sidecar is authorized. The next gate is a one-layer,
operation-complete actual-weight M2-M5 test; concurrent V>=16/32 and M>=96 are
more credible IU4 regimes.
