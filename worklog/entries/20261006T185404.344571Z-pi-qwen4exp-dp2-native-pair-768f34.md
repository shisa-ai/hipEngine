# Qwen4Exp DP-2 native scoped two-consumer F16 reuse

## Summary

DP-2 native scoped two-consumer F16 reuse is correctness-qualified on the
owned gfx1151 lane and remains default-off pending a clean engine A/B.

## Changes

- Added bounded `WideF16ActivationPair` ownership over the existing runner
  workspace. Admission is limited to gfx1151 Q8 dense-wide layers13–47, rows
  1024/4096, and the ordered `attn_qkv`→`attn_gate` or
  `shared_gate`→`shared_up` pairs.
- The first consumer casts once and the second consumes the same F16 bytes.
  Exact source/count/output/weight/key/stream/runtime/workspace/context checks
  and lifecycle invalidation preserve parent fallback. The opt-in
  `HIPENGINE_QWEN4_EXP_DENSE_F16_PAIR` flag defaults off; no production binder
  changed.
- Added focused CPU and guarded native tests plus
  `scripts/qwen4exp_f16_pair_native_gate.py`.

## Validation

- Focused CPU ownership/publication/dispatch/workspace suite: 153 passed.
- Native non-default-stream pair tests and the DP-5 regression passed.
- Full native gate: 28 cases, 168 candidate/parent arm runs, 128 decode steps
