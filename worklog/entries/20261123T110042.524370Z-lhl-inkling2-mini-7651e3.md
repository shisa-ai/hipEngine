# Check device Inkling routing through ordinary decode

## Summary

The scratch device router generated the same greedy completions on six W7900 prompts, but changed every compared decode score row. It also changed expert IDs on finite biased ties. Keep the host router in production.

## Changes

- Scratch only. Use the device-selected IDs and mixture weights for scalar decode while leaving prefill on the host router. Compare logits only for equal token histories. Separately construct finite router rows whose bias cancels the host sigmoid to expose rank-boundary differences.
