# P3 integer-MMQ continuation: opened, screened on built bodies, closed measured-negative

## Summary

P3's opening conditions were met (P2 dequant-ALU dominance + written
sizing), so the continuation was screened against the campaign-mandated
reproductions. Every prequantized/integer body that exists or ever
passed correctness on this device loses to the Q4T16 WMMA family at the
target shape; P3 closes as a measured negative without constructing a
new body.

## Decision and evidence

- Item 19's continuation condition ("reproduce the shared MMQ
  tile/decomposition") was already satisfied historically: items 20/21
  built exactly that (T16-backed MMQ128: +118.81%; source-compatible
  MMQ128 over prequantized `block_q8_0` rows: spill-free,
  source-matched fragment counts, still +3.95%/+5.32% slower than
  production) and the frozen gate removed them.
- Re-screen at the current head on Qwen3.8 shapes (H 5120, gate/up
  18432x2, rows256, dense): selected-wmma 10.71 ms (9.03 TF/s); best
  integer body `q8_1_ds4_mmq32` 13.21 ms (0.81x); other int modes
  0.23-0.68x.
- Synthesis: INT8 WMMA == BF16 WMMA rate (59.4 TOP/s, no tensor 2x) and
  the dequant-free bodies inherit the same LDS-staging/issue wall, so
  the >=2x Q4-family gain required for the 305.847 C8 target is not
  reachable through data-format change. C8 prefill stands at P2's named
  blocker.
