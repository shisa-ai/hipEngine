# Accept singleton-batch prefill logits in DMS evaluator

## Summary

Normalized the resident-session singleton-batch prefill logits before the frozen
DMS distribution scorer's one-row comparison. The first successful runtime smoke
then exposed a real compact-no-evict numerical-control failure; no candidate
quality conclusion was drawn from it.

## Changes

- Accept `(1, vocab)` prefill outputs as one vocabulary row while retaining the
  strict one-dimensional contract after normalization.
- Preserve shape details in malformed-row errors and cover the runtime shape in
  the unit test.
