# Close stale IKV-C2 status markers in plan, roadmap, and campaign docs

## Summary

The campaign doc already recorded `IKV-C2` as completed and promoted, but three
other sources of truth still described it as upcoming or incomplete. Stale status
markers are how a completed item gets re-litigated later, so each was corrected
against verified state rather than against the campaign doc's own summary.
