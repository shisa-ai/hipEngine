# Add report-only logit distribution diagnostics

## Summary

Added shared distribution diagnostics to quant-quality and execution-profile reports at the user's request. All diagnostics are report-only; existing thresholds, outlier-review rules, and admission decisions are unchanged.

## Changes

- `scripts/quant_quality/metrics.py` computes FP64 stable-softmax total variation, signed candidate-minus-reference entropy and maximum-probability deltas, and reference logit margins. Shared summaries report mean/min/max and p05/p50/p95/p99, four half-open margin buckets, flip counts/rates, and explicitly approximate row-independent Wilson intervals.
- `hipengine/benchmark/execution_profiles.py` reuses the canonical margins and diagnostics globally and by scope, including BF16-relative summaries. Sequence counts describe distinct scenario/request pairs, not independent samples. Quant-quality summaries without identity metadata report null sequence counts.
- Prefix-reuse reports inherit diagnostics through the existing profile evaluator without changing the script's gate logic. No flag, runtime arithmetic change, or new dependency was added.
- `docs/TESTING.md` documents definitions, empty-bin behavior, signs, uncertainty limitations, and report locations.
- Added analytic CPU tests for constant shifts, flattening/sharpening, margin boundaries, ties, empty bins, extreme finite logits, one-token vocabularies, scoped counts, JSON serialization, and unchanged pass/fail decisions. The existing evaluator CLI integration test now asserts that its saved artifact contains the diagnostics.
