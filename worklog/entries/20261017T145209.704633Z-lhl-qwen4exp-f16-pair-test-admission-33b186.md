# Repair Qwen4Exp F16 pair admission regression test

## Summary

The Qwen4Exp gfx1151 F16 staging-pair test still expected the pair-loan path at
1,024 rows after admission was intentionally narrowed to 4,096 rows by
`42dd3e04b` (`perf: narrow DP-2 owner admission to p4096`). The implementation
correctly falls back to two casts at 1,024 rows; the test contract was stale.

## Changes

- Parameterize the HIP test with the declared pair-admission result.
- Keep the 1,024-row case as a fallback/ownership test and retain the 4,096-row
  shared-gate/shared-up case as the admitted one-cast path.
- Do not broaden the production policy: p1,024 was measured slower and remains
  intentionally on the parent route.
