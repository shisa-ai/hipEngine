# Repair gfx1151 compact no-evict numerical control

## Summary

Repair the gfx1151 compact no-evict numerical control by selecting the existing
generic grouped attention producer. The wave producer reproducibly fails G0;
the shipping generic path passes the unchanged four-category control. gfx1100
is unchanged. This is not a throughput claim or a new kernel implementation.

## Changes

- Capture actual compact Q/K/V and outputs for all 16 attention layers at both
  decode steps of the historical mixed-category failure. Repack identical BF16
  bytes for generic dense split attention: context differences are small but
  nonzero. Captures are local `/tmp/dms-real-captures/`; raw activations are not
  committed.
- A diagnostic replacing only compact attention with dense context arithmetic
  gives exactly zero logit KL at both steps, establishing attention arithmetic
  as causal for this case, rather than lost K/V rows or the selector.
- A diagnostic disabling the wave-group6 build define selects the already
  implemented generic compact producer and passes G0. The shipping change makes
  that selection on gfx1151 only, with a removal condition in REFACTOR.md.
- The shared-memory race hypothesis is not established; no speculative barrier
  edit made. No threshold or evaluator changed.
- RED build-plan test failed before the change. Updated the fixture digest for
  the generic output after its CPU oracle passed; the digest is not the G0 gate.
