# Single-plane hidden alias for the non-DMS INT8 layer_outer route

## Summary

2026-09-08 engine-comparison doc priority #1: the pure-INT8 direct-resident
capacity route plans the `layer_outer_shared_oracle` prefill lifetime, so
the hidden planes cover the full declared capacity - two BF16 planes,
2.69 GB at 128K on the Qwen3.8-27B H5120 geometry (the route passes
131,072 at 23.898 GiB and OOMs at 139,264, versus nasone32/strix-llama.cpp
192K on Q8_0). The chunk-outer alternative would need one full-length BF16
oracle pair per INT8-retained full-attention layer (17 layers: ~8.6 GB at
131K), so layer_outer is the right plan; the recoverable waste is the
second hidden plane.

## Decisions

- Extend the DMS lane's route-scoped single-plane alias (adopted
  2026-09-08, commit 6c6d1ad4a) to the non-DMS INT8 layer_outer route:
  new gate `HIPENGINE_INT8_LAYER_OUTER_HIDDEN_ALIAS`, default OFF pending
  this route's own GPU-side A/B. The layer loop is layer-outer either way,
  and the same 1024-row layer chunks that the DMS gate already covers
  consume the source hidden rows before writing the final FFN output.
- The geometry-wide `hidden_inplace_min_rows` policy (4096) is untouched:
  ordinary dense/BF16 prefill keeps two planes below the threshold.
