# Deduplicate staged runner delegation into one shared mixin

## Summary

Removed the ~150 duplicated resolve-adapter/raise-if-missing/delegate lines the dense Qwen GGUF and PARO resident runners each carried. Both runner classes now compose `StagedAdapterDelegation`, a backend-neutral mixin in `hipengine/speculative/delegation.py` that implements the scheduler-facing staged lifecycle once and forwards it to the resolved `StagedTargetAdapter` through five named hooks. PARO gains the explicit `staged_speculative_owner()` opt-in (it previously resolved only structurally) and the `speculative_frontier_available` forwarder, both with unchanged outcomes.

## Changes

- `hipengine/speculative/delegation.py` (new): `StagedAdapterDelegation` mixin providing `staged_speculative_owner`, `speculative_capability`, `speculative_claims_fit`, `speculative_frontier_available`, `speculative_component_claims`, `reserve/release_speculative_claims`, `prepare_speculative_requests`, `propose_speculative_batch`, `execute_target_frontier`, `prepare_speculative_k0`, `note_speculative_ar_commit`, `rollback_speculative_cycle`, and `recover_speculative_cycle_failure`. Hooks: `_staged_adapter`, `_staged_adapter_missing_error`, `_staged_adapter_arch_environment` (device-touching stages wrapped; cold plan/claim queries stay unwrapped, preserving the GGUF pattern), `_begin_staged_adapter_cycle`, `_on_staged_adapter_cycle_recovered(plan, error, recovered)`.
- `hipengine/generation/qwen35_gguf.py`: mixin base + 4 hook overrides; deleted the duplicated block. Owner-specific surfaces stay in the runner: `execute_speculative_cycle` (opaque path), `speculative_kv_live_spans_owner` (runner-owned constant), `note_speculative_plan`/`note_provider_readiness` (row telemetry), `speculative_graph_available`, `speculative_partition_max_requests`, `server_mtp_batch_max_active_requests`, `speculative_post_reject_cooldown`, `restore_speculative_target_*`.
- `hipengine/generation/qwen35_paro.py`: mixin base + 3 hook overrides (missing-error string, recovered-reason counting); deleted the duplicated block. Kept `register_speculative_request`, `speculative_desired_candidate_count`, `speculative_graph_available`, `speculative_kv_live_spans_owner` (adapter-consulting, differs from GGUF).
- Net: 208 duplication lines deleted; the per-runner blocks shrink to named hook overrides.
