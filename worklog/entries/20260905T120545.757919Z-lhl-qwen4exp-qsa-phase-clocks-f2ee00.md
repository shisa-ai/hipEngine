# Measure QSA transition clocks with exact phase windows

## Summary

Record phase-aligned GPU clocks/power/temperature outside the benchmark
process. Preserve original timed boundaries and add no cooling delay.
Expose the exact page256 sibling as a separately named diagnostic A/B arm.

## Changes

- Existing before/after timestamps become explicit phase_windows_ns fields.
  An outer subprocess sampler reads sclk/temp/power every250 ms and records
  monotonic timestamps, independent of model allocations and Python GIL.

  and strict parents stay available. Q5 row4 production is unchanged.
