# Remove per-call native GGUF authorization scans

## Summary

Continue the user-approved direct cleanup, without subagents. Remove native
per-call certificate reconstruction and recursive pointer inventories. Keep
load-time dependency/ABI checks, including checks for shared residents. This is
host maintenance-surface reduction, not a measured inference-speed claim.

## Changes

- Remove `qwen35_gguf_native_operands.py`, invocation contexts, physical scratch
  inventories, graph identity rescans and index-publication receipts introduced
  by `6fb94aae9`. Private layer calls again receive the session's raw pointers.
- A session marks native availability only after its construction-time resident
  check succeeds. Eager-only sessions cannot request native execution later.
  Runtime entry checks retain route availability, row bounds and host/sidecar
  refusals; replay retains closed-owner, token and context-bound checks.
- Session-owned weight/scratch pointers and graph geometry cannot be replaced
  while live. Inspection confirms target scratch, token/hidden/logit and sampler
  output allocations are assigned in construction and cleared in close, not
  dynamically reallocated by a supported API. A new session is the supported
  reconfiguration boundary. Arbitrary private-field mutation is not an API to
  defend through every kernel call.
- Preserve resident compatibility reports, full native load dependencies, shared
  consumer/selected-call contracts, dtype/geometry prerequisites and all kernels.
- Replace tests for the retired mutation-defense API with tests showing eager,
  capture and replay do not repeat construction-time checks. Preserve real
  direct-layer ABI routing tests and add closed-session replay coverage.
- Update PLAN, the refactor ledger and campaign status. The old physical-operand
  section is explicitly historical. Admission certificate simplification is
  still open; this unit does not declare UD support.
- RED-first was not performed: this unit deliberately removes the experimental
  mutation-defense contract rather than fixing its implementation. Replacement
  runtime tests encode the narrower approved lifetime/route boundary; the
  unaffected loader/refusal/ABI tests remain the regression gate.
