# Calibrate exported DMS decision threshold

## Summary

Calibrate the exported schema-v2 `alpha_offset` on train-only eligible rows so
the retained sidecar's default decision rule targets its oracle eviction budget.
Previously the trainer exported offset zero and left calibration only in the
replay diagnostic, which was insufficient for runtime activation.

## Changes

- Added deterministic global threshold selection from final train logits and
  target labels, including all/none and tied-boundary handling.
- Export `alpha_scale=1` plus the calibrated offset in `dms_metadata.json`.
- Final validation metrics use the calibrated runtime threshold; epoch learning
  history retains threshold-zero diagnostics.
- Training summaries record eligible, target, and calibrated eviction counts.

## Validation

- Fixture calibration reaches its exact target count and validation remains
  above the binding unit threshold.
