# Run committed prompt blocks through the Inkling resident traversal

## Summary

Campaign task 14. In the `fast` profile a committed prompt block of more than one row that
projects only its last row, or nothing, now runs the whole-block device-resident traversal that
the opt-in decode route uses. Before, only the attention half of a block was resident and every
visit crossed the host for its controllers, residual reads and final rows. Now only the expert rows
cross: each visit downloads its normalized rows, routes and projects them through the ordinary
host path, and uploads the branch output. `step_block`, which projects every row for
verification, tap capture and provisional blocks keep the eager traversal.

Measured on `epyc` (Radeon Pro W7900, gfx1100, HIP 7.2.53211), mainline `UD-Q4_K_M`, `fast`
profile, 128 outputs, five repetitions after a warmup, the baseline row's decode-bench command:

| Prompt tokens | First token | Decode | 128 output IDs against the baseline |
| --- | --- | --- | --- |
| 47 | 0.258 to 0.207 s (1.25 times) | 18.17 to 17.92 tok/s | differ somewhere in the 128 |
| 575 | 2.978 to 2.333 s (1.28 times) | 18.01 to 17.83 tok/s | the same |
| 2,057 | 11.968 to 9.702 s (1.23 times) | 17.61 to 17.41 tok/s | the same |

- **The gate passes with the block path in place.** `fast` with device routes, resident decode and
  F32 experts, on a tree that held this change: 744 rows against strict (672 decode rows and 72
  prefill block ends), median KL 1.32e-13, p90 1.23e-5, no row over the damage line, top-1 99.87%
  (one row of 212 in `long_context`). The dense envelope passes too: mean 1.87e-4, p95 5.6e-4,
  p99 5.3e-3, maximum 1.9e-2. Controls, repeats, isolation, public route and the known-answer
  check are as in the recorded row.
- **The block path and the earlier one differ by rounding before the router.** On one 64-row block
  the expert input bytes differed on all 48 visits and the selected experts on 47 of them, which
  are near-tie swaps, and the block's last-row logits still agreed to 5.7e-6. Against strict on
  97 block-end rows the block path has median KL 1.8e-13, p90 1.7e-7 and three rows between
  1.8e-3 and 1.5e-2; the earlier path has p90 3.1e-9 and no row above 1e-3.
- **Through the server:** `hipengine serve --execution-profile fast --kv-storage auto` answered a
  223-token prompt (four blocks) with 12 outputs in 1.58 s and a 3,451-token prompt with 6 outputs
  in 17.3 s.
