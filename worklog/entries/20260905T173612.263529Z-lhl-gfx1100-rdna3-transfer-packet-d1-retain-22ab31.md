# gfx1100 rdna3 transfer packet D1 Q4 selected pairreuse retain

## Summary

Audit packet D1 (docs/20260905-gfx1100-audit.md): the exact Q4 selected
gate/up duplicate-expert pair-reuse dual owner is retained on gfx1100 at
physical c8 through `GGUF_Q4_T16_SELECTED_PAIRREUSE_MIN_ROWS = 8`
(retention commit 7e7b2cecb). Same-protocol p512/d128 native_c8 decode
improves 284.772 → 298.924 tok/s (+4.97%) with fully separated sample
ranges and repeatable trajectories. The audit's promotion requirement is
satisfied: both expert-ID distributions and the real natural reuse
frequency are measured, not assumed.

## Changes

- `GGUF_Q4_T16_SELECTED_PAIRREUSE_MIN_ROWS` 0 → 8 on hip_gfx1100. The
  route's geometry gate (`_gguf_t16_selected_pairreuse_enabled()` +
  `x_rows == 8 and rows == 64`) pins the pairreuse dual owner to physical
  c8; all other widths keep the per-row dual owner. Explicit env 0 still
  rolls back. Selected-down and Q6-down pair reuse stay floored 0 (packets
  D2/D3 unqualified on gfx1100).
- Added the `q4_selected_pair_candidate` route profile to
  scripts/execution_profile_gguf_batch_route_gate.py (package floor-driven;
  the three selected-pairreuse envs are unset, not zeroed).
- Added scripts/gfx1100_packet_d_natural_reuse.py: captures every MoE
  layer's selected expert IDs across packed-AR c8 decode steps on eight
  distinct natural mtpbench prompts (router monkey-patch, diagnostic only).
- Added scripts/diff_differential_arms.py: semantic-axis arm comparator for
  state/lifecycle differential JSONs (strips per-process identity: handles,
  addresses, buffer-identity hashes, raw K/V byte dumps).

## Validation

- Natural distribution (960 layer-steps, 8 distinct prompts, 24 steps,
  40 layers): within-step duplicate-lane fraction 0.61556, mean 24.60
  unique experts of 64 lanes; the direct p512/d128 fixture (four distinct
  prompt trajectories repeated to eight rows) models ≥16 paired lanes of
  64 (0.5). Natural reuse exceeds the fixture, so the fixture bench
  understates the reuse opportunity. Reproduced identically on a second
  run.
- Primitive gates green: `test_q4_t16_direct_dual_pairreuse_matches_production_bits`,
  `test_q4_t16_compact_pairreuse_matches_direct_bits_beyond_64_lanes`,
  Q5/Q6 direct pairreuse, compact down pairreuse (bit-parity with three
  synthetic ID distributions), plus routing scope/env rollback tests.
- RED→GREEN policy: `test_gfx1100_q4_selected_pairreuse_floor_admits_c8_only`
  failed at floor 0 (`assert 0 == 8`) and passes at floor 8; gfx1151
  parity test updated to expect gfx1100 == 8. Full bundle (compact MoE
  routing, rowtile policy, gfx1151 backend, T16 selected decode) 114
  passed; the transient `test_auto_backend_selects_supported_hip_arches`
  failure was the audit shell's `HIPENGINE_BACKEND` env, not code.
- Paired A/B (gguf_packed_ar_bench.py, native_c8, p512/d128, 1 warmup +
  3 measured, same host/protocol): control 284.772 [283.365, 285.888]
  (floor 0, env unset, commit a3293a5fd), candidate 298.924
  [298.161, 300.953] (floor 8, env unset, retention commit 7e7b2cecb).
  Ranges fully separated (285.888 < 298.161). Independent env-on run at
  the same code baseline measured 298.999 [297.504, 300.287], confirming
  the env and floor produce the same route and rate.
- State/lifecycle differentials (oracle steady c2/c4/c8 + shrink_sparse
