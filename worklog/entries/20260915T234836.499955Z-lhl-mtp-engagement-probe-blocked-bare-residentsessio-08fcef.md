# MTP engagement probe blocked: bare ResidentSession prefill stalls on gfx1100

## Summary

The first resident NextN MTP engagement probe on the 27B dense (gfx1100 lane)
stalls in the bare `Qwen35GGUFResidentSession` token-by-token prefill: >17
minutes at ~94-100% GPU[0] for a 16-token sequential prefill, repro'd three
times (twice with default route selection, once with the M6 production
defaults `use_wmma_prefill=True, use_gemv_decode=True` made explicit). The
same model's identical-shaped prefill runs in seconds inside the qualified
TP1/TP2 harness (`MlpTP2GenerationSession` → `Qwen35GGUFFullStackRunner`
with `execution_routes=("eager",)`), and the D1 DFlash2 driver's bulk
prefill loads in seconds on the same session class (its NaN is a separate,
also-recorded defect). The stall is therefore specific to the
ResidentSession prefill driver path on this lane — not model load (the
constructor completes; "prompt tokens: 16" prints), not the draft stack,
and not route-selection flags. Resident-scheduler evidence (M6 bench,
lifecycle gate) is gfx1151-lane qualified; `detect_hip_target_arches()`
here reports only `('gfx1100',)`.

## Changes

- `scripts/tp2_mtp27b_engage_probe.py`: minimal engagement driver (AR
  reference on sequential prefill, then `Qwen35GGUFMTPDecodeSession` over
  `Qwen35GGUFNextNDraftProvider.from_model` with
  `borrow_qwen35_gguf_nextn_fallback_weights`), uncommitted this entry;
  commits with the next unit that lands its result.
- Also established: `scripts/gguf_mtp_bench.py` (M6) is MoE-specific
  (hardcoded `blk.40.nextn.*`, expert-FFN kernel args, `qwen35moe` metadata
  keys) and cannot drive the dense 27B artifact without a rewrite; the
  runner's resident MTP stack is the correct consumer of the parameterized
  `blk.64` draft map.

## Validation

- Repro A (r2, bg-29): default routes, killed at 30 min, log ends after the
  prompt-token print; GPU 100%.
- Repro B (r3, bg-30): explicit wmma+gemv routes, killed at ~17 min, same
  point; GPU 94%.
- Contrast: tp2 e2e/attribution children complete full 16-token prefills on
  this host in seconds (benchmarks/results/2026-09-15-w7900-tp2-*.json).
