# Ignore untracked shared artifacts in serving cleanliness gate

## Summary

The production serving gate treated any untracked file as source dirtiness.
That is invalid in this shared worktree: unrelated benchmark artifacts belong
to other workers and must remain untouched, while only staged/unstaged tracked
source can alter the measured implementation.

## Changes

- Replaced `git status --porcelain` cleanliness with explicit
  `git diff --quiet` and `git diff --cached --quiet` checks.
- Added a temporary-repository RED/GREEN proving untracked files remain clean
  while a tracked edit fails the gate. Git command failures remain fail-closed.

## Validation

- RED: focused test failed because `_tracked_source_dirty` was absent.
- GREEN: focused test passes; Python compile and diff check pass.
