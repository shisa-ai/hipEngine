# Reject fused WMMA R28 production candidate

## Summary

Rejected and removed the default-off T2 fused-WMMA C7/R28 production
candidate. It is decisively faster and 1,915/1,922 evaluated active rows have
small drift, but one real `general_en_plan` transition flips target top-1 on all
seven slots with KL 1.009. This fails the absolute production ceiling and
changes speculative cycle/acceptance scheduling. Prompt-conditioned exclusion
would violate anti-gaming rules, so R28 retains the exact fallback globally.

## Changes

- Removed `GGUF_SPECDEC2_Q4_DUAL_SILU_PRODUCTION_R28_POLICY`, its environment
  flag, runtime policy iteration, selector test, and open REFACTOR entry.
- Corrected diagnostic capture metadata from ambiguous `active_mask` to
  `slot_active_mask`; candidate tokens are overlaid on device after the host
  layout and cannot be classified from placeholder token IDs.
- Kept generic packed-verifier numerical capture tooling because it closes a
  real production-profile evaluator gap and is inert unless explicitly enabled.
- Added a compact rejection artifact; no benchmark scoreboard row changed.

## Validation

- Leaf/marker: fused R28 is **1.486–1.490x** faster on layers 0/32/64; C7 target
  wall/device union improve **8.42%/8.76%**, and profiled complete throughput
  improves **5.06%** with exact IDs and marker acceptance.
- Full task/performance gate: pooled **76.434→82.134 tok/s (+7.46%)**; both
  orders win all 20 prompt cells by at least **4.48%**, every category/heldout
  slice improves, and all 140 generated-ID rows match. Accepted-token total is
  1,099 in both arms, but candidate emits 1,400 drafts versus strict 1,393 due
  to one extra cycle on `general_en_plan`.
- Full-logit strict-teacher reconstruction covers **1,922 active rows** with
  exact metadata/schedules and bit-exact candidate repeat. Global
  mean/p95/p99/max KL is **0.003747/0.000382/0.002002/1.00910**, top-1
  **99.636%**. Seven R28 rows at position 56 have strict/candidate top-1
  **424/25** and KL **1.00910** each; general_en top-1 is **98.056%**. The
  absolute max-KL ceiling is 0.05, so the packet fails.
- Outside those seven rows, **1,915 rows** have mean/p95/p99/max KL
  **7.22e-5/3.27e-4/0.001577/0.003494** and 100% top-1. This localization does
  not authorize prompt-conditioned dispatch.
