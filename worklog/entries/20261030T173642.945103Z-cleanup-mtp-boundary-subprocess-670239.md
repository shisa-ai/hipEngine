# Isolate the dense MTP context-boundary reproducer

## Summary

The dense 1024-context MTP sentinel reproducer is now runnable in a bounded
child process instead of being unconditionally skipped. This completes the
local isolation prerequisite of R0385, not the numerical repair. The exact
original model is absent locally; an alternate artifact was not substituted.

## Changes

- Added `tests/_gguf_mtp_boundary_isolation.py`: executes the original guarded
  body with the current interpreter, bounded timeout, captured diagnostics and
  explicit skip propagation. A failed/timed-out child starts no following GPU
  work. A successful child exits before a second fresh-process health request.
- Moved the original test body unchanged into a private worker function in
  `tests/test_live_qwen35_gguf_mtp_e2e.py`; kept HIP/model/backend/free-memory
  guards inside the child as well as parent collection guards. Removed only
  the unconditional skip, not runtime handoff protection.
- Added CPU tests for success ordering, exit/signal/skip handling, timeout and
  the real test's isolation wiring. Updated the ledger to retain only the
  reproduction/repair and full validation work.
