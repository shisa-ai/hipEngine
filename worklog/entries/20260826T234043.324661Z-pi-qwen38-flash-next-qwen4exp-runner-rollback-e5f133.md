# Add transactional Qwen4Exp runner rollback

## Summary

Added one request-local transactional snapshot/restore owner spanning Qwen4Exp
GDN/Conv/PLE/residual state, PLE hash history, attention live cursors, and raw
QSA index cursors.

## Changes

- `Qwen4ExpRunnerSnapshot` captures the existing exact device-state snapshot,
  immutable PLE hash states, and logical next-token position.
- Restore reinstates mutable device state and host hash history, bounds all
  paged K/V readers to the restored live cursor, and resets each index owner to
  the same count. Append-only K/V/index payload beyond the cursor is ignored
  and deterministically overwritten by subsequent steps, avoiding unnecessary
  multi-GiB cache copies.
- Index count restoration validates capacity; reset is the zero-count sibling.

## Validation

- RED: complete runner had no transactional snapshot API despite primitive
  state snapshot coverage.
- GREEN: composed runner rollback, exact device-state snapshots, and host index
  state files -> `8 passed`; the composition test verifies both attention and
  index owners plus PLE history at a three-token cursor.
