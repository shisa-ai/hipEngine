# Block exact row-tiled QSA prefill

## Summary

Blocked an exact row-tiled/persistent QSA prefill implementation after static
geometry showed that it cannot attack the measured device owner.

## Changes

- Recorded the incumbent CTA, thread, barrier, and selected-count constraints.
- Declared exact sparse-prefill QSA exhausted at H256 after the separate
  selected-token decomposition also failed.

## Validation

- Source audit: one 256-thread CTA owns each row/head and executes one initial
  barrier plus ten barriers for every selected token. The chunk already exposes
  512 × 24 = 12,288 CTAs.
- Four exact rows consume the 1,024-thread block limit while preserving total
  wave work. Variable counts require masked full-stride loops to keep block
  barriers legal. Wave reductions or partial summaries change association.

## Next

- Re-rank to an independent owner. Admit future sparse-prefill QSA only as an
  explicit T1/T2 production-numerics candidate with strict fallback.
