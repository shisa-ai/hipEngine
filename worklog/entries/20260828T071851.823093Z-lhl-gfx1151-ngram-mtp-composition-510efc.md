# Add independent ngram code repetition benchmark

## Summary

Added a repo-owned, repetition-heavy code-copy fixture and a thin wrapper around
the existing SPECDEC2 performance bridge. The suite has four independent
Python/TypeScript/Rust/SQL prompts and a fixed 2-train/2-heldout split. It is an
explicit workload diagnostic for n-gram replay and cannot replace the mandatory
canonical ten-prompt/four-category gate.

The wrapper changes only the prompt contract. True AR, SPECDEC2 execution,
timing ownership, correctness, memory/lifecycle, clean-source provenance, and
artifact validation remain owned by `scripts/specdec2_perf_bridge.py`.

## Changes

- Added `benchmarks/prompts/mtpbench-code-repetition.jsonl`.
- Added `scripts/gguf_ngram_mtp_code_bench.py` with fixed prompt IDs and heldout
  identities.
- Added focused fixture/wrapper tests; no runtime or policy change.

- `--help`, Python compile, Worklog2, and diff checks pass.
