# 24GB compact DMS serving and bounded MTP normalization

## Summary

Prioritize usable context on 24 GB over modest prefill speed regressions. The MTP-capable metadata-path adapter now selects the existing two-pass compact DMS prefill. With completed compact layers temporarily staged on host, the configured 131,072-token server completed a 131,039-token prompt plus 32 generated tokens, with MTP active and default prefix caching enabled. Automatic sizing selects 110,592 tokens and served a 2,048-token prompt plus 32 output tokens with MTP active. The fixed-context non-DMS control also passed with identical output. This is a synthetic capacity result, not a throughput or task-quality claim.

## Changes

- Select `dms_prefill_mode="layer_outer"` for the metadata-path serving adapter without disabling MTP or switching adapters.
- Bound MTP normalization to 4,096 hidden rows and subdivide larger handoffs on the same stream. Preserve shifted-row carry, prefix capture, and cancellation semantics. Opening a later sink no longer requires bulk storage to be resident; prefill reacquires it lazily.
- After both DMS passes and cold-prefix capture, retain the published target row in persistent storage and release the bulk workspace before verifier setup. Keep the bulk workspace if the published row cannot be retained. Release collector inputs only after cold capture, which still reads the logits.
- Keep portable NextN prefix KV snapshots as owned host byte arrays. Restore them byte-for-byte into the destination provider slot; retain the small boundary row and recurrent-state backups on device. Request-local transaction checkpoints are unchanged. `nbytes` remains device-byte telemetry, with `host_nbytes` reporting host KV storage separately.
- Price DMS target scratch without dense KV. Add compact codec payload/scales/positions, output headroom, the shared oracle, full hidden storage, collector/projectors, decode split workspace, optional head-major buffers, and bounded normalization. Preserve explicit transient environment overrides.
- The conservative compact-slot envelope allows nearly the entire context as output after a short prompt; it does not assume the configured compression ratio bounds decode allocations.
