# Wire public Qwen4Exp MTP generation

## Summary

Wired Qwen4Exp MTP through the public speculative-provider registry and `LLM`
surfaces. A prompt16/output4 target+sidecar smoke preserves all generated IDs
and exposes a buffered speculative stream. Natural 512/1K and HTTP server gates
remain open.

## Changes

- Added `Qwen4ExpMTPTextProvider` keyed by provider/model/backend/quant.
- Prompt prefill captures widened target rows and primes independent draft K/V.
- Candidate budgets 1–4 use sequential strict target verification; accepted
  prefixes advance, mismatches publish the target token, and draft cursor trims
  to the exact target commit position.
- Generator attachment exposes public blocking, legacy MTP, explicit provider,
  buffered streaming, capability, and close ownership surfaces.
- Marked the model plugin MTP-capable when an explicit sidecar provider is used;
  AR remains the default/fallback.
- Artifact:
  `benchmarks/results/2026-08-28-gfx1151-qwen38-flash-next-mtp-public-smoke.json`.

## Validation

- Fake verifier pins accepted/mismatch cursor semantics and exact output.
- Focused provider/draft/generator/model/registry bundle: 17 passed.
- Public `LLM` prompt16/output4: AR IDs and MTP IDs both
  `[264,264,264,264]`; buffered stream returns the same IDs and provider
  capability declares target-AR fallback.
- Synthetic cold/warm timing is explicitly non-comparable and not retained as
  performance evidence.
