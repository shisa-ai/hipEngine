# Bind G1 prefill quality in DMS evaluator

## Summary

Aligned the new DMS campaign G1 evaluator with the frozen campaign wording:
prefill logits now satisfy the same max-KL, top-1, category, and finiteness
screen as decode rows instead of serving only as a finiteness diagnostic.

## Changes

- Added explicit G1 prefill thresholds (`max KL <= 0.05`, top-1 >= 90%).
- Applied G1 prefill and decode checks globally and independently per category.
- Added a regression test where decode passes but one category's prefill KL and
  top-1 fail.
