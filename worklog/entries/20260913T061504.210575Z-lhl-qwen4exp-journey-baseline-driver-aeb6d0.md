# Add full-category Flash-Next AR MTP baseline driver

## Summary

Add a diagnostic full-category request-wall driver for the requested pwilkin
journey comparison. It measures real AR and explicit B2 MTP on the same UD
target/Q8_0 sidecar, with no runtime or kernel changes.

## Changes

- Reuse the canonical HTTP/provenance helpers and the committed ten-prompt
  suite; serialize identical raw token arrays for both engines.
- Report full/train/heldout/category ratios, exact output counts, per-repeat
  output IDs, same-schedule repeatability and equality to each engine's own AR.
- Keep external sequential server arms and local counterbalanced arms explicit.
  All results are diagnostic; this driver cannot promote an inference variant.
- Preserve partial results and server logs on failure, and terminate owned
  servers on every exit.
