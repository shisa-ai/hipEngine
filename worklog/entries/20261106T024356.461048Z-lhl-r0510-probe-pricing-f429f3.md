# Price bounded scratch probes before server warmup

## Summary

Connect server width preflight to the backend's temporary scratch-probe price.
Keep the width guard and full-session fallback for other backends.

## Changes

- Expose optional scratch_probe_capacity_estimate through LLM and Qwen35 GGUF.
  It prices the same bounded context used by release-only probes.
- Startup uses that estimate for width multiplication, without modifying request
  context or resident capacity policy. Existing guard still reduces over-budget
  probe widths; backends without the hook retain full-context pricing.
- Add integration test whose full-context price cannot fit four sessions but
  bounded-probe price can, asserting startup retains configured width four.
