# Implement R0511 constructor rollback for GGUF resident session

## Summary

`Qwen35GGUFResidentSession.__post_init__` now runs under an explicit
construction rollback. A failure after any acquisition releases every owned
resource exactly once in reverse-safe order, keeps a borrowed runner alive,
and re-raises the original `BaseException`. Cleanup failures are attached as
notes instead of replacing it.

The repair also hardens the nested owners the constructor reaches:
`Qwen35GGUFFullStackRunner.close` now attempts mapped-host cleanup and resident
weight release independently, `_map_host_token_embedding` preserves a mapping
failure when unregister also fails, the external-DMS dense prefill pool records
its allocation before binding so rollback can release an allocation that never
reached `_device_kv_allocation`, `_FullStackScratch.allocate` is transactional
over its own real allocations, and the bulk-prefill workspace keeps its
head-major acquisition inside the same rollback boundary.

## Changes

- `hipengine/runtime/qwen35_gguf_runner.py`
  - Added `_rollback_failed_session_construction` and
    `_rollback_failed_full_stack_runner` construction wrappers.
  - Added `Qwen35GGUFResidentSession._rollback_construction`, the single
    explicit release owner. Acquisition/release map:
    - owned runner -> `runner.close()`; borrowed runner -> detach only;
    - `_FullStackScratch` owner -> `canonical.close_scratch`;
    - session buffers, bulk-prefill token/hidden/scratch -> one id-deduplicated
      reverse free pass over fields plus `_buffers` and bulk-scratch buffers;
    - verify/rollback/initial/linear/block state -> per-section `close`
      through a rollback-only best-effort release adapter that records each
      failed free and continues; ordinary `close` keeps strict `free`;
    - packed verify workspace -> `_free_packed_verify_workspace`;
    - DMS pending and bound allocations -> one release per distinct allocation,
      then dense-prefill pool close;
    - DMS backend/projector/decision buffers -> their existing owners;
    - flight recorder -> device synchronize, then close;
    - expert-sidecar/library references -> detach (build handles are cached).
  - Recorded borrowed ownership before reading `shared_runner.runtime`, so a
    failed read cannot close the caller's runner.
  - Added `_dms_pending_allocation`; `_initialize_external_dms_serving` now
    publishes pool and allocation before `bind_device_kv_allocation` and leaves
    cleanup to `_rollback_construction`.
  - `Qwen35GGUFFullStackRunner.close` now attempts mapping cleanup and weight
    release independently, detaches weights before freeing, and notes a
    secondary cleanup failure on the primary one.
  - The host-token-embedding placement failure path now relies on the
    constructor wrapper's single `close` call, so mapping and owned-weight
    cleanup run once and the original placement error is preserved.
  - `_map_host_token_embedding` now catches an unregister failure, attempts
    unregister once, records it as a note on the original mapping failure, and
    re-raises that original failure so the constructor wrapper still releases
    owned weights.
  - Added `_AllocationRollback`, a narrow private best-effort owner used by the
    constructor-reachable acquisition seams. It tracks each real allocation
    immediately, deduplicates by object or live pointer, releases in reverse
    order, attempts every owner once, and attaches cleanup failures as notes to
    the original `BaseException`.
  - `_FullStackScratch.allocate` now wraps its existing body in a transactional
    owner. Dedicated mode tracks every `malloc` result at acquisition; single
    arena mode tracks only the real arena and never frees borrowed views.
    Existing allocation order, fallback from a failed arena, shapes, storage,
    and arithmetic are unchanged.
  - `_allocate_prefill_hidden_buffers` now rolls back `hidden_a` if the second
    allocation or the plane-count setup raises.
  - `_allocate_bulk_prefill_workspace` now keeps token, hidden, scratch, and
    head-major acquisition/replace inside one rollback boundary, publishes
    session fields only after success, and notes cleanup failures without
    replacing the original error.
  - The prefill scratch allocator also continues after an individual rollback
    free fails, recording the failure on the original setup error. A three-layout
    regression fails against the ancestor allocator and passes after this repair.
- `tests/test_unit_qwen35_gguf_session_constructor_rollback.py`
  - CPU fault injection at runner, scratch, session-buffer, bulk-workspace,
    DMS, reset, recorder, and late-setup boundaries.
  - Owned-versus-borrowed runner, repeated failure/retry, successful
    constructor plus close, cleanup-error notes, DMS bind-after-publication,
    DMS release/close failures, a mid-sequence canonical-scratch free
    failure that must not stop later releases or runner close, and
    FullStackRunner dual-cleanup coverage.
  - Every allocation in the synthetic constructor's successful path is failed
    in turn, with the count derived from a successful construction rather than
    pinned.
  - The real `_FullStackScratch` allocator is exercised with dense, MoE, INT8,
    and deferred-KV plans. Every allocation, every metadata/router copy, a
    post-acquisition constructor failure, and a cleanup failure are injected;
    single-arena success, single-arena failure, failed arena fallback, and
    fallback failure are covered.
  - Real `_allocate_prefill_hidden_buffers` coverage for second-allocation
    failure, count/setup failure, cleanup failure, and single-plane aliasing.
  - Real `_allocate_bulk_prefill_workspace` coverage for token, first/second
    hidden, and scratch allocation failures; head-major allocation and replace
    failures; cleanup failure; hidden-plane aliasing; and successful
    publication.
  - Real `_map_host_token_embedding` fault coverage for `host_get_device_pointer`
    failing together with `host_unregister`, proving one unregister attempt,
    original-error identity, an unregister note, and owned-weight release by
    the constructor wrapper.
