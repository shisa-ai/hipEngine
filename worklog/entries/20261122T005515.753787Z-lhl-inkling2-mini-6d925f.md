# Run packed Inkling GGUF through public generation

## Summary

Enable ordinary packed HIP text generation for both Inkling GGUF layouts through the public generator registry. The original checkpoint continues to use its existing text and image paths. The new route uses native matrix projections, attention and convolution; orchestration, expert ranking, activation and sampling still cross the host boundary.

## Changes

- Reuse Inkling's causal decoder traversal for GGUF. Bind physical weights and per-visit state, loop queries, GGUF's contiguous gate/up halves, relative-bias orientation, and unpadded vocabulary explicitly. Keep independent request state and the existing staged block attention ordering.
- Read mainline's embedded Inkling BPE and Loom's tokenizer sidecar. The embedded text split uses the pattern declared by the original `thinkingmachines/Inkling-2-Mini` tokenizer at revision `ed40e7da625f594fc9c4990f5f66be24873c22d7`. The packed route reports `inkling2_gguf_packed_hip` and FP32 KV. It does not implement GGUF vision or DSpark.
