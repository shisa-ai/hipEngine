# Drain staged speculative admission rollback

## Summary

Staged batch admission now attempts every earlier retirement after a later
admission fails, including interruption exceptions. Cleanup failures become
notes on the original error instead of replacing it or preventing peer cleanup.

## Changes

- Keep staged retirement inside its existing submission lock and preserve the
  cancel reason while draining all admitted children.
- Add a regression for third-child admission failure plus first-child cleanup
  failure; assert the second child is also retired and the original error survives.
