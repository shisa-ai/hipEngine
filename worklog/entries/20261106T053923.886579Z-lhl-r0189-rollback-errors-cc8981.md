# Preserve PARO rollback errors through synchronization failure

## Summary

Preserve both failures if target/provider rollback and the mandatory device
synchronization fail together. Failed journal restores remain available for retry.

## Changes

- Capture a rollback exception, always attempt synchronization, and
  report both exceptions as a group when synchronization also fails.
- Keep existing single-error behavior and retain checkpoint/journal references
  until rollback and synchronization both succeed.
- Add CPU failure/retry cases with and without simultaneous synchronization
  failure; successful provider restores are not repeated when target retry runs.
