# Force physical C2 target onto strict-teacher state

## Summary

Corrected the C2 production gate so actual packed target arithmetic executes on
strict-teacher resident state rather than requiring a free-running production
root to equal strict. This is the normative production comparison and is
necessary precisely because production generated-ID equality is diagnostic.

## Changes

- Live physical C2 capture now records only request-owned device proposal IDs,
  positions, and scheduling; it no longer treats free-running candidate logits
  as a strict-teacher comparison.
- The evaluator creates two resident sessions sharing one target runner, resets
  each to its strict prefix, replaces only the root with the strict teacher root,
  and executes one real packed C2 target for the pair.
- Every exact ragged shape gets one discarded warmup plus three full-vocabulary
  physical repeats. Their hashes/top-1/input schedule bind determinism.
- Each physical logit row is compared with strict serial target arithmetic on
  the identical inputs/context. Live proposal repeatability and physical-logit
  repeatability remain separate sub-gates.
- Updated host tests to reject missing repeat or proposal-input drift.
