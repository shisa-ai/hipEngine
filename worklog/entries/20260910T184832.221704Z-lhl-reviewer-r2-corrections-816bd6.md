# Reviewer R2 corrections: allocator regression + withdrawn cwidth metric

## Summary

The second review's five findings, acted on in its priority order.

## Changes

1. (High, fixed) The P4 corrective commit introduced a regression: the
   private-allocation branch was nested under `if kv_pool is not None:`,
   leaving kv_backing undefined for ordinary private sessions. The nesting
   is repaired (lease resolution under the kv_pool guard; the
   lease/private branch applies to both pool and pool-less paths). All
   three previously failing allocator test nodes and the full allocator
   selection bundle pass (135 tests).
2. (High, fixed) The C-width harness's decode metric was invalid (one
   isolated prefill subtracted from a wall containing width prefills; N x
   C1 called a serial baseline). The harness now records actual reported
   completion token counts and a complete-request throughput field, labels
   the decode-only figure as an explicitly-derived estimate, and documents
   the missing model-step-timed split and real same-GPU serial reference.
   The published artifact keeps the original measurements under
   `original_measurements_preserved` with the 31%/13%-of-serial
   conclusions WITHDRAWN; the valid observation is that complete-request
   throughput is approximately serial at C1/C2/C4 on this route (C2 wall
   ~2.0x C1, C4 ~4.0x).
3. (Medium, fixed) The decode-boundary ladder's R1 is labeled for what it
   is: a private session through the packed ENTRY (executor-entry cost
   only), not the roadmap's server pool/scheduler R1; R3's whole-request
   wall is labeled as not isolating the service cost. README claims
   adjusted ("~2% service wrapper" withdrawn).
4. (Medium, fixed) The "sub-ms/token HTTP transport overhead" claim is
   withdrawn: chunk gaps measure delivery cadence, chunks need not map
   one-to-one to tokens, and the artifact's difference field was
   whole-request SSE-minus-blocking. The README now states what was
   observed without the transport-cost claim.
5. (Medium, fixed) Publication contradictions resolved: the roadmap
   section 1.1 lead now distinguishes landed/diagnostic/qualified per
   packet (P1-P3 diagnostics with packet gates outstanding; P2 an
   observation harness); the capacity claim is a tier-1 allocation-validity
   bracket of DECLARED contexts (one 2,048-row request per point, not
   full-length completions) with the cross-card direct-ceiling comparison
   removed; the paired-reps row reports the 89-104% cross-rep variance
   honestly ("consistently within 5%" not established); the README parity
   section no longer calls layer-outer the default.
