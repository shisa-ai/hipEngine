# D2b native drafter forward wiring (conv+attention+MLP+selector)

## Summary

Wired the D2a native kernels (grouped dynamic conv, sliding attention, top-16,
candidate selector) plus the reusable DFlash drafter kernels (rmsnorm, qkv
projection, head-rmsnorm-rotary, dense bf16, silu_mul, add) into a torch-free
`DFlash2NativeDrafter.forward` + `select` module
(`hipengine/speculative/dflash2_native.py`). The composite forward now
reproduces the exact numpy oracle (DFlash2NumpyDrafter) to BF16 tolerance and
is deterministic.

## Changes

- `hipengine/speculative/dflash2_native.py` (new): native drafter module —
  weight upload via persistent host staging buffer, per-layer projected-context
  K/V cache (f32 K / bf16 V, rotary), block forward, top-16 selector.
- `hipengine/kernels/hip_gfx1100/speculative/dflash2.hip` / `dflash2.py`:
  sliding attention kernel + wrapper (dispatch + RED test).
- `tests/test_dflash2_native_kernels.py`: sliding-attention RED test vs CPU
  oracle.
- `tests/test_dflash2_native_forward.py` (new): D2b wiring tests —
  determinism, bf16-tolerance vs numpy oracle, select-path == numpy propose.
- `scripts/_xval_dflash2_forward.py` (new): native-vs-numpy cross-validation
  driver (bf16-tolerance gate).

## Validation

- `uv run pytest tests/test_dflash2_native_kernels.py tests/test_dflash2_native_forward.py`
  → 10 passed.
- Cross-validation (`_xval_dflash2_forward.py`): forward matches numpy oracle
  with mean abs err 0.08 on |ref| up to ~11 (bf16-tolerance gate PASS);
  deterministic byte-for-byte across runs.
- `select` path equals numpy `propose` draft tokens exactly on the fixture.
- `rocprofv3 --kernel-trace` smoke (3 forward+select cycles, small-vocab
  driver): all expected kernels under expected names — grouped conv (60),
  sliding attention (15), head-rmsnorm-rotary (15), qkv proj (15), dense
  bf16-to-bf16 (95), dense bf16-to-f32 (8), silu_mul (15), add (30), rmsnorm
  (33), top16 (3), selector proj (3), selector walk (3); zero scratch on hot
  kernels. This rocprofv3 version reports equal start/end timestamps so
  DurationNs is unavailable (documented profiler variant).

## Key decisions / bugs found

1. **Final-norm anchor off-by-one**: the final norm must skip the block anchor
   row and write `block_size-1` draft rows (draft_hidden is 7 rows); the
   original call wrote 8 rows from row 0 (also overflowing into the logits
   buffer). Fixed to read `block_hidden_a + hidden*2`, rows = bs-1.
2. **MLP conv finish in-place alias**: the output-side grouped conv was
   launched with `conv_out` as both input (down output) and output — a
   read-after-write hazard. Added a dedicated `mlp_finish` buffer.
3. **In-place rotary pair-read race**: `dflash_head_rmsnorm_rotary_f32` reads
   paired dims while writing the same buffer; passing `q_out` as both input and
   output raced across threads and made the forward non-deterministic
   (cross-run top1 flips). Added a `q_rot` output buffer.
4. **Output-head H2D quirk**: a raw `copy_host_to_device` into a freshly
   `hipMalloc`'d head buffer corrupts the first bytes (the same
   post-hipMalloc H2D quirk the module routes around). Added
   `upload_weight()` that routes through the persistent host staging buffer.
5. `select` now accepts a scalar or 1-element anchor array.
