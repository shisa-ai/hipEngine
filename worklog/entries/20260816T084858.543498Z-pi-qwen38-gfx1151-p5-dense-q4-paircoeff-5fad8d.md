# Screen dense Q4 adjacent-pair payload reuse

## Summary

Reject the transfer of Laguna's adjacent packed-Q and aligned coefficient-pair
reuse into Qwen3.8's dominant residual-Q8_1x2 split-weight gate/up owner. The
candidate is BF16-bit exact and positive on all three actual layers, but changes
the family only **1.431580 -> 1.425980 ms (1.00393x, 38/45 wins)** and projects
**0.1200 ms/token / 0.1524%** of selected 4K kernel wall, below the predeclared
1% operation-complete admission threshold.

## Changes

- Started from measured source evidence, not a geometry retry: Laguna's
  same-layout adjacent-column Q-byte reuse improved its gate path **1.945%**,
  and aligned d/dmin plus scale/min pair loading then improved the leaf
  **11.3508%** while lowering VGPR. The source artifact is
  `benchmarks/results/2026-07-30-gfx1151-laguna-q4-t16-paircoeff-retained.json`.
- Added a transient standard-Q4T16 sibling that loaded one packed-Q byte and
  aligned coefficient pair for adjacent columns while preserving the retained
  K ownership, Q8_1x2 activation producer, dp4a/FMA order, two-wave per-weight
  merge, BF16 boundaries, and SiLU publication.
- Screened layer 0/8/63 gate/up pairs. Every raw pair is **95.625 MiB**, and
  resident standard-T16 ownership remains **103,055,360 bytes** with no new
  workspace.
- Removed the transient kernel, wrapper, registry entry, and RED/GREEN fixture
  after the leaf stop; production source and tests are byte-identical to the
  base commit.
- Preserved compact evidence at
  `benchmarks/results/2026-08-16-gfx1151-qwen38-27b-q4-paircoeff-rejected.json`.

  32-MiB MALL. Layer speedups are **1.00434x/1.00372x/1.00372x** with
  **13/15, 13/15, and 12/15** wins.
- Actual outputs have zero BF16 mismatches, max absolute error 0, KL 0, 3/3
