# Bound eager packed workspace reservation and price private growth

## Summary

Eager packed workspace reservation is bounded to the existing 1,024-token
context floor per serving slot. Longer realized contexts use the existing
budgeted private backing. The estimator prices both holdings instead of
mistaking deferred allocation for eliminated memory demand.

## Changes

- Bound `packed_verify_workspace_lease_pages` independently of admission context.
- Report and include `private_workspace_bytes` in the breakdown and capacity
  estimate when full-context geometry exceeds the eager floor.

  HTTP readiness and completion checks to the cancellation/refill test.
- Resolve the reservation ledger entry and triage it. No new flag or arithmetic
  change. Server context already reaches the LLM; no duplicate knob was needed.
