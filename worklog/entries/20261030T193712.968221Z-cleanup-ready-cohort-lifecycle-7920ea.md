# Validate repeated public cohorts and independent server lifecycles

## Summary

Complete R0198's ready-cohort behavior and lifecycle checks on gfx1151.
Repeated C1/C2/C3 HTTP requests matched the singleton control, native prefill
handled the full groups, a short child completed before its long neighbor,
and an injected child-completion error did not fail the successful peer or
subsequent request. A real network disconnect also allowed request reuse.
