# Complete gfx1151 queue full-width matrix

## Summary

Completed the full canonical-width hardware-queue screen for gfx1151
Qwen3.8-27B Q4_K_S FP16-state serving: five queue policies, two
counterbalanced blocks, and 13 widths per child. All 10 children / 130 width
executions pass binding production control, native route/no fallback, memory
recovery, shutdown, and GPU-health gates. No MES lockup, timeout, or surviving
KFD process occurred.

The full-width result supersedes the core screen's queue1/queue8 finalist
interpretation. Queue2 has the highest normalized geometric-mean throughput,
but no queue policy wins generically. Queue1/4/8/unset are only
0.75%/0.64%/0.50%/0.42% below queue2 across all 26 matched block-width ratios.
Queue8's core c32 gain reverses in both full-width blocks (-3.68%/-6.90% vs
queue2). Keep queue2 as the current control without a new promotion; stability
and context sweeps remain binding.
