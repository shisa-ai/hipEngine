# Slot reset and prefix clone flush deferred packed decode state

## Summary

The sentinel-token and flush-wedge family closes at its root: session
reset() and _commit_prefix_state_clone cleared the shared packed decode
bookkeeping blindly, so recycling one slot (row completion / prefix
clone) discarded the deferred recurrent/KV state of every other
in-flight decode row. Surviving rows then continued from stale state and
sampled sentinel tokens, or later rounds wedged trying to flush
dirty-with-no-recipients state. Pre-existing behavior, exposed by the
union workspace making serving reachable.

## Changes

- reset() and _commit_prefix_state_clone flush deferred packed decode
  state (scatter back to recorded sessions) before clearing shared
  bookkeeping; raise if the flush fails.
- flush_packed_decode_state treats dirty-with-no-recipients as already
  discarded: clears stale flags and succeeds so callers re-gather via
  the initial-state sync instead of wedging.
- Prefill slab tail clears dirty before sessions so no reader can
  observe dirty state with no recipients.
- Reset-contract test updated to assert the flush happens first.

- Stability, packed verify layout, device KV binding, sampling bundles
  green.
- Full canonical gate relaunched from this tree.
