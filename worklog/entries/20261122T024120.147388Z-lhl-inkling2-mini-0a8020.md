# Keep ordered packed Inkling expert mixing and convolution on device

## Summary

Keep the packed expert down projection, ordered weighted sum, and following static convolution on the same device stream. Routing and the gated activation still run on the host. The change leaves the original-checkpoint arithmetic and scheduling unchanged.

## Changes

- Use a separately rounded multiply/add kernel for the GGUF ordered weighted sum. The existing pointwise variant does not round at the same boundary as the host NumPy ufuncs; it differed on the packed test even with fixed route IDs and coefficients.
- Upload the host activation, selected routes, outer scales, and mix coefficients together. Download one mixed row per token, after applying any device convolution consumer. Wide route lists split at the grouped kernel's grid limit without changing token or route order. The unfused host mix remains available if the registered primitives cannot cover the artifact's down projections.
