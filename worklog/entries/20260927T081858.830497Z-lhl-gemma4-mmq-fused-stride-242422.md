# Remove the additive Gemma4 gate/up split; MMQ leaf reads the fused stack by stride

## Summary

The comparison section's first defect is fixed. The Gemma 4 default route kept the
fused `ffn_gate_up_exps` allocation **and** split `gate`/`up` copies, because the
Q4_K int8 MMQ32 leaf derived each expert's weight stride from its own output width
and so could not read a fused stack. Peak device use was 32.35 GB and Gemma 4 no
longer loaded on the 24 GB RX 7900 XTX.

The leaf now takes an explicit `expert_stride_rows` (0 keeps the old per-half
behavior for every other caller), so Gemma 4 passes the fused width with the up half
addressed one half into each expert's block. The split scaffold is deleted and the
fused allocation is the only copy again. Same leaf, same arithmetic, no second
resident copy.

## Changes

- `hipengine/kernels/hip_gfx1100/quant/gguf_q4_k_q8_1_selected_prefill.hip`:
  `expert_stride_rows` threaded through the MMQ32 body, the shared launcher and the
  RAW/X8/T16 `extern "C"` entry points; the ds4x3 and guarded callers pass 0. The
  raw layout uses the stride, the repacked layouts carry their own indexing.
- `gguf_q4_k_q8_1_selected_prefill.py`: keyword `expert_stride_rows` on the mmq32
  wrapper plus the matching `c_int64` in `argtypes`, and a `_check_mmq32_common`
  span check.
- `hipengine/loading/gemma4_gguf_device.py`: dropped `split_gate_up`,
  `_mmq_split_requested`, `_is_fused_expert_gate_up` and the gate/up materialization.
- `hipengine/kernels/hip_gfx1100/gemma4/gemma4_experts.py`:
  `gemma4_project_experts_mmq_dual` reads `raw` with `expert_stride_rows=fused_width`;
  deleted `_MMQ_DUAL_WEIGHTS_ARE_SPLIT` and its refusal.
- `tests/test_gpu_gguf_q4_k_q8_1_selected_prefill.py`: fused-stride runner variant,
  a bit-identity test with a deliberately truncated stride as the negative control,
  and wrapper-validation cases.
- `docs/campaigns/GEMMA4-26B-A4B-OPTIMIZATION.md`: iteration 152; the iteration-136
  clearing condition and the iteration-137 additive-split paragraph now point at the
  resolution; the defect bullet and recommended-order item 1 are marked done.
