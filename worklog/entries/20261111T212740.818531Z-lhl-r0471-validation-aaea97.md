# R0471 public validation model-blocked: native-row admission needs UD-Q3_K_M

## Summary

Attempted the R0471 public engaged/unengaged native-row generation on gfx1100 through
`LLM.generate_detailed()` with a compact 4-prompt greedy batch. The scheduler integration
(committed 4b83dd727) is exercised, but every locally present GGUF artifact is refused by
`ar_decode_native_rows` admission with a named capability miss. The route requires BF16
recurrent `ssm_alpha`/`ssm_beta` weights AND resident device operands — the UD-Q3_K_M
artifact class — and no UD-Q3_K_M GGUF is on this machine. The public device run is
therefore model-availability-blocked, not an implementation defect.

## Changes

No production code change in this unit; `docs/REFACTOR.md` R0471 updated to record the
implemented integration and the model-availability blocker. Validation harness:
`/tmp/refactor-gfx1100/r0471_public_validation.py` (forces `native_batch_decode=True` at
generator construction because the route is a load-time session choice, runs engaged then
unengaged multi-prompt greedy generation, reports `native_rows_decode_steps` deltas).

## Validation

Measured admission outcomes on gfx1100 (W7900), `LLM(model, backend="hip_gfx1100")`:

- `/models/gguf/Qwen3.5-0.8B-Q4_K_M.gguf`: refused — `ssm_alpha`/`ssm_beta` are Q8_0
  (`gguf_q8_0_t16_v1`); native multirow owner needs a dense BF16 resident for the
  `dense_gemv_out_bf16` uint16 weight ABI (36 consumer_unqualified slots).
- `/models/gguf/Qwen3.8-27B-UD-Q4_K_M.gguf`: refused — "ar_decode_native_rows requires
  resident device operands before execution; deferred device slots are not a certified
  native adapter".
- `/models/gguf/Qwen3.6-35B-A3B-UD-Q4_K_M.gguf`: refused — `ssm_alpha`/`ssm_beta` are F32
  (`dense_f32`), again not the required dense BF16 resident.

Also confirmed two route facts while driving the harness: (1) toggling
`native_batch_decode` on a live session raises "ar_decode_native_rows must be requested at
session construction" (`_native_rows_ready` is load-time); (2) the unengaged control
generation runs cleanly on the Q4_K_M artifact (packed/serial default preserved). No
UD-Q3_K_M artifact exists under /models, /data/models, or ~/models (bounded find).
