# Qualify gfx1151 strict MTP2 B1 B2 B3 adapter

## Summary

Qualified the first real gfx1151 staged MTP2 c1 path under strict FP32 recurrent
state. B1/B2/B3 staged outputs match true AR and the unchanged private dense
transactional oracle exactly on the five-token greeting trajectory. B3 executes
one staged cycle with planned depth 3, accepts two drafts, emits the correction,
and then uses one ordinary AR tail step. The explicit `serial_exact` target mode
produces the same IDs as native-eager.

Two ownership defects were found and fixed. Packed Generation-2 prefill returns
host hidden rows but no persistent request `last_target_hidden` pointer, so the
adapter now owns one BF16 root-hidden buffer until verifier commit. More
importantly, Q4_K_S production defaults to FP16 recurrent-state storage, while
the current MTP chain verifier's base-state readers require FP32. The adapter
now rejects FP16 before proposal/target mutation and selects K0; strict S3 gates
run with `HIPENGINE_GGUF_FP16_RECURRENT_STATE=0`. The earlier unguarded attempts
caused repeatable HSA page faults in the documented incompatible GDN path; GPU
health passed immediately after each fault and no restore was required.

## Changes

- Added request-owned packed-prefill hidden handoff and target pointer lifetime.
