# YuE2 checkpoint inventory byte accounting

## Summary

`scripts/yue2_inventory.py --diff` reported a spurious mismatch on both
checkpoints because it compared the inventory's **tensor payload** against the
size the checkpoint's own `weights_manifest.json` declares, which is the
**file** size. The difference is exactly the safetensors JSON header (73,192 B
for `model.safetensors`, 48,200 B for the VAE), so the tooling that exists to
verify the checkpoint never reported a clean diff.

The inventory entry now carries all three quantities explicitly
(`payload_bytes`, `header_bytes`, `file_bytes`), `PINNED` names file and tensor
bytes separately instead of a single ambiguous `bytes`, and `compare()` checks
the pinned file size, the pinned payload, and the internal identity
`payload + header == file`. A payload/file confusion is now a reported problem
rather than a silent acceptance.

## Changes

- `scripts/yue2_inventory.py`: `file_bytes` and `header_bytes` in every entry;
  `PINNED` records `file_bytes` and `tensor_bytes`; `compare()` checks both plus
  the payload+header identity and compares a previous inventory's file size; the
  non-quiet summary prints all three quantities.
- `tests/test_unit_yue2_inventory.py` (new): builds a synthetic safetensors shard
  so the accounting is exercised without the real checkpoint - payload/file/
  header separation, component collapsing, a clean round-trip through
  `compare()`, and two negative cases (a payload compared against a file size,
  and a changed tensor shape). A cached-checkpoint test asserts the real
  checkpoints match the pins when they are present and skips otherwise.

## Validation

- `python3 scripts/yue2_inventory.py --model <YuE2-3B> --vae <YuE2-Vae>
  --verify-hash --diff artifacts/yue2/inventory.json`: both shards report
  `sha256=ok` against `weights_manifest.json` and `diff: inventory matches`
  (exit 0).
- `python3 -m pytest tests/test_unit_yue2_inventory.py`: 6 passed.
- `artifacts/yue2/inventory.json` regenerated with the corrected accounting
  (local, untracked; the script reproduces it deterministically from the
  checkpoint headers).
