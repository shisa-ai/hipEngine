### Japanese near tie and component isolation

At Japanese-plan root index 63 (context 94), same-state serial favors token
97155 by a logit margin of 0.0014343262, while the production verifier favors
4277 by 0.0019607544. Their row KL is 0.0000034773. Widths 2 and 4 favor
97155 on the shared first row; width 3 favors 4277. This is a real same-state
near-tie flip, not solely free-running state drift.

Component arms show an interaction rather than one universally exact switch:
changing only GDN to its strict flag, or changing only the shared-expert flag,
returns top-1 to 97155 and changes the selected commit row from 0 to 2 on that
state. Changing both flags returns top-1 to 4277. The linear-output and
full-attention-suffix selectors do not change logits in these tested arms.
This does not establish that those selectors are irrelevant at other shapes.

For Japanese-explanation B2's initial capture, changing only GDN reduces the
maximum serial-relative KL from 0.0047331725 to 0.0007940284; changing all four
flags gives 0.0048202147. The public attention mode remains `decode_batched`
throughout these flag crosses: the all-strict-flags arm is **not** the full
strict execution profile or a strict teacher. The result is not a reason to
change production defaults from this small sample.
