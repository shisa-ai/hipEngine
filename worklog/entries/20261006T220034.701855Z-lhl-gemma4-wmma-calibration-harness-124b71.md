# Pre-register the WMMA calibration protocol and packet harness

## Summary

Following the lead's 2026-10-07 decision that WMMA-class prefill attention is
admissible for Gemma 4 and the frozen 2026-08-16 bars need re-derivation for
router-MoE models, this unit freezes the calibration protocol before any
candidate result is read and builds the harness that runs it.

`docs/campaigns/GEMMA4-WMMA-CALIBRATION.md` (status: current) pre-registers:
the stability rule -- a teacher-forced row is unstable when the strict arm's
own logits have a top-2 gap under 0.25 (just over two bf16 ulp at the 30.0
logit softcap) or a maximum post-softmax probability under 2^-8; the bars --
every numeric threshold unchanged (mean 1e-3, p95 5e-3, p99 2e-2, max 5e-2,
top-1 99/97), evaluated over stable rows only, with unstable rows reported as
diagnostics; the arms (strict, WMMA candidates, INT8-KV rejected anchor);
the sanity anchors (strict-vs-strict bitwise, INT8 must fail the stable-row
bars by >=3x); and the promotion criteria. No bar was widened.

`scripts/gemma4_production_quality.py` gained the stability classifier and
dual verdicts (legacy all-rows recorded for continuity, stable-row bars
binding), explicit `--candidate-variants` and `--candidate-kv-storage` arms so
the WMMA and INT8 candidates run without touching the shipping default, and
per-case unstable-row diagnostics (count, worst KL, top-1 flips). The
classifier is CPU-tested (13 unit tests pass, including the mask/diagnostics
contract); a two-case GPU smoke run of the WMMA arm produced the first real
data: `code_merge_intervals` 64/64 rows stable, maxKL 0.0187, top-1 100%,
repeats/isolation/task green.

## Changes

- `docs/campaigns/GEMMA4-WMMA-CALIBRATION.md`: new, frozen before the run.
- `scripts/gemma4_production_quality.py`: stability rule, `stable_paired_summary`,
  explicit candidate arms, dual verdicts, diagnostics; the shipping-default
  self-comparison path is unchanged when no variants are passed.
- `tests/test_unit_gemma4_production_quality.py`: classifier tests.
