# Port the frozen legacy journal into Worklog2 entries

## Summary

- Imported all 7,232 pre-cutoff entries of `WORKLOG-LEGACY.md` into `worklog/entries/` as individual immutable Worklog2 entries with `worker: legacy`, superseding the bulk-import non-goal in `docs/archive/PLAN-WORKLOG2-revamp.md` (the lead directed this campaign).
- Each entry's filename timestamp and `base_commit` come from the first Git commit that appended it to the journal, recovered from the full patch history of `WORKLOG.md`/`WORKLOG-LEGACY.md`; zero entries needed the heading-date window fallback.
- Added `scripts/worklog_port_legacy.py` (report/generate/verify) and `worklog/legacy-port-manifest.json` with the full entry-to-commit mapping and anomaly lists.

## Changes

- `scripts/worklog_port_legacy.py`: standard-library-only port helper. Fence-aware journal splitter, commit-map builder over `git log --topo-order --reverse -p -M --full-history --diff-merges=first-parent`, duplicate-heading binding by author date, deterministic sha256 filename suffixes, in-memory Worklog2 schema validation of every generated entry (reuses `scripts/worklog.py`), byte-exact `verify` that regenerates every file from the frozen journal.
- `scripts/worklog.py`: conflict-marker rejection is now line-anchored and fence-aware (documented merge markers in prose or code no longer fail validation; column-zero markers outside fences still do). Heading/section scanning and the fence state machine now follow CommonMark fence rules (≤3-space indent, matching closer with no info string) via a shared `_fence_transition` helper — indented fence-like lines inside fenced code no longer toggle scanner state. `slugify` strips trailing dashes after 48-character truncation, fixing a latent self-check failure for long titles.
- `tests/test_unit_worklog_port_legacy.py`: 17 unit tests covering the splitter, wrap rules, wrapper-fence ranking, commit mapping with union-merge replay dedup, duplicate binding, window fallback, and schema validation of rendered entries.
- 13 ported entries carry verbatim bodies inside a fenced wrapper one backtick run longer than any body fence, because their bodies contain lines that would break the one-title rule (pasted `# ` shell-output comments); the manifest flags them `wrapped`.
- `worklog/README.md`, `WORKLOG.md`, `AGENTS.md`: document the ported entries, the port manifest, and that the frozen journal remains the canonical byte-exact original.

## Validation

- `python3 scripts/worklog_port_legacy.py verify`: 7,232 entries verified byte-for-byte against the frozen journal.
- `python3 scripts/worklog.py check --include-unstaged`: 10,564 valid entries (0.65 s) — no regression for the 3,332 pre-existing entries under the corrected fence and conflict-marker rules.
- `uv run pytest tests/test_unit_worklog_port_legacy.py tests/test_integration_worklog.py -q`: 48 passed (17 new unit tests; the existing conflict-marker rejection tests still fail correctly on column-zero markers).
- Legacy integrity: `worklog/legacy-manifest.json` sha256/bytes/lines cross-checked during generate and verify; `WORKLOG-LEGACY.md` untouched.
- Mapping coverage: 7,232/7,232 attributed; 12,712 append-replay re-adds deduplicated; 60 in-place edit commits and 95 union-merge timestamp inversions recorded in the manifest.
