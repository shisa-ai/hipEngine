# Add strict raw dense IQ2_XS leaf

## Summary

Add IQ2_XS to the existing raw dense strict projection family. Independent
synthetic decode and real-row projection gates pass on zbook / gfx1151. Model
materialization is deliberately unchanged; K_S still uses the BF16 fallback.

## Changes

- Add 74-byte IQ2_XS block decoding with packed 9-bit grid/7-bit sign indices,
  preserving the pinned C scale/magnitude/sign order. Reuse the existing 128
  strided-accumulator, separate F32 multiply/add reduction and BF16/F32 outputs.
- Register linear GEMV/prefill variants on the existing gfx11 peer surface.
  This is the strict unfused primitive, not an optimized fused route.
- Copy the packed table from this tree's gguf_iq_gemv.hip at cab9daff9 and
  verify all 512 entries after magnitude expansion against
  llama.cpp@17252c769a63c1cb650ce98ae309cf4de0da7778,
  ggml/src/ggml-common.h:iq2xs_grid. Preserve the pinned MIT notice.
  The new header participates in the JIT table hash.
- Extend real-row gates to the K_S blk.0.ffn_gate IQ2_XS first/last rows,
  K5120, N3 tail, activation rows 1/3, both outputs, three repeats. Add a
  synthetic one-hot GPU test exposing all independently decoded values and
  selector domains. Projection reductions normalize negative zero; exact
  signed-zero codec equality remains a separate CPU gate.
- Update catalog/campaign/fixture contracts. No model layout, dtype policy,
  arithmetic profile or default selection change; no speed claim.
