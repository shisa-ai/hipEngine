# R0523 c4 race: corruption originates in LATER layer blocks 24-47 (pre-flip)

## Summary

Refined the R0523 source-layer localization with two hidden-input (H) hash runs at
eager c4 (Qwen3.8-27B-Q4_K_M, bf16 KV, strict, identical prompts). Corrected an
earlier misreading: the post-flip hidden divergence is the flipped token fed back
(the consequence), but the LATER layers show a PRE-flip divergence (the cause). The
corruption originates in the later layer blocks (24-47), not the early ones (0-23).
No production behavior changed; diagnostics remain env-gated and uncommitted.

## Changes

- Reused the env-gated `_r0523_norm_hash` H-only multi-layer hook
  (`HIPENGINE_R0523_NORM_HASH_LAYERS`, `..._H_ONLY`) in
  `qwen35_gguf_full_attention_decode_batch.py`. No new production change.

## Validation

Measured (30-rep c4 eager bursts; `/tmp/refactor-gfx1100/r0523-layers2.*`, `r0523-layers3.*`):
- Run A (layers 3,7,11,15,19,23): flip reps' early layers first diverge at live=586,
  i.e. ONE STEP AFTER the token-73 flip (live=585) => post-flip feedback, not the cause.
- Run B (layers 27,31,35,39,43,47): later layers first diverge BEFORE the flip
  (rep5=536, rep19=521, rep3=579, rep17=565, rep22=523; flip=585).
- Cross-run confirmation: rep 3 and rep 17 appear in BOTH runs; their early layers
  diverge at 586 (post-flip) while their later layers diverge at 579 / 565 (pre-flip).
  => the corruption genuinely originates in the LATER layer blocks (24-47).
- Earliest-diverging later layer varies (27/31/35/39/43) => distributed within the later
  blocks; the source sits between sampled full-attn layers (e.g. rep19 between 31 and 35
  = GDN 32-34). GDN conv / recurrent-state snapshot / FFN in the later blocks are the
  remaining suspects; the per-row full-attn kernels and metadata were already cleared.
