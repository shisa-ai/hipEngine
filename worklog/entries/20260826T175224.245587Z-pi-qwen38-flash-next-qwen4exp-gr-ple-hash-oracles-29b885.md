# Add Qwen4Exp GR and PLE hash oracles

## Summary

Added torch-free NumPy oracles for Qwen4Exp grouped zero-centered RMSNorm,
gated-residual read/write, sigmoid-gated GDN output norm, and exact sparse PLE
row hashing with immutable per-request history.

## Changes

- GR read follows grouped norm -> low-rank down -> branch-scaled SiLU -> up
  sigmoid -> gated branch mean, while producing separate injection logits.
- GR write uses `2*sigmoid(inject/branches)` and preserves all four residual
  branches as authoritative state.
- PLE hashing preserves uint64 multiply overflow/XOR, bigram/trigram head
  partitioning, prime offsets, strict-prior EOS cuts, chunk continuity,
  discontinuity reset, and request-local immutable state.
- GDN output uses RMSNorm times sigmoid gate, explicitly not Qwen3.5 SiLU.
