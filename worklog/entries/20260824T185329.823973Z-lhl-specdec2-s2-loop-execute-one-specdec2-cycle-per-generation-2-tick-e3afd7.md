# Execute one SPECDEC2 cycle per Generation-2 tick

## Summary

Integrated the first real SPECDEC2 execution boundary into Generation-2.
`ResidentEngineLoop.submit_speculative()` records cold speculative intent but
uses the ordinary scheduler request, slot, prefill, completion, and reclaim
owners. A decode tick builds typed request semantics, resolves capability,
plans mixed K/K0 before mutation, checks complete fit, and executes at most one
typed runner cycle. Multi-token results publish through the canonical token/
completion event path.

This unit intentionally stops above provider/target lowering: the fake runner
returns a production `SpecCycleResult`, while S2's next units will materialize
frontiers/claims and connect EngineService.
