# Harden AQ6 determinism and control gates

## Summary

A completion audit of the first complete 68-observation AQ6 collection found two
verifier-coverage gaps before publication. The aggregate called repeated oracle
status/result hashes “determinism,” which could miss two distinct normalized
responses that happen to pass the same oracle. The live collector also did not
rejoin the ten frozen independent fail-safe parser/publication controls after
model collection. The raw collection is preserved as diagnostic only; it is not
the retained AQ6 baseline.

The harness now hashes response-owned generated IDs, public content, normalized
calls/arguments, parse errors, and finish state for every observation. Complete
normalized-response fingerprints are required as one set; partial fingerprints
fail closed. The ten policy controls run after development and heldout rows,
produce a `controls_complete` atomic checkpoint, and must all pass before final
ownership and artifact publication.

## Changes

- Added `normalized_response_sha256` to local records and aggregate rows.
- Made `aggregate_quality2_results()` select and report
  `normalized_response_v1` determinism when complete fingerprints are present;
  legacy oracle-only rows remain explicitly labeled `oracle_outcome_v1`.
- Added a RED test where two different direct responses both pass the same task
  oracle; the repaired aggregator now reports a deterministic mismatch.
- Rejoined all ten frozen malformed/truncated/duplicate/undeclared/schema/
  leakage/required/ambiguous/tool-none policy controls into checkpoint, records,
  summary, and validation surfaces.
- Added aggregate Section-9 metrics for terminal observations, JSON/declared/
  strict-schema call blocks, valid calls, correct tool/no-tool selection, exact
  arguments, external-oracle results, oracle kinds, safety outcomes, and
  response-owned token totals without publishing heldout row details.
- Marked per-response repair telemetry unavailable instead of inventing zeroes.
- Added `HSA_ENABLE_SDMA` and `HSA_USE_SVM` to artifact provenance.

The fail-safe controls are correctly labeled
`independent_parser_publication_policy` with `endpoint_exercised=false`; AQ10
owns the later live endpoint/lifecycle campaign. AQ6 does not conflate these
fixture controls with endpoint conformance.
