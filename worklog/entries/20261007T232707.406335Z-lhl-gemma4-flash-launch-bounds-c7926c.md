# Gemma flash decode launch bounds

## Summary

The widened production flash-decode block now declares a two-block residency target through `__launch_bounds__`. This gives the gfx1100 compiler an occupancy/register-pressure constraint without changing arithmetic, dispatch, or fallback semantics.

## Changes

- Added `__launch_bounds__(kFlashThreads, 2)` to `gemma4_attention_decode_flash_kernel`.
- Retained the 256-thread/eight-warp geometry and existing strict fallback.

## Validation

- Exact 64K production decode: 23.6880 tok/s versus 23.6758 tok/s baseline.
- Exact configured guard: 162 focused tests passed.
- Public 64K and 512-token paths reported `path parity=True`.
- Candidate accepted by the active performance loop.
