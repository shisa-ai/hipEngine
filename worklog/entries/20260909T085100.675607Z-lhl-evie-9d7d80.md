# EVIE-4.5B torch-free CPU reference: full-pipeline parity

## Summary

`hipengine/kernels/cpu_reference/evie.py` implements the complete EVIE-4.5B
(ColQwen3_5) forward in float32 NumPy and matches the torch reference
fixture end to end. This is the correctness oracle for the upcoming HIP
runtime and validates that every architectural detail (vision tower, hybrid
text stack, interleaved mRoPE, Prefix-MRL head) is now exactly understood.

## Changes

- `EvieWeights`: BF16 safetensors loader via in-tree
  `read_tensor_storage_bytes` (bf16 -> fp32 view trick; no torch).
- Vision tower: Conv3d patch embed (t2/p16), learned pos-embed table with
  bilinear align_corners=True resample in spatial-merge-block order, 2D
  RoPE on block-major (h, w) patch positions, 24 pre-norm blocks
  (LayerNorm+bias, fused QKV+bias, per-image bidirectional softmax, tanh
  GELU MLP), merger (per-patch LayerNorm, concat 2x2, erf GELU MLP).
- Text stack: tied-embedding lookup, per-layer input/post RMSNorm with
  delta weights (1+w), 24 GDN layers (in_proj qkv/z/b/a, causal conv1d k4
  SiLU, sigmoid beta, g = exp(A_log) * -softplus(a + dt_bias), recurrent
  gated delta rule with l2norm(q)/l2norm(k) (eps inside sqrt), q scaled
  1/sqrt(d_k), float32 state, RMSNormGated with silu(z), out_proj) and
  8 full-attention layers (q_proj doubles as query+sigmoid gate, q/k head
  RMSNorm, interleaved partial mRoPE [11,11,10] pairs over rotary dim 64,
  GQA 16/4, bidirectional), SiLU MLP, final RMSNorm.
- Prefix-MRL head: project -> slice -> per-token L2 (max(norm,1e-12)) ->
  attention-mask zeroing. MaxSim scoring.

## Validation

Against `tests/fixtures/evie/evie_4p5b_doc_query.npz` (torch fp32 CPU,
bit-deterministic):
- visual_features: max 3.6e-05 (rel 6.6e-06)
- query final hidden: max 3.9e-05 (rel 1.3e-06)
- doc final hidden (own vision feats end to end): max 5.5e-04
- doc embeddings 128d: max 1.1e-05
- MaxSim score: 5.9113913 vs reference 5.911393 (1.9e-06)

Bugs found and fixed during bring-up: A_log sign (exp(A_log), not
-exp(A_log)); nn.Linear weights are (out, in) so every projection needs .T;
RMSNormGated applies weight per v-head; cos/sin broadcast alignment for
(seq, heads, dim) tensors.
