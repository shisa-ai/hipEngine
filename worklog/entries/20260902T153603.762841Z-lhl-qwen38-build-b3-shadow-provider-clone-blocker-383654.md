population, then bounded the sole remaining pre-route blocker: the NextN

## Changes

- After resident owner acquisition, the adapter calls
  `shadow_target.clone_current_state_from(real_target)`.

  the shadow owner, and synchronizes before provider work.

  `clone_request_state(real_id, shadow_id)` before capturing both checkpoints.
- Any clone/checkpoint failure releases provider resources and aborts the owner
  bundle atomically.
- Added host tests for target/hidden/provider provenance and the missing-clone
  fail-closed path.
