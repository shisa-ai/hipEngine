### W8A16 primitive/runtime implementation and first sensitivity

Loader/runtime contracts report exact source, qweight, scale, sidecar, and active-read byte counts.
- Added explicit tied-wave8 LM, fused `fc1`+gated-SiLU, fused `fc2`+residual, single/triple projection, and head-major cross-K/V W8A16 families under four-axis registry keys. Host quantization/oracle tests, fake-runtime ownership/lifecycle coverage, and the gfx1151 primitive gate pass.
- Single-component sensitivity rejects the tied LM head, `fc2`, self attention, and cross attention on synthetic generated-token identity. `mlp_fc1` alone passes and records a first paired six-file decoder diagnostic of **5.440 -> 5.340 ms (1.019x)**; final repeated, Tier-B, broader-quality, and profiler gates remain open.

### Phase-6 qualification closure — retain implementation, reject promotion

- The full W8A16 primitive gate passes **5/5** on real gfx1151, including production-shape single/triple/head-major pair, tied-wave8 LM, and fused MLP boundaries versus independent quantized CPU oracles. CPU/fake-runtime tests cover deterministic quantization, all 81 selectable sidecars, fixed-address dispatch, byte accounting, no timed allocation, partial failure unwind, and clean teardown.
- Ordered sensitivity rejects LM head, `fc2`, self attention, and cross attention because each changes the synthetic position-1 token. `mlp_fc1` alone advances and passes full synthetic plus all six real Tier-B gates with exact generation, 100% selected-logit top-1, KL max **6.718e-4**, zero timed allocation, and clean teardown.
- The authoritative alternating 10/30 paired run measures six-file decoder-only median-of-medians **5.477 -> 5.455 ms (1.004x)** and P95 median **5.816 -> 5.718 ms (1.017x)**. Six of seven selected cached event medians do not improve; only position 193 reaches 1.011x. This does not establish a stable general cached-token win.
- A 100-clip Japanese commentary pass feeds identical eager PyTorch FP16 encoder outputs to both graph decoders. W8A16 changes five token sequences, adds 17 character errors versus FP16, and regresses historical-Whisper proxy micro-CER **0.54518 -> 0.54886**; reset reuse is exact 100/100. References are not human labels, so the production CER gate also remains open.
- `rocprofv3` observes the expected `moonshine_w8a16_mlp_fc1_gated_silu_kernel` 8 times/cached token and 40 times/five-token generation at local32/VGPR16/LDS0/scratch0, with exact synthetic generation, all marker regions, finite outputs, and zero allocation.
- Decision: retain the backend-neutral W8A16 format, kernels, loader/runtime sidecars, and FP16 fallbacks as research infrastructure, but promote no quantized family. Phase 7 and the `cuda_sm120a` handoff continue from the FP16 graph decoder. Evidence: `../amd-moonshine-onnx/results/2026-07-31-hip-phase6-w8a16.md` and `moonshine-hip-phase6-w8a16-v1.json`.
