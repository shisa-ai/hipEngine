# Generalize SPECDEC2 dense bridge across gfx11

## Summary

Generalize the newly landed dense SPECDEC2 P1 bridge so the gfx1151 and W7900/gfx1100 campaigns execute the same harness and artifact contract while retaining independent platform evidence. No runtime or adapter changes.

## Changes

- Added explicit `--backend`, `--target-arch`, `--quant-label`, and `--gpu-max-hw-queues` bridge selectors.
- Added `resolve_platform()` to enforce backend/arch identity and prevent the gfx1151 queue-2 campaign default from silently transferring to gfx1100.
- Preserved gfx1151 defaults (`hip_gfx1151`, `gfx1151`, `Q4_K_S`, queue 2) for its parallel campaign.
- gfx1100 resolves `gfx1100`, records its own quant label, and leaves queue policy unset unless the environment or CLI explicitly supplies it.
- Made provenance, host/model identity, environment, and LLM backend construction consume the resolved platform.

## Validation

- RED: generic bridge tests failed collection because `resolve_platform` did not exist.
- GREEN: `uv run pytest -q tests/test_specdec2_perf_bridge.py` passes `15/15`.
- The new test binds gfx1151 default behavior, gfx1100 no-transfer behavior, explicit CLI precedence, and backend/arch mismatch rejection.
- No GPU run is needed for this platform-selection unit.
