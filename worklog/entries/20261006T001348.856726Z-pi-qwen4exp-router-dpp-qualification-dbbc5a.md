# Qualify ordered router DPP on natural inputs and model wall

## Summary

The ordered router DPP sibling passes the complete canonical T0 substitution
check against the live tile4 production parent. All 12 cases preserve 1,548
full-vocabulary output rows per arm through 128 decode transitions, recurrent
state, layout/metadata and full-KV hashes. The private natural-input checker
confirms raw-bit parent/candidate/repeat logits, int64 expert IDs and routing
weights on 576 calls (1,081,344 router rows across all 48 layers).

The gfx1151 UD production profile now selects ordered router DPP by default.
The tracked-clean same-residency twelve-case/three-pair campaign improves
weighted synchronized prefill +0.553%/+0.486%/+0.589% at p512/p1024/p4096,
every case positive. The four GPU row-isolation/ownership tests pass. Strict
and Q4_K_M production keep tile4 and the exact parent remains registered.
The original campaign's code-p4096 final decode sample abruptly slows; a
focused recheck does not reproduce it, and both packets remain available.
This unit claims prefill improvement, not decode-speed or all-case request
wall non-regression.
