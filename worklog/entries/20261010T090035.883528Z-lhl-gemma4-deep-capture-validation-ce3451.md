# Deep capture routes validated: class-global and staged replay bit-exact

## Summary

The two remaining capture routes a whole-step graph could bake -- the
global-logits class kernel (keys past the 64 KiB LDS budget, engaged from
15329 keys at head_dim 512) and the staged singleton deep variant -- were
probed for replay exactness with the engagement bound lifted: at 16384
prompt tokens (class-global) and 32768 prompt tokens (class-global plus
staged), graph replay is bit-identical to the launched path at every step.
Correctness no longer bounds the decode-graph capture window anywhere on
this model; the guard is purely the measured engagement threshold
(`_CAPTURE_MAX_KEYS` = 2176 keys), where the launch-bound prize is real and
device-bound steps keep the launched fallback.

## Changes

- `tests/test_gpu_gemma4_decode_graph_capture.py`: a new test pins the
  class-global route's replay exactness at 16384 prompt tokens with the
  engagement bound lifted (captures > 0, fallbacks 0, logits equal at every
  step), so the correctness component cannot silently regress.
- `docs/REFACTOR.md`: the decode-graph entry's removal condition updated --
  the deep routes are measured replay-exact, so the guard is engagement-only
  and goes when the capture cost falls below the device-bound crossover.

## Validation

- Probe (`/tmp/deep_capture_probe.py`, engagement bound lifted to admit any
  bucket): 16384 prompt tokens, 8 decode steps -- captures=1, fallbacks=0,
  logits bit-identical at every step (class-global route). 32768 prompt
  tokens, 8 steps -- captures=1, fallbacks=0, bit-identical at every step
  (class-global and staged singleton routes).
- `tests/test_gpu_gemma4_decode_graph_capture.py`: 3 pass (the new
  class-global pin plus the existing window cases: 1024/2048 capture
  bit-exact, 4096 engagement fallback bit-exact).
- Docs gates: `scripts/docs/check_all.py` all 4 pass.
- No production or kernel code changed; the engagement bound, routes and
  arithmetic are the committed production state's, so the primary and
  prefill disclosures carry over unchanged (primary band 29.88-30.01,
  prefill band 949-995; last verify 29.927/994.7).
