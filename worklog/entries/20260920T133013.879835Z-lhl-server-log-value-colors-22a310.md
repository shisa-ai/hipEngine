# color log values by what they say

## Summary

`--log-color` styled a structured line's label and dimmed every `key=`, which left
the values - the numbers, sizes, and flags a reader actually scans for - at the
terminal's default weight. Values are now colored by what they say rather than by
which key they belong to, so a new field is legible without editing a map, and the
same rule styles bare measurements, which makes the numbers in a timing or memory
line read as one column.

## Changes

- `hipengine/server/log_style.py`: new `value_color()` plus one scan that styles
  `key=value` fields and bare measurements in a single pass (a second pass would
  nest escapes inside an already-styled value). Quantities are bold cyan with a
  dimmed unit, `true`/`yes`/`on`/`enabled` bold green, `false`/`no`/`off`/`disabled`
  bold yellow, absent markers (`None`, `null`, `unset`, `pending`, `unknown`) dim,
  paths blue, and other values brightened. A value is judged by its last `:`
  segment, so `candidate_budget=requested:None` reads as absent. Only a numeric
  value takes a following unit, so `storage=bf16 pages=4224` keeps `pages` as the
  next key.
- `hipengine/server/log_style.py`: a mixed-case label is styled when it is a known
  label (`KVCache:`, `Config:`) and left alone otherwise, so `RuntimeError: ...`
  prose keeps its plain text while the startup label column lines up.
- `tests/test_unit_server_log_style.py`: value-kind table, measurement styling,
  the `storage=bf16 pages=4224` regression, mixed-case label behavior, and new
  round-trip samples.
- `docs/API.md`: the `--log-color` section now says what each value color means.

## Validation

- `python3 -m pytest tests/test_unit_server_log_style.py -q`: 79 tests pass.
- Round-trip (`strip_styles(styled) == original`) checked over the new samples and
  the existing ones: styling is still presentation-only.

## Next

- Colors were chosen for a dark terminal; a light theme may want the bright
  variants toned down. The scheme is data, not code: `_LABEL_COLORS` for labels and
  the `_*_COLOR` constants for value kinds.
