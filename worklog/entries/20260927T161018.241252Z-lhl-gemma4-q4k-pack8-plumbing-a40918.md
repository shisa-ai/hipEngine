# The q4_k pack8 layout exists, so wiring is plumbing not a repack

## Summary

The remaining unknown from the previous entry - whether the weight carries a
pack8 layout at load - is answered: **the layout already exists**, so wiring the
q4_k selected pack8 GEMV is plumbing rather than a new repack pass.

- `hipengine/quant/gguf_q4_k.py:147` documents a *"Lossless pack8 layout for GGUF
  Q4_K GEMV"* and imports `Q4_K_PACK8_SHAPE` from `hipengine.quant.gguf_repack`.
- What is missing is only the two pieces the other quant types have: q8_0
  (`gguf_k_gemv.py:518`), q5_k (:613) and q6_k (:689) each build their wrapper
  with `_make_selected_pack8_wrapper`, and each has a
  `selected_pack8_gemv_bf16_bf16_out` entry in the variant map (:1599, :1641,
  :1679). q4_k's wrapper at `gguf_q4_k_gemv.py:1503` uses
  `_make_selected_wrapper` instead and has **no map entry**.
- There is an existing switch for this family: `HIPENGINE_GGUF_GEMV_DECODE`,
  described in `gguf_linear.py:161-165` as the opt-in for the GGUF pack8 GEMV
  decode family (P9.B), selecting the `pack8_gemv_decode_*` kernels over the
  legacy `pack8_gemv_*` decoders.

So q4_k selected looks like the one quant type the P9.B1-P9.B4b work did not
reach. That is consistent with the introducing commit being a Qwen35 decode
commit that wired the other three.

**The named clearing step**, since this is now a scoped change rather than an open
question: build the q4_k selected pack8 wrapper, add the variant-map entry, and
confirm the weight carries the pack8 layout at load. Then gate correctness
against the current route and measure decode.

## Validation

- The layout claim is read from the quant plugin's own docstring and import, not
  inferred from the kernel name containing "pack8".
- The missing-plumbing claim is a side-by-side read of the four quant types'
  wrappers and variant-map entries.
- The env var is read from its definition and comment in `gguf_linear.py`.
- **Not yet verified:** that the q4_k weight actually carries the pack8 layout at
  load for this artifact. The layout's existence is established; its production
  for this model is the first thing the next unit must confirm, because a
  registered variant whose weight is unpacked would read garbage rather than
  fail.
