# DFlash2 variable-block forward is a net loss: acceptance -7% (recall@16), flat throughput

## Summary

Ran the native drafter forward at a smaller block size (4 positions for a B3
chain instead of the config block size 8) via a `forward(bs=...)` /
`select(rows=...)` plumbing and `DF2_FWD_BS` env. **Net loss**: on
`code_merge_intervals` acceptance drops 3.08 -> 2.86 (-7%) and recall@16
0.970 -> 0.909, because the drafter's within-block attention is non-causal
and its quality depends on the full trained block context; throughput is flat
(9.29 vs 9.25 tok/s) because the 5-layer forward is launch-bound, not
compute-bound (74ms -> 67ms at bs=4). On the fox prompt acceptance was
unchanged (1.82) but recall@16 also fell (0.892 -> 0.842). Decision: keep the
drafter forward at config block size; variable-block is default-off via
`DF2_FWD_BS` (documented in `docs/REFACTOR.md` for removal).

## Changes

- `hipengine/speculative/dflash2_native.py`: `forward(bs=None)`,
  `_forward_layer(bs=...)`, `_run_attention(bs=...)`, `select(rows=None)`,
  `last_candidates(rows=None)` — backward-compatible, default = config block
  size (RED tests unchanged, 10/10).
- `scripts/dflash2_gguf_cycle.py`: both native cycles pass `bs=fwd_bs` /
  `rows=n_dr` with `fwd_bs` defaulting to `drafter.block_size`; `DF2_FWD_BS`
  overrides for the net-loss experiment.

## Validation

- `tests/test_dflash2_native_forward.py` + `test_dflash2_native_kernels.py`:
  10/10 pass (default path unchanged).
- B3 fox default: acceptance 1.82, recall 0.486/0.892/0.514, AR-exact.
- merge fwd_bs=4 vs 8: acceptance 2.86 vs 3.08, recall@16 0.909 vs 0.970,
  tok/s 9.25 vs 9.29 — net loss.
