# R0387 dense packed-step concurrency evidence and c4 intermittent nondeterminism

## Summary

R0387 dense gfx1100 packed-step profiling follow-up. Collected the matched
concurrency evidence on the W7900 and found a **rare intermittent nondeterminism
in the native c4 packed decode step**. All other measured widths are
deterministic and route-clean. The c4 divergence is real (concrete token-level
evidence) but did not reproduce in 15 focused repeats, so it is a low-rate race,
not a stable arithmetic error. No production code changed; this entry records
the measurement and the defect.

## Validation

All runs: W7900 GPU0 (gfx1100, `HIP_VISIBLE_DEVICES=0`), hermetic TheRock env,
model `/models/gguf/Qwen3.8-27B-Q4_K_M.gguf` (dense), BF16 KV, greedy top-k=1,
VRAM, `--correctness-profile strict`, route expectation `native`. Prerequisite
bundles green: `test_unit_server_f1_concurrency_bench.py` +
`test_unit_gguf_ar_decode_control.py` (85) and the execution-profile contract
bundle (25).

Concurrency sweep (`server_f1_concurrency_bench.py`, concurrencies
1,2,3,4,5,8,13; prompt 512, decode 128, 1 warmup + 3 measured, ctx 1024):
- c1/c2/c3/c5/c8/c13: warmup/measured/repeat-determinism and `route_ok` all pass.
- c4: `measured=False`, `repeat_determinism=False`. Route is
  `gguf_packed_ar_server_decode`, native c-aware, no serial fallback, one shared
  queue group. HTTP throughput c1≈24.9, c2≈41.3, c3≈52.0, c4≈59.7, c5≈65.1,
  c8≈75.3, c13≈62.5 tok/s.

c4 defect detail (sweep artifact `/tmp/refactor-gfx1100/r0387-concurrency.json`):
- 12 measured rows, 11 exact; 1 mismatch at record 9 / request 1, decode position
  73: expected token 6866, observed 3154. Control clean.
- repeat_determinism run_sha256 = [98c588…, 98c588…, 9135818…]: runs 0/1 identical,
  run 2 diverges for request 1.

Reproduction attempts (same model/env/oracle):
- c1+c4, 5 measured repeats (`r0387-c4-confirm.json`): all 5 signatures 98c588…,
  gate passed.
- c1+c4, 10 measured repeats (`r0387-c4-stress.json`): all 10 signatures 98c588…,
  gate passed.
- Net: 1 divergence in 18 c4 runs; 15 focused repeats clean. Intermittent race.

Kernel inspection: the c1 attention shared-memory reduction in
`paged_attn_decode.hip` is correctly barriered; the split-K reduce kernel is
fixed-order/deterministic (note: early-return before a `__syncthreads`); the
single-wave Q5 GEMV "no `__syncthreads`" is a correct single-wave design and not
this model's down path. The c4 race is not yet attributed to a single kernel.

rocprofv3 graph-mode cache-only census (`gguf_packed_ar_rocprof.py`, warm-build
outside the profiler, one ROCTX-marked steady replay, capture excluded; model is
hybrid GDN + full attention, `use_gemv_decode=True`):
- c4: `native_c4_graph_replay_profiler_census` PASSED. One captured replay,
  `full_attention=kv_live_spans_batch`, dense FFN `dense_ffn_rows` (64 gate/up +
  64 down), zero host row loops / steady state transfer, no full-vocab host
  readback. c1 reference 823 dispatches / 30.5 ms GPU; c4 packed replay 31.3 ms
  GPU (diagnostic only, not throughput).
- c2: tokens all exact and route_check passed, but the overall census is a
  FALSE-NEGATIVE: the `dense_q6_down` filter matches only the
  `…rowtile_col8_kernel` signature (`unsigned char const*, unsigned short*`) and
  misses the `…rowtile_col8_residual_kernel` variant (residual input is
  `unsigned short const*`). c2 down is 32 col8 + 32 col8_residual = 64 (correct);
  the filter counts 32 and fails `len == total_layers`. Harness counting bug, not
  a model defect.
- Family Amdahl (c1 reference): dense_projection ≈ 78.9% of GPU duration.
