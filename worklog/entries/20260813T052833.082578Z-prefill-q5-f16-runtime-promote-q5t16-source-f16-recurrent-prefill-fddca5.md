# Promote Q5T16 source-F16 recurrent prefill

## Summary

Promoted the previously retained Q5T16 source-F16 diagnostic into the existing
Qwen3.6-27B bounded T16/rocBLAS prefill owner. Only recurrent-output
K6,144/N5,120 bulk rows are admitted on gfx1100; the route casts the dead BF16
activation in place, reuses the existing liveness-aliased weight/output planes,
and keeps the sole resident Q5T16 payload. Decode, verifier/MTP small rows,
peer backends, shape misses, and explicit owner rollback retain exact T16.
