# Segment Laurent MTP proposal requests

## Summary

Added request segmentation to the existing llama.cpp verbose MTP proposal parser.
Every `new prompt` marker now starts a monotonically indexed request; subsequent
draft calls record that request index and its prompt-token count. The artifact
also summarizes draft-call count per request. This is the host-only prerequisite
for pairing first-cycle Laurent proposals with teacher-forced contexts.
