# Add counterbalanced Qwen3.8 dense-pair A/B

## Summary

Added a durable route-local performance harness for the Qwen3.8 rows1
H=5,120/N=17,408 dense gate/up+SiLU policy. It holds one model session resident,
forces the registered strict GDN context for both routes, warms each route, and
then counterbalances exact local32 versus the current residual-Q8_1x2
split-weight owner across matched p512/d128 graph-decode pairs.

## Changes

- Added `scripts/qwen38_dense_pair_perf.py` with current-owner and registry
  verification, shape-only policy replacement/restoration, same-session
  counterbalanced order, per-run correctness/memory fields, paired statistics,
  and benchmark provenance.
- Added a pure regression test for balanced medians, pair ratios, and win count.
- The harness fails closed for non-cached builds and marks captures invalid when
  the source is dirty or fewer than seven pairs are collected.
