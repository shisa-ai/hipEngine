# Add strict Qwen4Exp PLE HIP primitives

## Summary

Added strict raw-pointer gfx11 HIP primitives for the remaining PLE arithmetic:
signed-square-root branch gate, value broadcast/gating, and causal dilated
per-channel Conv with caller-owned in-place history.

## Changes

- The gate reduces each 2,560-wide branch in FP32 and applies the exact
  `sigmoid(sign(s)*sqrt(max(abs(s),1e-6)))` formula.
- Value broadcast expands `[rows,hidden]` to four gated residual branches.
- Conv runs kernel-size/dilation generically, processes each channel in causal
  row order, and updates exactly `(kernel-1)*dilation` history rows in place.
- Registered strict gfx1100 variants; gfx1151 receives peer aliases.

## Validation

- RED: build/registry test failed because the PLE HIP module did not exist.
- GREEN: `uv run pytest -q tests/test_qwen4_exp_ple_hip.py` -> `2 passed` on
  Radeon 8060S/gfx1151, including first JIT build.
- Native+CPU PLE bundle -> `7 passed`.
- Production H2560/four-branch parity: gate/value/Conv within 2e-6 and the
  9x10,240 FP32 Conv history array-exact after a five-row chunk.
- This is new in-tree code following the frozen CPU oracle; the required lineage
  audit remains mechanically blocked by missing manifest repositories as
  recorded in the GR worklog.
