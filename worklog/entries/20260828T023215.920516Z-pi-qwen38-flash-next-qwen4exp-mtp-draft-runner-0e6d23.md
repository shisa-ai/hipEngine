# Run the Qwen4Exp MTP sidecar layer

## Summary

Implemented the pinned sidecar's one-layer Qwen4Exp MTP draft at reduced
short-context capacity. Input formula, finite output, same-schedule repeat, and
draft cursor snapshot/restore replay pass. This is a component gate, not yet a
working speculative product.
