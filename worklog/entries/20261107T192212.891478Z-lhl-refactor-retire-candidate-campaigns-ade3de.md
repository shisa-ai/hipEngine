# Close retired candidate campaigns R0001 R0023 R0026 R0027 R0028 R0039 R0057 R0163

## Summary

Applied the lead decision of 2026-11-07, "retire failed candidates rather than
keep repair campaigns open", to the entries whose candidates are not live
defects. None of these entries owns code that only the candidate uses: each
candidate either shares a production path with another artifact or backend, or
is shared capability. Retirement therefore closes the restore/repair campaign
and keeps every current default and fallback.

- **R0023 / R0026 / R0027 / R0028 (Qwen4Exp UD-Q4_K_XL recovery families):** the
  `PRODUCTION_ARITHMETIC_RECOVERY_FLAGS` recovery is now permanent for
  UD-Q4_K_XL. This covers PRODUCTION_MOE_PREFILL, Q4_IU8_PREFILL, Q8_MMQ_PREFILL,
  GR_IU8, GR_IU8_DOWN, Q4_DP4A64, QSA_FLASH_PREFILL, GR_WIDE and the GDN peer
  prefill layers. The binders still enable those routes in production for the
  other Qwen4Exp quants (`_publish_gr_iu8` and siblings), so no code was removed.
  Docstrings that called them "disabled by production recovery" now say the
  recovery binds them off for UD-Q4_K_XL specifically.
- **R0039 (GDN multi-column composition):** already resolved. Multi-column is the
  production owner on layers 27-47 (2026-10-08 full layer2 envelope on the UD lane;
  the task finding is shared with the strict arm). Strict, DPP, row-split and
  column-warp references stay registered.
- **R0057 (gfx1151 DMS wave-group6 producer):** gfx1151 restoration retired.
  Wave-group6 stays a gfx1100-only compile define; gfx1151 builds the generic
  producer.
- **R0001 (PARO one-candidate verifier graph):** eager stays the one-candidate default
  (graph replay was 3.23%/3.06% slower). `SpecGraphStageCache` and the verifier
  graph remain shared capability for DFlash and explicit graph plans.
- **R0163 (unbounded FP16 recurrent storage in dense gfx1151 profiles):** retired.
  Both dense gfx1151 profile plans bind FP32 state. The unbound gfx1151 Q4_K_S
  FP16 default is a separate live default and is unchanged.
