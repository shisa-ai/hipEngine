# Preserve declared cohort across physical planning

## Summary

`plan.request_ids` is also physical because execution planning subsets the
`WorkItem` before speculative planning. Preserve the original logical cohort as
explicit immutable metadata rather than attempting to infer it from request
IDs, token rows, or benchmark identity.

## Changes

Added `declared_logical_c` to `WorkItem` and `SpecRequestPlan`, defaulting to the
local request count and rejecting values smaller than local ownership. The
execution planner carries the original value into every physical subset;
engine-loop planning passes it into speculative policy; W1 leaf admission reads
that field.

## Validation

Policy, execution-planner/token-budget, engine-loop, and MTP2 seam bundles: 126
passed. Tests assert C8 metadata survives a four-request physical subset. No
default changed.
