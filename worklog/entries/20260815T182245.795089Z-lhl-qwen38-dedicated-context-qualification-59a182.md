# Qualify Qwen3.8 dedicated-XTX context recommendations

## Summary

Qualified the actual dedicated RX 7900 XTX serving recommendation for `/models/gguf/Qwen3.8-27B-Q4_K_M.gguf`. The earlier 96K recommendation assumed generic extra margin that the product contract does not require. Under the explicit idle-card, max-active=1, AR-only, prefix-cache-off/MTP-off contract, 112K is now the recommended maximum. Four different pinned ShareGPT-derived 112K requests complete at the same high water as the earlier repeated-token row.

The c>1 result is intentionally separate: current packed AR adds a BF16 mirror to short INT8 caches, so it is memory-negative rather than an efficient INT8 capacity path. Measured 512-MiB-reserve settings are 4K/request at physical c2 and 1,280/request at physical c4. Offered c8 is two c4 queue waves and uses the same 1,280/request setting.
