# agentic session-replay benchmark from real agent transcript

## Summary

Build the agentic-workload evaluation the 2026-09-19 prefix-cache session was
designing when its transcript corrupted mid-tool-call and every response after
the compaction came back empty. The engine and merged main are unaffected; the
only unfinished work was this benchmark. The unit adds a converter that walks a
Jouzu session `.jsonl` by its `parentId` ancestry (file order is not chain
order: retries are siblings on dead branches), emits the OpenAI-style
message shapes the chat renderer accepts (assistant `tool_calls` + role `tool`
results, thinking blocks skipped, one synthesized result per genuine
mid-round user interrupt), and derives client request boundaries: every
request resends the whole transcript, which grows by one assistant round plus
its tool results or by one user message. A fixture sliced from the real
session (32 consecutive requests, tail of the pre-compaction chain, tip
`77d12a62`) drives a new `session_replay` lane in
`scripts/prefix_cache_multiturn_bench.py`.

Measured result (zbook / gfx1151, Qwen3.6-35B-A3B `UD_Q4_K_M`, in-process
resident loop, server chat renderer, greedy ignore_eos,
`--max-sequence-length 12288`, `--lane-kinds session`, `--code-tokens 128`,
one process per arm, sequential arm order, 32 requests per arm, single
repetition): real agentic cumulative resend is prefix caching's best case.
Radix with `HIPENGINE_GGUF_PREFIX_RETAINED_SNAPSHOTS=16` completes the lane in
**208.0 s against 581.3 s uncached: -64.2% wall, 2.79x (19.69 vs 7.05 tok/s),
30/32 lookups hit, 222,720 reused tokens = 96.2% of the 231,530-token
longest-common-prefix potential (3.8% block-granularity loss), prefill work
86% lower (428.4 s to 60.4 s)**. Default retention measures **-44.1% wall
(324.8 s), 19/32 hits, 157,952 reused tokens**: `cache_resident_entries` stays
pinned at 2, so each new completion evicts the previous request's snapshot and
thrashes the always-reuse-the-previous-turn pattern of a cumulative client
(35B snapshot clones cost ~67 MB state plus ~31 MB per reused page, so the
default byte-budgeted window holds only one large conversation snapshot).
Against the merged-main 14-lane campaign (-18.4% wall retained-16, -17.8%
default, 18/27 hits), the session lane shows the gap between default and
retained-16 grows from same-day noise on synthetic 3-turn lanes to 20 wall
points on real 32-turn tool traffic.

Caveats: single lane, single repetition, same-host A/B — an agentic
workload-shape measurement alongside the topline multi-lane campaign number,
not a replacement; generated outputs are not compared across arms (the
standing split-prefill caveat — possible one-BF16-ulp divergence above 2,048
tokens of total context — applies, and this lane's prompts reach 13,762
tokens); the fixture is one session's tail, so it is a workload-shape probe,
not a distribution claim.

## Changes

- `hipengine/benchmark/session_replay.py`: converter
  (`convert_session_jsonl`), fixture loader with strict pairing/boundary
  validation, `build_session_replay_turn_messages` (cumulative resend per
  request, mirroring `build_canonical_turn_messages` shapes),
  `build_session_replay_tools` (OpenAI envelopes). Default tip anchors on the
  compaction record's own `parentId` (definitive live tip) instead of file
  order, because dead retry branches can be appended after the live tip.
- `scripts/session_replay_convert.py`: CLI over the converter.
- `scripts/prefix_cache_multiturn_bench.py`: `--session-replay` /
  `--session-replay-workloads` args, `session_replay` lane kind
  (`--lane-kinds session`), fixture identity in the artifact protocol block.
- `benchmarks/prompts/agentic-session-replay-v1.json`: real-session slice
  (65 entries, 32 requests, tools `bash`/`edit`, 27 tool results capped at
  4000 chars, last request 28.1k content chars, prompts 740-13,762 tokens).
- Tests: `tests/test_unit_session_replay_convert.py` (13 tests: ancestry
  walk with dead branches and flow markers, renderer shapes, boundary
  semantics, tail slicing, caps, loader validation),
  `tests/test_unit_prefix_cache_session_lane.py` (5 tests: cumulative resend,
  LCP observation, turn limit, tool plumbing; no GPU).
- Artifacts: `benchmarks/results/2026-09-20-gfx1151-qwen36-gguf-prefix-cache-session-replay-{baseline-off,default,retained16}.json`.

## Validation

- RED-first: converter and lane tests were written against the module API
  before implementation and failed with `ModuleNotFoundError` / wrong
  boundary expectations; the boundary failures exposed two real design
  errors (default tip must anchor on the compaction parentId; sequential
  tool results chain linearly in the append-only log).
- 13 + 5 new unit tests pass; the existing
  `test_unit_prefix_cache_multiturn_bench.py` still passes 22/22 after the
  harness edits (40 passed total across the three files).
- Rendered a leading-assistant mid-conversation prompt engine-less through
  `_render_prepared_chat_prompt_for_request` to confirm the Qwen3.6 template
  and tool-transcript validation accept the slice start.
- Three-arm benchmark commands (exact, from a clean tree at `19f2dd45e` plus
  this unit's uncommitted files):

```
COMMON="--backend hip_gfx1151 --lane-kinds session --repetitions 1 \
  --session-replay benchmarks/prompts/agentic-session-replay-v1.json \
  --code-tokens 128 --max-sequence-length 12288"
uv run python scripts/prefix_cache_multiturn_bench.py $COMMON \
  --modes off --json /tmp/session-replay/off.json
uv run python scripts/prefix_cache_multiturn_bench.py $COMMON \
  --modes radix --baseline-artifact /tmp/session-replay/off.json \
  --json /tmp/session-replay/radix-default.json
HIPENGINE_GGUF_PREFIX_RETAINED_SNAPSHOTS=16 \
  uv run python scripts/prefix_cache_multiturn_bench $COMMON \
  --modes radix --baseline-artifact /tmp/session-replay/off.json \
  --json /tmp/session-replay/radix-retained16.json
```

- Per-turn evidence in the artifacts: prompt tokens, local LCP tokens,
  matched/reused/avoided/executed prefill tokens, reused pages and bytes,
  resident cache entries, fallback reasons (only `miss`; zero declines,
  zero `prompt_too_short` — every turn is deep enough to look up).
