# Normalize resident logit sample axes in calibration

## Summary

Fixed the calibration adapter after the clean one-prompt GPU screen exposed
resident sample logits shaped `[1, vocab]`. The initial synthetic fixture used
`[vocab]`, so the adapter rejected the real capture before emitting metrics.

## Changes

- Normalize one or more singleton sample axes to one vocabulary row.
- Continue rejecting tensors with multiple sample rows so calibration cannot
  silently flatten an unaligned batch.
- Added the missing `[1, vocab]` regression fixture.
