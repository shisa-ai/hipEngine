# Add same-resident GGUF c1 route performance gate

## Summary

Added a timing-only companion for quality-gated GGUF c1 numerical routes. It
prevents full-logit/state D2H work from contaminating the performance claim and
requires a complete passing same-host quality artifact before measuring.

## Changes

- Load one resident model, warm strict/candidate routes, and alternate route
  order for five p512/d128 eager repetitions.
- Preserve and restore the complete candidate environment around each run.
- Record per-run generated IDs, candidate repeatability, clean provenance, and
  candidate-versus-strict median throughput.
- Reject missing/incomplete/wrong-model quality inputs and non-repeatable
  candidate trajectories.
