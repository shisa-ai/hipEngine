# Separate pair operation decisions from resident launch bindings

## Summary

Separate immutable pair selection from launch-local resident weight ownership.
The ordinary public launcher constructs the decision then binds current operands;
no cache, selector, arithmetic, or fallback change is introduced.

## Changes

- `_GGUFLinearPairDecision` holds selected operation, geometry, registry keys,
  thread/library policy and fallback reason without resident weight references.
- `_GGUFLinearPairPlan` retains the existing exact operand ownership as the
  launch-local binding. Execution and source-F16 span consumers are unchanged.
- Tests compare equal decisions across independent resident pairs and exercise
  explicit binding while preserving foreign-owner rejection on existing plans.
