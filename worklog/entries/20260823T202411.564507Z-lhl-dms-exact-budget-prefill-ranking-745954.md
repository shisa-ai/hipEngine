# Add metadata-bound exact-budget DMS prefill ranking

## Summary

Added a metadata-bound `exact_budget` prefill selection mode for schema-v2 DMS.
The trained external-linear logits remain the eviction ranking signal, but the
window and target CR now determine an exact per-layer/head historical count.
This removes static-threshold budget drift without tuning weights or thresholds
against development rows. Legacy `threshold` behavior remains compatible.

## Changes

- Bound `prefill_selection_mode` into strict metadata validation and the schema-
  v2 runtime fingerprint; schema v1 remains threshold-only.
- Added deterministic CPU ranking: positive/high classifier logits evict first,
  equal-score ties evict older positions first, recent-window rows never evict,
  and every layer/head receives the exact declared count.
- Expanded the prefill collector's device logit storage to all compact layers,
  reads learned scores once after prefill, derives exact masks, and writes those
  masks back to the device decision owner before direct compact pack.
- New future-attention-trained exports declare `exact_budget` explicitly.
- Documented the correctness-first host ranking round trip and the production
  requirement to move bounded selection fully onto device.
