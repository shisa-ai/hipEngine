# Enable independent overlapping prompt activation ownership

## Summary

Enable overlapping prompt lifetimes on the default GGUF path. Each activation
owns a request claim and provider slot; ending or failing a peer no longer
clears another prompt's ownership. Chunk submissions remain serial.

## Changes

- Replace global activation exclusion with per-request prompt claims and an
  aggregate resource view; retire only the completed/aborted request claims.
- Allow multiple GGUF first chunks in one scheduler item.
- Preserve shared provider group reuse and independent sink lifetimes.
- Cover separate openings, first/second finish orders, peer cancellation and
  peer sink setup failure; verify the waiting peer retains its provider/claim.
