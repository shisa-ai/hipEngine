# Implement Qwen3.8 row-batched INT8 KV attention

## Summary

Completes the first atomic IKV-C2 unit: a registered row-batched direct
per-token/head INT8 GQA split-K attention producer and explicitly strided BF16
gated reducer for 24Q/4KV/D256. The existing c1 wrapper/kernel remains unchanged
and registered as the numerical fallback. This checkpoint proves the primitive
on GPU1 / RX 7900 XTX only; it does not yet claim runtime/model ownership,
native continuous-batch throughput, or C2 milestone completion.

## Changes

- Added one producer launch over `(KV head, split, row)` with row-major
  `KVLiveSpans` block tables, per-row live counts, and explicit query-row stride.
- Added one BF16 gated reducer with explicit row/head/dimension strides for both
  gate and output.
- Added FP32/FP16 scale ABI symbols, one distinct four-axis registry variant,
  package export, shape/layout/stride validation, and retained c1 fallback.
- Added HIP-guarded c1/c2/c4/c8 fixtures covering 1/255/256/257/513/1023/1025/
  8193-token contexts, ragged live counts, sparse inactive rows, reversed pages,
  non-zero physical blocks, and padded query/gate/output strides.
- Updated the stable kernel catalog without changing campaign status.
