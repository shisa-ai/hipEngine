# Measure routed weight overlap in Inkling decode cohorts

## Summary

Four-row decoding leaves some routed weight reads available for reuse. Counting unique expert IDs per tick and layer visit removes about one fifth of modeled expert bytes at 47 input tokens and about one eighth at 151 on both checkpoints. This is an accounting bound, not measured device traffic or a speedup.

## Changes

- Instrumented public resident decode ticks and counted each gate/up and down packed bank separately. Counted singletons as well as overlapping rows, excluding the first draw from already-computed prefill logits. The initial harness incorrectly expected every row to enter decode at the same tick; its replacements count stepped rows instead. No production change.
