# RF6 single-session eager verifier layer-stack boundary

## Summary

Extracted the single-session eager verifier layer walk from
`Qwen35GGUFResidentSession.verify_target_block` into
`hipengine/runtime/qwen35_gguf_verify_single_layer_stack.py`. The new owner runs
the existing `for layer_id, layer_type in enumerate(layer_types)` body and owns
the per-layer F32 residual-limit transition, pre-timer synchronize, expert
sidecar load/free lifetime, chunk-scratch selection, the native/linear/full
decode/full prefill operation call sites, the aggregate stage marks, and the
boundary/output captures.

`verify_target_block` keeps preflight, token staging/embedding, the
wmma/gemv/native/IQ policy context managers, output norm, LM head, readback,
cursor/result/transaction ownership, and graph/enqueue controls. No
runtime/session/runner proxy, mixin, operations dictionary, generic run-layer
thunk, or callback bag was added. Every lazy lookup (chunk scratch, next norm
weight, linear state rows, initial snapshot, full-attention cache) remains a
narrow typed operation invoked at its old point. There is no whole-plan
prevalidation.

The review repair removed the geometry-time conversion of
`_verify_linear_initial_snapshot_users`. The owner now calls a session adapter
only in the native branch, after the state-row resolver; the adapter reads and
converts the count at that point and returns the snapshot pair only when it is
positive. Bulk, full, non-capture, and native-without-defer calls never read or
convert the count.

## Review repair

The first version converted `_verify_linear_initial_snapshot_users` while
building `VerifySingleLayerGeometry`, so every route read and converted it
before the loop. The inline loop read it only inside the native branch, after
the state-row resolver. The repair removed the geometry field and moved the
check into a typed session adapter passed as `resolve_initial_state_snapshot`.
The owner calls that adapter only for native capture+defer, after the state-row
resolver; the adapter performs `int(getattr(...)) > 0` and then calls the
snapshot pair. The check sequence is unchanged.

The new tests use a count object whose `__int__` raises. The non-count routes
(bulk, full, non-capture, native-without-defer) complete with zero conversions
and match the committed old-control trace. The late test uses a count that
succeeds once and fails on the second conversion, so the first native layer
completes and the second fails after its state-row lookup; the failure keeps
the prior layer's operation and stage marks. A direct owner test with a sidecar
loader proves the failing layer's sidecar is freed and its stage marks are
recorded before the error propagates.
