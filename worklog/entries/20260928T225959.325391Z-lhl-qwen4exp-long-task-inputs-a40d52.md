# Enable explicit supplemental task suites and token budgets

## Summary

The task collector can now accept explicitly named supplemental natural-task
suites and reserve/check their input-token budget without replacing canonical
coverage or silently exceeding the old 1024-token allowance.

## Changes

- Add repeatable `--extra-prompts` and `--prompt-token-budget` (default1024).
  Canonical suites always load; shared loader rejects duplicate prompt IDs.
- Separate `canonical_suite_complete` from combined-selection `complete_suite`.
  Supplemental-only selections cannot imply canonical coverage.
- Record hashes of every loaded suite; reserve max output + input budget and
  check actual chat-formatted input length before prefill. Chunk remains1024.
- No fixture content, candidate arithmetic, runtime defaults or dependencies changed.
