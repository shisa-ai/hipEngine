# V4 was a run, not a build: the 4096-context decode baseline is frozen and self-gates at KL 0

## Summary

Punchlist V4 ("Re-run the decode gate at 4096 context with BF16 KV") is
**landed**. It read as though it needed new machinery; surveying before writing
found it needed none, and the run completed in 43.1 s with a clean self-gate.

Three facts removed the build:

1. **BF16 KV is already the default.** `docs/ENVS.md` records
   `HIPENGINE_KV_STORAGE` defaulting to `bf16`, described there as "the
   higher-precision baseline", and the punchlist's own setup line states
   "hipEngine `gemma4`, BF16 KV, default production route". D12 (INT8 KV) is
   `blocked (D2, D4)`. "With BF16 KV" was already true of every capture.
2. **The evaluator already exposes the parameters.**
   `gemma4_teacher_forced_gate.py` takes `--prompt`, `--context`, `--prefill`
   and `--slices` on both `capture` and `gate`. A 4096-key chain is an
   argument, not a feature.
3. **Nothing needed re-plumbing.** The gate drives the ordinary shipping
   policy, so no kv-storage or attention route had to be switched.

This repeats iteration 26's lesson: the existing artefact answered the
question a new build would have been written to answer.

Scanning the seven recorded `.npz` baselines under
`~/.cache/hipengine/tmp/` for their embedded `provenance` confirmed V4 was
genuinely undone rather than merely unrecorded — **every one is
`prefill=1024`** with `split_key_range [1024, 2047]`, exactly the 1024-key
chains V4 cites. Nothing above `prefill=1024` existed anywhere on disk.

## Changes

No source changes. One capture and one gate run:

```
gemma4_teacher_forced_gate.py capture \
  --prompt 5120 --prefill 4096 --context 8192 \
  --out  ~/.cache/hipengine/tmp/gate_v4_4096.npz \
  --manifest ~/.cache/hipengine/tmp/gate_v4_4096.manifest.json

gemma4_teacher_forced_gate.py gate \
  --prompt 5120 --prefill 4096 --context 8192 \
  --baseline ~/.cache/hipengine/tmp/gate_v4_4096.npz --out /tmp/v4_selfgate.json
```

## What this does and does not establish

Establishes: the long-context (4096) decode chain exists, reproduces at
KL 0, and is frozen, so D2 / D4 / D12 now have a baseline to gate against
instead of a stated gap.

Does **not** establish: that any candidate passes at 4096. The row closes on
the baseline plus its smoke; the comparison runs when a D2/D4 candidate
exists. No candidate was gated here, and no long-context accuracy claim beyond
self-reproducibility is made.
