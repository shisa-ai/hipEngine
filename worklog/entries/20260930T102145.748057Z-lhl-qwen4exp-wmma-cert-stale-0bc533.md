# The production wmma 16-47 numerical certificate is stale at HEAD

## Summary

The `wmma` 16-47 Q8_0 dense-prefill route is the production default for the wide
dense-prefill shapes, and its recorded numerical certificate is what admits it.
**Re-running the identical certified configuration at HEAD no longer reproduces
that certificate, at either chunk size.** Mean KL moves 3.795524e-4 ->
4.388172e-4, max KL 1.530440e-2 -> 2.341195e-2, and one row of 1548 now crosses
the 0.02 review boundary, so `requires_outlier_review` is true,
`quality_passed` is false and `measurement_valid` is false where it was `true`.

**All hard gates still pass** - mean 4.39e-4 against 1e-3, p95 2.36e-3 against
5e-3, p99 5.84e-3 against 2e-2, max 2.34e-2 against 5e-2, top-1 0.9942 against
0.99, with 2.28x / 2.14x / 1.84x headroom on the tightest three. So this is a
**review requirement, not a demonstrated quality failure**. It is the same class
as the DP-8 composition, which passed every gate with two rows over the boundary
and was held for review.

This was found while attempting work that turned out to be already done: RT-1's
chunk-4096 gate. X-6 already recorded that qualification, and RT-1 had already
been promoted (`5fa2c2da5`). The re-run was redundant; the disagreement with the
record is the finding.
