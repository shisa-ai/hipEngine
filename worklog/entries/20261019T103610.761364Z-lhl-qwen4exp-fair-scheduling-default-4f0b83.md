# Flash-Next declares the fair prefill/decode policy

## Summary

Flash-Next served concurrent HTTP requests one after another. The generator
declared no `engine_loop_config_defaults`, so it inherited the engine-wide
`prefill_decode_policy="protect_decode"`, which always picks decode while any
row is decoding: an arrival's prefill waited until the active request
finished. On the default server (two slots, 262,144 context) four concurrent
64-token requests completed at 3.7 / 7.0 / 10.3 / 13.2 s, strictly serial,
and with `HIPENGINE_QWEN4_EXP_AR_BATCH=1` the batch never stepped wider than 1
(`c2_block {"1": 126}`). The AR-batch qualification worked around this with
`HIPENGINE_PREFILL_DECODE_POLICY=protect_ttft` on every server command
(`worklog/entries/20261018T034525.696221Z-lhl-qwen4exp-arbatch-http-018db2.md`),
so a user running `hipengine serve` never got that behaviour. Gemma 4 and the
Qwen3.5 GGUF generators on main already declare `fair` for the same reason.

The merge itself is not implicated. On the pinned 2026-10-18 grid
configuration, HEAD (`f42e96268`) and the pre-merge tip `4c8ce6b5c` return
identical token IDs on all 50 probes. The seven AR probes that differ from the
committed packet (`benchmarks/results/2026-10-18-zbook-qwen4exp-http-grid/`)
differ on both trees, so they come from branch commits after that packet ran
(it predates `ef29083bb`). The production-vs-strict gate at HEAD
(`scripts/qwen4exp_layer2_profile_gate.py --candidate production_baseline
--prefill-chunk-size 4096`, 450 rows) passes every numerical limit: mean KL
6.90e-4, p95 4.36e-3, p99 8.41e-3, max 1.46e-2, top-1 446/450, with
three-repeat state determinism, and the strict teacher is bit-identical to the
2026-10-14 gate on all 18 prompts.

## Changes

- `hipengine/generation/qwen4_exp_gguf.py`: `Qwen4ExpGGUFTextGenerator`
  declares `engine_loop_config_defaults = {"prefill_decode_policy": "fair"}`.
  An explicit `HIPENGINE_PREFILL_DECODE_POLICY` still overrides it.
- `hipengine/generation/qwen4_exp_ar_batch.py`: module docstring no longer
  tells operators to set `protect_ttft`.
- `tests/test_unit_qwen4_exp_resident_serving.py`: RED test for the declared
  default and the env override.

  cancel-peer progress and mixed AR+MTP pass. The two failures are the

  `--phases c4` passes 67/67.

  35 checks, 0 failures.
