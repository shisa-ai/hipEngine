# EVIE-4.5B torch GPU baseline (bf16/fp32)

## Summary

Reference wall-clock numbers for the deployment configuration (bf16 sdpa) and
strict fp32 on the local gfx1151 (Radeon 8060S) host, fixed synthetic workload
(seed 20260909), via `scripts/evie_gpu_bench.py`. These are the numbers
MODEL-EVIE.md will compare hipEngine against.

## Changes

- Added `scripts/evie_gpu_bench.py` (deterministic synthetic pages, doc batch +
  query batch + MaxSim timing, best-of-N).

## Validation

- Measured on zbook/gfx1151, torch 2.13+rocm, transformers 5.15, sdpa,
  batch 8 pages (448x336, 151 doc tokens incl. 140 visual) + 8 queries
  (20 tokens), 3 repeats, best:

| Precision | doc 8 pages | query 8 | maxsim | total |
| --- | ---: | ---: | ---: | ---: |
| bf16 | 1117.2 ms | 237.8 ms | 0.8 ms | 1355.8 ms |
| fp32 | 3669.0 ms | 477.7 ms | 1.5 ms | 4148.2 ms |

- CPU fp32 (same host, single item): doc 31.6 s/page, query 18.4 s — the
  recurrent DeltaNet prefill dominates CPU time.
- bf16 vs fp32 MaxSim score[0,0]: 8.125 vs 8.1197 (bf16 noise floor for the
  workload).
