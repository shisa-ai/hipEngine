# Compute Inkling attention factors across a wave

## Summary

Compute the online-softmax factors with a wave-local prefix maximum. The denominator and value sums still consume those factors in the original FP32 slot order.

## Changes

- Replace the split value pass's per-slot serial maximum and exponent calculations with one wave of independent factor calculations per tile. Leave cache storage and rollback unchanged.
