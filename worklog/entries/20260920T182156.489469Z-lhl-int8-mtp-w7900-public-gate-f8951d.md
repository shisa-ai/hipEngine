# Validate supported INT8 MTP HTTP serving on W7900 without overrides

## Summary

The supported gfx1100 Qwen3.8-27B Q4_K_M artifact executes compact INT8 MTP
through a normal four-slot server without any KV or MTP screening override.
Both endpoints and SSE match true INT8 AR on the full category/heldout suite.
This is independent host correctness evidence, not a cross-host speed claim.

Correction to the previous lifecycle description: the original fixed text-stop
probe did not assert that stopping occurred. It now chooses an actual substring
of the baseline output and requires `finish_reason=stop`. The result passes on
gfx1151, but the existing text-stop policy selects AR (zero MTP cycles), so it
does not establish stopping inside an accepted speculative chain.
