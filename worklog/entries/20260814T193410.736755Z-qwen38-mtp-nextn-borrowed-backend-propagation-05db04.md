# Propagate target backend into dense NextN fallbacks

## Summary

Fixed dense GGUF NextN fallback materialization on non-gfx1100 HIP backends.
Qwen3.6/3.8-27B omit optional draft embedding/head tensors and borrow the live
target roots. On gfx1151 those roots were correct, but the NextN executor still
materialized its local block with the default gfx1100 key and rejected the
backend mismatch before the first proposal. The executor now derives one
concrete backend from borrowed roots and uses it for draft materialization and
its adapted full-stack runner.

- Added a backend resolver that accepts a requested backend or inherits the one
  shared by all borrowed fallback weights, rejecting mixed or conflicting
  ownership before allocation.

  one-layer runner; no backend branch or kernel math changed.
- Added RED/GREEN unit coverage for auto/explicit gfx1151 inheritance,
  conflicting explicit selection, and mixed borrowed backends.
