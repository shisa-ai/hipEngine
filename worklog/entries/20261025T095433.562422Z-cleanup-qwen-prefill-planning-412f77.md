# Separate prefill scratch layout planning from execution

## Summary

First unit of the approved four-part runtime cleanup: prefill scratch planning, resident-state transactions, layer execution, then diagnostics/profiling. Keep arithmetic and selected kernels unchanged while making ownership and dependencies explicit.
