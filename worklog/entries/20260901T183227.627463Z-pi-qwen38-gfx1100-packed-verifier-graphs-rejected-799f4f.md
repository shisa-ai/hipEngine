# Reject packed verifier HIP graphs

## Summary

Reject and remove HIP graph capture at both per-layer and complete-model packed
target-verifier boundaries. Both candidates preserve generated IDs, acceptance,
and selected-row ownership, but fail marker admission on the W7900/Qwen3.8
Q4_K_M C8/K3/D12 workload.

## Changes

- Removed `HIPENGINE_GGUF_PACKED_VERIFY_MODEL_GRAPH`, the graph cache, context
  buckets, capture/replay helpers, runtime branches, and unit tests; the product
  and test paths are byte-identical to pre-experiment commit `929027025`.
- Closed the refactor entry and added compact rejection artifact
  `benchmarks/results/2026-09-02-w7900-q4km-k3-packed-verifier-graphs-rejected.json`.

## Validation

- Per-layer graph (`abd16f9bd`, tracked clean): exact IDs and acceptance
  `[3,3,2]`; target wall 167.655→168.533 ms (+0.52%), kernel sum -0.18%,
  complete wall -0.30%. Graph-scheduler idle gaps grew 24.940→100.294 ms.
- Complete-model graph (`31ec0003f`, tracked clean): two cache hits reduced
  target wall by only 0.19% and 0.62% while collapsing body API calls
  1040→112. A natural physical-geometry change forced one new capture in the
  third measured cycle and regressed target wall 165.724→198.087 ms (+19.53%);
  total complete wall regressed 1.325929→1.358661 s (+2.47%).
- Full C5-C8 qualification was not run because both marker candidates failed
  admission. After removal, the four-file packed-verifier contract bundle passed
  95 tests, and both product/test files are byte-identical to `929027025`.

## Next

- Do not retry host-captured graphs for this dynamic packed geometry without a
  mechanism that updates kernel arguments or prewarms every physical geometry
  outside the measured request. Prefer device-driven persistent submission as
  the next launch-overhead direction.
