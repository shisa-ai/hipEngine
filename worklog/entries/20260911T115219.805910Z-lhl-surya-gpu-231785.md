# Surya GPU text decoder port: gfx1151 parity reached (smoke green)

## Summary

The fp32 Surya text decoder on HIP (gfx1151, Strix Halo iGPU) now matches the
CPU reference end to end: `scripts/surya_gpu_smoke.py` reports prefill logits
max|diff| 4.7e-05, per-decode-step logit max|diff| ~3e-04, and greedy tokens
identical for 16 steps against `kernels/cpu_reference/surya.py`.

Three root causes were found and fixed, all in `hipengine/runtime/surya.py`:

1. **H2D upload source lifetime.** On this stack the DMA of an unpinned-source
   `hipMemcpy` reads the host buffer *after* the call returns, so a
   same-statement temporary (`np.ascontiguousarray(...)` inline) could be freed
   and recycled before the copy landed. The destination then held stale-heap
   garbage — which is why every "corrupted buffer" probe kept showing host
   pointers (0x7f...) as float pairs. Fix: `_upload()` helper keeps the source
   alive and `device_synchronize()`s before releasing it; used for weights,
   rope tables, batched-GEMM pointer arrays, cu_seqlens/state_idx, ids, and
   visual features.
2. **Prefill score-tile addressing.** The batched-GEMM C tiles for the scores
   GEMM (col-major m=n=tokens, ldc=head_stride) must start at
   `h*tokens*head_stride`, not `h*head_stride` — the old code made every
   head's tile overlap all later heads. The V-GEMM's B (scores) pointers and
   the `evie_softmax_rows_f32` head stride (which is `tokens*head_stride`,
   unlike the mask kernel's `head_stride`) had the same missing factor.
3. **`_logits_last` read token 0's final-norm row** during prefill instead of
   the last token; `_final_norm_row` now records the row `_decode_stack` ends
   on.

Non-bugs worth recording: layer-wise "divergences" seen mid-debug were
instrumentation artifacts (an mlp hook reading x before the residual add; a
kcache probe reading per-head planes as one contiguous block; the smoke
comparing GPU prefill logits against the *last CPU decode step's* logits
because the CPU loop overwrote `ref_logits`).

## Changes

- `hipengine/runtime/surya.py`: `_upload()` helper + all upload sites
  converted; `_attention_packed` tile addressing (scores C, scores-as-B,
  softmax head_stride); `_final_norm_row` + `_logits_last`.
- `scripts/surya_gpu_smoke.py`: fixed stale-`ref_logits` comparison; per-step
  CPU logits kept in `ref_step_logits`.
- `scripts/surya_gpu_debug_attn.py`, `scripts/surya_gpu_debug_gdn0.py`,
  `scripts/rocblas_batched_probe.py`, `scripts/rocblas_scores_probe.py`:
  diagnostic scripts used to localize the three bugs (kept for future
  bring-ups; rocBLAS batched NN/TN verified exact on contiguous tiles).

## Validation

- `HIPENGINE_HIP_ARCH=gfx1151 python3 scripts/surya_gpu_smoke.py`:
  prefill max|diff|=4.721e-05 (logit-mag 22), steps 0..15 tokens equal,
  `greedy tokens equal: True`.
- Per-layer full-stack comparison (24 layers, post-attention and post-MLP
  residuals): max|d| <= 6.3e-05 vs CPU reference.
- Isolated stage checks: embed 0.0, rmsnorm 7.6e-6, GDN block 1.8e-6, MLP
  1.1e-6, attention layer-3 out 6.9e-07, probs 3.8e-6, KV cache 1.7e-5.
