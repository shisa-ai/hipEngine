# VibeVoice ASR GGUF exporter: byte-exact 901-tensor roundtrip

## Summary

GGUF v3 exporter for VibeVoice-ASR (HF -> GGUF, custom arch
`vibevoice-asr`) with byte-exact roundtrip; first step of the Q4_K_M
quantization plan.

## Changes

- `scripts/vibevoice_asr_to_gguf.py`: exports all 901 tensors BF16
  byte-identical under their original HF names via the in-tree
  safetensors raw-storage path (numpy cannot read bf16 safetensors
  directly); metadata keys `vibevoice.text.*` (spec geometry),
  `vibevoice.acoustic/semantic.*` (encoder geometry),
  `vibevoice.audio_token_id`, chunk size - enough to rebuild
  `VibevoiceQwen2Spec` and encoder configs from GGUF alone.

## Validation

- 901/901 tensors byte-identical GGUF -> safetensors (in-tree
  GGUFReader memmap vs raw storage bytes); metadata verified via
  scan_gguf; output 16.66 GB at /tmp/vibevoice-asr-bf16.gguf.
