# Check native C1 provider hidden and postcommit cursors

## Summary

Extend native C1 selected-prefix commit instrumentation to provider hidden and
device cursors. All 70 GPU calls pass; no runtime/default policy changes.

## Changes

- `--check-commit` independently selects local BF16 `pre_output_norm_hidden`
  row `accepted` (not global `row_start + accepted`) before the real device
  commit; checks destination pointer/size/bytes and `_last_target_hidden_ptr`
  publication afterwards.
- CPU independently encodes expected INT64 position/context values as
  `start_position + accepted + 1/+2`. Checks destination pointers, sizes and
  byte hashes after the real commit. No device metadata reused as expected values.
- Source/destination shape/dtype/size validation fails closed. No dependencies
  added; this diagnoses exact ownership, not independent numerical arithmetic.
