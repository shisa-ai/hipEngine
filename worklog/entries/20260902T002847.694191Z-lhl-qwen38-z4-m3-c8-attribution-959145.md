# Collapse C8 accept-boundary bound

## Summary

Profiled one cached, current-head, one-group C8/K3 canonical request. The large
`accept_ms` marker is not removable T0 host work: it primarily synchronizes
queued target kernels.

Across 16 R8/R16 target passes, target-pass host windows total 3,054.08 ms and
traced kernels total 2,938.29 ms (96.21% coverage). The host-minus-kernel ceiling
is 115.80 ms total, 14.47 ms/cycle, or 2.18% of complete C8 wall. This is far
below the 28.5% entry threshold. M3 is rejected as a C8 accept-boundary
mechanism.
