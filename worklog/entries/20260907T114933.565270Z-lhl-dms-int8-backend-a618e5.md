# Connect qualified DMS backend to INT8 device storage

## Summary

The qualified DMS backend now passes its codec to the compact device store.
Artifact qualification remains mandatory. No model qualification or serving
promotion is claimed by this host integration unit.

## Changes

- Remove the obsolete BF16-only device rejection, preserving the artifact
  qualification check and registered host fallback for unavailable devices.
- Pass the requested codec to the store and expose codec plus scale pointers
  to integrated kernel callers. Correct batch scale metadata to FP32, matching
  the CPU codec, device store and resource accounting.
- Add CPU scale-contract and GPU two-request pack tests checking exact INT8
  bytes/scales against CPU quantization of BF16 inputs, no host payload shadow,
  and nonzero scale pointers. Synthetic qualification is explicitly confined
  to test fixtures; it does not qualify a model artifact.
