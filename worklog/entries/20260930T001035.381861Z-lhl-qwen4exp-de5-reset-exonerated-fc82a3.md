# DE-5 follow-up: reset() is exonerated and the transient triggers on every prefill after the first

## Summary

The DE-5 re-derivation (`20260930T000236`) recorded one concrete next step: isolate the
~1.5 s per-prefill transient inside `reset()`. **`reset()` is exonerated** - the whole
thing costs **1.14 ms (warmup) / 2.23 ms (rep1)**, three orders of magnitude too small to
be the owner.

The run also **sharpened the trigger**, which is the more useful result. Every earlier run
had the warmup flat (~53-57 ms first-eighth). This probe inserts an extra prefill before
the measured decode (`prefill #1` -> `reset()` + components -> `prefill #2` -> decode), and
the warmup then carried the transient too. So the rule is not "warmup versus repeat":

**the first prefill+decode after model load is fast, and every subsequent one carries the
transient.**

That excludes anything depending on decode context or on loop count, and points at
something the first prefill establishes and each later prefill invalidates. The mechanism
is **not yet isolated** and is recorded as such.

## Changes

- `scripts/qwen4exp_de5_reset_split.py` (new): times `reset()` as a whole plus each
