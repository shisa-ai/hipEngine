# Skip redundant host probability sorting with exact tie semantics

## Summary

Keep the ordered-input CPU probability-sort bypass as the default. On physical
host zbook / Radeon 8060S (gfx1151), Qwen3.8-27B Q4_K_M with strict BF16 KV,
capacity 4 / occupancy 1, MTP and prefix cache off, host selection decreases
49.1733 -> 25.0754 ms/transition (-49.01%). Total instrumented decode transition
decreases 135.5853 -> 111.3815 ms (-17.85%), while model execution including
readback is 86.3137 -> 86.1981 ms. These are component timings, not HTTP,
complete-request, or long-context throughput claims.

All 10 canonical category prompts and 8 category-heldouts run at natural
lengths, with 16 output tokens, temperature 0.7, top-p 0.95, seed 17, twice.
All 36 candidate outputs and prompt hashes exactly match the corresponding
host-sampling baseline rows, and all 18 seeded groups repeat exactly. Hardware,
compiler, environment, model, suite hashes, capacity and variant manifest match.
No graph replays occur. Baseline and candidate are separate same-host runs;
this is not an interleaved process-local A/B.

## Changes

- `hipengine/generation/sampling.py`: before the second sort, check descending
  probability / ascending token-ID order. If it holds, copy the arrays rather
  than sorting again. Otherwise use the original lexsort. Checking probability
  ties is necessary because softmax rounding can collapse distinct logits.
  Copying preserves independent output ownership. No arithmetic, RNG, filter,
  candidate limit, sampling distribution, or kernel changes.
- `tests/test_unit_sampling_probability_order.py`: 19 tests cover sort avoidance,
  input permutations, top-p/min-p combinations, rounding ties, zeros, empty and
  singleton inputs, larger arrays, and output ownership.
- Recorded compact provenance and per-request measurements in
  `benchmarks/results/2026-09-21-zbook-gguf-host-sampling-sort.json`; updated
  `benchmarks/README.md` and `benchmarks/CHANGELOG.md`.
- No temporary flags or duplicate experimental dispatch paths were introduced.
  Unsorted-input lexsort is a necessary fallback, not removable experiment debt.
