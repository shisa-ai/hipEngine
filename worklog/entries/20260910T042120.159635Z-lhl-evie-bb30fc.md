# EVIE fp16 profile gate: manifest-pinned tests + review fixes

## Summary

External-review response for the fp16 production path. (1) The bench's
synthetic-page preprocessing had a real channel/temporal fold bug
(concatenate + reshape(3,2,...) mapped channel c slot t to index 2c+t);
fixed to np.stack + reshape(2,3,...). The correctness fixture uses the
real processor, so parity gates were never affected; performance is
unaffected (same shapes). (2) New committed gate module
tests/test_evie_gpu_runtime_fp16.py covers the fp16 path: per-token
embedding cosine vs the fp32 oracle, MaxSim delta, and 6.4-style
three-run determinism, single model resident. (3) An initial attempt that
co-resident-loaded a second full model in-process wedged the GPU and
crashed the host; the fp16 module is now sequenced so pytest tears down
the fp32 module fixture before the fp16 runner is created. (4) An earlier
"sporadic fp16 repeatability violation" observed only under co-resident
memory pressure is downgraded to a memory-pressure artifact: single-model
repeatability is bit-exact across all measured runs.
