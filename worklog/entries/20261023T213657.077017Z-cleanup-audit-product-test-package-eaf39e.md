# Isolate product test imports after syncing Gemma vision

## Summary

Rebased five cleanup commits without conflicts onto the incoming Gemma vision commit `d4bf3aa77`. Audit-first validation exposed a test-package collision: audit tests add their parent to `sys.path`, and a later `tests.*` import could select `audit/tests` rather than the product test directory. The default product-first run had not exposed this ordering.

- Add `tests/__init__.py` so pytest identifies the product test package while loading its conftest, before audit test modules can shadow it. Preserve existing bare sibling/helper imports by explicitly including `tests` after the repository root in pytest's `pythonpath`.
- Add a product-helper location assertion and an isolated audit-first pytest regression. Retain standalone audit unittest discovery.
- The initial validation environment lacked Pillow; use the existing `surya` image extra for the incoming vision tests. No dependency declarations or assertions were weakened.
