# Bound packed Inkling cold upload staging

## Summary

Bound the host source working set for large packed Inkling uploads. Prior Strix Halo diagnostics showed extended waits in whole-bank HIP copies with file-backed source pages and sustained host pressure.

## Changes

- Copy large mapped tensors through a reusable 16 MiB host window, preserving packed bytes and uploading into exactly the same device allocation. Do not cache raw mappings that exist solely for GPU upload. Small tensors keep the direct copy; the CPU reference can still cache its lazy row-slice mappings.
- Free a partially written device allocation on transfer failure. Release the staging window on close.
