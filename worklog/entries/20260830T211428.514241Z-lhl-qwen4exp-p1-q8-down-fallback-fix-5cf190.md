# Fix Q8_0 down strict fallback regression in grouped path

## Summary

Critical correctness regression introduced by the P1 device-driven grouped
Q8_0 down owner (commit 2a58aa1d8): restructuring the Q8_0 expert-down dispatch
in the grouped prefill branch dropped the strict `selected_projection` fallback
when neither opt-in flag (`HIPENGINE_QWEN4_EXP_Q8_0_GROUPED` /
`HIPENGINE_QWEN4_EXP_Q8_0_GROUPED_WMMA`) is set. For Q8_0 down layers (layer 2,
4, 30, 46, 47) routed through the grouped path with no flag, `expert_down` was
left unwritten (garbage), corrupting whole-model prefill output. Found while
running the heldout correctness suite: max KL 5.55 (vs the certified 0.0287).

## Changes

- `hipengine/runtime/qwen4_exp_runner.py`: restored the strict
  `selected_projection` fallback in the grouped Q8_0 down branch when neither
  opt-in grouped owner is active. Now: Q8_0 + WMMA flag -> D2H+WMMA loop;
  Q8_0 + grouped flag -> device-driven owner; Q8_0 + no flag -> strict
  per-expert selected gemv (the registered incumbent).
- `tests/test_qwen4_exp_runner_moe.py`: added
  `test_qwen4_exp_runner_moe_q8_0_down_grouped_strict_fallback`, a regression
  test that routes a Q4_K/Q4_K gate-up + Q8_0 down through the grouped path
  with no opt-in flag and requires the grouped output to match the strict
  rows=1 serial baseline (Q8_0 down always strict). Verified RED: with the
  fallback removed the test fails (99.6% mismatch, max abs 43264); with the fix
  it passes. Also generalized `_q4_weight` to `_quant_weight` + `_q8_0_weight`.

## Validation

- `uv run pytest tests/test_qwen4_exp_runner_moe.py` — all pass incl. the new
  regression test.
- RED confirmed by temporarily removing the fallback: test fails 4079/4096
  mismatched, max abs 43264; restored -> passes.
- Real-weight heldout correctness suite restored:
  `scripts/qwen4_exp_compare_suite.py` on the 8 gdn-prefill heldouts now
  **passes** with max KL 0.0287 / mean 0.00987 / top-1 100% — byte-identical
  per-row KL to the accepted 2026-08-27 artifact (0.0011/0.0121/0.0051/0.0287/
  0.0013/0.0094/0.0132/0.008). This confirms the regression is fully reverted.
- GPU: Radeon 8060S / gfx1151.
