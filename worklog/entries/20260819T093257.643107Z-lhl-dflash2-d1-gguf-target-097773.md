# D1: DFlash2 GGUF-target tap capture + end-to-end cycle driver

## Summary

The Qwen3.8-27B GGUF resident session can now capture the full-prompt
post-layer hidden at the DFlash2 tap layers, and a host-side cycle driver
(`scripts/dflash2_gguf_cycle.py`) ties the D0-exact NumPy drafter to the
resident target: prefill taps -> mask-noise block proposal -> sequential
greedy commit-only verify -> accepted-row tap append. DFlash2 greedy output
equals pure-AR greedy output on the smoke prompt (20/20), drafts are sensible,
and the pipeline is ready for D2 native kernels.

## Changes

- `hipengine/runtime/qwen35_gguf_runner.py`:
  - `DFLASH2_TAP_LAYER_IDS=(5,19,33,47,61)`, `DFLASH2_TAP_DEPTHS=(6,20,34,48,62)`
    (post-layer depth = target layer id + 1, matching `extract_context_feature`).
  - `DFlash2HiddenCaptureTargets`: caller-owned `(rows, hidden_size)` BF16
    buffers keyed by tap depth, validated against the tap-depth set.
  - `_capture_dflash2_prefill_taps()` helper + wiring in BOTH bulk-prefill
    layer loops (chunked and non-chunked), threaded through
    `prefill(dflash2_capture=...)`.
  - Non-bulk prefill with `dflash2_capture` raises (bulk-only).
- `tests/test_dflash2_gguf_capture.py`: 6 tests for tap-depth mapping and
  `DFlash2HiddenCaptureTargets` validation (valid/invalid depth, size, type,
  non-positive rows), HIP-gated.
- `scripts/dflash2_gguf_cycle.py`: D1 driver. Prefill captures taps to host;
  per cycle the drafter runs with mask-token (248070) noise embeddings for the
  7 draft slots and positions spanning context+block; projected-context cache
  appends each accepted row's taps (projected once, not re-projected per
  cycle). Verify is sequential greedy `session.step(capture_layer_output_hidden
  =tap ids)`: each accepted row is committed and its taps captured; a rejected
  row is never run, so the cache never contains rejected rows and no KV
  rollback is needed. Reports acceptance stats + optional pure-AR comparison.
- `docs/QWEN38-27B-DFLASH2-CAMPAIGN.md`: status updated to D1 complete.

## Validation

- `uv run pytest tests/test_dflash2_gguf_capture.py -q` — 6 passed.
- `uv run python scripts/dflash2_gguf_cycle.py --max-new-tokens 20 --compare-ar`
  on gfx1151 (`/models/gguf/Qwen3.8-27B-Q4_K_M.gguf`, drafter snapshot
  `50307d4c`): prefill 12 tokens in 0.76s, first_token 271; 12 cycles, 20
  produced tokens, mean acceptance 1.67, 0.095 accepted/draft; **DFlash2 vs AR
  greedy 20/20 agree (1.000)**. Decoded output identical to AR:
  `"\n\n...and then, with a sudden burst of energy, it lands softly on the
  other side,"`.
- Draft-quality spot check (translation prompt): drafts `' French', ',', ' at',
  ' most', ...` — sensible, not garbage; confirms taps/projection are aligned.
- Throughput is NumPy-drafter-bound (2.44 vs 10.91 tok/s AR on the smoke),
  confirming D2 native kernels are the speed path.
