# Keep Inkling controller projection intermediates on device

## Summary

Feed each message controller’s down projection directly into its forget and gain projections on the GPU. Return only the final controls for the existing host blend.

## Changes

- Reuse the selected projection kernels and FP32 intermediate storage for attention and MLP controllers. Verify bitwise parity against separate calls with vector and packed inputs.

## Validation

- `epyc` / Radeon Pro W7900 (`gfx1100`), original `thinkingmachines/Inkling-2-Mini` revision `ed40e7da625f594fc9c4990f5f66be24873c22d7`, `inkling2_mixed`, FP32 KV, single-request ordinary greedy decode. Baseline `966766f32`.
