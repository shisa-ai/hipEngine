# Add exact-token external llama benchmark driver

## Summary

Add a diagnostic external server driver for the requested nasone32 RDNA3 fork
comparison. Existing chat-based natural timing does not retain output IDs.
The new driver uses the dense hipEngine suite's tokenizer/chat renderer and
keeps complete input/output IDs for a separate AR/MTP comparison.

## Changes

- Add scripts/llamacpp_raw_suite_bench.py with natural and repeated-token
  workloads, one warmup, configurable repetitions, fixed B3/adaptive B3,
  BF16/F16/Q8 KV, explicit no-fit full GPU offload, source revision, and
  20 ms whole-card VRAM sampling.
- Validate full prompt/output accounting and normalize decode by N-1
  transitions for N visible outputs. Preserve partial results/errors and
  terminate the owned server in finally. Refuse occupied ports.
- No runtime or kernel behavior changes. All outputs are diagnostic and
  performance_claim=false until separately checked and summarized.

## Validation

- python3 -m pytest tests/test_llamacpp_raw_suite_bench.py -q: 5 passed.
- Tests cover transition denominators and rejection of missing output IDs,
  truncated/short prompts, and non-positive timing. RED-first was not used:
  this is an additive experiment driver, not a runtime/math change.
