# Reduce NumPy dispatch in Inkling RMS normalization

## Summary

Use the ndarray mean method in Inkling RMS normalization. It keeps the same square, mean, square root and divide order while bypassing generic NumPy dispatch.

## Changes

- Change the shared NumPy normalization helper. Do not keep an extra square buffer: reusing that buffer was slower than the direct method in the public screen.
