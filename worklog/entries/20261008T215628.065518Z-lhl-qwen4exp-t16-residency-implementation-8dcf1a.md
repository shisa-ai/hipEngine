# Tile-residency implementation: the four-step mechanism, default-off

## Summary

The tile-residency implementation (docs/QWEN4EXP-T16-RESIDENCY.md),
landed in four steps, all default-off, per the design committed at
b7aa950e4:

1. The binding stage (f48775f73): attach_t16_allocation / 
   detach_raw_allocation on Qwen4ExpDeviceWeight - the t16 stage is
   additive (raw stays until an explicit detach), the spec's byte
   accounting grows and shrinks with the stage, frozen-replacement
   semantics, and a guard refusing any detach before a t16 stage
   exists. GREEN 3/3.
2. The materialization helper (b7573e042):
   materialize_qwen4_exp_t16_stages (read -> repack through the
   production T16 layout for the slot's quant -> upload -> attach ->
   publish via the new Qwen4ExpResidentWeights.swap_weight), with
   free_raw defaulting to False so the strict fallback stays
   structurally resident. GREEN 4/4.
3. The dispatch re-keying (a92bbeb52): both env-gated T16 runner
   branches prefer the weight's own t16 stage, falling back to the
   module sidecar so every committed harness keeps working; the
   sidecar path proven end-to-end post-change (code-p512 316.3 ->
   351.1 tok/s, the committed +11% class). GREEN 5/5.
4. The construction wiring (af78b2214):
   HIPENGINE_QWEN4_EXP_T16_RESIDENT populates the binding stages at
   load, bounded by HIPENGINE_QWEN4_EXP_T16_RESIDENT_MAX_LAYERS (the
   transient dual residency before the free_raw phase may not fit);
   failures are fatal to construction. Proven end-to-end: a 2-layer
   window attaches raw+t16 on layer 0's expert_down at load, leaves
   layer 7 raw-only, and closes cleanly.

The routes themselves remain behind X-7 (HIPENGINE_QWEN4_EXP_T16_GATE_UP
/ _T16_DOWN, both default off); this unit completes the MECHANISM only.
The free_raw detach phase (the net-zero half) and the full-window A/B +
gate are the X-7-sequenced steps.

- hipengine/loading/qwen4_exp_materialize.py: the attach/detach stage

  the resident swap_weight method.
- hipengine/runtime/qwen4_exp_runner.py: both T16 branches re-keyed to
  prefer the binding stage, sidecar fallback retained.
- hipengine/generation/qwen4_exp_gguf.py: the env-gated construction
  populate with the bounded window.
- tests/test_gpu_qwen4exp_t16_binding_stage.py: the 5-test suite.

  families (this unit's companion commit).
