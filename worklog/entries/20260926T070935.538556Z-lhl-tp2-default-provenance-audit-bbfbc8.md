# Audit TP2 default propagation and schedule provenance

## Summary

The September 25 promotion changed the session default but not every caller.
`tp2_c1_bench.py` coerced an omitted flag to `False`, and
`create_native_adapter` still declared `bulk_prefill=False`. Both selected the
serial route when callers expected the session default. The native adapter
also made explicit `True` allocate a capacity-sized workspace while `None`
selected prompt-sized growth. That confounded schedule selection with memory
policy. `resolved_scope_manifest` labeled every TP2 session token-serial even
when its actual schedule was bulk.

This entry corrects harness routing and provenance only. It does not certify
TP2 generation or report a speed improvement.

## Changes

- Make the c1 benchmark flag tri-state, including `--no-bulk-prefill` for the
  serial route, while keeping TP1 bulk disabled.
- Pass the native adapter's omitted option through as `None`. Explicit bulk
  selection no longer changes workspace sizing.
- Record the session's actual prefill schedule in its scope manifest.
- Add CPU factory-level tests covering omitted/on/off flags, TP1 routing,
  workspace policy, and both scope-manifest schedules.
