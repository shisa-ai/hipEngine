# Dense Llama defaults its context to the kernel bound, not 8192

## Summary

The generator carried `_LLAMA_DENSE_DEFAULT_CONTEXT = 8192` as a third cap
alongside the checkpoint's position count and the decode kernel's LDS row. It had
no recorded justification and contradicted this family's own decision entry,
which says "the context default is the checkpoint's, capped by the kernel's" —
and it refused 7936 tokens of context that the kernels serve.

There is no 8K limit in this path. The real ceilings are the attention kernel's
64 KiB workgroup LDS row: 16128 tokens of cache capacity and 15856 tokens of
prompt. Memory is not the constraint at all — the KV cache costs 208 KiB per
token, so the ~57 GiB left after the 33B's 62 GiB of BF16 weights would allow
roughly 287,000 tokens. The limit is a shared-memory design choice in a kernel
that materializes a full FP32 score row, not the machine.

## Changes

- `hipengine/generation/llama_dense.py`: the default is now
  `min(max_position_embeddings, MAX_DENSE_DECODE_CONTEXT)` and the constant is
  gone. Nanbeige 4.3 33B now defaults to 16128 instead of 8192, which allocates
  3.2 GiB of KV against ~50 GiB of headroom at that model size.
- `tests/test_unit_llama_dense_generation.py`: a checkpoint declaring more
  positions than the kernel serves must default to the kernel bound, and its
  prompt bound must stay tighter than its cache.

## Validation

- `uv run pytest tests/test_unit_llama_dense_generation.py` — 28 passed.
- `uv run pytest tests/test_gpu_llama_dense_decode.py tests/test_gpu_llama_dense_prefill.py`
  — 9 passed.
- Nanbeige 4.3 33B, constructed without materializing weights:
  `context_length=16128`, `max_prompt_tokens=15856`,
  `max_position_embeddings=524288`, KV 3.2 GiB.

## Next

- The gap between 287,000 memory-permitted tokens and 15856 served ones is the
  whole cost of materializing a score row. Tiled online softmax removes it
  rather than doubling it, and it is the removal condition in `docs/REFACTOR.md`.
- A default of 16128 makes the long-prompt path reachable by default, and that
  path costs about 2.5 hours of prefill at 15856 tokens on this hardware. The
  cost is quadratic in prompt length, so it is worth profiling the tiled prefill
  next rather than raising anything else.
