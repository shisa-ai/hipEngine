# Qualify explicit gfx1151 MTP width/depth policy

## Summary

Replaced the GGUF MTP adapter's scalar physical-width ceiling with a
backend-package-owned set of `(physical width, maximum draft depth)` cells.
The gfx1151 Qwen3.8 Q4_K_M production package preserves C1-C4/K1-K3 and
qualifies explicit C8/K3. C5-C7 have no policy cell and use the registered AR
fallback.
The gfx1100 package and unrelated gfx1151 packages preserve their previous
behavior.

The current ten-prompt/four-category run measures explicit C8/K3 at 52.103
tok/s versus 52.025 true AR (1.0015x). This narrow positive result agrees in
sign with the earlier same-host B5 result (1.0057x). All 40 C5-C8 cells are
deterministic and AR-equal; C5-C7 execute no MTP cycles. Because the current
mixed Japanese/English slice is 0.9589x AR, the C8 evidence remains explicit
and is not automatic.
