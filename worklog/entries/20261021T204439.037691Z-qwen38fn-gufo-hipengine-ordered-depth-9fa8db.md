# Adapt ordered Gufo depth prompts to public hipEngine checkpoints

## Summary

Reuse Gufo's pinned text generation, calibration, prefix replies and ordered
retry history with hipEngine's public HTTP API. Name the cache adaptation:
Gufo reuses live reply state; hipEngine prepares an additional untimed prompt
checkpoint before the measured continuation. No runtime arithmetic changes.

## Changes

- Add `scripts/qwen4exp_hip_http_replay.py`, using the existing Gufo replay and
  HTTP economics helpers rather than a separate prompt recipe.
- Render both the complete conversation and its prior history through the
  public server. Prepare their exact common token prefix with one output,
  then require the measured request to reuse precisely that checkpoint.
- Keep natural EOS behavior for the publication recipe. Prefix replies may
  stop before eight tokens, as upstream permits; measured requests must still
  produce all 128 tokens. Existing HTTP economics callers retain their exact
  output requirement and ignore-EOS setting.
- Record request-owned token IDs, counts, cache reuse, route diagnostics,
  decode-state witnesses, recipe/helper hashes and server identity. Keep
  backend wall separate from GPU intervals and leave G0–G4 bindings pending.
