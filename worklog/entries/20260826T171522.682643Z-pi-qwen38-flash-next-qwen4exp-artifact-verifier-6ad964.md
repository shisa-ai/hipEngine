# Add Qwen4Exp artifact verifier

## Summary

Added a deterministic F0 verifier for the frozen Hugging Face source snapshot
and the converted qwen4exp GGUF. This makes download completeness, weight-index
coverage, PLE ownership, qtype bytes, and runtime-role bytes machine-checkable
without materializing model tensors.

## Changes

- Added `scripts/qwen4_exp_artifact.py` with `verify-hf` and `inspect-gguf`
  commands.
- `verify-hf` checks every path/size against Hugging Face's cached immutable
  tree, reports missing/mismatched/unexpected paths, validates the safetensors
  weight map, and emits tree/source identity hashes.
- `inspect-gguf` uses hipEngine's torch-free lazy scanner, requires architecture
  `qwen4exp` and exactly one PLE table, groups tensor bytes/counts by qtype and
  runtime owner, and can compute the final GGUF SHA-256.
- Added synthetic tests covering partial/wrong snapshots, complete weight-index
  coverage, frozen llama.cpp qwen4exp tensor-role names, and GGUF role/qtype
  aggregation.
