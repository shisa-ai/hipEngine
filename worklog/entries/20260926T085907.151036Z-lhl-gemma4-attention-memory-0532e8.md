# Repair scalar V loads and initialize empty attention slices

## Summary

Scalar decode lanes now load one scalar, not an aligned pair at potentially
odd scalar offsets. Empty split slices write zero partials rather than leaving
scratch contents for combine to consume. Nonempty accumulation order is unchanged.

## Changes

- Added a compile-time load-width helper used by both scalar and split decode.
  Pair lanes retain pair loads; scalar lanes never form a pair lvalue or read
  past the last scalar.
- Removed the empty-slice early return. Its normal loop writes zero partials.
- Added twelve GPU cases with NaN-poisoned workspace: F32/BF16, head dimensions
  256/512, and key/slice counts 1/4, 5/4, 17/8. These exercise the raw launch ABI;
  ordinary automatic selection does not select these small-key split shapes.
