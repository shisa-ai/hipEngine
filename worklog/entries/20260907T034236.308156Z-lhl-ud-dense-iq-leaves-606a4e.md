# Add strict raw dense IQ4_XS IQ4_NL IQ3_S GPU leaves

## Summary

Add raw compressed dense projection leaves for three K_M types. Real-row
GPU outputs match the declared strict CPU reduction exactly on gfx1151.
Materializer integration and Q3_K are still needed before K_M inference.

## Changes

- Add `gguf_iq_dense.{hip,py}` and strict linear GEMV/prefill registry keys.
  gfx1151 uses the existing peer alias mechanism. No fused pair or sidecar.
- Source math: llama.cpp@17252c769a63c1cb650ce98ae309cf4de0da7778,
  `ggml/src/ggml-quants.c`; IQ3_S table: `ggml/src/ggml-common.h`, MIT license
  reproduced in the device source. In-tree selected IQ/Q3 files were inspected
  for raw-pointer and wave reduction conventions; no selected dispatch changes.
- Contract: BF16 activation, unrounded decoded F32 weights, 128 strided F32
  multiply/add accumulators, wave32 shuffle tree, serial four-wave reduction
  from zero; BF16 output rounds once using round-to-nearest-even. F32 output
  does not round. Compile with `-ffp-contract=off`. This new strict leaf is
  its own unfused fallback, not a production arithmetic optimization.
- One block per output column/activation row; multiple rows share the same
  kernel but do not share arithmetic. Generic block-aligned K, positive N,
  rows 1..65535 accepted; numerical evidence below is narrower than that ABI.
- Tests use independent donor-decoded real rows, K=5120/17408, N=3 (odd tail),
  activation rows 1/3, both outputs, three repeats. Exact bit comparison to
  the declared reduction plus FP64 matmul KL<=0.05/top-1>=90% outer gate.
  Full-N, synthetic GPU codebook exhaustiveness and model gates remain open.
- The full lineage command failed on an unrelated missing atlas reference
  checkout. Narrow `--file '*gguf_iq*'` / `'*gguf_q3*'` commands selected zero
  entries. Exact donor provenance is recorded here; no external tree changed.
