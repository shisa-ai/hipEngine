# Reject a transport whose devices, runtime, or algorithm differ from the plan

## Summary

Repairs review finding R6 (P1). `DistributedContext.create()` validated a
supplied transport by world size only, so a plan for devices `[0, 1]` accepted a
transport built for `[1, 0]`. Every rank then allocated on one GPU while its
collectives and stream belonged to the other. Nothing downstream can detect that
failure: each rank holds a plausible buffer and every collective completes.

The same check now also rejects a transport built on a different runtime and one
whose algorithm differs from the plan's. A transport that declares no device
list is treated as a mock and is accepted only when the plan itself says
`algorithm="mock"`, so substituting a mock for a real transport is an explicit
choice rather than a silent one.

## Changes

- `hipengine/distributed/context.py`: new `_validate_transport_identity()`,
  called after the world-size check and before the context is returned; any
  rejection closes the transport, as the world-size path already did.
- `hipengine/distributed/context.py`: ordered device comparison against
  `plan.ranks`, identity comparison of `transport.runtime` against the selected
  runtime, and `transport.algorithm` against `plan.algorithm`.
- `tests/test_unit_distributed_context.py`: five new tests plus a configurable
  `ReversedDeviceTransport` that implements only the surface the context
  inspects. The two existing mock-transport tests now declare
  `algorithm="mock"`, which is the point of the algorithm check.

## Validation

- RED before the fix: reversed-device, algorithm-mismatch, and runtime-mismatch
  tests all reported `DID NOT RAISE TransportStateError`.
- GREEN after: `tests/test_unit_distributed_context.py` plus the transport,
  RCCL, plan, and KV unit files, 65 passed.
- `tests/test_gpu_distributed_transport.py --suite gpu`: 5 passed, confirming
  the real `RcclTransport` path still constructs and closes correctly.
- Full unit tier with this change and the backend-neutral attribution change:
  9090 collected, 9068 passed, 22 skipped, 0 failed, exit 0.
