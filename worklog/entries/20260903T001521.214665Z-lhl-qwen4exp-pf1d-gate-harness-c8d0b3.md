# PF-1d MMQ plane gate harness

## Summary

Built `scripts/execution_profile_q8_mmq_plane_gate.py` (dense-pair-gate
pattern adapted to the Qwen4Exp runner): strict-teacher full-vocabulary
trajectories on the canonical exact-token fixture with the MMQ policy flipped
per phase (None -> exact coltile teacher; `replace(policy, planes=N)`
candidate; incumbent context), calibrated `EvaluationThresholds` quality
evaluation, same-schedule repeat determinism, policy restore on exit,
evidentiary variant manifest, provenance, and a compact artifact. Smoke run
on `code-p512` (4 decode steps) validates the plumbing end to end.

## Changes

- New gate script only; no production code touched. Runner binding uses
  `resolved.construct_generator(factory)` so the production profile binder
  configures the MMQ resources before capture; the policy is swapped on the
  runner attribute and restored in `finally`.

## Smoke result (code-p512, 5 transitions, 3 candidate repeats)

- Repeat determinism: **passed** (3/3 identical trajectories — the P3-style
  first-run state risk did not reproduce here).
- Quality vs strict coltile teacher: mean KL 1.68e-3, p95 4.71e-3, max
  5.06e-3, top-1 4/5. Hard gates failed on this 5-row smoke (prior passing
  candidate class measured mean KL 3.16e-4, top-1 447/450) — directionally
  consistent with d4x2 failing the calibrated bar; the full 12-case gate run
  is required for the binding verdict (single-prompt results are not
  retainable).
