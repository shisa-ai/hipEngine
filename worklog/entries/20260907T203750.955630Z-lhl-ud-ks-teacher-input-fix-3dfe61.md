# K_S context512 teacher gate: input-mismatch correction

## Summary

The catastrophic K_S 512-context teacher-gate failure (KL 22.04) was an input
mismatch, not a model or kernel defect: the teacher input binary
`/tmp/ud-llama-context512-M.bin` carried **K_M** greedy continuation tokens
while the K_S captures consumed **K_S** continuations. Regenerating the
teacher input from the captures' own consumed tokens and rerunning the
teacher reclassifies the gate from catastrophic to a near-pass.

## Changes

- Parsed the actual teacher input binary: per-prompt teacher-token vectors
  differ from the K_S capture tokens in exactly two prompts. Prompt index 7
  (`general_ja_explain`) first differs at continuation index 4 (teacher
  150110, capture 2) — invalidating steps 5-8, exactly where KL jumped.
  Prompt index 2 differs only at continuation index 8, which the tokenwise
  harness drops (`teacher.end() - 1`) and never consumes, so its rows were
  valid all along.
- Regenerated the input from `base['inputs']`/`base['tokens']`
  (`/tmp/ud-llama-context512-S-fixed.bin`), asserted per-prompt prompt-token
  and consumed-token equality against both saved captures, and reran the
  full 162-row teacher.
- The old-vs-new teacher files differ in exactly prompt 7 steps 5-8 and are
  byte-identical elsewhere, confirming the correction touched only the
  invalidated rows.
- The prior artifact's "pipeline ruled out" reasoning was indeed
  insufficient: reproducing the K_M numbers validated the comparator but not
  the input binary's provenance. The K_M input hash appearing in the K_S
  artifact (`input: /tmp/ud-llama-context512-M.bin`) was the smoking gun.

## Validation

- Input-binary equality asserted per prompt (512 prompt tokens + 9 consumed
  tokens) against both saved captures before the teacher rerun.
- Old-vs-new teacher outputs differ only in prompt 7 steps 5-8 (byte-identical
  elsewhere), matching the invalidated rows exactly.

`benchmarks/results/2026-09-08-zbook-ud-ks-context512-teacher-gate-corrected.json`
(supersedes `2026-09-07-zbook-ud-ks-context512-teacher-gate.json`):

- `raw_iq2_xs_default` (production): mean KL **0.001045**, p95 0.0038,
  p99 0.0169, max 0.0201, top-1 **161/162**. Passes p95/p99/max/top-1;
  misses the mean gate (≤0.001) by 4.5%. No layer-localization campaign is
  needed to explain the prior blowup.
- `bf16_expanded_iq2_xs` arm: mean and top-1 fail (160/162). The raw default
  is strictly better on mean KL and top-1.
- Residual disagreements are small and step-local: worst is
  `heldout_general_en_incident` step 6 (KL 0.0207) and the known
  `general_ja_explain` step-4 top-1 flip (KL 0.00119) — a real distribution
  disagreement that changes greedy selection but no longer cascades.

## Corrected gate result

- The old gate artifact stays committed (immutable history); the corrected
  artifact supersedes it and records the full correction chain.
- Promotion remains not qualified: the mean-KL gate misses by 4.5%, and the
  independent-repeat, task, and serving gates for K_S are still outstanding.
  Whether the corrected gate eventually passes is a measurement question,
  not a debugging one.
