# Prefill flushes deferred packed decode state before slot reuse

## Summary

With the union workspace and graph invalidation in place, the canonical
gate progressed to static_c8 and failed with sentinel tokens
(0x7FFFFFFF) on the second decode step of interleaved serving. Root
cause: _prefill_native_row enters prefill_batch_native while the batch
owner holds deferred (scatter_state=False) packed decode state in the
shared packed slots; prefill clears the decode bookkeeping and reuses
the slots, discarding every in-flight row's recurrent/KV state without
scattering it back to the sessions. The next decode round continues from
clobbered state and samples garbage. static_c1 survived because its
serial path flushes owners explicitly.

## Changes

- prefill_batch_native flushes any dirty deferred packed decode state at
  entry (raises if the flush fails), protecting every caller.
- _step_native_chunk's changed-tuple error now reports holder state
  (dirty/state/layout/session counts) for future diagnosis.
- engine_service driver thread prints its traceback when
  HIPENGINE_ENGINE_SERVICE_TRACEBACK is set (the _fail_all path
  otherwise swallows the driver exception).
