# 16K INT8 MTP server timing with and without DMS

## Summary

Measured DMS off and on at the same 16,384-token input through the public HTTP server on host `epyc`, physical GPU1 (Radeon RX 7900 XTX). Pooled client prefill is **644.699 → 328.628 tok/s (−49.03%)**; pooled decode is **28.616 → 9.815 tok/s (−65.70%)**. Median time to first text is **25.407 → 49.850 seconds**. Both arms use source `5633c93e0037153ff579257c8ac3512ac7156a7c`, production profile, INT8 KV with FP32 per-token/head scales, active MTP, one request, and a configured 17,408-token window. Generation uses normal greedy EOS handling and a 256-token cap; actual output counts may be shorter. This is a current-source policy comparison, not a before/after measurement of the memory fix.
