# Qwen3.8 B2 repairs F16 staging cache-hit dispatch

## Summary

The first cache-only B2 serving screen found a pre-measurement integration
defect, not a performance verdict. An env-off launch populated the linear
dispatch cache; the env-on launch reused that entry and then read the
cache-miss-only local `dispatch`, raising `UnboundLocalError`. The dispatch
cache now carries the resolved registry layer needed by the post-cache F16
staging route.
