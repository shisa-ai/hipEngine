# Add exact C1 replay oracle to DMS concurrency probe

## Summary

The concurrency harness can now evaluate INT8 and compare every interleaved
logit byte against independent C1 sessions. This closes a harness evidence gap:
finite logits alone do not establish isolation. No GPU result is claimed yet.

## Changes

- Add offline codec factory injection and `--verify-c1`. Close all concurrent
  owners before opening independent references, avoiding extra peak memory.
  Compare SHA256 of every FP32 logit array, including the cancelled row's
  actual prefix and the survivor's full horizon.
- Correct the obsolete docstring claiming the owner-routing defect is open;
  that defect was repaired by8016952c5.
- Add CPU fake-session tests: identical outputs pass, deliberately changed
  finite logits fail. Include cancellation and unequal decode horizons.

## Validation

- `.venv/bin/python -m pytest -q tests/test_dms_concurrency_oracle.py`:2passed.
- Tests were added with the harness, rather than before it: this is an opt-in
  evidence collector, not a change to runtime math. The injected finite-logit
  corruption supplies an explicit negative oracle test.
- `python3 scripts/worklog.py check` and `git diff --check` before commit.
