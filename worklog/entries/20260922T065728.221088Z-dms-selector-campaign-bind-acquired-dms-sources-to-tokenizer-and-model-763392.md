# Bind acquired DMS sources to tokenizer and model

## Summary

Bound the acquisition artifact to the manifest sealer's tokenizer and model
identity checks. This closes an integration gap where sealed manifests could
record CLI-supplied provenance without verifying the already-tokenized input.

## Changes

- Emit the exact tokenizer binding at acquisition-artifact top level.
- Load either that binding or the backward-compatible metadata binding in the
  sealer CLI.
- Fail closed when a candidate record declares a different tokenizer binding or
  model hash from the values being sealed.
- Cover acquisition-to-sealer binding and both mismatch paths.
