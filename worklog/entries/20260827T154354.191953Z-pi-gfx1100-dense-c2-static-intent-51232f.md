# Preserve future-C2 intent for independent automatic SSE

## Summary

Fixed independent automatic SSE admission after the real production probe showed
that HTTP 200 alone was a proxy: both frontend C1 children ran pure AR because
the exact future-C2 evidence was discarded before the resident due group formed.
The frontend now carries typed static intent while the resident owner still
selects K0 for C1 and MTP only for exact C2.

## Changes

- Let a serving rejection carry a typed speculative-capable static eligibility
  only when `physical_group_not_qualified` is the sole failed evidence axis and
  the realized frontend width is below the exact evidence width.
- Include typed static eligibility in the immutable plan fingerprint.
- Use the static row's automatic bit for request admission without relabeling
  the dynamic rejection itself as automatic/admitted.
- Route single-row SSE through Generation-2 when typed intent is present and
  attach that intent to `SamplingParams`.
- Require a request's static evidence width exactly at adapter capability time:
  future-C2 C1 stays transitional K0; two due peers can execute C2.
