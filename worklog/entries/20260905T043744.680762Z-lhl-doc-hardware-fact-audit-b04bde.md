# Correct memory terminology and hardware facts across docs

## Summary

Swept the documentation for the `HBM` shorthand and for hardware figures that
contradict `docs/ROOFLINE.md`. Neither validated host uses HBM: the W7900 is
GDDR6 and the Radeon 8060S is unified LPDDR5X. Four numerical errors were found
alongside the terminology, one of which understates W7900 capacity by half.

No measured row, artifact, or conclusion changes. Every correction is to
descriptive text about the hardware, not to a result.

## Changes

Terminology, 46 occurrences across 13 documents:

- `VRAM` in the `gfx1100` campaign documents, matching `docs/ROOFLINE.md`:
  `MEGAKERNEL.md`, `MTP.md`, `PREFILL.md`, `DFLASH.md`,
  `DFLASH_FUSION_COSTMODEL.md`, `OPTIMIZE-DENSE.md`, `PHOTON2.md`,
  `TUNING-gguf.md`, `AGENTIC-OPT.md`, `PLAN.md`.
- `memory` in `TUNING-gfx1151.md`, since Strix Halo is unified LPDDR5X and
  `VRAM` would be equally wrong there.
- `device memory` in `CONCURRENCY.md`, which spans both backends.
- `docs/RDNA3-TUNING-GUIDE.md` keeps `external memory`, which is deliberate: it
  is the one document that must cover GDDR6 and LPDDR5X in the same sentence.

Three references to HBM are correct and were left alone. `SPECULATIVE-DECODE.md`
compares the W7900 against HBM2e/3 datacenter parts, and `PHOTON2.md` cites an
H100 80 GB HBM3 baseline.

Hardware facts:

- `PLAN.md`: the device memory tier said `24 GiB on W7900`; the W7900 has
  48 GiB. Its bandwidth column said `~1 TB/s`; corrected to 864 GB/s GDDR6 to
  match the other rows, which all name a real interface.
- `MEGAKERNEL.md`: the persistent-barrier crossover was attributed to a `64 MB
  Infinity Cache`; the W7900 last-level cache is 96 MB (16 MB x 6 MCDs).
- `MEGAKERNEL.md`: an occupancy note said `32 blocks on 48 CUs`; the W7900 has
  96 CUs and 48 WGPs. The document already flagged this conflation in section
  9.3 but never applied the fix to section 1. That flag also named
  `ROOFLINE.md` as carrying the same error; `ROOFLINE.md` is now correct, so the
  stale cross-reference was dropped.
- `GFX1151-TUNING-LANDSCAPE.md`: the AOTriton crossover rationale described
  `gfx1100` as `96 CU / 48 MiB MALL`; the MALL is 96 MiB. The argument is
  unaffected, since it turns on the 8060S being the smaller part.

## Validation

- Confirmed the corrected W7900 figures against `docs/ROOFLINE.md` section 1.1:
  96 CUs, 48 WGPs, 6 MB L2, 96 MB Infinity Cache (16 MB x 6 MCDs), 384-bit
  GDDR6 at 864 GB/s, and against the guide's validated host table.
- Confirmed no conclusion depends on a corrected figure. The 64 MB stage row in
  the `MEGAKERNEL.md` crossover table is measured, and a 64 MB working set
  sitting at the cache edge is consistent with a 96 MB last-level cache. The
  `32 blocks on 96 CUs` correction strengthens the occupancy argument it
  supports rather than weakening it.
- Swept for further hardware contradictions and found none: W7900 bandwidth is
  864 GB/s in all 15 statements, `gfx1151` is 40 CUs and 256 GB/s LPDDR5X
  throughout, L2 is 6 MB, the WMMA tile is 16x16x16 in all 40 statements, the
  maximum workgroup is 1,024 in all 9, and no document claims native FP8 on
  `gfx11`.
- Restored `MEGAKERNEL.md` from its pre-correction revision before substituting,
  so the retained diff is 16 lines with original wrapping rather than a
  reflowed file.
- Verified no introduced line exceeds its document's existing width convention.
- `git diff --check`
- Documentation-only change; no GPU benchmark or kernel test was run.
