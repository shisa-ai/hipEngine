# Decode original Inkling 2 Mini expert weight formats

## Summary

Add a NumPy reference for reading original packed expert matrices one expert at a time. This decodes weights only; it does not implement the checkpoint's activation quantization or run generation.

## Changes

- Decode NVFP4 low-nibble-first E2M1 weights with E4M3 block scales and the per-expert outer factor. Decode MXFP8 E4M3 weights with UE8M0 block scales. The storage layouts and multiplication order follow the [Transformers release converter](https://github.com/huggingface/transformers/blob/6173a2f679ff4ed393afc499aefc569da7e68bc1/src/transformers/core_model_loading.py).
- Reject incompatible shapes, storage dtypes, and invalid NVFP4 outer factors.

## Validation

- Both Inkling unit modules passed (13 tests total), including hand-computed scale and nibble fixtures. The new module failed to import before implementation.
- Default CPU suite, fixture checks, and registry, CPU fixture, and smoke-build-plan checks passed.
- Memory-mapped the original target checkpoint and decoded experts 0 and 127 for both matrices in layers 0, 19, 20, and 23. All samples had the expected shape and finite, nonzero values; this checked real storage, not logits.
