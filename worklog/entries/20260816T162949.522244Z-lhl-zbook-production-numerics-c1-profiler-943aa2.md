# Add ZBook c1 ownership profiler

## Summary

Added a fail-closed current-owner profiler to start the independent ZBook
production-numerics c1 lane without importing any W7900 or other-gfx1151 rate.
It emits one same-host p512/d128 current-package baseline and a marked decode-
only role/kernel Amdahl table for mechanism selection.

## Changes

- Added `scripts/zbook_production_numerics_c1_profile.py`.
- The adapter requires `hostname=zbook`, gfx1151, p512/d128, at least five wall
  repeats, a clean source tree, exact repeated-token guard output, cached builds
  inside rocprofv3, exact marker windows, and attributed launch correlations.
- Warmbuild runs outside rocprofv3. The profiled child uses existing ROCTX role
  instrumentation and records kernel/marker/HIP trace hashes.
- New canonical provenance v2 records the physical host. Output explicitly makes
