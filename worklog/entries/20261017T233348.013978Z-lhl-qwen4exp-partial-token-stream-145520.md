# Handle partial-token logprob omission in chat streams

## Summary

The first live text-stop audit found a chat error when a stop cuts a token, leaving visible text without a complete-token logprob. Chat now accepts that omission only when retained source records prove the visible text is a strict prefix of their decoded text. Missing backend records still raise an unsupported-logprobs error.

## Changes

- Added the same partial-token allowance to content and reasoning stream serializers. The probability of a token fragment is not invented.
- Extended the partial-token unit test to exercise chat serialization as well as completions.
