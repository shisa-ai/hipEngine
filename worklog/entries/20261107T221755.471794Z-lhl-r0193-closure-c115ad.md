# Close R0193 MoE numerical-scope plan transport

## Summary

The MoE C2 numerical-scope field (`disable_f32_residual`) travels in the immutable
profile-owned `PhysicalTargetArithmeticPlan` bound on the gfx1151 MoE generator, and
it is applied around physical verification. Public validation is the same run
recorded for R0191/R0194
(`worklog/entries/20261107T215207.470839Z-lhl-r0191-r0194-moe-c2-public-58c985.md`).
`moe_physical_c2_numerics_session` remains a supported diagnostic scope. R0193
closes.
