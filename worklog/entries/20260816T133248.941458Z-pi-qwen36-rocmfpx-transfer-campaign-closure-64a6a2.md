# Close the Qwen3.6 ROCmFPX transfer campaign

## Summary

Closed the five-opportunity transfer campaign nominated by the read-only
ROCmFPX audit on the Qwen3.6-35B-A3B gfx1151 paths. The campaign imported no
external runtime or format code and changed no architecture.

Final decisions:

1. **Small-M weight reuse:** hipEngine's existing exact output-tiled pack8
   route already implements the mechanism; fresh repaired-runtime c4/c8 gains
   are +3.41%/+4.00%. Keep it and do not duplicate it.
2. **One-plane Q8_1:** reject. Projection speed does not survive the
   operation-complete `SiLU(gate)*up` KL gate.
3. **SiLU+rotation boundary:** retain the exact pair-rotate shared-prefill route
   default-on. It improves the actual leaf 1.371x and removes 69 launches; the
   strict registered fallback and temporary rollback env remain.
4. **Selective unsafe math:** reject and remove. Numeric/sentinel gates pass,
   but the actual leaf is 7.67% slower.
5. **Adaptive MTP:** keep the existing prompt-agnostic B1-probe structure. It is
   exact and beats true AR/fixed controls, but one dirty-provenance packet and
   a noise-scale B3-vs-B2 delta do not justify a new cap or topline.

Net: one new default-on exact boundary fusion, one existing default revalidated,
two transient candidates fully removed, and one existing policy revalidated
without promotion.
