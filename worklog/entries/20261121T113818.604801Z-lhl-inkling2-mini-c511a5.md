# Pin Inkling attention and convolution activation exchanges

## Summary

Use the shared page-locked activation exchange around target attention and short convolution. Queue both copies on the same stream as the kernels and wait once before returning the result.

## Changes

- Leave FP32 attention, convolution, cache appends, and rollback journal writes unchanged. Retain ordinary copies where page locking is unavailable.
