# Screen gfx1151 static-K Q4T16 decode

## Summary

Reject compile-time K specialization for the dominant exact Q4T16 c1 family.
All seven actual role geometries remain BF16-bit exact, but the dominant FFN
gate/up role regresses and the call-weighted request projection adds 4.711 ms
(0.0425%). The retained dynamic-K local32 source is restored byte-for-byte; no
full-model gate is warranted.
