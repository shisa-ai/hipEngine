# Muse Glimmer: F16 activation pre-cast is the dominant prefill lever

## Summary

Reviewers' #1 hypothesis confirmed by measurement. The shared_b bf16 path runs
load_compact_row_half16<uint16_t>, doing 16 scalar bf16->f32->f16 conversions
per fragment per column block, stealing VALU issue slots from WMMA (RDNA3
issues WMMA through the VALU). Casting the activation to F16 once (0.043 ms)
and using the existing half_t specialization (single vector load) jumps
ffn_gate from 19.8 to 27.8 TF. Combining with the fixed wide-N 8-wave tiles
reaches 29.2 TF.
