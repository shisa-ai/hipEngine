# Gemma split divergence depends on preceding cache history

## Summary

At the recurring failing position, using split attention only for the current
forward with strict cache history gives KL 0.00000626851446. Using split for all
decode forwards after the common 1024-token prefill gives KL 0.05558947161998167.
The accumulated history materially affects the failure. This does not establish
which earlier position or layer causes it, nor prove a repair impossible.

The target is absolute input position 1888, scored row 864 of the frozen chain.
The strict trace matches the frozen strict logits exactly at positions 1886–1890.
The full-split trace reproduces iteration 49's maximum KL exactly at 1888.

## Layer evidence

All indices are zero-based. At position 1888, layer 0 matches; the first observed
attention context difference is layer 1 (451 BF16 elements, maximum absolute
value difference 0.0078125). By layer 21, the residual output maximum difference
is 0.265625, although the selected expert sets have matched in every layer so
far. Expert sets first differ at layer 22 and also differ at 27, 28 and 29.
Final layer residual output maximum difference is 34.25.

Routing changes alone are not an explanation: at position 1887, 22 layers
select different expert sets while KL is only 0.000000106421532449. The
current-only split control has no expert-set changes at position 1888 and much
smaller KL. Later control positions return to strict attention, but their caches
include position 1888's changed values; they are not fresh strict baselines.

## Changes

No production code changed. This is a diagnostic, not promotion or speed evidence.
No RED test applies: the experiment observes existing intermediate arrays without
changing their values. Layer wrappers copy context, projected attention, residual,
dense/expert branch results, selected experts and routing weights after each
layer at five positions. Copies synchronize and therefore cannot measure speed.

Host `epyc`, physical GPU1 RX 7900 XTX, hip_gfx1100, Gemma 4 26B-A4B-it
UD-Q4_K_XL, BF16 KV, context 8192. Identical 2048-token chain, common prefill
of 1024 tokens; decode continues through absolute position 1890.

provenance, per-layer measurements at 1888, neighboring-row summaries, raw
