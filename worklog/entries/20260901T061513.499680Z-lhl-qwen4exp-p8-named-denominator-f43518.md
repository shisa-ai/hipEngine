# Retire the P8 strawman denominator

## Summary

The retained P8 whole-transition result of **3.15x** was measured against a
probe-local eager arm, not the named decode path. Against production
`runner.step()` at the same profile, prompt, and context the graph is
**1.112x**. The rung still clears the section 5.1 impact gate and stays in the
queue at rank 2, below the p4096 QSA cliff.

## Validation

Clean gfx1151 run at `7c16a1e92`, strict manifest `e93c8fa4…`, 30 synchronized
samples per arm, three counterbalanced repetitions:

- named default, MoE graphs on, device argmax: **68.855 ms/step**;
- MoE graphs on, host full-logit D2H: **69.187 ms/step**;
- MoE graphs off, device argmax: **143.989 ms/step**;
- MoE graphs off, host full-logit D2H: **144.155 ms/step**;
- discarded warm arm: **93.08 ms/step** (first-touch weight paging).

So the shipped per-layer MoE graph cache is worth **2.091x**, the probe's
script-level launch loop a further **1.35x**, and whole-transition capture only
the residual **1.112x / 6.945 ms per step**. The probe's eager arm overstates
the named path by **2.83x**. Device argmax versus host full-logit D2H differs
by at most 0.35 ms with the sign flipping between runs, so the AR output
boundary is not a decode lever. MoE cache records 48 captures and zero rejects.
Steady allocation growth is **0**; teardown returns **82,741,321,248 bytes /
1,638 allocations** to zero. An independent earlier repeat of the same protocol
measured 69.102/143.038/68.756/141.601 ms, within **0.7%** of every retained
arm. `sync_benchmark_readme.py --check` passes.

Derived ledger arithmetic, computed from the existing frozen p508/tg rows: no
itemized prefill module owns more than **18.9%** of the 4.334-s device gap and
**41.6%** is unattributed; itemized decode deltas sum to **124.7%** of the
9.73-ms gap because llama spends **2.40 ms/token** more than hipEngine outside
them. The p512 non-kernel residual is **20.82 ms/token (30.0%)**, so perfect
submission contraction reaches **48.63 ms/token (20.56 tok/s)** — above the
patched-HIP target, below upstream Vulkan.
