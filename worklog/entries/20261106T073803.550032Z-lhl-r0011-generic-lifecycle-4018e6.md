# Cover generic-only child retirement and peer progress

## Summary

Generic-only service children permit an AR peer to finish while their own
advancement is paused, then retire on cancellation, deadline or shutdown.
Provider admission/completion errors permit subsequent generic reuse.

## Changes

- Extract the bounded generic-only fake driver and add an explicit advancement
  event. No frontend or MTP model calls are used.
- Cover peer AR progress, terminal abort exactly once, no active backend state,
  reuse after cancellation/deadline/error and shutdown retirement.
