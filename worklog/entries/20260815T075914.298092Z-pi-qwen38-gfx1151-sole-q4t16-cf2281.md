# Qualify Qwen3.8 gfx1151 sole Q4T16 ownership

## Summary

Qwen3.8-27B on Radeon 8060S / gfx1151 now has a candidate sole
`gguf_q4_k_t16_v1` owner for every rank-2 Q4 weight. The fail-fast and bounded
512/128 gates are exact, remove all persistent pack8/decode sidecars, reduce
tracked peak memory from 31.659 to 18.623 GiB, and improve dirty-candidate
prefill/AR medians from 85.234/7.041 to 193.889/10.879 tok/s. These are
qualification measurements, not yet retained clean performance claims.

## Changes

- Enable `GGUF_DENSE_Q4_T16` in the gfx1151 package so capability-driven main
  and NextN materialization reuse the existing operation-complete T16 family.
- Extend gfx1151, main-plan, selected materialization, peer-policy, and NextN
  ownership tests. Every 288 layer Q4 owner has only `tiles`; the raw token
  embedding remains unchanged.
- Add `scripts/qwen38_q4_t16_actual_operation_gate.py`, a non-performance gate
  over a 143.438-MiB actual Qwen3.8 FFN gate/up/down pool. It checks c1,
  verifier rows 2/3/4, tails 16/33, and M512/M1024/M4096 for singleton,
  dual+SiLU, and down+residual/unfused-add operation classes.
