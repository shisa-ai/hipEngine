# Use four outputs for aligned Inkling NVFP4 tiles

## Summary

Wide NVFP4 expert tiles use four outputs per wave when all groups are complete. Remaining aligned widths use two outputs; other widths keep the one-output implementation. Route order and per-output arithmetic are unchanged.

## Changes

- Apply the existing template to four outputs with no ABI change. Extend the paired and scalar parity fixture around the alignment boundary and on the real wide gate/up geometry.
