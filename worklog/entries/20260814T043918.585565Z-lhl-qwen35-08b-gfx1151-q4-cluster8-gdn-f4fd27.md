# Retain Q4-scoped cluster8 GDN for Qwen3.5 0.8B gfx1151

## Summary

Promoted the already-registered Vulkan-shaped eight-lane GDN recurrence for
only the Qwen3.5-0.8B Q4_K_M geometry on gfx1151. The 16K/16V shape exposes
only 64 one-wave exact-LDS32 blocks at pp512; cluster8 recovers state-row
parallelism, passes the complete peer-aligned semantic and production-graph
decode contract, and improves paired full-model prefill 4.33%. Q8_0 keeps the
strict-exact route after its otherwise-fast candidate misses decode
non-regression by 0.0108%.

## Changes

- Added a generic backend-plugin capability keyed by actual GGUF file type plus
  `(num_k_heads, num_v_heads, head_k_dim, head_v_dim)`; no backend or quant
  branch was added to engine/model code. Using file metadata also fails safe if
  a benchmark caller supplies a stale quant label.
- Scoped gfx1151 cluster8 to `(MOSTLY_Q4_K_M,16,16,128,128)`. The existing
  nonvolatile direct-LDS32 default remains in force for Q8 and every other
  gfx1151 shape; gfx1100 defaults are unchanged.
- Preserved explicit `exact` and `HIPENGINE_GGUF_GDN_PREFILL_MODE` rollback and
  bisection routes.
- The production audit found current exact geometry of 64 x 32-thread blocks,
  16 KiB LDS/block, 1.6 blocks/CU, and an observed compiler occupancy target
  reduction from four to two waves/EU. Compact-peer is structurally irrelevant
  because this model has one V head per K head and therefore no duplicate Q/K.
- Bounded three existing candidates without kernel edits. Complete-chain leaf
  speedups were 1.529x peer-wave32, 1.618x peer-cluster8, and 1.316x wave32-tree;
  cluster8 had output NMSE 8.24e-10, state NMSE 5.87e-14, and 100% row top-1.
- Post-route marker attribution cuts GDN 67.599 -> 42.828 ms (-36.64%). The
  largest non-exhausted owner is now remaining linear-attention projections at
  74.771 ms versus 19.350 ms Vulkan, a 20.49% request bound.
