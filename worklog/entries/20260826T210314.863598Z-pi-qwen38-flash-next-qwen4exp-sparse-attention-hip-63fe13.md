# Add strict sparse Qwen4Exp paged attention

## Summary

Added strict sparse QSA paged GQA over selected logical positions and original
uncompressed BF16 K/V under `KVLiveSpans`.

## Changes

- Online-softmax kernel consumes explicit int64 selected positions and int32
  physical page table, maps group-12 Q heads to K/V heads, and accumulates FP32
  context without compacting or compressing K/V values.
- Registered a strict `qsa_sparse_attention/bf16_kv/strict_spans` fallback.

## Validation

- RED: sparse test failed because the wrapper did not exist.
- GREEN: real HIP test passed on Radeon 8060S/gfx1151.
- 24Q/2KV/256-dim official geometry with a deliberately swapped two-page table
  and seven non-contiguous positions matches the independent logical-position
  CPU oracle within 2e-5 using BF16-rounded original K/V.
