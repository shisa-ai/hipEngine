# Localize recurrent subchunk numerical divergence

## Summary

The broad external recurrent-subchunk wrapper fails its paired numerical screen
at 1,023 tokens. Do not promote it. Longer cases match, but route instrumentation
is needed to establish whether those cases exercised the candidate partition.

## Changes

`~/gate-runs/qwen38-edge-cache-repaired-20260926/`, using the same wrapper as

production correctness claim follows.
