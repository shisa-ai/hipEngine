# Attribute host cost in warmed packed Inkling prefill

## Summary

Warm packed prefill spends substantial time waiting for HIP and evaluating host sigmoid. In the slower Strix Halo profile, allocating the per-visit KV banks accounted for most of an additional host-side wait, so allocation should be isolated before changing arithmetic.
