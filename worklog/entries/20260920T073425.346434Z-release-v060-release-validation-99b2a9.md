# Repair CPU-only release test prerequisites

## Summary

Repair release validation on a CPU-only Python 3.12 environment without
changing inference code or weakening numerical gates. The host has AMD
hardware visible through system discovery but no HIP library on the CPU
environment's loader path, exposing assumptions masked by GPU environments.

## Changes

- Shared HIP test fixture requires the runtime library before returning an
  architecture; Q5 and Laguna poison tests request that fixture.
- Synthetic MTP artifact tests select the CPU-reference provenance backend.
- Test doubles initialize the new adapter, timing, and prefix state; memory
  assertions include private-workspace/accounted-byte telemetry.
- Logger assertions set the actual uvicorn logger level. Missing-model guards
  check every required control/checkpoint before loading, independently per
  plain GGUF control.

  compression bytes. On this host the generated and committed pixels were
  already identical, with a different PNG encoder.

  serial/parallel assertions are unchanged.

  result-artifact citations, with two new RED/GREEN tests. No missing result
  artifact exception was introduced.
