# Correct: layer-2 grouped routing is neutral (thermal-variance supersession)

## Summary

The apparent grouped-routing speedups in 20260830T212030 (+4.8%, single
repeat) and the broad-flag measurement in 20260830T212716's context are
thermal/session variance, not real wins. This entry supersedes those speedup
claims. The isolated, controlled finding: routing layer 2 (Q5_K/Q5_K/Q8_0)
through the grouped Q5_K WMMA gate/up path is **neutral** at p512
(-0.4% aggregate, within noise), deterministic, and arithmetic-changing but
the heldout correctness gate still passes. Conclusion: do NOT promote layer-2
routing on present evidence.

## Changes

- Re-applied layer 2 to `QWEN4_EXP_PRODUCTION_MOE_PREFILL_LAYERS` and ran a
  controlled 3-repeat p512 canonical benchmark in the same thermal window as
  the 3-repeat baseline; then reverted the change (working tree clean).
- No source change is retained: the earlier +4.8%/+6.7% readings were
  cross-window artifacts. This entry corrects the two committed records.

Decisive check: the broad-flag candidate
(`HIPENGINE_QWEN4_EXP_GROUPED_MOE_PREFILL=1`, measured 84.73) produces

(84.73 vs 79.10) is therefore pure host/thermal variance, not a code effect.
Baseline and either grouped config differ in output tokens (layer-2 grouped
changes arithmetic) but the perf delta is within noise.
