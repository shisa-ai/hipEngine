# R0523 c2 identical prompts clean: race requires 4-row packed geometry

non-degenerate prompts (all last=token_id+1=9708), c2 is byte-clean while c4
races on all rows. Both engage the same packed-decode path, so the fault is
specific to the 4-row packed geometry, not any multi-row batch.
