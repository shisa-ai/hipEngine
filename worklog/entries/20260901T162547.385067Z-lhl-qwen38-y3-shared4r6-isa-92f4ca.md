# Analyze Y3 shared4r6 generated ISA

## Summary

Disassembled the retained planar-Q6 shared4r6 code object to identify whether
the compiler already interleaves dequantization and WMMA issue.

## Changes

- Extracted the gfx1151 code object and published static instruction/barrier
  counts plus one exact decode-granularity candidate.

## Validation

The specialized body contains two static workgroup barriers and 192 WMMA
instructions in sixteen groups of twelve. The 326-instruction cooperative
decode region between barriers contains 22 global loads, two LDS stores, 17
converts, 17 mix-FMAs, and zero WMMA. The generated schedule therefore does not
cross-interleave dequantization and tensor instructions at the handoff.

## Next

- Screen adjacent-column-pair cooperative decode. Qmicro low bytes are shared
  by a column pair and high bytes by a quartet, allowing exact record-byte and
  address reuse without changing LDS layout or WMMA accumulation order.
