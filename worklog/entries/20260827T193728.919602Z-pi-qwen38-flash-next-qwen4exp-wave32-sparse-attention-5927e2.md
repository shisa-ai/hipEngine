# Promote Qwen4Exp wave32 sparse attention

## Summary

Promoted the production wave32 H128 sparse-attention variant. It removes the
strict owner's per-selected-token workgroup barriers, improves the real kernel
9.41%, and passes a four-category sparse packet plus natural 4K retrieval with
bit-exact final logits/control/task output.

## Changes

  four coordinates and follows strict strides 64/32 before the 32-lane shuffle
  tree; online-softmax token order remains ascending.
- Registered `production_wave32_h128_spans` and
  `production_rows_wave32_h128_spans`; strict shared-memory variants remain

  `HIPENGINE_QWEN4_EXP_QSA_WAVE32=0` bisection fallback.
