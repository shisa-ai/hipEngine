# W7900 Qwen3.8: remove the resident AR route's equal-chunk-length guard so mixed-length waves group (inert by default)

## Summary

`_try_prefill_native_work_batch` refused any work item whose rows did not share one
chunk length. The AR wave never has uniform prompt lengths (standard suite: 35, 36,
36, 39, 39, 43, 46, 48, 60, 67), so the route was unreachable in practice and the
C1-C8 matrix prefilled one request per step - 305-335 ms per lane, flat in width,
against llama.cpp's 216-436 ms for the whole wave. The guard is removed. It is
**inert by default**: `engine_loop` still only reaches the batch route when
`packed_prefill_max_rows > 1`, which the undeclared
`GGUF_C2_PACKED_PREFILL_MAX_ROWS` keeps at 1.

## Changes

- `hipengine/generation/qwen35_gguf.py`: replace the
  `len({len(chunk) ...}) != 1` early-return with an empty-chunk refusal, and record
  in the docstring why mixed lengths are legal (`full_prompt_lengths` is forwarded
  per row, which is how the serving route already drives the same entry point).
- `tests/test_generation_qwen35_gguf_sampling.py`:
  `test_resident_ar_packed_prefill_groups_mixed_prompt_lengths` - RED first (the
  guard returned `False`), GREEN after. Drives the real method through
  `__new__`-stubbed rows/leases/owner and asserts one grouped call carrying lengths
  `(4, 2, 1)` with `native_full_prefill_rows == 3`.
- `scripts/gguf_backend_capability_exec.py`: reject a non-source target. The A/B
  `on` arm passed the interpreter after `--`, so `runpy` tried to compile an ELF and
  died with "source code string cannot contain null bytes"; a silent duplicate arm
  was one typo away.
- `docs/REFACTOR.md`: the section I added earlier today now states what is landed
  and what still gates promotion.

## Validation

- `pytest tests/test_generation_qwen35_gguf_sampling.py tests/test_gguf_prefix_cache_runner.py -q`
  -> 126 passed, 1 skipped, including the five pre-existing packed-prefill tests
  (equal-length inputs unaffected) and the new mixed-length test.
- Wrapper guard verified against the exact bad invocation; it now errors with the
  corrected usage instead of reaching `runpy`.
- Default behaviour is unchanged by construction (capability still undeclared); the
  tripwire test pins that, and the capability wrapper independently echoed
  `previous: None` for `GGUF_C2_PACKED_PREFILL_MAX_ROWS`, re-confirming the
  dead-branch finding.

## Consequence for the running A/B

The `off` arm (started 11:48:31, before this edit, capability unset) is a clean
status-quo-ante control. The `on` arm imports this code, so the pair now measures
**fix vs baseline** rather than capability alone. Attribution comes from the packet's
own prefill route group sizes, not from the wall ratio alone. Content-exactness is
the binding gate: the packed route changes GEMM shapes, and greedy sampling can flip
on a logit perturbation.
