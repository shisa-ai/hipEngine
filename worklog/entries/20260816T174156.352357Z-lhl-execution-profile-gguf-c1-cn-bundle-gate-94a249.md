# Add bundled c1 and cN production candidate gate

## Summary

Extended the existing c>N Q8T16 rowtile quality adapter to gate the actual
first production bundle: strict disables both the cooperative/persistent c1
router and Q8T16 rowtiling; candidate enables both. The old Q8-only protocol
remains available by default for reproducibility.

## Changes

- Add `--include-router-candidate` to apply complete strict/candidate router
  environments at every existing strict/candidate decode scope.
- Preserve and restore caller environment values and record both route
  manifests in the artifact.
- Reuse the existing 18-prompt static-c4/c8, 8->4->2->1 retirement, sparse-c8,
  1,050-row, three-repeat evaluator protocol.
