# VibeVoice ASR torch fixtures, Qwen2 CPU reference, fixture bug fixes

## Summary

Torch oracle fixtures (CPU fp32) for the VibeVoice-ASR front-end + Qwen2
backbone, the numpy Qwen2 CPU reference, torch-free Qwen2 loader, and parity
tests. Several oracle/fixture bugs found and fixed en route. Follow-up to
`20260913T212039.508803Z-lhl-vibevoice-asr-hip-encoder-aa97fd.md`.

## Changes

- `hipengine/kernels/cpu_reference/qwen2.py`: numpy fp32 Qwen2 reference
  (plain RMSNorm 1e-6, GQA + QKV biases, scalar rotate-half RoPE theta 1e6,
  SiLU MLP, untied head) validated per-layer vs transformers in-process.
- `hipengine/loading/vibevoice_asr.py`: torch-free `load_vibevoice_qwen2`
  from the HF artifact (`language_model.*`, `lm_head`), spec from config.
- Oracle script fixes (each found by a failing parity gate):
  * eager attention required (tokenizer encoder has no SDPA path);
  * 3-D input_values: transformers 5.15.0 `get_audio_features` crashes on
    standard 2-D `(batch, samples)` input in the chunk-cache path (upstream
    bug; the processor's 2-D contract cannot reach the model directly);
  * `randn_like` on a permuted view uses preserve_format and scrambles the
    fill order - latents must be made contiguous before recording noise;
  * raw clips below 3200 samples are unprocessable even in HF (deepest
    conv needs padded input >= kernel; the chain minimum is exactly 3200) -
    processor's mandatory pad_to_multiple_of=3200 exists for this reason;
    boundary fixture set changed to 3200/3201/6400/6401;
  * `audio_placeholder_positions` was saved as batch indices (all zeros);
  * teacher-forced logits were computed on raw input_ids (placeholder token
    embeddings) instead of audio-scattered inputs_embeds.
- Live tests: boundary frame counts; Qwen2 teacher-forced LM parity.
- GPU test: HIP front-end vs torch-GPU bf16 fixture (skips until fixture).

## Validation

- Live CPU-parity (fp32, real weights): per-stage trace, full forward,
  sampling+connector, boundary frames - 4/4 passed vs torch CPU fixtures.
- numpy Qwen2 layer 0 vs transformers in-process: rel 6e-7 (no-audio) /
  1e-6 (with audio); all 28 layers track within fp32 noise (<= 6e-2 at
  layer 27). First-position logits match the fixture (atol 2e-2).
- Full live suite including the LM test pending the final fixture
  regeneration at commit time (regen in background).
