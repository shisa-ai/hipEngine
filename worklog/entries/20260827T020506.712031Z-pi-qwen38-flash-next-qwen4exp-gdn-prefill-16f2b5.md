# Add exact Qwen4Exp GDN bulk prefill

## Summary

Added strict row-bulk Qwen4Exp GDN Conv+FP32 recurrence execution as the first
mechanical prerequisite for practical Flash-Next long-context prefill.

## Changes

- Added `hipengine_qwen4_exp_gdn_prefill_f32`, which processes row-major FP32
  projected Q/K/V, output-gate, alpha, and beta rows in serial decode order per
  value head while retaining one authoritative FP32 recurrent state.
- Registered the raw-pointer prefill sibling under the Qwen4Exp strict GDN
  registry family; decode remains the strict primitive fallback.
- Made `run_qwen4_exp_gdn_token_mixer` select the existing exact FP32 causal
  Conv prefill plus the new recurrence for `rows>1`, preserving the old c1
  decode path unchanged.
