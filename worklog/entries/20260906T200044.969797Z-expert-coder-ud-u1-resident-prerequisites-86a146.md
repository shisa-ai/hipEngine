## Changes

- `hipengine/quant/gguf_repack.py`: immutable `GGUFRepackShape` owns rank,
  positive expert/N/row-byte dimensions, and output-tile divisibility. Source
  block bytes come from the canonical GGUF quant layout registry, not another
  numeric whitelist. The existing Q4 pack8/T16/qmicro, Q5/Q6 T16-derived, Q8
  T16, and Q4/Q5/Q6 X8 CPU converters now invoke these shared contracts;
  conversion bodies/math are unchanged.
- `loading/qwen35_gguf_materialize.py`: one converter dispatch table replaces
  the old per-layout converter branch chain. Each route couples its real
  converter, the shared shape contract, and the same dense-to-expert rank
  promotion used previously. The new public
  `validate_qwen35_gguf_resident_prerequisites` checks source logical/byte
  geometry, element/byte counts, resident source compatibility, allocation
  names, and independently selected allocated sidecars. The actual materializer
  uses these same routes and validates before even `reader.tensor_data`.
  Removed now-redundant late sidecar compatibility exceptions after allocation.
- `loading/qwen35_gguf_admission.py`: calls that validator before byte accounting
  for **every selected resident**, including slots outside the requested
  operation's role set. Resident failures aggregate under participating
  operations, or operation `-` for a resident-only failure, and remain required
  but unrecorded in completeness accounting. Successful slots outside operation
  scope still do not gain operation authorization. Filtered/debug preflight is
  subject to the same boundary. F1 operation dependency closure is not changed.
- All size calculators and their existing defensive guards are unchanged.
  In particular, byte-neutral counts need not themselves reject shapes: the
  new boundary rejects invalid residents before any size calculation. Q5
  `qmicro_planar` sidecar bytes still use the accepted exact converter formula.
- `tests/test_qwen35_gguf_resident_prerequisites.py`: 43 CPU cases, including
  five RED byte-neutral examples with legal neighbors, full/filtered aggregate
  failures, actual tiny-loader zero-payload/zero-allocation sentinel, all 11
  primary converter route identities and rank/tile/block/dimension boundaries,
  converter byte-size checks, real materializer upload adapters with fake
  device allocation, independent sidecar checks, raw seven-format N257
  preservation, and non-repacked source geometry. Observations of the shared
  contract inside actual converter calls are asserted before calling admission's
  validator, avoiding a metadata self-oracle. Existing CPU inverse/round-trip
  converter tests supply the arithmetic preservation gate.
- Two older admission tests now assert the specific shared N16/N8 prerequisite
  diagnostic rather than the former allocation calculator's `tile-aligned`
  wording. `docs/UD-QUANTS.md` explicitly corrects the round-6 closure claim,
  records this bounded shape repair, and leaves integrated F1/F3/F4/F5 open.
