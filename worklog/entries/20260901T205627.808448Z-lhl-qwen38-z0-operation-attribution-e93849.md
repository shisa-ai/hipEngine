# Attribute Qwen3.8 Z0 operation wall

## Summary

Captured current-head cache-only `rocprofv3` kernel, HIP-runtime, and
memory-copy traces for every exact C2/C8 grouped prefill row shape and for one
canonical C5/C7/C8 explicit-MTP diagnostic on physical host `gfx1151`.
C7/C8 passed self-exactness, AR/MTP equality, route engagement, and budget
checks. C5 reproduced the full-suite correctness failure and remains
attribution-only.

Every C2/C8 prefill point is GPU-bound: wall minus the HIP-event span is below
0.04 ms and no memory-copy engine event falls inside a tick. The standardized
server artifact confirms that both C2 requests share one grouped prefill tick
in every prompt cell. Grouped C2 rows are 70, 72, 78, 86, 92, 96, 120, and
134.

At correctness-passing C7/C8, operation wall is 647.6/661.9 ms per average
request cycle. Named telemetry stages account for 439.3/439.6 ms, leaving
208.3/222.4 ms outside those stages. The residual is an upper bound over
scheduler, server, inter-group waiting, and uninstrumented work; this unit does
not claim those causes are individually resolved.
