# Screen cheaper sigmoid for packed Inkling experts

## Summary

Selected-expert sigmoid accounts for most host sigmoid time in packed prefill. A faster host formula improved the short diagnostic requests, but changed FP32 values, so it is not a strict replacement.

## Changes

- No runtime changes. Screened the stable logistic formula `t = exp(-abs(gate)); where(gate >= 0, 1, t) / (1 + t)` in the selected-expert activation only. Attention gains and expert routing retained their existing sigmoid.

Both the 512-route block and 8-route token cases changed bits, with a largest absolute sigmoid difference of `1.7881393e-07`. A separate NumPy 2.4.6 synthetic screen also ruled out bitwise parity for a decomposed `logaddexp` formula.

All generated token IDs matched in both run orders.
