# Run published UD K_M through raw dense consumers

## Summary

Published Qwen3.8-27B UD-Q4_K_M runs eager c1 inference on zbook/gfx1151.
A five-token prompt produces eight tokens with finite full logits. This is
integration evidence, not teacher-quality or performance qualification.

## Changes

- Plan rank-2 layer IQ4_XS/IQ4_NL/IQ3_S/Q3_K as a single raw compressed
  allocation. Keep root and rank-3 expert routes separate. No repack/policy,
  model runtime, profile binder, or quant-dependent dispatcher branches added.
- Declare concrete raw linear keys with BF16/F32 outputs; reject FP16 outputs
  and F32 inputs for the new dense types. Existing raw launch ABI is unchanged.
- Metadata preflight now covers all K_M slots; K_S has seven remaining planner
  refusals (Q3_K embedding, IQ3_XXS/IQ2_S projections). These declarations do
  not establish backend numerical qualification or full serving support.
- Update preflight regression expectations and registry-isolation fixtures to
  include the new production registrar. Preserve allocation-before-refusal
  protection using K_S, which still has missing formats.

```bash
from pathlib import Path
import numpy as np
from hipengine.loading.gguf import load_gguf_index
from hipengine.tokenization.gguf import Qwen35GGUFTokenizer
from hipengine.runtime.qwen35_gguf_runner import Qwen35GGUFResidentSession
model='/models/gguf/Qwen3.8-27B-UD-Q4_K_M.gguf'
tok=Qwen35GGUFTokenizer.from_gguf_info(load_gguf_index(model))
ids=tok.encode('The capital of France is')
with Qwen35GGUFResidentSession(model, backend='hip_gfx1151', max_sequence_length=64,
        compiler_version=Path('/tmp/ud-hipcc-version.txt').read_text()) as s:
    r=s.prefill(ids, use_bulk=False, return_logits=True)
    generated=[]
    for i in range(8):
        assert np.isfinite(r.logits).all()
        generated.append(int(r.token_id))
        print(i, generated, tok.decode(generated), flush=True)
        if i<7: r=s.step(r.token_id, return_logits=True)
PY
```
