# Add GGUF c1 production-route numerical gate

## Summary

Added the first reusable same-resident GGUF c1 candidate gate for the calibrated
production-numerics campaign. It treats gfx1151's incumbent cooperative F32
router as a T2 candidate against the separate strict projection/select chain;
it does not inherit the gfx1100 qualification.

## Changes

- Capture strict full logits and three teacher-forced candidate trajectories on
  every prompt/category/heldout row.
- Evaluate the calibrated mean/p95/p99/max KL and scoped top-1 gates.
- Fingerprint live Conv/GDN/KV state after every trajectory and require finite,
  layout-stable, bit-repeatable candidate state while recording strict versus
  candidate value drift diagnostically.
- Keep performance out of the quality process; exact state/control ownership
  remains a separate dynamic-scenario requirement.
- Add tests for complete environment scoping/restoration and the state-repeat
  acceptance contract.
