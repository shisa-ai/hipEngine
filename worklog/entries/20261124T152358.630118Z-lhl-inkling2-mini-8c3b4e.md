# Device route-tile builder for the resident route path

## Summary

First building block for plan step 2's device-resident routing (campaign step 7):
`hipengine/kernels/hip_gfx1100/moe/inkling2_route_tiles.{hip,py}`. The kernel
reproduces `build_expert_route_tiles` on the device — group route indices by
expert (stable within expert), walk experts ascending, emit fixed-width tiles
(`width` 2 or 4) padded with -1 — and additionally gathers a per-expert outer
scale table into per-route scales. Single-block kernel; O(R^2) rank scan,
intended for decode route counts (8) and prefill tails (up to a few thousand).

Verified bit-exact against the host builder on W7900: ids in {1,3,7,8,15,64,
512,1024 routes} x widths {2,4} (including all-same-expert, all-distinct, and
skewed random draws), padding slots, route-to-record index consistency, and
the gathered-scales path vs `table[ids]`. 20 GPU tests, all pass; neighboring
MoE suites unaffected (37 passed including the new tests).

Not wired into the resident path yet — this is the tile half of the see
below; the packer (device staging buffer assembly) and the router-logits-to-
tiles chain land next, behind the same verification bar.
