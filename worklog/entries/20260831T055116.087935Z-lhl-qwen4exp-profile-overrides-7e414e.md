# Add post-binder Qwen4Exp profile overrides

## Summary

Extended the durable Qwen4Exp gap profiler so an isolated candidate route can
be measured after the named production-profile binder has established the
baseline environment. This replaces one-off `/tmp` candidate profile harnesses
and unblocks a strict-versus-grouped layer-2 role trace without representing the
candidate as named production.

## Changes

- Added repeatable `--override HIPENGINE_KEY=VALUE` arguments to
  `scripts/qwen4exp_profile_gap.py`.
- Restricted overrides to unique `HIPENGINE_*` keys and preserved `=` inside
  values.
- Applied overrides after generator construction/profile binding but before
  warmup and measurement.
- Added artifact fields `configuration_class`, `named_profile_intact`,
  `overrides`, `override_stage`, `bound_route_env`, and effective `route_env`,
  including keys not in the profiler's standard route census. Override runs
  explicitly set `named_profile_intact: false`.
- Added seven focused parser/application tests and documented the diagnostic
  command in the performance campaign.

## Validation

- RED: `uv run pytest -q tests/test_qwen4exp_profile_gap.py` -> 6 failed before
  parser support; the post-binder metadata test separately failed before its
  helper was added.
- GREEN: `uv run pytest -q tests/test_qwen4exp_profile_gap.py` -> 7 passed.
- The change is profiler-only. It does not alter runtime dispatch, production
  manifests, or the public generation path.
