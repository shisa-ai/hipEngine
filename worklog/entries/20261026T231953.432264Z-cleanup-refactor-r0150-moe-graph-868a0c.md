# Replace MoE graph process override with explicit owner control

## Summary

Retire the process-environment graph override while keeping backend-capability
selection, explicit eager/captured diagnostics and fail-closed eager fallback.

## Changes

- Runner/generator construction carries an explicit optional graph choice;
  ordinary callers keep the backend default.
- Fixture and harness migration preserves eager isolation after removing the
  environment read. Cache diagnostics use `set_enabled`, which allocates a
  capture stream when enabling a cache initially constructed disabled.
