# Resident-block decode path lands behind HIPENGINE_INKLING2_RESIDENT_DECODE (default off)

## Summary

Wired the previously uncalled `_resident_block` whole-token traversal as an opt-in single-token
decode path (`HIPENGINE_INKLING2_RESIDENT_DECODE=1`, fast profile, requires resident-block support).
The whole per-token chain (attention halves, residual updates, expert FFN, loop controller) now runs
inside one device arena per token; the host sees only the final hidden row and the residual-stack
blocks. Previously blocked by two latent defects, both fixed:

1. Non-NVFP4 expert banks (mixed-quant layers) made `_resident_block` crash with "Inkling GGUF device
   expert input needs one shared-tile route set". The fallback now bounces the normalized rows through
   the host, runs the standard routed path, and uploads the result back into the arena.
2. `_forward` had no caller for the resident block; it is now gated on width==1, no capture, no undo
   state, `model.resident_decode`, and `resident_block` availability.

Measured (W7900, UD-Q4_K_M, fast profile, device routes on): 48-token greedy chain is
**token-identical** to the eager path (all 48 positions match). Wall time 2.76 s vs 2.66 s eager
(~4% slower): launch-bound at rows=1, consistent with iteration-173 GPU-busy measurements. Kept as an
opt-in flag, documented in docs/ENVS.md and tracked as R0527 in docs/REFACTOR.md. It is the substrate
for HIP-graph capture of the decode chain, not a throughput win today.

Note: eager default path is unchanged (flag off by default; default decode path untouched).

## Changes

- `hipengine/runtime/inkling2_mini_reference.py`: `_forward` resident-decode branch (width==1 gate).
- `hipengine/runtime/inkling2_gguf.py`: non-NVFP4 fallback in `_resident_block` (host round trip).
- `hipengine/generation/inkling2_gguf.py`: `_resident_decode_requested()` env gate, sets `model.resident_decode`.
- `docs/ENVS.md`: new flag row. `docs/REFACTOR.md`: R0527 with promotion condition.

## Validation

- 61 unit tests pass (reference, mini, gguf_runtime, gguf, gguf_resident suites).
- 48-token greedy A/B on the real artifact: identical token ids with flag on vs off.
- Timing: 3 reps eager 2.633/2.638/2.638 s vs resident 2.761/2.761/2.760 s (48 tokens each).
- Resident run repeated after revert of instrumentation: clean tree apart from this change set.
