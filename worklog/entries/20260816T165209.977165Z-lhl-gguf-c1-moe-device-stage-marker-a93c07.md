# Close c1 MoE device-stage interval

## Summary

Fixed profiler-only c1 MoE stage attribution. The device recorder marked
post-attention norm before `_run_post_attention_moe_c1()` but never marked its
completion, so the entire MoE was incorrectly charged to the next layer's
`*_norm` interval.

## Changes

- When and only when a GPU stage recorder is present, add
  `<stage_prefix>_moe_total` after the existing c1 MoE call.
- Normal execution launches no marker and is byte-for-byte unchanged.
- Added RED/GREEN coverage for the exact marker sequence.

## Validation

- RED: focused test observed only `decode_ffn_post_norm_residual` and failed on
  the missing `decode_ffn_moe_total` marker.
- GREEN: the affected FFN tests plus ZBook adapter/rocprof helper tests pass
  `15/15`; `git diff --check` passes.
- The preceding complete ZBook packet is valid for baseline, launch census, and
  zero-duration diagnosis, but its device-stage labels are not used for target
  selection because they absorb c1 MoE into the next norm.
