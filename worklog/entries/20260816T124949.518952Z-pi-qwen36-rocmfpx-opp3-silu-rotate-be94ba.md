# Retain exact shared-prefill SiLU rotate fusion

## Summary

Retained the exact registered FP16 pair-rotate primitive as the default
packed-PARO shared-expert prefill boundary. It replaces standalone SiLU plus
down rotation while preserving the FP16 activation rounding point. The
actual-shape leaf and launch count improve; complete c4/c8 wall remains within
noise, so this is a sub-window/launch-count retention rather than a new
aggregate topline.

## Changes

- Routed non-small `shared_expert_paro_w4_fp16` through
  `silu_mul_pair_rotate_out_fp16` by default.
- Kept the registered `silu_mul_separate_out_fp16 + paro_rotate1_fp16` chain as
  `HIPENGINE_SHARED_PREFILL_SILU_ROTATE_FUSED=0` fallback.
- Added RED/GREEN dispatch coverage and an actual-shape GPU bit-exact test.
- Added the compact artifact and benchmark rollup note/changelog line. The
  rollback-removal trigger is recorded below; its `docs/REFACTOR.md` ledger
  update is split into the immediate follow-up because a concurrent execution-
  profile unit owns that high-conflict file.

## Validation

- RED: the new default-route test observed `silu_separate` and `rotate1` before
  implementation. GREEN: candidate and explicit fallback dispatch tests pass.
- Actual shape rows16/features512/group128/krot8: fused FP16 bits exactly equal
  the unfused chain.
- Leaf rows512/features512/group128/krot8, 500 iterations:
  `29.6433 -> 21.6168 us`, **1.37131x**, zero bit mismatches.
- Complete prompt512/decode32 runs match independent c1 at c4 and c8. Against
  the mean of before/after controls, prefill throughput changes
  **+0.222%/+0.081%** and complete wall **-0.156%/+0.021%** (neutral).
- c8/L4 trace passes hidden/token equality and changes:
  - total dispatches `4644 -> 4575`;
  - separate SiLU `69 -> 0`;
  - pair-rotate `3 -> 72`;
  - standalone rotate1 `257 -> 188`.
- `python3 -m py_compile hipengine/runtime/qwen35_paro.py` passes.
- `uv run pytest -q tests/test_qwen35_decode_state.py tests/test_paro_silu_plan.py --tb=short` passes all collected nodes with three pre-existing HIP-guarded skips.
