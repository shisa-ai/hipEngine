# P7 t1: re-qualified server INT8 capacity ceiling

Roadmap P7, first deliverable: the fresh C1 capacity ceiling the README
required. With the P3 layer-outer executor and the P4 lease removal, the
server INT8 route's capacity bracket (allocation probe, real server
process, 2,048-row prompt, 8 decode tokens, clean SIGTERM teardown every
point) passes 65,536 / 98,304 / 131,072 / 155,648 declared contexts.

## Changes

  re-qualified with bracket artifact links.
- Artifacts: 64K/96K/128K/152K probe JSONs.

## Validation

- 131,072 matches the plain direct-engine INT8 ceiling; 155,648 matches
  the direct single-hidden-plane number - the server route is no longer
  the capacity bottleneck at C1.

  reservation pinned; the fresh ceiling is 2.87x that number.

  0.75-1.62 GiB; workspace 1.01 GiB flat; lease 0 everywhere).
