# Remove the generic dense Q8 iu8-WMMA route after role isolation rejected it

## Summary

The generic dense Q8 iu8-WMMA route is deleted. It was rejected by role
isolation (`20260930T091752`, 14 of 17 roles claim and all 14 fail the canonical
envelope alone), so the code path, its flag, its role scope, its contract tests,
its candidate spec and its diagnostic harness are removed rather than left
gated off.

**One latent hazard this removal closes, found while mapping the blast radius.**
The route was not merely default-off. `hipengine/generation/qwen4_exp_profiles.py`
still bound `HIPENGINE_QWEN4_EXP_Q8_IU8_WMM` to `"1" if production else "0"`,
and the route was suppressed *only* because the flag also appeared in
`PRODUCTION_ARITHMETIC_RECOVERY_FLAGS`, whose blanket sweep zeroes it. It was not
in `PRODUCTION_Q8_QSA_RESTORED_FLAGS`, so the sweep won. Any future narrowing of
that sweep — which this project has already done once for DE-1 and is considering
again — would have silently re-enabled a route that fails the canonical envelope
in 14 of 17 roles. The rejection entry recorded the arithmetic; this entry
records that the arithmetic was one edit away from being live.
