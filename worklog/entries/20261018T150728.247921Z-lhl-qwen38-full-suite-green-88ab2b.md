## Validation

ps18 diagnosis, for the record. The four failures were
`test_qwen38_int8_batch_attention_matches_cpu_and_independent_c1` variants failing with
`FileNotFoundError: cached build artifact missing for require_cached=True`. The test derives
its build-cache key from `/tmp/hipengine-hipcc-version.txt`, and a `rocprofv3` warmup earlier
in this session had written that file as `hipcc --version | head -1` instead of the
documented full output, changing the compiler-version string and therefore the key. Restoring
the full output (`hipcc --version > /tmp/hipengine-hipcc-version.txt`) made all four pass:

```
uv run pytest tests/test_gpu_qwen38_int8_batch_attention_gpu.py
4 passed in 1.31s
```

ps19 then ran the whole suite with the corrected file. Note that the background-task wrapper
reports "completed (exit 0)" for any run because of its trailing `echo rc=$?` sequence, so the
gate was read from the log (`rc=0`, `failed=0`, `aborts=0`, summary line present) rather than
from the task status.
