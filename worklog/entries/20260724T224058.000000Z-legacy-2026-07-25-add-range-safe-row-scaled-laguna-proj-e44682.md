## Changes


- Added separately registered BF16-to-FP16 row scaling for the hipBLASLt projection route. Each row uses `2^ceil(log2(max_abs/65504))` when needed, so the low-precision input stays finite and the scale is exactly representable. Companion kernels restore the scale either in-place on FP32 Q/K/V/gate output or while converting FP32 attention-output projections back to BF16. Existing unscaled cast variants and production dispatch remain unchanged.
- The GPU fixture covers scale-one input and a BF16 row with magnitude 131,072 (`scale=4`), verifies finite FP16, and recovers the original BF16 values through both FP32 and BF16 boundaries. `uv run pytest -q tests/test_cast_plan.py` reports **4 passed**.
- Cached gfx1151 `rocprofv3 --kernel-trace` at `/tmp/laguna-scaled-cast-trace.MX9RMc/gfx1151/144367_kernel_trace.csv` names the scaled cast, FP32 in-place restore, and FP32-to-BF16 restore at **9.538/5.050/5.050 us** on the two-row fixture. All use local256, VGPR16, and zero scratch; only the max reducer uses 1,024 B LDS. Trace SHA-256 is `83fbfc7bf1e9fb4a7740f418202499af00e8f6d1fe555b5b66c30ec94a7ce542`.
