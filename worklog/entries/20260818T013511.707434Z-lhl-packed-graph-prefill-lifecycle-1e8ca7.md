# Invalidate packed decode graphs before prefill slot reuse

## Summary

The deterministic `continuous_fixed` request-11 sentinel was a graph/private-
workspace lifecycle defect, not a layer-7 math or KV-pool addressing defect. A
packed decode graph remained replayable after `prefill_batch_native()` flushed
its state and then reused the same private packed slots. A later graph replay
therefore treated prefill-owned recurrent/KV data as its prior decode state;
the first non-finite residual appeared at full-attention layer 7 and propagated
to the `0x7fffffff` argmax sentinel.

Disabling decode graphs made the unchanged 12-request workload pass. Closing
all graphs that bind the shared packed workspace before prefill, then flushing
the last synchronized graph state on the prefill stream, made the graph-enabled
workload pass as well.

## Changes

- `prefill_batch_native()` now invalidates binding packed/c1 decode graphs
  before it flushes deferred packed state and reuses the private slots.
- The flush uses the prefill stream, preserving explicit ordering without a
  default-stream detour.
- `_invalidate_live_packed_decode_graphs()` delegates from resident slot views
  to the shared batch owner so a view cannot miss owner/peer graph bindings.
- Added host RED coverage for invalidate -> flush -> prefill ordering and for
  slot-view invalidation delegation.
