# Add frozen full-logit Qwen4Exp comparator

## Summary

Added a torch-free full-vocabulary last-token comparator between hipEngine and
the frozen llama.cpp PR #27742 Qwen4Exp implementation.

## Changes

- Built external target `llama-debug` in the existing native gfx1151 build. Its
  frozen source exports FP32 logits and exact token IDs after one prompt decode.
- Added `scripts/qwen4_exp_compare_logits.py`: run llama first, release that
  process, require exact tokenizer IDs, materialize hipEngine, then report
  teacher→hipEngine KL, top-1, mean/max absolute logit error, artifact parts,
  backend, and exact comparator command as JSON. Default gate is KL <= 0.05 and
  top-1 equality; CLI flags may tighten or diagnose but cannot hide nonfinite
  or shape/tokenizer failures.
