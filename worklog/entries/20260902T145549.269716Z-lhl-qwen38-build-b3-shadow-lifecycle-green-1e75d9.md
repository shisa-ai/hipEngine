# Qwen3.8 B3 implements shadow lifecycle GREEN

## Summary

Implemented the B3 request-owned shadow lifecycle contract to GREEN without
selecting a route or changing serving behavior. The current C1 path remains the
strict fallback.

## Implementation

`C1ShadowSessionLifecycle` owns two physical lanes under one real public
request. It rejects missing/aliased target sessions, provider checkpoints,
hidden rows, KV owners, and recurrent owners. Both lanes compute; only the real
request may publish or own the public commit. Compaction changes slots only.
Cancellation restores both checkpoints once. Reclaim is idempotent and records
successful surfaces incrementally, so a partial cleanup failure can retry
without releasing an already-reclaimed resource twice.

The constructor has no variadic or prompt/token/candidate inputs, preserving
the input-independent anti-gaming policy structurally.
