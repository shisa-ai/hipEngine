# Cover full Q5 Q6 UD output geometry

## Summary

Extend the raw Q5/Q6 leaf gate from sampled N=5 to full output widths for
seven published K_M tensors. 84 tests pass on zbook / Radeon 8060S / gfx1151.
No kernel, runtime dispatch, residency default or model-quality gate changed.

## Changes

`tests/test_gguf_ud_q56_roles.py` now runs sampled and full geometries for
rows 1/8/32, BF16 input, and BF16/F32 output. Full `(N,K)` geometries are:
Q5 attention gate (6144,5120), Q5/Q6 SSM out (5120,6144), Q6 attention K
(1024,5120), Q5/Q6 FFN down (5120,17408), Q6 NextN eh_proj (5120,10240).
Full tensors retain the first/middle/last sample hash cross-check, not a new
whole-tensor hash pin. Published-file identity evidence is recorded earlier.

Keep output canaries, poisoned row-local repeat comparisons against the batched
launch, float64 elementwise bounds and unrounded float64 KL <= 0.05. Top-1
compares to the CPU reference rounded to the declared output dtype. This is
an output-ABI leaf check, not a model-logit quality or serving certificate.

## Validation

Initial expanded test: 81 passed, three BF16 top-1 failures in 9.07s. No
implementation changed: RED-first against new production behavior is inapplicable.
Investigation reran only the three failures and inspected CPU/device maxima:

- Q6 attn_k, rows1: FP64 top-1 0%; BF16-rounded CPU top-1 100%; all 1024
  device outputs exactly match rounded CPU output. FP64 values at indices
  909/189 are 0.46617883/0.46584653; both round to 0.46679688.
- Same tensor, rows8: FP64 top-1 87.5%, rounded top-1 100%; three elements
  differ from the rounded float64 dot (F32 accumulation), within fixed bounds.
- Q6 eh_proj, rows8: FP64 top-1 87.5%, rounded top-1 100%; 15 elements differ
  within fixed bounds. Row6 maxima at 2372/784 are 0.60202535/0.60025917;
  both round to 0.6015625.

These are real unrounded top-1 discrepancies, not suppressed model failures.
The leaf oracle now respects BF16 output rounding; unrounded elementwise and
KL comparisons remain unchanged. It does not establish >=90% top-1 against
unrounded FP64 for those three cases, and cannot promote a model default.
