# Staged-f32 fails the 0-47 production gate on mean, p95 and top-1

## Summary

The canonical 12-case D128 gate at layers 0-47, on the fixed dispatch key:

| metric | value | limit | |
| --- | ---: | ---: | --- |
| mean KL | 1.269e-3 | 1e-3 | **fail, 1.27x over** |
| p95 KL | 6.663e-3 | 5e-3 | **fail, 1.33x over** |
| p99 KL | 1.620e-2 | 2e-2 | pass |
| max KL | 2.925e-2 | 5e-2 | pass |
| top-1 | 0.98385 | 0.99 | **fail** |

1548 rows, `measurement_valid: true`, canonical coverage complete, determinism
clean (three repeats, identical trajectory hashes on all 12 prompts).

**Full scope is not promotable.** The route stays off by default.

Engagement was checked first, as intended: candidate and teacher logits hashes
**differ**, so this is a real measurement rather than a repeat of the invalid run.

## The failure shape is the useful part

The **tail passes while the mean and p95 fail**. That is a different problem from
a route that fails only on `max_kl`, and it points somewhere specific: the drift
is **broad-based across the distribution, not driven by rare outliers or one bad
transition**. A tail-only failure would invite a per-layer guard on the offending
layers. This one would not be fixed by that, because there is no small set of
layers carrying it - so the lever is scope, which is what the ladder tests.

## A discrepancy worth recording, not resolving yet

Kernel-level relative L2 is **4.6e-07 to 9.1e-07**, 50-100x tighter than the f16
WMMA route's 4.709e-05. Per-layer whole-model drift does not follow:

- staged f32 at 0-47: 1.269e-3 over 48 layers ~ 2.6e-5 per layer
- f16 WMMA at 16-47: 3.80e-4 over 32 layers ~ 1.2e-5 per layer

So the staged tile's per-layer contribution is roughly **2.2x worse** than WMMA's
despite a 100x tighter per-kernel relative error. Either the two errors are not
the same kind of quantity (a per-kernel L2 against a whole-model KL over a
trajectory), or the summation-order change propagates differently than an operand
precision change. I am not claiming a cause. It does mean the kernel-level
relative error is **not** a usable predictor of scope headroom, which is worth
knowing before the next candidate is scoped by extrapolating from it.

The two scopes are also not directly comparable: WMMA's 0-47 number was `code`
only (3 cases, 387 rows) against this run's 12 cases and 1548 rows.
