# Retain wave-cooperative DMS attention at dense parity

## Summary

Retained a production-T1 wave-cooperative compact-attention producer for exact
Qwen3.8 24Q/4KV/D256 group-6 geometry on gfx1151. Each wave scores one compact
token by distributing its 256-dimensional K dot product over 32 lanes while
sharing K loads across all six query heads. This closes the explicit c1 128K
DMS decode-performance blocker: median DMS decode is 136.27 ms/token versus
matched dense 137.43 ms/token while preserving 1.882225x live-KV compression
and 3.750 GiB payload savings.

## Changes

- Added a shape-bounded group-6 wave producer. A build-plan capability enables
  it only for native gfx1151; gfx1100 and unsupported shapes retain the prior
  grouped producer, and the registered CPU reference remains strict fallback.
- Replaced the group-6 parent-exact digest contract with a deterministic
  production digest plus CPU-reference KL/top-1 gate. The arithmetic change is
  wave reduction order only; sidecar, ranking policy, token sequence, ownership,
  and compact ABI are unchanged.
- Updated DMS/kernel documentation and benchmark rollups. Full evidence is in
  `benchmarks/results/2026-08-24-gfx1151-qwen38-dms-wave-cooperative-dense-parity.json`.

## Validation

- All 14 affected HIP nodes pass: seven compact-attention tests, the direct
  device pipeline, and six c1-c32 pack/append/attention/reclaim cases. Production
  digest `baf26fe9...72964d` repeats exactly and satisfies the CPU-reference
  KL <= 0.05 / top-1 >= 90% outer gate.
- Scoped gfx1151 128K leaf median: 13.920 -> 1.422 ms/layer (9.792x);
  cached-only rocprof names
  `dms_compact_attn_splitk_group6_wave_producer_kernel<6>` at 1.472 ms plus the
  expected reducer at 0.095 ms, both scratch0. Trace SHA `0ccca854...5a99`.
- The complete 14-node HIP bundle was rerun after backend scoping, and a native
  gfx1100 cross-build succeeds without the wave-group6 compile define.
- Frozen four-category 32K d8: 32/32 rows, 100% top-1, max/mean KL
  0.003784/0.000333. Pooled median DMS decode 192.74 -> 104.62 ms/token
  (1.842x); matched dense 99.96 ms/token.
- Fresh sealed four-category 128K validation d8: 32/32 rows, 100% top-1,
  max/mean KL 0.002899/0.000321. Pooled median DMS decode 357.96 -> 136.27
  ms/token (2.627x, 7.34 tok/s); matched dense 137.43 ms/token. Capacity remains

  construction; the evidence run changed only the CLI filter to the manifest's
