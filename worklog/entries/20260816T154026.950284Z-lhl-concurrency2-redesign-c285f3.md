# Define Generation-2 concurrency and shared KV architecture

## Summary

Defined the Generation-2 serving architecture that replaces static HTTP batch
ownership and fixed physical-width admission with one model-owning engine
service, independent child-request completion, and one policy-shaped global KV
capacity pool. The redesign keeps the exact resident runner, `KVLiveSpans`, KV
transactions, c1/c2/c4/c8 execution buckets, and registry boundaries while
making smooth logical c1-c32 operation the first production qualification.
