# Device-1 all-NaN localized: full-width decode GEMV silently no-ops on device 1

## Summary

The device-1 (RX 7900 XTX) all-NaN logits that block the TP2 teacher controls
are localized to a **silent no-op in the full-width decode GEMV**. The TP1
full-width MLP calls `launch_gguf_linear(..., use_gemv_decode=True)` for
`ffn_gate`/`ffn_up` at `(rows=1, in_features=5120, out_features=17408)`. On
device 0 those calls write all 17,408 outputs; on device 1 they write **none**,
leaving whatever stale bytes were in the output buffer — which on device 1
happen to be non-finite, producing all-NaN logits.

Evidence chain:

1. Three identical 16-position TP1-d1 controls: 0/3 PASS, every call
   `finite=0/3973120 nan=3973120`. Device 0 (same harness, same token prefix):
   `finite=3973120/3973120 min=-15.27 max=31.73`. TP2 (both devices, eager,
   4 positions): `finite=993280/993280` — so device 1's sharded-MLP path is
   fine and the failure is specific to the **full-width TP1 MLP**.
2. Layer probe (patched `_local_mlp`): layer 0 `post_norm` finite 5120/5120,
   but `ffn_gate`/`ffn_up` carry non-finite values whose count varies between
   runs (27/30/37), i.e. stale buffer contents, not a deterministic weight.
3. Raw weight bytes for layer-0 `ffn_gate`/`ffn_up`/`ffn_down`/
   `post_attention_norm` are **byte-identical** on device 0 and device 1
   (matching sha256), so weight upload is not the cause.
4. Sentinel probe (committed): fill `mlp_gate`/`mlp_up` with bf16 `0x7BFF`,
   run one teacher-forced token, count remaining sentinels.
   - device 0: `WRITTEN (gate 0/17408, up 0/17408)`, logits finite 248320/248320.
   - device 1: `NO-OP (gate 17408/17408, up 17408/17408 unwritten)`, logits
     finite 0/248320.
   Deterministic across repeated runs.

Because the launch is a silent no-op rather than an error, device 1 can also
return **finite but wrong** results whenever its stale memory is finite; the
all-NaN case is the visible symptom, not the only failure mode. Any TP1
device-1 teacher control or comparison that ran while this held is suspect.
