# Open Qwen3.8 compact INT8 KV continuous campaign

## Summary

Approved the reconciled Qwen3.8 INT8 KV implementation findings as the next
compact continuous-batching campaign. The campaign preserves the completed
resident scheduler and short mirrored lifecycle, then closes artifact-scoped
capability admission, no-mirror c>N prefill/decode, complete memory accounting,
and production lifecycle/economics in milestones `IKV-C0` through `IKV-C7`.

## Changes

- Added `docs/QWEN38-INT8-KV-CONTINUOUS.md` as the campaign authority with fixed
  local/origin model identities, retained evidence, exact missing code seams,
  non-goals, milestone dependencies, correctness/memory/lifecycle/trace gates,
  promotion levels, and stop rules.
- Made immutable artifact/backend/weight-quant/KV-layout/scale-policy identity
  the first gate. The local gfx1100 file `7b2aec...` passes its measured ladder;
  the distinct origin gfx1151 file `7e78da...` remains quality-rejected. Neither
  result transfers by filename or 24Q/4KV/D256 geometry.
- Split compact c>N delivery into an honest serial c1-per-row correctness
  milestone and a later row-batched INT8 split-K producer/reducer. The serial
  milestone explicitly includes shifted block-table-aware no-mirror prefill;
  enabling `_step_native_serial()` alone is insufficient.
- Kept request-budget-sized upfront allocation in one backing chunk. Per-token
  cross-chunk extension is a separate ABI campaign, not an IKV prerequisite.
- Required admission to budget INT8 payload/scales, any mirror, packed/split-K
  workspace, prefill hidden/oracle ownership, graph pins, and whole-device
  reserve before allocation.
- Integrated the campaign into `PLAN.md`, `KVCACHE.md`, `CONCURRENCY.md`,
  `TESTING.md`, `REFACTOR.md`, and the documentation index. The active queue now
  names IKV-C0-C7 before deferred F5/H work.
