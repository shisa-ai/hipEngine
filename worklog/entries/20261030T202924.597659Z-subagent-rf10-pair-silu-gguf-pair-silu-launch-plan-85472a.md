# Separate GGUF pair-SiLU launch planning from execution

## Summary

`launch_gguf_linear_pair_silu` now resolves a private, launch-local `_GGUFPairSiluPlan` and executes it immediately. The plan covers the full existing branch order: prefill production Q4 pair, IQ4_XS dual, Q5 pair, production Q4 chunk groups, Qmicro Q8_1x2 rowbatch, pack8 WMMA, T16 WMMA (including expanded metadata), T16 rowtile, pack8 rowtile, and the decode-side Q4T16, IQ4_XS, mixed IQ4/Q4/Q5, Q5T16, T16 sidecar/interleaved, and pack8 owners.

The public signature, boolean return, branch priority, sidecar priority, registered custom variants, padded/grouped physical rows, workspace ownership, exact kwargs/library precedence, and direct-control fallback contracts are unchanged. No reusable cache, profile token, public API, framework, flag, default, or math/backend conditional was added.
