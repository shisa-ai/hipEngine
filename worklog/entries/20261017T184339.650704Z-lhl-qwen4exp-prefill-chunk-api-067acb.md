# Add resumable target and draft prompt primitives

## Summary

Add the prompt-state primitives needed by PS1 in
`docs/QWEN4EXP-PRODUCTION-SERVING.md`: target prefill can append to a live
request without resetting it, and draft prompt priming can resume with the
previous target chunk's final hidden row. Existing ordinary prefill still
resets. No serving route or numerical dispatch default changes in this unit.

## Changes

- `Qwen4ExpGGUFResidentModelRunner.prefill_append` reuses the existing prefill
  implementation and dispatch contexts with an explicit no-reset mode. It
  checks remaining sequence capacity before mutation and uses the prepared
  workspace rather than carrying temporary bindings across requests.
- `Qwen4ExpGGUFMTPDraftRunner.prime_prompt_chunk` preserves shifted hidden-row
  ownership across chunk boundaries and supports a cancellation check before
  each draft token. Ordinary `prime_prompt` uses the same primitive after reset.
- Added CPU host-fixture coverage for chunk equivalence, hidden-row identity,
  capacity-before-mutation, fresh reset, invalid cross-chunk seeds and bounded
  cancellation/reuse. Device kernels and arithmetic bodies are unchanged.
