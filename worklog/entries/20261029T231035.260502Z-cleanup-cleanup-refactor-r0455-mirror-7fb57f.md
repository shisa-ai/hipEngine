# Scope GR producer mirror diagnostics to execution

## Summary

R0455 iteration 418 replaces the process-wide mirror opt-out with a
context-local `gr_f16_mirror` diagnostic scope. Production mirror publication
stays enabled. Dedicated scratch and direct-launch ownership remain open.

## Changes

- GR mixed-activation and GDN core mirror producers consume the same scoped
  decision. Nested scopes restore their enclosing decision on exceptions;
  independent contexts default to publication. No environment writes remain.
- Migrated engine A/B, native pair gate and cast-owner harnesses. Reports name
  the execution-local boolean control, not an environment value.
- The native pair gate had an obsolete 1024-row staging expectation. It now
  shares the engine harness's current-policy-aware counter. Regression coverage
  includes non-admitted and admitted chunk sizes without weakening parity.
