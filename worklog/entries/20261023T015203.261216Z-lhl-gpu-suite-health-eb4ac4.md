# Full GPU-visible suite green on the W7900 + RX 7900 XTX host

## Summary

Release runs hide ROCm, so no release had run the GPU tiers. On this host
(`epyc`: Radeon Pro W7900 + RX 7900 XTX, both gfx1100) a GPU-visible
`--suite all` first segfaulted at about 20%. After the fixes below, one
uninterrupted run passes: 26,811 tests, 0 failures, 0 errors, 1,556 skips,
1 h 48 min (`.venv/bin/python -m pytest --suite all -q`, both GPUs visible).

## Changes

Product fixes:
- `120d127c4` Qwen4Exp GDN DPP library built for the running GPU (was
  gfx1151-only; the gfx1100 batch decode launch segfaulted).
- `06fc28a41` `LLM.close()` closes the generator and its MTP head (a closed
  Gemma 4 LLM held about 30 GiB).
- `022f473da` Gemma 4 attention scratch closes without syncing a stream a
  decode-graph session already destroyed (segfault on close).
- `2cf06f8ef` Gemma 4 layers share one expert workspace and temporaries
  pool per runner: a default Gemma 4 LLM on a W7900 ran out of memory on its
  first decode since v0.8.0.
- `9fbb2a29c` packed INT8 MTP verify rows may share their request's KV
  blocks: n=2 explicit MTP on INT8 KV had always fallen back to AR.
- `0bc5c7530` Gemma 4 requests that opt out of MTP report the plain route.

Test and harness fixes:
- `cb5d44d44` VibeVoice GPU tests skip when the checkpoint is not cached.
- `6f322ce3a` conftest registry baseline imports every gfx1100 kernel
  module; a speculation server test no longer leaks two engine threads per
  test; the EVIE-8B fp16 tier moved to its own module; the Gemma 4
  class-global replay runs under the strict profile.
- `a6bde50c3`, `eabbbff8e` Gemma 4 live tests follow head auto-discovery,
  resident owners and the reporting fix.
- `884878923`, `16de4e6b3` EVIE cross-shape bound and per-architecture
  fp16 envelope (decision entry
  [20261022T204746.616943Z-lhl-evie-gfx1100-fp16-0a61af.md](20261022T204746.616943Z-lhl-evie-gfx1100-fp16-0a61af.md)).
- `ec43b07b1` Gemma 4 route reporter test resets the process global.
- `1a768a258` two Qwen3.5 GGUF live tests close their session/runner; one
  left about 21 GiB resident and a later `hipMalloc` segfaulted.

## Validation

- Intermediate runs with a per-test thread/VRAM probe located each leak
  (aborts at 34% and 38%, then a 9-failure completed run). The final run is
  without the probe: the probe's per-device `hipSetDevice` itself fails
  `test_gpu_sampler_full_vocab.py::test_workspace_growth_shrink_commit_and_reuse`.
- Default unit tier after the shared-code changes: 16,223 passed.
- Measurements for the product fixes are in their commit messages.
