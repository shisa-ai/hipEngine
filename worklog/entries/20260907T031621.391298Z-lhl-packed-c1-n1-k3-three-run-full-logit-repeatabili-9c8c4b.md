# Packed C1 N1 K3 three-run full-logit repeatability

## Summary

Three independent N1/K3 actual packed-C1 captures match exactly: 70 cycles,
267 active full-logit rows and ten prompts per run. Captured contexts, route
metadata, array shapes and float32 bytes match. All arrays are finite and
match their stored SHA256 digests. This is repeatability of captured surfaces,
not full profile qualification. Public C1 remains disabled; automatic stays K0.

## Changes

- Add CPU-only `compare` mode to `scripts/qwen38_packed_c1_logits.py`.
  Require three distinct resolved directories, complete nonempty captures,
  equal cycle counts, valid finite float32 row geometry, verified array digests,
  actual byte equality and exact metadata. Directory uniqueness prevents
  accidental self-comparison; recorded separate commands establish process
  independence, not the directory names alone.
- Add eight tests covering success, duplicate directory, partial capture,
  metadata mismatch, stale digest, differing bytes, nonfinite and wrong shape.
- Record hardware/model provenance and all three capture commands plus the
  comparison command in
  `benchmarks/results/2026-09-07-w7900-packed-c1-repeatability-diagnostic.json`.
  No runtime, kernel, dependency or public policy change; no performance claim.
