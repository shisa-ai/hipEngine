# vibevoice-tts milestone 2: torch-free decoder + HIP GPU runtime

## Summary

Milestone 2 boundary done: the acoustic TokenizerDecoder runs torch-free on
both CPU (numpy reference) and HIP GPU, gated on the frozen milestone-1
fixture chain. GPU replay of both fixture requests matches the CPU reference
within the eager-bf16 envelope (pooled waveform RMS rel 1.20% single / 1.02%
two — the same magnitude as the CPU↔oracle spread), and `decode_bulk` is
bit-identical to per-frame streaming.

## Changes

- `hipengine/kernels/cpu_reference/vibevoice_tts.py`: TokenizerDecoder port
  (depths 8-3-3-3-3-3-3, hop 3200) with the fork's streaming contract:
  fixed-length left-zero-padded caches (kernel-1 rows for convs, K-1 for
  convtr, K=2·stride) are value-identical to the fork's growing caches;
  always keep the last T·stride convtr rows; eager-faithful double-rounded
  RMSNorm. (Committed in 5446aa395.)
- `hipengine/loading/vibevoice_tts.py`: torch-free safetensors decoder bundle
  + the two checkpoint scaling factors (weight-not-config, NaN refusal).
- `hipengine/kernels/hip_gfx1100/vibevoice/decoder.{hip,py}`: new
  `vv_convtr_gemm_bf16` causal streaming transposed-conv kernel — two taps
  per output row (W[k0]·x[j0] + W[k0+r]·prefix/x[j0-1]), tap-major
  [K][C_in][C_out] upload, rows_out = rows·stride. Registered in the shared
  `vibevoice` family (both gfx peers resolve it through the four-axis keys).
- `hipengine/runtime/vibevoice_tts_decoder.py`: GPU streaming runtime over
  the registered primitives (vv_conv_gemm / vv_convtr_gemm / vv_rmsnorm /
  vv_depthwise_conv fused / dense_gemv / vv_add_bias / vv_gelu /
  vv_scale_residual), bf16 storage + fp32 accumulation, grow-on-demand
  scratch keyed per logical buffer, rolling prefix caches with post-launch
  update (roll AFTER the op — rolling before double-counts the new rows).
- `tests/test_live_vibevoice_tts_decoder_gpu.py`: HIP-guarded replay parity,
  bulk==streaming bit identity, reset sensitivity, registry resolution.
- `scripts/vibevoice_tts_decoder_rocprof_smoke.py`: cached-only trace child.

## Validation

- `python3 -m pytest tests/test_unit_vibevoice_tts_decoder.py` — 5 passed
  (148.7 s): full fixture replay of both requests (25+55 frames, resets at
  generated speech-end tokens) within the measured eager-bf16 envelope;
  stream/helper equivalence; reset sensitivity.
- `python3 -m pytest tests/test_live_vibevoice_tts_decoder_gpu.py` — 6 passed
  (86.7 s) on gfx1151: per-frame GPU-vs-CPU parity within the same envelope
  (worst frame-peak ratio 4.8% single / 2.0% two, pooled RMS rel 1.20%/1.02%),
  bulk == per-frame bit-exact per reset-delimited segment, reset changes the
  output, registry resolution.
- `python3 -m pytest tests/test_live_vibevoice_asr_cpu_reference.py` — 5
  passed (41 s): shared ASR reference undisturbed.
- `rocprofv3 --kernel-trace -f csv` on

  (prebuilt .so + require_cached, no hipcc in the profiled process): 561

  vv_convtr_gemm_kernel 6× mean 908.4 µs, vv_conv_gemm_kernel 2× mean
  166.6 µs, vv_rmsnorm 52× 11.3 µs, vv_depthwise_conv 26× 14.7 µs,

- Debugging notes worth keeping: eager `_round(x, "bfloat16")` returns
  fp32 arrays with bf16-rounded VALUES (convert with f32_to_bf16_bits at the

  (2,1,0), convtr [in,out,K] → (2,0,1); FFN residual adds to the POST-MIXER
  activation.
