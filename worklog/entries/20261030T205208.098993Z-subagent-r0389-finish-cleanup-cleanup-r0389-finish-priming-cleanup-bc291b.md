# R0389 finish prompt priming cleanup failure

## Summary

Repair the R0389 prompt-priming cleanup leak when `finish_prompt_priming`,
`sink.close`, or the transform-buffer release raises. The decoder must attempt
every owned release, preserve an operational prefill/cancellation error as the
primary exception, and propagate a cleanup failure when prefill itself succeeded.

## Changes

- RED before repair: added four post-output-norm decoder lifecycle tests covering
  `finish_prompt_priming` failure on success and during an operational target
  failure, plus `sink.close` failure on success and during an operational target
  failure.
- RED command: `.venv/bin/python -m pytest tests/test_unit_qwen35_gguf_mtp_session.py -o addopts= -q -k "finish_failure or sink_close_failure"`.
- RED result: **4 failed, 165 deselected**. The unmodified `finally` stopped at
  the first raising cleanup call, so the transform buffer was not released and a
  cleanup error replaced the operational target error.
- Repaired only `Qwen35GGUFMTPDecodeSession._prefill_target_and_draft`: each
  owned release (`finish_prompt_priming`, `sink.close`, transform `free`) now has
  its own narrow `try/except BaseException`. Every release is attempted.
- An operational prefill or cancellation error remains primary; cleanup failures
  are attached as notes. With no operational error, the first cleanup failure is
  raised and later cleanup failures become notes on it. No arithmetic, route,
  flag, or general cleanup framework changed.
