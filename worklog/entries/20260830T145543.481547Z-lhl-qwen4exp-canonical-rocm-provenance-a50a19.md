# Record ROCm 10 platform in canonical benchmark artifacts

## Summary

Corrected canonical benchmark host provenance when the driver runs from
hipEngine's isolated virtual environment. The ROCm platform package is installed
in the parent TheRock environment, so Python package metadata alone returned no
version even though `hipcc` and the runtime were ROCm 10.

## Changes

- Added a `rocm-sdk version` fallback after Python package-metadata lookup.
- Return `None` rather than failing on hosts without either provenance source.
- Added a focused test that forces the package-metadata miss and verifies the
  exact `10.0.0` command result.

## Validation

- `uv run pytest -q tests/test_qwen4exp_canonical_ar_bench.py`: 8 passed.
- The live host's `rocm-sdk version` reports `10.0.0`; existing HIP component
  provenance remains captured independently by full `hipcc --version` output.
