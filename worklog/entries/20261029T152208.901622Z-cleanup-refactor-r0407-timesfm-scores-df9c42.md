# Remove the unused TimesFM attention score buffer

## Summary

Remove the independent TimesFM score-buffer debt embedded in original R0407.
Neither current FP16 flash nor FP32 scalar attention reads it. Public validation
also exposes and repairs a short-prefill/wider-AR scratch-capacity defect without
changing kernel arithmetic.

## Changes

- Delete only `_Buffers.scores`, its allocation and free-list entry. Preserve
  every current attention operand and both precision routes.
- Allocation ownership tests declare the independent live-buffer byte sum,
  cache ownership, shape reuse and one free per owner in both precisions.
- Short prefill can have fewer patches than a later four-patch autoregressive
  segment. Allocate scratch for their maximum, keeping logical prefill rows
  unchanged. Bound the prefill point-output D2H copy by the actual host output
  bytes, not the now-larger scratch capacity.
- GPU regression covers one/three/five-patch inputs, FP16/FP32, repeated decode
  and a wider fully front-masked prefix control for the same visible series.
  CPU sizing checks also cover horizons with no autoregressive segment.
- Remove the active TimesFM ledger note, close its scoped decision and final
  R0407 subitem. The separate AOTriton rollback-interface choice stays deferred.
