# Packed workspace stability RED tests for serving-load churn

## Summary

RED tests pinning four defects found in the load-fault review of
`_ensure_packed_verify_workspace` and the prefill scratch allocator:

1. prefill (1x128) / decode (NxN) geometry interleave forces
   free+realloc of the entire packed state and scratch each cycle;
2. resize frees buffers while packed decode graphs still bind them
   (release_idle/clone paths check graph liveness, the resize path does
   not) - the deterministic first-serving-poll page-fault suspect;
3. `_GGUFFullAttentionPrefillScratch.allocate` is not atomic on failure
   (dict-comprehension allocations leak every earlier buffer when one
   malloc fails) - the burst-n=8 error-2 wedge suspect;
4. resident slot views never delegate to `_resident_batch_owner` (field
   is dead), so each view allocates its own workspace set.
