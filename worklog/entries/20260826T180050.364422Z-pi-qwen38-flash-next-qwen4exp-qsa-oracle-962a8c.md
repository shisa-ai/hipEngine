# Add Qwen4Exp QSA CPU oracle

## Summary

Added a torch-free QSA oracle covering FP32 complete-block pooling, post-pool
RMSNorm and text-path interleaved partial RoPE, per-head rectified scoring,
deterministic whole-block selection, incomplete-tail inclusion, and sparse GQA
attention over original uncompressed K/V.

## Changes

- Logical token positions are independent of physical key/value order; complete
  blocks retain physical member owners and non-tail holes fail closed.
- Selection masks future blocks, uses stable lower-block tie breaks, expands
  selected blocks to original positions, and appends only the current tail.
- Sparse attention supports group-12 geometry generically and rejects missing,
  duplicated, or future logical positions.

## Validation

- RED: QSA tests failed collection because the QSA CPU API did not exist.
- GREEN: QSA+PLE+GR test bundle -> `21 passed`.
- QSA/PLE/GR plus generic CPU-reference compatibility bundle -> `34 passed`.
- Hand-checkable gates cover 4-token pooling + 1-token tail, pair-interleaved
  RoPE, ReLU-before-head-sum scoring, reduced budget/tail boundaries, stable
  ties, non-contiguous physical slots, dense equality below budget, and direct
  use of selected original values.
