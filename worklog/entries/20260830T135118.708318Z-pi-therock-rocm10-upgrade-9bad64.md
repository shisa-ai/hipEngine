# Upgrade gfx1151 TheRock environment to ROCm 10

## Summary

Upgraded the default HP ZBook `gfx1151` TheRock Python environment at
`/home/lhl/miniforge3` from nightly ROCm `7.15.0a20260727` to the stable
TheRock ROCm `10.0.0` release. The SDK, device package, PyTorch stack, profiler,
and hipEngine fresh-JIT smoke are operational on the Radeon 8060S. This is an
environment refresh, not a performance claim.

## Changes

- Installed `rocm`, `rocm-sdk-{core,devel,libraries}`, and
  `rocm-sdk-device-gfx1151` `10.0.0` from
  `https://stable.repo.amd.com/rocm/whl-next/`.
- Moved the matching framework stack to PyTorch `2.13.0+rocm10.0.0`,
  torchvision `0.28.0+rocm10.0.0`, torchaudio
  `2.11.0.2+rocm10.0.0`, and Triton
  `3.8.0+git4cff872c.rocm10.0.0`; replaced the obsolete gfx11 family pack with
  the stable `amd-torch-device-gfx115x` plus `gfx1151` packages.
- Reinitialized the expanded SDK devel tree. Existing shell configuration still
  points at the same core/devel/libraries paths and required no edit.
- Preserved a validated rollback clone at
  `/home/lhl/.local/share/therock-backups/miniforge-rocm715-20260727` and the
  before/after package manifests and install logs under
  `/home/lhl/.local/state/therock-upgrades/2026-08-30-rocm715-to-rocm10`.

## Validation

- `python -m pip check`: no broken requirements.
- `rocm-sdk test`: **27 passed**; `rocm-sdk version` and the ROCm core version
  header both report `10.0.0`; `rocm-sdk targets` includes `gfx1151`.
- `rocminfo`, `amd-smi list`, and `hipGetDeviceCount` identify one Radeon 8060S
  / `gfx1151` device. A fresh login shell resolves `libamdhip64.so` from the
  default TheRock devel tree.
- Fresh `hipcc --offload-arch=gfx1151` compile and launch returned the expected
  device result `2 3 4 5`. The ROCm 10 platform contains HIP component
  `7.15.26333-0000000` and clang commit `8f497e0992f`; this component version is
  distinct from the ROCm platform package version.
- PyTorch reports `torch.cuda.is_available() == True`, identifies Radeon 8060S,
  and passes an exact GPU matrix-multiply check.
- `HIPENGINE_BUILD_CACHE_ROOT=/tmp/hipengine-rocm10-smoke-cache
  HIPENGINE_HIP_ARCH=gfx1151 PYTHONPATH=. /home/lhl/miniforge3/bin/python -m
  pytest -q tests/test_hip_runtime.py tests/test_hip_graph_capture_replay.py`:
  **6 passed**, including a newly compiled ROCm 10 cast library and four exact
  graph relaunches.
- `rocprofv3 --version` reports profiler `1.3.5` and ROCm `10.0.0`.
