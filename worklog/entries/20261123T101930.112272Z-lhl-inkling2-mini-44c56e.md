# Reuse wide Inkling NVFP4 inputs across four outputs

## Summary

A four-output NVFP4 tile preserved score bits and shortened both measured expert projections in public W7900 prefill. On Strix Halo the synthetic wide shapes improved modestly. No production code changed in these probes.

## Changes

- Scratch only. Select the existing tile template with four outputs on wide dimensions divisible by the full four-output workgroup. Keep accumulation and wave reduction order per output.
