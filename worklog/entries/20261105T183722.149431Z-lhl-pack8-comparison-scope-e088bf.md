# Scope pack8 cumulative and threshold comparison controls

## Summary

R0375/R0376 comparison callers now use explicit pack8 bulk/pair fields in the
restoring cumulative diagnostic scope. Keep the two legacy readers temporarily
until public caller validation; backend and arithmetic behavior are unchanged.

## Changes

- Cumulative roles pin all five comparison fields without writing pack8 envs.
- Threshold children transport pack8 choices as explicit arguments and strip
  inherited rollback variables.
- Single and paired bulk selectors share the scoped bulk value, including its
  cache identity; fused SiLU retains its separate pair value.
- Legacy readers remain solely as compatibility fallback outside a scope.

## Validation

- Focused harness, threshold, dispatch and scope tests pass.
- Test inherited rollback isolation, nested and exception restoration, and
  scoped bulk cache identity. No GPU arithmetic or performance claim.
- Missing 0.8B checkpoints still defer the cumulative public numerical packet.
