# Compare dense 27B hipEngine with llama.cpp HIP and Vulkan

## Summary

Compared current clean hipEngine `bfb7cfadd` against clean llama.cpp HIP and
Vulkan build 10438 / `9d57ce456` on Radeon 8060S (`gfx1151`). The matched
natural25 suite uses identical prompt token arrays, greedy decoding, BF16 KV,
25 visible outputs / 24 timed transitions, all four categories, and all
heldouts. hipEngine and llama.cpp HIP preserve their own true-AR outputs under
MTP; llama.cpp Vulkan does not, so its MTP throughput is diagnostic only.

## Validation

- Matched p512 median prefill tok/s (three runs): Qwen3.6 hipEngine 147.194,
  llama HIP 353.670, llama Vulkan 243.577; Qwen3.8 147.984, 353.620, 242.538.
- Qwen3.6 natural25: hipEngine AR/B3 7.1268/22.1321 tok/s (3.1055x,
  75.68% acceptance); llama HIP AR/B3/B4 12.0963/21.9491/21.2092
  (1.8145x/1.7534x, exact); llama Vulkan 12.7754/28.3720/30.0102, but B3 and
  B4 each match only 6/10 Vulkan-AR prompts.
- Qwen3.8 natural25: hipEngine AR/B3 7.1358/19.4404 tok/s (2.7243x,
  63.10% acceptance); llama HIP AR/B3/B4 12.0437/19.6552/19.1429
  (1.6320x/1.5894x, exact); llama Vulkan 12.7723/26.0789/26.1064, but B3
  matches only 9/10 and B4 only 6/10 Vulkan-AR prompts.
- Exact B4 result on llama HIP: B4 regresses B3 by 3.37% on Qwen3.6 and 2.61%
  on Qwen3.8. The apparent Vulkan B4 deltas (+5.77% / +0.11%) are invalid as
  speed wins because both B4 rows fail greedy equivalence.
- Cross-engine AR: Qwen3.6 hipEngine and llama HIP match 10/10 prompts; Qwen3.8
  matches 9/10. Vulkan AR differs from hipEngine on 4/10 Qwen3.6 and 2/10
  Qwen3.8 prompts.
- Base-memory scopes at context capacity 768: hipEngine AR owns 31.659 GiB and
  phase-sampled HIP use peaks at 33.126 GiB; hipEngine B3 tracked peak is
  33.043 GiB. llama HIP AR/B3 uses about 15.790/16.339 GiB GTT delta plus
  4.48/4.24 GiB peak RSS; Vulkan AR/B3 uses about 15.868/16.722 GiB GTT
  delta plus 3.34/3.06 GiB peak RSS. No measured run used swap.
- All hipEngine B3 rows pass exact greedy and GPU/CPU acceptance gates and free
  all tracked allocations. All llama HIP B3/B4 rows match their backend AR.
