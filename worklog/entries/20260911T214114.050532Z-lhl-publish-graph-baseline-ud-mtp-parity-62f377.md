# Publish graph-baseline UD MTP parity

## Summary

Completed the clean four-arm c1/natural25/B3 paired run on physical GPU1
(RX 7900 XTX) using recorded production graph replay as the true no-MTP AR
denominator. The repaired denominator shows that UD is reasonably close to
plain in AR but still far behind in MTP: K_M reaches 0.860x plain AR and 0.560x
plain MTP; K_S reaches 0.791x plain AR and 0.516x plain MTP.

All four arms pass the binding evidence, timing, deterministic-repeat, and
GPU/CPU acceptance gates. K_M and both plain controls are generated-ID exact.
UD K_S repeats the two known `general_ja_plan` near-tie divergences, so its
suite-level speed-claim eligibility remains false pending the calibrated
teacher-forced production gate. Neither UD preset is admitted for MTP.
