# Add gfx1100 Inkling 2 packed expert projection

## Summary

Add a gfx1100 primitive for matrix-vector projection over original Inkling 2 Mini NVFP4 and MXFP8 expert storage. This projects one expert with FP32 activations and does not yet register a full GPU model route.

## Changes

- Decode the packed weights and block scales on device; accumulate the dot product in FP32 without expanding a complete expert matrix. Register the raw-pointer launcher under `inkling2_expert_projection`.

## Validation

- The GPU fixture failed before implementation. Four gfx1100 cases then passed against the CPU unpacker and FP64 dot products at the original projection widths, with an FP32 accumulation error bound and matching top-1 results.
- `rocprofv3 --kernel-trace` with compiler version provided and cached builds required confirmed both packed kernel variants ran. An initial run without the cached-build environment timed out.

## Next

- Load the original packed weights into owned GPU buffers and connect the projection to the model runner. The native text, image, and DSpark paths are still open.
