# Trim unreachable bias columns from packed Inkling attention

## Summary

Packed attention blocks no longer stage relative-bias columns that no query in the block can read. The host computes the same bias values, and the existing device attention leaf reads the reachable prefix.

## Changes

- Bound the packed bias stride by the configured extent and the maximum causal live count in the block. Keep the single-row and provisional rollback paths unchanged.
