# Add production FP16 SPECDEC2 bridge protocol

## Summary

Extend the common SPECDEC2 performance bridge with an explicit production
profile so P8 economics compare production FP16 SPECDEC2 against production
FP16 true AR under the same timing owner. Strict remains the default. The old
request-local native MTP control is FP32-only and is therefore an honest skipped
diagnostic in production rather than an invalid denominator or hidden failure.

## Changes

- Added `--execution-profile strict|production` and profile/state provenance.
- Production pins FP16 recurrent state through the registered profile and passes
  the requested profile to `LLM` construction.
- Legacy native C1 is skipped only for production FP16 with an exact reason;
  artifact validation accepts that cell while still requiring true AR and
  SPECDEC2 IDs/timings to be exact.
- Added bridge contract coverage for the production C1 skip and preserved the
  strict/default schema.

## Validation

- `uv run pytest -q tests/test_specdec2_perf_bridge.py`: **20 passed**.
- Python compile and diff checks pass.
- Speed denominators remain true no-MTP AR; no verifier-derived row is admitted.
