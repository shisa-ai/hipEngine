# RF-12 split server API integration tests by behavior

## Summary

Split the 25,807-line `tests/test_integration_server_api.py` into 16
behavior-named integration modules, with shared test doubles and builders in
`tests/support/`. No test function, parametrization, mark, or assertion changed.
Pre/post collection is identical after dropping filenames: 698 identities, zero
missing, zero extra, zero duplicates.

The legacy module path is retained as a 77-line, test-free compatibility shim
for external importers. All seven in-tree consumers now import their explicit
`tests.support` owners, and the shim documents a concrete removal condition
(`rg -n "tests[.]test_integration_server_api" tests scripts` matches only the
shim and its contract check). The shim re-exports helpers only; it collects
zero tests, so no case is duplicated through re-exports.
