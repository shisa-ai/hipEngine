# Add C2-7 compact DMS backend and CPU oracle

## Summary

Added the torch-free C2-7 compact DMS backend composition and correctness oracle, derived from FastDMS `c602b0ec3266da7f74d6a658b3dafcddb443fddd`. It reuses the common resource ledger, scheduler, typed lease, `KVStorageView`, and `KVLiveSpans` contracts; no DMS scheduler fork exists.

## Changes

- Strict `DMSRetrofitConfig` loader requires packaged/explicit corrected-mask, trained-checkpoint metadata bound to the exact artifact. Training-log fallback is diagnostic opt-in only; ordinary checkpoints fail closed.
- `CompactExtentPool` provides atomic per-layer/head best-fit allocation, rollback, deterministic coalescing, fragmentation telemetry, and conservation checks.
- `DMSCompactBackend` declares stable payload/position/eviction/extent/workspace pools, returns atomic claims based on retained rows rather than logical context, publishes per-head-variable spans, and keeps prefix reuse disabled.
- Streaming count/rank/scatter semantics pack BF16-rounded survivors directly with no persistent dense shadow. Decode append expires marked rows outside the window and updates live counts/positions/eviction metadata transactionally.
- Added grouped-GQA compact-attention CPU oracle, borrowed-query decision extraction/zeroing, and no-evict/dynamic-live helpers.
- Added independently qualified per-token/head symmetric INT8 payload composition. Codec changes planes/scales only; topology, extents, scheduler, transactions, and lifecycle are unchanged.
- Registered CPU-reference DMS decision, streaming-pack, compact-attention, and INT8 codec kernels.
- Added `DMSAdmissionManager` and `DMSCompactResidentRunnerAdapter` for common token-budget c1-c32 execution.

## Validation

- DMS metadata, decision lane, liveness, codec, measured fixture KL/top-1, attention, fragmentation, no-shadow pack, transactional rollback, prefix fail-close, BF16/INT8 composition, c1-c32 scheduler, and registry tests — 16 DMS nodes plus six registry nodes pass.
- Synthetic INT8 compact-attention fixture passes KL <= 0.05 and top-1 >= 90%; qualification remains fixture/artifact scoped and is not a model product claim.
- Ruff, compileall, import, and diff checks — passed.
