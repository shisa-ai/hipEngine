# VibeVoice causal chunk state and final frame preservation

## Summary

Implement causal encoder chunk carry, recording isolation and final partial-frame preservation.

## Changes

- Every stem, downsample, depthwise mixer and head keeps its incoming BF16 tail across chunks. Tail state is local to one `encode` call and discarded between recordings. Existing im2col/GEMM kernels consume prefix-plus-current inputs; no device kernel body changed or was ported.
- Default encoder chunk size is 1,440,000 samples (60 seconds), positive hop-aligned custom sizes are supported, and only the final frame is padded. Both encoder streams are joined before acoustic sampling and connectors. Frontend now returns ceil(samples/3200) frames for nonaligned PCM.
- Scratch arenas reset between encoder passes and never grow while views are live. Returned latent arrays own host storage; sampling allocations are exception-safe.
- Legacy short torch trace fixtures captured bare unpadded encoder outputs; that test compares their complete-frame causal prefix. Separate new tests cover processor-style partial-frame behavior.
