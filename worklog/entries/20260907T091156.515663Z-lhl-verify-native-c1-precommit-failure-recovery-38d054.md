# Verify native C1 precommit failure recovery

## Summary

Native C1 precommit-failure recovery passes all 10 category-suite prompts at N8
and N2 on epyc W7900 GPU0. Each deliberate fault leaves 131 canonical target
buffers unchanged, restores provider host/logical/device cursors, and continues
with exact independent AR outputs and final request drain. The full-attention
provider has no Conv/GDN checkpoint buffers; provider live-KV rollback, postcommit
rebuild and same-request MTP resumption are not qualified by this diagnostic.

## Changes

- No implementation yet. In `qwen35_gguf_mtp2.py`, `rollback_cycle` restores the
  provider checkpoint then drops/disables speculative request state.
  `recover_cycle_failure` permits ordinary AR fallback only if target cursors
  remain canonical, or rebuilds target rows for `_PhysicalTargetCommitError`.
- `_execute_target_frontier_batch` includes acceptance and selected commit;
  injecting after its return is not a precommit fault. The packed
  `verify_target_blocks_batch` call returns inside it before acceptance and is
  the candidate injection boundary, after real target GPU work but before commit.

  checkpoint may legitimately contain no Conv/GDN pairs; the helper incorrectly
