# Add Qwen4Exp PLE injection oracle

## Summary

Added the remaining PLE arithmetic/state oracle: key/value projections,
grouped key/query norms, signed-square-root branch gating, grouped Conv input
norm, causal dilated depthwise Conv, SiLU, and widened residual injection.

## Changes

- Added immutable Conv history with position continuity/reset and chunk-invariant
  updates; kernel size 4 and dilation 3 retain exactly nine normalized rows.
- PLE value is broadcast across residual branches and gated independently by
  each branch's signed normalized key/query dot product.
- Exposed intermediate gate, gated value, Conv output, updated residual, and
  next state for failure localization.

## Validation

  API did not exist.

  tests/test_qwen4_exp_cpu_reference.py` -> `12 passed`.
- PLE/GR plus generic CPU-reference compatibility bundle -> `25 passed`.

  chunked execution is exactly equal to one-shot and discontinuity resets.
