# Register Qwen4Exp public text generation

## Summary

Registered the distinct Qwen4Exp public text generator for gfx1151 local
Q4_K_M and Unsloth UD-Q4_K_XL. It lazily scans/maps/plans/materializes split
GGUFs, owns tokenizer/resident/48-layer runner, serializes prompts through c1,
and exposes structured greedy outputs.

## Changes

- Added F5 strict adapter with text/exact-ID prompts, serial multi-prompt
  ownership, capacity admission, EOS/length finish details and clean teardown.
- Rejects non-greedy sampling rather than silently misrepresenting support.
- Added the built-in lazy import and exact registry keys; no engine architecture
  or quant branch was added.
