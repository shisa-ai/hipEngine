# Add exact resident-device Q8 MMQ weight packer

## Summary

Add a registered GPU packer for the retained exact Q8 MMQ candidate layout.
This removes CPU preprocessing/D2H requirements from future resident sidecar
integration; production remains raw MMQ.

## Changes

- GPU packer reads resident raw Q8 blocks and emits K-major76-word padded rows.
  No allocation inside kernel wrapper. Host geometry, pointer and overlap
  checks; registered four-axis weight_pack key and size API.
- Screen optionally uses GPU pack and compares its entire byte layout with
  CPU reference before exercising full quantize/matmul/repair chain.

## Validation

- RED missing registry packer; GREEN9 tests. Byte exact CPU reference at
  (N,K)=(1,256),(97,512),(320,10240),(10240,2560), including signed zeros,
  FP16 subnormals, large finite scales and repeats. Consumer bits stay exact.
- Cached trace expected `q8_0_mmq_pack_weights_kernel`,0.319113ms for actual
  layer0 QKV,24 VGPR, scratch0/LDS0. Diagnostic only, not throughput evidence.
- Commands/host/model/source provenance and profiled chain stored in
  `benchmarks/results/2026-09-06-framework-qwen4exp-mmq-gpu-pack.json`.
