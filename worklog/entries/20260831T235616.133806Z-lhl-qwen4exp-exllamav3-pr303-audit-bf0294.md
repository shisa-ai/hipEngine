## Validation

Clean gfx1151 measurement finds the pinned Qwen4Exp sidecar's full 675,430,400-
byte Q8_0 head at **3.153 ms**, **41.3%** of a **7.639-ms** draft step; full-logit
D2H itself is only 0.034 ms but forces host NumPy argmax/hidden chaining.
An 8K/16K/32K individual-row Q8_0 head would add only 21.25/42.5/85 MiB.
Unlike EXL3, GGUF Q8_0 rows are independent, so no 128-token Hadamard grouping
transfers.

The retained ten-prompt suite made 159 proposals in 51.711 s. Even deleting the
head entirely saves only 0.501 s: **0.97% wall and 0.955x→0.964x AR**. A real
selected head costs nonzero time and may lower acceptance.

Clean profiler source is `b9b11b346`; tracked memory returns 4,128,848,868 bytes
/ 114 allocations to zero. Focused test, Python compile, JSON parse, worklog,
README synchronization, full-doc re-read, and diff checks pass.
