# Reject source shaped sole T16 dense Q4 integer MMQ

## Summary

Implemented and screened the requested source-shaped dense Q4T16 x Q8_1
integer-WMMA rung without changing runtime ownership. The candidate was correct,
deterministic, byte-neutral for resident weights, and used only 2.81 MiB of
bounded activation workspace, but the best spill-free I128/J128/K256 consumer
was about 2.1x slower than the retained output-major shared-B FP16-WMMA owner on
an actual Qwen3.6-27B production shape. The complete candidate implementation
was removed; only the compact rejection evidence remains.

## Changes

- Built a diagnostic dense Q4T16 integer-MMQ body from the existing Q5
  I128/J128/K256 scaffold and K-major DS4 producer, consuming only the existing
  T16 payload and applying scale/min corrections after integer WMMA.
- Added then removed its independent RED/GREEN tests and actual-weight benchmark
  after the performance gate failed. No runtime/default dispatch or persistent
  layout survived.
- Retained only
  `benchmarks/results/2026-08-12-qwen36-27b-q4t16-source-shaped-dense-mmq-rejected.json`
  with commands, correctness, resource diagnosis, and measured rejection.

## Validation

- Focused gate during screening: **5 passed**, covering rows 17/128/129 and
  aligned plus output/row tails.
- Actual-weight 16-row CPU gate: KL mean `3.77e-7`, KL max `4.70e-7`, top-1
  `1.0`; outputs finite and repeat-exact.
- Actual immutable `blk.0.attn_gate.weight`, M512/K5120/N6144: initial
  I128/J128 combined **2.069529 ms**; spill-free bounded I128/J128
  **1.517838 ms**; I64/J64 **1.620414 ms**. Retained production measured
  **0.706486-0.770125 ms** in the same screens.
- Resource extraction found the branch-free body at VGPR256, 418 spills, and
  1,364 private bytes; the bounded body was VGPR187 with zero spills. Activation
  packing cost only about 0.013-0.032 ms, so the consumer remained the blocker.
- Post-removal `python3 scripts/worklog.py check`, JSON parse, and
  `git diff --check` pass with only this documentation/evidence unit present.

## Next

- Do not repeat source-shaped I128/J128 or I64/J64 Q4T16 integer MMQ unless a
  materially different weight-consumer dataflow, compiler, or upstream source
  changes the economics. Continue the measured ladder at Q6, then Q5 and GDN.
