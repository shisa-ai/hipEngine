# Compare short known-answer tasks under Inkling strict and fast

## Summary

Check the integrated Inkling `fast` profile against `strict` using fixed answers rather than teacher-forced logits. This is a short task diagnostic, not a production or matched Loom gate.

## Changes

- Added `scripts/inkling2_gguf_task_check.py`. The prompt packet fixes the cases, answers, rendering, exact trimmed-answer scorer, and per-case no-regression rule before either profile runs. It uses direct-answer prompts with an explicit model text prefix, not the Loom chat protocol.

## Validation

- `PYTHONPATH=. python scripts/inkling2_gguf_task_check.py "$model" --backend "$backend"` and the same command with `--reverse` ran through public `LLM.generate_detailed()` at hipEngine `17a800373`. Both profiles scored 9/12 on Strix Halo/pinned Loom Q4_K_XL and W7900/mainline Q4_K_M, with no case-level regression. Strict and fast emitted the same IDs on every case on each host, and reversing the order preserved token IDs and profile manifest digests.
