# Add counterbalanced Q8T16 batch-route A/B

## Summary

Added a durable same-session performance rebase for the historical gfx1151
Q8T16 all-rowtile batch route. The harness measures current package execution
versus the explicit candidate at physical c4 and c8, while preserving the
already-retained c8 pair-col8 owner in both routes.

- Added `scripts/q8t16_batch_route_perf.py` with one shared resident model,

  graph manifests, lifecycle accounting, paired summaries, and clean
  provenance.

  ratios.
