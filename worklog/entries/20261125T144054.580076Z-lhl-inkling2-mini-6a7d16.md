# Make the gated Inkling plan the production default

## Summary

Campaign plan step 8 (task 26). An omitted profile on `inkling2_gguf` now resolves to
`production` on `hip_gfx1100`. Before, it named no profile and built the generator without the
plan: 64-row prompt blocks and the paired rows of R0527 put its decode at 17.2 to 17.8 tok/s on
the W7900, where the gated route reaches 29.7 to 37.6. The lead asked for the default to be
production correctness rather than strict.

The `production` plan is the `fast` plan's prompt blocks with the decode arithmetic the gate
passed:

| Scope | `production` | Strict fallback |
| --- | --- | --- |
| Prompt blocks of 192 rows or more, gate and split down | `selected_wmma_f16_parts_f32_out` | tile4 F32 |
| Block attention, relative bias | `block_table_waves` | `block_sigmoid` |
| Prefill gate, block controllers, block attention inputs | `block_sigmoid`, `blend_norm`, `clip` | the host and ordered kernels |
| Expert activation | `split_activation_device` | `split_activation_host` |
| Single-token gate, shared input | `selected_shared_register_fp4_f32_f32_out` | `selected_register_fp4_f32_f32_out` |
| Resident single-token attention | `decode_table_sigmoid` | `split` |
| Every other decode expert scope | the strict F32 kernel | the same |
| Eager decode attention at 513 live keys and more | `split` | the same |
| Graph | `resident_single_token_whole_token_graph` | |

`fast` keeps its Q8-dot decode experts and its chunked attention. Its arm without route flags
fails the code scope of the gate, before and after the block attention kernel: KL p90 0.027 with
the tiled kernel and 0.097 with the new one, on the same commit `832d43611` ([tiled
control](/tmp/inkling-gate-runs14/gate-fast-tiled.json), uncommitted tree).

## Changes

- `register_inkling2_gguf_profiles` registers `production` for the backends in
  `PRODUCTION_BACKENDS`, today `hip_gfx1100`, where the gate rows exist. `hip_gfx1151` keeps the
  path that names no profile until its row passes; an explicit `production` there falls back to
  strict and reports it.
- A new scope, `resident_single_token_relative_bias`, names the decode attention of the resident
  visit. The strict and `fast` plans select `split` there.
- `Inkling2GGUFGenerator(production=True)`: the prompt blocks of `fast`, the selected F32 experts
  on every path (`q8_dot_experts` off in the projections), ordered attention on the eager decode
  fallback, and the three route flags on. `1` and `0` remain the caller's levers; an unset flag
  takes the profile's route.
- `scripts/inkling2_profile_gate.py` gains the `production` candidate and reads the block width of
  every profile but strict from the generator class.
