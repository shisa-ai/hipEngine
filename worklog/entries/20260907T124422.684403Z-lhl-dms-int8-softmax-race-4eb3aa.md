# Repair INT8 attention softmax shared-memory race

## Summary

Fix a write-after-read race in the INT8 split-K attention producer. The
shared maximum slot was overwritten for the probability sum before every
warp had read it. The C1 model replay that failed before the barrier now
passes byte-exactly; C2 interleaving, cancellation and refill also pass.
Post-repair numerical, fixture and cached profiler validation pass.

## Changes

- Add a block barrier between reading the shared maximum and reusing the
  reduction array. No arithmetic reassociation or acceptance relaxation.
- Add the 8193-token fixture and increase repeat attention checks to sixteen.
  The synthetic fixture did not reproduce the race; model replay supplies RED.
- Earlier pre-repair numerical passes cannot qualify this implementation:
  the race violated deterministic replay even when top-1 stayed unchanged.
