# Add dense-27B KV diagnostic controls

## Summary

The native mixed-KV quality suite can now select FP32 INT8 scale metadata and
express an empty expected layer set. The resident benchmark can independently
set context capacity, allowing matched 4K/128 timing and memory comparisons at
a 32K cache capacity instead of conflating prompt length with allocation size.

## Changes

- Added `--kv-scale-dtype {fp16,fp32}` to
  `scripts/qwen35_native_mixed_kv_suite.py` and included it in artifact command
  metadata and policy resolution.
- Added `none`/`empty`/`-` parsing for an explicitly empty expected BF16 or INT8
  full-attention layer set.
- Added `--max-sequence-length` to `scripts/qwen35_gguf_bench.py`, with a
  fail-closed lower bound covering prompt, warmup, decode, and the next row.
- Added focused parser, command, and capacity-validation tests.
