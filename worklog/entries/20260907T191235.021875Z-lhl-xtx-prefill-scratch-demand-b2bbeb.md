# Demand-driven split-K partials and DMS prefill workspace release

## Summary

Memory review target 3, both halves, implemented and measured at the
73,728-token C1 INT8 capacity point on GPU1.

(a) Split-K partial buffers (`full_attn_split_partial/m/l`) are now
allocated at the single-query decode floor instead of the native-prefill
16-row batch size, and grown on demand through
`ensure_full_attn_split_query_rows` (root-aware for `for_chunk` /
`for_packed_verify_layout` views; grown buffers tracked and freed at
session/packed-verify/standalone close). The native prefill fallback and
multi-row batch decode launch sites ensure their row count before launch;
`_FullStackScratch` (per-slot sized) needs no growth and is bypassed by a
defensive helper.

(b) The bulk prefill workspace (bulk scratch, prefill hidden A/B, prefill
token buffer) allocation is extracted from `__post_init__` into
`_allocate_bulk_prefill_workspace`; `_release_bulk_prefill_workspace` frees
and prunes it (refused while resident slot views exist);
`_ensure_bulk_prefill_workspace` re-acquires lazily, with slot views
delegating to their batch owner. `_finalize_external_dms_prefill` releases
the workspace before the compact pack so it no longer coexists with the
dense BF16 pool and the compact destination. Bulk-prefill entry guards
ensure instead of failing when released.

Measured ladder at 73,728 (whole-card 20 ms sampling, fresh process each):

| step                            | tracked peak GiB | delta MiB | headroom MiB |
| ------------------------------- | ---------------- | --------- | ----------- |
| baseline (shared runner)        | 23.186015        | —         | 9.6         |
| + private-C1 placement (t2)    | 22.520570        | −681.4    | 1052.9      |
| + demand split-K (t3)           | 22.420574        | −102.4    | 1157.0      |
| + workspace release (t3b)       | 22.278109        | −145.9    | 1305.0      |

Target-3-only saving: −247.9 MiB tracked / −246.5 MiB whole-card; total
versus the same-day baseline: −929.7 MiB tracked / −1295.3 MiB whole-card.
Probe wall unchanged (268.5 → 264.2 s). Clean drain to zero tracked bytes and
card-baseline return in every run.
