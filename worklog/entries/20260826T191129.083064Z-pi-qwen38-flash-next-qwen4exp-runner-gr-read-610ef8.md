# Compose Qwen4Exp device GR read

## Summary

Started the dedicated physical Qwen4Exp runner with a complete device GR read:
grouped BF16->F32 norm, down projection, branch-scaled SiLU, up sigmoid gate,
independent injection projection, and gated branch mean.

## Changes

- Added bounded `Qwen4ExpGRScratch` device ownership with failure unwind and
  idempotent reverse close.
- GR projections use model-neutral resident `GGUFDeviceWeight` dispatch from F32
  activation to F32 output; the runner has no backend/quant branches.
- Added strict scaled-SiLU and sigmoid pointwise siblings to the GR HIP family;
  in-place operation is supported for bounded scratch reuse.
- Exported the runner's GR result/scratch/composition API.

- RED: runner test failed collection because `qwen4_exp_runner` did not exist.
- GREEN: `uv run pytest -q tests/test_qwen4_exp_runner_gr.py` -> passed on
  Radeon 8060S/gfx1151.
- Runner/GR/dispatch focused bundle -> `4 passed`.
- Fixed-seed reduced dense F32 projections match the NumPy GR oracle within
  2e-5 for normalized state, gate, mixed hidden, and injection logits; scratch
  close is idempotent and leaves no owner.
