# Complete C8 K3 peer and semantic-role census

## Summary

Completed C8-P1 before selecting another implementation. The current hipEngine
profile is now mapped by semantic role and by its two R32 plus one R24 target
cycles. Direct prewarmed current/Laurent llama.cpp C8/K3 profiles isolate a new
first-ranked mechanism: matrix-tiled recurrent Q5 `ssm_out` ownership.

On the matched-output `general_en_explain` cell, both peers generate/accept
152/128 drafts (84.21%), emit the same visible output, use F16 K/V, and launch
19 HIP graphs. Current-to-Laurent decode span is 1231.717 to 1098.313 ms and
kernel sum is 986.749 to 863.917 ms. Q5 changes from MMVQ 131.651 ms to MMQ
32.018 ms across eight target rounds, accounting for 99.633 ms or 74.69% of
the decode-span delta. Applying that 0.2432x ratio to hipEngine's 15.052 ms Q5
cycle wall estimates 3.661 ms/cycle and 11.392 ms/cycle upside. This is a
source-grounded estimate, not a retained throughput claim.

  `25748619d26231137fa3add44d0a42d2c73c6003`, which flattens GDN output to 2D
  before Q5 projection and switches the peer from per-sequence MMVQ to

  the target lacked attach initialization, then host `ptrace_scope=1` blocked
