# Preserve AR peer mixed-target diagnostics

## Summary

The mixed-economics HTTP capture kept the MTP request's execution summary but
omitted ordinary AR peers' final diagnostics. Preserve that field so a run can
reconcile peers' shared-target participation with their ordinary batch steps.

## Changes

- Add nullable `diagnostics` to each request record. Copy only the diagnostics
  actually published by the server; do not synthesize an MTP summary for an AR
  request or infer missing target work.

## Validation

- Both new regressions fail before the change with `KeyError: diagnostics`.
- `.venv/bin/python -m pytest tests/test_unit_qwen38fn_mixed_economics.py -q`:
  41 pass. This is capture coverage, not a live performance result.
