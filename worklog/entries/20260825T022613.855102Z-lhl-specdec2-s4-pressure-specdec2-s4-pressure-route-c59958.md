# Route long-context pressure through SPECDEC2

## Summary

Extend the existing production long-context/global-KV pressure gate so the same
real Uvicorn SSE workloads can explicitly request speculative MTP. This lets S4
prove long-context and pool-pressure cells select K0 before provider mutation
while retaining the already-qualified Generation-2 page rejection, regrow,
graph invalidation, changed page-table, memory recovery, and exact-output gates.

## Changes

- Add an optional `speculative_mtp` field to the shared production HTTP workload
  helper and propagate it through `_execute_workload`.
- Add `--speculative-mtp` to `gguf_long_context_pressure_gate.py`, including its
  normal, forced-pressure, and graph-regrow requests and artifact configuration.
- Bound the physical dense MTP2 capability to context 1023, matching the packed
  target verifier's strict live-row contract.
- Make `prepare_k0` attach/catch up a provider only for temporary `NO_PROVIDER`
  or policy-selected AR transitions; context/resource/output/physical misses do
  not open or mutate provider state.
- Add focused context-miss no-attachment and parser tests.
