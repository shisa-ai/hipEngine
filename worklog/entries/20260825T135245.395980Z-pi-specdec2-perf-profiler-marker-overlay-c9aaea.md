# Load ROCprofiler SDK marker overlay

## Summary

The first packed-PARO rocprof leaf produced kernel/HIP/copy/allocation CSVs but
no marker CSV.  The common ledger loaded legacy `libroctx64.so`; ROCprofiler
7.2 marker tracing requires the SDK overlay `librocprofiler-sdk-roctx.so.1`.
A minimal direct experiment proved the latter emits `marker_api_trace.csv`.

## Changes

- Prefer the ROCprofiler SDK marker overlay and retain legacy ROCTX as the
  non-profiler fallback.
- Added a unit contract for overlay preference.
