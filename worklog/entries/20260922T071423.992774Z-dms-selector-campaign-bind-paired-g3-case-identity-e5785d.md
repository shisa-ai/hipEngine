# Bind paired G3 case identity

## Summary

Completed the G3 identity review by binding every result row to the same frozen
case coordinates and prompt/answer hashes, and by requiring the task manifest's
exact suite, target length, and 24-case coordinate matrix before execution.

## Changes

- Reject task manifests whose case suite/target differs from the manifest or
  whose family/category/placement coordinates are not the frozen matrix.
- Reject paired G3 arms when case semantics, prompt hashes, or answer-token
  hashes differ despite matching case IDs.
- Keep the tested-length gate on legitimate paired failures instead of allowing
  a result row to relabel its context length.
