# INT8 KV MTP performance claim against a matched AR baseline on gfx1151

## Summary

Task 20: the INT8-KV MTP cell that the W7900 topline still carries as "—" now has
a measured gfx1151 rate against a matched true no-MTP AR baseline, taken in one
server process per width with `speculative_mtp` set on every request.

Host is the desktop `gfx1151` lane, Radeon 8060S, machine_id `55ea6c50…`, the same
lane as the existing gfx1151 topline rows. Model is Qwen3.8-27B `Q4_K_M`
(17,106,775,008 bytes, sampled-sha256 `e7c9c4c1…`) on per-token-head INT8 KV with
fp32 scales, production profile, ten-prompt four-category suite with 12 of 30 cells
held out, 24 outputs per request, raw greedy.

| width | AR tok/s | MTP tok/s | ratio | engaged | exact |
| --- | ---: | ---: | ---: | ---: | ---: |
| c1 | 10.84 | 19.31 | **1.782x** | 10/10 | 10/10 |
| c2 | 10.79 | 25.75 | **2.386x** | 10/10 | 10/10 |
| c4 | 10.70 | 32.75 | **3.061x** | 10/10 | 10/10 |

Draft acceptance is 1015/1127 = 90.06% over 581 cycles. The gain grows with width:
per-request AR is flat across the sweep while MTP rises, so the four-request group
is 3.06x its own AR arm.

The task description predicted the opposite, that INT8 MTP gives up the c=N
advantage that INT8 AR keeps. That is not what this run shows, and the automatic
arm explains where the expectation came from, below.

## Findings

- **Automatic scope is promoted at c1 and c4 but not at c2.** The automatic arm of
  the same sweep records `requested_route: speculative_mtp_auto` and
  `decision_reason: automatic_mtp_scope_not_promoted` at c2, so all ten cells fell
  to AR (10.40 against 10.42 tok/s, 0.998x) while c1 and c4 engaged 10/10. The
  explicit request at c2 runs, as the table above shows. `hipengine/server/api.py`
  defines `_SPECULATIVE_MTP_AUTO_REJECTION_REASON` for this and keeps a screening
  override for explicit intent only, so automatic intent cannot admit an
  unqualified physical cell. This is a promotion-coverage gap on one width, not a
  capability miss, and it is recorded as its own task.
- **The INT8 KV path on this artifact needs the documented diagnostic override.**
  `HIPENGINE_GGUF_INT8_KV_ALLOW_UNVERIFIED=1` is required because this artifact's
  compact-INT8 quality record is rejected, so the rates above describe that
  configuration and not a default INT8 path. The equivalent W7900 run is
  qualified without an override.
- Neither artifact records `machine_id`; the bench does not emit it. The lane is
  stated from the host itself (`/etc/machine-id`), not inferred from the filename.
