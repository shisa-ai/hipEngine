# Measure replacement MMQ production stack

## Summary

Measured and admitted the replacement Qwen4Exp production candidate: Q8 dense
MMQ, Q5_1 down MMQ layers 32–47, Q4_K dual MMQ layers 35–47, and calibrated
DP4A decode safe-43, with strict grouped prefill on omitted layers. The stack
passes the complete numerical/state/task/c2 packet and improves same-session
strict p508/p1012 wall by 19.43%/19.58%. The legacy cooperative-MoE prefill
cannot be composed with the MMQ routes inside the current numerical envelope,
so the new production plan must replace—not layer on top of—that prefill path.

  those paths publish the valid SiLU product in `expert_intermediate`; the old
  selector read stale `expert_gate` whenever `exact_grouped_q4_gate` was false.
- Added the retained stacked-candidate artifact with complete gate, paired wall,

## Validation

- Initial legacy-cooperative composition exposed the ownership bug through
  massive nondeterminism; a one-prompt RED after the fix returned 25/25 top-1,
  mean KL 4.93e-5, state/repeat exact.
- Legacy cooperative + MMQs remains numerically rejected after the fix:
  Q4 suffix35 misses prefill-last p95 (5.25e-3); even Q8+Q5 with Q4 omitted
  misses prefill-last mean/p95 (1.10e-3/6.21e-3). This is arithmetic
  composition pressure, not state corruption.
- Replacement complete gate (450 rows, three candidate repeats): KL
  mean/p95/p99/max `3.23e-4/1.70e-3/4.79e-3/1.24e-2`, 448/450 top-1, no scope
  failures, state/repeat exact, automatic admission.
- Counterbalanced one-residency performance vs strict: p508
  8.383->6.754 s (-19.43%, 60.60->75.21 tok/s); p1012
  17.040->13.702 s (-19.58%, 59.39->73.86 tok/s). Per-mode logits SHAs are
  deterministic.
- Free generation: 16/18 strict-exact, 18/18 candidate-repeat exact. The two
  divergences are task-valid alternatives (`code_topological_sort` removes an
  unused import; `heldout_general_ja_speculative` changes equivalent wording).
- Physical c2: both rows exact, six stream chunks, teardown zero.
- Cached-build rocprof prefill trace: Q8 MMQ 314 launches / 27.818 ms, Q5_1
  MMQ 14 / 209.577 ms, Q4_K MMQ 13 / 118.497 ms; expected symbols present,
