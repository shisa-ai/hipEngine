# Task 22 blocked: UD K_S MTP exactness failure localized to a 0.0096-logit batch-composition near-tie; paired harness gated

## Summary

Task #22 (paired UD/plain MTP measurement) is gated on U6 certification, and U6
is incomplete, so no paired performance number was produced. Instead this unit
removed the one *correctness* blocker from the gate by localizing the UD Q4_K_S
exactness failure, and made the gate machine-enforced.

**The K_S failure is a near-tie argmax flip, not a defect in either path.** On
`general_ja_plan` at output position 12, the true no-MTP AR path picks token
99720 at logit 21.181459 over token 211768 at 21.171841 — a spread of
**0.009619** — and the MTP B3 verifier picks the AR's rank-1 token 211768. The
flip is deterministic (identical token hashes in both certification runs and
again in this diagnostic). The verifier evaluates that output row inside a
4-row batch (`target_logits_shape [4, 248320]` for budget 3) while the AR path
evaluates it as a single row, so the two routes differ by roughly one part in a
thousand in logit space. `docs/EXECUTION-PROFILES.md` defines
batch-composition invariance as a gate separate from arithmetic equality, which
is exactly the class this falls in.

Paired controls on the same prompt, same protocol, all exact: plain
`Qwen3.8-27B-Q4_K_S.gguf`, plain `Qwen3.8-27B-Q4_K_M.gguf`, and UD
`Qwen3.8-27B-UD-Q4_K_M.gguf`.

Consequence for U6 item 5: the gate as written (exact greedy IDs vs the AR
denominator) is unmet for ud-q4-k-s, and resolving it is a **profile decision**,
not another measurement — under a strict profile K_S cannot carry MTP scope;
under the production profile the calibrated mean/tail/max KL and top-1 gates
replace exact-ID equality and this near-tie is recorded as a known
batch-composition deviation. That decision was not taken here.

## Changes

- `benchmarks/results/ud-mtp-ks-near-tie-localization.json`: the diagnostic
  record (tokens, logits, spread, determinism, paired controls, what is not
  measured). Not a performance artifact; carries no token rates.
- `hipengine/loading/qwen35_gguf_admission.py`: U6 item 5's evidence and
  blocker now state the localized near-tie and the decision it requires,
  instead of "diverges at position 12".
- `scripts/ud_mtp_paired.py`: the paired UD/plain driver for #22. One
  `PAIRED_PROTOCOL` mapping supplies every flag, so the four resolved commands
  differ only in `--model`/`--quant`/`--output`; all four run the same
  `qwen36_dense_gguf_suite.py` entry point, so the AR baseline is each
  artifact's own true no-MTP greedy path and the KV layout comes from the same
  resident-session construction. It **refuses to run** unless
  `_UD_MTP_CERTIFICATIONS` is complete for both UD artifacts — the task's
  precondition is enforced in code, not by comment, and no flag bypasses it.
  `--dry-run` resolves the commands and reports the gate without touching the
  GPU.
- `tests/test_ud_mtp_paired.py`: protocol identity across pairs (only the
  artifact differs), gate mirrors the certification record, the gated run
  refuses and writes nothing, and the dry run emits the protocol.
- `docs/UD-QUANTS.md`: the K_S bullet now carries the localization and the
  profile decision.
