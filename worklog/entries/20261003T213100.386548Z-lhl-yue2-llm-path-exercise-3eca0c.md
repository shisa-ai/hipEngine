# Exercise the LLM song path and confirm which code ran

## Summary

`LLM(model_dir, vae_model=vae_dir).generate_song(...)` was run against the local
YuE2 checkpoints with a length-capped request, and the run confirms which code
executed: the HIP AR/NAR/VAE runtimes on `hip_gfx1151`, with no NumPy reference
operator and no torch module. This is a wiring and plumbing exercise on a cached
snapshot, not a parity measurement or a benchmark row.

## Changes

None. This unit is the exercise and its recorded numbers.

## Validation

Request: `cot="off"`, `seed=20260916`, style "Warm acoustic pop, clear lead vocal,
fingerpicked guitar", a two-line `[verse]`, and the product's own arithmetic apart
from the phase budgets (`abc_sampling` / `semantic_sampling` capped at 64 tokens,
which is what bounds a fifteen-minute full-length song into a 15-second run).
