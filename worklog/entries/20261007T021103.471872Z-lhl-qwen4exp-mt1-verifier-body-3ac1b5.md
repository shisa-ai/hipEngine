# Qwen4Exp MT-1 verifier body composed; rows>1 dispatch not c1-exact

## Summary

MT-1's remaining unit was "compose the q8_0 rowbatch into a verifier body pass and
measure the COMPLETE pass". The composition now exists and is measured, on
synthetic layer fixtures and on the real target. The result is a **concrete
blocker**: the rows>1 production dispatch does not reproduce the c1 arithmetic
per row, so the composed body is not a width-invariant verifier. The blocker is
arithmetic in the rows>1 dense/MoE/attention dispatch, not wiring and not the
layer structure.

## The composition

The strict decode QSA mixer is rows==1-only
(`run_qwen4_exp_dense_qsa_token_mixer` rejects every width 2..8). The rows>1 body
that already exists is the one the prefill chunk uses:
`run_qwen4_exp_qsa_prefill_layer` (QSA), `run_qwen4_exp_gdn_layer` (GDN, shared
with decode) and `run_qwen4_exp_ple`. `scripts/qwen4exp_mt1_batched_body_probe.py`
composes those into a non-resetting verifier body and scores every row with one
batched head (`run_qwen4_exp_gr_read` + `launch_gguf_linear` on `root.lm_head`),
then compares row by row against `verify_target_block_serial_exact`.

## Synthetic layer fixtures: bit-exact

`scripts/qwen4exp_mt1_verifier_body_probe.py`, one measurement per process:

| primitive | rows | result |
|---|---:|---|
| strict decode QSA mixer | 2..8 | rejects every width (`requires rows == 1`) |
| rows>1 QSA attention (`qsa_prefill_token_mixer`) | 6 | output, KV cache, index raw keys bit-exact vs serial |
| full QSA layer (`qsa_prefill_layer`) | 4 | output, KV key/value bit-exact vs serial |
| GDN recurrent layer (`gdn_layer`) | 3 | output, conv state, recurrent state bit-exact vs serial |
| q8_0 dense rowbatch | 2..8 | bit-exact width-invariant to serial c1 |

So the layer structure is not the blocker, and the q8_0 rowbatch is not the whole
story.

## Real target: not c1-exact

`scripts/qwen4exp_mt1_batched_body_probe.py`, Qwen3.8-Flash-Next UD-Q4_K_XL,
production profile, toy token chain `1..rows`:

| rows | top-1 agreement | hidden max abs delta | logits max abs delta | row-0 hidden delta |
|---:|---:|---:|---:|---:|
| 2 | 1.0 | 0.3125 | 1.0818 | 0.1055 |
| 4 | 1.0 | 0.3125 | 1.0818 | 0.1055 |
| 6 | 1.0 | 0.5176 | 1.0818 | 0.1055 |
| 8 | 1.0 | 0.5176 | 1.0818 | 0.1055 |

Top-1 matches on this toy chain, but hidden and logits diverge, and **row 0
already diverges**. Row 0 of a batched body should equal one serial step, so the
divergence is in the rows>1 production dispatch, not cross-row accumulation: the
prefill chunk wraps the rows>1 pass in `raw_k_prefill_rowbatch_session`, the q8
MMQ prefill context and the wide-F16 activation context, so the model's non-q8_0
dense projections (Q4_K/Q5_K/Q6_K) and the batched attention/MoE run
prefill-shaped kernels whose per-output reduction differs from the c1 decode GEMV.
The q8_0 rowbatch is width-invariant; the other quant paths are not.

## Disposition

- The composed body is **diagnostic only**. It is not in the engine and not wired
  into the provider; the provider still runs the serial verifier.
- The prototyped `verify_target_block_batched_body` runner method was measured and
  **removed** from `hipengine/runtime/qwen4_exp_runner.py`. Shipping a verifier
  body that returns divergent hidden/logits is a correctness footgun, and the
  composition lives in the probe instead.
- MT-1's remaining unit is therefore **arithmetic**: the rows>1 dense/MoE/attention
  dispatch must reproduce the c1 per-output reduction per row at every width 2..8
  before a batched body can carry the exact accepted prefix.

## Validation

- Synthetic layer RED: QSA attention (rows=6), full QSA layer (rows=4) and GDN
  (rows=3) output/KV/state bit-exact vs serial c1.
- Real-target comparison at rows 2/4/6/8: top-1 1.0, hidden/logits divergent as
  tabulated. `batched-body.json` is the direct artifact.
- `uv run pytest tests/test_unit_qwen4exp_mt1_verifier_body_boundary.py -q` ->
  passes; the changed runner has no diff (`git diff --stat` empty), so the
  production path is untouched.
- Limits recorded in the artifact: small-shape synthetic fixtures; one toy token
  chain, one model/quant/host for the real target; top-1 agreement is reported to
  localize the divergence, not as the MT-1 gate. No end-to-end MTP claim.
