# Add strict segmented GDN row journals

## Summary

Added optional FP32 row-journal publication to the ordinary segmented lowp GDN
kernel without changing its output or final-state arithmetic. This supplies the
missing selected-commit primitive for exact physical multi-request verifier
segments while retaining the existing no-journal and FP16-state wrappers.

## Changes

- Extend the segmented kernel with a nullable row-state destination and write
  every updated state at its token-major row offset.
- Add a BF16/FP32-state public wrapper and four-axis registry key
  `gdn_recurrent_rmsnorm_gate+state_rows/gguf_qwen35/bf16_segments_strict_order`.
- Preserve typed-null calls for all existing wrappers.

## Validation

- HIP RED/GREEN compares six token rows across two R3 segments against six
  calls to the existing scalar BF16 GDN: output, every row state, and final
  per-segment state are bit-identical.
- `python3 scripts/check_lineage.py --kind kernel --diff stat` reviewed before
  implementation; this is an in-tree extension of the existing gfx1100 GDN.

## Next

- Integrate the registered primitive only after the packed MoE C2 Q8/Conv
  prepare route is independently shown scalar-equivalent; keep scalar fallback.
