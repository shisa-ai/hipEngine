# Measure complete native DP-2 owner cost

## Summary

The complete native runner-pair operation is faster at rows=4096 and slower at
rows=1024 after charging scope admission, normal dispatch, ownership teardown,
event completion and final synchronization. The candidate is therefore
narrowed to rows=4096; rows=1024 remains on the parent. This is an owner-level
result, not a whole-model throughput claim or a production default promotion.

## Changes

- Added the native owner timing path in commit `5ed9c3e37`. The clean screen
  uses the actual `_launch_qwen4_exp_dense_pair` helper and the existing
  workspace, with no new kernel or persistent cache.
- Narrowed `GGUF_DENSE_WIDE_F16_PAIR_POLICIES` in
  `hipengine/kernels/hip_gfx1151/__init__.py` from rows `{1024, 4096}` to
  `{4096}`. The p1024 native cost screen is positive for neither pair and is
  no longer admitted; p512 and unmeasured rows remain parent paths.
- Preserved the existing ordered pairs, layers13–47, exact identity checks,
  DP-5 publication contract and opt-in environment flag.
