# Share packed Inkling expert transfers across decode rows

## Summary

Same-visit resident decode rows can send packed expert activations and routing metadata in one exchange. Each row still launches its original gate/up, activation, down and ordered mix kernels and writes to a distinct result slice. The exchange does not share arithmetic or deduplicate expert weights.

## Changes

- Build independent launch plans and reserve the maximum intermediate and Q8 packing scratch before submitting work. Reuse that scratch in stream order, and run each row's existing convolution callback before downloading the group. Use the same owner for the one-row and prefill cases; strict retains its existing non-fused path.
