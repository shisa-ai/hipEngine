# Add physical C2 production numerical gate

## Summary

Added a correctness-only production gate for the actual request-major 27B Dense
C2 packed verifier. It does not substitute a C1 proxy or generated-ID equality:
production physical logits are compared with strict serial logits under the same
strict-teacher context.

## Changes

- Added `scripts/qwen36_dense_mtp2_c2_production_gate.py`.
- The gate runs all ten prompts as five physical C2 pairs for at least three
  repeats, permutes pair order, captures actual device proposal IDs, copies the
  packed verifier's full-vocabulary logits after target execution, and replays
  strict serial rows at the identical prompt/output position.
- It evaluates binding mean/p95/p99/max KL and overall/per-category/shape/
  transition top-1, same-schedule logit determinism, output repeat/isolation,
  paired tasks, profiles/fallback, finiteness, exact physical request pairing,
  and final lifecycle drain. Candidate-ID/logit D2H exists only in this
  correctness process and carries no performance claim.
- Added pure host tests proving repeat coverage and drift rejection.

## Validation

  finite full-vocabulary logits at R6 and that actual device proposal IDs can be
  aligned per resident request.
- New gate tests plus existing MoE/numerical metric tests: **14 passed**.
- Ruff, Python compile, and `git diff --check` pass.
