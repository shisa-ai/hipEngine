# the layer diverges in isolation so the defect is inside gemma4_layer_forward_bf16

## Summary

`20260928T055010` left the experts, the embedding gather, and the layer
wrapper's sequencing as the untested pieces. This unit bisects that set in half
by calling `gemma4_layer_forward_bf16` directly at rows=1 against rows=2, with a
fresh random pre-layer input, an empty KV cache, and a freshly reset runner for
each call, so the only difference between the two calls is the block width.

**The layer itself diverges:**

| layer | kind | row 0 bit-equal | relative L2 |
| --- | --- | --- | --- |
| 0 | sliding | **False** | **0.00814221** |
| 1 | full | **False** | **0.00398055** |

The magnitudes are the same order as the model-level divergence, so this is the
mechanism rather than an artifact of the probe.

## What that clears

Both layer kinds diverge, so this is not the sliding path specifically.

## What is left, and it is a short list

Everything still in play is inside `gemma4_layer_forward_bf16` and was never
probed on its own. In the order worth testing:

1. **`gemma4_router_topk_bf16`.** A per-row top-k over experts. Its input is the
   normed hidden, which is bit-exact, so its *values* agree; what could differ
   is the selection when the kernel's row tiling changes how a row's experts are
   chosen. A different expert set would move the output by about the magnitude
   observed.
2. **The experts.** `gemma4_project_experts_grouped_row4` is named for its row
   count, the entry points take `compact_rows` and `total_rows` derived from the
   routing, and the fixture's expert tensors are Q4_K -- a different quant family
   from the Q8_0 projection that was cleared.
3. **`gemma4_partial_rotary_bf16`**, `gemma4_gelu_tanh_mul_split_bf16`,
   `gemma4_branch_add_bf16`, `gemma4_add_rmsnorm_scale_bf16` -- all present in
   the census, none probed.
4. The wrapper's own sequencing and residual adds.

The single-key argument still holds: row 0 of an empty cache reads exactly one
key, so a 0.8 percent difference cannot come from a long reduction.
