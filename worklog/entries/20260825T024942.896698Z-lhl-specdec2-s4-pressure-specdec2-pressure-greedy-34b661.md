# Keep speculative pressure requests raw greedy

## Summary

Correct the shared live-load request payload for explicit speculative MTP. The
production AR pressure protocol uses `ignore_eos=true`; that field intentionally
blocks raw greedy MTP semantics. Explicit speculative pressure requests now use
`ignore_eos=false` while retaining temperature 0/top-p 1, streaming, timeout,
and exact prompt identity.

## Changes

- Extract `_stream_request_payload` for focused request-contract testing.
- Set `ignore_eos=false` only when `speculative_mtp=true`; AR protocol is
  unchanged.
- Add a strict payload test.

## Validation

The focused payload test requires streaming, explicit MTP, raw greedy sampling,
and the original timeout. Python compile and diff checks pass. The clean hardware
pressure packet follows this commit.
