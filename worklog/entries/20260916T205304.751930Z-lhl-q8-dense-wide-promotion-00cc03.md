# Promote the wide-row Q8_0 dense prefill route to the production default at 16-47

## Summary

The production binder now routes `gguf_ud_q4_k_xl` Q8_0 dense prefill at layers
16-47 to `dense_wide256_f32_f32_out` and no longer binds the certified f16 WMMA
route at that scope. Layers 0-15 stay on the exact coltile chain, which remains
the registered strict fallback. This is a default-path swap inside one arithmetic
class, not a new one: the two routes hold the identical 12-case envelope, and the
wide route is 5.4% faster at 1K/4K.

## Why it is promoted rather than kept behind the flag

`docs/REFACTOR.md` carried two conditions for this and both were met:

- The wide route passes the calibrated production envelope at 16-47 with
  `strict_logits_sha256` and `candidate_logits_sha256` byte-identical to the
  certified WMMA route's gate artifact
  (`benchmarks/results/2026-09-17-q8-dense-wide-16-47-gate/`).
- It measures 4.389 -> 4.151 s at 1K and 18.208 -> 17.217 s at 4K against that
  route, and a tie at 512
  (`benchmarks/results/2026-09-17-q8-dense-route-ab/`).

Keeping both families selectable for the same layers is the contention the
2026-09-17 route fix had to resolve, so the WMMA binding is retired rather than
left beside the new default.

## Changes

- `hipengine/generation/qwen4_exp_profiles.py`: `PRODUCTION_Q8_DENSE_WIDE_PREFILL_LAYERS
  = range(16, 48)`; the binder binds `HIPENGINE_QWEN4_EXP_Q8_DENSE_WIDE=1` and
  `..._DENSE_WIDE_LAYERS=16..47` for the production profile on
  `gguf_ud_q4_k_xl` (and `"0"`/`""` elsewhere, so strict is unchanged), and binds
  `HIPENGINE_QWEN4_EXP_Q8_WMMA_LAYERS=""`. Both new keys go through
  `_apply_profile_env`, so a caller-set value is reported as a discarded
  pre-binder conflict like every other binder-owned route.

  wide-scope test (binds the wide route, asserts the WMMA binding is retired);

  fixture learns the two new binder-owned keys, which it did not clear and which
  leaked into later test files in the same process.

  now declares its own precondition instead of assuming an unset ambient env.

Note for anyone re-running the census through the hermetic wrapper: it uses
`env -i`, so `HIPENGINE_KERNEL_CENSUS=1` must be exported *inside* the wrapped
command (`therock.sh bash -c 'export HIPENGINE_KERNEL_CENSUS=1; exec python …'`).
Without it the census reports zero launches and an empty run looks like a
non-launch rather than an uninstrumented one.

## What this does not do

- The 12-case canonical prefill rate for the new default is still unmeasured.
  `docs/QWEN4EXP-STATUS.md` §5 item 1 remains open, and the campaign's "current"
  rows are projections from the route A/B ratios until it runs.
- The wide selector's env flag and the retired WMMA route are still registered;
  deleting them is the remaining half of the REFACTOR trigger.
- The variant manifest still names the exact coltile chain for this role, so the
  manifest hash alone does not identify the composition — recorded in
  `docs/REFACTOR.md` with the layer-windowed precedent to mirror.
