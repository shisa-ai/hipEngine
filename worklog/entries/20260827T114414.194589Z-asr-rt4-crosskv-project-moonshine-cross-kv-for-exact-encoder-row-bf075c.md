# Project Moonshine cross KV for exact encoder rows

## Summary

Implemented exact-row cross-KV projection for padded decoder buckets. The 1,248-frame decoder previously projected all 1,248 rows after D2D handoff even when only ~235-316 encoder rows were valid. The candidate tracks `source_frames`, zeros the padded cross cache, and uses the existing exact batch=1 capacity-strided kernel to project only valid rows. An actual 20-fixture screen improved 38.100/45.137→34.866/42.050 ms P50/P95 (8.49%/6.84%) with 200/200 exact text. Source is retained pending downstream high-confidence promotion.

## Changes

- Added exact encoder source-frame ownership to `MoonshineCudaResidentRuntime`, set by full cache loads and D2D handoff, cleared with encoder state, and exposed in the allocation contract.
- `precompute_cross_kv` now clears the padded cache and dispatches the existing batch=1 head-major kernel with `rows=source_frames` and `output_frames=encoder_frames`; exact-capacity inputs retain the original single kernel.
- Added `cross_kv_exact_rows=false` as an exact diagnostic rollback for same-worker paired gates; default is true.
- Added CPU RED/GREEN dispatch/cache/source-frame coverage and a real-GPU primitive gate proving byte-exact valid prefixes and all-zero padded tails.
- Hardened driver runtime-identity introspection for injected fake decoders while retaining EOS graph identity.
- Published `benchmarks/results/2026-08-27-cuda-sm120a-moonshine-exact-cross-kv-candidate.json` and benchmark changelog row.

## Validation

- RED padded-source test failed because eight full-capacity single projections were dispatched. GREEN asserts eight batch=1 calls with source rows 24/output capacity 40, one full-cache memset, and source-frame telemetry.
- Real GPU primitive: exact-row batch=1 valid K/V prefixes byte-equal the parent projection and padded tails exactly zero.
- Relevant CPU bundle (runtime, projection, C5 driver) passed all runnable tests with configured CUDA fixture skips; focused real-GPU primitive passed.
- Six short files with AOT attention + conditional EOS: 4.638982 ms median-of-medians; all timed streams exact.
- Actual 20-fixture alternating screen: full bucket 38.099510/45.137164 ms; exact rows 34.866291/42.050434 ms P50/P95, saving 3.233/3.087 ms (8.49%/6.84%); all 200 observations exact.
- Compilation, JSON, raw hashes, worklog, diff checks, and GPU cleanup passed before commit.
