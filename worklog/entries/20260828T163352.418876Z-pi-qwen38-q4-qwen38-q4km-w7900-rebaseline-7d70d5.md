# Rebaseline canonical Qwen3.8 Q4_K_M on W7900

## Summary

Rebaselined the canonical Qwen3.8-27B `Q4_K_M` artifact on physical host
`epyc`, Radeon Pro W7900/gfx1100, at clean source `cabb68b44`. Three fresh
strict C1/K3 D24 full-suite lifecycles measured pooled true AR **21.958** and
MTP **32.153 tok/s** (**1.4643x, +46.43%**). All 30 prompt cells were
AR=MTP exact and every run reproduced **157/199 (78.89%)** draft acceptance.

The automatic C1-C8 sweep was honest: only C1 engaged. C2-C8 selected typed
K0 and remained exact. Explicit full-suite physical C2/C3/C4 diagnostics were
also exact and engaged, but reached only **0.5137x/0.4597x/0.4790x AR**, so no
C>1 route is retainable. Same-host current/Laurent llama.cpp HIP complete-wall
C1 rows were **20.974→25.432** and **19.781→26.879 tok/s**; every W7900
external arm was self-deterministic and all cross-engine AR/MTP outputs matched
on 10/10 prompts.
