# Global strict softmax statistics do not clear attention numerical failures

## Summary

Both matched no-split controls fail the frozen production numerical bars on
saved 64-row code and mixed-summary teacher chains. The controls use strict QK
scores and residual WMMA P*V. One retains online softmax; the other starts with
the global strict maximum and normalizes with a strict 256-lane denominator.
Full-attention split count is fixed at one for both, so merging does not explain
the difference between them.

| Control | Chain | Mean KL | Maximum KL | Top-1 |
| --- | --- | ---: | ---: | ---: |
| Online, no split | Code | 0.002166 | 0.087396 | 1.000000 |
| Global statistics, no split | Code | 0.001482 | 0.078159 | 1.000000 |
| Online, no split | Mixed summary | 0.010483 | 0.226637 | 0.984375 |
| Global statistics, no split | Mixed summary | 0.009229 | 0.239151 | 0.968750 |

Global statistics reduce mean KL on these chains but do not clear the failure.
The residual WMMA P*V representation and accumulation remain changed. This
control does not establish either as the sole cause or demonstrate a deployable
repair. No shipping kernel or default changed; no performance claim is made.
