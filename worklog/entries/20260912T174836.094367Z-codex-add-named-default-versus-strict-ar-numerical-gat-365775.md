# Add named default versus strict AR numerical gate

Add a C1 AR evaluator that constructs public strict and omitted-profile LLMs.
This closes a harness gap, not the hardware qualification: existing FP16 state
gates use the same production arithmetic with FP32 state as their denominator,
and cannot independently certify the public strict-to-default composition.

  default D128; preserve resolved manifests, actual FP16 state/BF16 KV identity,
  model/provenance, and explicit C1-eager-only limitations.
- Close every LLM in finally, including failed capture. This gate does not
  claim HTTP, MTP, graph, task, or full-production qualification.
