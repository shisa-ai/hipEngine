# Publish W7900 OLD versus CONCURRENCY2 C1-C8

## Summary

Completed the requested same-host, same-model, same-protocol OLD versus
CONCURRENCY2 server comparison at every logical width C1-C8 on W7900 GPU0.
CONCURRENCY2 is faster at every width: C1/C2/C3/C4/C5/C6/C7/C8 improve
**+5.74/+0.83/+84.04/+5.70/+62.61/+55.15/+46.90/+12.70%**. All old and new
cells pass independent-C1 output equality, repeatability, <=5% variance, and
final ownership.

The large odd-width gains are execution-shape wins. OLD rounds C3 to masked
eager C4 and C5-C7 to masked eager C8. CONCURRENCY2 captures one exact native
graph for each physical C2-C8. C2/C4/C8 were already graph shapes and still
improve 0.83%/5.70%/12.70%.
