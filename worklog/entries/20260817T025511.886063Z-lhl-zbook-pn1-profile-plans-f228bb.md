# Register Qwen3.6 GGUF gfx1151 execution-profile plans (PN1 part 1)

## Summary

Registered the strict and production runtime execution-profile plans for the
Qwen3.6-35B-A3B GGUF gfx1151 model (`(qwen3_5_moe_gguf, hip_gfx1151,
 gguf_q4_k_m)`), wired registration into `register_builtin_generators()`, and
added resolution/fallback/duplicate/missing/binder tests. This is the first
half of PN1; the standardized actual-control capture and GPU smoke remain.

## Changes

- Added `hipengine/generation/qwen36_gguf_profiles.py`: strict plan (base F32
  router, exact Q8T16 decode, strict GDN chain, no rowtile) and production plan
  (incumbent package route: cooperative persistent F32 router + package-floor
  rowtile policy), both with strict rollback keys per scope and a construction
  time cold-path policy binder. `batch_invariant` is deliberately unregistered
  so it fails closed to strict (`fell_back_to_strict`).
- Wired `register_qwen36_gguf_gfx1151_profiles()` into
  `register_builtin_generators()` so plans exist before LLM construction
  resolves an explicit `HIPENGINE_EXECUTION_PROFILE`.
- Added `tests/test_qwen36_gguf_profiles.py` (12 tests): idempotent
  registration, strict exact/unfused manifest, production incumbent manifest
  with strict fallbacks, batch-invariant fail-closed, stable manifest hashes,
  duplicate/missing-plan errors, factory-or-binder requirement, and the strict
  vs production cold-path binder env policy.
- Updated `docs/QWEN36-35B-ZBOOK-PRODUCTION-NUMERICS.md` PN1 status and
  punchlist to mark the completed registration items and the open
  control-capture items.

## Validation

- Verified registered gfx1151 variants for every declared selection
  (`f32|router_logits|f32_hidden`, `gguf_q4_k_m|linear|
  pack8_full_k_grid_y_native_exact_bf16_bf16_out`, `gguf_q4_k_m|paged_attn_decode|
  bf16_context_batch_shared_native_exact_spans`, `gguf_qwen35|linear_attn_chain_conv_decode|
  bf16_c1_exact_state_rows_tloop`).
- `uv run pytest -q tests/test_qwen36_gguf_profiles.py` (12 passed) and the
  shared bundle `tests/test_execution_profiles.py` +
  `tests/test_execution_profile_runtime.py` +
  `tests/test_execution_profile_evaluator.py` + the new file (35 passed).
- Verified end-to-end: after `register_builtin_generators()`, strict resolves
  (`fell_back=False`), production resolves (`fell_back=False`), and
  batch_invariant fails closed (`fell_back=True`); the resolved generator
  factory is `make_qwen35_gguf_q4_k_m_generator_gfx1151`.
- No GPU run or performance claim in this unit; the no-change GPU smoke is a
  remaining PN1 item.
