# Reuse normalized Inkling residual blocks

## Summary

Normalize each completed residual block once and reuse it in subsequent reads. Normalize the live partial on each read; leave scoring and weighted sums unchanged.

## Changes

- Keep normalized blocks in the forward pass's residual stack, including across loop restarts. Check bitwise equality with the original reader for vector and packed inputs.

## Validation

- `epyc` / Radeon Pro W7900 (`gfx1100`), original `thinkingmachines/Inkling-2-Mini` revision `ed40e7da625f594fc9c4990f5f66be24873c22d7`, `inkling2_mixed`, FP32 KV, single-request ordinary greedy decode. Baseline `9568ce45d`.
- `bash /tmp/hipengine-inkling2-verify.sh normalizedblocks`: warm median 15.0966 to 15.2649 tok/s at five input / 24 output tokens (three runs per arm). The synthetic 512-input / 128-output case rose from 13.0268 to 13.1601 tok/s (+1.02%), one run per arm, with identical output IDs.
- Host microbenchmark: median 51.13 to 38.52 µs per read for four queries over 12 cached blocks and one live vector, width 2048, `OPENBLAS_NUM_THREADS=1`, five repeats of 2,000 calls, with bitwise-identical results. Excludes the one-time completed-block normalization.
