# Reorganize docs into status-declared sections with generated indexes

## Summary

`docs/` had grown to 153 files and 167k lines in a flat namespace. Only 50 were
listed in `docs/README.md`, so 103 were invisible to the index. Campaign files
were 52 files / 67k lines — 40% of the tree — and nearly all self-declared
closed, superseded, or historical in prose headers of wildly varying length (one
`Status:` line runs about a thousand words). Six files had zero inbound
references.

The failure this caused is the same one addressed one commit earlier in
`AGENTS.md`, one level up: normative content diluted by historical content in a
shared namespace, so "is this binding?" could not be answered without opening a
file too large to open casually. Agents therefore treated closed campaign
records as potentially binding, which feeds the over-restriction reflex.

Lead decisions taken for this unit: flat `campaigns/` with a generated index;
status front-matter plus a validator; full reorganization in one commit;
`scripts/docs/` as the home for documentation tooling; `RDNA3-TUNING-GUIDE.md`
stays at the top level because it has external references and is the current
respin of the kernel-scope material in `LESSONS-LEARNED.md`.

## Changes

- Top level is now 14 documents plus `source_lineage.json`: the five normative
  rules files (`PLAN`, `EXECUTION-PROFILES`, `OPTIMIZATION`, `TESTING`,
  `BENCHMARK`) and the live references (`API`, `ENVS`, `MODELS`, `KERNELS`,
  `ROOFLINE`, `RDNA3-TUNING-GUIDE`, `LESSONS-LEARNED`, `REFACTOR`, `README`).
- `docs/reference/` 38 live subsystem contracts; `docs/campaigns/` 61 campaign
  records; `docs/model-cards/` 10; `docs/archive/` 25 superseded/closed/history.
  All moves used `git mv`, and every file kept its basename so stale references
  in immutable worklog entries stay resolvable by search.
- Every indexed document gained front-matter: `status:`
  (`normative`/`current`/`closed`/`superseded`), an `owns:` line, and
  `superseded_by:` where applicable. Status is now greppable without opening the
  file. Published Hugging Face model cards are excluded: they carry their own
  front-matter schema and ship with weights.
- Added `scripts/docs/check_docs.py` (validates front-matter, regenerates the
  five index pages from a marker-delimited template so prose survives) and
  `scripts/docs/check_all.py` (single entry point running the docs gate plus the
  existing `check_envs_docs`, `sync_benchmark_readme --check`, and
  `check_published_command_drift` gates). Existing gates were left in place so
  their ~25 inbound references and two test files keep working.
- `owns:` is a hard requirement for top-level and `reference/`; elsewhere
  `owns: TODO` is accepted and warned. 46 campaign/archive documents currently
  carry TODO — that is the fill-in backlog, surfaced rather than hidden.
- Rewrote links tree-wide: 531 files in the first pass, then an idempotent
  repair pass for links carrying `#anchors`, which the first pass's regex
  skipped. `AGENTS.md` gained a "Docs declare their own status" ground rule, new
  Key Files rows, and `check_all.py` in the docs verification tier.
- Fixed three test path constants built from parts rather than a literal string,
  which the textual rewrite could not see:
  `test_integration_docs_publish_provenance_gate.py`,
  `test_integration_server_api.py`, `test_unit_gfx1151_backend.py`.

## Blockers and corrections

Three self-inflicted errors found and reverted during this unit, each a case of
a textual rewrite reaching content that is deliberately immutable:

1. **`benchmarks/results/` artifacts.** The rewrite edited 314 retained evidence
   JSON files, breaking SHA256 pins asserted by seven `test_unit_laguna_*`
   tests. Benchmark artifacts record what was true when measured and must never
   be rewritten. Reverted.
2. **Hash-pinned kernel source.** `hipengine/kernels/hip_gfx1100/__init__.py`,
   `hipengine/runtime/gguf_linear.py`, and `scripts/specdec2_perf_bridge.py` are
   SHA-pinned as frozen promotion evidence. Their diffs were comment-only doc
   paths, but a documentation reorganization must not alter a kernel source
   hash or force re-certification of a promotion contract. Reverted; those three
   files now carry stale `docs/` paths in comments, resolvable by basename.
3. **External repository paths.** The rewrite mangled two entries in
   `docs/source_lineage.json` that point into `~/amd-gpu-tuning/` — a different
   repository that was not reorganized. Reverted, and `scripts/check_lineage.py`
   re-run.
