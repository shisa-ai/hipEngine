# Implement exact PF-5 GDN tile-16 staging

## Summary

Implemented the PF-5 lever-2 T0 candidate declared in
`20260905T010924.264937Z-lhl-qwen4exp-pf5-gdn-tiled16-red-154d7d.md`.
The candidate is bit-exact to the production `<4,4>` columnwarp chain and wins
the interleaved operation-complete recurrence+norm/gate screen at all three
anchors. The 512-row production chunk improves 3,041.948→2,066.418 µs
(-32.069%). No runtime route or execution-profile default changed in this unit.

## Changes

- `hipengine/kernels/hip_gfx1100/linear_attn/qwen4_exp_gdn.hip`: added
  `qwen4_exp_gdn_prefill_tiled_f32_kernel<16,16,4>` and a raw-pointer launch
  entry for the Qwen4Exp Hk=16/Hv=32/D=128 prefill shape.
  - Each 512-thread block owns 16 output columns.
  - Each token warp computes the same `r=0..3` Q/K norm partials and XOR-shuffle
    tree as the parent, publishing bit-identical q_scale/k_scale/beta/decay.
  - All column warps reuse 16 raw Q/K rows from 16,896 bytes of LDS while each
    recurrent-state shard stays in registers across the complete sequence.
  - The existing `qwen4_exp_gdn_core_norm_gate_f32_kernel` remains the second
    operation-complete stage.
- `hipengine/kernels/hip_gfx1100/linear_attn/qwen4_exp_gdn.py`: added the
  validated wrapper and registered
  `(hip_gfx1100, gdn_recurrence_norm_gate, f32_state,
  qwen4exp_gdn_tiled16_prefill)`. The columnwarp and serial strict variants are
  unchanged and remain registered.
