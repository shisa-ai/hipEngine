# Gate raw Q5 Q6 real role widths

## Summary

Add raw-leaf tests using published K_M rows at actual role input widths.
All 42 sampled raw-leaf checks pass on gfx1151. No performance claim.

## Changes

- Add tests/test_gguf_ud_q56_roles.py for Q5/Q6 at K=5120/6144/17408 and
  Q6 NextN eh_proj K=10240, rows 1/8/32, BF16/F32 outputs. Five sampled
  weight rows include first/middle/last and a repeated row, testing odd N.
  Pin each concatenated compressed sample by SHA256 so a file or offset
  change cannot silently replace the test input.
- Require byte-exact batched versus single-row results on two repeated
  row-local runs, output canaries, finite outputs and CPU-reference outer
  KL/top-1 gates. Poison output before each row-local run so no-op writes fail.
  Also compare every output to the float64 dot product: F32 rtol=2e-5,
  BF16 rtol=0.004, atol=2e-4 for either. These fixed bounds complement, rather
  than replace, the exact row-partition contract. This is not an independent
  codec oracle or full-N gate.
- Skip when the optional model or HIP is absent. HIPENGINE_UD_ROLE_MODEL is
  only a test input override, not a runtime experiment flag.
- No implementation change: these are coverage additions to existing kernels.
  An initial collection error used the wrong BF16 utility import; corrected
  to hipengine.quant.gguf before enqueueing GPU work.
