# Add canonical Qwen4Exp profile inputs and lifecycle census

## Summary

Made the retained profile tools capable of collecting the requested current
canonical role ledger. Prefill profiling can now consume the committed exact-
token fixture directly, every measured kernel has an outer operation boundary,
and both prefill and context-conditioned decode record steady allocation growth
and teardown. The trace analyzer also accounts for allocation rows inside the
measured window and after the first graph launch.

## Changes

- Added `--fixture` and `--case-id` to `scripts/qwen4exp_profile_gap.py`; canonical
  p512/p1024/p4096 cases bypass tokenizer reconstruction and automatically size
  the sequence allocation.
- Added source, host, exact command, fixture identity, complete tracked-memory
  snapshots, zero-growth checks, and teardown verdicts to profile artifacts.
- Added outer prefill/decode role ranges. Nested layer/linear markers remain the
  more specific owner, while root/head/copy work now lands in an explicit
  operation boundary rather than the unattributed bucket.
- Extended `scripts/qwen4exp_context_decode_profile.py` with the same outer role
  range and steady allocation byte/count checks while preserving its exact
  mutable-state replay hashes.
- Extended `scripts/qwen4exp_trace_analyze.py` to count allocation rows/bytes in
  the measured marker and at or after the first graph launch.
- Extended `scripts/qwen4exp_role_analyze.py` to report attributed and
  unattributed device-time coverage, not only row coverage.
