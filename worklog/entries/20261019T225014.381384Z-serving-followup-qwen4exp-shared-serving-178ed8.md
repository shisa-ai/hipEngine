# Wire scheduler-owned Flash-Next mixed target serving

## Summary

Explicit Flash-Next MTP requests within a mixed-capable batch owner's input
contract import prefilled state into the batch and retain one request-owned
draft. The existing speculative planner drives proposal, one shared physical
target pass and accepted-prefix publication beside ordinary AR peers.
Automatic selection keeps its existing lone-request policy while mixed-cycle
economics are measured. No second scheduler or GPU owner was added.

## Changes

- Initial roots are emitted from prefill results without stepping the target
  twice. K0 consumes the previous root with its hidden seed, then advances its
  draft once. Terminal AR tokens are published without unnecessary target work.
- Each cycle checkpoints request RNG, processors, grammar, logprobs and draft.
  Cancellation aborts provisional state and restores those checkpoints before
  the scheduler retires the cancelled row. Committed prefixes preserve draft
  catchup and report actual target/draft cursor deltas.
- A quiesced failed pass names only its physical participants for retirement;
  unrelated slots remain usable. A device synchronization or cleanup failure
  stays fatal rather than asserting safe containment. A new draft-admission
  counter prevents one planned admission batch from oversubscribing drafts.
- Telemetry reports mixed request widths, total target rows, candidate counts,
  accepted counts and cycle wall time. Capabilities distinguish request width
  from total verification rows.
