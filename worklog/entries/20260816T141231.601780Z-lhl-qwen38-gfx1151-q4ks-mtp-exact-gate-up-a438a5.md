# Repair exact Qwen3.8 Q4_K_S native B3 gate/up

## Summary

Task 23 localized the Qwen3.8-27B Q4_K_S native B1-B3 trajectory failure to
one arithmetic boundary: rows2-4 dense gate/up+SiLU used the direct-BF16 qmicro
rowtile owner, while true AR used the retained residual-Q8_1x2 split-weight c1
owner. A same-snapshot B3-cycle bisect proved that serializing only gate/up
through the c1 owner makes all 64 layer outputs, state rows, KV buffers, hidden
seeds, and target top-1 bit-exact. The retained rows2-4 rowtile8 shares each
compact-weight traversal while preserving that c1 arithmetic independently per
row. It changes no acceptance, prompts, weights, payload ownership, workspace
size, or peer route.
