# R0137 FP16 recurrent-state owner transport

## Summary

Migrated the profile-owned `HIPENGINE_GGUF_FP16_RECURRENT_STATE` decision from
process-global environment writes to an explicit optional generator/session/
runner field. Dense gfx1100/gfx1151 and inherited moe-gfx1100 profiles bind
`False`; moe-gfx1151 remains unbound (`None`) and resolves its own direct
environment/backend default instead of inheriting another owner's write.

The full-stack runner resolves the field once, before native-rows
materialization and scratch allocation, and carries that resolved bool into the
session ABI. Direct/unbound sessions keep the existing environment and
backend-package policy. Shared/reused sessions validate the live allocation
against the owner request instead of retargeting it.

## Changes

- `hipengine/generation/qwen35_dense_gfx1100_profiles.py`: strict binder sets
  `generator.target_fp16_recurrent_state = False`; removed the FP16 environment
  write. Production inherits through `_strict_binder`.
- `hipengine/generation/qwen35_dense_gfx1151_profiles.py`: binder sets the typed
  field from `fp16_state`; removed the FP16 environment write. Both existing
  dense profiles pass `False`.
- `hipengine/generation/qwen35_gguf.py`: added the generator field, a
  session-kwargs helper, transport to shared/direct/native/MTP session
  constructors, both runner constructors, the NextN provider call, and
  `_configure_session` ABI validation. The provider pool key is unchanged: the
  pool belongs to one generator and the decision is fixed for its lifetime.
- `hipengine/runtime/qwen35_gguf_runner.py`: added the runner/session fields, a
  resolver that prefers the owner value, and `_freeze_fp16_recurrent_state()`.
  Native-rows preflight and the post-materialize final flag share one resolved
  value. Session construction validates a shared runner's live ABI.
- `hipengine/runtime/qwen35_gguf_nextn.py`: forwarded the decision to the
  executor's full-stack runner and batch session.
- `scripts/gguf_production_load_gate.py`: captures `resolved_backend`,
  `target_arch`, and the resolved recurrent-state bool together while the shared
  runner is live, before `llm.close()`. The plain captured bool is recorded as
  `resolved_fp16_recurrent_state` in the existing provenance environment
  metadata; no synthetic `HIPENGINE_*` environment input is named.
- `tests/test_unit_qwen35_gguf_fp16_owner_transport.py`: new resolver/once-only,
  actual `__post_init__` preflight-plus-final single-resolution, shared-runner/
  shared-session/direct-scope transport, NextN true/false/None, reused-ABI
  mismatch, scratch-pricing, and dense-vs-moe default tests.
- `tests/test_integration_gguf_production_load_gate.py`: fake-lifecycle test
  clears `_shared_runner` after capture and verifies the captured bool reaches
  provenance without running the full load gate.
- Updated the three existing profile test modules for typed binding and the
  unbound moe-gfx1151 case.
