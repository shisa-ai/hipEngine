# Scatter Qwen4Exp QSA index keys by chunk

## Summary

Replaced Qwen4Exp prompt QSA's per-row 512-byte D2D index-key copies with one
registered block-table-aware scatter per QSA layer/chunk. It is bit-exact and
wall-neutral but cuts p512 trace launches 11,053→4,933.

## Changes

- Added raw-pointer `qsa_index_append/f32/strict_rows_paged` scatter kernel and
  wrapper. Logical rows map through the authoritative paged block table.
- Added `Qwen4ExpQSAIndexDeviceState.append_rows`; c1 `append` remains fallback.
- Prompt QSA now scatters the contiguous projected key chunk once and advances
  its logical count transactionally.

## Validation

- Permuted two-block fixture proves physical scatter placement exactly.
- 16 QSA kernel/runtime tests pass.
- Counterbalanced p508 complete model: 58.678→58.669 tok/s (-0.015%, neutral),
  full logits/top-1 bit-exact.
- Structural p508: 6,096 D2D copies→24 scatter kernels (-6,072 submissions).
- Cached p512 rocprof: total launches 11,053→4,933 (-55.37%), expected scatter
  symbol, 427 remaining copyBuffer launches, no compiler child.
