# Concurrency2 C2-0 host contracts and simulator

## Summary

Implemented the C2-0 executable host architecture from `docs/CONCURRENCY2.md`: immutable child/parent and output contracts, the format-neutral KV backend/resource/storage-view protocol, and a deterministic c1-c32 simulator proving independent completion and backend swapping without GPU access.

## Changes

- Added `KVBackendSpec`, atomic named claim/delta types, complete pool plans, typed leases, storage plane/views, `KVBatchView`, and the runtime-checkable `KVCacheBackend` protocol.
- Added blocking and bounded streaming child collectors with an out-of-band terminal slot, frontend-only parent aggregation, stable child phases, and request-ID-keyed output events.
- Added one deterministic engine/resource-ledger implementation plus dense BF16, dense INT8 payload+scale, mixed recent-BF16/packed-history demotion, and DMS-like variable-span fake backends.
- Extended `KVLiveSpans` validation so per-head-variable `[rows, layers, heads]` metadata uses sequence rows rather than flattened cell count.
- Added RED/GREEN c1-c32 delayed-arrival, ragged-length, queued/active cancellation, refill, compaction/demotion, slow-consumer, physical decomposition, injected reserve-failure, conservation, independent-output, and final-drain coverage.
- Marked the C2-0 roadmap checklist complete; no production scheduler/backend switch or GPU path changed.
