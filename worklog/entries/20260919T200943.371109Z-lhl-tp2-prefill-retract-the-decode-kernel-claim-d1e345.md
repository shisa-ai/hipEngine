# tp2 prefill: retract the decode-kernel claim and fix the measurement tools

## Summary

Supersedes the *causal* half of
`20260919T184012.884201Z-lhl-tp2-prefill-missing-dispatch-contexts-8b41d7.md`.
That entry claimed the TP2 prefill gap was "a missing dispatch context" because
the attention path ran decode-shaped GEMV kernels. **The kernel claim is false
and is retracted.** The measured effect of the contexts is real and reproduces;
the explanation for the remaining gap is not established.

A reviewer caught the mechanism: the census hooked
`resolve_gguf_linear_dispatch`, which runs *before* the runtime's prefill
rewrites. Re-hooking the authoritative final `kernels.registry.resolve` records
no decode variant on this path at all.

## Changes

- `scripts/tp2_prefill_dispatch_census.py` — hook the final `resolve` (what
  actually launches) and keep the pre-rewrite candidate only to expose the
  rewrite delta. Re-run at rows=512 gives
  `q4_k -> t16_wmma_prefill_bf16_bf16_out` (5 dispatches),
  `q5_k -> t16_wmma_prefill_bf16_bf16_out` (1),
  `q6_k_qmicro_planar -> t16_wmma_prefill_bf16_bf16_out` (3).
- `scripts/tp2_prefill_context_ab.py` (new) — commits the decisive context
  experiment that previously lived only in `/tmp/probe7.py`. One session,
  A/B/B/A counterbalanced, both arms warmed once unmeasured, raw samples and
  within-arm drift reported.
- `scripts/tp2_shard_pair_ab.py` — require explicit `--arm-a`/`--arm-b`;
  refuse identical arms unless `--noise-floor`. The documented fusion command
  compared `{17408,8704}` against the same current default, i.e. an A/A
  experiment reporting a number as an effect.
- `scripts/tp2_prefill_phase_attribution.py` — instrumentation overhead sign
  was inverted (reported as making the run faster). Now `instrumented - min(uninstrumented)` = +2.6 ms / +0.53% added latency.
- `hipengine/kernels/hip_gfx1100/__init__.py` — capability comment no longer
  asserts the retracted "rendezvous-bound / absorbed as extra wait" mechanism.
- `docs/REFACTOR.md` — the decode-kernel table and the "this is why attention
  runs at 31.2 TFLOPS" inference are replaced with the corrected record; the
  rebalance arithmetic is corrected; the PCIe and host-timeline claims are
  bounded to what they measure.
- `benchmarks/README.md` — bulk prefill is **opt-in** (`bulk_prefill=False`),
  not the default; the passing arm-vs-control gate and the failing cross-route
  gate are distinguished.
- Tests: `tests/test_unit_scripts_tp2_prefill_dispatch_census.py` (new, pins the
  observation point); `tests/test_unit_scripts_tp2_prefill_phase_attribution.py`
  updated off the removed `_record_all` interface, plus pairing, host-stamp,
  and overhead-sign regressions.
