The full `pytest` run aborts at 16% because a segfault kills the process, so the
suite cannot report the state of the remaining 84%. Any full-suite run on this
machine has to deselect this node to produce a signal:

```

  "tests/test_gguf_linear_dispatch.py::test_q5_t16_routes_decode_bounded_native_rowtile_and_dense_wmma"
```

That is a real coverage hole, not a cosmetic one: the node is the only dispatch
test for the Q5_K T16 bounded native rowtile and dense WMMA route, which is the
route the UD Phase 5 unit identified as 19.6% of decode step time.
