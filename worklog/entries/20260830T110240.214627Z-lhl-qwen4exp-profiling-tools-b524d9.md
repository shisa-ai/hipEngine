# Durable Qwen4Exp profiling tools

## Summary

Promoted the durable pieces of the /tmp Qwen4Exp profiling pattern into the
repository: the named-production wall/profile driver, generic kernel/HIP trace
summarizer, ROCTX role attributor, decode-sync A/B diagnostic, and markdown
report renderer for the committed fresh-profile artifact.

## Changes

- Added `scripts/qwen4exp_profile_gap.py` with CLI-selectable model/prompt,
  prefill/decode modes, cached-build controls, ROCTX measurement ranges,
  role markers, runtime census, and graph snapshots.
- Added `scripts/qwen4exp_trace_analyze.py` and
  `scripts/qwen4exp_role_analyze.py` for kernel/HIP/copy windows and
  correlation-ID role attribution.
- Added `scripts/qwen4exp_decode_sync_ab.py` as a clearly diagnostic exact-ID
  synchronization A/B.
- Added `scripts/qwen4exp_perf_gap_report.py` to render the committed profile
  artifact as compact markdown tables.
- Left one-off candidate gates and rejected experiment harnesses in /tmp; their
  retained evidence remains in benchmark artifacts and immutable worklogs.

## Validation

- `python3 -m py_compile` on all five scripts.
- `uv run pytest tests/test_qwen4exp_profile_tools.py -q` (3 passed).
- `uv run python <script> --help` for all five CLIs.
- No HIP/model execution was run for this tooling-only unit; GPU-specific
  behavior remains governed by the campaign profile commands.
