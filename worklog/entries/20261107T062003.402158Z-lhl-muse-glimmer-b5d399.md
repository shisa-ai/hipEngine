# Muse Glimmer prefill: PMC bottleneck + pipelined kernel attempt

## Summary

Per lead direction, profiled the shared_b Q4 projection with rocprofv3 PMC
counters (the launch-overhead blind spot noted) and built a software-pipelined
double-buffered variant. The kernel is DATA-FEED bound, not compute-starved:
LDSBankConflict 48.5%, MemUnitBusy 71.2%, MeanOccupancyPerCU 7.8 waves,
GPUBusy 100%, ALUStalledByLDS 0.02, WriteUnitStalled 0.07. The pipelined
kernel is exact but 0.73x slower because double-buffering the 25.5 KB weight
slab (51 KB LDS) drops occupancy from 2 to 1 block/CU. Reverted.

## Changes

- Experimental pipelined kernel (glimmer_decode_q4_slab helper + double-buffer
  weight_tile[2] + decode(blk+1)-before-WMMA(blk)) added then reverted; tree
  clean at a5c89c49e.

## Validation

- PMC on shared_b ffn_gate rows=512 (21 dispatches): GPUBusy 100,
  MeanOccupancyPerCU 7.80, LDSBankConflict 48.49%, MemUnitBusy 71.15%,
  ALUStalledByLDS 0.019, WriteUnitStalled 0.068, VALUInsts 49151/wave.
- Pipelined vs shared_b ffn_gate rows=512: shared_b 6.19 ms (22.0 TF), pipe
  8.46 ms (16.1 TF), 0.73x; cosine 0.99992, maxerr 0.0000 (exact).
- Hot-path review (lead priority 3): graphed decode_step non-GPU overhead
  0.344 ms/step (CPU softcap tanh+mul+contig 0.082 ms); decode is GPU-bound,
  Python dispatch is not the bottleneck. Decode graph capture succeeds when
  run cleanly (valid exec handle).

## Next

- The projection bottleneck is the b_reg LDS bank conflict (48.5%, the
  272-half stride gives an 8-bank column offset => 4-way conflict) plus
  activation re-reads from global per output-column block (MemUnitBusy 71%).
  Double-buffering trades occupancy for overlap and loses. Remaining levers
  are a conflict-free WMMA LDS swizzle and/or activation tiling — both
  require LDS budget the current geometry lacks (weight 25.5 KB + per-wave
  activation 32 KB already ~57 KB; full-block activation does not fit).
- Decode fusion (lead priority 2) is the next tractable lever; GEMV is 80.8%
  of decode (memory-bound), fusible norm/cast overhead ~3%.
