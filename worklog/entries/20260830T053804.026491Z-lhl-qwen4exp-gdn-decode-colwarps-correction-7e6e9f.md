# Invalidate unreachable GDN decode-colwarps route

## Summary

Invalidated the claimed GDN decode-columnwarps all-layer route. Fresh API and
kernel tracing proved that the profile env was unreachable: rows==1 executed
`qwen4_exp_gdn_decode_f32` before the selector in the rows>1 branch. The old
450-row packet therefore compared the strict decode owner to itself. Wiring
the actual column-warp path as a diagnostic made GDN recurrence slower
(2.454 -> 6.832 ms/token plus a 0.117-ms tail) and reduced full decode to
14.46-14.55 tok/s versus roughly 15.1-15.5 for the retained owner.
