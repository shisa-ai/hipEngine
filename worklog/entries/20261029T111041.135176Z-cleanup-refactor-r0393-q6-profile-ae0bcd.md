# Isolate Q6 grouped profile choice per generator and session

## Summary

Bind Q6 grouped production/strict choice to each generator and resident session
instead of writing the process environment from the gfx1100 profile binder.
This removes cross-owner arithmetic selection leakage without widening the
existing route's geometry or artifact-selection conditions.

## Changes

- Dense gfx1100 production snapshots the user's Q6 override on
  `generator.use_q6_dp4a_grouped`, default true. Strict sets false. Neither
  writes `HIPENGINE_C8_Q6_DP4A_GROUPED`; other profile axes are unchanged.
- `_configure_session` carries that owner choice into every new/reused resident
  session. The runner's eligibility helper accepts it explicitly; unspecified
  standalone sessions retain environment-based diagnostic control.
- Keep backend, physical C8, model/file-type and kernel row/geometry/resource
  conditions unchanged. Registered strict primitive and direct diagnostics
  remain available; no arithmetic or default-eligibility promotion.
- Update profile/session tests to bind simultaneous strict/production owners,
  opposite ambient values, user override snapshotting, and reconfiguration.
  Update ENVS and narrow R0393 to the still-open identity/plugin policy.
