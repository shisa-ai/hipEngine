# Retain Qwen3.8 serial Q/K postprocess contraction

## Summary

Retain one exact gfx1151 serial full-attention composite that consumes packed
BF16 Q/gate and BF16 K directly, preserves the established FP32 head RMSNorm
and partial-RoPE trees, and copies gate BF16 bits. It removes **32
launches/token (726 -> 694)** and halves the complete 4K Q/K postprocess span
**0.214228 -> 0.106899 ms/token (-50.100%)**.

## Changes

- Added the registered
  `split_qgate+head_rmsnorm+partial_rotary/gguf_f32_weight/qwen35_position_qk_bf16_f32`
  composite and kept the split, cast, and F32-input head primitives as the
  complete fallback.
- Added a gfx1151 capability only for serial `(rows,Q,KV,D)=(1,24,4,256)`.
  Qwen3.5-0.8B, prefill, native verifier rows, shape misses, and peer backends
  retain the primitive chain.
- Added a cached capability/registry resolver to the GGUF runner; engine/model
  code contains no backend or quant branch.
- Added RED/GREEN route, BF16/F32 bit-identity, and CPU KL/top-1 coverage.
- Published the compact artifact and updated the campaign, kernel catalog,
  benchmark rollup, and changelog.
