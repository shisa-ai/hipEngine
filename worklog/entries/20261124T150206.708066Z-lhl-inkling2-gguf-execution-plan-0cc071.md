# Add the Inkling prompt budget, depth attention and remaining prefill strategies

## Summary

This unit follows the [decode budget entry](20261124T144739.251742Z-lhl-inkling2-gguf-execution-plan-2982c8.md) and covers what it left out. Prompt processing is the wider gap in the pinned Strix pair: first text arrives 19 times later at 575 tokens and 4.3 times later at 47, and at 575 tokens it is 53% of the end-to-end gap. Three facts govern the prompt side on Strix Halo. Cost is paid per block-visit, 432 of them for 575 tokens. 64-row blocks re-read 277 GB of weights for that prompt, about 1.2 s at the read reference and more than twice Loom's whole prefill. Each kernel family sits far from either hardware limit. Decode attention is also a matched-cell cost: token time rises 30% between 47 and 575 input tokens where Loom's rises 6%, and the split score and value kernels read K/V at about 9 GB/s at 2,057 tokens. Counting every visited tensor, Loom's ordinary decode uses about three quarters of the Strix weight-stream floor, so prompt processing is the only part with several-fold headroom over it.

## Changes

- [GGUF implementation plan](../../docs/campaigns/INKLING2-MINI-GGUF-EXECUTION.md): new "Prompt budget" section with the end-to-end split of both matched cells, cost per block-visit, weight re-reads by block width, the compute floor from tensor shapes, where today's kernels sit, and where a win over Loom is possible. ## Validation

- Byte and traffic figures for the mainline file, from the repository root, CPU only:

  ```bash
  PYTHONPATH=. .venv/bin/python - "$MODEL" <<'PY'
  import sys
  from hipengine.loading.gguf import scan_gguf
  t = {x.name: x for x in scan_gguf(sys.argv[1]).tensors}
  core = list(range(6, 18))
  plan = [*range(6), *core * 3, *range(18, 24)]
  def layer(L): return [(n, x) for n, x in t.items() if n.startswith(f'blk.{L}.')]
  ctrl = sum(2 * x.nbytes for n, x in t.items() if n.startswith('blk.') and 'loop_' in n)
  exp = sum(x.nbytes * 8 / 128 for L in plan for n, x in layer(L) if '_exps' in n)
  dense = sum(x.nbytes for L in plan for n, x in layer(L) if '_exps' not in n and 'loop_' not in n)
  head = t['output.weight'].nbytes * 200058 / 201024
  bank = {L: sum(x.nbytes for n, x in layer(L) if '_exps' in n) for L in set(plan)}
  other = {L: sum(x.nbytes for n, x in layer(L) if '_exps' not in n) for L in set(plan)}
  print('GB per token: experts %.3f dense %.3f controllers %.3f head %.3f total %.3f'
        % (exp / 1e9, dense / 1e9, ctrl / 1e9, head / 1e9, (exp + dense + ctrl + head) / 1e9))
  for T, W in ((575, 64), (575, 128), (575, 256), (575, 512), (575, 575), (8192, 64), (8192, 1024)):
      frac = 1 - (127 / 128) ** (8 * min(W, T))
      e = sum(bank[L] for L in plan) * frac * -(-T // W)
      d = sum(other[L] for L in plan) * -(-T // W)
      print('T=%d W=%d: experts %.1f GB, all %.1f GB, %.3f s at 221 GB/s' % (T, W, e / 1e9, (e + d) / 1e9, (e + d) / 221e9))
  PY
  ```
