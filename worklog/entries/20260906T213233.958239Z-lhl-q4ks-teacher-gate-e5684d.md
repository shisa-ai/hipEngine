# Q4_K_S INT8 teacher-gated: no-mirror route passes both suites

## Summary

The Packet 3 teacher-gating item is complete for both quants on the XTX.
Q4_K_M was already qualified and promoted (2026-08-15/16 complete 512/8 and
4K/16 teacher suites). Q4_K_S had no retained KV capability evidence, and
the first gate attempt exposed why that matters: the runtime-layer session
fail-closed to a **mirrored fallback** — a 48 MiB persistent BF16 KV mirror
(16 layers x 3 pages x 1 MiB) whose logits are trivially identical to the
teacher because attention reads BF16 values, not INT8 dequant. A KL-0.0
"pass" through that route gates nothing.

To exercise the real compact route for an artifact without retained plugin
evidence, the mixed-KV suite gained an opt-in
`--diagnostic-kv-capability` injection that passes exactly the mapping
`_qualified_no_mirror_int8_capability` accepts, recorded as
`diagnostic_kv_capability_injection: true` in the payload (default behavior
unchanged; 7 existing suite tests pass). With the injection:

- 512/8 complete suite: 11/11 prompts, 99 positions, mean/max KL
  0.000101/0.001915, top-1 1.0, zero BF16 mirror, 16/16 layers INT8.
- 4K/16 complete suite: 11/11 prompts, mean/max KL 0.000132/0.008881,
  aggregate top-1 0.9893, minimum-prompt top-1 0.9412 (gate 0.90), zero
  mirror.

Both are on par with the Q4_K_M qualification numbers
(0.000113/0.002293 and 0.000146/0.014308; min-prompt top-1 100%/94.12%) —
expected, since the two files share the same attention/KV weight values and
KV INT8 quantization dominates the compared logits.

Promotion boundary: adding a Q4_K_S evidence row to the plugin tuple is the
INT8 campaign's decision under its own protocol; this run is the diagnostic
evidence for it. MTP composition acceptance/rollback tests remain blocked by
the MTP warmup bug recorded in Packet 2.
