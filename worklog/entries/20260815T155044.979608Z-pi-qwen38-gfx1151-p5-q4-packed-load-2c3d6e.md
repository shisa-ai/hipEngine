# Screen gfx1151 Q4T16 packed quant loads

## Summary

Reject packed 32-bit quant loads for the dominant Q4T16 c1 family. The sibling
is BF16-bit exact for all seven actual production roles, but regresses the
three highest-call roles and adds 1.321 ms to the call-weighted request
projection. The retained scalar-load local32 source, wrapper, and test are
restored byte-for-byte; no full-model gate is warranted.
