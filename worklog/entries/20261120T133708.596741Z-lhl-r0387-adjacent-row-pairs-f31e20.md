# Schedule compact Q4 row pairs sharing a weight tile adjacently

## Summary

The paired gate/up kernel took 15.55 ms of 39.92 ms summed kernel time in one warmed four-request decode transition. It was the largest kernel cost, not a throughput measurement.

## Changes

- Assign adjacent linear workgroup indices to the two independent row pairs reading the same weight tile. This changes neither the paired reduction nor its arithmetic. Better cache reuse is the hypothesis; cache hits were not measured.

Each arm matched all 120 measured reference outputs. The duplicate-prompt diagnostic does not meet the distinct-oracle cardinality gate.
