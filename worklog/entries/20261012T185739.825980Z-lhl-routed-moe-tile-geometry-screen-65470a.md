# Routed MoE tile geometry screen

## Summary

The focused routed-MoE screen shows a strong tile-geometry effect on the
shipped synthetic shape. At 256 rows with balanced one-row-per-expert
routing, tile16 measured 4.3494 ms gate/up and 2.8791 ms down, while tile32
measured 9.6832 ms and 6.0347 ms. With sparse two-row-per-expert routing,
tile16 measured 2.2528 ms and 1.5508 ms, while tile32 measured 4.8893 ms and
3.0619 ms. Tile16 is about 2.2x faster in both distributions. The result
supports padding/tile occupancy as a concrete expert-family lever, but it is
still a hipEngine synthetic screen and not an external-engine equivalence.
