# Qwen3.5 0.8B final cumulative semantic packet

## Summary

The final current-HEAD 18-prompt category+heldout cumulative semantic packet
passes for Qwen3.5-0.8B Q4_K_M and Q8_0 on gfx1151.  It covers unaltered
natural chat tokens and a category-derived p512 profile, each with 24 strict-
context teacher-forced decode transitions per prompt.

Current defaults pass **1794/1800 top-1 (99.667%)** with max KL **0.005930**.
Q4 current is 449/450 on both profiles; Q8 current is 448/450 on both.  Every
strict/pre/current repeat is trajectory/logit deterministic, every Conv/GDN and
live-KV state fingerprint is repeat-deterministic and finite, and all **72**
strict/current recorded-graph prompt-role trajectories exactly match same-role
eager with final top-1 100% and max KL **0.000475**.

Candidate state bytes intentionally differ from strict because accepted GDN and
WMMA routes reassociate arithmetic; strict state is exact on 36/36 profile
prompts and candidate state is exact on 0/72 while remaining deterministic and
finite.  Current free-running trajectories match strict on 66/72 profile
prompts; the binding comparison is teacher-forced on the strict token context,
so those expected greedy divergences do not invalidate the gate.
