# Retain Qwen3.6 wide weight arena

## Summary

Retained a model/file-type-scoped 80-MiB immutable-weight arena cutoff for the
Qwen3.6-27B private-c1 gfx1100 route. It is the first metadata inventory
crossover that captures every non-head allocation: physical weight owners fall
370 -> 2 and the standard XTX 512/128 process peak falls 16.171 -> 16.095 GiB
(-77.840 MiB) with exact output and neutral 731.185/33.525 tok/s. Memory remains
0.405 GiB above the Vulkan ceiling.

## Changes

- Extended the existing package policy value with `max_allocation_bytes` and
  propagated it explicitly from session admission through the full-stack runner
  to the fail-closed materializer. Peer models/backends retain the 16-MiB
  default, and the existing disable-only environment seam remains.
- Selected 80 MiB from metadata rather than timing: 64 MiB leaves 33 dedicated
  owners; 80 MiB captures the next complete family and leaves only the
  1,042,944,000-byte untied head. Larger cutoffs below the head capture nothing.
- Added exact actual-model inventory coverage and updated the campaign,
  benchmark rollup/changelog, refactor ledger, and compact artifact.

## Validation

- RED: focused policy import failed before the new resolver existed. GREEN:
  host-policy/propagation, actual materialization inventory, and runtime
  residency bundle reports 29 passed.
- Actual 80-MiB plan/runtime: 849 selected allocations, 15,363,373,056 requested
  bytes, 15,364,018,176-byte owner, unchanged 645,120-byte padding, one
  1,042,944,000-byte dedicated owner, and two physical owners total.
- XTX 512/1 cold process is finite/exact at logit 24.801517/token 9707; peak
  delta improves 16.138 -> 15.964 GiB and teardown returns within 2 MiB of idle.
- XTX 512/128 r3 is exact at logit 24.123718/token 9707 each reset, zero native
  fallback, prefill 710.251/731.889/731.185 (median 731.185), decode
  33.576/33.525/33.516 (median 33.525), tracked 15.605 GiB, and 5-ms whole-card
  peak delta 16.095 GiB. The prior 16-MiB route measured 16.171 GiB.

  with exact three-reset output in both processes. This qualifies this arena
