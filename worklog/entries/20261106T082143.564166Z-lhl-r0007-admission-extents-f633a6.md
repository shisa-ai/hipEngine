# Validate batch admission extents before reservation

## Summary

Batch admission now validates optional position extents identically in static
and pooled layouts before reserving blocks or resetting state.

## Changes

- Reject booleans, nonintegral values and nonpositive extents instead of silently
  truncating them or ignoring them in static layouts.
- Enforce max_positions before pooled block rounding as well as static admission.
- Preserve implicit static full-window admission when positions is omitted.

## Validation

- RED: six of eight new invalid-extent cases failed; static admission accepted
  invalid inputs and pooled float/bool inputs reached mapping after truncation.
- GREEN: runner, AR decode/capacity and mixed-serving lifecycle files: 97 passed
  using `uv run pytest -o addopts='' -q` with those explicit file targets.
- Each invalid-extent test checks that ownership, free blocks and page tables
  remain unchanged. No device/public inference claim; HIP unavailable locally.
