# Add counted non-GR Q8 diagnostic gate

## Summary

Add a canonical-depth diagnostic that excludes generic Q8 IU8 during GR
reads while leaving non-GR generic projections enabled. No production path
or mathematical implementation changes.

## Changes

- New qwen4exp_dense_q8_nongr_gate.py wraps the existing full depth gate.
  It temporarily disables the generic selector within the GR read call,
  restores environment/function on failure and records actual read counts.
- The underlying dispatch cache includes the generic selector bit, so
  strict and candidate entries remain distinct. The full-matrix result
  must have6912 excluded reads and21744 IU8 calls without a GR-down shape.
- This is a single-threaded diagnostic, never a performance policy.
