# Freeze Generation-2 KV backend host contracts

## Summary

Freezes the format-neutral host ownership seam required by
`docs/CONCURRENCY2.md` before dense no-mirror INT8 is wired into the
Generation-2 scheduler. The unit is additive and CPU-only: it does not modify
the existing scheduler, server, GGUF runner, kernel family, pool implementation,
or high-conflict architecture documents.

## Changes

- Added immutable `KVBackendSpec`, pool plan/spec, named resource claim/delta,
  lease, storage-plane/view, and `KVBatchView` value objects.
- Added a runtime-checkable `KVCacheBackend` protocol matching the Generation-2
  scheduler-facing lifecycle without codec-specific fields or byte formulas.
- Added a deterministic multi-pool `ResourceLedger` with atomic provisional
  reserve, commit, rollback, release, signed committed deltas, operation-ID
  ownership, exact/bounded confidence handling, pooled multi-lifetime claims,
  and conservation snapshots.
- Added fake BF16-shaped and INT8 payload+scale-shaped backend contract tests;
  both implement the same host protocol while declaring different pool plans.
- Added injected-failure coverage at every claim boundary, malformed request/
  release metadata atomicity, and a deterministic 500-step randomized
  reserve/commit/adjust/release lifecycle.
