## Re-assessment (three-failed-candidates rule)

The state machine has recorded three consecutive failures
(iterations 15-era close, 16, 17 — reverts=3), which triggers the
campaign rule: re-profile (done — this iteration) before further
variants, then reassess whether a supported win remains.

**Assessment: a supported, well-specified win remains.**

- The pack8 decode kernels register `bf16_bf16_out` symbols
  (e.g. `..._selected_dual_pack8_gemv_decode_compact_bf16_bf16_out`),
  i.e. bf16-truncated outputs, while the default dense decode path uses
  the family's `_f32_out` variants (`gguf_q5_k_..._gemv_decode_bf16_f32_out`
  naming exists in-tree).
- bf16 per-token logit truncutation matches the failure signature
  exactly: extreme-tail kl_max (2.447) and 32/1023 top-1 flips with a
  much smaller kl_mean — truncation noise flips near-ties.
- Fix-shaped iteration-18 candidate: an f32-out pack8 decode symbol +
  registration + wire-up in `gguf_linear.py`'s `HIPENGINE_GGUF_GEMV_DECODE`
  switch, validated against the frozen teacher-forced gate as oracle.

If the f32-out variant passes the gate, the compact route gets its
first clean two-env evaluation; the perf thesis is separate and still
weak (combined candidate measured 23.2045 vs 23.1326 default, inside
