- Clean (non-profiled) and profiler-instrumented walls agree to ~1-2 ms at each
  width, so the reconciliation is not an artifact of one instrument.
- Non-kernel residual (clean wall − kernel sum): c1 5.26 ms, c4 4.61 ms,
  c8 6.84 ms. It is roughly constant as width grows (755 → 839 → 872 kernels),
  so it is a **fixed per-step overhead** (graph-replay launch + host layer loop +
  marker sync), **not host dispatch cost scaling with launch count**. Per the
  conditional queue, dispatch/sync is therefore NOT the primary target.
- Steady-state H2D/D2H = 0 copies and manifest synchronizations = 0, scalar
  fallbacks = 0; the residual cannot be attributed to data movement or sync.
- Multi-stream kernel overlap prevents a per-kernel gap decomposition; the
  total residual (wall − kernel sum) is the sound upper bound and it is small.
