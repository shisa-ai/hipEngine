# Bulk-prefill NaN localized on gfx1100: layer 3 first nonfinite, token-by-token clean

## Summary

The INT64_MAX probe sentinel from entry 9f4a1c is downstream masking: the
single-device resident runner's **bulk prefill** route produces NaN on the
gfx1100 lane, starting at layer 3 (one nonfinite lane of 5120, propagating to
~2046/5120 by layer 63 and to an all-NaN final hidden row; the head then

the same harness). Prior bulk-prefill evidence (DFlash2 row-8 regression,
