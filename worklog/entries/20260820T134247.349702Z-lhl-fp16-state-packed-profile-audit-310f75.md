# Add packed c4/c8 fp16-state profile audit

## Summary

Added the missing c>N numerical/determinism/isolation adapter for the R2 FP16
recurrent-state route. The earlier 450-row adapter is intentionally c1-only;
this companion runs the actual packed segmented-prefill and indexed-singleton
decode path at c4/c8 against FP32 state on the same production route and
physical schedule.

## Changes

- New `scripts/execution_profile_gguf_fp16_state_batch_gate.py`:
  - complete prompt+heldout suite at static c4 and c8;
  - category-diverse 512-token c8 prompts to stress per-token FP16 state
    round-trips in packed segmented prefill;
  - c8->c4->c2->c1 retirement transitions;
  - sparse physical-c8 active slots `(0,2,5,7)`;
  - same-width neighbor substitution and row-permutation isolation;
  - three exact candidate repeats, calibrated full-vocabulary strict-teacher
    mean/tail/max KL and top-1 by category/shape/transition;
  - explicit manifest requirement that every c>N decode uses
    `indexed_batch`/`indexed_singleton` rather than the segments fallback.
- The adapter freezes state dtype at runner construction, runs strict FP32 and
  candidate FP16 in separate resident stacks, and teacher-forces candidate rows
  onto the corresponding same-width FP32 trajectory.
- The artifact deliberately sets `profile_qualification_claim=false`: this is
  the missing packed-route numerical/control capture, not a substitute for a
  runtime-resolved profile manifest, BF16-relative/task scores, or the serving
  SLO-goodput packet.
- Added CPU unit coverage for matrix construction, 512-token prompt expansion,
  trajectory exactness, indexed-manifest enforcement, and logit validation.
