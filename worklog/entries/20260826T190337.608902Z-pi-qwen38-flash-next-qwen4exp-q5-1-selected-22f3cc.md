# Add Qwen4Exp Q5_1 selected expert kernel

## Summary

Added byte-neutral raw GGUF Q5_1 selected-expert GEMV so Unsloth's requested
UD-Q4_K_XL artifact is not blocked by its 43 Q5_1 expert-down tensors. The
local standard Q4_K_M path may use Q5_K and keeps existing kernels.

## Changes

- Added one in-tree BF16-input/BF16-output raw Q5_1 selected projection with
  explicit selected expert IDs and generic E/K/N geometry.
- Dequantizes GGML's 24-byte/32-value Q5_1 blocks (`d*q + m`) in the GEMV and
  registers a strict `moe_linear/gguf_q5_1` variant for gfx11 peers.

## Validation

- GREEN: `uv run pytest -q tests/test_qwen4_exp_q5_1_selected.py` -> `2 passed`
  on Radeon 8060S/gfx1151, including first JIT build.

  array-exact vs hipEngine's independent CPU Q5_1 dequant+GEMV oracle.
- New in-tree code; no external kernel body copied and the manifest lineage
  blocker remains as previously recorded.
