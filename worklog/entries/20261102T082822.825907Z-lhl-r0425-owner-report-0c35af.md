# Retire global profile conflicts in favor of owner reports

## Summary

Replace process-global pre-binder conflict diagnostics with a binding-time report
on each generator and runner. Route policies and arithmetic are unchanged.

## Changes

- `profile_ignored_overrides(owner)` returns a detached map of ignored ambient
  values and final bound selections. Rebinding replaces only that owner's report;
  late runners inherit detached copies. Recovery's intermediate selections cannot
  leave misleading entries when the final selection matches the ambient input.
- Remove global conflict/suppression maps, warnings and error policy. Keep
  explicit owner-scope diagnostics and direct/unbound compatibility fallbacks.
- Migrate profile and ownership tests to assert the owner report. Repair an
  existing layer-2 test double missing the three migrated Q4 fields; this is a
  test-only repair, not a new production route.
- Update environment and execution-profile references. Remove completed R0425
  from the unfinished ledger; move its remaining direct/unbound fallback inventory
  into R0149, preserving those cleanup requirements without retaining the completed
  profile-binding history.
- Repair six older batch capture-key test files to include the already-shipped
  plane count, risk multiplier and Q5_K selection. Unbound multiplier is 4.0,
  distinct from the profile-bound 1.0; no production defaults changed.
