# Extract GGUF decode-batch full-attention owner

## Summary

Moved the attention half of `_run_full_attention_decode_batch_layer_rows` into
`hipengine/runtime/qwen35_gguf_full_attention_decode_batch.py`. The runner method
is now an adapter that builds explicit view/selector records, calls the owner,
then calls the existing output and post-attention FFN owners.

The split-workspace provider is a caller-owned selected-operation closure. It
re-reads the current workspace fields on every call, so a replacement or grown
workspace is visible without the owner holding a scratch/session proxy. The Q8
triple-DP4A closures bind `scratch` on the adapter side; the owner never receives
a scratch object.
