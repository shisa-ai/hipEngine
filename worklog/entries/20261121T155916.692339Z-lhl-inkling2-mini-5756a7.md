# Collapse static Inkling prompt convolution launches

## Summary

Committed Inkling text prefill now launches static output convolution once per visit, projection, and prompt block rather than once per row. The batched path is bitwise equal to the scalar recurrence.

## Changes

- Keep one thread per channel and process rows in causal order. In-place attention and expert output buffers retain their existing owners, with no extra device allocation. One-row decode and journaled provisional blocks still use scalar launches; the latter must snapshot state separately for each possible accepted prefix.
- The existing K/V short convolution still runs per row; it is a separate transfer and state path.
