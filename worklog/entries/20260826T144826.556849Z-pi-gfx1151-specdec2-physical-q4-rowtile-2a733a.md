# Screen gfx1151 physical Q4 rowtiles

## Summary

The merged gfx1100 R6 rowtile result transfers as a strong gfx1151 mechanism
premise but not as a strict route. A cache-only actual-weight screen on the idle
stable gfx1151 host found the existing generic rowtile 3.87x-9.85x faster than
the shipped Q4T16 physical selector across all seven Qwen3.8 Q4_K_M shapes at
R6/R8. It changes 10.2%-11.2% of BF16 output elements, bounded to
0.001953125-0.0078125 absolute, so it is rejected for strict dispatch.

The mismatch localized the opportunity to padding rather than data format. A
new strict one-wave/one-16-row-tile WMMA sibling preserves the shipped
K16/FP16-WMMA/FP32-accumulator/BF16-store schedule and passes exact parent/CPU
RED/GREEN coverage at R6/R8/R12/R16. A clean actual-weight screen retains it on
gfx1151 for six standard-Q4 shapes where every width wins; narrow K/V remains
on shared-B and all peers/misses keep their source registrations.
