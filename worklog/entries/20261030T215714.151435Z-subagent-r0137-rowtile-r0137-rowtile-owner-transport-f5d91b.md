# R0137 rowtile owner transport

## Summary

Migrated the Qwen3.5 dense gfx1151 production verifier-Q4 rowtile decision from
the profile binder's process-global environment write to an explicit generator
field frozen on each resident session. Strict and production generators bound
before their sessions are created no longer overwrite each other's choice.
`LLM` construction is lazy; a public call such as `LLM.tokenize()` materializes
its engine service and may eagerly prepare sessions. Direct generator users can
bind both profiles before either creates a session. Both lifetimes must preserve
the owner decision.

## Changes

- `hipengine/generation/qwen35_dense_gfx1151_profiles.py`: the binder now sets
  `generator.target_verifier_production_q4_rowtile`; only the
  `HIPENGINE_GGUF_VERIFY_PRODUCTION_Q4_ROWTILE` environment write was removed.
- `hipengine/generation/qwen35_gguf.py`: added the typed generator field and a
  session-kwargs helper; passed the decision to every shared/direct/native/MTP
  session constructor, `_configure_session`, and the dense NextN provider.
- `hipengine/runtime/qwen35_gguf_runner.py`: added the session field and a
  resolver that uses the owner value when present and the ambient diagnostic
  environment only for unbound/direct sessions. The existing ContextVar scope
  and hot dispatch are unchanged.
- `hipengine/runtime/qwen35_gguf_nextn.py`: forwarded the decision through the
  NextN executor to its batch session.
- `tests/test_unit_qwen35_dense_gfx1151_profiles.py`: added construction-order,
  ambient-override, unbound-fallback, shared/direct session transport, and NextN
  transport coverage.
