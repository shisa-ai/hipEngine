# Qualify sequential PARO verifier evaluator on XTX

## Summary

The full-logit verifier evaluator is now tractable: strict capture and fast replay run sequentially, so only one 35B target session is resident at a time. An independent RX 7900 XTX gfx1100 D8 smoke completed and passed. This qualifies the harness mechanics only; it is not transferable W7900 production evidence.

## Changes

- Added `run_sequential()` and made it the CLI owner.
- Strict capture records proposals, full verifier logits, commit rows/positions, bonuses, and contexts.
- Fast replay consumes that immutable strict schedule, compares aligned full-vocabulary rows, and repairs any candidate-selected commit row back to the strict owner before the next cycle.
- Forced fused verifier LM head off during evaluation so full logits are materialized, and read `verify_lm_logits` rather than unrelated batch-decode logits.
- Added setup/replay progress markers and a focused verify-buffer ownership test.

## Validation

- sequential strict capture: 4 cycles;
- aligned rows: 8;
- mean/p95/p99/max KL: `9.73e-7 / 4.15e-6 / 5.41e-6 / 5.72e-6`;
- top-1 agreement: `100%`;
- strict/fast accept and bonus decisions: exact;
- status: `passed`;
- artifact: `benchmarks/results/2026-08-24-7900xtx-paro-fast-verifier-sequential-smoke.json`.

The first XTX attempt caught the wrong `batch_lm_logits` source; the focused test now pins `verify_lm_logits`. No W7900 qualification claim is made from this peer-GPU smoke.
