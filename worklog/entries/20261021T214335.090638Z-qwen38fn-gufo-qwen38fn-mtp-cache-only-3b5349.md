# Skip discarded MTP prompt-row outputs before final carry

## Summary

The lead directed implementation progress rather than further baseline expansion.
The existing campaign identifies scalar full-layer draft priming as discarded
work: each prompt row consumes the previous authoritative target hidden row,
not the predictor output from the preceding prompt row. This first bounded
increment keeps the scalar cache arithmetic and removes only unused attention
and feed-forward outputs. Batched projections remain a separate unfinished
part of MTP-PREFILL.

The candidate lives in a separate worktree so the already-running ordered MTP
baseline keeps its source unchanged. No expanded prepared or serving matrix is
launched before this implementation's focused validation.

## Changes

- Add a `cache_only` operation mode to the existing scalar QSA mixer, QSA layer
  and draft forward. It still projects Q/K/V, appends raw index keys,
  applies the existing rotary transform, and writes KV through `KVLiveSpans`.
  It omits sparse query selection, attention, output projection and MoE. The
  final full row prepares any newly required pooled index blocks.
- Use this mode for all but the last row of each prompt chunk. The last row
  keeps the complete layer and refreshes hidden carry. Each row still checks
  cancellation before mutation; shifted target seeds and chunk boundaries are
  unchanged. Normal proposals and accepted-token catch-up keep the full path.
- Do not change kernels, arithmetic, allocation sizes, execution profiles or
  environment defaults. The mode is an internal operation contract, not a
  rollout flag. The existing full scalar `forward(run_head=False)` is the
  independent oracle for this increment.
- Fix the existing QSA index restore cursor: preserve at most the already
  initialized pooled blocks, rather than declaring every complete raw-key block
  initialized. Dense execution has not prepared those blocks. Sparse selection
  now builds the missing blocks after a trim or restore.
- Mechanism reference: Gufo `fec4759d` predictor KV-only prompt construction,
  already mapped by the campaign. No external implementation was copied.

  stateful graph ownership and verifier body boundaries.

  cache-only, chunk and prefix-cache tests pass after the repair.
