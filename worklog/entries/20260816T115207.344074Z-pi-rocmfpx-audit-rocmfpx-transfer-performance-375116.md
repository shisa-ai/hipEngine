# Review transferable ROCmFPX performance mechanisms

## Summary

Audited `/home/lhl/ROCmFPX` read-only at
`0d313da1849f73c5a7f8c5f7e5b8d7d278fbb69d` strictly as a mechanism source.
hipEngine should not adopt ROCmFPX formats, ROCmFP4/FPX kernels, or its runtime.
Most transferable ideas are already represented more directly in hipEngine.
The remaining high-value direction is a real small-M quantized matrix path that
reuses streamed weights across c4/c8 or verifier rows; bounded production
arithmetic can then test one-plane Q8_1 activations as an optional accelerator.

No code was copied and no performance claim is made by this source review.
ROCmFPX and upstream measurements nominate experiments only; their hardware,
model, format, runtime, and workload scopes do not transfer to hipEngine.

### Ranked in-tree experiment queue

The value estimates below are inferred screening ranges, not performance
claims. Advance only when a fresh profile assigns enough complete wall to the
affected family for at least a 1% request-level win.

| Rank | Experiment and hypothesis | Affected regime / likely value | Required gate | Stop rule |
| ---: | --- | --- | --- | --- |
| 1 | **True small-M weight reuse at c4/c8 and verifier width.** Reuse existing T16/pack8 bytes once across activation rows instead of running row-parallel GEMV. Start with BF16/FP16 activations; route by actual routed rows through `(backend, layer, quant, variant)`. | c4/c8 continuous batching and B2-B5 target verify; highest structural upside. A 5–20% projection-family screen, plausibly 3–8% complete c>N if the family is first-order, is worth testing. | T0 parent parity if association can remain identical; otherwise T2 strict-teacher mean/tail/max KL, category top-1, state/isolation, determinism, task quality, expected-symbol trace, and exact fallback. | Stop if the current profile assigns <15% complete wall, weights are still re-read per row, c4/c8 leaf gain is <5%, VGPR/LDS occupancy erases reuse, or projected complete gain is <1%. |
| 2 | **One-plane Q8_1 activation plus `sudot4`/integer MMQ.** Once rank 1 has an exact ceiling, replace BF16/FP16 activation fragments with one packed Q8_1 plane using existing in-tree producers/consumers. | Same small-M regimes; medium-high arithmetic upside but high quality risk. Screen for 5–15% projection-family and >=1% complete improvement; do not start at c1. | T1/T2 same-artifact production gate: mean/p95/p99/max KL, every category/shape top-1, repeat determinism, neighbor isolation, task quality, and BF16-relative report where available. Strict keeps the current BF16/FP16 or residual-Q8_1x2 route. | Stop immediately on control/state failure. Reject a role/shape on any binding quality failure. Add a residual plane only if its measured consumer remains faster than rank 1's exact control; prior Laguna evidence says blind repair is uneconomic. |
| 3 | **Measured compound epilogue or rounded-boundary removal.** Fuse a profiled scale, SiLU, residual, or output conversion and allow production to avoid an otherwise strict BF16 round trip. | c1 and c>N projection/glue paths; medium, usually 1–3% complete only when a launch/store-load boundary is visible. | T2 operation-complete strict-teacher and task gate, finite/NaN/Inf checks, graph/eager repeat, expected launch-count reduction, registered strict unfused chain. | Stop if no complete operation disappears, the profile ceiling is <1%, the fused kernel adds enough registers to regress its producer, or complete wall does not improve in paired runs. |
| 4 | **Selective unsafe-math code object.** Compile only one measured transcendental/reduction family with `-funsafe-math-optimizations`; keep explicit IEEE masking sentinels and hash flags into the variant manifest. | Exp/SiLU/softmax/GDN only if profiled; low-medium and likely <1–3% complete. Never blanket-enable. | T1/T2 strict-teacher tails, long-context state checks, NaN/Inf/masked-row fixtures, deterministic repeats, compiler/version/flag provenance, strict object fallback. | Stop if disassembly/resources and leaf time are unchanged, projected complete gain is <1%, any finite/masking fixture fails, or benefit exists only with `-ffast-math`/finite-math assumptions. |
| 5 | **Adaptive MTP admission and depth, separate T3 campaign.** Select static graph buckets from measured complete-cycle cost, per-position acceptance, context, occupancy, and expected continuation length; compare against the best fixed-depth policy. | Request/SLO economics rather than kernel arithmetic; potentially high avoidance of MTP-negative requests, but no honest fixed speed estimate before a full-suite sweep. | True AR denominator, complete proposal+verify+accept+commit+scheduler wall, full category/heldout suite, CPU/GPU transaction parity, greedy AR output equality, deterministic benchmark policy, and task quality. | Stop if it cannot beat the best static depth on heldouts/SLO goodput, causes any category regression, learns from prompt/token IDs, requires random exploration during measurement, or uses acceptance ratio without complete-cycle cost. |

Rank 2 is the main production-numerics opportunity suggested by ROCmFPX, but it
must follow rank 1: otherwise activation quantization can hide the fact that the
kernel never achieved actual weight reuse. Rank 5 is useful product work but is
not authorized by the `production` arithmetic profile.

### Already implemented; do not rediscover

- T16/X8/pack8 canonical resident layouts and load-time preprocessing.
- BF16-to-Q8_1 and residual-Q8_1x2 packers, `sudot4`, integer-WMMA probes, and
  selected/dense DP4A consumers.
- Dense and selected WMMA prefill, compact routed rows, activation-source maps,
  shared gate/up activation loading, and per-shape tile policies.
- Fused gate/up+SiLU, down+residual, shared-expert combine, router/top-k, GDN
  state publication, graph replay, and native proposal/verify/accept cycles.
- Paged attention/KV paths that avoid materializing an entire cache view.
