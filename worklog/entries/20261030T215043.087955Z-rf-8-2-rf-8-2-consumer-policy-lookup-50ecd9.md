# RF-8.2 backend wrapper policy lookup via declared owners

## Summary

The 83 policy names that gfx1151 backend wrapper functions read are now
resolved through the RF-8.1 declared-owner reader at each operand, exactly
where the committed code read the module global. There is no eager snapshot:
a setting in a branch that is not reached is never read, so an absent
later-branch setting cannot fail an earlier branch. The alias block and
`__all__` are still present and unchanged.

## Changes

- `hipengine/kernels/backends.py`: the package-first / declared-owner /
  default logic is factored into `backend_package_capability_from_module`, and
  `backend_package_capability` delegates to it after its existing key check and
  import. Behavior is unchanged.
- `hipengine/kernels/hip_gfx1151/__init__.py`: `_SELF` plus
  `_capability(name)` (package binding first, then the declared owners in
  declaration order, then `NameError`). Each policy operand in the 7 GGUF
  prefill/GEMV wrappers and in `register_gfx1151_kernels` is a direct
  `_capability("NAME")` call: 264 operand reads over 83 distinct names. The
  committed short-circuit expressions are otherwise untouched; no local
  snapshot, proxy, persistent value cache, or second registry was added. No
  alias, `__all__`, signature, or kernel callee changed.
- Tests (`tests/test_unit_gfx1151_policy_capability_gguf_boundary.py`):
  `_capability` package/owner/`NameError` contract; the factored reader agrees
  with `backend_package_capability`; explicit package `False` disables its
  band and `None` is read as `None` (TypeError on comparison); a replaced
  shape set swaps the admitted shape into and out of the small-M band; owner
  mutation is visible on the next call with the package binding absent; all 7
  wrappers dispatch identically with every package alias deleted in-process;
  the registrar snapshot is identical with `BACKEND`/`STAGED_F32_VARIANT`
  deleted; a later-branch setting deleted from the package and all three
  owners does not affect an earlier branch but still raises when a branch that
  reads it is reached; and repeated reads of the same name in one call all
  return the same value.

## Measurement

  `_capability("NAME")` replaced by `NAME` is byte-identical to `HEAD`. This is
  the committed short-circuit expression, with only the read site changed.
  The only new function is `_capability`; nothing was removed. The
  module-level diff is `import sys`, the expanded `backends` import, and
  `_SELF`/`_capability`.
