# Close c8 production transport A/B

## Summary

Closed the submission-mechanism branch of #37 through the actual production
owner. A six-process counterbalanced clean packet measures HIP graph at
58.932 ms median and native PM4 at 57.966 ms, a -0.966 ms / -1.640% isolated
steady-transition improvement. All runs produced the same eight 32-token rows,
used one physical packed c8 group, and drained all requests.

Direct AQL is rejected: it removes HIP graph's three ~11.5 ms mid-replay trace
gaps but adds a 12.563 ms interval before the first kernel, reduces overlap, and
regresses profiled wall from 60.429 to 62.685 ms. PM4 inner kernels are nested
in one IB and therefore invisible to rocprofv3; only complete wall and native
transport/lifecycle provenance are claimed.

The key decision is negative but important: the 44.713 ms HIP-graph interval
without a visible kernel is not recoverable overhead. Exact transport A/B finds
about 1 ms steady-step headroom, so projection family traffic/issue/occupancy
counters return to the top of the #37 queue.
