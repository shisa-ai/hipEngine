# Qualify integrated DMS c1 capacity at 128K and 256K

## Summary

Retained the first full-model explicit-c1 no-shadow decode capacity evidence for
the exact Qwen3.8-27B Q4_K_M artifact and trained schema-v2 sidecar on the
exclusive gfx1151 `zbook` lane. Both 128K and exact-limit 256K runs complete,
produce finite compact decode, release dense KV before decode, and return the
tracked allocator to zero. This is capacity/execution evidence only.
