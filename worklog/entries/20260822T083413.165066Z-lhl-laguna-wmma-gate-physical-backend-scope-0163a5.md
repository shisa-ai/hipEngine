# Scope Laguna WMMA gate to physical gfx1151

## Summary

Resolved task #30 as a test-scope bug, not a gfx1100 arithmetic change. The
failing `test_laguna_global_gqa2_vstage64_matches_cpu_with_eviction` is a
physical gfx1151 Laguna global-GQA2/WMMA qualification fixture: it allocates the
`hip_gfx1151` backend and the WMMA primitive was admitted from a cache-only
Radeon 8060S artifact. The shared-source test had only a generic HIP guard, so
it executed on the current W7900/gfx1100 host and failed 21/6144 near-zero gated
BF16 comparisons (max violating absolute delta 1.5259e-4).

Do not weaken the numerical tolerance or modify the kernel from the wrong
physical backend. Scope the gate to detected physical gfx1151; it remains live
for task #50's later backend pass. This removes a false gfx1100/main merge
blocker without claiming gfx1151 correctness.

- Changed only the Laguna global GQA2/WMMA eviction gate to skip unless a
  physical gfx1151 is visible.
- Removed one pre-existing unused import in the same test-local import block.
