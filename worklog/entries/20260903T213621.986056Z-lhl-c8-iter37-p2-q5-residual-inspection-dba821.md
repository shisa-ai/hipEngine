# C8 iter37: Q5 residual inspection — both owners ~30 GB/s, schedule-bound, direct-load dp4a axis live

## Summary

Applied the P4 inspection method (offline ELF + resource metadata audit) to
the two retained Q5 MMQ owners behind the C8-P2 residual
(**7.280 ms/cycle** of the original 11.392 ms/cycle peer target still open;
pool realized 15.052→10.940).

Built both production binaries from their exact planner commands
(raw: plain `-O3`; source: `-funsafe-math-optimizations -ffast-math
-fno-finite-math-only`), extracted the gfx1100 device ELFs from the
`.hip_fatbin` sections, and read `NT_AMDGPU_METADATA` plus disassembled
bodies:

| owner (variant) | VGPR | SGPR | LDS | spill | WG | body mix |
| --- | ---: | ---: | ---: | ---: | ---: | --- |
| raw `gguf_k_raw_mmq32_q8_1_d4s4_f32_kernel<Li5,Li2>` | 46 | 28 | 5,888 B | 0 | 128 | 331 vec / 59 mem / **64 v_dot4**, s_waitcnt ×38 |
| src `gguf_q5_k_mmq_i64_j32_k256_q8_1_d4s4_f32_kernel<u16,Lb0,Li32>` | 122 | 29 | 0 B | 0 | 128 | 708 vec / 153 mem / only 16 v_dot4; 67 v_fmac + 64 v_cvt + 58 v_mul F32 dequant |

Findings:

1. **Effective bandwidth ≈ 30 GB/s in both owners.** Pool 10.940 ms/cycle
   over 48 `[5120,6144]` Q5_K weights (6.887 MB) + R32 q8_1 activations
   (0.786 MB) = 330.6 MB/weight-set/cycle → 30.2 GB/s; per-weight
   0.2297 ms (src R32 ladder: 11.025 ms/48).
2. **Not occupancy/VGPR-bound**: raw is VGPR46/zero-spill (occupancy-rich,
   ~44 waves/CU by VGPR and LDS), src is VGPR122/zero-spill (~8 waves/CU,
   same as the P4 occupancy non-binding case).
3. **The demonstrated same-regime ceiling is 101–134 GB/s** (Q6 grouped
   census + dp4a e2e family). The residual is therefore **schedule
   headroom, not a DRAM roofline** — the pool bound at those rates is
   ~2.5–3.3 ms/cycle, so the 11.392 ms/cycle peer target stays credible.
4. The raw owner already uses dp4a (64 dot4/body) but stages weight tiles
   through 5,888 B LDS with s_waitcnt chains; the src owner spends its
   issue slots on FP32 dequant arithmetic (fmac/cvt/mul) with only 16
   dot4s. Both fail to overlap weight traversal with dot work at the
   demonstrated rate.
5. **The one unexplored axis consistent with the dp4a-Q6 lesson: a
   direct-load (LDS-free) u32-record dp4a schedule at the actual R24/R32
   shapes** — Laurent's load-dot structure without the fixed-J32 206-VGPR
   geometry that was rejected, and without J16 minitiles (rejected
   both-orders). All previously tried Q5 schedule changes are closed by
   the rejected-axes record; this one is not.
