# Layer-2 Q5_K gate/up WMMA body microbench

## Summary

Microbenchmarked the layer-2 Q5_K dual gate/up (hidden=2560 in -> ffn=640 out,
512 experts) comparing the strict per-expert selected Q5_K gemv (current
default) against the existing selected Q5_K WMMA prefill body
(`gguf_q5_k_selected_wmma_prefill_compact_bf16_bf16_out`, fp16 WMMA,
production-class). The WMMA body wins decisively at sparse and wide active-row
profiles and is neutral at dense/deep. Because the real layer-2 p508 scenario
produces many tokens across a small active-expert set, the WMMA body is the
promising lever for the dominant ~397.95 ms layer-2 prefill term. It changes
arithmetic (fp16 WMMA), so any promotion still requires the full P1 production
gate; this microbench only establishes that pursuing it is worthwhile.

## Changes

- Added `scripts/gguf_q5_k_gate_up_microbench.py` (3-way diagnostic: strict
  selected gemv vs grouped WMMA gate/up on layer-2 shape).

## Validation

- `python3 scripts/gguf_q5_k_gate_up_microbench.py --repeats 15` on local
  W7900/gfx1100 (wall-clock medians, device-synchronized):

  ```
  profile   rows  strict_ms   wmma_ms strict/wmma
  sparse      16      0.617     0.160        3.85
  dense       64      1.926     1.896        1.02
  deep       256      7.008     7.511        0.93
  wide      1024     25.856    14.975        1.73
  ```

  strict/wmma > 1 means WMMA is faster. WMMA wins 3.85x at sparse and 1.73x at
  wide; roughly neutral at dense/deep. Diagnostic only, no retained claim.
