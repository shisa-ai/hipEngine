# R0523 c4 race: distributed KV corruption; projection/norm/KV-write/split-K-reduce cleared

## Summary

Continued R0523 (intermittent native c4 packed-decode divergence vs the c1 oracle,
~4-16% of reps, always a large token flip at a sensitive argmax position). All runs
eager (`HIPENGINE_GGUF_DECODE_GRAPH=0`), Qwen3.8-27B-Q4_K_M, bf16 KV, strict profile,
identical prompts across the 4 slots so slot-1-vs-slot-0 hashing is a valid oracle.
Stage-by-stage hashing narrowed the owner substantially and cleared several suspects.
The corruption is a one-time race event that then propagates through the KV/residual
feedback loop (persistent divergence from a random start step), and it is DISTRIBUTED
across full-attention layers, not fixed to layer 47.

## Validation

Measured (30-rep c4 eager bursts; artifacts `/tmp/refactor-gfx1100/r0523-*.{json,server.log.bak}`):
- Projection stage hash: slot-1 `full_k`/`full_v` (K/V GEMV out) non-deterministic; K and V
  always diverge together; slot-0 identical across reps. 100% co-occurrence with token flips.
- FORCE-SINGLE (K/V off the pack8 dual pair onto single pack8): race PERSISTS => the K/V
  projection GEMV is NOT the owner.
- attn_norm OUT hash: slot-1 diverges, but hidden-IN is ALREADY corrupt at the first
  divergence step (all reps) => attn_norm kernel is not the owner. Kernel
  `gguf_norm_fixed5120_wave256_kernel` is one-block-per-row, correct barriers, bit-identical
  to rows==1 (deterministic).
- Source-layer hash (hidden-IN at full-attn layers 3,23,43,47): first divergence at L23
  (reps 9,10) or L43 (rep 15); L23/L43/L47 diverge the SAME step, L3 later. => corruption
  originates in a layer BEFORE the first diverging full-attn layer and is distributed;
  the owner is a component shared by all full-attn layers, firing at varying layers/steps.
- KV write kernel `qwen35_write_paged_kv_mixed_value_prompt_position_tensor_kernel`: simple
  scatter, one block-y per row, distinct element per thread, no shared mem/atomics => clean.
- Packed-AR attention is split-K (`bf16_split_k_gqa_gate_bf16_batch_spans`). Reduce kernel
  launched with threads==head_dim (no early-exit-before-barrier); context kernel threads==256==head_dim
  (q_shared load in bounds); barriers correct on inspection. Not yet empirically cleared.
- Earlier falsifications still hold: Q4_K down-residual cap (do not retry) and graph-replay
  ownership (race persists eager).
