# Screen gfx1100 high-row dense-F32 alpha-beta pair

## Summary

Rejected gfx1100 production admission of the existing exact dense-F32
alpha/beta pair at physical C5-C8 B3 rows15/18/21/24. The pair cuts the C8
family from 96 to 48 launches and 2.0565 to 1.469006 ms, but the binding target
operation regresses both wall and device sum. This repeats the prior W7900
low-row failure mode, so all candidate code and tests were removed before a
full-suite spend.

## Changes

- Temporarily extended the flat pair wrapper/HIP validation through rows24 and
  admitted only `(15|18|21|24, K5120, N48+N48)` in the gfx1100 capability.
- Added RED/GREEN capability, wrapper, route/fallback, and rows24 GPU exactness
  coverage, then removed the candidate range, policy, and tests after rejection.
  The existing rows1-4 primitive remains unchanged and registered; gfx1100
  production continues to issue two singleton projections.
- Added rejection artifact
  `benchmarks/results/2026-09-02-w7900-q4km-k3-dense-f32-high-row-pair-rejected.json`
  and updated `docs/KERNELS.md` with the do-not-repeat result.

## Validation

- RED: four focused nodes failed on the absent gfx1100 capability, high-row
  wrapper range, and route. Transient GREEN: all four passed.
- W7900 rows24 GPU gate passed BF16-bit parity against both singleton
  projections plus the existing CPU KL <= 0.05 and top-1 >= 90% checks.
- Same-host C8 production-profile trace, Qwen3.8-27B Q4_K_M, K3, 8 requests x
  12 output tokens: generated IDs exactly match true AR and the control.
- Dense-F32 family: **96 -> 48 launches**, **2.056500 -> 1.469006 ms
  (-28.568%)**. Complete target marker: **173.632824 -> 173.816277 ms
  (+0.106%)**. Target kernel sum: **159.009213 -> 160.441627 ms (+0.901%)**.
  The apparent outer complete-wall change **1.367357 -> 1.351955 s** is
  uncounterbalanced/nonbinding, as in the prior low-row rejection.
- The bridge workload and profiler traces completed; its final artifact guard
  exited 2 solely because the candidate was intentionally uncommitted. Raw
  paths/hashes and the exact command are in the rejection artifact.
- Full C5-C8 gate intentionally not run because both binding operation metrics
  reject the candidate.

## Next

- Do not revisit launch-only dense-F32 alpha/beta pairing on gfx1100. Reopen
  only for a materially different bandwidth/schedule or a cross-family owner
  that improves the complete target operation.
