# Bound Qwen3.8 Q6 fused-activation decode

## Summary

Reject a fused SiLU-to-Q8 activation route for planar-Q6 FFN-down before
implementation. With Q8 production made artificially free, the best existing
t256 consumer improves only **0.993641 -> 0.990665 ms (1.00300x, 24/45
wins)** versus the **1.08087x** family speedup required for 1% current 4K
kernel-wall saving. The optimistic bound projects just **0.517 ms / 0.0400%**.

## Changes

- No source or runtime change. Reused the existing planar-qmicro Q6 Q8_1/dp4a
  consumer and moved activation quantization entirely outside warmup and timed
  regions, creating a strict upper bound for any fused gate/up-SiLU-to-Q8
  producer.
- Screened t64/t128/t256 on actual layer 0/31/63 K17408/N5120 FFN-down weights.
  The three-weight source pool is **209.180 MiB**, and every individual weight
  exceeds the 64-MiB cache contract.
- Preserved compact evidence at
  `benchmarks/results/2026-08-16-gfx1151-qwen38-27b-q6-precomputed-q8-bound-rejected.json`.

## Validation

- Four warmups, 15 counterbalanced pairs per layer, and burst eight used cached
  gfx1151 binaries. Aggregate t64/t128/t256 speedups are
  **1.00056x/0.98498x/1.00300x**; only t256 is positive on all three medians,
  and it wins just **24/45** pairs.
- All candidate outputs are finite; max KL is **1.624e-6**, max absolute
  difference is **0.0078125**, top-1 agreement is 3/3 at every geometry, and
  tracked ownership returns exactly **0 -> 0 bytes**.
- The current post-grouped profile assigns planar-Q6 **172.751809 ms** of
  **1,292.498954 ms** selected kernel wall. Applying the best optimistic ratio
  saves **0.517312 ms / 0.040024%**, 25x below the 1% gate.
- Raw t64/t128/t256 SHA-256 values are
  `184b424c55dff7283a665e92db6737c4acb7ebcded391e14d1ed4798686f5c18`,
  `483825c3151d505daf16e336f2099054f0dbac2bd3e7dfad44a30b3036038ce4`,
  and `5df6711f5c74d5185d9924906f9165bb5fbf61280d84bb5209128d773ff9fdb6`.

## Next

- Do not implement fused Q8 production for Q6 down. Its zero-cost upper bound
  misses admission, so rerank outside Q4/Q6 activation quantization and GEMV
  geometry.
