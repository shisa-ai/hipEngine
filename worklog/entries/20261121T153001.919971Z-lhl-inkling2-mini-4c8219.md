# Compare original and GGUF Inkling on W7900

## Summary

On the Radeon Pro W7900, Unsloth's `UD-Q4_K_M` in ROCm `llama.cpp` decoded 53.7% faster than the original mixed NVFP4/MXFP8 checkpoint in hipEngine for the same synthetic 512-input / 128-output text request. The GGUF stack also reached the first token sooner and used 2.71 GiB less sampled peak VRAM. This compares complete runtime/checkpoint pairs, not quantization in isolation.

## Changes

- No inference code or defaults changed. The benchmark driver and raw logs are local artifacts; this is a diagnostic, not a scoreboard row or a quality qualification.
