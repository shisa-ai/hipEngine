# Split Inkling target attention score and value passes

## Summary

Split target attention into a parallel score pass and an ordered value pass at 16 or more live cache positions. Keep tiled attention for shorter spans. Both routes preserve the FP32 reduction and recurrence order.

## Changes

- Share one lazily allocated score buffer across layer visits within the request. Use the existing FP32 `KVLiveSpans`, cache append, and rollback paths.
