# c8 down: direct ROW_TILE=8 (weight read once) replaces 2x4 split

## Summary
c8 (rows=8) was "fully rowtile" only in the sense that the down used a 2x4
split — two exact rows=4 rowtile calls that **read the down weight twice**. A
direct ROW_TILE=8 reads it **once**. The dense rowtile down GEMV was capped at
rows<=7 (the 2x4 split was the c8 path), so c8's down paid a 2x weight-read
penalty. This entry adds a native ROW_TILE=8 instantiation to the down GEMV and
switches c8's down to it. (The earlier 20260819T135018 entry's "c8 down stays
wmma" note was imprecise: c8's down was the 2x4 rowtile split, not wmma.)

## Changes
- `gguf_t16_selected_gemv.hip`: `launch_q4_dense_rowtile` rows cap 7->8 +
  CASE(8). The kernel template is generic over ROW_TILE, so ROW_TILE=8 is exact.
- `gguf_linear.py`: removed the sidecar-decode `rows==8` 2x4-split special case
  so c8's down falls through to the variant dispatch; `_q4_t16_sidecar_decode_variants`
  2..7 -> 2..8 (returns the direct rowtile variant for rows=8). gate/up already
  used ROW_TILE=8; only the down changed.

## Validation
`scripts/tmp_rowtile8_down_probe.py` (real down tiles 17408x5120, Qwen3.8-27B):
  down ROW_TILE=4: 0.1195 ms/call; 2x4 split (2x): 0.2199 ms
  down ROW_TILE=8: 0.1520 ms  ->  1.45x faster than 2x4 split
  per-step FFN down (64 layers): 14.1ms -> 9.7ms (save 4.3ms/step)

`scripts/gguf_packed_ar_bench.py --configurations native_c8 --prompt-length 128
--decode-steps 8 --warmup-runs 1 --measured-runs 2` (W7900, gfx1100):
  c8: step 116.8ms -> 111.4ms, 68.61 -> 71.86 tok/s (per-row 14.6 -> 13.9ms),
  passed=True (prefix-exact), repeatable=True. c2-c7 unchanged (change only
  touches rows=8).
