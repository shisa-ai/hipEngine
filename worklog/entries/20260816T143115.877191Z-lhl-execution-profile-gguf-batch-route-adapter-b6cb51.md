# Add GGUF batch-route profile requalification adapter

## Summary

Added a full-logit execution-profile requalification adapter for the historical
gfx1151 GGUF Q8T16 all-rowtile batch candidate. The adapter compares packed
static c4/c8, c8->c4->c2->c1 retirement, and sparse physical-c8 execution
against independent strict-c1 teacher trajectories and requires three exact
candidate repeats.

The higher-priority post-fix A4 candidate was audited first but is not runnable
on this host: its frozen protocol, source evidence, SLO thresholds, and route
all bind AMD Radeon Pro W7900/gfx1100. This machine exposes only Radeon
8060S/gfx1151. No cross-hardware transfer or inferred A4 verdict is made.

## Changes

- Added `scripts/execution_profile_gguf_batch_route_gate.py` with strict-backend
  GDN validation, current-package denial verification, explicit candidate-env
  restoration, serial-prefill identity checks, full prompt+heldout capture,
  static and dynamic packed-state execution, sparse active masks, calibrated
  tail/top-1 attribution, repeat hashes, prompt/model/source provenance, and
  fail-closed qualification blockers.
- Added pure tests for descending width schedules and evaluator preservation of
  shape/transition attribution.
- The adapter deliberately makes no performance or runtime-profile
  qualification claim and does not fabricate the evaluator's complete exact
  control-plane, task, or BF16-relative packet.
