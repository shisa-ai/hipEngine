marker-delimited steps. Device argmax removes the explicit device synchronize
and reduces blocking copy bytes, but does not yet reduce copy call count.

## Changes

- Added the compact/full HIP ledger to the retained P5 artifact.

## Validation

Both runs use named production at manifest
`4c636c229c292d98cc91426c8e4b00dd1aa5f0bfac7900d894dca5fff4e0d866`,
with four decode-step ROCTX windows and zero tracked bytes after close.

Per token, both routes issue 28 blocking and 12 async HIP memcpy calls. Compact
changes blocking bytes from 1,024,200 to 30,928, changes the one D2H from
993,280 bytes to 8 bytes, removes one `hipDeviceSynchronize`, and adds two
argmax kernel launches. The compact roles are:

- 25 scalar H2D calls: one input token plus position/context for 12 QSA states;
- one 10,240-byte H2D: host-staged PLE embedding;
- one 20,480-byte D2D: preserved last target residual/hidden;
- twelve 512-byte async D2D: one QSA index-key append per QSA layer;
- one 8-byte D2H: selected token;
- one 16-byte memset: GR inject scratch.

The profiled wall values are diagnostic only. Raw digest inventory is embedded
in `/tmp/qwen4exp-p5-copy-compare-1b6bf8e69.json`; compact/full child and trace
summaries are under `/tmp/qwen4exp-p5-copy-{compact,full_logits}-1b6bf8e69/`.
