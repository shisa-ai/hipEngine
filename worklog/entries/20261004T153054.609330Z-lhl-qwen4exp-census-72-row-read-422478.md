## The actionable finding: X-6 is a silent false pass, and it blocks DP-7

**X-6's status cell records a defect, not an optimization.** At HEAD, `--route wmma --layers 16-47`
— the *certified* configuration — returns **identical candidate/teacher logits hashes, KL exactly
0.0, and `status: complete` with `measurement_valid: true`**. The teacher arm does not resolve to
the exact chain it claims. The 2026-09-16 certification had a genuine exact-chain teacher and
nonzero KL, so **this is a regression, and the 16-47 gate cannot be re-run at HEAD to reproduce its
own certification**.

**Verified cause, recorded in the cell:** the dispatch memoization key carries `use_wmma` as a
boolean but **no WMMA layer-scope term** (the scope is a context-local weight filter), so the key
is identical between the route's two arms and **the teacher arm replays the candidate dispatch**.

**Why this matters beyond X-6:** a gate that returns KL 0.0 with `measurement_valid: true` is worse
than one that fails. Any numerical gate run through that route since 2026-09-29 returned a vacuous
pass. **And `DP-7`'s state cell says its chunk-4096 promotion is "blocked only on `X-6`"** — so
this one defect is the sole blocker on a measured **−4.94%** complete-engine prefill win. That is
the concrete, highest-value chain the census surfaces: fix the memoization key, re-run the 16-47
gate, unblock DP-7.

## Checked: this campaign's own chunk-4096 gate is NOT affected

X-6's defect class is exactly the kind that would silently invalidate other gates, so the
chunk-4096 gate from this campaign was checked against it directly
(`benchmarks/results/2026-10-04-qwen4exp-prefill-chunk-4096/gate-chunk4096.json`):

| the false pass would show | this gate shows |
| --- | --- |
| KL exactly `0.0` | `kl_mean = 3.04e-4`, `kl_max = 7.77e-3`, `kl_p95 = 1.79e-3`, `kl_p99 = 4.27e-3` |
| identical teacher/candidate NLL | `strict_teacher_nll_mean = 0.17428` vs `candidate_teacher_nll_mean = 0.17386`, `teacher_nll_delta = -4.14e-4` |
| no top-1 mismatches | real `top1_mismatch_rows` at teacher token ids 23846 and 103910 |
| one arm's profile for both | `strict_manifest.execution_profile = strict`, `candidate_manifest.execution_profile = production` |

**The gate used a genuine strict teacher.** The `wmma` string in that artifact is a *variant name*
(`selected_dual_wmma_iu8_risk_prefill_bf16_bf16_out`), not the gate's route. **This campaign's
chunk-4096 evidence stands.**
