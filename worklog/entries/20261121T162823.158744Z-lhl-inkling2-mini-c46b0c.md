# Share Inkling expert weights across paired prompt rows

## Summary

Reuse packed expert weights across pairs of prompt rows routed to the same expert. Preserve each route's original output location and reduction tree.

## Changes

- Build stable same-expert pairs as part of the existing activation transfer. Each GPU lane decodes the weight once and applies it to two independent accumulators. The kernel handles odd counts by emitting only the real route. Gate and down projections both reuse the pair plan; pointwise activation and expert mixing keep their original order.
- Use pairing for blocks of at least 16 rows with at most 65,535 routes. Decode and short provisional verification retain their existing projection. Register the paired projection alongside the original grouped projection.
