# Preserve GR staging alias guards before route selection

## Summary

R0455 cleanup exposed a staging-safety gap: the direct GR norm/down path
bypassed the workspace alias guards in the older publication-loan branch.
Move those guards before route selection so both paths share them.

## Changes

- Validate the workspace against residual, norm weight, normalized output,
  down output and down weight before a direct launch can write it.
- On overlap or invalid pointer bounds, keep the FP32 fallback and shadow its
  staging workspace only for that launch. Restore the enclosing session.
- Remove the duplicated checks from the old publication branch. No kernel
  arithmetic or normal non-overlapping allocation behavior changes.
