# Test operation-complete IU4 verifier leaf

## Summary

Implemented and measured the predeclared one-layer operation-complete native-IU4
leaf on actual Qwen3.8-27B Q4_K_S layer-0 gate/up weights. The single-request
verifier thesis fails: inclusive M2/M3/M4 moves 0.459/0.473/0.553 to
0.584/0.591/0.601 ms, only 0.787x/0.800x/0.920x current with 0/15, 0/15, and
1/15 paired wins. The first crossover is M5 at 1.195x; M8 reaches 1.598x and
M16-M128 reaches 3.190-4.463x against the runtime-equivalent chunked rowtile8
decode owner.

The naive sidecar is also not quality-qualified. Original BF16/F16 weights are
not available in the authoritative artifact, so the experiment explicitly
re-quantizes dequantized Q4_K_S. One long-K S4 scale per output produces about
15.9% weight NRMSE and 28.5-29.4% operation-output NRMSE versus current exact.
This cannot authorize T3 integration. No 5.329-GiB model-wide gate/up companion
is allocated.
