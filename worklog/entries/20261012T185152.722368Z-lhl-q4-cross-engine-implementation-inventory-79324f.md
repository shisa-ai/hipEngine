# Q4 cross-engine implementation inventory

## Summary

The source inventory confirms that hipEngine already contains several of the
mechanisms exposed by gufo: reusable Q8_1 activation materialization, paired
small-batch expert projections, grouped selected-expert layouts, shape-specific
HC routes, and runtime routed tile hints. The pass-1 family gap therefore cannot
be explained by simply adding those names; it needs same-operand timing and
launch attribution. Gufo additionally has a dedicated parallel three-pass
expert-ID map builder and a wave64 Q4 gate/up kernel that shares gate/up loads
and applies the SwiGLU epilogue in one launch. The largest unresolved gap is
QSA attention, followed by the exact expert route and launch schedule.
