# Distill RDNA3 and RDNA3.5 tuning guidance

## Summary

Created a self-contained RDNA3 tuning guide after reviewing the external
`amd-gpu-tuning` lineage and hipEngine's current documentation, source,
worklogs, and Git history. The guide separates portable method from the host-
and architecture-specific decisions required for `gfx1100` and `gfx1151`.

## Changes

- Added `docs/RDNA3-TUNING-GUIDE.md` with the hardware model, workload-regime
  classification, correctness and measurement protocol, kernel and runtime
  tuning rules, architecture-specific guidance, rejected shortcuts, and a
  repeatable tuning procedure.
- Reconciled historical contradictions: hipEngine assumes wave32 even with
  `-mcumode`; broad non-temporal weight streaming was rejected while long-
  context dense K/V streaming has a measured crossover; inclusive kernel sums
  do not measure wall coverage under stream overlap.
- Included late campaign lessons that older summaries did not yet consolidate,
  including cache-cold buffer rotation, low-row VGPR occupancy cliffs,
  operation-complete sole layouts, bounded FP16 staging, stateful graph keys,
  and `gfx1100`-only PM4 qualification.
- Review coverage included 7,246 frozen legacy worklog sections, 1,296
  immutable Worklog2 titles, and 10,084 hipEngine commit subjects, with decisive
  retained and rejected entries opened for source evidence.
