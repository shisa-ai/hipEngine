# Reject sole-T16 dense Q5 integer MMQ

## Summary

Implemented and screened the last non-duplicative dense Q5 integer rung: the
in-tree llama.cpp-shaped I128/J128/K256 Q5 integer-WMMA consumer adapted to the
production sole-resident Q5T16 bytes. It passes component quality and uses only
3.375 MiB of bounded activation workspace, but loses the retained FP16-WMMA
owner on the actual Qwen3.6-27B `ssm_out` shape. The complete candidate was
removed; no runtime, decode, MTP, residency, or memory route changed.

  `benchmarks/results/2026-08-13-qwen36-27b-q5t16-source-shaped-dense-mmq-rejected.json`.
