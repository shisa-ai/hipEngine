# Share counted Inkling down weights across decode rows

## Summary

Compatible fast decode rows now reuse packed down weights as well as gate/up weights. The down projection consumes the same expert route records as the gate, retains fused per-route activation and Q8 packing, and writes separate outputs for the original ordered mix and convolution.

## Changes

- Register the counted split-activation kernel on both HIP backends and reuse the gate tile implementation with per-route rather than per-request packed inputs. Keep the prior path for single rows, strict execution, and other bank geometry.
- Use the existing exchange and route records for both projections, with separate outer-scale vectors for each bank. Reserve both output slices and the largest Q8 pack before dispatch.
