# Add gfx1151 hardware queue matrix mechanics

## Summary

Added the complete gfx1151 hardware-queue experiment surface for explicit
`GPU_MAX_HW_QUEUES=1,2,4,8` and a genuinely unbounded `unset` arm. The unset
arm does not silently inherit hipEngine's current gfx1151 package default of two:
it leaves ROCm's variable absent and explicitly suppresses only that package
default before `libamdhip64` loads.

This unit adds mechanics only. It did not execute a model, HIP kernel, benchmark,
or profiler and makes no queue performance/stability decision.

## Changes

- Extended `server_f1_concurrency_bench.py --gpu-max-hw-queues` to the bounded
  `1,2,4,8,unset` domain while preserving historical default `1` for direct old
  commands. Numeric arms record policy `explicit`; unset records
  `runtime_default` and removes `GPU_MAX_HW_QUEUES` from the child environment.
- Added pre-HIP process-environment reports. Each server artifact now records
  requested policy, effective configured value/source, and explicit null
  runtime queue IDs/count with `requires rocprof queue trace` rather than
  inferring actual queues from the configured limit.
- Added the temporary cold-path
  `HIPENGINE_GPU_MAX_HW_QUEUES_POLICY=runtime_default` suppression in backend
  process setup. Normal selector-unset users retain the current gfx1151 package
  default; explicit numeric user values still win. Invalid mixed policy/value
  combinations fail before HIP initialization.
- Added `scripts/server_f1_hwqueue_matrix.py`: deterministic forward/reverse/
  rotated counterbalancing, one process group at a time, four-sample thermal and
  KFD exclusivity preflight, postflight health capture, child timeout with
  SIGTERM/30-second owned-group grace, continuous matrix artifacts, product-vs-
  mechanical gate classification, and immutable spec/result hashes.
- Run leaves are unique by commit/profile/queue/suite/tag/block. Resume requires
  the exact spec hash, schema-2 completed child artifact, expected width set, and
  unchanged result hash; it never overwrites a mismatched leaf.
- Production children explicitly set FP16 state, remove physical-width override,
  and consume task #11's fail-closed correctness bundle. SLO failures may be
  collected across the matrix, but control, determinism, route, stream, child,
  or KFD failures stop the campaign.
- Added the queue policy to general artifact provenance and a `docs/REFACTOR.md`
  removal trigger: task #7 must collapse the temporary suppression/report/matrix
  seam after selecting one stable policy.
