# SPECDEC2 bridge contract leak made order-dependent test failures

## Summary

Task #26's "anomalous" broad-order bridge failures were reproduced with a two-file command and traced to
a real shared-state leak, not pytest ordering noise. `tests/test_gguf_ngram_mtp_code_bench.py` called
`scripts.gguf_ngram_mtp_code_bench.configure_code_repetition_contract()`, which permanently rebinds four
`scripts.specdec2_perf_bridge` module globals (`DEFAULT_PROMPTS`, `FULL_PROMPT_IDS`,
`_REQUIRED_CATEGORIES`, `_HELDOUT_IDS`) to the four-prompt code-repetition fixture and never restores them.
Every later bridge test in the same process then validated canonical artifacts against the four-prompt suite
and failed with `full bridge has an incomplete canonical prompt suite`. Collection order
(`test_gguf_ngram...` before `test_specdec2...`) makes this deterministic, so the file only passes when run
alone or before the wrapper test. This resolves the handoff's open question in
`20260830T193959…` ("neither it nor the bridge changed in this campaign, so this is an unresolved
order/shared-state anomaly"): the defect predates the campaign and the broad selection is now green.

## Changes

- `scripts/gguf_ngram_mtp_code_bench.py`: added `code_repetition_contract()`, a context manager that
  snapshots the four shared globals, binds the code-repetition fixture, and restores the previous values on
  exit. Kept `configure_code_repetition_contract()` as the explicitly documented process-wide binder for a
  single-purpose CLI process, and changed `main()` to run inside the scoped contract.
- `tests/test_gguf_ngram_mtp_code_bench.py`: the contract test now binds through the context manager and
  asserts the canonical 10-prompt suite and four required categories are intact afterwards. This test was the
  leak source.
- `tests/test_specdec2_bridge_contract_isolation.py` (new, 7 tests): canonical values are canonical; binding
  restores on exit, on exception, and under nesting; the code-repetition suite still loads inside the
  contract; and `main()` must use the scoped binder.
