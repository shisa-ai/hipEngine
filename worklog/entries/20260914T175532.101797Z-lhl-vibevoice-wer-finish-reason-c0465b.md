# WER drivers retain per-generation finish reason and surface truncation counts

## Summary

Closes the second sub-clause of the transcript-gate finding: a generation that
hit the token cap was indistinguishable in the artifacts from one that stopped
naturally. A truncated answer and a schema failure are different failure modes,
and only the schema failure was being recorded.

All three drivers now record a per-clip ``finish_reason`` (``"eos"`` or
``"length"``), a per-lane ``truncated_transcripts`` list, and print the
truncation count. ``greedy_generate`` appends the stopping token before
breaking, so a final token that is not EOS means the cap cut the answer off;
that single condition is the derivation in every driver.

The comparative harness already knew the information in one place:
``scripts/vibevoice_asr_bench.py`` records ``natural_eos`` per timing. The
``--systems`` driver now reads it instead of discarding it, so no bench change
was needed.

## Changes

- `scripts/vibevoice_asr_wer_full.py`: `finish_reason` in each timing entry,
  `truncated_transcripts` per lane, truncation count in the lane and driver
  summaries. Also carries the malformed-clip exclusion and the
  `malformed == 0` qualification verdict (separate finding).
- `scripts/vibevoice_asr_wer_q4.py`: parallel `finish_reasons` list,
  `finish_reason` in every `per_clip` record, `truncated_transcripts` in the
  artifact, truncation count in the summary line.
- `scripts/vibevoice_asr_wer.py`: the `--systems` driver reads
  `natural_eos` from the lane result and records `finish_reason` per clip.
- `tests/test_gpu_vibevoice_qwen2_q4_runner.py`:
  `test_greedy_generate_exposes_truncation_through_its_last_token`.

## Validation

- `python3 -m pytest tests/test_gpu_vibevoice_qwen2_q4_runner.py`:
  **13 passed, 1 xfailed**.
- Contract check on the Q4 runtime, which the derivation depends on:

  | cap | len | last token | last == EOS | finish_reason |
  | --- | --- | --- | --- | --- |
  | 1 | 1 | 151644 | no | `length` |
  | 3 | 3 | 198 | no | `length` |
  | 64 | 28 | 151645 | yes | `eos` |

  So a binding cap is labelled `length` and a natural stop is labelled `eos`.
- End-to-end: a 4-clip comparative run writes
  `timings[i]["finish_reason"]` and an empty `truncated_transcripts` for a lane
  where all four clips stopped naturally.
