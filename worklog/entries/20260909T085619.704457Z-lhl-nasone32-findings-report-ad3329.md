# Draft upstream findings for the nasone32 fork

## Summary

Collected the reproducible nasone32 fork defects found during the
2026-09-08 engine comparison into docs/NASONE32-FINDINGS.md as two
ready-to-file upstream issue drafts:

1. Chunked GDN default non-determinism: greedy AR output is not
   repeat-stable on general_ja_explain (run-0 ID row differs from runs
   1/2) and the MTP output disagrees with the same server's AR output on
   that prompt (27/30 suite exact); GGML_CUDA_GDN_CHUNKED=0 restores
   30/30 and repeat stability with only the env var changed.
2. Adaptive speculative depth silently disabled: common/common.h:329
   defaults n_min_adaptive to 3 and the README adaptive example also sets
   maximum 3, so the documented example runs fixed depth and cannot adapt;
   our survey rows confirmed adaptive == fixed B3 aggregate behavior.

Two candidates were checked and deliberately excluded as non-defects: the
VRAM growth observation (our measurement contamination from a busy card,
now guarded by idle admission) and the mid-context 8K/16K crash (our own
runner's scratch-cap bug). The perf-rejected donor kernels are design
choices, not bugs, and stay out of the report.
