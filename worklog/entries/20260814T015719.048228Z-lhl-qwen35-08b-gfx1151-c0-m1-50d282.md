# Certify Qwen3.5 0.8B gfx1151 routes and module baseline

## Summary

Completed D08-C0 route certification for Qwen3.5-0.8B Q4_K_M and Q8_0 on
Radeon 8060S/gfx1151. Explicit bulk+WMMA improves Q4/Q8 prefill to
1427.45/4144.52 tok/s, while production graph replay improves decode to
87.12/114.31 tok/s. Fresh serial llama.cpp Vulkan remains faster at
6492.02/6123.47 prefill and 201.17/165.32 decode, so module attribution remains
required. hipEngine tracked peak is 1.180 GiB Q4 and 1.210 GiB Q8 graph.

## Changes

- Added the diagnostic route artifact
  `benchmarks/results/2026-08-14-gfx1151-qwen35-08b-vulkan-parity-c0.json`

  memory, effective paths, and exclusions.
- Updated `docs/QWEN35-08B-GFX1151-VULKAN-PARITY.md` to close D08-C0, admit P1

  ROCm 7.15 exports `roctxProfilerResume/Pause` from
  `librocprofiler-sdk-roctx.so`; legacy `libroctx64.so` remains a fallback.
  The control ABI is now the header-defined `uint64_t -> int` signature.
- Added RED/GREEN tests for SDK-library preference and legacy fallback.

## Validation

- `python3 -m pytest tests/test_qwen35_gguf_bench_roctx.py -q` passes 4/4 after
  the two new tests failed RED on the legacy-only loader.
- Real selected-region Q4 captures emit 491 prefill and 2,672 eight-step graph
  decode kernel rows with expected names/resources and no profiled build.
- rocprofv3 1.3.5 emits zero kernel duration for every row in both selected and
  full traces on this gfx1151 stack; this is recorded as a measurement blocker,
  not treated as timing evidence.
- Every C0 hipEngine row has finite final logits and repeated token 9707; this
  is route sanity only, not the final semantic correctness packet.
- Concurrent llama rows were rejected due GPU contention; replacement Q4 and
  Q8 rows were run strictly serially.
