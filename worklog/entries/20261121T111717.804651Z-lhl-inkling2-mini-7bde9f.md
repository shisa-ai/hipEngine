# Cache exact expansions of small Inkling checkpoint tensors

## Summary

Cache the exact FP32 expansion of small BF16 checkpoint tensors used by host operations. Keep large matrices lazily sliced and preserve the checkpoint's native GPU formats.

## Changes

- Keep read-only expansions up to 64 KiB per tensor for the lifetime of the checkpoint owner. Reuse those views for subsequent whole-tensor and slice reads; larger tensors are still widened only for the requested slice.
