# Inventory local and published Qwen DMS sidecars

## Summary

Two external-linear sidecars are available for the Qwen3.8-27B Q4_K_M target:
the locally trained W256/CR2 package and the published W8192/CR2 package.
Both are offline-trained predictors used for online inference-time eviction;
W8192 is not a separate online-training implementation.

The weights, training provenance and offsets differ: comparing these packages
is not a controlled window-only experiment. Published metadata records a
`protected_window_override_v1` derivation from W256, with no subsequent

training run reproduced in this session.

## Validation

- `load_dms_retrofit_config` successfully loaded both packages against the
  target fingerprint already observed in the public integration tests:
  `7e78da5d7e3ae28d178121f58646953305f3e5bd3cb46f4a75584e8b6c6fe169`.
  Both declare physical full-attention layers `3,7,...,63`, hidden size 5120,
  24 Q heads, 4 KV heads and head dimension 256. Loader validation checks
  sidecar hashes and BF16 tensor shapes `[16,4,5120]` and `[16,4]`.
- Published metadata SHA-256:
  `62c1f2d2c590aff2756796f01bddfaf1b602750ceada4b3ac23639902ff8edfe`;
  downloaded predictor bytes: 655640; predictor hash matches metadata.
- Source checks: published repository API, pinned metadata/model card, local
  metadata, `hipengine/kvcache/dms.py:build_dms_exact_budget_eviction`,
  `build_dms_live_mask`, and `hipengine/kvcache/dms_device.py` projector.
  At prefill, exact-budget ranks scores over eligible historical rows. During
  decode, the device evaluates learned scores and expires marked rows outside
  the protected window. Training is not performed while serving.
- Runtime protection uses `current_position - token_position <= window_size`:
  for a contiguous prompt it includes the current token plus up to W earlier
  tokens. Below that span no prefill row is eligible for eviction. Actual
  whole-cache compression is therefore below the historical 2x setting.
- No persistent hipEngine server was found running at inventory time. The
  completed library/HTTP integration tests selected local W256 and then closed
  their servers. Published W8192 has passed metadata loading, not yet the live
  comparison in this session.
- The publisher's DMS model listing also includes `Llama-3.2-1B-DMS-8x`.
  It is a different target-model retrofit, not an interchangeable Qwen sidecar;
  it is excluded from this matched Qwen comparison, not declared unsupported
  by all hipEngine paths.
- The published model card's library/MTP limitations predate integration commit
  `92cdce5f7`; they do not describe today's public path. Its historical timing
  and quality tables are not fresh measurements for this comparison.
