# Roll back partially initialized prompt provider rows

## Summary

Prompt setup now records provisional provider ownership before reset, buffer
allocation and sink construction. Rollback can therefore release a request even
when construction fails before its sink is published.

## Changes

- Track provisional request/group ownership through the existing abort path.
- Release a reset provider slot when prefix restore refuses it, and return an
  empty newly acquired group to its pool rather than leaving a claim behind.
- Inject first- and second-sink allocation failures; verify provider slots,
  group, normalization buffers and claim are released before successful retry.
