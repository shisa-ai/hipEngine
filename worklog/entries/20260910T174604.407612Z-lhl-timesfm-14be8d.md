# TimesFM 3.0 pre-merge review fixes — guard, determinism, fallback, evidence

## Summary

All four reviewer findings fixed before the timesfm -> main merge:
per-target guard scales (a 2.1% single-target injection previously
passed), determinism regression tests, the strict unfused fp32 fallback
for the fused var kernel, and the benchmark-evidence rollup.

## Changes

- scripts/timesfm3_gpu_bench.py: _signal_scales now returns per-(batch,
  target) scales and the fp16 gate checks each target independently
  (reviewer P1; verified with a controlled 2.1% single-target
  injection, which now fails).
- tests/test_timesfm3_gpu_decode.py: fp32 gate is absolute
  (atol=1e-4, rtol=0, plus a 5e-5 hard max); pytest evaluator uses
  per-(b,u) scales; new determinism tests decode twice per fixture per
  precision and require bitwise equality (reviewer P2).
- timesfm3.hip/.py + runtime: var_attention takes a "normalized" flag;
  fp32 routes through the strict unfused chain (head_rmsnorm x2 +
  head_perdim + raw attention), fp16 keeps the fused path — the fused
  composite now has its strict unfused fallback (reviewer P2). fp32
  parity returned to the exact pre-fusion 8.3e-6.
- Evidence rollup (reviewer P2): result artifact
  benchmarks/results/gfx1151-timesfm3-varnorm-fusion-2026-09-10.json
  (exact commands, measured 0.3213 s median over 5 process invocations,
  torch protocol recorded: vendored TimesFM3Torch, 5 decodes after
  warmup, synchronize, identical inputs); benchmarks/README.md row +
  Last updated; benchmarks/CHANGELOG.md one-liner.
- MODEL-TIMESFM3.md: 272 patches / 6,528 rows (was 258+17/6,600);
  status line says the campaign has started; fp32 description notes
  the unfused fallback.
- docs/REFACTOR.md: open entry — both timesfm kernel families lack
  four-axis registry registrations; runtime-level fallbacks are the
  contract of record until a second consumer appears.

## Validation

- pytest tests/test_timesfm3_gpu_decode.py: 13/13 (parity x3 fixtures,
  fp16 gate x3, determinism x6, precision validation).
- Guard synthetic injection: 2.1% on (b0,u1) detected.
- fp32 parity (unfused): base 8.3e-6, edge 1.1e-5, covmask 1.1e-5.
- fp16 metric re-measured: 0.316-0.323 s across 5 fresh processes.
- sync_benchmark_readme.py --check green.

## Decisions

- fp32 strict = unfused everywhere (not just an escape hatch): the
  fusion is a production-fp16-only optimization with an always-on
  strict fallback path.
- Determinism is enforced by test, not by convention: any future
  nondeterministic reduction in this stack fails CI, not a fixture
  parity flap.
