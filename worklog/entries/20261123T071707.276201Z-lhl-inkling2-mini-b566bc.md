# Validate Inkling DSpark GGUF header geometry

## Summary

Validate the Inkling DSpark GGUF sidecar directly against target dimensions and logical visit boundaries, and expose the names expected by the recurrent draft runtime. Header validation does not read tensor payloads. This unit does not enable drafting.

## Changes

- Bind recurrent, attention, context projection and feed-forward tensor aliases with explicit shape and storage checks. Reject incompatible target dimensions, tap order, attention semantics, RoPE geometry and sliding-window patterns.
- Map each requested tensor lazily and decode only its selected rows. The target's logical vocabulary can be smaller than the padded recurrent token table.
