# Add integrated DMS no-evict quality control

## Summary

Added an explicit integrated `no_evict` decision control and a strict
dense-teacher quality harness so compact-kernel numerical drift can be separated
from learned eviction quality on the actual no-shadow c1 route.

## Changes

- Added normalized `dms_decision_mode={sidecar,no_evict}` selection to explicit
  metadata-backed resident sessions; unknown modes and controls without metadata
  fail closed.
- No-evict prefill initializes the device decision tensor to false and bypasses
  the projector; no-evict decode publishes false decisions on the active stream.
  Both still use direct compact pack/append/attention and release dense KV.
- Added `scripts/qwen38_dms_integrated_quality.py`: one shared model load,
  sequential dense/no-evict/sidecar owners, strict dense-teacher input trajectory,
  full-logit KL/top-1/finite gates, memory/capacity/timing, hashes, and clean Git
  provenance.
- Added CPU mode-validation and real HIP all-false collector RED coverage.

## Validation

- Focused external/runtime/compact bundle: 20 passed.
- Real exact-Q4 768-token + four-step dense-teacher smoke passes:
  no-evict max/mean KL 0.0004144/0.0001782, 100% top-1, 1.0x live CR;
  sidecar max/mean KL 0.0015007/0.0005989, 100% top-1, 1.54217x live CR.
  Both routes use finite logits and final tracked allocation is zero.
- Targeted Ruff with repository exclusions, py_compile, and diff checks pass.
