# x7 scoping: graph replay costs 12.5us host vs 1423us launched, capture infra already exists for qwen

## Summary

- Inventory first (the probe had resolved `hipStreamBeginCapture` et al.):
  graph capture is fully wired in `hipengine/core/hip.py` (begin/end capture,
  instantiate, launch, node/edge inspection) and there is a production-grade
  module — `hipengine/runtime/gguf_decode_graph.py`, "state-bound whole-step
  GGUF decode graph capture" with session keys, state generations, and
  rollback rules — used in production by `qwen35_gguf_runner` only. Gemma4
  does not import it. X7 for Gemma4 is therefore a port-pattern job, not
  invention.
- Screen (`scratch/d8_graph_replay_screen.py`, artifact
  `benchmarks/results/2026-09-30-gemma4-x7-graph-replay-screen.json`): 784
  direct stream ops cost **1423 us median host submission**; the same chain
  captured once and replayed costs **12.5 us per `hipGraphLaunch`** — 1.41
  ms/step of host time at decode launch counts, capture + instantiate
  succeeding from the raw ctypes surface.
- Measurement caveat found while screening: without a drain before each timed
  replay, replay medians bimodal at 2–3 ms — device backpressure from the
  synthetic chain, not graph cost. Any engine-side graph measurement must
  pace the same way.
- Integration facts recorded for the build:
  1. The legacy default stream cannot capture (HIP error 900); gemma4's
     wrappers all default to `stream=0`, so X7 threads an explicit stream
     through `_forward_block_inner`.
  2. Kernels whose grid scales with context length (global-layer attention
     tiles) break stable capture. The qwen module's pattern — device-side
     scalar recording via `record_i64_scalar_indexed` /
     `advance_decode_position_i64` — is the port target; per-step recapture
     is not, because capturing re-issues the very launches replay saves.
- Wall ceiling unchanged and stated as before: launch host time overlaps
  device work, so X7's wall gain is bounded by the ~1.7 ms wall-minus-busy
  gap, not the 1.4–2.6 ms host figure.
