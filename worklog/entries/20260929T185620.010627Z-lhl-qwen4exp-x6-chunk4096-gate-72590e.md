# X-6: the canonical numerical gate at chunk 4096 reproduces chunk 1024 bit-identically

## Summary

X-6 requires *"Re-run the numerical gate at each new chunk size"*, and the existing
certification recorded `prefill_chunk_size: 1024` with scope *"this route/layer set,
manifest and chunk size only"*. That is exactly what blocks RT-1's chunk-4096 promotion.

**Re-run at chunk 4096 with the identical certified configuration. It reproduces chunk 1024
bit-identically, and the chunk-4096 qualification now exists for this route.**

All 12 trajectory hashes identical; 3 repeats passed with no mismatches; `status: complete`;
`measurement_valid: true`; `canonical_numerical_qualification_claim: true`.

## This was predicted, which is why it is bit-identical

The chunk-invariance packet I committed immediately before this run showed chunks 1024,
2048 and 4096 publish **identical `logits_sha256` on all 12 canonical cases**. Bit-identical
logits force identical KL metrics, and that is what the run shows - all five KL metrics agree
to the last digit. So the run is simultaneously a qualification and an **independent
confirmation of the invariance finding at the gate level**, on the full 12-case suite rather
than the single case the invariance packet could compare across packets.

## What this does not establish

I want to be precise, because "gate passed" is easy to over-read:

- **`profile_qualification_claim` is still false.** X-6's other certificates are untouched:
  category-heldout, strict-teacher/BF16-relative, exact control/isolation/graph/lifecycle,
  task-quality, and engagement/repair-oracle coverage.
- **Other routes have their own gates.** This qualifies the wmma 16-47 dense-prefill route,
  not the engine's chunk-4096 default. A blanket chunk flip would need every affected route
  re-gated.
- **RT-3's blocker is separate and still open**: short-request costs historically kept 1024
  as the default, so the right form is a shape-based policy rather than a blanket flip.
- **No performance claim.** This is a qualification, not a timing measurement.
- **Must not be extrapolated to chunk 256**, which is outside the invariance class and
  differs on all 12 cases.
