# Compare Inkling GGUF verification on a real target

## Summary

Serial and packed DSpark verification matched ordinary generation on two real W7900 prompts with the pinned sidecar. The pilot used different target weights from Loom, and is not a performance or acceptance comparison with Loom.

## Changes

- No runtime changes. A scratch harness connected the in-tree packed draft owner to the target's logical feature taps and existing verified generation. It preserved the draft diagnostics in the normal GGUF output decoration. The ordinary control used public `LLM.generate_detailed()` without a draft.
