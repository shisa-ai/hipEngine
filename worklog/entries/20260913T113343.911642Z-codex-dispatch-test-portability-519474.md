# Isolate dispatch-floor unit fixtures from host architecture

## Summary

Fixed the eight host-dependent dispatch-floor unit failures recorded in
worklog/entries/20260913T111026.016255Z-codex-memory-ownership-34a234.md.
The fixture embeds gfx1100 hardware, but the normalizer deliberately gives
HIPENGINE_HIP_ARCH precedence over embedded environment metadata. An inherited
gfx1151 selection therefore changed the HIP artifact while the Vulkan fixture
remained gfx1100, failing comparison validation before the intended assertions.

## Changes

- Add a file-local autouse monkeypatch fixture removing HIPENGINE_HIP_ARCH for
  each test, with automatic restoration afterward. No suite-wide environment
  mutation or production normalizer change.
- Explicit tests cover the environment overriding artifact metadata and an
  explicit argument overriding the environment.
- Add a dedicated cross-architecture rejection test so isolation does not hide
  the comparison safety gate that exposed the original failures.
