# Replay and screen external DMS sidecars

## Summary

Added torch-free external-sidecar loading/projection and deterministic
capture-label replay. The screen calibrates thresholds on train-only rows and
reports validation-only no-evict/CR2/CR4/CR8 behavior without claiming the
runtime logit gate has run.

## Changes

- Parses canonical BF16 safetensors directly into immutable FP32 NumPy weights
  and biases after strict metadata/hash validation; no torch import enters the
  runtime-accessible module.
- Maps physical full-attention IDs to compact indices and projects the declared
  normalized hidden stage while preserving the input/Q channels.
- Recomputes the exact per-scenario oracle budget from retained future-use
  scores, calibrates one global threshold on train rows only, and evaluates
  validation rows twice for deterministic equality.
- Reports actual compression, precision/recall, live/evicted cells, protected-
  window violations, suppressed protected decisions, and layer/head/category/
  context slices for no-evict and CR2/CR4/CR8.
- Explicitly records that dense-vs-masked logits are unavailable in capture-only
  replay; exact runtime replay remains binding for product quality.
- Added a strict Qwen3.8 replay CLI, CPU fixtures, and `KVCACHE.md` semantics.

## Validation

- RED: replay tests failed collection before `dms_sidecar.py` existed.
- Ten focused replay/schema tests pass. Known BF16 tensors project exactly
  against manual NumPy matmul, do not mutate hidden inputs, and physical layer
  mapping is strict.
- Fixture no-evict/CR2/CR4/CR8 repeats are dictionary-identical, use train-only
  calibration and validation-only reporting, and have zero protected-window
  violations.
- Exact-model mechanical screen passes strict model/sidecar hashes and all 16
  physical layers. No-evict is exactly 1.0x; the degenerate four-token fixture
  reaches 1.93939x for CR2/CR4/CR8 with 0 protected violations and 0.96875 oracle
  recall. Replay artifact SHA-256:
  `721f3d8e930266cb819acaed55b4e3feddf1f6badab3977f06e480ce7ed9fb37`.
- Those rows are all-positive synthetic plumbing and are not compression/quality
  evidence. Dense-vs-masked logit quality is correctly reported unavailable.
