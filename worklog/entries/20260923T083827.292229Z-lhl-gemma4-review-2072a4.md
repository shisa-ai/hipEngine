# Repair Gemma 4 generation request contracts

## Summary

Review of `92d618624` found that the adapter ignored the tokenizer's full
end-of-generation set, performed an unused forward after the last requested
token, silently ignored several unsupported controls, and retained weights
when runner construction failed. These are request and ownership fixes; kernel
arithmetic is unchanged.

## Changes

- Use all tokenizer end tokens by default, preserve explicit EOS overrides,
  and honor `ignore_eos` independently of explicit stop IDs.
- Avoid forwarding a final token whose logits will never be consumed.
- Reject grammar, forced-sequence-completion, and thinking-budget requests
  with named implementation gaps instead of silently ignoring them.
- Publish loaded weights and runner together only after construction succeeds;
  free the weights on failure.
- Add CPU-only regression tests in `tests/test_unit_gemma4_contracts.py`.
