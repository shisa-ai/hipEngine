# The teacher-forced instrument's baseline moved 1000x while the kernel stayed bit-identical

## Summary

The flash decode kernel is bit-identical between 2026-09-30 and today (24/24
cases, `benchmarks/results/2026-10-08-gemma4-flash-kernel-deviation.json`), and
its f32 agreement with the incumbent is 4.7e-7 .. 9.1e-7. The teacher-forced
instrument nevertheless reads **~1000x higher today for the same route**:

| instrument reading, same shape (1,023 rows, 8,192-token corpus, frozen chain, KL(baseline \|\| candidate)) | era | mean KL |
| --- | --- | --- |
| flash route vs the chain it replaced (d2 / d4) | 2026-09-30 | 7.75e-6 / 5.16e-6 |
| same route, same instrument, re-run at `e27781214` | today, old tree | 7.75e-6 (reproduces d2 exactly) |
| router-fused, MoE stride, SGEMM, router-token-tile, compact-3launch | 2026-09-28 .. 09-30 | 5.5e-6 .. 2.2e-5 |
| **the shipped route set vs exact** | **today, HEAD** | **5.38e-3** |
| sliding layers only on flash vs exact | today, HEAD | 1.23e-2 |

The 09-28 .. 09-30 rows are *different* changes (router, MoE, SGEMM, attention)
and all measured 1e-5. So the shift is not about the attention route, and it is
not about any kernel: it is a property of the model state the instrument runs
against.

**Mechanism, and it is measured rather than inferred.** The kernels differ by
~7e-7 relative in f32, but the attention output is stored in bf16, whose ULP is
2^-8 = 3.9e-3 relative. A 7e-7 difference is therefore invisible *unless* a value
sits on a rounding boundary, where it flips a whole ULP. The diagnostic measures
that event rate directly: 1.2e-4 .. 4.9e-4 of elements differ, against the
arithmetic prediction 7e-7 / 3.9e-3 = **1.8e-4** -- a match within a factor of
~2. Half the cases flip zero elements; the rest flip 1 or 2 out of 4,096-8,192.

Each flip injects a full bf16 ULP into the residual stream, ~1-2 per layer per
token. Whether a token's trajectory then diverges visibly depends on whether one
of those ULP steps crosses a downstream decision boundary (router top-k, a
near-tie in the logits), which is a property of the model's state distribution.
The model-level distribution has exactly that shape: on HEAD `kl_p95` is 2.3e-3
while `kl_p99` is 0.19 -- a 50x jump -- with 24 of 1,023 rows over limit, and
those 24 rows carry ~87% of the mean. A heavy tail from a few boundary
crossings, not smooth numerical drift. It also explains why the metric is
non-monotone in the flash layer count (1.23e-2 with 25 layers, 5.38e-3 with 30):
the aggregate is decided by which rows happened to cross, so adding arithmetic
difference can move it either way.

**Consequence for promotion.** The envelope's mean-KL bar (1e-3) was attainable
on the 09-30 model state -- every gate that era read 1e-5 -- and is *not*
attainable on today's state, where a bit-identical kernel reads 5.4e-3. A
candidate failing at 5e-3 today therefore carries no information about the
candidate: the reading is dominated by the model's sensitivity to a bf16
rounding boundary, not by the size of the arithmetic change. The instrument still
catches gross errors (the 0.131 cross-commit arm, the 3.47 p99 of the
split-vs-0930 arm, a top-1 collapse), but it cannot discriminate at the 1e-3
scale right now, which is the scale its bar is set at.

**The stable alternative already exists and is measured.** Kernel-level
deviation plus the bf16 flip rate are deterministic, kernel-local, and do not
depend on the model's chaotic state: flash reads 7e-7 and 2e-4 against the
incumbent, identically on both trees. For a *reassociating* kernel that is the
quantity the gate should decide on; the model-level teacher-forced instrument
should be reserved for gross-regression checks (top-1 rate, order-1e-1 KL) and
for candidates that change the *attended key set* rather than the summation
order. Changing the envelope's thresholds or their role is a decision, not a
measurement, and is left to the lead.

## Validation

- Kernel bit-identity and the f32 deviation: 24/24 cases equal across
  `abf639894` and HEAD.
- Flip rate against the arithmetic prediction: 1.2e-4 .. 4.9e-4 measured vs
  1.8e-4 predicted from (f32 deviation)/(bf16 ULP).
- Era comparison uses the same instrument construction on both sides: 1,023
  rows, 8,192-token corpus, frozen baseline chain, `KL(baseline || candidate)`,
  `direction` identical.
- The tail shape is read from the committed artifacts
  (`2026-10-08-gemma4-short-route-vs-exact.json`,
  `2026-10-08-gemma4-short-256flash-vs-exact.json`), not recomputed.
- Control: the self-gate reads mean 0.0 with 100% top-1, so the instrument is
  not broken -- it is insensitive at this scale on this state.
