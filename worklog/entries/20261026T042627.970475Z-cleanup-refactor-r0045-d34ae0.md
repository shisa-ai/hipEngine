# Replace Q8 T16 global sidecar lookup with explicit operand

## Summary

R0045 is resolved: the Q8 T16 pre-converted half-weight operand is owned by
its weight and passed explicitly, rather than recovered from a global pointer
table. Kernel bodies, conversion arithmetic, reserve policy, and default
wave schedules are unchanged.

## Changes

- Added registered `t16_wmma_prefill_f16w_bf16_bf16_out` variants and the
  `t16_f16w` launch ABI with `(tiles, f16w)` operand order. Original `t16`
  signatures, raw-pointer and residual routes remain unchanged.
- Added a registered-capability rewrite for matching sidecars; no new backend
  or quantization-name branch. Dispatch cache keys include sidecar pointer and
  shape so absent or differently shaped operands cannot reuse its dispatch.
- Gemma weights own, account for, and release sidecars. All conversions finish
  before metadata is built and published. Allocation and metadata failures
  clean up unpublished buffers; existing sidecars are not overwritten.
- Removed the global pointer table and register/unregister/lookup APIs.
  Shared wrapper policy preserves gfx1100 two-wave and gfx1151 four-wave
  defaults and decoding fallback for shapes without a half-weight kernel.
- Extended CPU ownership/cache/ABI/backend tests and GPU explicit-operand
  parity coverage. Updated PLAN and REFACTOR.
