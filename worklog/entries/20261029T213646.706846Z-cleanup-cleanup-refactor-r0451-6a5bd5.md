# Retire Qwen4Exp T16 routed experiments

## Summary

R0451, sweep iteration 410, owns the coordinated retirement of Qwen4Exp's
experimental T16 gate/up and down routes and residency controls. R0448 and
R0449 were previously consolidated into this item. Retirement is complete.

## Changes

- Removed generator construction-time population, slot/layer environment
  controls and explicit population method.
- Removed Qwen4Exp-only attach/detach/materialization helpers after searching
  callers. Preserved generic resident weight replacement and runner rebinding;
  added a CPU behavioral regression covering replacement and both layer kinds.
- Removed runtime gate/up and down selection, sidecar caches and direct kernel
  imports. Removed the down route's active-expert scratch allocations and
  matching planner terms. The frozen allocation census matches again without
  the prior allowance for those buffers.

  shared post-construction hook (including its long-context caller). Campaign

  the exclusively owned packed Q5_1 specialization, wrapper, registry entry,
  repack helpers and tests; Gemma4's distinct expanded Q5_1 layout remains.
- Removed the obsolete ledger section and moved environment names to the
  retired-controls reference. Added scoped audit triage.
