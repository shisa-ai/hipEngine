# Evaluate integrated DMS INT8 without fabricated qualification

## Summary

Integrated DMS INT8 executes through the resident model owner in an explicitly
unqualified offline evaluation mode. The 768-token/eight-step smoke passes;
this does not qualify serving, eviction quality or long-context capacity.

## Changes

- Inject a backend factory into the resident session without codec-specific
  dispatch branches. Default construction is still BF16.
- Add an offline INT8 factory with explicit evaluation access, no fake
  qualification object, and `codec_evaluation_only` observability. Ordinary
  INT8 construction still rejects absent qualification. Record the evaluation
  lifetime in `docs/REFACTOR.md`.
- Add codec selection to both integrated quality harnesses. Assert device
  payloads and dense prefill pool release. Report actual store resident bytes
  separately from logical payload and scale bytes.
- Add two-request device tests for exact payload/scale snapshot restoration,
  decode eviction, cancellation/reclaim, refill and neighbor isolation.
- Publish smoke artifact, numerical rollup and campaign progress.
