# EVIE GDN in_proj fusion: negative result

## Summary

Attempted the 4-to-1 GDN in_proj GEMM fusion (loader-side [qkv|z|b|a]
weight concat, single 12352-wide GEMM with pointer-slice outputs).
REJECTED: every downstream kernel (qwen35 conv prefill, gates,
rmsnorm-gate, l2norm-repeat, v-expand) assumes contiguous per-part
planes — a fused (tokens, 12352) layout would require stride parameters
in all of them, including the shared qwen35 conv kernel. The alternative
(fused GEMM + 4 strided gather-copies) saves only ~3 launches per layer
over 4 gemms + 4 x-casts; not worth the complexity.
