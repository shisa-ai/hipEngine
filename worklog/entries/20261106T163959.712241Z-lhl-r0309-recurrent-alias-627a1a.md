# Fix packed prefill recurrent input output alias

## Summary

Packed prefill repeatability is repaired without disabling the default route or changing kernel arithmetic. The segmented recurrent launch read FP32 convolution input and wrote BF16 output at the same address: the planner placed their declared stage-disjoint lifetimes in shared storage. Concurrent segment blocks could overwrite another segment's unread input.

This resolves the defect recorded in `worklog/entries/20261106T161932.648028Z-lhl-r0309-prefill-nonrepeat-f3d1bc.md`.

## Changes

- Start `recurrent_bf16` lifetime at recurrence stage 4 rather than stage 5, preventing overlap with convolution input and other live recurrent inputs.
- Add RED-first planner regression at 3, 18 and 65 rows, checking both lifetime overlap and physical storage separation.
- Update affected deterministic allocation-size expectations to include disjoint output storage.
