# Decode selected NVFP4 magnitudes from a register table

## Summary

Replace the device-memory magnitude lookup in the selected NVFP4 decode kernel with a packed register constant. Keep the packed GGUF layout, external scales, and each route's FP32 accumulation order unchanged.

## Changes
