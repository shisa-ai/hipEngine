# Publish dense-27B FP32-scale INT8 KV outcome

## Summary

Closed the dense-Qwen3.6-27B compressed-KV decision without changing production
defaults. The native 24Q/4KV INT8 consumer is functional, but pure FP32-scale
INT8 fails the required complete 512/8 quality suite at 77.78% minimum-prompt
top-1. A deterministic 9-BF16/7-INT8 layer map passes complete 512/8 and 4K/16
suites plus bounded mixed 8K/16K/32K rows, but remains diagnostic-only because
prefill-oracle peak rises, graph admission is unsafe, executable eager decode
loses to BF16 graph, and 256K capacity is not viable under the current oracle
lifetime.

## Changes

- Added a compact benchmark artifact with exact commands, source hashes,
  quality rows, layer partitions, kernel-trace evidence, memory math, and the
  runtime/support decision.
- Updated `docs/KVCACHE.md`, `docs/GGUF.md`, `docs/TESTING.md`, and
  `docs/REFACTOR.md` to replace the obsolete missing-24Q/4KV blocker with the
  measured quality/runtime frontier.
- Updated the Qwen3.6-27B campaign handoff and benchmark README/changelog.
- Kept BF16 K/V as the sole supported/default dense-27B route; no temporal-tail,
  prompt-conditioned policy, or mixed graph admission was retained.

## Validation

- Native pure FP32-scale INT8 complete 512/8: 10/11 prompts pass; aggregate
  mean/max KL `0.00009146/0.001121`, aggregate top-1 `97.98%`, minimum-prompt
  top-1 `77.78%` — rejected.
- Native pure FP32-scale INT8 complete 4K/16: 11/11 prompts pass; mean/max KL
  `0.002503/0.28625`, minimum-prompt top-1 `94.12%`.
- Native 9-BF16/7-INT8 complete 512/8 and 4K/16: 11/11 prompts pass at each
  shape; minimum-prompt top-1 `100%/94.12%`.
- Bounded mixed candidate 8K/16K/32K: mean KL
  `0.010971/0.003333/0.001535`, all 100% top-1.
- Cached `rocprofv3 --kernel-trace`: 24Q/4KV kernel observed at `73,321 ns`,
  workgroup `(256,1,1)`, grid `(1024,3,1)`, zero scratch.
- RX 7900 XTX 4K/128, 32K capacity: mixed eager `28.124 tok/s` versus BF16
  graph `31.430 tok/s` (`-10.52%`); mixed live saves `0.434 GiB`, but tracked
  peak adds `0.448 GiB`.
- `python3 -m json.tool benchmarks/results/2026-08-13-qwen36-27b-int8-kv-fp32-mixed-layer-diagnostic.json` — passed.
- Every source artifact SHA-256 in the compact artifact was recomputed and
  matched.
- `python3 scripts/worklog.py check` and `git diff --check` — passed.
