# Report automatic MTP eligibility and evidence-backed startup status

## Summary

Repair two reporting gaps in d3a5ccf02 after merging origin/main. An admitted
explicit-only plan no longer advertises automatic MTP, and sampled evidence is
no longer mislabeled unmeasured because of its reason string.

## Changes

- Startup reports `MTP explicit-only (default AR; <reason>)` for admitted plans
  without automatic eligibility, matching the automatic request-routing rule
  for both auto and enabled server policies. Refused plans stay unavailable.
- Measurement status uses the plan's evidence key, fingerprint, and artifacts,
  not a qualified_ reason prefix. Missing evidence is marked unmeasured even
  when the candidate budget is unresolved. Candidate depth still comes from
  the resolved plan before falling back to the configured budget.
- Regression coverage uses actual measured-slower and sampled C1-C4 evidence
  rows, plus missing automatic eligibility and misleading reason strings.
  API documentation describes the status and evidence rules.
- No admission, kernel, sampling, or performance behavior changed.
