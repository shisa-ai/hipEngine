# R0522: retire scalar Muse split decode attention; triage muse audit rows

## Summary

Executed REFACTOR R0522 after verifying its done-when: AR decode and DFlash
verify both run `muse_glimmer_decode_attention_shared` (all runtime imports
checked; the only other `variant='muse_glimmer'` resolve is the unrelated

  gated scalar case in `test_gpu_muse_glimmer_decode_glue.py`;
- the probe's `--kernel split` mode (script retained per the 2026-11-08
  script-retention decision; R0522's named scope authorizes removing the
  comparison mode, `--kernel shared` behavior is now the only mode).
The combine kernels stay — the shared launcher uses both. R0522 entry
removed from docs/REFACTOR.md per the ledger convention (history lives here
and in Git).

left 13 kernel + 10 stub rows untriaged against zero budgets, so
`audit.py check` was already red before this change. Verified and triaged
all 23 as NOT-DEBT/keep with per-row notes: the kernels are registered
(decode/vision/grouped-GEMV), direct-owner proposal-only draft kernels, or
