# Design native EOS ownership and admission seam

## Summary

Implement precommit EOS limiting and scoped admission. GPU0 N8/N2 pass all
ten canonical prompts each for the real C2-to-C1 EOS diagnostic. No public
serving evidence or automatic policy is changed.

## Changes

- Add `greedy_chain_eos_limit` in speculative/streaming.py: inspect reachable
  raw-target predictions through the first rejected edge and bound remaining
  output at EOS. The target consumes root plus accepted inputs; making EOS the
  final next token excludes EOS and later suffix inputs from selected state.
- This is generic control logic, not altered acceptance math or a model-specific
  token rule. No-EOS requests retain their decode budget.
