# Muse Glimmer fused QK-norm/rope/KV-append generalized to multi-row

## Summary

Generalized `muse_glimmer_qk_norm_rope_kv_append` from rows-1 to a block of
rows so the DFlash verify path can use the fused decode glue. Each row runs
the identical per-head Q/K RMSNorm + rotary + K/V append chain at `pos[row]`;
the rows-1 decode launch is unchanged.

## Changes

- muse_glimmer_decode_attention.hip: add a `blockIdx.y` row dimension to the
  fused QK-norm/rope/KV-append kernel (row-offset Q/K/V/q_out, position
  `pos[row]`); the extern launcher takes `tokens` and a 2D grid.
- muse_glimmer_decode_attention.py: wrapper takes `tokens` (default 1) and
  passes it through the ABI; tokens==1 keeps grid.y==1, pos[0]==*pos.
- tests/test_gpu_muse_glimmer_decode_glue.py: add
  `test_fused_qk_rope_append_multirow_matches_per_row_chain`.

## Validation

- Strict parent-parity: multi-row Q out + K/V cache rows equal the rows-1
  chain (bf16_to_f32 x2 -> head-norm partial rotary -> f32_to_bf16 x2 -> KV
  append) applied per row, bit for bit, at tokens 2/5/8 x RoPE/NoPE.
- All 19 glue tests pass on gfx1151 (ROCm liveness confirmed).
