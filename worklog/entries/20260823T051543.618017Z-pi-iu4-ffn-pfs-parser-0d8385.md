# Add immutable IU4 FFN sidecar parser

## Summary

Added the fail-closed product/manifest foundation for the published Qwen3.8
Kairic IU4 FFN sidecar. The stdlib/NumPy reader validates SHA-256, PFSIU4F
header/table/file bytes, all 384 six-per-layer entries, exact role/dtype/shape/
length contracts, contiguous offsets, bounds, and reserved fields before
exposing read-only mapped gate/up/down S4 plus scale/sum views. A byte-lossless
transpose converts the release `[N64,K8word,N]` layout into hipEngine's paired-
K32 tiles. The new `iu4_s4_kairic_ffn_v1` quant identity keeps this T3 product
separate from the earlier re-quantized research sidecar.

## Changes

- Added `hipengine/quant/iu4_ffn_pfs.py` with configurable tiny-fixture specs and
  frozen release identity for HF revision `42de3b69...`, file size
  8,576,856,064, SHA-256 `adcbb90a...ba2b`.
- Exported the explicit product quant, parser, errors, and tile converter from
  `hipengine.quant`.
- Added synthetic two-layer fixtures that independently construct PFS weight
  order, recover every signed nibble after conversion, verify scale/sum views,
  and reject hash mismatch/non-contiguous entries.

Format lineage is read-only `ciru-ai/ROCmFPX@e1da26bb8237fb5642488a2387efc793b141aae5`,
`ggml/src/ggml-cuda/promptforge.cu` (`PFHeader`, `PFEntry`,
`load_iu4_sidecar`). No runtime or kernel code was copied in this unit.
