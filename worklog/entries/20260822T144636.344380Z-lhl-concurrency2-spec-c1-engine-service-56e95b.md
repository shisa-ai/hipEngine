# Integrate SPEC-C1 into EngineService

## Summary

Closed guarded phase-serial SPEC-C1 integration. Drivers exposing
`submit_speculative_detailed` now admit one `VERIFY_CHAIN` child through the
same EngineService request table, collectors, cancellation, completion/release,
and output path as AR. Drivers lacking that submission method use the retained
exact model-owned route only before child admission, with explicit telemetry.

The validated model-owned target/provider transaction remains inside the
existing MTP cycle; this unit changes lifecycle ownership, not GPU arithmetic.
Cross-request proposal/verify packing remains SPEC-C2.
