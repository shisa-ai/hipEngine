# Add exact-Q4 compact DMS quality runner

## Summary

Added a reproducible exact-Q4 quality-only runner after the held-out prototype
proved compact decode can be substituted into the real GGUF layer stack. It uses
dense prefill, then overwrites each full-attention decode output with compact
attention before the exact output projection/FFN and compares final logits.

## Changes

- Shares one exact GGUF weight owner across dense and compact sessions.
- Extracts exact BF16 prompt K/V from resident caches, streams them into the host
  compact backend, and applies no-evict or train-calibrated CR2/CR4/CR8
  decisions.
- Teacher-forces identical dense input tokens through each compact scenario,
  commits per-layer current K/V transactionally after every model step, and
  compares full-vocabulary final logits.
- Reports per-row/category/global KL mean/p95/max, top-1 agreement, outer-floor
  verdicts, compact live-cell compression, and byte-hash repeatability.
- Marks the route quality-only with `dense_shadow=true`; it is not allocator or
  performance evidence.
- Added pure metric and threshold-identity tests.

## Validation

- Held-out `code-08` prototype: no-evict compact vs dense KL
  `0.0000524998`, matching top-1; learned CR4 KL `0.00115571`, matching top-1,
  at 1.94077x total live-cell compression.
- No-evict therefore clears the outer safety floor before learned-sidecar
  interpretation on the prototype.
