# Keep Inkling vocabulary weights in native BF16 on gfx1100

## Summary

Keep the original BF16 vocabulary matrix on device, with FP32 activations, accumulation, and output. The native kernel changes the reduction order, not the weight values. The explicit `strict` profile retains the FP32 rocBLAS projection. F32 checkpoint weights are not rounded to BF16.

## Changes

- Resolve the vocabulary projection once with the Inkling gfx1100 execution profile. Route ordinary and packed verifier vocabulary projections through the same owner.
