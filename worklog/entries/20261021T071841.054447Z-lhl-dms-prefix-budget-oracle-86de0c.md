# Allow budget eviction when the prefix oracle returns to source

## Summary

The public DMS prefix harness accepts budget-driven partial or zero reuse when returning to a source after a branch. It still requires a matching recorded parent for positive reuse and exact generated IDs against the uncached matched-partition oracle. Production runtime and cache budgets are unchanged.

## Changes

- Extract scenario reuse-count validation. Off and matched arms still require zero reuse; immediate repeats/extensions keep their exact expected counts, and branches keep their existing candidate-boundary check.
- A source return may reuse any count between zero and source length because its former full snapshot may have been evicted. The existing parent-content/partition validation and final matched-oracle equality remain mandatory.
- Add 13 focused cases covering partial/zero/full source reuse, out-of-range refusals and unchanged branch/off/repeat/extension contracts.
