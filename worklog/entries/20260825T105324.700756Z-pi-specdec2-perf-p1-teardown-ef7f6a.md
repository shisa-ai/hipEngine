# Preserve SPECDEC2 bridge primary failures

## Summary

The first clean cached gfx1151 bridge smoke failed before measurement because
`dense_gemv.so` was not cached for the exact compiler-version identity. This is
the intended `require_cached` precondition. The failed EngineService driver then
made `llm.close()` time out, which replaced the actionable cache-miss exception
at the outer harness boundary.

## Changes

- Added a narrow teardown helper that re-raises close errors during ordinary
  completion but records them as secondary when a measurement failure is
  already active.
- Record a secondary close error in the load/artifact while preserving the
  original measurement exception and traceback as the primary failure.
- Added a regression test for both active-primary and ordinary-close behavior.
- No runtime, kernel, adapter, timing arithmetic, or performance policy changed.

## Validation

- Python compilation and `git diff --check` pass.
