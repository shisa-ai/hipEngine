# Add exact row-batched Moonshine encoder projections

## Summary

Profiled the current RT-2 complete route and screened an exact encoder projection rowbatch4 candidate. The profile confirms encoder projections dominate the 15.37 ms encoder kernel sum, but sharing each weight row across four independent audio rows was decisively slower: six-short-file median-of-medians regressed 4.747→5.415 ms (+14.09%), and the 20-fixture product screen regressed 39.216/46.352→45.125/52.900 ms P50/P95 (+15.07%/+14.13%). Every primitive and transcript remained exact. The entire prototype was removed; only compact negative evidence, changelog, and this immutable decision remain.

## Changes

- Captured a one-request Nsight Systems `node:host-and-device` trace for the representative 7.628-second/27-token fixture under the promoted conditional-EOS route.
- Prototyped rowbatch4 single, QKV-triple, fc1-bias, and fc2-bias-residual kernels that retained each parent reduction's thread count/order per row while sharing one loaded weight row across four rows.
- Added wrapper/runtime/driver controls and RED/GREEN tests for raw ABI dispatch and real-GPU byte identity. The primitive gate passed byte-exact after matching fc2's retained t64 parent schedule and FP16 projection boundary.
- Ran both the existing six-short-file complete route and an actual 20-fixture alternating product screen. Both failed before any expensive full-quality campaign.
- Removed all prototype source, wrapper, runtime, driver, and test changes. Published `benchmarks/results/2026-08-27-cuda-sm120a-moonshine-encoder-rowbatch4-rejected.json` plus one benchmark changelog row.

## Validation

- Baseline representative trace: 38.460 ms complete wall; encoder kernel sum 15.369 ms. Top encoder families: fc1-bias 4.313 ms, O-projection 3.913 ms, QKV-triple 3.406 ms, conv2 2.805 ms, attention 1.240 ms, conv3 0.927 ms, fc2-bias-residual 1.362 ms. This measured evidence justified trying projection weight reuse first.
- RED wrapper test failed because `row_batch` did not exist. GREEN dispatch passed. The first real-GPU primitive gate exposed one fc2 output ULP because the candidate incorrectly used t256 versus the retained rows>1 t64 schedule; after matching the parent schedule and explicit FP16 projection boundary, all single/bias/residual/triple outputs were byte-exact.
- Six-short-file complete route, two warmups/ten attempts per file: baseline 4.746684 ms versus candidate 5.415347 ms median-of-medians (+14.087%); both all-timed token gates exact.
- Downstream 20-fixture screen, five alternating iterations and 100 observations/route: baseline 39.215623/46.352487 ms versus candidate 45.124738/52.900112 ms P50/P95 (+15.068%/+14.126%); all 200 observations matched expected text.
- Prototype removal verified by clean diff before adding only artifact/changelog/worklog. JSON parse, raw hashes, worklog checks, and diff checks passed before commit.

## Next

- Keep the current exact encoder. Continue RT-3 from the measured family map; prioritize changes that reduce projection device work without four-row cooperative synchronization. Do not retry rowbatch4 shared-weight traversal on this architecture/geometry.
