# Replace Laguna source-F16 environment selection with a scoped owner

selector with a context-local diagnostic owner. Retain all comparison modes
and production defaults; no product decision is needed for this migration.

  The runtime no longer reads `HIPENGINE_LAGUNA_F16_PREFILL`; automatic
