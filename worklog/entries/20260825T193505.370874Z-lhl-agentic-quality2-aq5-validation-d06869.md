# Qualify AGENTIC-QUALITY2 fixtures and sandbox

## Summary

Qualified the frozen 34-block AGENTIC-QUALITY2 v2 suite for live baseline use.
V1 was superseded pre-model after fake-endpoint validation corrected two
fail-safe control specifications; no model answer or candidate informed v2.
A new fail-closed loader joins exact suite/oracle/source hashes, validates the
17/17 split and family/language/executable cardinalities, enforces one-to-one
same-split oracle ownership, validates strict call shapes and source-use policy,
and rejects hidden expected material in user-visible prompt surfaces.

All 34 reference cases reproduce their committed canonical result hashes, and
all ten independent fail-safe policy controls match their expected reject/
withhold result. The evaluator supports one, multiple, and no-tool outcomes;
repository actions; hidden-behavior code; deterministic instruction checks; and
explicit `blocked_sandbox`. Aggregation is order-independent, detects repeat
mismatch, publishes development detail, seals heldout detail by default, keeps
blocked/unscorable observations outside an explicit scored denominator, and
never embeds raw token arrays.

The ZBook supports unprivileged bubblewrap. Generated Python now runs one hidden
input per fresh user/PID/network/session namespace with only read-only
`/usr`/libraries, candidate source, generic runner, and that input mounted.
Expected outputs stay in the host evaluator and never enter the namespace.
`/tmp` and `/work` are private, `/proc` and `/dev` are namespaced, environment is
cleared, capabilities are dropped, and `prlimit` applies CPU/address-space/file/
process/FD/core limits in addition to host wall/output bounds. Timeout kills the
complete outer process group. If bubblewrap/interpreter/prlimit is absent, the
evaluator returns `blocked_sandbox` before execution.

Probes pass for valid code and fail closed for network, `/etc`, home/repository/
model, `/dev/kfd`, inherited secret, child process, hidden-expected discovery,
wall timeout, memory, file-size, and output attacks. This is CPU/process evidence;
no GPU or model ran and no quality mechanism was admitted.
