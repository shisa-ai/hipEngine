# Add dense-27B native INT8 split-K attention

## Summary

Added the missing block-256, 24-query-head, 4-KV-head, head-dim-256 native
INT8 split-K GQA specialization used by dense Qwen3.6-27B. The retained
16Q/2KV Qwen3.5 route remains a separate unchanged template instantiation.

## Changes

- Added a focused GPU/CPU-reference test covering the retained 16Q/2KV shape
  and new 24Q/4KV shape with FP16 scales, reversed physical pages, two full
  pages plus a partial page, and independent zero-scale K/V rows.
- Extended the raw-pointer HIP launcher to select the new
  `q_per_kv=6, num_q_heads=24, num_kv_heads=4` template for per-token/head
  INT8 K/V.
- Kept the shared Python validator and sibling block16,
  Hadamard-group32, and INT8-key/BF16-value launchers internally consistent by
  adding the same 24Q/4KV specialization rather than admitting an unsupported
  shape to their old 16Q/2KV templates.
