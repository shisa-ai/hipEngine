# Disqualify the substitution bisect on arena reuse

## Summary

The substitution harness is visit-aligned but not run-independent: its four variants ran in one process, so the second and later runs began with an arena recycled from the previous run. The bisect numbers are withdrawn, and the third-message result that contradicted the 9.5e-06 agreement is explained by that contamination rather than by a measurement error in the earlier comparison.

## Changes

- Counted the host traversal's `_prepare_layer` calls to locate the message visit.

## Validation

64 rows, fast profile, `hip_gfx1100`. The host's first message visit is call index 18 with `messages` of shape `(64, 4, 2304)`, matching the block's 19th visit, so the two references are aligned and the earlier message comparison stands.

- The four substitution runs shared one process. Each `_resident_block` call allocates its arena through `resident(extent)`, and the allocator recycles the previous run's memory, so runs two to four started with the previous run's contents. The baseline was the first run and is unaffected, which is why it reproduced 6.065.
- The earlier determinism check ran the block twice in one process and measured 0.000e+00 on the read, the branch and the source rows. That is consistent with both runs inheriting the same recycled arena, so it establishes reproducibility but not freedom from arena dependence.
- Zeroing the arena once at the start of a traversal leaves the end-to-end error at 6.065, so the error itself is not arena contamination. Only the substitution harness was contaminated.

## Next

- Re-run the substitution bisect with each variant in its own process, or with the arena zeroed at the start of every run. Expect the third-message variant to return to the baseline once the contamination is removed, since that message already agrees with the host to 9.5e-06.
- If all four variants then return to 6.065, the loop re-entry is fully verified at its inputs and the defect is in the state the visit carries forward rather than in any value it consumes.
