# Close fp16-state GDN audit with repaired packed gate and bracket

## Summary

Closed the requested end-to-end audit of the Qwen3.8 GDN FP32->FP16 recurrent
state work. The typed decode implementation is valid and the gfx1151 c8 shared
state-cache leaf is locally optimal versus the plain implemented sibling, but
the original evidence was overstated and the first packed implementation was
not valid: its c=N prefill bypassed the compact-peer production schedule and
failed binding top-1 scopes. Commit `fd7533217` froze the state dtype per runner,
completed registry/fail-closed provenance, and closed c8 RED/trace coverage.
Commit `d73c08a0e` added the missing indexed compact-peer segmented prefill
owner. The repaired opt-in now passes the packed hard gate and retains a clean
~3% c4/c8 decode benefit; FP32 remains strict/public default.
