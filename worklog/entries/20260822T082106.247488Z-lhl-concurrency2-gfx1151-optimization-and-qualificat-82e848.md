# Define gfx1151 Generation-2 optimization plan

## Summary

Added a Generation-2 gfx1151 port/qualification/optimization plan to the C2
source of truth. The plan preserves common host orchestration while requiring
independent device/model evidence, and turns “gfx1151 inherits C2” into an
ordered campaign rather than an ambiguous portability claim.

The campaign starts with path/capability and production qualification, then
prices scheduler widths/graphs before ranking model-specific kernels. It
incorporates current evidence: physical c2/c4/c8 is package-specific; ZBook
power/thermal identity is binding; repeated JIT/library loads are already closed
on the Qwen3.6 eager hot path; the c1 T0 Q4/Q8 ladder is a measured no-win;
Qwen3.8 projection families outrank already-reduced attention/norm work; graph
replay and compact KV are not presumed wins.
