# Compose Qwen4Exp physical top-10 MoE

## Summary

Composed the physical Qwen4Exp c1 MoE stage: F32 router logits, normalized
softmax top-k, BF16 selected routed gate/up/SwiGLU/down, weighted aggregation,
F32 shared SwiGLU/down, scalar shared sigmoid gate, and BF16 combined output.

## Changes

- Added reusable MoE scratch with selected/routing outputs exposed for control
  gates and idempotent reverse close.
- Selected projection dispatch resolves the actual resident quant key through a
  common registry variant; the runner has no quant branches. Registered raw
  Q4_K single-selected and normalized Q5_1's ABI to the same structural call.
- Added native F32 SiLU-multiply for the shared expert; existing PARO sibling
  accepts BF16 inputs and was therefore not reused incorrectly.
- Q5_1 now supports repeated source rows (`x_rows`) like Q4_K/Q5_K selected
  owners and remains registered under its compatibility MoE key too.

## Validation

- RED: runner test failed collection because MoE scratch/composition did not
  exist; first GREEN attempt localized NaNs to using a BF16-input SiLU wrapper
  on F32 shared rows, then the F32 sibling fixed that type bug.
- GREEN: MoE/Q5_1/GR focused bundle -> `4 passed` on Radeon 8060S/gfx1151.
- Reduced Q4_K routed experts: selected IDs exact, routing weights within 2e-6,
  every intermediate finite, final BF16 output within 2e-2 of the independent
  dense-dequant NumPy top-k/shared oracle.
- Q5_1 selected projection remains BF16 array-exact after its common-ABI change.
