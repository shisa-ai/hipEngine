# Screen exact fused Q4 prefill row retiles

## Summary

Added separately registered, default-off exact 64-row and 128-row siblings for
the dominant gfx1100 dense-Q4 fused gate/up+SiLU prefill family. Actual Qwen3.8
weights show a sharp measured crossover: row64 wins through R64, row128 wins
R65-R128, and the incumbent 256-row parent wins again at R129. The candidate is
not yet promoted; a tracked-clean complete category+heldout gate is next.

## Changes

- Parameterized the existing fused Q4T16 kernel's compile-time row tiles per
  wave while retaining the existing 4-tile/256-row instantiation as the strict
  registered parent. Added standard-Q4 row64 (one tile/wave) and row128 (two
  tiles/wave) C ABI wrappers, Python wrappers, and registry variants.
- Added production-shape parent-parity coverage at R64 and R67 plus selector,
  boundary, peer-fallback, and same-build rollback contracts.
- Added a bounded shape/range selector in `gguf_linear.py`. It can select only
  standard `gguf_q4_k_t16_v1`, K5120/N17408, rows33-128, and only when the
  candidate variant is registered; every miss falls back to the registered
  256-row parent. `HIPENGINE_GGUF_Q4_T16_DUAL_SILU_RETILE=1` enables the
  screen; default remains `0` until the outer gate passes.
- Updated `docs/KERNELS.md` and `docs/REFACTOR.md` with the registered siblings,
  measured bands, rollback, and removal trigger.

## Validation

- RED: selector contract initially chose the parent at R33/R64/R65/R128 and
  failed 4/8 boundary cells before runtime policy was added.
- Production-shape strict parity: R64 row64 and R67 row128 pass BF16-bit equality
  against two shared-B singleton WMMAs plus standalone SiLU.
- Selector/rollback bundle: 9/9 pass.
- Actual `blk.0.ffn_gate.weight` + `blk.0.ffn_up.weight`, 18 samples/arm over all
  six order permutations at prompt rows 35/36/39/43/46/48/60/67: both siblings
  are bit-exact. Row64 improves the parent **1.517-1.592x** at every R35-R60
  cell; row128 improves R67 **1.492x**.
- Crossover repeat, 12 samples/arm: row64 improves R61/R63/R64
  **1.596/1.596/1.611x**; row128 improves R65/R66/R67/R96/R112/R128
  **1.492/1.492/1.491/1.454/1.481/1.484x**. At R129, row128 falls to
  **0.784x** and the parent wins; row64 similarly loses after R64.
- Full `tests/test_gguf_q4_k_t16_dense.py`: **100/100 pass** on W7900
  (`bg-44`).
