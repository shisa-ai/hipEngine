# Detect overwritten Python definitions in the cleanup audit

## Summary

Added the `shadowed-definition` check to fill one concrete dead-code discovery gap. Findings name the earlier and later definitions, compare signatures and bodies, and require review before deletion. The initial real scan finds four pairs; all four are individually inspected and triaged, not automatically removed.

## Changes

- Use parsed same-scope function pairs with a cheap lexical prefilter. Decorators, class bindings, conditional alternatives, intervening name uses/rebindings, later headers retaining the earlier binding, and groups larger than two are excluded.
- Stable identity hashes parsed definitions, not line numbers. Location-only moves preserve evidence; semantic edits reopen review.
- Add 45 contract tests covering positive pairs, guard differences, signatures, decorators, aliases, annotations/defaults, scopes, malformed input, identity, registry integration and real-corpus locations.
- Document the code-corpus boundary and dynamic-access/definition-time limits. No claim of general dead-code reachability is made.
- Record removal decisions for the Qwen DMS method, Yue distribution helper, adjacent GGUF wrapper, and duplicate Qwen GPU-test helper. No budget increase.

## Validation

- RED/GREEN was used for initial check development. Parent review found header-line and mixed-rebinding gaps; the corrected check inspects header AST nodes and rejects mixed groups. A further parent RED case exposed that groups larger than two could hide intermediate captures; the implementation now deliberately handles pairs only.
- Focused product-tier/audit validation: 197 tests and 10 subtests passed; standalone unittest discovery: 183 tests passed. This includes 45 new check contracts.
- Full default-unit run before the final check-specific repairs: 16,562 passed, 271 skipped, 10 subtests. Final edits affect only this new check and its tests; focused revalidation replaces another broad run.
- `audit.py scan` reports exactly four shadowed-definition candidates, each inspected against its source. Documentation and audit gates run before commit.
- The configured independent reviewer could not launch because its model name matched multiple providers. No model configuration was changed; parent review and concrete counterexample tests supplied verification.
