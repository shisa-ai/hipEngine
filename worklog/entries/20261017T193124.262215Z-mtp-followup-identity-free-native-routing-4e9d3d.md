# Remove artifact identity from Qwen MTP route selection

## Summary

The Qwen MTP route previously consulted artifact/quant identity evidence while
selecting sampled and native verification paths. That made an unfamiliar file
or quant string eligible for a different route despite having the same declared
kernel capability. The route now consults backend/model capability declarations
and execution context only; evidence remains provenance and promotion data.

## Changes

- Remove artifact-size and evidence-row matching from sampled-route
  qualification.
- Remove Q4_K_S quant-name routing and use the backend's declared native-state
  capability for MoE containment.
- Remove the obsolete Q4_K_S capability constant and sampled-qualification
  debug flag documentation.
