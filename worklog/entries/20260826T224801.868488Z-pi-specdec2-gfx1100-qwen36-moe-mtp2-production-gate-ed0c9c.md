# Add 35B MoE MTP2 production quality gate

## Summary

Added the dedicated Qwen3.6-35B-A3B MoE Generation-2 C1/K2 production
qualification harness. The gate separates exact control/ownership from T2
arithmetic: it captures real model-plugin MTP drafts and native graph decisions,
uses strict AR as the teacher trajectory, compares full-vocabulary eager
production verifier rows on identical contexts, and requires deterministic
repeats, reverse-order isolation, graph/eager decisions, paired task
non-inferiority, manifests/fallbacks, and lifecycle drain.

## Changes

- Added `scripts/qwen36_moe_mtp2_production_gate.py` for the frozen W7900,
  35B Q4_K_M, BF16 KV, production, C1/K2, natural D24 key.
- Captures all ten train/heldout prompts with real EngineService graph cycles,
  including the terminal K1 zero-accept transition.
- Applies calibrated mean/p95/p99/max KL and overall/per-category/shape/
  transition top-1 thresholds to every aligned full-logit row.
- Keeps raw logits outside Git; output records compact row metrics and stable
  capture hashes.
- Added pure unit tests for global/scope envelope enforcement, tail metrics,
  and paired task regression/non-inferiority decisions.
