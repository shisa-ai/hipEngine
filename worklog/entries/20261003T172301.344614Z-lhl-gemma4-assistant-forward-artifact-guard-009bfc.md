# the assistant-forward module resolves its artifact and guards every node

## Summary

The first failure in the full-suite replay was
`tests/test_gpu_gemma4_assistant_forward.py::test_the_adapter_cycle_agrees_with_a_token_by_token_decode`.
It was not a GPU or ordering failure. The module hard-pinned the backbone and
head to `/models/gguf/gemma-4-26B-A4B-it-GGUF/...`, a root that no longer exists
on this box (the artifacts moved to `/mnt/nvme1/models/gemma-4-26B-A4B-it-GGUF`,
with the head under `MTP/`). The module's first three nodes carry a `_needs`
guard on those paths, so they skipped; the fourth node had **no decorator at
all**, so it ran anyway and died in `GGUFReader(BACKBONE)` with
`FileNotFoundError` before touching the GPU. That is the whole `sssF` in the
replay log: three artifact-guard skips plus one unguarded node hitting the same
missing path.

Reproduced with full collection and `-x` on GPU1: `226 passed, 21 skipped,
4 xfailed`, stopping at that node with the `FileNotFoundError` traceback
(`/mnt/nvme1/gemma4-eval/20261003-continuation-repair/repro-first-failure.log`).
