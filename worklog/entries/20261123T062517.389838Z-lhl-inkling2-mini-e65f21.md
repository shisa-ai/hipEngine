# Keep Inkling attention outputs resident for shared projection

## Summary

Keep each request's attention result on the device until the shared output projection and its per-row convolution complete. Compatible Q8_0 matrices use the packed multi-row projection after gathering the independent device vectors. Other matrices retain the scalar operation in the same fenced download.

## Changes

- Borrow each attention output across one resident traversal stage. Queue only the attention input upload and launches for that row, then fence the shared result before the session can reuse its staging. An exceptional exit fences the stream before releasing the borrow. Keep scalar, prefill and provisional verification on their previous paths.
- Gather separate device vectors without a host round trip, run the tagged output projection, and apply each convolution consumer to its own result row before downloading.
