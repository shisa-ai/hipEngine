# Reuse dense Q8_0 weights across packed Inkling prefill rows

## Summary

Reuse the existing raw Q8_0 FP32 eight-output-by-four-row kernel for aligned dense projections during packed Inkling prefill. Singleton decode and unaligned output widths still use the original launcher. Expert projections are unchanged.

## Changes

- Resolve the existing kernel through the backend registry. Use it for more than one row when the output count is a multiple of eight; otherwise retain the same unpadded output shape on the parent path.
