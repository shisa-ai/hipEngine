# 2026-07-24 — Freeze exact Laguna D12 raw-Q5 wave32x2 design

## Changes


- Audited retained `gguf_q5_k_pack8_decode_out_block` and read-only llama.cpp Vulkan `c0bc8591e` Q5 DMMV. Vulkan's W7900 route uses one subgroup64 for two output rows with raw K blocks and subgroup reduction; its F16/F32 arithmetic is not portable. D12 transfers only the one-subgroup/two-row geometry onto native HIP wave32 and explicitly reconstructs the retained four logical wave partials.
- Selected local32/output-tile2: lane `l` owns logical threads `l,l+32,l+64,l+96`, preserves each `[t,t+128]` K sequence, broadcasts two outputs' exact scale/min coefficients from lanes 0..15, runs four independent 16..1 shuffle trees, and serially adds logical groups 0..3. This keeps encoded-weight work, arithmetic count, total physical waves, and outputs/wave unchanged while removing 1,024 B LDS, every superblock barrier, and the cross-wave exchange. It is not tile16, Q8_1, a repack, or post-op fusion.
- The nominal weight+activation source proxy rises 80% because the 12/18-KiB activation row is reread by four times as many workgroups. Cache residency is only a hypothesis: both K6144/K9216 N3072 BF16-output weights and both K3072 N6144+48/N9216+72 F32 query-gate pairs must win matched current HIP-event and wall micros, independently by family, while remaining bit-exact, local32, LDS0, scratch0, and preferably <=96 VGPR.
- D9's two families are **2.659 + 2.189 = 4.848 ms/token**. A planning-only 10/20/25/30% contraction models **48.234/49.389/49.988/50.601 tok/s**; reaching 20 ms requires **25.10%** across both or **45.76%** from attention output alone. Current pack8 singleton/pair paths remain mandatory fallbacks. Design artifact: `benchmarks/results/2026-07-24-gfx1100-laguna-q2-xl-d12-q5-wave32x2-design.json`; task #292 implements/gates and task #293 measures/adjudicates.
