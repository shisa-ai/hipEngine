# Add bounded owner-local launch decision reuse

## Summary

Add a bounded execution-context owner for immutable pair, pair-SiLU, triple
and residual decisions. Normal resolution still precedes reuse and resident
bindings remain launch-local.

## Changes

- Intern equal resource-free decisions within one explicitly bound owner.
- Bound storage and clear decisions on registry-generation changes.
- Restore nested owner scopes on cancellation/error; no global decision owner.
- Submit each resolver's frozen decision before resident binding. Without an
  owner scope, behavior is unchanged.
