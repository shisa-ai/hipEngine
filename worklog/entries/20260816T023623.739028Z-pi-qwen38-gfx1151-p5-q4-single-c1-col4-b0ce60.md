# Screen Qwen3.8 Q4 singleton c1 col4 decode

## Summary

Retain only the gfx1151 serial-c1 Q4T16 K5120/N1024 full-attention K/V
four-column owner. Across a 67.5-MiB rotating pool of 24 immutable weights it
improves **16.962 -> 16.441 us/projection (1.03169x, 14/15 wins)** with every
BF16 bit identical. Cached profiling names the row-1 specialization at 56 VGPR,
zero LDS, and zero scratch versus 96 VGPR for local32. The post-grouped 4K
projection is only **11.821 us/token / 0.0146% kernel wall**, but repository
policy retains exact non-regressive verified-subwindow wins. Native rows/MTP,
peers, and every other Q4 singleton shape retain their prior owners.

The broad col4 policy is rejected: FFN-down regresses 8.11%, and routing every
Q4 singleton would project a **0.772% selected-wall loss**. Weak full-Q/QKV
medians also lack robust pairwise wins. No broad selector is retained.

## Changes

- Instantiated the existing exact Q4T16 four-column rowtile body for `rows=1`
  and exposed a separately scoped `dense_single_col4_bf16_bf16_out` registry
  key. The row2-4 wrapper and its validation remain unchanged.
- Added the gfx1151 architecture-local c1 shape map only for
  `(in_features,out_features)=(5,120,1,024)`. The existing
  `native_batch_decode_session` guard preserves local32 for B1-B3; shape misses
  and peer backends also remain local32.
- Added synthetic BF16-bit exactness, registry resolution, capability-map, and
  serial/native/miss dispatch tests.
- Added the durable compact artifact and benchmark/campaign/kernel-catalog
  rollups. No resident layout, payload, workspace, graph ABI, or `KVLiveSpans`
  change is involved.
