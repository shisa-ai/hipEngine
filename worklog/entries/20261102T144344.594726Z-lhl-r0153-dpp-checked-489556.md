# Bind checked-row DPP diagnostics to owners

## Summary

The natural-owner, state and complete-engine checked/full-row diagnostic
scripts explicitly enable the DPP family on their generator instead of writing
a shared process key. Production selection and registered kernels are unchanged.

## Changes

- Add an outer diagnostic lifetime stack; bind DPP after generator construction
  and restore original generator/current runner state on return or exception,
  including exceptions before the existing registry/measurement cleanup starts.
- Report the actual owner field and explicit true choice in each artifact.
- CPU tests call each real `main`, starting from None/false/true owner choices,
  and stop during kernel resolution to verify state during setup and restoration
  afterward. Caller process input must stay unchanged.
- No kernel, arithmetic, profile or default changes. The legacy runtime fallback
  remains until generic diagnostics migrate.
