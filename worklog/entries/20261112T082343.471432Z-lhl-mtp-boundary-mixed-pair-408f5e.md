# Remove obsolete handoff guard and repair mixed-pair verifier parity

## Summary

Close R0385 per the lead's direction to use the available same-architecture
Qwen3.8 model rather than require the missing Qwen3.6 artifact. Removed the
historical device-proposal handoff guard. The crossing exposed a separate native
verifier arithmetic mismatch, repaired without changing scalar AR.

## Changes

- Native verifier mixed IQ4_XS/Q4_K-T16 gate/up pairs reuse the registered scalar
  pair-SiLU plan row by row. Prefill, other pairs, attention and down projection
  keep their existing paths. No model identity or context threshold is added.
- Remove `target_graph_proposal_handoff_boundary_miss`; actual graph capacity and
  binding-generation checks remain.
- Dense live tests default to the available Qwen3.8 UD artifact and accept
  `HIPENGINE_TEST_DENSE_GGUF_MODEL` overrides.
- Test both mixed operand orders and row counts; keep public prefill selection
  outside the native verifier context unchanged.

  `/tmp/hipengine-repair-run.sh`; model
  `/models/gguf/Qwen3.8-27B-UD-Q4_K_M.gguf`, BF16 KV, greedy decode.
