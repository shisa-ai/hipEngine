# R0523 single-HW-queue test: race persists (3/60) with GPU_MAX_HW_QUEUES=1 -> within-stream graph-replay origin, not cross-queue

## Summary

Ran the untraced c4 clearing command with `--gpu-max-hw-queues 1`
(`run-r0523-hwq1.sh`, artifact `r0523-hwq1.json`, 60 measured reps) to test whether
the R0523 race is a cross-HW-queue concurrency issue.

Result: the race STILL reproduces — measured exact_rows=237, mismatch_count=3
(req3/pos17/16->15 and 2x req1/pos73/6866->3154), repeat_determinism mismatch=3.
The env was confirmed applied: `environment.effective_server_environment.GPU_MAX_HW_QUEUES=1`
and `protocol.gpu_max_hw_queues_requested_policy=1` in the artifact.

CONCLUSION: forcing a single HW queue does NOT eliminate the race. The origin is
therefore NOT cross-queue arbitration; it is within a single stream's packed
decode graph replay (a buffer-ownership / in-graph ordering defect), consistent
with the per-layer hidden trace localizing onset to full-attention layer 47.
