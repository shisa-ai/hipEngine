# Keep INT8 diagnostic override within implemented capability

## Summary

Restrict the public INT8 diagnostic override to recorded quality rejections.
A missing kernel capability still raises even with the override enabled.

## Changes

- `_resolve_request_kv_policy` previously bypassed every non-admitted verdict
  under either diagnostic environment spelling, including `unsupported`.
- Only `status == "rejected"` may now become `diagnostic_override`. Kernel
  declaration misses retain their named refusal and never substitute BF16.
- Keep the supported environment controls, layout resolution, defaults, scale
  binding and arithmetic unchanged. No caller migration or interface retirement.
- Regression covers rejected/unsupported on both HIP backends through the
  public generator's request policy resolver with a controlled verdict.

## Validation

- GREEN: `uv run pytest -o addopts='' -q` on capability, INT8 policy,
  packed-verifier layout, INT8 MTP, per-layer prefill oracle, allocation probe
