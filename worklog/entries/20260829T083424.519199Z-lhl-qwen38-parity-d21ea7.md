# Parity P2.1: kill per-reset template scan in zero_states reclaim path

## Summary

Third retained serving unit of the external-parity campaign. Phase-count
instrumentation of the C1 prefill arm (22 requests, max_tokens=1) showed
every request pays a post-prefill delivery/reclaim pass of ~45 ms, of which
~39 ms is `zero_states`: ~96 per-layer conv/recurrent state buffers each
zeroed through `_zero`, which runs `np.all(zeros == 0)` over the full
state-sized template array on the host before every memset. The templates
(`conv_zero`, `recurrent_zero`) are immutable `np.zeros` arrays constructed
once at allocation and never mutated, so the scan recomputes a constant.

`zero_states` now issues the memsets directly (async when a stream is
given, sync otherwise — the same branch `_zero` would have taken), removing
the host scan entirely. Bytes written are identical; no arithmetic,
ordering, or ownership change.
