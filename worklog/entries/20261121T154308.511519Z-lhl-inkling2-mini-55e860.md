# Batch Inkling 2 Mini text prompt prefill on gfx1100

## Summary

Production Inkling 2 Mini text requests on `gfx1100` now prefill in blocks of up to 64 tokens. This halved time to first token in the 512-token diagnostic without changing the generated IDs.

## Changes

- Reuse the layer-major target traversal for committed prompt blocks. Project vocabulary logits only for the final prompt row; DSpark still receives every prompt row's captured state in order. A one-token tail uses the existing scalar path.
- The strict profile and image prompts keep scalar prefill. Image prompts supply external embeddings, which the token-block interface does not accept. Packed verification still uses its existing provisional all-row logits and rollback path.
