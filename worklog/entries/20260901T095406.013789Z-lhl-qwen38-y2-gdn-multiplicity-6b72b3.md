# Qwen3.8 Y2 GDN multiplicity blocker

## Summary

Closed Y2's GDN multiplicity branch with a measured named blocker. GDN consumes
64.37 ms, or 5.48% of the rows288 tick, but every one of its five stages
already launches exactly once per each of 48 recurrent layers. The Y2
single-sweep/multiplicity-removal bound is therefore 0 ms. Further GDN work is
algorithmic recurrence, issue, or fusion work and belongs to Y3.

## Changes

- Audited the Y0 cache-only rows288 trace at kernel granularity.

  `benchmarks/results/2026-09-01-gfx1151-qwen38-y2-gdn-no-multiplicity-blocker.json`.

## Validation

- Five GDN kernel families total 240 launches; each family has exactly 48
  launches, one per recurrent layer.
- Stage split: recurrence 42.579 ms, RMSNorm+gate 13.249 ms, compact prepare
  4.460 ms, convolution 3.946 ms, state 0.137 ms; sum 64.371 ms.
- Existing P3 evidence shows the current compact peer-wave recurrence is
  peer-bit-exact and 1.517x/1.479x/1.422x faster than strict direct at
  rows512/1024/4096, with `chain_lds32_direct_nonvolatile` retained as strict
  fallback.
