# Restore two-speaker late diffusion gate after numpy basin flip

## Summary

The ud-gfx1151-opt2 loop guard (full `python3 -m pytest -q`) was red on
`tests/test_unit_vibevoice_tts_diffusion.py::test_trajectory_conditioning_is_diagnostic`.
The assertion `late_ratio.max() > 0.08` ("two late steps now fit the nominal
gate; restore it") failed at 0.0444. Forensics established it was not born red:

- the freeze commit `c78fd581c` recorded "13 passed" on 2026-09-15 with the
  same committed inputs; its worklog tabulates two-speaker late eps 0.3655.
- re-running the freeze commit's tree today still yields 0.0444, so no repo
  change explains the difference.
- the fixture npz is git-identical (content-addressed), the HF snapshot is
  untouched since 2026-09-09, `resolve_model_path`/loader/`hf_cache` are
  unchanged since before the freeze, and a BLAS thread probe (1/2/4/8/16) is
  bit-identical at 0.044444.

The variable is the **numpy version**: the frozen two-speaker replay sits in a
ULP-chaotic regime where numpy selects the basin. Measured in pytest context
(the only context the gate runs in), late eps of peak:

| numpy | source | late eps | diagnostic (>0.08) | restored gate (<0.08) |
| --- | --- | --- | --- | --- |
| 2.4.4 | miniforge `python3` | 0.0444 | FAIL | PASS |
| 2.5.3 | repo `.venv` (`uv run`, uv.lock) | 0.0444 | FAIL | PASS |
| 2.5.2 | emulation `uv run --with numpy==2.5.2` | 0.3655 | PASS | FAIL |

2.5.2 was the freeze-time version (its miniforge dist-info is stamped
2026-09-15 17:53, hours before the freeze measurement; `conda list` still
reports it while the importable files are 2.4.4). Neither live interpreter has
2.5.2 anymore: uv.lock was later resolved to 2.5.3 and miniforge's package
imports as 2.4.4. Outside pytest context 2.5.3 also shows the divergent basin
(0.3655), so the basin flip is numpy-version- and context-dependent either way.

Decision: **restore the late-step gate** — the action the failing assertion
itself prescribes — rather than pinning an obsolete numpy. Both installed
pythons agree in the test's context (0.0444 eps / 0.0175 speech of peak against
the frozen 0.08 / 0.05), no environment or config changes are needed, and the
gate fails closed if the 2.5.2 basin returns. The version matrix above is the
recorded provenance; nothing here weakens an existing threshold — two-speaker
gains whole-trajectory gates it never had.
