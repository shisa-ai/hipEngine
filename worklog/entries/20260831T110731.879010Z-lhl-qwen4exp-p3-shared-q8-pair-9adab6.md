# Add Qwen4Exp shared Q8 activation-pack pair

## Summary

Added a default-off P3 shared-expert candidate that packs each admitted F32
activation into D4x3 once, then reuses that workspace for both Q8 gate and up
projections. The two guarded MMQ projections and exact-correction passes remain
unchanged, so the candidate preserves the current production arithmetic while
removing one quantization launch per layer.

## Changes

- Added model-neutral `launch_gguf_q8_0_mmq_f32_pair()` with shape, capacity,
  alias, registry, and workspace-session checks.
- Added Qwen4Exp shared gate/up dispatch behind
  `HIPENGINE_QWEN4_EXP_SHARED_Q8_PAIR=1`; both named profiles bind it off.
- Added mocked producer-count coverage and a production-shape gfx1151 GPU test
  comparing pair outputs bit-for-bit with two singleton MMQ launches.
- Added the candidate cleanup trigger to `docs/REFACTOR.md`.

## Validation

- RED: the new dispatch test failed import before the pair helper existed.
- GREEN:
  - mocked rows512 K2560/N640 pair performs one activation quantization, two
    guarded projections, two exact corrections, and two risk-counter resets;
  - gfx1151 rows64 K2560/N640 pair outputs for two distinct raw-Q8 weights are
    F32-bit exact to two singleton production-MMQ launches;
  - reduced MoE composition and strict/production binder tests pass.
- No profile default changed. The candidate only activates inside an admitted
  Q8 MMQ session and declines non-Q8/non-raw/unadmitted shapes.
