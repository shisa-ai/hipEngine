# Group Inkling query, key, and value projection transfers

## Summary

Pack independent query, key, and value projection inputs into one activation exchange per attention visit. Keep the shared-input path when a local visit uses the same input for all three.

## Changes

- Reuse the selected FP32 or native BF16 projection kernels without changing their arithmetic. Validate bitwise parity against separate calls for vector and packed inputs.

## Validation

- `epyc` / Radeon Pro W7900 (`gfx1100`), original `thinkingmachines/Inkling-2-Mini` revision `ed40e7da625f594fc9c4990f5f66be24873c22d7`, `inkling2_mixed`, FP32 KV, single-request ordinary greedy decode. Baseline `34d62518a`.
- `bash /tmp/hipengine-inkling2-verify.sh qkvprojections`: five input / 24 output tokens, warm median 12.5697 to 13.1297 tok/s (three runs per arm). The synthetic 512-input / 128-output case rose from 11.1911 to 11.4333 tok/s (+2.16%), one run per arm, with identical output IDs.
- The warm trace showed 632 to 576 stream waits and 1,264 to 1,152 asynchronous copies per token. All 48 focused tests passed. Public text and single-image packed DSpark matched ordinary and baseline IDs and proposal/acceptance counts. DSpark throughput was not remeasured.
