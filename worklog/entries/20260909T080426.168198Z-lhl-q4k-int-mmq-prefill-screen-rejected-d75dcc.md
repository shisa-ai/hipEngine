# Screen raw-Q4_K Q8_1 integer MMQ bulk prefill and reject it

## Summary

Implemented and screened the PP8192-attribution candidate (worklog
pp8192-gap-attribution-8bb338 "Next"): the nasone32 bulk-prefill arithmetic
class — raw GGUF Q4_K weights with DS4 Q8_1 activations in an integer MMQ
consumer with efa4e8641-family load reuse — as a GPU0 (W7900) leaf while the
coder's INT8-PREFILL lane held GPU1. The retained float Q4T16 WMMA prefill
owners win 9/9 case-rows on real Qwen3.8-27B Q4_K_M weights at rows
512/1024/4096, so the candidate is rejected with no route or dispatch
change. Together with the 2026-09-09 VDR decode screen, this closes the
last nasone32 projection donor hypothesis for the PP8192 gap on both the
decode and prefill sides; no handoff to the coder is warranted.

Two consumer classes were built (both raw-Q4_K, satisfying the 2026-08-12
"materially different weight-consumer dataflow" boundary that rejected the
T16-payload consumers): mmq32, a local128 staged-dp4a 32x32-tile port of the
retained raw Q5 MMQ32 C8-owner idiom, and wmma32, a direct-global iu8-WMMA
32x16-tile dense port of the 2026-06-16 selected ds4-wmma32 family winner.
Each class ships ctl/vdr siblings whose only difference is load scheduling
(block header and subblock scale/min product hoisting), proven bit-exact by
a RED-first test with a CPU DS4-pack + MMQ oracle.

## Decisions

- The screen consumes the existing gguf_q8_1_mmq_ds4_pack_bf16 producer
  (one residual pass; ds4-first struct layout confirmed from source after
  an initial qs-first assumption produced NaNs).
- The gate/up t16 arm uses the per-matrix gguf_q4_k_t16_wmma_prefill owner
  (the projection-class comparison); the fused dual+SiLU production owner
  (SwiGLU product output) is recorded informationally — it is faster than
  the two single calls, so the rejection margin against production dispatch
  is even larger than the headline ratios.
- No dispatch, runner, or registry-default change; the kernels, harness and
  oracle are retained as leaf evidence for future integer prefill routes.
