# Retire Qwen4Exp Q8 MMQ attention-gate candidate (R0147) and close prepack rollback (R0129)

## Summary

- **R0147:** the Q8 MMQ attention-gate candidate, which extends guarded MMQ to
  the GDN `attn_gate` K2560/N6144 shape, was rejected in `b62ba02bc`, and every
  profile published it off. It is retired under the lead's 2026-11-07
  retire-failed-candidates decision. The runtime owner scope, the policy
  widening, the generator/runner plumbing, the layer2 candidate spec and the
  harness override translation are removed. The harnesses now reject the old
  override key instead of passing it through.
- **R0129:** the MMQ prepack choice already has no environment reader. It is
  profile-owned: production publishes true, strict publishes false and uses raw
  Q8. The `q8_mmq_prepack_enabled(owner, enabled)` scope is the supported
  diagnostic the campaign harness uses. That is ownership, not a rollback flag,
  so R0129 closes with no code change and no performance-driven retirement.

## Changes

- `hipengine/runtime/qwen4_exp_runner.py`: removed `q8_mmq_attn_gate_enabled` (scope,
  constructor input, class field) and the `attn_gate_enabled` widening in
  `_qwen4_exp_q8_mmq_policy`.
- `hipengine/generation/qwen4_exp_profiles.py`, `hipengine/generation/qwen4_exp_gguf.py`:
  removed the publication and forwarding.
- `scripts/qwen4exp_candidate_ar.py`, `scripts/qwen4exp_profile_gap.py`: removed the
  attention override binders. Both now raise on `HIPENGINE_QWEN4_EXP_Q8_MMQ_ATTN_GATE`.
  `scripts/qwen4exp_layer2_profile_gate.py`: removed the `q8_mmq_attn_gate` candidate,
  spec field and provenance keys. `scripts/execution_profile_q8_mmq_plane_gate.py`:
  dropped the reported field.
- Deleted six attention-gate-only test files. Added
  `tests/test_unit_qwen4exp_mmq_attn_retired.py` (retired key raises in both harnesses;
  the runtime has no owner). Updated the shared profile, layer2, profile-gap,
  router-producer and Q8 MMQ gate tests.
- `docs/ENVS.md`: the attention-gate row describes the retirement.
