# Freeze Qwen3.8 Q4_K_M MTP serving campaign

## Summary

Freeze the Qwen3.8-27B `Q4_K_M` exact-MTP serving campaign from current merged
main before changing behavior. The retained natural25 direct leaf is exact and
fast at B3, but it constructs resident target/provider/verifier objects directly
and excludes prefill from decode timing. It is a premise, not proof that the
public LLM/OpenAI route is exact, faster, lifecycle-complete, or safe to select
automatically.

Current code already exposes explicit LLM/OpenAI MTP and keeps `auto` on K0.
The first work is therefore measurement and artifact-scoped admission—not a new
scheduler or another MTP implementation.
