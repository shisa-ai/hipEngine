# Localize the resident block non-determinism to process state

## Summary

The resident block reads device state that only a host traversal initializes: its first run in a process differs from every later run, and a host `prefill_block` before the first block run makes all block runs agree. Once stable it is still about eleven logits from the host at 151 rows, while it matches to 2.2e-04 at 64 rows, so the defect scales with row count.

## Changes

- Four block runs on one 151-row block, comparing logits against the host and against each other, with and without a host traversal first.
- Two diagnostics, both reverted: zeroing the resident arena at entry and zeroing the per-visit host KV buffers in `_new_state`.

## Validation

151-row block, `Inkling-2-Mini-UD-Q4_K_M-mainline.gguf`, `hip_gfx1100`, fast profile, logits max absolute difference:

- Host path four times: bitwise identical every run.
- Block path four times, no host call first: run 1 differs from run 2 by 1.047e+01, runs 2/3/4 bitwise identical.
- Same, with the arena zeroed at entry: run 1 differs by 1.067e+01. Unchanged, so the unwritten read is not in the arena.
- Same, with the per-visit host KV buffers zeroed: run 1 differs by 1.053e+01. Unchanged, so it is not those buffers.
- Block path four times with a host `prefill_block` first: all four bitwise identical, and all four 1.096e+01 from the host.
- 64-row block, same script: the block is 2.185e-04 KL from the host, so the error appears between 64 and 151 rows.

## Next

- The row-count dependence is the strongest signal: check the arena row stride and the per-visit row count against `rows` in the message and attention reads, at 65 and 151 rows rather than at 64.
- The host-initialization dependence says the block reads a buffer the host traversal populates first. The device KV pool and the attention session's relative table are the remaining candidates after the arena and the host visit buffers were cleared.
- Do not quote any earlier block number measured in a process that ran the block before the host.
