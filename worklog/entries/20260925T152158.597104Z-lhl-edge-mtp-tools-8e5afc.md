# Enable constrained MTP with byte-preserved Qwen3.6 target

## Summary

hipEngine's real streaming tool request now executes MTP with processed-argmax
constraints and prefix caching. The frozen Qwen3.6 target GGUF contains no MTP
block; a separate assembled artifact preserves every target tensor byte and
adds pinned Qwen3.6 NextN tensors. The 140-turn speculative comparisons and
shared quality diagnostic are still pending. No speed or accuracy claim is
made from these integration preflights.
