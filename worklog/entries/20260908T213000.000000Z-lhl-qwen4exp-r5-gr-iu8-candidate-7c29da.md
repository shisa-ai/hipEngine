# R5 GR composite screen: iu8-WMMA GR up candidate

## Summary

Executed R5 against the refreshed owner ranking: the GR family's dominant
kernel is the fused GR up projection
(`q8_0_gr_up_sigmoid_mean_coltile2_branch4_rowbatch4_f32`, 4.913s of the
18.5s code-p4096 prefill device total). Located the actual publication
boundary first: the fused kernel publishes F32 `gate` and `mixed`; `gate`
is consumed by nothing downstream (only `mixed` feeds the QSA mixer / MoE,
both F32), and the composite's single BF16 rounding boundary is the
`gr_write_bf16_f32` at the very end. The sigmoid inside the composite is
contractive (|sigma'| <= 0.25) and the gated mean averages, so projection
drift contracts rather than amplifies through the composite. The exact
(non-reassociative) route was previously and correctly deemed
non-transferable; under the production-correctness contract the owner is a
T1 target.

Built the candidate: dense iu8-WMMA Q8_0 projection with in-kernel
three-plane residual activation staging (fp32 scales, R4a guard heritage),
raw signed Q8_0 codes as the integer B operand (the weight path has no
requantization at all; Q8_0 has no min-offset term, so no act-sum term is
needed), followed by the retained exact sigmoid + gated-mean epilogue
kernels (the runner's unfused path). No risk queue or repair: exactness is
not the contract here, the KL envelope is.

Operation-complete screen on actual `hc_attn_up` weights
(`scripts/qwen4exp_gr_iu8_screen.py`): **2.93x at rows 1024 / 3.77x at
rows 512** versus the fused parent including the split-epilogue overhead
(the earlier projection-only discriminator estimate was 1.94x). Drift:
gate max_abs 1.8e-7 with rel p50 = 0; mixed absolute 1.2e-7 with large
relatives only on near-zero outputs (median rel 0, p99 5.6e-7).

Full-model qualification (`scripts/qwen4exp_gr_iu8_logits_probe.py`,
teacher-forced prefill, canonical fixture, 0/1 arms each run twice):
candidate is bit-deterministic across runs; logits KL versus the incumbent
production route <= 7.4e-8 across all 9 cases (the binding production bar
is mean KL 1e-3; the rejected Q5_K bundle sat at 1.2e-3); top-1 agreement
100% on every case with argmax gaps 15-29 versus argmax drifts 0.15-2.0
(10-100x margin). The residual absolute logits drift (median 0.1-0.2) is
the signature of benign discrete-selection flips (MoE top-k / QSA index
near-ties) amplifying the ulp-level kernel drift - the same drift class
the incumbent production routes exhibit versus the llama.cpp teacher.
