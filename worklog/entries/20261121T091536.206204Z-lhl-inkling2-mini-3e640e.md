# Tile Inkling target attention without changing FP32 order

## Summary

Compute target attention scores for a tile of cache positions in parallel. Preserve the FP32 dot-product tree, score order, denominator and value recurrence. The serial kernel remains registered as a reference.

## Changes

- Share work across four waves per query head and synchronize between tile phases instead of between every reduction step of every cache position. Keep FP32 KV and the existing append and rollback paths.
