# Validate opt-in N2 diagnostic hidden rows

## Summary

Narrowly extended the N2 result contract for the new opt-in quality diagnostic.
N2 continues to return no host hidden rows by default; diagnostic hidden rows
are valid only alongside aligned full-logit rows and must be exact-shape finite
FP32 arrays.

## Changes

- Validate diagnostic logits as finite rank-2 FP32 with one row per target row.
- Validate diagnostic hidden values as finite `(rows, hidden_size)` FP32 only
  when diagnostic logits are present.
- Preserve the default empty `(0, 0)` FP32 N2 hidden payload.
- Added positive and negative dataclass tests.
