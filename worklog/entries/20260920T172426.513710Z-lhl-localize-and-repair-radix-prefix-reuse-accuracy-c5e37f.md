# Localize and repair radix prefix reuse accuracy

## Summary

Investigating the W7900 prefix-cache accuracy failures with radix left enabled
as directed. The quoted rollback predates the current server default.
The BF16 cause is localized and repaired. INT8 is a separate following unit.

## Changes

- Gapped BF16 suffixes now resolve the registered gather instead of requiring
  the optional contiguous-layout optimization. Explicit rollback and memory
  limits remain. No kernel bodies or contiguous defaults change.
- Added gather teardown for both owning sessions and lightweight slot views;
  the old INT8-only release early return leaked their BF16 gather allocations.
- The gate compares private batched-prefix/batched-suffix recomputation and
  applies the existing execution-profile mean/p95/p99/max KL/top-1 evaluator.
  Serial-suffix KL is still measured on identical teacher tokens against both
  candidate and private recomputation and is explicitly diagnostic.
- Preserve unrelated worklog/audit edits and commits by other workers.
