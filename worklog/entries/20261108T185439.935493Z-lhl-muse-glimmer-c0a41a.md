# Muse Glimmer host sampler: incremental history counts + vectorized penalties (-86% at 131K)

## Summary

Task #5 (§11.1 host sampler track). Sampled AR requests (DFlash is greedy-only)
pay the host sampler directly. Profiling with scripts/sampler_host_cost_probe.py
split the cost: greedy 0.18 ms (flat, already optimized by 45433fe8b), top-p
~5-6 ms (flat, full-vocab argsort), and an active repetition penalty that grew
O(history): 0.27 ms @512 -> 6.29 @32K -> 21.51 @131K. The penalty regression was
`RowSamplingState.history_counts()` rebuilding `Counter(prompt + generated)`
from scratch every token (O(prompt+generated)), then a per-token Python loop
applying the penalty over the unique tokens.

Two changes, semantics bit-identical:
1. Incremental history counts. The prompt is fixed and generated tokens only
   grow via observe(), so history_counts() now builds the Counter once (first
   use) and observe() increments it; clone() rebuilds independently. The O(n)
   per-token rebuild is gone (the prompt count is paid once per request).
2. Vectorized penalty application. _apply_history_penalties now gathers the
   unique in-vocab ids/counts with np.fromiter + a boolean mask and applies
   repetition (sign-dependent mul/div), presence, and frequency*count with
   element-wise numpy ops instead of a Python loop. The frequency term is cast
   to the logits dtype before subtraction to match the scalar path's value-based
   cast (a float32 array -= a float64 array rounds 1 ulp differently); op order
   per token is unchanged.

Measured (sampler_host_cost_probe, 30 iters, vocab 201088): repetition penalty
0.27/6.29/21.51 -> 0.19/1.02/2.93 ms/token at 512/32K/131K (-86% at 131K), now
near-flat. Greedy and top-p unchanged. Bit-identical to the original scalar
penalty (targeted test) and the full sampling unit suite stays green.

## Changes

- hipengine/generation/sampling.py: RowSamplingState `_history_counts_cache`
  (init=False, compare=False), lazy history_counts(), observe() increment;
  vectorized _apply_history_penalties (np.fromiter ids/counts + mask, dtype-cast
  frequency term).
- tests/test_unit_sampling_history_penalty.py: incremental counts == full
  rebuild after observe/clone; cache not shared with clone; vectorized penalties
  bit-identical to a scalar reference across rep/presence/frequency combos incl.
  out-of-vocab ids and negative/positive logits; neutral penalties no-op.
- No flag; pure host optimization, default path.
