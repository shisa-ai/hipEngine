# Complete Qwen3.8 Q4_K_S qualification

## Summary

The deferred natural AR/MTP gate exposed two bounded integration gaps after the
Q4_K_S target route had already passed its actual-weight and 512/8 gates. The
Qwen3.8 trailing NextN mapper assumed the Q4_K_M draft layout, rejecting the
Q4_K_S block's legitimate Q4 `attn_v` and `ffn_down` tensors as non-Q6. The
transactional verifier also lacked the quant-independent Q4_K_S alias for the
shared GPU accept primitive. This checkpoint fixes and tests both boundaries so
a clean full AR+B1-B3 suite can proceed. No performance result is retained here.

## Changes

- Select the dense NextN dtype contract by GGUF file type. Q4_K_M retains Q6
  `attn_v`/`ffn_down`; Q4_K_S requires Q4 for those exact roles. MoE and every
  other dense file type retain their prior validation contracts.
- Register `gguf_q4_k_s` against the existing quant-independent
  `dflash_accept_chain/i32` primitive. The kernel body and acceptance math are
  unchanged; gfx1151 continues to receive the normal backend alias.
- Add synthetic no-model coverage for the Q4_K_S NextN dtype contract, complete
  local-file planning coverage for all seven sole Q4T16 draft weights, and
  registry coverage for Q4_K_S transactional acceptance.

## Validation

- RED: the first full natural-suite attempt failed before generation with
  `blk.64.attn_v.weight: expected Q6_K, got Q4_K` and the same error for
  `blk.64.ffn_down.weight`. The new complete-file test reproduced that strict
  mapping failure before implementation.
- A separate clean-worktree suite reproduced the same failure, proving this was
  not caused by the shared working tree or GPU contention.
- GREEN: nine focused checks pass across synthetic Q4_K_S mapping, retained
  Q4_K_M contract rejection, complete Q4_K_M/Q4_K_S NextN planning, gfx1151

- The Q4_K_S draft plan now owns seven Q4 tensors as sole `gguf_q4_k_t16_v1`
  payloads; Q4_K_M remains at five Q4T16 tensors plus raw Q6 `attn_v` and
  `ffn_down`.
- Two attempted natural runs were deliberately terminated when another Qwen
