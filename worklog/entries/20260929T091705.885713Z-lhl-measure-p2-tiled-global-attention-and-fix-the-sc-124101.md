# Measure P2 tiled global attention and fix the scoreboard bucketing

## Summary

P2 (tiled `flash_attn_tile<512,512,4,8>` for the 5 global layers) landed and
was wired to the default path, but its row was blocked on one number: "only
the 39.2 -> ~32 ms measurement". This unit produced that number and, on the
way, found that the instrument could not have produced it correctly.

The first `gemma4_scoreboard_snapshot.py --gpu 1 --tag p2` run reported
`attn.global` as **0.00 ms on zero launches**, with `flash_attn_tile` sitting
in `other` at 100.93 ms. `ENGINE_FAMILIES` matched `attn.global` only on
`gemma4_attention_decode_class_kernel<unsigned short, 2` — the symbol P2
deleted. Two further new symbols were also unmatched: P3's bound Q8_0 down
owner and P2's four dtype-staging converters. Read naively, the row would have
shown the tiled kernel as a total loss.

After fixing the rules and re-running with `--keep-traces`:

- **`attn.global` 612.17 -> 100.68 ms at 4096 (-511.50, -83.5%)** and
  **38.75 -> 8.83 ms at 1024 (-29.92, -77.2%)**, launches unchanged at 40
  and 10 in both arms, so the delta is purely the symbol swap.
- Staging costs **+3.48 ms at 4096 / +0.56 ms at 1024** — about 0.7% of the
  saving, confirming P2's dtype microbenchmark at scoreboard level.
- Net `attn.global` including staging: **612.17 -> 104.16 ms at 4096**,
  **38.75 -> 9.39 ms at 1024**. The row predicted 39.2 -> ~32 ms (a ~7 ms
  gain); the measured gain is 29.4 ms, **4.2x the estimate**.
- Total prefill busy 3474.4 -> 2650.2 ms (-23.7%) at 4096; topline
  1145.8 -> 1493.6 tok/s (+30.4%).
- **`attn.sliding` 1213.55 ms** — a live value replacing the 1211.3 that had
  been carried stale for three iterations while rocprofv3 hung.
