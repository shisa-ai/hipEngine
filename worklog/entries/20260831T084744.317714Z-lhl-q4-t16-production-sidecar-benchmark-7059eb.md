# Add a production-owned Q4-T16 sidecar leaf benchmark

## Summary

Task #12 cannot safely reuse the synthetic prefill-row sweep: a guessed compact
payload previously wedged the GPU, and full-layout synthetic output disagreed
with the production rowtile owner. This unit adds a source-clean benchmark that
gets each tiles pointer from the normal Qwen GGUF materializer and inventories
the actual shipping resident layout before launching a candidate.

## Changes

- Added `scripts/gguf_t16_sidecar_row_bench.py`. It materializes only the named
  FFN/QKV/attention roles from the exact model, times only
  `gguf_q4_k_t16_v1` roles, asks the production sidecar selector for the
  incumbent, and compares it with small-M and strict shared-B at rows 2-8.
- Each cell requires bit-exact BF16 output and finiteness before its timing can
  pass. Nine samples rotate all three arms through all order positions; each
  sample records HIP-event burst time and operation-complete synchronized wall.
- The inventory makes incompatible roles explicit rather than silently
  reconstructing them: Qwen3.8 FFN gate/up are qmicro, recurrent QKV/down are
  Q6, and standard full-attention roles are measured only when their resident
  layout matches the candidate ABI.
- Added focused parser/order/summary tests. No runtime dispatch, kernel, profile,
  registry, or policy changed.
