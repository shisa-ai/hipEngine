# Implement SPEC-C3 streaming and sampling semantics

## Summary

Closed SPEC-C3 committed output and sampling-accounting correctness. No
provisional token can form a stream event. Blocking and streaming speculative
children share output-tail normalization, collectors, cancellation/reclaim,
and finish semantics. Existing sampling guards still reject processed sampling
before launch; the stochastic oracle binds future provider probabilities/RNG.

## Changes

- Added committed event, output-tail, and stochastic acceptance records/helpers.
- Added EOS, stop token/sequence, length-tail, accepted-prefix, correction/bonus,
  and per-candidate uniform/RNG accounting.
- Added EngineService speculative normalization and one-prompt committed stream.
- Added public `LLM.stream_speculative_mtp_detailed` without a legacy streaming
  fallback.
- Added blocking/stream equivalence, provisional-event rejection, cancellation,
  backpressure-neighbor, and sampling tests plus audit/docs/artifact updates.
