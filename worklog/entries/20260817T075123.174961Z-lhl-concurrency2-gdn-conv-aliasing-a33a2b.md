# Fix conv_out arena aliasing that broke packed-vs-c1 bit-exactness

## Summary

Root cause of the packed-vs-independent-c1 divergence (previous entries
`...f5a653.md` / `...f8b77c.md`) is `59fd48631` ("perf: reuse split GDN conv
scratch lifetime", 2026-08-15): it shrank `conv_out`'s prefill-arena lifetime
to stage `(2, 4)` so its full-row plane could share physical pages with
`recurrent_out`, on the claim that split prepare consumes `conv_out` completely
before recurrence begins. That claim is false — the exact recurrence reads the
full convolution sequence while writing `recurrent_out` (the pre-commit comment
said exactly this), so the shared pages alias and corrupt GDN state in
multi-row prefill. This produced the small (~1e-2) hidden-state divergence for
packed c2 and c8 versus independent c1, including token divergence at c8.
Fix: remove the override; `conv_out` keeps its base `(("linear", 2, 5),)`
lifetime in every GDN mode, restoring page disjointness.

## Changes

- `hipengine/runtime/qwen35_gguf_runner.py`: deleted the split-mode `conv_out`
  lifetime override from `59fd48631`; left an explanatory comment.
- `tests/test_qwen35_gguf_prefill_scratch_liveness.py`: renamed
  `..._reuses_dead_conv_output_scratch` to `..._keeps_conv_output_disjoint`;
  now asserts the `(2, 5)` lifetime, page disjointness of `conv_out` vs
  `recurrent_out`, and the restored arena footprint (sum ≤ 475 MiB, max buffer
  467 MiB + 576 KiB — the ~66.5 MiB memory saving from `59fd48631` is
  forfeited because it was based on invalid aliasing).
