# Add SPECDEC2 P8 production FP16 capability

## Summary

Added the profile-scoped P8 capability foundation without changing automatic
policy. Qwen3.8 gfx1151 now resolves a non-fallback `production` manifest whose
SPECDEC2 target chain selects the existing FP16-state row writer with explicit
FP32 strict fallback. MTP2 admits FP16 state only when that complete immutable
manifest is attached; strict, fallback-to-strict, legacy-env-only, and malformed
manifests still select K0 before mutation.

The audit initially expected a new producer-folded FP16 snapshot kernel. GREEN
bring-up proved that would be the wrong route on gfx1151: P4 intentionally
excluded snapshot/fused-chain aliases and retained consumer-owned D2D rollback.
P8 preserves that ownership. Initial Conv/GDN snapshots and row journals are
sized from the live FP16 state buffers; the existing typed chain writer performs
FP32 accumulation/FP16 round-trip; Q5 output uses the existing exact standalone
cast instead of an unqualified fused chain owner.

## Changes

- Registered strict/production Qwen3.8 plans with immutable manifest hashes,
  FP16 production binder, FP32 fallback, and retained prefill-GDN capture.
- Added fail-closed manifest authorization to MTP2 capability/open/refill and
  bound profile hash/state dtype to target sessions before graph preparation.
- Routed chain-journal GDN through the FP16-state registry key while leaving
  producer snapshot capability unavailable under FP16 state.
- Extended native target graph configuration identity with manifest hash and
  recurrent-state dtype.
- Added RED/GREEN coverage for profile/fallback selection, adapter admission,
  typed chain plan, and graph-key separation; updated kernel/refactor ledgers.
