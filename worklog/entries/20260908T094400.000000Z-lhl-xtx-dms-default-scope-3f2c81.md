# DMS as the default enduser path: scope and proposed flip

## Summary

Scoping task for making DMS the default route for enduser installs. The
finding: the enduser surface has no DMS path at all today — this is a
plumbing project plus a quality-gated default decision, not a toggle.

## Current state (verified)

- `hipengine.LLM.__init__` (hipengine/llm.py) accepts backend/quant/
  execution_profile/max_*/prefix_cache/speculative_*/kv_storage/
  kv_scale_dtype/kv_scale_granularity — no DMS kwargs.
- `hipengine.server.ServerConfig` (hipengine/server/api.py:310) mirrors
  the same options — no DMS fields; `get_llm()` constructs `LLM(...)`
  dense-only.
- The generation path (Qwen35GGUFBringupGenerator and the resident batch
  owner) constructs `Qwen35GGUFResidentSession` without DMS options and
  the shared session-pool key carries no DMS identity.
- DMS is reachable only via the probe-level construction:
  `Qwen35GGUFResidentSession(dms_metadata_path=...,
  dms_backend_factory=create_dms_int8_evaluation_backend,
  dms_max_new_tokens=..., dms_prefill_mode="layer_outer")`. One metadata
  path drives the retrofit config, sidecar load, and fingerprint binding
  to the exact Q4_K_M model file.
- docs/KERNELS.md records the deliberate posture: "no model package
  defaults to DMS." The distribution blocker stands: no packaged sidecar
  artifact set exists for endusers.

## Proposal (recorded in DMS.md P1)

- Phase 1, opt-in (ship-safe now): `dms` option on `LLM` and
  `ServerConfig` — `off` (default) / `auto` (discover sidecar next to the
  model, fall back to dense with one log line when absent) / explicit path
  (fail closed on absent, malformed, untrained, or fingerprint-mismatched
  metadata). Session defaults: int8_evaluation codec, layer_outer
  prefill, single-plane hidden alias. Thread DMS identity through the
  session-pool key. Estimated 2-3 days including tests and the README
  quickstart.
- Phase 2, default flip (gated): default `auto` only for the qualified
  pair (Qwen3.8-27B Q4_K_M + gfx1100 + artifacts present) after the
  DMS-ANALYSIS.md Gate 1/Gate 2 quality ladder passes and the P5/P7
  lifecycle/soak items close; speculative/MTP stays off until its
  ownership contract passes. Never a silent default without artifacts.

## Changes

- docs/DMS.md: P1 gains the scope note and the two-phase proposal.
