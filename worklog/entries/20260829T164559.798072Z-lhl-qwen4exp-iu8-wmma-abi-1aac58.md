# Pin iu8 WMMA register ABI for kernel port

## Summary

Empirically pinned the register->matrix ABI of
`__builtin_amdgcn_wmma_i32_16x16x16_iu8_w32` on gfx1151 (RDNA3.5, wave32)
using one-hot sweeps and paired byte probes. Despite the 16x16x16 name, one
call computes `D[m=32][n=8] += sum_{k<16} Bside[m][k] * Aside[n][k]` with
exact signed int8 products accumulated in int32:

- Second operand (intx4, 16 signed bytes): thread t supplies row t's
  k=0..15; byte j = k j (identity order).
- First operand (intx4): byte j = k j of one column; even thread 2c supplies
  column c for D rows 0-15, odd thread 17+2c supplies column c for D rows
  16-31 (used threads: {0,2,...,14} U {17,19,...,31}; column data must be
  replicated in both row-halves).
- Accumulator (intx8): thread t holds D row t, ints i0..i7 = columns 0..7.
- Signedness verified: -1 x 1 -> -1 with the `true` sign flags.

## Changes

- No repo code; probes at /tmp/probe_i8abi{,2,3}.hip (compile with plain
  `hipcc --offload-arch=gfx1151`).

## Validation

- A-side one-hot x B-all-ones sweep: only threads {0,2..14,17,19..31} are
  read; each contributes to exactly one column of D (t/2 resp. (t-17)/2).
- B-side sweep: all 32 threads read, thread t -> D row t, all 8 ints.
- Paired one-hot 16x16 byte matrix: strictly diagonal (byte j of A multiplies
  only byte j of B), identity k-mapping on both operands.
- Signed test: -1 * 1 = -1.
