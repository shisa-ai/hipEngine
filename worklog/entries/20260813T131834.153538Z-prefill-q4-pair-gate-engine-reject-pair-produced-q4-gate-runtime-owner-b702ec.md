# Reject pair-produced Q4 gate runtime owner

## Summary

Rejected and removed the bounded pair-produced Q4T16 linear-attention gate
runtime policy. Complete quality passes, but the binding counterbalanced XTX
M512 engine row regresses with only 1/7 wins. The exact Q4T16 gate remains the
production owner; the separately retained runtime-unwired leaf remains useful
diagnostic evidence.

- Complete ten-prompt/four-category quality passes at **96.97% minimum prompt
  top-1**, max KL **0.016595**, deterministic repeats, and **1,440** asserted new
  gate pair launches. The first attempted ownership assertion expected only 24
  Q6-QKV peer layers; runtime correctly applies the shape policy to all 48 Q4
  gates, giving 144 M512 launches per candidate prompt.
- Counterbalanced XTX M512: **958.415 -> 956.960 tok/s (-0.152%)**, paired median
  **-0.181%**, only **1/7** wins. M1024 is **996.385 -> 997.268 (+0.089%)**,
  paired median **+0.093%**, 6/7 wins. Token trajectories and tracked peaks are
  exact; identical-owner decode is +0.023%/-0.085%.
- A 4K control was discarded before timing because the harness mutated package
  maps after session policy normalization and therefore observed a nonzero
  candidate delta under the baseline label. Since M512 already rejects the
  route, W7900 and remaining MTP/DFlash/trace safeguards were skipped.
- After removal, focused package/dispatch/shared-pair/scratch tests pass. JSON,
  worklog, ruff, and diff hygiene pass.
