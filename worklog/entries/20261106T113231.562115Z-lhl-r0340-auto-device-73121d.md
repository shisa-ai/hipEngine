# Validate automatic F16 alternate launch widths on device

## Summary

Automatic source-F16 single/triple dispatch now has device-level coverage of
alternate launch widths and generic K, without requiring a model checkpoint.

## Changes

- Add eight cases: K256/3072 at 64 threads, K3073 at 128 threads, and K4096
  at 256 threads, each with single and triple projection.
- Record the actual registry variant and compare device outputs byte-for-byte
  with the GEMV reference using the same launch width.
- Use context-local auto decode/prefill scopes so ambient diagnostics cannot
  change the test; free every allocation in teardown.
