# Qwen3.8 B3 clones independent state at arbitrary boundaries

## Summary

Implemented B3's exact arbitrary-boundary state clone primitive to GREEN. It
copies independently owned full-attention KV and recurrent state without using
prefix-cache sharing. No adapter caller or route changed.

## Implementation

`Qwen35GGUFResidentSession.clone_current_state_from` validates live distinct
sessions, current source boundary, reset destination, same runner/runtime/KV
format, disjoint page IDs, no deferred state, no live destination graphs, and
capacity. It zips source/destination physical page segments, copies every
full-attention storage/mirror/scale plane, copies every Conv/GDN pair, then
publishes the device and host cursor through the existing clone commit boundary.

The primitive supports the canonical 35-67 token request boundaries; it does
not weaken the older prefix-cache APIs' 256-token shared-page contracts.
