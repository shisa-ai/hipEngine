# Diagnose GGUF sampled decode and repair prefill logits ownership

## Summary

Repair the GGUF native sampler's first-token failure under a shared resident
batch owner. Packed prefill produces device logits on that owner, but selection
was called on the request's slot view, whose `_verify_lm_rows_capacity` is zero.
This is an ownership bug, not a missing allocation or kernel. The sampler stays
opt-in; no performance/default-promotion claim is made.

## Changes

- `_prefill_sampled_row` samples packed prefill logits on `packed_owner` while
  keeping `output_session=lease.session` for request-owned selected-token state.
- New unit regression covers both distinct batch-owner/slot objects and the
  standalone block-table path. It checks logits availability, output ownership,
  selected-token history, and no full-vocabulary D2H telemetry.
- This fixes the immediate capacity-zero blocker recorded on 2026-09-11 in
  `benchmarks/CHANGELOG.md`; it does not claim closure of that entire INT8 gate.

```python
import os
os.environ["HIPENGINE_QWEN35_NATIVE_SAMPLER"] = "1"
from hipengine import LLM, SamplingParams
llm = LLM("/models/gguf/Qwen3.8-27B-Q4_K_M.gguf",
          backend="hip_gfx1151", quant="gguf_q4_k_m",
          max_active_requests=4, max_sequence_length=512,
          kv_storage="bf16", prefix_cache="off",
          engine_command_timeout_seconds=15)
try:
    llm.prepare(max_sequence_length=512)
    for _ in range(2):
        output = llm.generate_detailed([[9707] * 64], SamplingParams(
            max_tokens=4, temperature=0.7, top_p=0.95,
            seed=17, ignore_eos=True))[0]
        print(output.generated_token_ids, output.telemetry.to_json_dict())
finally:
    llm.close()
```
