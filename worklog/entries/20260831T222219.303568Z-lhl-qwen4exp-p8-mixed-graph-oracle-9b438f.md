# Add Qwen4Exp mixed graph state oracle

## Summary

Extended the P8 probe across mixed GDN/QSA segments while preserving normal
runtime control ownership and the default one-layer diagnostic.

## Changes

- Added explicit default-false `position_prepared` plumbing to QSA layer/mixer
  execution. Normal callers still upload position/context exactly as before;
  capture diagnostics may stage fixed position before stream capture.
- Snapshot/restore/hash selected QSA K/V, position/context, raw/pooled index,
  selection, and complete decode-state owners.
- Added fixed-position host-cursor disclosure and unit coverage proving the
  prepared route skips the legacy-stream upload.

## Validation

The focused probe plus QSA bundle reports 8 passed. The original mixed capture
RED failed with HIP 906 because `set_position()` attempted a legacy-stream H2D
copy during non-default-stream capture. With explicit pre-staging, an
unretained layers-0..3 exploration passes four fixed-position output/device-
state replays and is positive. Task #63 will rerun clean and publish evidence.

## Next

production graph still requires device-owned position/index cursor updates and
exact K/V/span lifecycle; this parameter alone does not solve that ownership.
