# Repair merge-dropped Q4 T16 pair32_nwave nibble shift

## Summary

The origin/main merge (`5decbf124`) broke the Q4_K T16 selected-dual
`pair32_nwave` gate/up WMMA prefill kernel without a conflict. Main changed
`load_q4_t16_b_reg` from `(…, bool valid_col, …)` to `(…, int q_shift, …)`
(its K-major/LDS rewrite drops the validity branch and takes the per-lane
nibble shift). The branch-side `pair32_nwave` kernel still passed
`valid_col[tm] && expertN_valid`, which converts silently to a shift of 0/1,
so odd columns decoded the wrong nibble. Symptom: the Qwen3.6-35B-A3B Q4_K_M
layer-0 WMMA-vs-GEMV gate (`tests/test_live_qwen35_gguf_p10_x2_layer_correctness.py`)
went from max diff 0.000488 to 0.09375. Expert selection and the GEMV reference
were bit-identical to the parent; only the WMMA candidate moved.

A signature scan of every `.hip` file changed on both sides found no other
`__device__` helper whose parameter list changed on main.

The two other unverified GGUF live files had separate, non-kernel failures:

- `test_qwen35moe_prefill_default_selects_fast_bulk_with_native_fallback`
  fails on main itself: main added `_iq_dense_mmq_context()` to `prefill()`
  and the test's `object.__new__` session (backend left at `"auto"`) does not
  stub it. Test-only gap; real sessions resolve the backend in `__post_init__`.
- `test_split_prefill_divergence_boundaries_are_unchanged` (main-only pin):
  the branch passes `target_arch` into `resolve_prefill_config_for_sequence`,
  so resident sessions on gfx1151 now get the 256-row linear/MoE chunk
  profile, which main never applied there. A 257-token single call is then
  itself 256 + 1 and equals the split. The one-row-suffix divergence is
  unchanged: at 255 + 1 and 128 + 1 the merge matches main bit for bit.

## Changes

- `gguf_q4_k_t16_selected_prefill.hip`: `pair32_nwave` passes
  `q_shift = (lane16 & 1) * 4`; invalid lanes already decode from the clamped
  `sel` base and are dropped by the store loop, matching main's convention.
- `test_gpu_gguf_q4_k_t16_selected_wmma_prefill.py`: new bit-exact
  `pair32_nwave` vs compact32 test (bf16/fp16, four count layouts). RED on the
  unfixed merge (8 failed), GREEN after.
- `test_live_qwen35_gguf_runner.py`: stub `_iq_dense_mmq_context`.
- `test_live_qwen35_gguf_chunked_prefill.py`: pin the one-row-suffix
  divergence at 255 + 1 so the single call fits one chunk on every arch.
