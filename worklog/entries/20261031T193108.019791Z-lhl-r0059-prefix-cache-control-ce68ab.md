# Retain explicit prefix-cache rollback and correct CLI help

## Summary

Retain `HIPENGINE_PREFIX_CACHE=off` as a supported environment adapter alongside
`hipengine serve --prefix-cache off` and `LLM(prefix_cache="off")`. The explicit
cache policy already exists; removing the adapter would discard live operator
and cache-disabled comparison interfaces without simplifying cache ownership.
R0059's retention decision is complete and its ledger entry is removed.

## Changes

- Keep defaults, explicit CLI-over-environment precedence and disabled-cache
  comparisons unchanged. `docs/ENVS.md` already documents the adapter and the
  radix default.
- Fix an observed CLI help defect: engine-loop help still said `default: off`
  although the parser and `EngineLoopConfig` select `PREFIX_CACHE_DEFAULT`
  (`radix`). Derive help from that same constant.
- Add a host regression for help/default agreement and explicit environment
  and CLI intent, including both override directions.
