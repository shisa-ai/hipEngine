# Maintain live implicit build resolution and explicit library lifetime

## Summary

Keep live environment observation for implicit builds and caller-pinned explicit
library handles. R0446 does not require replacing the existing identity caches
with one global handle or moving every launcher into a runner. Focused identity
and public handle-lifetime validation pass. Remove R0446 from the active ledger;
its lifetime decision and evidence live here rather than remaining deferred.

## Changes

- Document the existing boundary in `docs/ARCHITECTURE.md`: implicit calls
  observe build inputs, explicit handles bypass resolution, and invalidation
  drops cache references without replacing callers' retained objects.
- Correct the invalidation docstring's suggestion that it releases loaded
  libraries. It clears Python cache references, not user-held handles.
- No build identity, dispatch arithmetic, kernel or production default changed.

## Validation

- Existing build/decode/pair-library bundle: 55 pass
  (`/tmp/r0446-focused.xml`), including warm identity, environment changes,
  invalidation, missing cached artifacts and variant/quant precedence.
- Public cached-library test passes: real kernel wrapper calls observe
  warm reuse, a fresh implicit handle after invalidation, a retained explicit
  handle bypassing the builder, normalized same-target environment changes,
  exact output repeats and allocation restoration.
- Ten new fake-loader lifetime cases plus existing build regressions: 32 pass
  (`/tmp/r0446-lifetime.xml`). They interleave variant flags, architectures,
  profiles, compiler identities and HIP/CUDA builds; retain explicit handles
  across invalidation; and exercise removed artifacts and changed source bytes.
- The memo intentionally observes raw call/environment inputs rather than
  source bytes or changed process compiler-version pins on a warm hit. Source
  changes and a newly selected process-version default require invalidation;
  the pin itself survives invalidation. Document that boundary instead of
  claiming live source-content observation.
- Public evidence: `/tmp/r0446-public.xml`. No compiler ran and no incompatible
  target executed; the environment change only normalized whitespace around
  the same target. Missing artifacts and distinct backends use CPU fake-loader
  evidence, not a claim that this GPU executes CUDA or another architecture.
- The first documentation check caught synthetic compiler macro names that
  looked like runtime environment keys. Rename those test-only macros without
  the `HIPENGINE_` prefix; no new configuration is introduced.
- Final lifetime regression rerun (32 tests), post-closure documentation,
  discovery and audit gates pass
  (`/tmp/kendex-pi-bg/bg-123-1793508190652.log`).
