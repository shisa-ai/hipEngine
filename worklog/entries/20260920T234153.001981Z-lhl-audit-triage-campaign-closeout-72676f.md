# Audit triage campaign close-out: all nine kinds triaged

## Summary

All nine original audit kinds are now fully triaged: 2,102 decisions over 3,179
rows, with **0 open and 0 stale rows** in `axis-branch`, `candidate`,
`doc-path-drift`, `flag`, `kernel`, `ledger`, `stub`,
`ungoverned-flag-branch`, and `unguarded-hip-test`. The budget is ratcheted to
a **zero ceiling for those nine kinds**, so the next untriaged row in any of
them fails `audit.py check` instead of landing silently.

A tenth kind, `worklog` (1,077 rows), was added mid-campaign by a concurrent
unit (`26746c281 feat: inventory the worklog as audit rows`). It is that unit's
campaign and is left open here; its ceiling of 1,076 is one below the current
count, so `check` currently reports that single overage and nothing else.

## Changes

- **Rebinding across three rescan waves.** The tree moved under the campaign
  repeatedly (capability admission, merges from `origin/main`, the v0.6.0
  release). Decisions whose row ids moved were re-attached by identity, not by
  id: 58 stub/doc-path-drift/ungoverned rows in the first wave, then 38 and 2
  more as new rows appeared. Every re-attachment records `rebound_from`.
- **216 false "phantom name" decisions corrected.** The earlier flag triage
  checked only literal `environ.get("X")` / `getenv("X")` reads, so it missed
  helper-mediated reads (`_env_flag`, `_env_int`, `_env_bool`, `_env_enabled`,
  `_env_value`, `_env_positive_int`, ...) and reads through a module constant
  (`_X_ENV = "HIPENGINE_X"` then `os.environ.get(_X_ENV, ...)`). Re-derived with
  both forms: **127** are governed flags with a `docs/REFACTOR.md` removal
  condition (keep), **55** are production-default configuration knobs or server
  CLI options (keep), and **34** are default-off runtime toggles with no
  recorded removal path and are re-tagged `DOC-DRIFT`/defer.
- **54 stale decisions re-confirmed** after checking each premise on the
  current tree (mention sites moved; environ-read status unchanged), plus 61
  ledger citations re-pointed to their new `docs/REFACTOR.md` lines.
- **New rows triaged**: one new ledger entry (Provider Prefix Checkpoint
  Rollback — live item, removal trigger and validation command present) and the
  new stub raise sites from the merged code, each recorded as a deliberate
  capability boundary.
- **Budget tool fix** (`audit/hipaudit/report.py`): `save_budget(lower_only=True)`
  dropped a kind from the payload once it had no untriaged rows, which silently
  removed the ceiling — new debt in a fully triaged kind would have gone
  ungated. It now keeps every previously recorded kind, including at zero.
