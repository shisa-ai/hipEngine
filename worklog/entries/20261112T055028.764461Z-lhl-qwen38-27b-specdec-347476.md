# DSpine refine verified-rows-only: host chain walk 25->8ms, net +1.4% (head projection dominates)

## Summary

Task #40 (reviewer P0.2), part 1 of 3: the DSpine GPU refine projected the head over all 15 block rows and ran the host transition-cache chain walk over all 15, but only `n_verify=5` drafts are verified. The greedy chain walk is left-to-right, so the first `n_verify` drafts are identical with or without the unverified tail. Limiting the refine to the verified rows cuts the host chain walk (the [n,K,H] head-row gather + score-table matmuls) **25.7 -> 8.0 ms median** and top-16 **5.3 -> ~1.7 ms**. Net matched decode **+1.4% (13.91 -> 14.10 tok/s, within thermal noise)** because the bandwidth-bound head projection (~18 ms, 2.5 GB BF16 at ~139 GB/s) dominates and does not shrink with rows. AR-exact, acceptance unchanged (0.520).

**Finding:** the reviewer's "cheap +13%" estimate for P0.2 is optimistic. The cheap part (verified-rows-only) is noise-level net; the real ~+10% lever is the head projection itself, which needs a Q8 f32-out head kernel (kernel work) or target-head reuse. Also fixed a latent buffer overread this exposed: `copy_device_to_host` defaults to `buffer.nbytes`, so copying the `n_max`-sized top-k buffer into an `n`-sized host array overflowed the heap (core dump) once `n < n_max`.

## Changes

- `hipengine/kernels/cpu_reference/dspine.py`: `refine_greedy_from_cand` derives `n` from `cand.shape[0]` and slices the stash to `[1:1+n]`, enabling a partial-row refine (backward compatible: full-block cand gives the same result).
- `hipengine/runtime/dspine.py`: `refine_gpu(..., n_rows=None)` projects/top-16s only the first `n_rows` proposal rows; buffers stay sized at `n_max=bs-1`; the top-k D2H copy passes `nbytes=n*K*4` (fixes the overread).
- `hipengine/speculative/dspine_cycle.py`: the GPU-refine path passes `n_rows=n_verify`.

## Validation

- Draft identity: `refine_gpu(n_rows=5)` == `refine_gpu(n_rows=15)[:5]` on identical forward state (code_merge_intervals, general_en_plan) — exact match.
- Matched full-mtpbench A/B (10 prompts, 25 tokens, 3 reps, gfx1151, Q8 drafter, verify 5, gpu-refine): original **13.91 tok/s** (AR 11.24) vs rows-only **14.10 tok/s** (AR 11.31), both `exact=True`, acceptance **0.520** both. +1.4%, within noise. Artifacts `/tmp/dspine_orig_r3.json`, `/tmp/dspine_rows5_r3.json`.
- Refine breakdown (per-kernel syncs, 21-22 cycles): head 20.2 ms (39.5%), top-16 5.3 ms (10.4%), host 25.7 ms (50.1%) before; host median 8.0 ms after. The host chain walk — not the head projection — was the largest single component.
- Core dump (`free(): invalid size`, EXIT=134) reproduced before the copy-size fix; EXIT=0 after. Original code (n==n_max) never overread.
- `pytest tests/test_unit_dspine_cpu_oracle.py`: 3 passed.
