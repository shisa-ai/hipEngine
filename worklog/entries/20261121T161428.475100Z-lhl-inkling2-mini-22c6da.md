# Batch Inkling expert routing over prompt rows

## Summary

Compute the routing projection and expert selection across the prompt block instead of projecting and transferring one token at a time.

## Changes

- Project each block once, apply the routing bias only to ranking, and normalize the selected uncorrected scores per row. Stable sorting still breaks ties by expert index; selected experts are still passed to the feed-forward owner in expert order. Ordinary decode still submits a vector.
