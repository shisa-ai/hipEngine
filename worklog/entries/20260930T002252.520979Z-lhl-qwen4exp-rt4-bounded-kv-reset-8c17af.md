# RT-4 bounded KV reset implemented and measured

## Summary

RT-4's proposed contract change is implemented and measured: `reset()` can clear
only the K/V bytes the request could have written instead of the full allocated
capacity, saving **14.17 ms per request at 128K capacity** (15.5 ms -> 1.13-1.74
ms, 11.0x).  The change is classified T1/exact because it skips only bytes the
invariant proves are already zero, and it is default-off behind
`HIPENGINE_QWEN4_EXP_BOUNDED_KV_RESET` pending the exactness gate.

**RT-4's recorded `6,144 MiB / 29.182 ms` at 128K is 2x too large.**  The row's
own footprint formula (`12 x 2 x 256 x 2 x 2B = 24,576 B/token`) yields
`131072 x 24,576 = 3,221,225,472 B = 3,072 MiB`, and this probe reaches the same
3,072 MiB from the allocated buffers independently, measuring 15.5 ms.  Halving
the row's time gives 14.59 ms against this run's 14.64 ms prediction.  The row's
bandwidth, footprint-per-token and waste-fraction conclusions are unaffected.

## Validation

**A/B at native capacity** (`scripts/qwen4exp_de5_reset_split.py --capacity
131072`, `code-p1024`, 64 decode steps, 12 attention states, model
`unsloth-Qwen3.8-Flash-Next-UD-Q4_K_XL` on the W7900):

| | flag=0 | flag=1 |
| --- | --- | --- |
| warmup `reset_ms` | 15.689 | 1.133 |
| rep1 `reset_ms` | 15.519 | 1.741 |
| decode last-eighth | 51.800 / 49.662 | 51.983 / 49.734 |

`kv_bytes_total` 3,221,225,472 B; predicted full clear at 220 GB/s 14.64 ms;
measured 15.17-15.33 ms (within 5%).  Decode is unaffected in both regimes, as
expected for a change that only skips zeroing already-zero bytes.

**Unit:** `tests/test_gpu_qwen4exp_kv_reset_bounded.py`, 5 passed.  The
load-bearing cases are the poison test (proves the clear is bounded, not a
renamed full memset) and the shorter-after-longer stale-KV test (the hazard the
row names explicitly).

**Soundness argument:** `allocate()` memsets the whole cache and KV writes only
land below `position` (block table is the identity `arange(blocks)`, never
mutated), so bytes at or above `round_up(position, block_size)` are already zero.
