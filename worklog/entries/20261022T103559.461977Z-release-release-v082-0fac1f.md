# Prepare and validate v0.8.2 for publication

## Summary

The lead asked for v0.8.2. The release packages the 24 GB GGUF context
recovery, exact-budget DMS sizing with the `max_tokens` clamp, and the
Flash-Next prefix reuse and prefill time sharing landed since v0.8.1.
Preparation changes metadata and documentation only.

## Changes

- `pyproject.toml` set to 0.8.2. A new `CHANGELOG.md` section covers the
  changes. The root README changes only the Current release summary and its
  release-note link, per `docs/HOWTO-README.md`.
- `docs/API.md` DMS sidecar paragraph now describes exact-budget store sizing
  and the `max_tokens` clamp (`finish_reason: "length"`, banner output limit).
- The 24 GB serving-capacity gate is not rerun. All six RX 7900 XTX cases
  passed on the current runtime code (see
  [the capacity-gate entry](20261021T184249.523532Z-lhl-xtx-24gb-dms-clamp-capacity-gate-010752.md));
  every commit since `0710386f0` is documentation-only.

## Validation

- Python 3.12 compileall passes. `hipengine --help` and `hipengine serve
  --help` pass. README export sync, all four documentation gates, and
  published-command drift pass. Artifact provenance: 184/184 cited
  artifacts, 0 violations, 15 existing warnings.
- Full `--suite all` with GPUs visible (W7900 + RX 7900 XTX) segfaulted at
  about 20% in
  `tests/test_gpu_qwen4exp_ar_batch_decode.py::test_serving_generator_decodes_two_rows_in_one_batch_step`
  (`qwen4_exp_gdn_decode_rowsplit_indexed_f32`, `qwen4_exp_gdn.py:692`).
  The crash reproduces 3/3 alone, on GPU0 alone, and on the `v0.8.1` tag, so
  it predates this release. v0.8.1's all-tier run hid ROCm and never executed
  it. Not fixed here; Flash-Next owns that path.
- Full `--suite all` with ROCm hidden (Bubblewrap tmpfs over `/opt/rocm`,
  clean env, matching the CPU-only publish runner): exit 0 in 508 s, 20,322
  passed, 6,375 skipped, no failures. Skipped GPU cases are not executed GPU
  validation.
- Fresh sdist-to-wheel build:
  `hipengine-0.8.2-py3-none-manylinux_2_39_x86_64.whl` (27,568,664 bytes) and
  `hipengine-0.8.2.tar.gz` (20,785,984 bytes) pass the size limit and twine
  check; the wheel declares `Root-Is-Purelib: false`. An isolated install
  outside the repo reports 0.8.2 and serves CLI help.
