# Keep GGUF decode-graph eager override as supported control (R0277)

## Summary

R0277 asked whether to keep or retire the GGUF decode-graph eager override
(`HIPENGINE_GGUF_DECODE_GRAPH=0`) and its comparison interfaces
(`scripts/gguf_decode_graph_g5.py`, the `scripts/gguf_mtp_bench.py` graph/eager
modes). Decision: keep them as supported controls. Graph replay is on by default
and capability-gated per backend; the opt-out is the documented rollback lever for
a path that is already on. This is the shape CLAUDE.md allows for a flag, and it
matches the lead's 2026-11-07 keep-supported-config calls on R0211/R0212 and
R0067. Retiring them would need a capture-inclusive public comparison on each
backend, including gfx1100, for no product gain. Reversible.

## Changes

- Removed R0277 from `docs/REFACTOR.md`. No code change; the `docs/ENVS.md` row
  already documents the rollback opt-out.
