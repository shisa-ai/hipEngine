# Add Qwen4Exp layer-2 production gate

## Summary

Added the durable complete-profile adapter required to qualify the reopened
layer-2 Q5_K grouped-WMMA route. It compares registered strict against the
current production stack plus the diagnostic post-binder route on identical
prompt/teacher-token schedules, evaluates the calibrated numerical envelope,
fingerprints request-local state, checks candidate repeatability/lifecycle, and
records free-generation task outputs without auto-approving divergences.

## Changes

- Added `scripts/qwen4exp_layer2_profile_gate.py`:
  - default 18-prompt category+heldout suite, 24 decode steps, 450 strict-teacher
    full-vocabulary rows, and three candidate repeats;
  - strict and production manifests plus hashes;
  - candidate/fallback registry preflight;
  - finite/layout/metadata/repeat-exact recurrent/PLE state fingerprints;
  - 32-token strict and two-repeat candidate free-generation task packet;
  - fail-closed `requires_task_review` for any deterministic cross-route output
    difference;
  - exact lifecycle and tracked-source requirements.
- Added five pure/registry tests for manifest serialization, state hashing,
  state-repeat rejection, task-review classification, and gfx1151
  candidate/fallback availability.
- Made `gguf_k_selected_prefill` an explicit gfx1151 alias source. Previously
  the alias depended on import order because the broad quant package did not
  import that module; a cold profile preflight therefore failed despite the
  runtime's direct wrapper import.
- Named the adapter in the P1 campaign checklist.
