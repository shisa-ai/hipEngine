# Fuse exact Qwen4Exp Q4 gate and up decode

## Summary

Promoted the registered exact raw-Q4 selected dual gate/up owner for Qwen4Exp
c1 decode. It halves Q4 launches and improves paired complete-model decode
2.55% with identical IDs and no new storage.

## Changes

- Qwen4Exp dynamically resolves `selected_dual_gemv_bf16_bf16_out` when c1
  gate/up share a quant key and the registry contains the exact sibling.
- Multirow, mixed-quant, and registry misses retain singleton projections.

## Validation

- 25 Q4 selected/Qwen4Exp tests pass; dual primitive matches two singletons.
- Counterbalanced median 5.276522→5.142086 s, 6.064601→6.223155 tok/s
  (+2.61%, 1.0261x), identical 32-token IDs.
- rocprof shows the expected dual symbol and Q4 launches 94→47/token; total
  launches 80,599→78,672 over 41 tokens. Cross-run clocks shifted globally,
  so absolute trace duration is not used as the speed claim.
- Zero new resident bytes.
