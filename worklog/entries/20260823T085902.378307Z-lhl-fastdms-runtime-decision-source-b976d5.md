# Integrate external DMS decision runtime

## Summary

Integrated the schema-v2 external decision source through a Qwen model-plugin
capability, registered CPU strict fallback, exact GGUF hidden-stage collector,
and compact-backend transaction bridge. Ordinary Q channels are never passed to
or mutated by the decision source.

## Changes

- Registered `(cpu_reference,dms_decision_source,bf16,
  external_linear_sidecar_v1)` with strict hidden/weight/bias/alpha validation.
- Added the Qwen hybrid model-plugin capability resolver. It verifies the
  physical full-attention map and input stage, advertises only prefill/decode,
  keeps prefix/speculative modes unsupported, and names dense BF16 as fallback.
- Added `DMSExternalDecisionRuntime` for registered prefill/decode projection,
  physical→compact mapping, transactional pack/append, and rollback after
  post-mutation host failures.
- Added `ExternalDMSDecisionCollector` at the exact GGUF pre-Q hidden boundary;
  it produces `[tokens,compact_layers,kv_heads]` decisions and records teacher
  vocabulary coverage without consuming Q/K.
- External schema-v2 compact backends now carry a decision-source-distinct
  kernel bundle key and expose decision source/layer map telemetry. Schema-v1
  bundle identity remains unchanged.
- Device-payload pack/append is deliberately rejected by this bridge because the
  existing transaction snapshot restores host metadata/payload dictionaries but
  not device compact bytes. This is fail-closed, not an inferred device pass.

## Validation

- RED: runtime tests failed import before the decision runtime/capability existed.
- 22 focused external-runtime and legacy compact-backend tests pass.
- Registered CPU projection matches exact hand-calculated logits/decisions.
- Qwen plugin rejects a wrong physical layer map; verify-chain fails before
  mutation; injected failure after host append restores live counts/positions.
- Exact Qwen3.8-27B Q4_K_M gfx1151 bulk prefill invokes the sidecar at all 16
  physical layers: decision shape `[4,16,4]`, teacher vocab 248,320, top-1 369,
  and metadata confirms Q preservation. The synthetic fixture sidecar marks all
  256 decisions positive, so this is boundary/mapping evidence only.
