# Select 0.8B fused dense-down residual route

## Summary

Selected combined Q4-pack8 + Q6-dense rounded-BF16 residual fusion for the sole
D08-D3B full-model gate. On all 24 current down weights it is bit-exact,
improves the complete package 1.171x, projects 0.165 ms / 1.99% graph saving,
and adds no bytes.

## Changes

- Added in-tree registered `linear+residual` siblings to the current Q4 pack8
t32 and dense-BF16 t256 bodies. Each rounds projection to BF16 before adding
BF16 residual and rounds the sum to BF16; primitive projection+add stays
registered.
- Added a HIP-guarded RED/GREEN test for four-axis registration, bit-exact GPU
comparison to the unfused chain, and an independent CPU rounded-BF16 boundary.
- Screened exactly frozen A) Q4 fusion, B) Q6 fusion, and C) combined package;
no thread/layout/repack variant was added.
- Published the screen artifact and updated the campaign, benchmark rollup,
changelog, and kernel catalog.

## Validation

- RED: the new test failed collection because both fused wrappers were absent.
  GREEN: all 3 registry/Q4/Q6 tests pass, with every result bit-exact.
- A: 1.1033 -> 1.0048 ms (1.098x), 18/20 sample and 5/5 block wins, projected
  0.101 ms / 1.21% graph saving.
- B: 1.1033 -> 0.9855 ms (1.119x), 19/20 and 5/5, projected 0.120 ms / 1.45%.
- C: 1.1033 -> 0.9420 ms (1.171x), 20/20 and 5/5, projected 0.165 ms / 1.99%
  and 310 -> 286 graph nodes. All 24 actual-weight rows are finite/bit-exact;
  persistent and hot-scratch deltas are zero.
- Cached-build `rocprofv3 --kernel-trace` records both expected `true` fused
  names and t32/t256 geometry. The profiler emits zero durations on this
  gfx1151/TheRock stack (known M2 blocker); 20 same-stream device-marker samples
  provide plausible durations.
- The affected bundle passes 64 tests before one unrelated Q5T16 gfx1151 lazy-
  bootstrap test failure. The failing node reproduces in a detached clean
  `bde03ee60` worktree, proving it predates D3B.
