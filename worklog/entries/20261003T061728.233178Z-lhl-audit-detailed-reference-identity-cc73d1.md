# Preserve detailed audit references without ambiguous reattachment

## Summary

first numeric field, preserving numeric detail fields. Reattachment requires
one unique best match in both directions; tied repeated sites remain open for
source review instead of inheriting decisions by row order.

  references, numeric detail preservation, stale evidence, repeated-site ties,
