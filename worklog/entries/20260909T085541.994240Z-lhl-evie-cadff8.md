# EVIE model contract, BF16 loader, registry plugin

## Summary

EVIE-4.5B is now a registered hipEngine model plugin (architecture
ColQwen3_5, name evie_4p5b) with a pinned spec parser, full expected-weight-
shape contract (725 tensors, 4.544B params in model.safetensors), and a
torch-free BF16->FP32 device loader.

## Changes

- `hipengine/models/evie.py`: EvieModelSpec / EvieModel plugin, layer-sequence
  metadata (vision + text layer primitives), parse_evie_model_spec with
  drift rejection against the pinned 4.5B geometry, expected_evie_weight_shapes
  for every tensor, validate_evie_weight_index (missing/extra/shape/dtype).
- `hipengine/loading/evie.py`: convert_evie_weight_to_fp32 (raw storage
  bytes, BF16 bit-shift view), materialize_evie_weights, load_evie_model.
- Registry export in `hipengine/models/__init__.py`.
- Tests: `tests/test_evie_model_contract.py` (4 passing, cached-snapshot
  validation guarded).

## Validation

- `python3 -m pytest tests/test_evie_model_contract.py -q`: 4 passed.
- Real checkpoint validates: 725 tensors, spec layer kinds [3,7,...,31] full.
- Registry: registered_models() includes evie_4p5b; kernel registry and
  worklog tests unaffected.
