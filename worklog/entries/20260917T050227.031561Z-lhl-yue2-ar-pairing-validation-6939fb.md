# YuE2 AR paired head validated on the session loop and the session gate

## Summary

Closes the production gates on the paired-branch lm head
(`worklog/entries/20260917T044041.101794Z-lhl-yue2-ar-paired-head-8d0d27.md`). The
kernel-level gate proves per-row bit identity and the replay matrix is unchanged, but a
caller consumes neither: they consume the session loop's tokens. This unit validates the
layers in between — per-branch logits, the combined CFG score row, the sampler's masked
score row and softmax distribution, the emitted tokens, the RNG stream, and session
lifecycle behaviour — and brings the published session-gate table current, which had been
left at its pre-M7 values.

## Changes

- `scripts/yue2_ar_pairing_validation.py` (new): drives the production
  `generate_tokens` at temperature 1.0 on two greedy-fixture cases, with a
  `_RecordingRuntime` subclass whose `logits` is the pre-pairing implementation (per-branch
  final norm into the single-row head) as the control. It records every returned logit row
  and compares the tokens, the RNG state, the truncation class, the CFG score row, the
  masked score row, the softmax distribution (max abs and KL) and the top-1. A lifecycle
  pass runs case A, then case B, then case A again in one process with a `runtime.reset()`
  between.
- `benchmarks/results/yue2_ar_pairing_validation_20260917.json`,
  `benchmarks/results/yue2_session_gate_paired_head_20260917.json` (new artifacts).
- `benchmarks/README.md`: the greedy session-gate table now carries the post-M7 numbers
  with a same-artifact link and an explicit note on what moved; the AR replay section
  records the paired-head re-run. `benchmarks/CHANGELOG.md`.
- No runtime, kernel or test change: this is a validation unit. No flag or fallback path
  was introduced, so `docs/REFACTOR.md` needs no entry; the serial-head control lives only
  inside the validation script.

## Validation

- `python3 scripts/yue2_ar_pairing_validation.py --json /tmp/yue2_ar_pairing_validation.json`
  -> **status pass**. On `mandarin-off-s1234` (CFG on, guidance 1.01, 98/12-token
  branches) and `english-melody-s1234` (CFG off): 64 generated tokens identical, RNG state
  identical, truncation class identical, `logits_exact` true with max abs 0.0,
  `cfg_scores_exact` true with max abs 0.0 and identical masks, `probs_exact` true with
  max abs 0.0 and KL 0.0, identical top-1 (163899), and **every** recorded step row exact
  (all-steps max abs 0.0), not just the first. Lifecycle: order
  `[mandarin-off-s1234, english-melody-s1234, mandarin-off-s1234]` in one process, each
  case's tokens reproduced exactly after the intervening case and a `runtime.reset()`.
- `python3 scripts/yue2_session_gate.py --json /tmp/yue2_session_gate_paired.json` ->
  **pass** on all three cases. Teacher-forced agreement: ABC 99.7% (`english-melody`) and
  99.1% (`english-full`); semantic 98.2% / 97.1% / 96.7% (full / melody / off). All above
  the 0.9 gate, prefix identity exact on every case, truncation class as expected.
- The same session gate was run for the M7 change, and its artifact records the
  post-change values as 99.7% / 99.1% ABC and 98.2% / 97.1% / 96.7% semantic
  (`benchmarks/results/yue2_m7_gemm_algorithm_20260917.json`,
  `session_gate_after_change`). Today's run reproduces those exactly, which is the
  session-level evidence that the paired head changes nothing a caller sees.
- AR replay with the paired head: status pass, pooled mean KL 1.1579e-3 over 576 rows and
  18 cases, top-8 recall 0.9588, and the `--repeat 1` aggregate byte-identical
  (`benchmarks/results/yue2_ar_replay_paired_head_20260917.json`,
  `..._repeat_20260917.json`). The committed M7 artifact reports 0.001158 for the same
  matrix, so the replay matrix is unchanged by this work as well.
- `python3 scripts/sync_benchmark_readme.py --check` -> blocks synchronized.

## Rollup correction

The published session-gate table showed `english-melody-s1234` ABC 100.0% and
`mandarin-off-s1234` semantic 96.1%, with `english-full-s1234` semantic 97.9%. Those are
the **pre-M7** values: the M7 artifact recorded the post-change values but the README
table was never updated. It now carries the post-M7 numbers (99.7% / 99.1% ABC,
98.2% / 97.1% / 96.7% semantic), links the new artifact, and states what moved and when.
The free-trajectory divergence columns also moved (38/18/17 to 27/2/23), which is the
same arithmetic change showing up in token space.
