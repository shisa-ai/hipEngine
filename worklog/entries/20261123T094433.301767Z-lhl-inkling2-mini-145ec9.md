# Share Inkling Q5_K gate-up token activations

## Summary

Q5_K tiled gate/up reads one activation row per token rather than uploading a copy for each selected expert. Route order, packed weights and per-output arithmetic are unchanged.

## Changes

- Register the shared-input Q5_K expert tile through the existing dispatch. It reuses the one- and two-output schedule and validates that the route count is divisible by the input repeat count. Individual-route and repeated-input tiles remain available.
