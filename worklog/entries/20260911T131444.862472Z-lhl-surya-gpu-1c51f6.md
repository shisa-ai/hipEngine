# Surya GPU coverage: rect page, request isolation, kernel trace

## Summary

Close the coverage and evidence gaps left by the review follow-up in
`worklog/entries/20260911T125739.777575Z-lhl-surya-gpu-7fef0c.md` (commit
`513015ff7`): rectangular-page vision parity, repeated-request isolation, and
the required `rocprofv3 --kernel-trace` entry for the Surya kernel family.

## Changes

- `tests/test_surya_gpu.py`
  - `test_gpu_vision_matches_oracle_rect`: non-square 14x22 grid
    (`page_rect.png`) against the `oracle_rect.npz` `vision_merged` tensor.
    This is the grid shape that exposed the tile-addressing class of bug in
    the square-only bring-up.
  - `test_gpu_repeated_request_isolation`: two pages on one runner, each run
    twice with a different page interleaved, both matching the CPU-reference
    greedy ids. Guards conv/GDN/KV state reset between requests.
  - Shared `_gpu_ocr_ids` / `_cpu_ocr_ids` / `_rect_inputs` helpers.
- `scripts/surya_gpu_rocprof_driver.py` (new): minimal rocprofv3 driver for one
  full OCR request, documented with the prebuild-then-cache-only recipe.
- `benchmarks/results/2026-09-11-gfx1151-surya-kernel-trace.json` (new):
  aggregated kernel trace.
- `docs/MODEL-SURYA.md`: status table rows for the trace and rect coverage.

## Validation

- `HIPENGINE_HIP_ARCH=gfx1151 python3 -m pytest tests/test_surya_gpu.py -q`
  → 7 passed.
- `rocprofv3 --kernel-trace --output-format csv -d /tmp/surya-rocprof -- env
  HIPENGINE_HIP_ARCH=gfx1151
  HIPENGINE_COMPILER_VERSION_FILE=/tmp/hipengine-hipcc-version.txt
  HIPENGINE_REQUIRE_CACHED_BUILD=1 python3
  scripts/surya_gpu_rocprof_driver.py --decode-steps 8` → 4495 kernel rows; all
  four Surya op kernels present with plausible durations:

  | Kernel | launches | total ms | avg us |
  | --- | --- | --- | --- |
  | `surya_split_qgate_kernel` | 48 | 0.115 | 2.40 |
  | `surya_gdn_l2norm_kernel` | 18 | 0.219 | 12.17 |
  | `surya_scatter_kv_kernel` | 96 | 0.171 | 1.78 |
  | `surya_causal_mask_scale_kernel` | 6 | 0.021 | 3.43 |
  | `qwen35_gdn_prefill_recurrent_kernel` | 144 | 33.863 | 235.16 |
  | `rocblas_gemm_plain` | 1571 | 277.527 | 176.66 |

  The reused EVIE vision kernels (`evie_rope`, `evie_layernorm`,
  `evie_gelu_tanh`, `evie_softmax_rows`, `evie_add_bias`) and the GDN
  conv/recurrent families are also present. No performance claim is derived
  from this trace; it establishes kernel identity, launch counts, and
  plausible durations.
