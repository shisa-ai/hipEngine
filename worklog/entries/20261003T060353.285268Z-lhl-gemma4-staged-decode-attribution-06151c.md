# Refresh staged-default Gemma decode attribution and optimize

## Summary

Task #34 profiles current production after the staged-PV prefill specialization.
The length-dependent decode cost is staged attention, especially singleton full
PV: at 8191 teacher-prefix tokens its five launches take about 24.4 ms in the
trace with two CTAs each. Dense and expert projections are substantial but
roughly flat over the measured depths. The default now uses a singleton PV
work decomposition with more independent dimension-slice CTAs and unchanged
arithmetic. Synthetic attention is 28.7–81.7% lower latency across ten shapes;
nine-pair fixed-context decode at 8191 is 64.84 → 37.97 ms. These are bounded
same-host results, not a refreshed free-running or llama.cpp curve.

## Changes

- Add `scripts/gemma4_decode_attribution.py`: load the public Gemma surface,
  prefill exact campaign prompt IDs, save a teacher token and fixed KV prefix,
  rewind before each singleton decode, and verify full-logit replay bits.
  Unprofiled forward/argmax/synchronize wall phases are recorded separately.
  Optional ROCTX windows enable fully contained kernel-family attribution;
  their wall time never substitutes for unprofiled latency. Optional cProfile
  records decode only, also diagnostic rather than clean latency.
- Add CPU accounting/trace contracts. Extend the existing staged microbenchmark
  with singleton-query key depths 127/513/2053/8191/17000, independent poisoned
  output/workspace capture, unchanged paired AB/BA measurement protocol.
- A bounded coder owns staged HIP/wrapper/primitive tests. Hypothesis: singleton
  PV at 32 threads, two resident GQA rows and independent 32-dimension slices
  creates more CTAs without splitting or reassociating any key chain. Multi-row
  launch remains unchanged; arbitrary/odd GQA and actual packed-Z bounds must
  work. Previously admitted singleton ratios that exceed the specialized packed
  Z limit use the existing eight-row launch rather than lose support. No new
  flag, evidence gate or profile branch is requested.
