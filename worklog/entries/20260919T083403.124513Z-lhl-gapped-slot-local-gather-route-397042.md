# Gapped slot-local prefill gather route

## Summary

A prefix-cache hit whose device-KV pages land non-contiguously used to drop the
whole packed prefill slab onto the native three-pass paged prefill kernel,
which the previous unit measured at a ~34x per-launch / 16.4x per-suffix-case
multiple of the AOTriton slot-local route. The gapped gather route closes that
gap with no new kernel: a gapped BF16 slot keeps the slot-local executor, its
identity spans are swapped for spans carrying the session's real chunk-local
block table, and the existing head-major paged-KV copy gathers those pages
into the same dense buffers the contiguous route feeds AOTriton. The forced
gapped 35B regression lane (2048+6144) went **134,511 ms -> 8,306 ms** against
8,226 ms contiguous; the 0.8B went 621.7 -> 168.1 ms against 166.9-167.0 ms.
The `HIPENGINE_GGUF_PREFIX_GAPPED_SUFFIX_MAX` decline now binds only when the
fast gapped route is unavailable (kill-switch, no head-major KV, oversized
context), so gapped hits of any suffix length are accepted where the gather
serves.

## Mechanism

The slot-local route reads a *rebased contiguous view* with identity spans -
that is exactly why it required contiguity. A gapped session has no rebase, so
the gather path keeps the pool-chunk base pointers and swaps the spans: the
paged KV write (`qwen35_write_paged_kv_mixed_value_bf16_prompt_spans`), the
native three-pass fallback (below the AOTriton threshold), and the
head-major copy (`qwen35_copy_paged_kv_bf16_to_head_major`, spans variant)
all address the scheduler-owned pages through the same block table, and
AOTriton then reads the gathered dense head-major buffers. On gfx1151 those
buffers are already allocated per session at full prefill capacity
(`GGUF_AOTRITON_HEAD_MAJOR_KV = True`), so the route change is pure plumbing
plus one ~0.1-2 ms gather per layer.

## Validation

- RED -> GREEN: `tests/test_unit_gguf_gapped_slot_local_prefill.py` failed at
  import before the helpers existed; 10 nodes pass after.
- `tests/test_unit_gguf_prefix_cache_runner.py` + the new file: **30 passed**;
  `tests/ -k "prefix or kvcache or device_kv or pool"`: **321 passed, 1
  failed** - the pre-existing `test_unit_grammar_masks` `llguidance` import,
  unrelated and documented in the previous unit.
- Route proof, 0.8B 2048+512, gfx1151, probe with hard route assertions:
  gapped arm `scatter=True, gather=True, slots=[0]`, suffix **168.1 ms**
  vs contiguous 166.9-167.0 ms; outputs identical (token 9708 in all arms).
  Kill-switch (`HIPENGINE_GGUF_GAPPED_GATHER=0`) restores the old route:
  616.5-621.7 ms, `gather=False`, same output.
- rocprofv3 `--kernel-trace` on the gapped arm after the change: `attn_fwd`
  24 calls / 80.2 ms; the native
  `qwen35_paged_full_attn_prefill_gqa_gate_bf16_kernel` has **zero launches**
  (it was 1,645.9 ms / 18 launches before). The warmup-fragmented source
  prefill that previously fell gapped onto the paged kernel also rides the
  gather now.
- Correctness, `scripts/gguf_prefix_reuse_gate.py` (active source = naturally
  gapped placement, the retained anchor geometry prefix 256 / suffix 1):
  **passed, output exact, every Conv/GDN and live K/V byte exact,
  teacher-forced KL 0.0** through the gather route. At prefix 2048 / suffix
  512 the gate's state-byte comparisons fail identically with the gather on
  and off (pre-existing repeated-token-prompt degeneracy: the source's greedy
  argmax flips between the two fill tokens; outputs stay exact and top-1
  agreement is 1.0 in both routes) - not caused by this change.
- 35B regression lane, Qwen3.6-35B-A3B `UD-Q4_K_M` (16q/2kv/256d, 10
  full-attn layers), gfx1151, forced gapped vs contiguous, prefix 2048 /
  suffix 6144:

  | arm | before | after |
  | --- | ---: | ---: |
  | contiguous | 8,185 ms | 8,226 ms |
  | gapped (forced) | 134,511 ms | **8,306 ms** |

  Same output token both arms; the gapped route is now within ~1% of
  contiguous. Single-run route diagnostics from
  `scripts/gguf_prefix_route_rocprof_probe.py`, not the retained benchmark
  protocol; the served multi-turn A/B follows in the rollup.
