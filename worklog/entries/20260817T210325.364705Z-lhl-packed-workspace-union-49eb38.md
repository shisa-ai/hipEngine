# Union-geometry persistent packed workspace and owner-shared bookkeeping

## Summary

Implements the four stability contracts pinned RED in
20260817T195210.103847Z: the packed verify workspace is sized once to the
union of every geometry the serving loop requests (prefill chunk rows,
physical packed width <= 8, 1024-token context cap) so prefill/decode
interleave performs zero hipMalloc/hipFree in steady state; genuine growth
fails closed while packed decode graphs bind the buffers; the batch owner
and its resident slot views share one mutable bookkeeping holder; and every
scratch allocation path is atomic on failure. Also adds a device
synchronize before workspace frees so queued async work cannot touch
returned pages.

## Changes

- `_PackedWorkspaceState` shared holder; the nine packed workspace fields
  became class properties redirecting to it, so all 80+ existing
  touchpoints work unchanged and owner/view see one state.
- `resident_slot_view` shares the holder, registers the view with the
  owner (`_resident_slot_views`) for graph-liveness scans, and no longer
  resets shared bookkeeping.
- `_ensure_packed_verify_workspace`: view delegation to
  `_resident_batch_owner`; union sizing via
  `_packed_verify_union_geometry` (defaults: slots 8, rows >= 128 or
  bulk-prefill rows, max_seq >= 1024); growth-only resize guarded by
  `_assert_no_live_packed_decode_graphs` and the existing dirty-state
  flush.
- `_free_packed_verify_workspace` and
  `_ensure_packed_ar_attention_workspace` synchronize the device before
  freeing and invalidate-safe guard the monotonic attention workspace.
- `_GGUFFullAttentionPrefillScratch.allocate` and
  `_allocate_prefill_scratch_liveness_owner_slots` are atomic: every
  buffer is tracked at allocation time and freed on any failure
  (fixes the burst-n=8 partial-failure leak/wedge).
- `_GGUFPackedTargetState.allocate` tracks conv/recurrent buffers before
  the memset that could previously leak the pair.
