# Use verifier strict fallback as quality teacher

## Summary

Corrected the numerical denominator in the 35B MTP2 production gate. The
second clean attempt showed that public strict AR IDs come from the packed
server decode owner, while the verifier's registered strict fallback is its
serial-exact target owner. Some prompts contain near-ties where those distinct
strict implementations choose different free-running tokens.

## Changes

- Autoregress the serial-exact verifier fallback itself to each absolute target
  position before strict/candidate full-logit comparison.
- Stop force-feeding unrelated packed-AR generated IDs into that strict
  fallback.
- Keep public strict AR outputs as the paired task and true-AR performance
  baseline, where they are the correct product denominator.
