# Frozen multi-sequence G0/G1/G2 DMS campaign evaluator

## Summary

Implemented the Phase A frozen multi-sequence distribution evaluator required by docs/campaigns/DMS-SELECTOR-IMPROVEMENT.md Section 4 (evaluation firewall and gates). The evaluator is independent of any candidate implementation: it consumes dense-teacher and candidate logits and decides pass/fail against frozen thresholds. No GPU/model runs, no free-running generation, no diagnostic oracle selectors, no final data generation, and no prompt-conditioned production routing were added in this unit.

## Changes

- Added `hipengine/benchmark/dms_campaign.py` (pure numpy/stdlib): frozen `GATE_THRESHOLDS` (G0 combined max-KL 0.001 / 100% top-1; G1 decode max-KL 0.05 and top-1 >= 0.90 per category with finite prefill/decode; G2 decode mean 0.001 / p95 0.005 / p99 0.02 / max 0.05 globally and per category, top-1 >= 0.99 global and >= 0.97 per category, prefill max-KL 0.05 and finite globally and per category), `compare_row` full-vocabulary KL with mismatch diagnostics (winners, strict margin, candidate rank of the strict winner, top-k overlap, max abs logit delta, nonfinite guards), `evaluate_gate` scope checks with row-coverage enforcement (a missing category fails every gate), rows-above-KL-0.02 and top-1 mismatch reports with sequence/category/step/phase identity, `load_manifest` with explicit split/category filtering and mandatory exact `expected_sequences_per_category`, `sequence_correlations` reporting repeated-prefix and identical-text-hash sequences as correlated groups rather than independent prompts, and `dms_digest` extracting an observed DMS capacity/mask/count digest for route verification.
- Added `scripts/qwen38_dms_campaign_quality.py`: CLI with `--gate g0|g1|g2`, required `--expected-sequences-per-category`, and the existing model/metadata/backend/codec/decode/modes options. Evaluates every selected manifest sequence separately (one dense BF16-KV teacher trajectory per sequence, then `no_evict`/`sidecar` candidate modes replaying the exact teacher input tokens), scores full-vocabulary prefill and decode rows, asserts no retained dense prefill pool, device payload presence, and tracked-allocation teardown to baseline, records prompt/source/category/step counts, exact model/metadata/data/evaluator SHA-256 hashes, route/backend/codec and git provenance. Heavy runtime imports are lazy so tests and `--help` never load the model stack.
- Added `tests/test_unit_dms_campaign_quality.py`: pure scoring/manifest tests covering every G2 threshold (mean/p95/p99/max/global top-1/per-category top-1) failing individually and jointly, G0 tightness and 100% top-1, G1 per-category max-KL/top-1 floors, prefill failure, nonfinite candidate logits failing all gates, sequence-count enforcement and split/category filter errors, full mismatch-diagnostics fields, rows-above-0.02 reporting, and repeated-prefix correlation reporting (shared token prefix and identical normalized-text hash grouped as correlated; verdict row counts carry independent-source-group counts and a "not independent prompts" note). RED confirmed first (module missing at collection), then GREEN.
