# Skip unused MTP prompt query projections

## Summary

The lead prioritized prefill gains and reducing the extra prefill cost of MTP.
The cache-only predictor prompt path was still projecting attention queries,
then discarding them. Use the existing standalone key normalization/rotation
operation and omit the unused query projection. Baseline is `9b7aa06af`, not
the earlier graph experiments.

## Changes

- Cache-only bulk QSA skips both attention-query and index-query projections.
  It still writes keys, values and index keys and preserves logical commit and
  cancellation handling. Ordinary target prefill retains the split query/key
  operation and its existing arithmetic.
- Both standard rotary positions and multi-axis rotary positions use their
  existing standalone normalization/rotation wrappers. Kernel source is unchanged.
- Add CPU regression coverage for both position modes, four row/start shapes,
  skipped projections, key geometry, stream identity and KV/index writes.

## Validation

  chunk boundaries and lengths 17, 65, 257 and 2052. Six GPU cases compare the
