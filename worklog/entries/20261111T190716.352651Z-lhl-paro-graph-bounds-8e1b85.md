# Repair Paro graph replay attention bounds

## Summary

Reproduced and repaired the first graph/eager state difference in
R0281-PARO-ARGRAPH. Attention spans captured the initial host context bound,
while device counts advanced on replay. The second replay exceeded that bound.
Capture now uses the declared replay-span bound and restores eager behavior
when capture exits, including exceptions. No kernel or graph eligibility policy
changed.
