# R0132 gfx1100 MoE native-context: Phase B diagnosis localizes arithmetic; Phase C admits MoE by capability

## Summary

R0132 Phase B ran the recorded gfx1100 MoE full-logit diagnosis at cycle ends 8/96/128
(eager and graph) with the MoE artifact `Qwen3.6-35B-A3B-UD-Q4_K_M.gguf`. The former
"eager native full-logit differs at p8 / p128 selected-state not localized" blocker is
localized: ownership/control is exact on every surface and only numeric values drift by
bounded production arithmetic (EXECUTION-PROFILES §4.1). Phase C therefore admits MoE by
structural capability instead of the 95 numeric fallback. The full gfx1100 validation matrix
(BF16/INT8 KV × eager/graph) and the public LLM MTP surface are green; the unit is committed.

## Phase B evidence (physical gfx1100/W7900, ROCm, PCI 0000:0d:00.0, KFD 47021)

- Ownership baseline: `tests/test_live_gguf_native_spec_cycle.py::test_native_b2_target_graph_matches_eager_hidden_state_and_kv`
  PASS (MoE native graph vs eager hidden/KV, max_seq 256).
- Eager native vs serial_exact (`scripts/gguf_mtp_long_context_gate.py --disable-target-graph`,
  cycle ends 8/96/128 × budgets 1/2/3): end96/end128 ALL surfaces byte-exact; end8 control exact
  (cursor/commit_position/accept_summary/acceptance/rollback) with tiny value drift
  KL mean 3.4e-4 / max 9.9e-4, top1 1.0. Artifact `/tmp/refactor-gfx1100/r0132-moe-eager.json`.
- Graph route (process-local `native_context_override` 256 to admit MoE graph above the 95
  fallback): graph submitted for all cases; ownership/control exact; value drift small —
  KL mean 0.0002–0.0054, max 0.0107, top1 1.0. Artifacts `r0132-moe-graph.json`,
  `r0132-moe-graph-kl.json`.
- Dense control (`Qwen3.8-27B-Q4_K_M.gguf`, no override): graph state/KV/hidden byte-exact at
  8/96/128. Confirms `cursor_exact=False` under `require_target_graph` is general deferred-position
  behavior (the gate skips the cursor check in graph mode), not a MoE failure. Artifact
  `r0132-dense-graph.json`.
- Classification: §4.1 permits KV/recurrent value and bounded MoE-expert drift when ownership,
  valid ranges and scatter/gather maps stay correct — which they do. This is the arithmetic branch,
  not an ownership failure. §6.1 calibrated envelope binds on the complete 450-row set; the 9-case
  probe is screening (top1 100%, max KL 0.0107 below the 2e-2 review threshold).
