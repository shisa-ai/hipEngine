# VibeVoice ASR front-end rocprof smoke and torch fixture prep

## Summary

rocprofv3 kernel-trace smoke for the new VibeVoice front-end kernels
(the repo's required evidence for new/ported kernels), plus the trace
driver script. Follow-up to
`20260913T212039.508803Z-lhl-vibevoice-asr-hip-encoder-aa97fd.md`.

## Changes

- `scripts/_vibevoice_rocprof_driver.py`: minimal front-end driver with a
  `--warm` prebuild mode; profiled run uses `require_cached=True` plus
  `HIPENGINE_COMPILER_VERSION_FILE` so the JIT cache key stays stable under
  rocprofv3 and no hipcc/clang is spawned in the profiled process.

## Validation

- gfx1151 (Radeon 8060S), `rocprofv3 --kernel-trace`, 2 s run over a
  48 000-sample PCM front-end forward: kernels observed under expected
  names with plausible durations - vv_depthwise_conv (9.7 ms x 106 +
  clone 3.0 ms x 108), vv_conv_gemm (2.2 ms x 52 + 0.7 ms x 53),
  vv_add_scaled_noise / vv_scale_residual family, vv_rmsnorm / vv_gelu in
  the dense-GEMM-dominated tail, plus reused dense_prefill/dense_dual
  wmma GEMM kernels (1.3 ms x 501). Trace db kept at
  /tmp/vv_rocprof/vv_results.db (scratch, not committed). Profiler
  string-attribution merges same-signature kernels, so per-kernel family
  totals are approximate; the smoke gate is name + plausible duration.
