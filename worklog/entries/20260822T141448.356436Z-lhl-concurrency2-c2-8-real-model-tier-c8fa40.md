# Qualify realistic model KV tier economics

## Summary

Replaced C2-8's repeated-payload economics proxy with actual model-produced KV.
A Qwen3.6-35B PARO p512 prefill yields 10 MiB of BF16 K/V across ten full-
attention layers. KVTC zlib compresses it to 7.58 MiB (1.319×). Median host
restore/decompression is 39.527 ms versus 185.705 ms same-loaded-model native
prefill, a 146.179 ms host-boundary saving.

This does not promote tiering: callback restore does not yet copy bytes into the
model GPU cache, timings are not HTTP TTFT, and offload compression costs about
0.56 s/object as maintenance.

## Changes

- Added `scripts/tier_model_kv_gate.py` to capture live BF16 K/V without writing
  raw payloads, measure restore/recompute, force host/NVMe pressure, restore,
  request cancellation, and final drain.
- Added `TieredKVCacheBackend.cancel_request()` for queued restore/offload work.
  Restore cancellation preserves the cold object and allocates no hot state;
  queued offload cancellation reclaims its owned hot lease.
- Added RED/GREEN cancellation coverage.
- Updated C2-8 audit evidence, Concurrency2, changelog, and compact artifact.

## Validation

- RED failed on absent `cancel_request`; GREEN passes.
- Full tier unit file: 10 passed.
- Actual gate: 10 MiB payload, SHA recorded but raw bytes not retained; three
  offloads spill one host/two NVMe, restore is byte-exact, one queued restore is
  canceled before maintenance, and final store/ledger are empty.
- Restore samples 39.527/39.564/38.167 ms; recompute prefill
  181.831/186.497/185.705 ms.
- Tier/audit focused bundle: 13 passed. Ruff, py_compile, JSON, Worklog2
  (581 entries), audit regeneration, README sync, and diff checks pass.

## Next

- Keep tiering default-off until integrated GPU-cache rehydrate and request-level
  TTFT/SLO policy are qualified. The realistic host-byte gate is complete.
