# P5 t2: kernel-family attribution from the trace

## Summary

Roadmap P5's kernel-family attribution deliverable, derived from the same
rocprofv3 kernel trace captured for the layer-outer promotion gate
(1,500-row prefill, cache-only recipe).

## Changes

- `benchmarks/results/2026-09-10-w7900-p5-kernel-family-attribution-1500.json`:
  per-family launch counts, times, shares, and findings.

## Validation

- 2.374 s total kernel time across 3,724 launches vs a 2.58 s wall
  (~92% kernel-busy): the prefill is GPU-bound, matching the direct
  route's profile.
- Family groups: FFN/dense WMMA 72.2%; native paged tail attention 18.0%;
  AOTriton round attention 1.0%; GDN/linear 5.5%; rocclr copies 0.5%.
- Key finding: the <512-row tail round pays 426.26 ms for 476 rows while
  the AOTriton round pays 22.71 ms for 1,024 rows (~18x per-row gap) -
  admitting AOTriton below the 512-row threshold on the packed route is
  the top remaining attention optimization.
- The 1,428 copyBuffer launches cost 10.87 ms total: the layer-outer
  executor's per-(layer, round) host work is not a material copy burden.
