# Separate GR-wide and production-composition numerical drift

## Summary

A four-arm comparison separates GR-wide's contribution from the remaining
production composition. Wide-on changes full-depth logits within both strict
and production. Production wide-off also misses the envelope against strict
wide-off. Disabling wide is therefore not a complete repair. No default,
arithmetic or threshold changed.

## Changes

- Saved the diagnostic in
  `audit/refactor-sweep/2026-11-01-r0028-isolation.json`: source/host/model,
  command, protocol, thresholds, numerical summaries, actual leaf counts,
  lifecycle and original report/script hashes.
- Narrowed R0028 to two independently observable problems: the wide/F16-operand
  projection composition and the remaining production composition.

## Validation

- `bg-59` failed before model construction because the temporary script had
  not registered execution-profile plans. Registering the gfx1151 kernels and
  profiles repaired the probe setup; `bg-60` completed all four arms.
- The diagnostic command and model identity are in the artifact. It uses four
  canonical p1024 categories, 64 forced decode steps, 260 rows per arm and one
  run, with the strict wide-off trajectory supplying the same teacher inputs.
  It is not a task, repeat-determinism or full-shape qualification gate.
- Strict wide-on: 384 actual F32-wide calls, mean KL 0.0018234358082457381,
  p95 0.012230574539486514 and top-1 0.9884615384615385 against strict
  wide-off. This isolates a contribution of enabling the wide composition;
  it does not distinguish F16 operand rounding from accumulation order.
- Production wide-off: no wide calls, mean KL 0.0016271298076533781,
  p95 0.0083804010788772 and top-1 0.9692307692307692 against strict
  wide-off. Other production changes independently contribute drift.
- Production wide-on: 384 actual residual-F16 wide calls, mean KL
  0.0015524815824572021, p95 0.006778611300082384 and top-1
  0.9884615384615385 against strict wide-off. Against production wide-off,
  mean KL is 0.0016453134201367123 and top-1 is 0.9692307692307692.
- All compared logits are finite. Both profile owners close with zero active
  allocations/current bytes. Strict wide-off self-comparison is exactly zero;
  it is a baseline construction check, not a repeat test.
