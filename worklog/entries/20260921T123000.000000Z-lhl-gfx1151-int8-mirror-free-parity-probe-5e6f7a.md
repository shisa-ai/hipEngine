# Expose an explicit mirror-free INT8 batch-parity diagnostic

## Summary

The existing `qwen38_int8_batch_decode_gate.py` correctly compares independent
C1 and row-batched trajectories, but it refused the rejected gfx1151 artifact
before execution and derived resident capacity only from the short prompt
lengths. That made it unsuitable for the needed mirror-free diagnostic probe.

## Changes

- Add `--allow-rejected-artifact` as an explicit diagnostic-only bypass for the
  artifact qualification refusal.
- Add `--max-sequence-length` so the probe can allocate a capacity above 8192 and
  reach the mirror-free INT8 regime.
- Preserve the existing explicit `--diagnostic-direct-rows` width override and
  require the requested trajectory to fit the chosen capacity.
- Add parser coverage for the new diagnostic controls.

The probe still records diagnostic status and does not promote a rejected
artifact. The live command must set the existing server-equivalent environment,
for example `HIPENGINE_GGUF_INT8_KV_ALLOW_UNVERIFIED=1`,
`HIPENGINE_GGUF_INT8_KV_ALLOW_UNVERIFIED_LONG=1`, and
`HIPENGINE_GGUF_INT8_KV_BF16_PREFIX_FULL_LAYERS=0`.
