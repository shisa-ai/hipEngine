# Suspend Flash-Next prefill at completed-layer boundaries

## Summary

Commit the completed runtime suspension primitive separately from the open
scheduler integration and changed-token-chunk numerical evaluation. With the
same input chunks, suspension preserves the existing arithmetic and state.
This commit does not select a different token chunk size or change a kernel.

## Changes

- Extract resumable iterators while keeping synchronous prefill wrappers.
- Yield only after completing residual work and synchronizing the device;
  isolate suspended dispatch context and invalidate shared activation mirrors.
- Keep final output-head work in a separate segment. Reset and close dispose
  of a pending iterator before state reuse or allocation teardown.
- Add CPU context/chunk/time-share tests and guarded GPU same-chunk parity and
  cancellation/reuse tests. Scheduler wiring is a separate pending unit.
