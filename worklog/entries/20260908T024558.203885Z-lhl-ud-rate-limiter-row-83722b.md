# Localize rate-limiter KL to output probability margin

## Summary

CPU inspection of existing captures narrows the rate-limiter row to an
output probability-margin discrepancy involving ` and` and `<|im_end|>`.
It does not identify a faulty layer or establish a correction. No GPU run,
runtime change, promotion, or performance claim.

This follows [the common-KV diagnostic](20260908T023520.305736Z-lhl-ud-ks-common-kv-5b669d.md)
and [the residual experiment](20260907T132243.865018Z-lhl-ud-residual-precision-4836b6.md).

## Changes

Added `scripts/ud_precision_row_diagnostic.py` and compact artifact
`benchmarks/results/2026-09-08-zbook-ud-rate-limiter-row.json`.
The script checks original teacher manifest hashes, wire/token alignment,
instrumented/prior bitwise logits, layer coverage and finiteness, residual
control parity and paired resident metadata. It computes full-vocabulary
KL and a three-bucket KL (teacher top two tokens and the complement), then
replays selected output rows using decoded Q6_K weights and saved final
hidden vectors. Token selection is analysis-only; no inference modification.
Selected K_S rows verify their consumed histories against K_M, because the
BF16-KV teacher used the K_M wire input. The script records input/source and
selected tensor hashes. Full live model identity is inherited from the
capture manifest, not newly rehashed.

Step 0 consumes absolute position 511, the final prefill token. Step 1
consumes absolute position 512, the first forced continuation token. Prior
layer capture used scalar prefill (`use_bulk=False`); this is not evidence
of a bulk-to-scalar dispatch transition.

| K_M rate-limiter step 1 | Teacher margin | Candidate margin | KL |
| --- | --- | --- | --- |
| Raw vs BF16-KV | 2.240633011 | 3.187547684 | 0.030410558805 |
| Raw vs F16-KV | 2.947946548 | 3.187547684 | 0.001270231771 |
| F32 residual vs BF16-KV | 2.240633011 | 1.973466873 | 0.003338362244 |

Margin is logit(` and`) minus logit(`<|im_end|>`). The three-bucket
partition preserves 99.96739% of raw K_M's KL.
For K_S, teacher/expanded/raw `<|im_end|>` probabilities are
0.030445760 / 0.014586578 /
0.004871948; raw KL is 0.030748560961.
Both raw arms retain the teacher's top-1 at this row. This row is a tail
fidelity issue, not the top-1 miss responsible for the K_S matched-teacher
aggregate failure. Nothing here justifies special-token correction or
prompt-specific behavior.

K_M CPU final-norm replay with BF16-rounded normalized input reproduces
our sampled margin at 3.187549521, versus
captured 3.187547684. Removing that BF16 rounding changes the replay
to 3.189538666. The F16-KV teacher-hidden F64 replay is
2.959789970, versus teacher capture
2.947946548. This supports an upstream hidden-vector discrepancy
rather than a large final-head arithmetic error for these sampled rows.
The teacher replay is not Q8_1 emulation and is not expected to be exact.

The final-layer relative RMS vs F16-KV teacher is
0.177399291 at rate-limiter step 0 and
0.143718927 at step 1: the KL spike does not coincide
with larger global final-hidden relative error. Hidden RMS alone is a poor
ranking signal here. The two teachers themselves differ substantially in
this row's margin, so existing F16-KV hidden captures cannot attribute the
larger BF16-KV KL discrepancy to a layer/state transition.
