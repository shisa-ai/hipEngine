# Dispatch raw GGUF projections from F32 activations

## Summary

Extended model-neutral GGUF linear dispatch to route raw quant weights from F32
activations to F32 outputs. Qwen4Exp GR reads are F32 and feed Q8/Q4/Q5/Q6
projections; this uses already registered raw GEMV kernels rather than adding
model or quant branches to the runner.

## Changes

- Added the generic `(raw_gguf, f32, f32)` dispatch-table entry using each
  resident weight's quant key and `gemv_f32_f32_out` variant.
- Added a Q5_K resolution regression alongside the existing BF16 routes.
