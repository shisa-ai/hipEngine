# Extend native sampled MTP to concurrent groups and repair warmup

## Summary

Extend the default native sampled MTP route from one to four active requests
on the existing Qwen3.8 Q4_K_M/gfx1151/BF16/capacity-four/K3 serving scope.
Fix the explicit-concurrency startup probe without changing request prefill
policy. Final live repeatability, concurrency and lifecycle validation passes;
no new speed claim.

## Changes

- Packed target verification now requires full logits whenever any request
  samples, bypassing the greedy-only fused top1 producer. Request-local spans
  are sampled with NativeSamplerChainWorkspace, then passed to the existing
  GPU prefix acceptance and selected-state commit. Bounded top-k/history
  processors use private hypothetical-prefix states and native per-row draws.
  Host rollback rows retain host sampling with commit-only RNG advancement.
- Exact request/transaction/span checks precede sampler launches. Workspaces
  are adapter-owned, reused per owner/row shape, and closed with the adapter.
  Each committed request advances only its own sampling state.
- Add separate automatic policy rows for physical c1/c2/c3/c4 without changing
  greedy policy. No other backend/artifact or wider capacity is implied.
- Startup scratch probing previously loaded unused legacy draft assets and
  instantiated a MoE block-40 runner for dense block-64 NextN. Remove those
  unused allocations: the probe already executes target prefill/verification,
  and the live NextN provider still prepares itself on real request admission.
- Fix NextN checkpoint capture's last-consumed versus next-input cursor
  confusion: scratch position/context are saved without adding another token
  to the batch session cursor on restore. Sampled canonical state rebuild no
  longer compares its committed token with a new greedy prediction.
- Clarify missing-depth sampled-graph diagnostics and retrieve actual warmup
  errors from the request adapter state, not the sampler state.
- The existing dirty runner prefix changes are preserved. Only the packed
  verifier `require_logits` and initial-state-owner preservation hunks belong
  to this unit.
