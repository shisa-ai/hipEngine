# The census audit's two malformed-row flags: one is a cell mis-assignment, the other is real staleness

## Summary

The §11 census audit issued exactly two "MALFORMED, FLAGGED NOT SETTLED" flags,
both asserting that a row's *First-bounded-experiment* column holds a **state**
where an experiment belongs. Both were checked against the rows' own table
headers by counting cells. **One flag is wrong and one is right but mis-framed.**

## `PL-1` — the flag is a cell mis-assignment, and is withdrawn

The audit claimed `PL-1`'s experiment column reads *"OPEN — workload-dependent, not
a warm-kernel priority"* and therefore "holds a STATE where an experiment belongs".

`PL-1` sits under the four-column header `ID | Mechanism / evidence | First bounded
experiment and deciding gate | State`, and its row has **four cells**. The text the
audit quoted is in the **`State`** column — where a state belongs. The experiment
column holds a complete bounded experiment:

> Measure gather, dedup/scatter, I/O and H2D separately on declared warm and
> cold/new-row category inputs. Compare the existing mmap path with one changed
> copy/read mechanism; inventory weight pinning/residency, startup fragmentation
> and KV-versus-page-cache budget, and charge host RSS/page-cache pressure and
> first-token wall. Advance only for a declared serving scope with a
> complete-request benefit, not another warm sweep or unchanged direct-to-ring
> layout.

That is a measurement protocol, a comparison, an inventory and a deciding gate. The
row is well-formed, the flag is withdrawn, and `PL-1` **stays actionable with its
experiment unchanged**.

## `X-7` — the flag is correct, and the fix is a column update, not a closure

`X-7` sits under the five-column header `ID | Item | Evidence | First bounded
experiment | State` and has **five cells**, so its mapping is also unambiguous. Its
experiment column read *"Close before extending the admitted scope"* — an instruction
to close rather than an experiment to run, exactly as the flag said.

The flag's inference from that ("if the admitted scope is now closed the row is done;
if it is not, the column should name what is still owed") is the part that needed
reading rather than applying, because the row's State cell is a long, actively-worked
record that has since **named the outstanding work itself**:

> "**Not decided here:** whether a route with a ~0.4 per-logit delta can meet a 1e-3
> mean-KL limit on a 4-row scope at every prompt - that is a scope-and-threshold
> question for the qualification packet, and this row stays open on it."

So the column is stale, not the row, and the stale text predates every entry above it
in the State cell. The experiment column now carries the work the State cell had
already named: settle the scope-and-threshold policy — whether a route whose per-logit
perturbation is ~0.4 can meet the 1e-3 mean-KL limit on a 4-row `prefill_last` scope
at every prompt, and if it cannot, set the limit, the scope row count or the route's
admitted scope accordingly, then requalify on the long-form heldout fixture.

## One attribution error of my own, corrected in the same pass

The `GD-1` text committed minutes earlier in `551e62e5e` echoed the census's wording
and called *"Inside noise, not additive"* the row's **Evidence** column. `GD-1` sits
under `ID | Mechanism / measured cost | Opportunity and limit | First bounded
experiment | Track | State`, so the correct name is **Opportunity and limit**. The
substantive conclusion is unaffected — the figure's source artifact settles that
column either way — but the column reference is now right in both places it appears.

## Validation

Docs-only change. Cell counts were checked programmatically against each row's own
header: `PL-1` 4/4, `X-7` 5/5, `GD-1` 6/6, and every other section-7 row still maps
to its header. `MALFORMED` no longer appears in the ledger.

A first version of the `PL-1` text quoted the header inline with escaped pipes
(`ID \| Mechanism / evidence \| ...`). Escaped pipes do not split a GFM cell, but
they *do* inflate a naive pipe count — the same class of ambiguity this census
family has been tripping over — so the header is now named without them.
