# Complete RF3 MTP lifecycle correctness

## Summary

Completed RF3 lifecycle correctness for dense GGUF MTP on gfx1151. Request-owned
cancellation/deadline checkpoints, deterministic fault boundaries, terminal
transaction ownership, EOS/stop trim, graph failures, safe server shutdown, and
post-fault health now have direct evidence. Automatic MTP remains disabled.

## Changes

- Added stable phase hooks at before proposal, after proposal/before target,
  after target prepare, after target commit, after draft repair, before output
  publication, and after publication.
- Poll request cancellation/deadline both before cycle mutation and after the
  owned target+draft cycle is terminal, suppressing non-streaming publication
  when cancellation arrives in flight.
- Fixed stale immutable transaction cleanup: once scheduler KV commit succeeds,
  exception handling cannot attempt rollback through the old pre-commit object.
- Threaded the request-owned checkpoint from the dense generator into every MTP
  cycle. Removed the unscoped module-global termination flag in favor of the
  existing per-request cancellation token.
- Changed forced server shutdown to cancel tokens and wait for the actual model
  thread/GPU owner to retire before engine close. Public futures/streams receive
  cancellation immediately, but their unkillable threadpool work is not raced.
- Added `scripts/gguf_mtp_lifecycle_gate.py` and focused CPU/server/graph-fault
  tests.

## Validation

- Real gfx1151 artifact: 11/11 passed in 120.10 s
  (`/tmp/mtp-rf3-lifecycle-final-v2.json`): six injected phases, in-flight
  cancel, in-flight deadline, EOS at prefill, EOS in cycle, and stop token in
  cycle. Every fault left no prepared verifier transaction and was followed by
  exact AR and MTP health with complete lifecycle phase records.
- The first real packet found an illegal post-commit rollback attempt at

- Six server control tests pass: caller cancellation acknowledgement, deadline

- Memory peak 18,720,029,538 bytes / 1026 allocations; final current bytes and

  `benchmarks/results/2026-08-22-gfx1151-qwen36-27b-rf3-lifecycle.json`.
