# Correct SPECDEC2 activation rollback to K0

## Summary

Correct the temporary P2 activation rollback semantics before using it for
baseline A/B. Explicit streaming-off originally selected the prompt-hidden
capture fallback, but p512+ cannot stage that path because `hidden_seeds` is
absent when streaming is disabled in the current packed prefill call. The route
honestly selected K0, making strict-route bridge validation fail.

The rollback should be K0 by design: it is cheaper and more representative of
the actual pre-P2 operator fallback than paying an obsolete full-prompt replay.
