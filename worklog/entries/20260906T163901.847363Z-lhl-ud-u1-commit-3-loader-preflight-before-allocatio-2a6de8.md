# UD-U1 commit 3: loader preflight before allocation, resident preset key, identity-caller binding

## Summary

Real runtime-caller integration for UD-U1 admission: the production GGUF
materialization path now preflights every requested AR operation over every
planned slot BEFORE any device allocation, refuses unsupported artifacts with
the aggregated refusal list, and binds the artifact admission preset key into
the resident record and the K_M/K_S identity callers (runner policy identity,
packaged hot-vocabulary selection). Plain controls keep byte-identical
behavior; same-stamp UD artifacts can no longer inherit plain-certified
identities.

## Changes

- `hipengine/loading/qwen35_gguf_materialize.py`:
  - `materialize_qwen35_gguf_weights` resolves the trailing NextN structural
    map (needed for the pinned manifest fingerprint), runs
    `preflight_qwen35_gguf_artifact(DEFAULT_AR_OPERATIONS, ...)` and raises
    `Qwen35GGUFAdmissionError` before `plan_qwen35_gguf_materialization`,
    arena creation, or any `malloc` (proven by allocation-sentinel tests).
  - `plan_qwen35_gguf_materialization` / `_plan_layer` gain an optional
    `slot_filter` so the loader's `selected_slots` test/debug hook plans (and
    preflights) exactly the requested subset — a qualified subset of a UD file
    still materializes while unsupported slots stay refused for full loads.
  - `Qwen35GGUFResidentWeights` gains `artifact_preset_key` (None for the
    plain stamp lane), set from the admission report's resolved preset.
- `hipengine/runtime/qwen35_gguf_runner.py`: `_gguf_policy_identity` extends
  the policy-table key with the artifact preset key when one is bound —
  plain keeps the historical `(geometry, file_type)` key (all existing
  policy tables resolve unchanged), while a same-stamp UD preset yields a
  3-part key that misses plain-certified tables and falls back to generic
  paths. `ensure_device_token_embedding` propagates the preset key.
- `hipengine/loading/gguf_mtp_hot_vocab.py`: `default_gguf_hot_vocab_path`
  accepts an optional artifact preset key appended to the packaged-selection
  identity, so a UD artifact never reuses a plain artifact's packaged
  hot-vocabulary certification under the same stamp.
- `hipengine/loading/qwen35_gguf_nextn_materialize.py`: resolves the AR
  artifact preset from the same reader (GGUFModelInfo-guarded so stub-based
  tests are unaffected) and passes it into the hot-vocabulary identity.
- `tests/test_gguf_ud_admission.py` additions: allocation-sentinel proofs
  (UD full load → admission refusal with zero allocator invocations and every
  refused slot named; plain 0.8B control → reaches allocation; UD selected
  subset → reaches allocation), runner policy-identity table-miss proof,
  hot-vocab identity binding, resident preset-key field, preflight
  `slot_filter` scoping.
