# Reject dense 27B in-place GDN scratch alias

## Summary

Rejected and removed the exact compact-GDN `prefill_value`/`recurrent_out` in-place scratch candidate. It saved **66.5 MiB tracked / 65.984 MiB whole-device** at 8K, but complete 8K prefill regressed **1.321%** versus a same-tree no-alias control. The no-prefill-regression requirement binds; the current published matrix remains unchanged.

## Changes

- Added RED coverage for distinct value/output pointers and an alias-safe compact recurrence signature, then proved the temporary in-place path matched separate-output BF16 results and FP32 recurrent-state bits exactly on gfx1100.
- Temporarily admitted the alias only for the model/quant/backend-qualified compact-peer mode; the 4096-row planned bulk scratch fell **480.987 -> 414.487 MiB**.
- Removed all kernel, registry-policy, planner, and test changes after the binding regression. No selector, fallback, dead route, or compiled artifact remains in the repository.
- Preserved the rejection evidence in `benchmarks/results/2026-08-14-qwen36-27b-gdn-value-recurrent-alias-rejected.json`.

## Validation

- RED failed both the kernel no-alias signature and planner pointer equality; GREEN passed the focused planner tests and live gfx1100 in-place output/state bit oracle.
- Selector-unset XTX 512/128 remained within noise at **-0.101% prefill / -0.105% decode**, saved **0.5 MiB tracked**, and saved no sampled whole-device memory.
- Selector-unset XTX 8K/128 moved **821.496 -> 811.399 tok/s (-1.229%)** versus the prior retained matrix while saving **66.5 MiB tracked / 65.984 MiB whole-device**; all IDs stayed 9707 and logits finite.
- A fresh same-tree 8K no-alias control reached **822.260 tok/s**, making the candidate regression **1.321%**. It also showed the relaxed kernel qualifier alone was not the loss (**+0.093%** versus retained).
- A counterbalanced actual-geometry M4096 prepare+recurrent+RMSNorm leaf found in-place **1.275% faster**, localizing the full-engine loss to the arena repack/address-color change rather than recurrence arithmetic.
- After removal, `git diff` is empty for every production/test path touched by the candidate; JSON parsing, worklog validation, and diff checks pass.

## Next

- Skip this exact arena repack. Audit a materially larger structural owner or a placement-stable contraction; do not trade 8K prefill for the 65.984-MiB sampled saving.
