# Characterize the residual divergence: deterministic, input-independent, not routing

## Summary

Follow-up on the residual boundary divergence recorded after the pinned-upload fix. The corrupting visits are structurally fixed (17, 29, 47), independent of prompt and row count, and are not accompanied by expert-route flips. The mechanism is still unidentified.

## Changes

- Measured boundary divergence across two prompts and two row counts.
- Compared expert routes and gate logits between host and block at the corrupting visits (via instrumented capture of both paths).

## Validation

64-row and 32-row runs, fast profile, hip_gfx1100, fresh processes; prompts: Japanese library prompt and an English sentence. Boundary divergence:

| boundary | 64 rows, JA prompt | 32 rows, JA prompt | 64 rows, EN prompt |
| --- | ---: | ---: | ---: |
| 18 | 2.558e+02 | 2.511e+02 | 2.907e+02 |
| 30 | 2.716e+02 | 2.716e+02 | 2.479e+02 |
| 42 | 1.183e-04 | 4.959e-05 | 2.060e-04 |
| 48 | 7.291e+01 | 6.608e+01 | 9.836e+01 |

- Same boundaries corrupt across all three configurations; magnitudes vary modestly. This is not a property of the prompt or of sequence length.
- At visit 29, block vs host gate logits differ by at most 1.4e-05 and the selected expert sets are identical for every row, so the divergence is not an expert-routing flip at that visit.
- Elevated but small errors (1e-04 class) appear at several non-corrupting global-attention boundaries (23, 35, 41), suggesting progressive fp-level drift that is normally absorbed but occasionally crosses into a discrete divergence. The trigger is unidentified; candidates remaining: a softcap/clip boundary in the attention or gate path, or a subtly different math path in the global (dynamic-conv) attention the host and block both take.
- Passes 2 and 3 restore the identical saved prelude hidden state yet do not reproduce each other's outcome, so the divergence path is not a simple monotonic accumulation of fp error; it is input-state dependent in a way not explained by saved state alone.
