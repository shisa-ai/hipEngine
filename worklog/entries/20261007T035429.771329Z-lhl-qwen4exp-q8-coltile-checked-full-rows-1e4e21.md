# Screen checked-int32/full-four-row dense Q8_0 DPP coltile sibling

## Summary

The separately registered diagnostic sibling
`coltile8_rowbatch4_wave_scale_pipelined_dpp_checked_full_rows_f32_f32_out`
is 1.111–1.506x faster than the current dense DPP owner
`coltile8_rowbatch4_wave_scale_pipelined_dpp_f32_f32_out` across 48 real-weight,
complete dense Q8_0 projection cases (rows 512/1024/4096, layers 0/22, eight
shapes). Geometric mean 1.409x; 48/48 case medians improve and both arm orders
win every case; every measured pair is bit-identical. The candidate is
default-off, no production selector points at it, and the generic DPP parent is
the fallback for tails/overflows/unsupported shapes. This is synthetic-input
operation evidence, not a model rate and not a default change.
