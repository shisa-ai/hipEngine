# Make diagnostic overrides take effect for resource-owning selectors

## Summary

`--override` was advertised as applying a diagnostic route change after the
named-profile binder, and two things made that promise false for two of the ten
disabled selectors. Neither would have shown up as an error: both would have
been measured as a neutral selector and reported as "worth nothing".

1. `HIPENGINE_QWEN4_EXP_Q8_MMQ_PREFILL` owns MMQ sidecar buffers that the
   binder allocates in its own pass. With the production default the binder
   reads `0` and returns early, so flipping the flag afterwards left the
   selector on with no buffers behind it.
2. `HIPENGINE_QWEN4_EXP_Q4_IU8_PREFILL` is unreachable while
   `EXACT_GROUPED_Q4=1`, the production default: the exact risk+repair branch is
   an earlier arm of the same `if`/`elif` chain in `qwen4_exp_runner`, so the
   fast suffix is never consulted.

## Changes

- `scripts/qwen4exp_profile_gap.py`: `_apply_post_binder_overrides` takes an
  optional `runner` and re-runs the binder's own
  `configure_mmq_prefill_resources` hook when the override leaves
  `Q8_MMQ_PREFILL` truthy. This mirrors what `qwen4exp_journey_localize.py`
  already does by hand at its own override site.
- `scripts/qwen4exp_context_decode_profile.py`: passes its runner through.
- `scripts/qwen4exp_disabled_selector_ranking.py`: the `q4_iu8` arm becomes
  `q4_iu8_fast` and sets `Q4_IU8_EXACT=0`; `all_prefill` does the same. The
  arm table carries the shadowing note next to the definition.
- `tests/test_unit_qwen4exp_disabled_selector_ranking.py`: adds a guard that
  any arm enabling `Q4_IU8_PREFILL` also disables its shadow.

  tests/test_unit_qwen4exp_profile_gap.py
  tests/test_unit_qwen4exp_context_decode_profile.py` → 23 passed.
- Read from the dispatch, not assumed: `qwen4_exp_runner` lines 3989
  (`if q4_iu8_exact:`), 4143 (`elif exact_grouped_down:`) and 4170
  (`elif weights["expert_gate"].spec.quant_key == "gguf_q4_k":`) place the

  `EXACT_GROUPED_Q4` to `1` unconditionally in the production binder.
- The other eight disabled selectors were read for the same problem and have
  direct gates: `PRODUCTION_MOE_PREFILL` (runner 3308), `Q8_MMQ_PREFILL`
  (6507, 6557), `GR_IU8` (3266), `GR_IU8_DOWN` (3246), `GDN_PEER_PREFILL`
  (5841), `GDN_COLWARPS_PREFILL` (5848), `QSA_FLASH_PREFILL` (2726),
  `Q8_IU8_WMM` (`runtime/gguf_linear.py` 2818, 3362).

## Consequence For Prior Runs

No committed measurement is affected: the configure hook is reachable only
when `Q8_MMQ_PREFILL` is truthy, and no retained capture set it. This entry is
the record that the mechanism, not the measurements, was wrong.
