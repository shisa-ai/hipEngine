# Avoid retrying failed packed growth lease release

## Summary

Packed arena selection retried a failed growth-lease release through its outer
exception handler. Both incompatible eager/growth cleanup and replacement-binding
refusal did this. Clear the local ownership token before invoking release so an
exception propagates without a second call against partially released ownership.

## Changes

- Transfer each refusal cleanup key out of the pending ownership variable before
  release in `hipengine/runtime/gguf_packed_backing.py`.
- Add two fault-injection regressions in the packed-layout unit file.

  chunk-local consumer and DMS migration remains open.
