# Exercise public profile composition in the packed numerical gate

## Summary

Extend the existing packed numerical gate with public strict/default session
construction so legacy FP16-storage diagnostics cannot masquerade as
whole-profile evidence.

## Changes

- --public-profiles leases a configured public owner and configures seven
  shared-runner peer sessions through the same generator. ExitStack closes
  every child, lease and model on failures and success.
- Preserve both actual manifests and state/KV identity; public mode no longer
  labels the candidate as a forced FP16-storage experiment.
- Public mode requires static C2/C4/C8; the original legacy mode keeps its
  C4/C8 matrix and metadata. Dynamic, sparse, repeat and isolation gates are
  reused unchanged.

## Validation

- RED: missing public session factory and unsupported C2 both reproduced.
- GREEN: 25 packed-gate/public-profile/tier tests passed.
- No runtime dispatch or kernel source changed in this harness unit.
