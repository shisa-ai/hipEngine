# Bind packed MTP verifier roots to resident linear state

## Summary

Packed K1 target verification copied every request's Conv/GDN root state into
its temporary packed slab before every cycle even when all sessions already
owned stable rows in the shared resident state slab. A warmed C8 attribution
measured 9,216 D2D imports and 8,002,732,032 imported bytes per arm from
`_sync_packed_verify_initial_state`; the kernel trace recorded 17,309 total
copy kernels / 90.1 ms versus AR's 796 / 6.3 ms.

The verifier now resolves the existing package-owned
`GGUF_DIRECT_RESIDENT_LINEAR_STATE` capability, binds its read-only root state
indices directly, and skips only those initial Conv/GDN imports. Candidate
state rows remain separately captured and the selected accepted row is still
committed explicitly. Any ownership/capability miss retains the previous
packed-state copy chain.

On the full canonical ten-prompt C6/C8 D24 K1 screen, the minimum MTP/true-AR
ratio improves **0.882563 -> 0.893444 (+1.23%)**. C6 is
36.018/39.995 = **0.900581x** and C8 is 42.613/47.696 = **0.893444x**;
20/20 cells are exact, engaged, and budget-conformant. This is an exact
intermediate dataflow win, not a production MTP promotion; both cells remain
below own AR and the loop's 1.15x target.

## Changes
