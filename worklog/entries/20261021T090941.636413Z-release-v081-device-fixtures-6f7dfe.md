# Isolate release fixtures from host GPU availability

## Summary

The completed Python 3.12 v0.8.1 no-ROCm release run found three device-
availability failures in integration tests. The Laguna fixture replaces model
weights and execution but left device admission attached to the physical host.
The Vulkan probe checked compiler/library availability but assumed a physical
device could initialize. These repairs change tests only, not runtime behavior.

## Changes

- The Laguna generator fixture supplies a selected gfx1151 device alongside its gfx1151 fake weights/session. The real compatibility check still runs, now against the fixture's device rather than the host's gfx1100 devices.
- The Vulkan timing probe returns a distinct unavailable status for an incompatible driver, failed physical-device initialization, or an empty physical-device list. Pytest reports that status as a skip with the probe's reason. Other Vulkan errors still fail, including enumeration failures other than initialization; their result code is printed.

## Validation

- RED: the completed Python 3.12 no-ROCm full suite reports 19889 passing cases, three failures and 6335 skips/expected failures in 574.115 seconds. The two Laguna failures name `BackendDeviceCapabilityError` for the fixture's gfx1151 backend on the host's gfx1100 device. The Vulkan probe exits 3. A separate scalar loader probe confirms `vkCreateInstance=0`, `vkEnumeratePhysicalDevices=-3` (`VK_ERROR_INITIALIZATION_FAILED`), count zero, when device files are hidden.
- GREEN: `bash /tmp/hipengine-v081-no-rocm.sh python -m pytest tests/test_integration_generation_laguna_gguf.py tests/test_integration_micro_vulkan_multi_queue_timing.py tests/test_unit_backend_device_capability.py -q -ra --junitxml=/tmp/hipengine-v081-focused.xml` gives 79 passes and one explicit Vulkan-unavailable skip in 2.224 seconds. Both original Laguna failures now pass and the original Vulkan failure now names its missing device precondition.
- With host device access restored, `env -u LD_LIBRARY_PATH -u HIPENGINE_HIP_ARCH -u HIP_VISIBLE_DEVICES /tmp/hipengine-v081-venv/bin/python -m pytest tests/test_integration_micro_vulkan_multi_queue_timing.py -q -ra --junitxml=/tmp/hipengine-v081-vulkan-host.xml` passes both tests, with no skips, in 1.251 seconds. The timing probe therefore still executes when its hardware is available.
- Preserve the completed broad result plus focused repair evidence. No full local suite rerun is needed for two isolated test-file changes; the immutable-tag publishing workflow will execute its required full release suite on the hosted runner.
