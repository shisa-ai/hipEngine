# Integrate bounded real Qwen4Exp chunked prefill

## Summary

Integrated bounded multirow prefill through the complete resident Qwen4Exp
model. Size 2 passes the first real Q4-XL serial/teacher smoke and is retained
as an explicit candidate; strict public generation remains serial until the
complete production-profile and long-QSA gates pass.

## Changes

- Added bounded prompt scratch/metadata ownership and full-model chunk
  composition across embedding, PLE, GR, GDN, QSA, MoE, final head, mutable
  recurrent/PLE/KV/index state, and teardown.
- Added `prefill_serial()` and explicit `prefill_chunked()` controls; public
  `prefill()` remains the registered strict serial fallback. The comparator now
  supports serial/chunked/both modes, chunk sizing, serial-to-chunk logits, and
  measured prefill walls.
- Corrected the existing runner token staging ABI from INT32 to INT64. The
  embedding kernels consume `int64_t`; c1 had worked accidentally because the
  upper four bytes of its one-token allocation were zero, while an INT32 array
  made adjacent prompt IDs become invalid INT64 values.
- Generalized the BF16 embedding branch-repeat primitive to explicit
  `(rows, branches, hidden)` ownership and added a multirow distinct-input RED.
- Rejected size 9 and neutral strict-order experiments; restored the faster bulk
  PLE/GDN/QSA/MoE leaves rather than retaining changes with no numerical gain.

## Validation

- Final `PYTHONMALLOC=debug` component/model/generation bundle: 29 passed.
- Cached gfx1151 `rocprofv3 --kernel-trace` records the generalized
  `repeat_bf16_branches_kernel(..., rows, branches, hidden)` at 1,683 ns.
- Real artifact: Unsloth Qwen3.8-Flash-Next UD-Q4_K_XL, four hash-verified
  shards, prompt `The answer to 2 + 2 is`, gfx1151 128 GiB unified W7900 lane,
  context 2,051, exact command:
  `uv run python scripts/qwen4_exp_compare_logits.py /models/gguf/unsloth-Qwen3.8-Flash-Next-UD-Q4_K_XL/UD-Q4_K_XL --prompt 'The answer to 2 + 2 is' --context 2051 --prefill-mode both --prefill-chunk-size 2 --json-out /tmp/qwen4exp-chunked-both-size2.json`.
- Size 2: teacher/serial/chunk top-1 all 220; teacher→chunk KL 0.0051036;
  serial→chunk KL 0.0040972; tracked teardown zero; serial 2.193096 s,
  chunked 1.209922 s (1.813×, 44.8% lower wall). This is a single-prompt
  implementation smoke, not a retained public performance claim; compact
  artifact: `benchmarks/results/2026-08-27-gfx1151-qwen38-flash-next-chunked-prefill-smoke.json`.
- Size 9 rejection: teacher top-1 remains 220 but serial→chunk KL 0.097543;
  0.800727 s versus 2.311568 s cannot be retained under the numerical gate.
  Serial PLE and strict row-ordered recurrence/attention/MoE reductions were
  measured neutral and removed.
