# Retain Q8T16 rowtiling from physical c4

## Summary

Independently requalified the historical gfx1151 Qwen3.6 Q8T16 broad rowtile
candidate under the calibrated production-numerics contract. Keep the direct
c2 owner, but retain all-projection rowtiling at physical c4/c8: strict-teacher
quality is bit-identical across the complete adapter matrix and current-package
counterbalanced wall improves both admitted shapes.

## Changes

- Added backend capability `GGUF_Q8_T16_DECODE_ROWTILE_MIN_ROWS`: gfx1151 is 4,
  gfx1100 remains 0, and the old unrestricted bool remains false.
- Packed enqueue resolves the capability from physical rows. C2 stays direct;
  c4 uses rowtile4 singleton/pair/triple; c8 preserves its existing rowtile4-
  col8 pair and adds rowtile4 singleton/triple.
- Added RED/GREEN policy tests and backend capability assertions.
- Added compact quality and retained decision artifacts; updated campaign,
  concurrency, env, refactor, scoreboard, and benchmark changelog guidance.
