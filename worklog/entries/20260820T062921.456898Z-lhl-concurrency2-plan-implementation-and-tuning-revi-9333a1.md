# Concurrency2 plan implementation and tuning review handoff

## Summary

Reviewed Generation-2 architecture, its 82 branch commits, the recent c1-c8
Qwen3.8 tuning, kernel dispatch/correctness coverage, scheduler reachability,
benchmark/profiler harnesses, worklog claims, and the dirty Q4
`ROW_TILE=16/32` prototype. Core architecture is retained: one model-owning
`EngineService`, independent child lifecycle/output, stable request/resident/
execution identities, format-neutral resource ledger, global backend pool,
`KVLiveSpans`, token-budget rounds, exact grouping, and registered strict
fallbacks are the right foundation for arbitrary c=N.

The review found the width-adaptive handoff materially inconsistent with source:

1. Direct c5/c6/c7 are one native physical group, not c4+c1 decomposition.
2. Group decomposition already exists, but it is largest-width chunking plus
   ceiling padding—not an artifact-backed cost optimizer.
3. The production owner advertises only `(1,2,4,8)`, so direct c3/c5/c6/c7
   tuning is not product-reachable; logical c5-c7 run masked c8 today.
4. The old `step − Q4 probe ×64` FFN/non-FFN split was structurally invalid.
5. Active AR decode has exactly 64 Q6 projection calls + 48 Q5 calls = 112;
   the prior 114 expectation incorrectly counted block 64 (NextN) Q6 down/V.
6. Q5 has a true rowtile only through 4. Planar-qmicro Q6 has a true rowtile
   through 4; its same-named rows5/6 wrapper actually launches direct per-row
   GEMV, then rows7/8 use padded WMMA.
7. Q4 standard rows5-8 lacked targeted strict primitive coverage, and Q4
   qmicro rows5-7 could dispatch unsupported HIP cases.
8. The direct-width benchmark and profiler harnesses were incomplete/stale:
   c3/c5/c6/c7 were not in the default correctness packet, and profiler
   admission/family classification excluded their threshold traces.

All implementation/harness defects above are repaired in committed units:

- `c8d8abc93` — standard Q4T16 rows2-8 strict coverage; qmicro fails closed

- `20fc18aba` — merged the five main hot-path library-hoist commits; retained
