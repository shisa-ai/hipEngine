# IQ4_XS gate/up dual on the cooperative structure (+census 6ms, 0.950x parity)

## Summary

The last named lever of the prefill-parity run: a fused IQ4_XS gate/up
dual with SiLU, the raw-IQ port of the Q5 T16 dual. One 256-thread
block owns a 32-column x 256-row tile for BOTH matrices; each
activation K16 fragment feeds both matrices' WMMA chains and the two
LDS weight slabs are decoded once per block with the IQ4_XS fast path
(one 136-byte block per 32-K scale group per column, d hoisted, fused
LDS codebook). Both accumulators are bf16-rounded before the SiLU
exactly like the unfused pair, so the route is bit-exact with the
two-singles path.

## Measurements

- Leaf: 2.57ms vs 2.72ms for two 64-column cooperative singles at the
  (17408, 5120) gate/up shape (1.06x) - the 32-column dual's shared
  activation loads match the 64-column singles' amortization, so the
  gain is the fused epilogue and half the launches.
- Census: the 40 pairable IQ4_XS singles moved from 148.5ms of single
  time into 89.7 + 52.5ms (pairs x20); wall 558.1 -> 556.9ms.
- E2E: K_M prefill 930.8 -> 933.2 tok/s, decode unchanged (26.1).
  Campaign total: 590.9 -> 933.2 = +58%; parity vs plain Q4_K_M
  (982.8) = 0.950x (0.60x at campaign start).
