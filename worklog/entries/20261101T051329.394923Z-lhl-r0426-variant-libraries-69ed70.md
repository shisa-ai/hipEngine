# Honor variant libraries in pair and fused SiLU launch plans

## Summary

Pair and fused-SiLU execution ignored variant-specific libraries in favor of
legacy quant keys. Route both through the existing variant-aware owner while
preserving each plan's ordered fallbacks. Remove only the completed library
subitem from R0426; its controls, census and diagnostic decisions remain open.

## Changes

- `_variant_scoped_library` accepts optional ordered fallback keys; ordinary
  linear callers keep quant fallback by default. Explicit variant `None` is
  authoritative, as it is for ordinary linear launches.
- Paired execution supplies its plan's existing library keys. Fused-SiLU
  execution supplies its existing legacy key. Mixed-quant aliases and separate
  Q8 activation-quantizer lookups are unchanged.
- No kernel bodies, registry routes, arithmetic or default selections change.
  The residual composite already checks fused/normal variants before quant.
