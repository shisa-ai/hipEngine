# TimesFM 2.5/3.0: Framework Desktop gfx1151 lane recorded as separate rows

## Summary

The retained TimesFM 2.5 and 3.0 rows were all measured on the power- and
heat-limited **zbook** lane. The same workloads now have their own rows on the
**Framework Desktop** lane (host `gfx1151`, machine ID
`55ea6c509d0b49eea8de7094a1023668`), so the two physical Strix Halo hosts are
visible side by side:

| Workload | zbook (retained) | Framework Desktop (new) | Framework lower by |
| --- | ---: | ---: | ---: |
| TimesFM 2.5 200M, b8/ctx8192/h512 | 0.0823 s | **0.0621 s** | 24.6% |
| TimesFM 3.0 500M, b8/3 var/ctx8192/h512 | 0.3213 s | **0.2197 s** | 31.6% |

Both machines run the same `gfx1151` backend and identical code, so the gap is
**host power/thermal headroom, not a code improvement**. It is recorded as two
independent lanes and is explicitly **not** retainable as an old→new delta; no
same-host A/B was run because no code changed.
