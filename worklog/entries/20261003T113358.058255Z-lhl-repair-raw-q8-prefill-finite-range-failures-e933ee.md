# Repair raw Q8 prefill finite-range failures

## Summary

Raw Q8 WMMA prefill narrowed finite BF16 GeGLU activations (up to about 1.55e7
in the tiny Gemma fixture) to FP16, yielding infinities and NaN accumulators.
The six recorded runner failures reproduce before repair. Recompute only
non-finite WMMA accumulators from original activations and raw Q8 weights in
FP32, as the existing T16 owner already does. Do not clamp inputs or scale the
fixture. This is a finite-range correctness repair, not a performance claim.

## Changes

- Add a raw-Q8 FP32 recomputation helper and use it at single/dual WMMA stores.
  Finite WMMA accumulators retain the prior arithmetic unchanged.
- Add nine GPU range regressions over BF16/F32 inputs and rows 4/17/33,
  covering non-tile-aligned single-output width 24 and both dual outputs with
  opposite-sign Q8 scales, using the independent CPU dequantized oracle.
  No tolerance or existing fixture is weakened.
- Strengthen the public `LLM.generate()` test to read and check finite device
  logits after native greedy forwards, including a four-token prefill. The
  first instrumentation attempt targeted host `forward()` and correctly failed
  to witness the native-greedy route; the final test checks `forward_argmax()`
  without redirecting production generation.
