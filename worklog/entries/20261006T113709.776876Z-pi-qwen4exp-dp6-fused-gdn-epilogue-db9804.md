# Define bounded DP-6 fused GDN projection epilogue candidate

## Summary

DP-6 pricing identifies the Qwen4Exp GDN SSM causal convolution as the
largest eligible epilogue pass (58.036 ms in the corrected X-3 scope, 0.369%
of the kernel union; the earlier 116.121 ms figure included a different
capture). The in-tree target is the GDN `attn_qkv` Q8_0 wide F16-input
projection followed by the fixed-K4 FP32 causal convolution in
`run_qwen4_exp_gdn_token_mixer`; there is no `ssm_in` GEMM symbol in this tree.

The first experiment is deliberately bounded and default-off: add a separately
registered raw-pointer `dense_wide256_f16in_f32_f32_out_conv_k4` sibling only
for the existing production shape `(rows 4096, K 2560, N 10240)` and only for
GDN layer IDs 13-47 under the existing wide F16 activation session. The fused
leaf writes the ordinary F32 QKV projection result and immediately applies the
same four serial FMA products plus SiLU using the existing per-layer conv
weights/state; it updates the same `conv_state` ABI after the projection. The
ordinary dense-wide leaf plus exact conv kernel remain the strict fallback.

The candidate must not alter the model's output ABI, QKV layout, recurrent state,
KV or decode path. It must not claim exact bit parity merely from source order:
the first RED contract is finite output, state isolation, deterministic repeat,
CPU reference agreement within the existing production envelope, and exact
fallback registration. Any arithmetic drift is measured through the production
profile gates; if the fused operation cannot meet the gate it stays off.

## Scope and gates before implementation

- Selection: explicit env override only; unset/`0` uses the current dense-wide
  projection and standalone exact convolution. No model-profile promotion in
  this unit.
- Shape: `rows == 4096`, `in_features == 2560`, `out_features == 10240`,
  `conv_kernel == 4`, GDN only, layer 13-47, `hip_gfx1151` production UD
  F16-input route. All other shapes/backends/quantifications fall back.
- ABI: raw device pointers; Q8_0 weight layout is read by the same dequant
  helpers as the parent. The fused output must match a separately run parent
  projection plus exact conv on fixture and natural activation inputs, and the
  input projection buffer remains absent because only its consumer is fused.
- State: initial conv state is not modified until the same logical point as the
  parent; final state equals parent after synchronization. Repeated execution
  and back-to-back layers must not alias workspace or state.
- Validation: unit route/registration/fallback RED tests first; HIP synthetic
  output/state/CPU-reference gate; native canonical plus category-heldout
  state/KV/logit/ID comparison; operation timing with alternating arm order.
  Promotion requires a complete production profile gate and an end-to-end A/B;
  otherwise retain the candidate only as default-off diagnostic or reject it.
