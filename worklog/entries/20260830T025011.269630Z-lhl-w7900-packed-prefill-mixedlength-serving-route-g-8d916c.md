# W7900 Qwen3.8: the equal-length prefill rule is AR-route policy, not a runner limit - serving route groups mixed lengths today

## Summary

I wrote a RED test expecting the runner to reject a mixed-length prefill group and
**it passed**. The serving route reaches `prefill_batch_native` with arbitrary
prompt lengths today (`qwen35_gguf.py:3025`, chunked only by slot count), so the
equal-length rule is a policy of the **resident AR route's**
`_try_prefill_native_work_batch` alone. #8 therefore needs no padded/masked kernel
work: declare the capability and align the AR guard with the serving route's
policy, qualified against the strict per-request chain.

## Validation

`pytest tests/test_generation_qwen35_gguf_sampling.py -k packed_prefill -q` ->
7 passed, including both new tests and the five pre-existing packed-prefill tests
(one-native-c8-slab, notimplemented-falls-back, etc.). The new characterization test
asserts a single batch call whose rows cover `{4, 2, 1}` token lengths, i.e. grouping
genuinely spans mixed lengths rather than being re-split by length.

Call-site reading: `_try_prefill_native_work_batch` (line 6401) requires equal chunk
lengths and `chunk == row.prompt_ids`; the serving route at line 3025 imposes neither
and passes `prompt_batch` of whatever lengths the wave holds. Both reach the same
`getattr(owner, "prefill_batch_native")` entry point, which is why the guard, not the
runner, is the difference.

Supersedes the inference in
`...20260830T024125...packed-prefill-grouping-guards-unreachable-c0cacc.md`: its
guard description is still accurate, but its implication that grouped prefill
"therefore implements only the same-length case" for the engine as a whole is wrong.

No-RED rationale (recorded per `AGENTS.md`): I could not write a cheap RED test for
the resident AR route, because `Qwen35GGUFResidentModelRunner` (line 4975) needs a
generator plus a leased session graph and no existing test constructs it. The
empirical substitute is already running: the capability 1-vs-8 A/B on the real
mixed-length suite (predicted neutral by the guard), the runner-level grouping probe,
and the equal-length wave ceiling, which together measure rather than argue whether
the guard relaxation delivers.
