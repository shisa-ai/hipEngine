## Decisions

- DFlash2 delta is drafter-side only: (1) two-tap grouped dynamic conv
  (group 16, kernel 2, before/after each attn+MLP sublayer, 20 applications
  across 5 layers) and (2) low-rank bilinear top-16 candidate selector
  (rank 256, greedy walk). Verifier/accept/commit machinery stays the chain
  path; no tree work.
- Drafter snapshot validated locally: `DFlash2DraftModel`, 5 sliding-attention
  layers (2048 bidirectional window, 32Q/8KV/D128, q/k head norms), fc over
  5x5120 taps at target layers [5,19,33,47,61], target-shared output head,
  vocab 248320, block 8, mask 248070, BF16, 81 tensors (~3.85 GiB).
- Reference repo cloned read-only to `~/dflash` (z-lab/dflash @ 07ebd93);
  reference math read from `dflash/model.py`. llama.cpp PR #27342 +
  `incoai/Qwen3.8-27B-DFlash2-GGUF` recorded as comparator lanes.
- Campaign doc: `docs/QWEN38-27B-DFLASH2-CAMPAIGN.md`, milestones D0-D6
  (metadata/oracle -> drafter backbone -> native conv/selector/top-K head
  kernels -> B=7 native rows verify -> gfx1151 measurement vs exact MTP B3
  1.7845x -> gfx1100 correctness-only -> closeout). Promotion rule: must beat
  own exact MTP B3 with exact AR equality on the full mtpbench suite.
- Backend ownership flagged: DFlash speculative kernels live in the
  hip_gfx1100 package while the tuned lane is gfx1151; a small registry
  layout unit precedes kernel work. No backend branches in engine code.
