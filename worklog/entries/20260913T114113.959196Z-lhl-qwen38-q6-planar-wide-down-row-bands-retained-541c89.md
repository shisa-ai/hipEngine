# gfx1151 planar Q6 wide-down bands: retained artifact, rollup, and tracked-peak scope

## Summary

Retains the `fca92ac62` wide-down prefill retile with its compact artifact,
scoreboard row, changelog entry, and a clean 128-token-decode rerun. The
rerun reproduces the change at +7.65%/+5.00%/+7.56% (512/1024/4096) with
prefill CV <= 0.14%.

The same session also resolved a provenance question that the scoreboard row
depends on. The public table's `Tracked peak` column read 24.153 GiB, measured
at `a2f62c881` in the frozen release export. Re-running the identical command
on this host against the live checkout reports 37.428 GiB, and that number is
not caused by the retile: the live tree's pre-change arm at `b98417620` also
reports 37.428 GiB. The extra 13.275 GiB is
`a038c2f9f feat: size the dense GGUF resident context from free HIP memory`,
which sizes the resident context from free device memory instead of a fixed
small context; on this 120 GB host that reservation dominates the allocator
high-water mark. Session-owned peak is identical in both trees (19.810 GiB),
sampled device-used peak differs by 1.5 GiB (26.289 vs 24.789 GiB), and the
pre-change prefill rates agree within 0.21%, so this is a scope change in the
column, not a memory or throughput regression.
