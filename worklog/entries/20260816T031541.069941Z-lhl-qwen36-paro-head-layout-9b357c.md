# Fix canonical PARO linear-attention head layout

## Summary

Fixed the first exact-checkpoint divergence in hipEngine's packed PARO runtime. The checkpoint retains Transformers' canonical grouped V-head order, but the runtime had applied the interleaved K-head mapping intended for llama.cpp-converted GGUF tensors. A separately cached compile-time GDN sibling now implements grouped `repeat_interleave` semantics for PARO while the existing GGUF ABI and tiled mapping remain unchanged.

## Changes

- Added a RED HIP oracle with distinct K heads and V heads that requires canonical `v_head / (num_v_heads / num_k_heads)` mapping.
- Made all GDN kernels select grouped or tiled head mapping at compile time, including scalar decode, indexed/segmented decode, prefill preparation, chain, and tree paths.
- Added `build_qwen35_linear_attn_gdn_grouped_heads()` plus its dry-run planner and public exports.
- Selected only the grouped sibling in `Qwen35ParoResidentSession`; GGUF continues to use the default tiled build.
- Source contract references:
  - Transformers `modeling_qwen3_5_moe.py`: Q/K use `repeat_interleave(num_v_heads // num_k_heads, dim=2)`.
  - llama.cpp `conversion/qwen.py::_LinearAttentionVReorderBase`: GGUF conversion explicitly permutes V/Z/A/B/conv/out-projection tensors from grouped to tiled order before using modulo broadcast.

## Validation

- RED: `python -m pytest -q tests/test_qwen35_paro_gdn_head_layout.py` failed because the grouped builder did not exist.
- GREEN on gfx1151: the same test passed against the grouped GDN binary.
- Focused HIP/kernel bundle passed 39 tests: grouped PARO oracle plus `tests/test_qwen35_gguf_gdn_prefill_correctness.py tests/test_qwen35_linear_attn_gdn_plan.py`; the latter preserve the default tiled binary and include separate-cache plan coverage.
- Exact layer-0 token-271 boundary versus the independent ParoQuant runtime:
  - fused GDN: MAE `3.83e-6`, relative L2 `5.73e-4`, cosine `0.999999863`;
  - out projection: MAE `6.99e-6`, relative L2 `1.03e-3`, cosine `0.999999504`;
  - complete layer: MAE `2.56e-5`, relative L2 `1.11e-3`, cosine `0.999999436`.
- Full 10-prompt, 90-row teacher-forced suite versus ParoQuant Transformers improved from mean KL `12.07584` / top-1 `0%` to mean KL `0.00115135` / top-1 `98.89%`.
- The corrected runtime passes the absolute BF16 gate: mean KL `0.0270379` and top-1 `92.22%`. It remains quality-traded versus the Q4_K_M baseline under the paired noninferiority protocol; that is checkpoint quality, not a remaining runtime-layout divergence.
- External caches and detailed local comparisons remain under `/models/eval-results/hipengine-qwen36-teacher-v1/` and `/tmp/qwen36-paro-hipengine-grouped-*.json`; large logit arrays are intentionally untracked.
