# The Gemma 4 prefill gap is one kernel, and its first fix needs no numerical gate

## Summary

The prefill deficit against llama.cpp is one variant choice, and it is measured
rather than inferred: the shipped strict-order staged attention is **5.121x**
slower than the registered-but-unselected WMMA candidates at 131072 tokens.
Applying that would move the 131072 prefill ratio from **0.23x to 1.20x**.

But the trace says the first fix is not the arithmetic. The staged score and P*V
stages both report **LDS 0** — one thread per (query, key, head) score with
nothing staged — so the score pass runs at **0.914 TFLOP/s**, about 1 percent of
this part's measured 84.8 TFLOP/s BF16 WMMA rate. Tiling Q and K into LDS
changes no floating-point operation, so that headroom is reachable **without a
numerical gate**. That is the recommendation.

## Why the WMMA candidates are not the fix

They are faster and they are **not shippable**. `111ec0a60` demoted them from the
production default to "explicit evaluation" after the multicategory teacher-chain
packet found KL failures. The localization work already pinned the drift and
closed the cheap alternatives:

| Experiment | Result |
| --- | --- |
| WMMA score reassociation alone | p99 KL 0.0277 (bar 2e-2), max 0.0752 (bar 5e-2) — fails |
| + global 256-lane softmax statistics | mean improves, max still fails |
| + separated probability high/residual/tail accumulators | max KL 0.494 — worse |
| strict scores + global stats + ascending FP32 P*V | KL 0, top-1 1.0, bitwise equal to strict |

So the drift is entirely in the P*V stage, and no precision-only variation
recovered it. `docs/REFACTOR.md` records that the packet includes chains on which
the older full-attention parent also fails, which is a calibration question for
the lead and not something this unit acts on.

## The recommendation

**Tile Q and K into LDS in the staged score and P*V kernels.** The stages report
LDS 0, so each thread re-reads its Q row and K row from the cache hierarchy for
every pair it scores. The WMMA path is 5.121x faster at depth and stages 33,280
bytes of Q tile and 16,640 bytes of K/V tile — that is the difference, and it is
data movement, not arithmetic. The strict head-dimension accumulation order and
the separate 256-lane softmax denominator are untouched, so this needs no
execution-profile gate: it is a performance change to a path whose parity
contract already passes.

Order of work: (1) the LDS tiling above, re-measured with the A/B harness at
32768 and 131072; (2) if it does not close the gap, the WMMA P*V divergence is
worth the remaining distance, and it is worth 5.121x at 131072.
