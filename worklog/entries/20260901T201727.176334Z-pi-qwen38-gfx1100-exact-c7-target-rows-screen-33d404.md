# Screen exact C7 target rows and reject C8

## Summary

Added a default-off gfx1100 production screen that removes two inactive target
rows only at physical C7/K3: active R28 composes exact grouped prefixes and
strict tails instead of padding to R30. The same idea is rejected at C8 because
R32 falls below the retained fused gate/up threshold and complete wall regresses
despite lower target/device time. C8 remains padded R36.

## Changes

- Added backend capability policy
  `GGUF_SPECDEC2_EXACT_C7_TARGET_ROWS_POLICY`, default off under
  `HIPENGINE_GGUF_SPECDEC2_EXACT_C7_TARGET_ROWS=1`.
- Extended request-local exact-row admission and Q4/Q5/Q6 ownership for R28:
  Q4 `R8+R8+R8+R4`, Q5 grouped `R6×4+R4`, and Q6 `R8+R8+R8+R4`.
  The existing R30 path is unchanged when the flag is zero.
- Added RED→GREEN adapter/dispatch/ownership tests and a compact screen artifact.

## Validation

- Focused RED contracts initially failed on the padded parents, then passed after
  implementation: adapter R28 admission, Q4 pair fallback preservation, Q4
  grouped-prefix/tail selection, Q5 prefix/tail selection, and Q6 mixed route.
- W7900 gfx1100, ROCm 7.2.4, Qwen3.8-27B `Q4_K_M`, production BF16, capacity 8,
  K3/D12, one train prompt, cached-only `rocprofv3` kernel+ROCTx traces.
- C7 exact IDs and `[3,3,2]` acceptance match. Physical rows change
  `[30,30,24]→[28,28,24]`; three-cycle target wall improves
  **563.170→548.367 ms (-2.63%)**, device union **488.278→467.514 ms
  (-4.25%)**, kernel sum **-3.84%**, Q4/Q5/Q6 sums **-4.77%/-1.69%/-3.81%**,
  and profiled complete throughput improves **0.30%**.
- C8 exact IDs/acceptance also match and target wall/device union improve
  1.43%/1.71%, but Q4 sum regresses 66.4% after the fused-owner transition and
  complete throughput regresses **0.32%**. A preceding sequential unprofiled
  pair also regressed about 0.3%, so R32 is removed from the candidate scope.
- Artifact:
  `benchmarks/results/2026-09-02-w7900-q4km-k3-c7-exact-target-rows-screen.json`.
