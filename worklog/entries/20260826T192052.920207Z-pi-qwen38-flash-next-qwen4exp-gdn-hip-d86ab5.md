# Add strict Qwen4Exp GDN decode recurrence

## Summary

Added a strict FP32-state Qwen4Exp GDN decode recurrence at official
16-key/48-value-head, 128-dim geometry with sigmoid output gating.

## Changes

- Added raw-pointer recurrence over convolved Q/K/V, alpha/beta, dt bias,
  A-log, per-head norm, and caller-owned FP32 matrix state.
- Preserved llama qwen4exp's tiled head association (`v_head % k_heads`), Q/K
  L2 normalization/scaling, decay/beta equations, serial state update, output
  RMSNorm, and the architecture-specific sigmoid (not Qwen3.5 SiLU) gate.
- Registered a strict `gdn_recurrence_norm_gate/f32_state` variant with gfx1151
  peer aliasing.

## Validation

- RED: GDN test failed because the qwen4exp module did not exist.
- GREEN: `uv run pytest -q tests/test_qwen4_exp_gdn_hip.py` -> `2 passed` on
  Radeon 8060S/gfx1151, including first JIT build.
- At full 48x128x128 FP32 state, output and updated matrix state match the
  independent NumPy segmented recurrence + sigmoid norm oracle within 5e-5.
- New in-tree code; no external kernel body copied and lineage blocker remains
  as previously recorded.
