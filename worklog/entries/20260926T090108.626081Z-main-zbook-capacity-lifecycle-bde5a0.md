# Exercise GGUF public capacity cancellation and refill ownership

## Summary

Public generation, stream cancellation and capacity refill preserve pool
ownership for the local small Qwen3.5 model. The eager reservation policy is
unchanged; task 2 remains open.

## Changes

- Add `tests/test_live_gguf_capacity_ownership.py`, guarded by HIP availability
  and local model presence. It exercises C1/context511, C4/context1536 and
  C4/context5379 through `LLM.generate()` and `LLM.stream_detailed()`.
- Compare estimated workspace lease pages with the actual pool lease, require
  a live request before cancellation, wait for row release, then refill all
  serving slots and compare deterministic output. Check engine service health
  and baseline tracked allocation counts/bytes after close.
- No RED-first bug reproduction: this unit adds live coverage for an existing
  ownership contract, without changing production behavior.
