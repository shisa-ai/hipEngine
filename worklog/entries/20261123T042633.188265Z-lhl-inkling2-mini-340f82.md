# Check the arithmetic of grouped Inkling router projections

## Summary

Stacking real Inkling router inputs into a matrix and switching the FP32 projection from matrix–vector to matrix–matrix arithmetic changes both logits and expert weights. It did not change any selected expert IDs in these samples. This is not an exact replacement for independent decode rows.

## Changes
