# Add fail-closed W0 profiler prompt subset

## Summary

Added an explicit diagnostic-only prompt-count option to
`scripts/gguf_mtp_c1c8_server_bench.py` so W0 can profile the R8-R32 shape
curve without running every canonical prompt under serialized hardware-counter
collection. The option still loads and validates the complete canonical suite,
then selects its first N prompts. It is rejected unless
`--generation2-diagnostic` is active, and the output records
`performance_claim_eligible: false` for a subset.

This does not weaken the full-suite performance protocol. Retained speed claims
continue to require all ten prompts; the subset exists only for kernel/fetch
attribution after the independent full C6/C8 suite establishes cycle economics.

## Changes

- Added `--diagnostic-prompt-count N`, default 0/full suite.
- Record selected prompt IDs, subset count, full-suite status, and performance-
  claim eligibility in the raw protocol block.
- Added fail-closed parser/selection tests for non-diagnostic use and invalid
  counts.
