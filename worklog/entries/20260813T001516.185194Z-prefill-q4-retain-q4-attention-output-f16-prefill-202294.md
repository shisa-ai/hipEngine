# Retain sole-T16 Q4 attention-output F16 prefill

## Summary

Extended bounded Q4 source-F16 prefill to the full-attention output projection
(K=6144/N=5120). Actual-weight screens, complete quality, and counterbalanced
same-session full-prefill A/B pass on both gfx1100 boards at 512/1K/4K. The
route is byte-neutral and prefill-only.

## Changes

- Added the Q4 attention-output shape with measured tile anchors
  1024/1024/512/512/512 at M512/768/1K/1280/4K.
- Added full-attention stage 5-6 to the Q4/Q6 transient-plane lifetimes and
  qualified attention output for in-place activation casting. This is safe
  because its gated attention input dies at the projection handoff. The first
  RED smoke caught overlap before this lifetime/in-place ownership was added.
- Exact wider input projections, FFN gate/up, rows<512, decode, MTP, and peer
  backends remain unchanged.

## Validation

- Actual-weight component speedups on W7900 are
  **1.439x/1.429x/1.288x/1.235x/1.108x** at M512/768/1K/1280/4K; XTX is
  **1.270x/1.250x/1.255x/1.092x/1.026x**. Every screen wins 15/15 samples.
- Counterbalanced seven-pair full-prefill A/B versus the retained K/V owner:
  - XTX 512/1K/4K: **+0.350%/+0.306%/+0.074%**, all **7/7** paired wins.
  - W7900 512/1K/4K: **+0.096%/+0.299%/+0.301%**, with **7/7, 7/7, 5/7** wins.
- Complete 10-prompt/four-category/330-transition gate passes with minimum
  per-prompt top-1 **96.97%**, max KL **0.0174443**, and deterministic repeats.
- 512-token public prefill smoke is finite with token 9707. Focused owner tests,
  scratch liveness, `ruff`, and `git diff --check` pass.
