# Flag rows record how the runtime reads each flag

## Summary

187 flag decisions were `NOT-DEBT/keep` on a false premise. Their notes said
the flag was "phantom", "never read by hipengine/" or "read only outside the
runtime", but the runtime reads it. The original triage grepped for literal
`environ.get("NAME")` and missed the tree's common shapes:
- a module constant handed to `_env_flag(_X_ENV, True)`;
- a helper that takes the name as a parameter;
- a table of names.

Stale detection could not catch this, because the decisions were wrong when
they were written.

The flag extractor now parses each runtime module and records how the runtime
uses each name. Defaults come from the read call. The triage notes can no
longer contradict the row without showing up.

## Changes

- `audit/hipaudit/inventory/flags.py`:
  - `module_reads()` classifies each runtime use as `env`, `indirect`, `bound`
    or a mention. `env` covers direct reads, reads through module constants
    and `_env_*` helpers, `environ[...]` and `in environ`. `indirect` covers
    hand-offs to helpers and tables. `bound` covers `environ[...] = `,
    `pop`/`setdefault` and `_bind_*env` calls.
  - Defaults resolve from the read call, including literals bound to module
    constants. 395 flags that were `unknown` now have a default.
  - `.hip`, `.h` and `.sh` sources count `getenv("NAME")` and `${NAME}` as
    reads.
  - New evidence `runtime_read` and `runtime_bound` (hashed) and
    `runtime_reads` (examples, not hashed), with a signal stating each.
  - Python names listed in `__all__` (`HIPENGINE_X_ENV`) are not flags.
- `checks/skeletons.py`: `ungoverned-flag-branch` only considers flags the
  runtime reads or hands off. 230 findings, up from 102, because defaults are
  now known.
- Migration, recorded in `audit/migrations/evidence-basis-v3.json`:
  - 662 flag and 100 branch decisions were rebased; the new facts are
    consistent with their notes.
  - 187 contradicted flag decisions kept their old basis, then were
    re-triaged by rule from the verified facts:
    - `docs/REFACTOR.md` names the flag: `NOT-DEBT/keep` (governed).
    - Configuration value or route scope (paths, arch, sizes, timeouts,
      layer windows, modes): `NOT-DEBT/keep`.
    - Diagnostic (audit, fence, log, trace): `NOT-DEBT/keep`.
    - A route-forcing or boolean toggle with no REFACTOR entry:
      `DOC-DRIFT/document`, 52 flags, mostly
      `HIPENGINE_QWEN35_BATCH_DECODE_FORCE_*`.
  - The 130 new branch findings mirror their flag's decision.
  - Every note quotes the read site. These decisions carry
    `by: lhl (flag-read-v3 rule)`.
- Two branch decisions on `HIPENGINE_W4_MULTI_ROW_PACK8` are archived; their
  notes said the flag is default-on, and the extractor now agrees.
- `audit/agents/triage.md`: start flag triage from `runtime_read`.
