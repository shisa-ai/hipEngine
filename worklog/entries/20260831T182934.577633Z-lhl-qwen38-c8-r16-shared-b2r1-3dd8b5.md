# Retain exact shared-B one-row Q4 verifier owner at R16

## Summary

After the C6/R12 pair retention, C8/K1 remained bound by the Q4 single
K17408/N5120 R16 down projection. The current shared-B2W2 body carries four row
tiles per wave (128-row capacity, 224 VGPR) for a 16-row workload. Templating
the row-tile count exposes an exact `<2 output tiles, 2 waves, 1 row tile>`
sibling: it keeps the 32-column cooperative weight slab but reduces the active
accumulator schedule to R16.

The actual-shape screen is bit-exact and improves **0.735→0.534 ms (1.38x)**.
The full canonical C6/C8 K1 screen measures C6
**37.117/39.896 = 0.930346x AR** and C8
**43.286/47.578 = 0.909786x**, with 20/20 exact/engaged/budget cells. The loop
minimum improves 0.898603→0.909786. Automatic serving remains K0.
