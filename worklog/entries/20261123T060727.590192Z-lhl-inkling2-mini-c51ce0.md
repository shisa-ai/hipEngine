# Replay packed Inkling attention inputs across requests

## Summary

Sharing compatible packed Q8_0 attention matrices across requests, while leaving the other projections on scalar kernels, reproduced the input-projection bits on both GPUs and reduced the replayed projection phase. The replay did not mutate convolution or KV state and does not establish a serving speedup.

Use the existing dense packed multi-row kernel only for compatible Q8_0 outputs. Combine the remaining scalar projections in the same exchange and reconstruct each request's original output order. The initial capture missed ordinary projections and was replaced. No production code changed.
