# Separate Qwen diagnostic capture and timing ownership

## Summary

Fourth unit of the approved runtime cleanup, following `203cb69a5`. Separate diagnostic host capture/reporting, the legacy one-layer projection probe and timing storage from session execution. Keep stateful capture setup, kernel execution and synchronization in session orchestration; expose explicit borrowed inputs to host readers.

## Changes

- `qwen35_gguf_capture.py` owns host snapshot types, summary schemas and selected-buffer readers. Readers take configuration, dimensions, scratch, pointers and copy functions, never a session or runner. Compatibility type aliases remain in the runner.
- The shared next-token result moves to a neutral results module, avoiding a production dependency on the standalone probe.
- Source-audit tools follow the capture reader binding instead of assuming host-copy code is inline. Negative tests reject missing source or a changed dtype binding.
- Timing and one-layer probe owners are integrated through aliases. Production execution, profiling interval boundaries, registry choices and numerical defaults are unchanged. Probe constructor rollback frees loaded weights if layer validation fails, and each temporary allocation is registered before the next allocation can fail.
- The real MoE probe run exposed an inherited admission mismatch: partial projection loading requested full-model expert-call partners. The probe now supplies the existing `selected_call_intents=()` contract for a non-expert diagnostic. No admission gate is bypassed or changed; its actual projection slots are still checked. The constructor regression failed first and all **29 probe tests** passed after the repair.
- Event teardown attempts all handles, retains failed destroys for explicit retry and clears stale timing intervals. Wall-clock buffer ownership is unchanged: a failed free retains the buffer, and successful retry releases it once. An initial proposed drop-before-free change was rejected during parent review because a failed release does not establish that a resource was freed.
