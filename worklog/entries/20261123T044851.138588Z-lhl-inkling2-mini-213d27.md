# Screen exact grouped Q8 gate reads in Inkling decode

## Summary

A grouped NVFP4 gate/up prototype reproduced the existing decode Q8-dot bits while reusing weights across independent rows. It helped when many experts overlapped but could lose with distinct or mildly overlapping routes. Do not replace the scalar gate unconditionally with this prototype.

## Changes

- Adapted the prior scratch tile to use one Q8-packed activation per request rather than one per route. The reference is the already-shipped shared-input Q8-dot gate, not the FP32 prefill projection. No production code changed.
