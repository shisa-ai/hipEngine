# Repair lifecycle-gate injection portability (R0523)

## Summary

Repair `scripts/gguf_mtp_lifecycle_gate.py` so its in-flight cancel/deadline and
terminal rows are portable across hosts. On the W7900 the six phase-fault
containment rows already passed, but cancel/deadline failed because the gate
counted raw checkpoint calls (prefill's per-chunk checkpoint polling adds calls
before the first decode cycle), and the EOS/stop-in-cycle rows failed on a
fixed `cycles==1` that depends on draft acceptance. Product behavior was
correct throughout; only the gate's injection/assertion assumptions were stale.
Close R0523.

## Changes

- `scripts/gguf_mtp_lifecycle_gate.py`:
  - Cancel/deadline now inject at the checkpoint whose last seen lifecycle phase
    is `after_draft_repair` (the owned boundary after target commit + draft
    repair, before publication), instead of the second raw checkpoint call.
    Dropped the host-dependent `checkpoint_calls == 2` assertion; kept the
    `seen[-1:] == ["after_draft_repair"]` injection-point assertion, the
    closed-verifier check, and exact following MTP health.
  - Terminal rows assert the exact terminal prefix plus `cycles >= 1`
    (speculation engaged) instead of `cycles == 1`; the cycle count is
    acceptance-dependent, the contract is an exact in-cycle stop with clean
    health. No containment assertion was weakened.
