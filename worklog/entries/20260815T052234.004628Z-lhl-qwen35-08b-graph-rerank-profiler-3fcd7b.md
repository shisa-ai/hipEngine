# Add 0.8B graph rerank profiler

## Summary

Added a durable profiler for the approved Qwen3.5-0.8B post-X2 graph rerank.
It replaces the prior `/tmp`-only M9-M12 scripts and directly addresses X2-K4's
open ~2.3-ms/token attribution question.

## Changes

- Capture eager, recorded-graph, production-graph, and device-marker-instrumented
  trajectories for Q4_K_M and Q8_0 in one resident session per quant.
- Inventory every graph node/kernel and measure graph-launch API wall,
  synchronize wall, production replay wall, semantic device-stage sum, and
  host-minus-device residual over 128 token-level samples.
- Preserve the prior ~6-ms isolated-owner estimate only as a comparison; the
  same-session device-stage chain determines whether its gap is API overhead or
  isolated-microbench undercount.
- Record model/script/compiler hashes, clean-tree state, memory, graph transport,
  and eager/recorded/production/instrumented numerical agreement.

## Validation

- `python3 -m py_compile scripts/qwen35_08b_graph_rerank.py` passes.
- `uv run python -c "import scripts.qwen35_08b_graph_rerank as m; print(m.STEPS,
  sorted(m.MODELS))"` imports without executing GPU work and reports the expected
  128-step Q4/Q8 contract.
- The source is a cleaned, main-guarded descendant of the M12 profiler whose
  retained graph and semantic contracts previously passed on this hardware.
