# Reject the resident block promotion on the per-row gate

## Summary

The resident block traversal fails the production KL envelope and is not deterministic, so it stays off the default path. Wiring it into `_forward` for multi-row prefill made the public route produce different tokens from control at depth 575 and fail a bitwise repeat check, which makes this a defect to localize rather than rounding to tune.

## Changes

- Wired `_resident_block` into `_forward` for multi-row prefill only, then reverted it after the gate.
- Extended the resident verification harness to count resident-block launches alongside resident-attention launches, so "the public route ran" covers both halves, and to report the two token counts separately on failure.

## Validation

Per-row gate, `Inkling-2-Mini-UD-Q4_K_M-mainline.gguf`, `hip_gfx1100`, fast profile, seven depths 64/65/151/257/511/575/1031, four teacher-forced rows each:

- `kl_strict` first row (the prefill row): 2.2e-04, 3.1e-02, 4.3e+00, 6.5e-02, 6.2e-01, 1.3e+00, and a crash on the last depth's assert.
- Control (`kl_strict_control`, the resident-attention half alone): 6.6e-15 to 2.6e-04 on the same rows.
- Depth 575 detail: `kl_strict` 1.345, 0.275, 2.868, 0.313 against control 1.4e-13, 3.0e-06, 1.7e-04; top-1 2 of 4 against control 4 of 4; public token ids differ from control.
- The repeated `forced()` run was not bitwise identical, so the block path is non-deterministic.
- Envelope for comparison: median row KL <= 1e-3, p90 <= 2e-2, top-1 >= 96%.

## Next

- Localize the non-determinism first; a path that does not repeat cannot be measured. Candidates in the order they were introduced: the device-cursor attention plan fed `blank`/`np.empty` placeholders, the restart window `(working, saved + 1, count - saved - 1)`, and the snapshot restore that overwrites the flipped working region.
- The clearing command is the same harness with `resident_block` set on the model: `.venv/bin/python /tmp/hipengine_inkling_resident_attention_verify.py <gguf> hip_gfx1100 <revision> 64 65 151 257 511 575 1031`. It must report `repeat_bitwise: true` and fit the envelope before `_forward` is wired again.
- The earlier end-to-end KL of 2.185e-04 was a single 64-row block; it does not generalize and must not be quoted as the path's accuracy.
