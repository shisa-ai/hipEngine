# Add bounded synchronous stream producer bridge

## Summary

Add and integrate a bounded synchronous producer bridge for server text and
multi-row streams. R0503 remains open for loaded-engine HTTP validation.

## Changes

- `StreamBridgePool` owns at most eight dedicated producer threads globally and
  eight queued items per stream plus one producer-held item. It does not reserve
  the shared server threadpool for a stream's lifetime or dispatch per item.
- Construct, advance and close each iterator on its producer. Propagate errors
  after preceding queued items, preserve order and deliver the first ready item
  without waiting for later production. Async waiters do not consume workers.
- Async cancellation stops buffering and wakes backpressure. A blocked `next()`
  retains its worker slot until it returns, then closes on the same thread.
  Python cannot safely kill an indefinitely blocked synchronous iterator.
- Integrate detailed, compatibility and multi-row stream wrappers with explicit
  async-generator closing. Leave nonstreaming generate fallback unchanged.
- Add deterministic lifecycle/first-ready/error/backpressure/capacity tests and
  direct server wrapper checks; existing HTTP stream fixtures still pass.
