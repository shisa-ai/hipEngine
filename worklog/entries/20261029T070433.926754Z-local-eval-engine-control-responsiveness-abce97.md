# Repair long-operation control responsiveness and cancellation ownership

## Summary

Task 20 is complete for the Qwen GGUF public DMS serving routes: CPU tokenization no longer queues behind device work, cancellation and deadlines interrupt prefill at existing boundaries, and expired admission cannot leave unowned requests. Device synchronization or reclamation failure stops serving rather than claiming successful cleanup.

This is a host-control and ownership change, not an arithmetic, chunk-geometry, context-limit, or output-budget change. It does not make an individual GPU kernel preemptible.

## Changes

- Opt in initialized Qwen CPU tokenizer methods to a lifecycle-checked frontend path. Device and mutation controls remain on the sole driver.
- Arbitrate command completion and abandonment under one lock. Skip abandoned queued work and reclaim late admissions before another poll. Inventory returned submissions before binding, including partial speculative batch admission.
- Give handles child-local stop intent while observing their parent token. Support multiple parent dispatch owners, registration after cancellation, optional token-like parent methods, and local deadline acknowledgement details.
- Bind stop checks in both compact-config and legacy-sidecar DMS paths. Preserve deadlines only for explicitly cooperative DMS runners; shared dense physical batches retain scheduler-owned cancellation.
- Synchronize before observing stop intent at existing runtime boundaries. Delay sidecar, collector, oracle, stage-recorder, and partial compact-backend cleanup if synchronization fails. Keep a strong session owner on the shared runner until successful teardown. Guard model, generator, and shared-runner close before discarding ownership or releasing weights.
- Escalate normal cancellation, timeout, completion-error, and backpressure reclaim failures to the fatal driver path. Publish the child error, answer active and queued callers, attempt remaining cleanup, and reject new requests. Cleanup retry does not restore an unhealthy service.
