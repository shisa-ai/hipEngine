# Retain R0371 Moonshine LM-head route selector

## Summary

R0371 is a completed supported-retention decision: keep the explicit
`wave8_argmax` / `wave8_top1` selector, the unfused projection/argmax
primitives, and the selective W8A16 route. No runtime, kernel, CLI,
documentation, audit, GPU-test, staging, or commit change was made. CPU
contracts now cover the explicit selector, decoder-smoke CLI mappings, route
gate rejection, and the constructor's loud rejection of unsupported or
quantized top-1 requests.

## Changes

- Constructor audit: `MoonshineResidentRuntime` defaults to
  `MOONSHINE_DEFAULT_LM_HEAD_ROUTE = "wave8_top1"`, normalizes only the two
  declared routes, reserves top-1 partial scratch only for `wave8_top1`, and
  rejects `wave8_top1` with a selective `lm_head` W8A16 sidecar
  (`hipengine/runtime/moonshine.py:39-46`, `:169-226`, `:286-297`).
- Runtime dispatch audit: `wave8_top1` calls
  `moonshine_f16_lm_head_projection_wave8_top1`; `wave8_argmax` calls
  `moonshine_f16_lm_head_projection_wave8` followed by
  `moonshine_argmax_fp16`; a selective `lm_head` W8A16 sidecar calls
  `moonshine_w8a16_lm_head_wave8` followed by `moonshine_argmax_fp16`
  (`:1097-1135`). `lm_head_contract()` reports the selected route, full-logit
  materialization, stable lowest-id top-1, partial scratch shape/dtypes, and
  the explicit `wave8_argmax` fallback (`:602-621`).
- Decoder-smoke audit: `--lm-head-route` exposes both routes with the promoted
  default; `--w8a16-families` forwards selective families to the constructor;
  the report carries `lm_head`, `w8a16_families`, and the route-specific
  boundary policy (`scripts/moonshine_decoder_smoke.py:56-76`, `:240-276`).
- Leaf benchmark audit: no route CLI is needed; the benchmark explicitly times
  `wave8_argmax` and `wave8_top1` against the same buffers and reports both
  route summaries, profiler requirements, and the retained decision artifact
  (`scripts/moonshine_lm_head_bench.py:237-335`). Existing unit tests cover the
  summary, profiler gate, and artifact arithmetic.
- Route-gate audit: the child command passes `--lm-head-route`; the report gate
  checks route, partial count/dtypes, fallback, graph replay, allocation, and
  teardown; the summary requires the complete paired route matrix
  (`scripts/moonshine_lm_head_route_gate.py:37`, `:80-190`, `:220-360`,
  `:380-410`).
- Added `test_constructor_rejects_unsupported_route_and_quantized_top1` in
  `tests/test_unit_moonshine_lm_head_reference.py`. It covers the default and
  explicit `wave8_top1` with selective `lm_head` W8A16, plus an unknown route,
  and verifies the loaded model is released when construction rejects.
- Added route-gate contracts in
  `tests/test_unit_moonshine_lm_head_route_gate.py`: a report for
  `wave8_argmax` is rejected when `wave8_top1` is expected; an unknown expected
  route raises; decoder-smoke CLI preserves explicit `wave8_top1` and
  `wave8_argmax`; selective W8A16 families are preserved; an unknown
  `--lm-head-route` exits with code 2.
- Existing `test_lm_head_real_token_dag_keeps_default_and_unfused_quantized_routes`
  remains the distinct kernel-owner sentinel for FP16 top-1, FP16 unfused, and
  selective W8A16 unfused dispatch.
