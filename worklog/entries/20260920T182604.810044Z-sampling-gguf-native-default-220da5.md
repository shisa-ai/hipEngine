# Enable supported GGUF native sampling by default

## Summary

Supported, available GGUF native GPU sampling is default-on. The prior category,
numerical, lifecycle and performance evidence establishes the fast path;
leaving the historical global opt-in in place was unnecessary. This changes
placement, not sampler arithmetic or request capability boundaries.

## Changes

- Unset `HIPENGINE_QWEN35_NATIVE_SAMPLER` enables native placement. Explicit
  `0`, `false`, `no`, `off` or empty values retain the host rollback.
- Unsupported requests and unavailable native sessions retain host fallback.
  Capabilities report default-on and honor explicit disable.
- Host-route tests explicitly disable native placement. The lifecycle harness
  no longer forces enablement, so an unset-env run validates the real default.
- Performance evidence remains in
  `benchmarks/results/2026-09-21-zbook-fast-cpu-gpu-sampling.json`; this unit makes
  no new speed claim or gfx1100 hardware-validation claim.
