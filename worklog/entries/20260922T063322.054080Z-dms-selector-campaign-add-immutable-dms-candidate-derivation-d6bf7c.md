# Add immutable DMS candidate derivation

## Summary

Added a deterministic candidate-package derivation tool for the campaign's
protected-window and exact eligible-history compression sweep. It copies the
frozen sidecar unchanged, creates new metadata and provenance, and refuses to
mutate or reuse an existing output directory.

## Changes

- Added `scripts/qwen38_dms_derive_candidate.py` with a Python API and CLI for
  deriving W/CR candidates from schema-v2 external-linear exact-budget metadata.
- Bound every package to parent-metadata and sidecar hashes, candidate ID,
  source/target W and CR, generator provenance, and checksummed output files.
- Added unit coverage for immutable sidecar bytes, preserved training/calibration
  fields, provenance, checksum failures, invalid policy values, and output reuse.
