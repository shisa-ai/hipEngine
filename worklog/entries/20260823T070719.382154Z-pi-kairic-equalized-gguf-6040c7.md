# Kairic Equalized GGUF authority adapter

## Summary

Implemented the missing source-format boundary for the immutable Kairic Edge
Qwen3.8 authority. Custom GGUF IDs 100/102 are not generic "Equalized" types:
they are CIRU `Q4_0_ROCMFP4` and `Q6_0_ROCMFPX` block32 formats. hipEngine now
parses both, dequantizes them exactly, exposes explicit quant plugins, plans the
public coherent file type, and admits its PFS only on gfx1151 under the same
explicit product selector.

The first authority runtime deliberately expands compressed weights instead of
claiming native compressed execution. ROCmFP4 codebook products are losslessly
representable in BF16; ROCmFP6 remains lossless F32. The actual 16.618-GB sparse
header plans 49.579 GiB resident across the 64 target layers. This is a
correctness/denominator adapter and strict fallback, not a compact decode path.

A separately isolated expanded-BF16 prefill policy reuses the existing dense
WMMA kernel only at the 21 measured Kairic shapes (M512/1024/2048, seven KxN
families). Every point wins; M96 is excluded after K6144xN5120 measured 0.629x.
The immutable GGUF is downloaded and SHA-validated; a one-shot same-session
control/PFS smoke passes. The complete 50-prompt gate is a separate validation
unit and remains in progress.

- Added GGML IDs `Q4_0_ROCMFP4=100`, `Q6_0_ROCMFPX=102`, coherent file type
  102, exact block metadata, finite UE4M3 decoding, codebook10 unpack, and
  signed-magnitude6 unpack to `hipengine/quant/gguf.py`.
- Added explicit `gguf_q4_0_rocmfp4` / `gguf_q6_0_rocmfpx` registry plugins.
- Added source-format materialization policy:
  - ROCmFP4 -> distinct lossless dense-BF16 authority layout;
  - ROCmFP6 -> lossless dense-F32 authority layout;
  - existing Q6_K embedding and Q8_0 output stay compressed/native.
- Generalized dense-F32 materialization to dequantize non-F32 source blocks.
- Registered the coherent product quant with the existing Qwen generator.
- Replaced the hard-coded Q4_K_S PFS admission check with a backend package
  file-type capability. gfx1151 admits Q4_K_S and the coherent ROCmFP4 authority;
  gfx1100 still fails closed.
- Isolated Kairic expanded-BF16 WMMA shapes from peer BF16 policy through a
  distinct resident layout and backend capability; the existing scalar kernel
  and `HIPENGINE_GGUF_DENSE_WMMA_BULK=0` remain rollback.

  `benchmarks/results/2026-08-23-gfx1151-qwen38-rocmfp4-authority-dense-bf16-leaf.json`.
