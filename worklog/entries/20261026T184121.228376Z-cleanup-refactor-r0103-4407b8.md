# Bind narrowed F16 consumer pairs in production

## Summary

Bind the existing narrowed two-consumer F16 ownership path in UD production;
keep other profiles and all ineligible shapes on their parent route.

## Changes

- The binder publishes the pair setting only for UD production without strict
  fallback; every bind writes it, preventing stale enablement on other profiles.
- Existing gfx1151 rows4096/layers13–47 and ordered-pair capability checks,
  lifetime checks and parent fallback are unchanged.

  both consumers can already read that image without conversion. If a mirror
  appears after admission, the unused loan is invalidated; it is not counted

  key rewrites as their live consumers.
