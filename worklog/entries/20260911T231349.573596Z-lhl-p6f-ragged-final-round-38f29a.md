# P6f ragged final round covered on GPU; state gate passes at a short final round

## Summary

Task `#21` (P6f) listed "shifted/ragged layouts" as a GPU-gated packet item. The
reachable half is now covered: a single-slot prompt whose final planner round is
short, with the layer-boundary state gate required to pass on it.

The P6e proof's prompt was exactly `row_capacity * rounds` (3,072 = 3 × 1,024),
so every planner round was full and the executor's per-round row bases were
never exercised at a short final round. `--prompt-extra-rows` appends rows beyond
a whole number of rounds, and a new `ragged_final_round` gate asserts the
declared shape actually reached the executor.

Measured on the W7900, Qwen3.8-27B `Q4_K_M`, INT8 KV, 3,172 rows with a 100-row
final round (4 planned rounds), 16 segments of 4 layers:

| Gate | Result |
| --- | --- |
| `exact_continuation` | both arms sample token 286 |
| `real_yield` | 16 segments, minimum 308.0 ms |
| `bounded_decode_gap` | interleaved p95 33.084 / max 33.115 ms vs standalone p95 33.582 / max 38.876 ms |
| `cleanup` | peak suspended state 223,821,824 bytes, released |
| `layer_boundary_state` | 64 planes compared, 0 mismatches, `state_position` 3,172 for both arms |
| `ragged_final_round` | `final_round_rows` 100 < `row_capacity` 1024, declared ragged |

The full-round shape was re-measured with the same six-gate harness and also
passes (64 planes, 0 mismatches, token 265). Both artifacts set
`performance_claim: false` and change no scoreboard row.

Scope, stated because it is not the whole packet gate: multi-slot unequal prompts
are unreachable through the resumable entry, which requires slot-stable chunks
and declines otherwise. That path is covered by the existing decline tests
(`test_gguf_packed_layer_outer_prefill.py`), not by a GPU state gate. Aliasing on
this executor remains the one outstanding P6f packet gate.

## Changes

- `scripts/gguf_resumable_prefill_gpu_proof.py`:
  - New `--prompt-extra-rows` option; the prompt is now
    `row_capacity * rounds + extra_rows`.
  - The harness derives the planner's real shape
    (`_plan_packed_ar_prefill_chunks`) instead of assuming it, recording
    `planned_rounds`, `final_round_rows`, and `ragged_final_round` in the
    artifact workload.
  - New `ragged_final_round` gate: a ragged prompt must produce a short final
    round and a whole number of rounds must not, so neither shape can silently
    be padded into the other.
- `tests/test_gguf_resumable_prefill_gpu_proof.py`: 30 tests (was 26). New
  coverage for the gate: a declared short round passes; a declared ragged prompt
  that ran full rounds fails; a declared full-round shape that came out short
  fails; and zero/over-capacity/degenerate shapes fail.
- `docs/SERVER-DIRECT-PARITY-ROADMAP.md`: outstanding list now names only
  aliasing on this executor; ledger row and the remaining-packets paragraph
  updated with the ragged result and the slot-stability scope note.
- `tests/test_gguf_packed_layer_outer_prefill.py`: module docstring updated to
  match.
- `benchmarks/CHANGELOG.md`: dated entry.
- New artifact `benchmarks/results/2026-09-11-w7900-p6e-resumable-prefill-state-gate-ragged.json`;
  the full-round artifact was regenerated with the sixth gate.

## Validation

- `uv run pytest tests/test_gguf_resumable_prefill_gpu_proof.py -q` → 30 passed.
- `uv run ruff check scripts/gguf_resumable_prefill_gpu_proof.py
  tests/test_gguf_resumable_prefill_gpu_proof.py` → all checks passed.
- GPU runs (exact commands in the artifacts), AMD Radeon Pro W7900 (gfx1100),
  `HIP_VISIBLE_DEVICES=0`:
  - ragged: `--prompt-extra-rows 100 --layer-budget 4 --decode-tokens 24` →
    `passed: true`, six of six gates.
  - full rounds: `--layer-budget 4 --decode-tokens 24` → `passed: true`,
    six of six gates.
- The `ragged_final_round` gate is non-vacuous: three of its five unit tests
  drive it to `passed: false` on a shape mismatch, and the ragged GPU artifact
  records `final_round_rows` 100 against `row_capacity` 1024, so the run
  genuinely took the short-round path rather than a padded one.

## Honest limits

- One green run per shape. Both shapes pass deterministically-shaped gates, and
  the ragged run's own `ragged_final_round` gate proves it exercised the short
  round, but no repeat run was taken.
- The ragged case is a single slot with a short final round. Multi-slot unequal
  lengths are declined by the executor's slot-stability guard, so no GPU state
  evidence exists for them by construction; that is a scope boundary, not a
  measured pass.
- Byte-exactness is established for `per_token_head` scales at these two shapes
  only. `block16` and `hadamard_group32` remain unit-tested for the prefix
  arithmetic but unmeasured on hardware.
