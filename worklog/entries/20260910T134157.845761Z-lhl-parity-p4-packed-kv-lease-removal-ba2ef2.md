# P4: remove the duplicate packed-KV reservation

## Summary

Roadmap P4 (F2). The server no longer pins a second full-context KV
reservation when no packed-KV plane consumer can appear. Two layers:

1. State level: `_GGUFPackedTargetState` gains an `unleased` backing kind -
   no packed KV planes, no pool page consumption. Slot-local packed prefill
   (single-slab and the layer-outer executor) passes
   `require_kv_planes=False`; every plane consumer (non-slot-local packed
   prefill, packed batch decode, the MTP verifier, hidden-seed priming)
   keeps the default `True` and upgrades an unleased state through the
   existing growth path. `full_cache` fails closed on unleased states, the
   layout rebind is the identity binding, and the KV-copy plane path raises
   its existing missing-plane error.

2. Pool level: `configure_engine_loop` creates the global pool WITHOUT the
   workspace page share and skips `lease_workspace` when `capacity == 1`,
   prefix cache is off, and the MTP serving policy is off. A plane consumer
   that appears anyway fails safe: the state allocation falls back to a
   private KV chunk. `HIPENGINE_GGUF_PACKED_KV_LEASE=1` forces the eager
   lease for debugging or rollback.

The MTP serving policy now reaches `configure_engine_loop`: new
`EngineLoopConfig.speculative_mtp_serving` field, `LLM` constructor
parameter, and the server passes its `ServerConfig.speculative_mtp_serving`
through (the loop config was previously built from env only, so the server
flag never reached the pool gate).

## Changes

- `hipengine/runtime/qwen35_gguf_runner.py`: `lease_kv_planes` parameter on
  `_GGUFPackedTargetState.allocate`; `unleased` backing kind; rebind
  early-return; `require_kv_planes` on `_ensure_packed_verify_workspace`
  (delegate passthrough, readiness check, allocate flag); slot-local
  callers pass False.
- `hipengine/generation/qwen35_gguf.py`: pool-level gate + skip, lease-skip
  marker in the observability snapshot.
- `hipengine/generation/engine_loop.py`: `speculative_mtp_serving` config
  field + from-args wiring.
- `hipengine/llm.py`, `hipengine/server/api.py`: policy passthrough.
- `scripts/gguf_server_allocation_probe.py`: records the generated text head
  for before/after determinism checks.
- Tests: unleased-state contract (fail-closed full_cache, identity rebind,
  linear-state presence), the upgrade path, the delegate-signature fix,
  FakeLLM/build_llm signatures.

## Validation

route, 2,048-row prompt, clean teardown everywhere:

- 16,384 declared, chunk-outer: pinned pages 64 -> 0, lease 0.508 -> 0
  GiB, pool high-water 0.579 -> 0.0714 GiB (the request's own KV only).
  Removing the lease also halved the pool-backed oracle capacity, so the
  16-owner transient dropped 2.0 -> 1.0 GiB.
- 32,768 declared, layer-outer enabled: pinned 128 -> 0, lease 1.016 -> 0,
  oracle 4.0 -> 0.25 GiB (1 owner), hidden 0.431. Combined P3+P4 total
  route transients ~1.6 GiB vs ~6.4 GiB at the P0 baseline.
- Determinism: identical generated text with the lease forced on
  (HIPENGINE_GGUF_PACKED_KV_LEASE=1) vs off, same prompt, 16 decode
  tokens.
- Bundles: packed-workspace-stability (15 incl. 2 new), layer-outer (13),
  server-api (71), engine-loop/kv-pool selection green.
