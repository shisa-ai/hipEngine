# Retain scaled-F16 prefill comparison as a named diagnostic

## Summary

R0271's locally actionable half is decided: retain the `prefill_350` comparison
and its `prefill_350_candidate` lane as intentional reference code, with
`scripts/laguna_grouped_down_category_bench.py` named as the diagnostic owner.
The arm executes `hipblaslt_scaled` source-F16 against a `retained` control.
The gfx1151 package default is `hipblaslt_range_direct`, so neither arm is the
default and neither may be substituted for it. The public validation half of
R0271 stays open: the Laguna checkpoint is absent locally.

## Changes

- `scripts/laguna_grouped_down_category_bench.py`
  - Module description names `prefill_350` as the reference diagnostic for the
    scaled source-F16 route and states that neither arm is the range-direct
    default.
  - `CategoryComparison.diagnostic_owner` (default `None`) is set on
    `PREFILL_350_COMPARISON`; the artifact now records it as
    `protocol.diagnostic_owner`. Other comparisons record `null`.
  - `_configure_prefill_lane` single-sources cumulative-lane application for the
    benchmark and oracle paths and refuses a projection route that resolves to
    something other than the declared lane mode, so a scaled arm cannot silently
    become range-direct (or the reverse). `_set_f16_prefill_mode` now returns the
    validated mode; its assignment behavior is unchanged.
  - Repaired false artifact metadata: the cumulative note claimed both arms
    freeze the same grouped-down and dense/shared routes. That is true only for
    `cumulative_control`; `prefill_350` runs `mmq64x32_d4_f32`/`mmq128x32_d8_f32`
    and `wmma_pack8` against `adaptive_grouped_smallm_fused`/`direct` and
    `retained`. `_protocol_note` keeps the control sentence and emits a
    per-arm, "not interchangeable" sentence for the other cumulative lanes. The
    other five comparison notes are preserved verbatim.
  - Extracted `_lane_configurations` from the inline protocol literal so the
    recorded per-arm routes are host-testable. It reproduces the current
    `2026-07-25-gfx1151-laguna-prefill-350-d8-category.json` lane metadata
    exactly, plus the `attention_hipblaslt` key the pre-existing code already
    emitted.
- `tests/test_unit_laguna_grouped_down_category_bench.py`
  - Pins both arms' projection routes, the named owner, and that the resolved
    gfx1151 default is neither arm (and is the `production_absolute_candidate`
    route).
  - Pins the recorded per-arm metadata and the corrected note for `prefill_350`;
    confirms the `cumulative_control` note still matches lanes that do share
    grouped-down/gate-up/dense-Q4 modes.
  - Exercises the refusal with a fake session and a monkeypatched resolver.
