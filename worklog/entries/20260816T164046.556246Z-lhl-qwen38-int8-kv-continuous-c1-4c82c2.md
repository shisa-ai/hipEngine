# Complete Qwen3.8 compact serial INT8 KV C1

## Summary

Completes `IKV-C1` after the blocker recorded in
`20260816T125303.696140Z-lhl-qwen38-int8-kv-continuous-c1-c62b08.md`.
Qualification is exclusively on GPU1 / RX 7900 XTX / DRM card0 (23.984 GiB);
GPU0/W7900 remained owned by another worker and supplied no retained evidence.
The exact `7b2aec...` gfx1100 artifact now admits compact logical c2/c4 through
an honest physical-c1 serial fallback. This is a correctness/capacity milestone
with no native-c>N or throughput claim.

## Changes

- Bound no-mirror multi-session admission to immutable capability evidence and
  a declared `max_serial_resident_rows=4`; unknown, diagnostic, rejected, or
  wider contracts still fail closed.
- Split resident layout validation from packed-attention eligibility, routed
  direct INT8 c>N decode through `_step_native_serial()`, and exposed logical C,
  physical width 1, serial row/model-step counters, and promotion-ineligible
  execution manifests.
- Unified direct-INT8 base-zero and shifted prefill on the single-row
  block-table-aware path. The transient BF16 oracle and retained physical INT8
  payload/scale tables no longer alias one another's addressing contract.
- Kept direct INT8 scheduler prefill whole-prompt so one bounded exact oracle is
  not released between chunks; transient oracle/table ownership drains before
  decode.
- Added fail-closed token range guards, request-level layout audits, active
  persistent-KV metrics, response-retained layout diagnostics, and benchmark
  polling of INT8/scale/BF16 ownership.
- Added focused host coverage for capability bounds, base-zero/shifted native
  and sampled prefill, retained page tables, no-mirror scratch/lifetime,
  physical-width manifests, and telemetry.
