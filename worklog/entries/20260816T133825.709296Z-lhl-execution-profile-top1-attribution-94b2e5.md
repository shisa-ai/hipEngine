# Attribute every execution-profile top-1 mismatch

## Summary

The calibrated evaluator previously emitted detailed diagnostics only for rows
above the KL review boundary. A numerically small near-tie could change top-1,
count against the binding top-1 gate, and still have no prompt/step attribution.
Emit a full diagnostic record for every top-1 mismatch independently of the KL
review list.

## Changes

- Added strict/candidate top-1 token IDs to the internal aligned row vectors.
- Reused one row-diagnostic builder for KL-review and top-1-mismatch rows. Each
  mismatch now records request/scenario/teacher step and scope, winners, KL,
  top-k overlap, strict margin and candidate rank, teacher NLL/delta-p, and
  maximum absolute logit delta.
- Added `top1_mismatch_rows` to finite and non-finite results and made it a
  required field in the evaluation schema.
- Documented the attribution contract in `docs/TESTING.md`.
