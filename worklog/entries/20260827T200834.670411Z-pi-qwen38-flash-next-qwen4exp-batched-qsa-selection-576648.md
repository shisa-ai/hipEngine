# Batch Qwen4Exp prompt QSA selection

## Summary

Promoted exact chunk-batched QSA score generation and deterministic top-k.
Natural 4K improves 1.60% in a paired same-residency A/B, while score/top-k
launches fall 98.44% with identical arithmetic, selected positions, and output.

## Changes

- Generalized the strict device radix top-k kernel to one CTA per query row with
  variable visible prefixes and tails.
- Added a registered row-batched wrapper and a bounded FP32 score workspace to
  `Qwen4ExpQSAPrefillMetadata` (16,777,216 bytes at 262K/chunk64).
- Prompt QSA now launches one score grid and one top-k grid per sparse
  layer/chunk. `HIPENGINE_QWEN4_EXP_QSA_BATCHED_SELECTION=0` retains per-row
  device selection for bisection.
- Updated post-timing diagnostics to read the final row from the batched score
  workspace rather than the c1 score owner.
- Artifact:
  `benchmarks/results/2026-08-27-gfx1151-qwen38-flash-next-batched-qsa-selection.json`.
