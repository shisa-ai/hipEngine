# Retain Qwen3.6 small-weight arena

## Summary

Retained the existing bounded small-weight arena for the model-scoped
Qwen3.6-27B private-c1 XTX path. It packs 481 allocations <=16 MiB into one
212,750,336-byte owner and leaves 369 large tensors dedicated, reducing physical
weight owners 850 -> 370. Standard 512/128 sampled peak delta falls 16.214355
-> 16.171387 GiB (-44 MiB) while exact output and passing PM4 decode remain.

## Changes

- Added `GGUF_PRIVATE_C1_SMALL_WEIGHT_ARENA_POLICIES` keyed to
  `Qwen3.6-27B/MOSTLY_Q4_K_M`; unmeasured models do not inherit pointer-layout
  changes. The generic gfx1151 capability remains unchanged.
- Extended private-c1 policy resolution with optional model/file identities.
  Session setup scans only GGUF metadata when a backend publishes a non-empty
  model policy, before materialization/upload begins.
- Kept the existing fail-closed planner/allocator: <=16-MiB views are non-owning
  slices of one 4-KiB-aligned owner; all larger payloads stay dedicated; an
  arena denial falls back before partial ownership can escape.
- Published `benchmarks/results/2026-08-12-qwen36-27b-xtx-small-weight-arena.json`
  and updated the campaign scorecard, benchmark rollup, and changelog.

## Validation

- Model-scoped policy and host/mapped ownership test file: `15 passed` on GPU1.
- Planner/runtime audit: 481 selected logical allocations, 212,105,216 requested
  bytes, 212,750,336 owner bytes, 645,120 padding bytes, 369 dedicated owners,
  16,194,211,840 dedicated requested bytes, and 370 physical owners total.
- Full 512/1 smoke is exact: finite final logit 24.801517, token 9707. Sampled
  peak delta is 16.138184 GiB vs 16.181152 without the arena; tracked peak rises
  only by the planned 645,120 padding bytes.
- Default-PM4 512/128 r3 is exact: final logit 24.123718 and token 9707 each run;
  384 launches, zero native fallbacks. Prefill samples are
  703.033/727.781/719.232 tok/s (median 719.232, within prior 1.966% spread);
  decode 33.515/33.470/33.485 (median 33.485, +0.119%).
- Standard sampled peak delta is 16.171387 GiB vs 16.214355 (-44 MiB); tracked
  peak 15.605463 GiB; tracked bytes after close zero.
