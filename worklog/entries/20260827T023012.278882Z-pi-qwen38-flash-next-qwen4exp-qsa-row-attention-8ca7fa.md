# Add Qwen4Exp row-bulk QSA KV and attention

## Summary

Added complete-span row-bulk FP32→BF16 Qwen4Exp K/V writes and variable-
selection sparse QSA attention, with the existing FP32 dense batch context as
the below-budget sibling.

## Changes

- Added a shared-cache FP32 K/V prompt-row writer to the existing paged writer
  family. It consumes one complete row block table and INT64 logical position
  per row; it does not assume physical contiguity.
- Added row-bulk sparse original-K/V QSA attention with one selected-count and
  padded selected-position row per query. c1 sparse attention remains the
  strict primitive fallback.
- Added one reduced test that uses a physically reversed two-page table,
  variable positions/selection lengths, shared cache writes, sparse QSA, and
  the existing dense FP32 batch attention context.

## Validation

- RED: focused test first failed because the FP32 row writer and sparse-row QSA
  symbols did not exist.
- `uv run pytest -q tests/test_qwen4_exp_qsa_sparse_hip.py tests/test_qwen35_paged_kv_write_plan.py tests/test_qwen4_exp_qsa_hip.py -x`
  -> 10 passed.
- Every written physical BF16 page is exact to the logical oracle under table
  `[1, 0]`; sparse variable-selection and dense variable-context FP32 outputs
  match the original-K/V CPU oracle at `2e-5`.
- Cached gfx1151 trace records FP32 prompt-row KV write at 8,376 ns, sparse-row
  QSA at 7,213 ns, and the reused dense batch context at 397,985 ns for three
  rows ending at positions 2/257/510.
