# Add Qwen4Exp multirow MoE execution

## Summary

Extended strict Qwen4Exp top-10/shared MoE composition from c1 to independent
multirow token batches without changing the c1 primitive fallback.

## Changes

- Added generic BF16 token-local selected-expert weighted-sum and shared-gate
  combine batch kernels/wrappers in `paro_combine`.
- `run_qwen4_exp_moe` now accepts positive row counts, keeps existing selected
  projection and c1 combine routes, and uses the batch reductions only for
  `rows>1`.
- Parameterized the reduced Q4_K model oracle over one and three rows and added
  exact batch-vs-independent-c1 output/selected/routing assertions.

## Validation

- RED: the three-row reduced model failed the runner's `rows == 1` guard.
- `uv run pytest -q tests/test_qwen4_exp_runner_moe.py -x` -> 2 passed.
- Three-row BF16 output bits, selected expert IDs, and FP32 routing weights are
  exact to three independent c1 executions; all compact/intermediate/shared
  boundaries are finite and the existing CPU model tolerance gate passes.
- Cached gfx1151 rocprof trace of the three-row case records
  `weighted_sum_batch_out_kernel<unsigned short,float>` at 1,963 ns and
  `shared_gate_combine_batch_out_kernel<unsigned short>` at 1,403 ns.
