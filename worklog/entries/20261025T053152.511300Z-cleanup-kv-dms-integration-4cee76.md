# Unify DMS request admission and session retirement boundaries

## Summary

Integrate typed compact-DMS serving with the existing Qwen request lifecycle rather than maintaining a second admission/prefill/cleanup implementation. Document subsystem ownership separately from the kernel registry axes and perform a second source-backed review of KV/DMS and shared speculative boundaries.

## Changes

- Both DMS selectors publish one generator sidecar path; typed mode/decision options remain explicit. LLM/server reject both selectors together through one configuration resolver.
- Typed DMS acquires sessions through the shared generator path, including automatic context selection, policy/profile configuration and capacity reporting. Its separate prefill/decode/admission/retirement implementations are removed. Typed feature restrictions remain unchanged; the metadata-path composition retains compact INT8, DMS prefix snapshots and existing MTP integration.
- Registration validates context before publication even without a dense pool, applies the same compact output bound, and rejects prompts below the current bulk-convolution minimum before entering device work. This is the existing implementation precondition, not a new evidence gate. Short-prompt DMS execution would require another capture implementation.
- Admission assigns the compact session lease to its request. Common row cleanup delegates dense reuse versus private-session close. Queued cancellation cannot close an unowned idle session; compact retirement never resets then reuses retention state.
- The second pass found and fixed target-architecture scoping for delayed compact admission, stale prefix-mode observability and the typed sidecar path missing from HTTP readiness. CLI help distinguishes the two selectors. Session-local compact row zero remains distinct from engine request identity.
- Public validation exposed unbalanced fake head-major buffers from capacity sizing. The allocator trace identifies synthetic addresses, not GPU allocation leaks. Release those sizing buffers before another fake sizing run can reuse their addresses; accounting and byte estimates remain intact.
- Add `docs/ARCHITECTURE.md` as the subsystem entry point, linked from AGENTS, the documentation index and PLAN. Add `docs/reference/KV-DMS-INTEGRATION.md`, revise DMS serving, and distinguish production consumers from tested generic KV adapter interfaces. Preserve dated MTP campaign evidence; do not rewrite it as universal runtime support.
