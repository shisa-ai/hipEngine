# Admit explicitly bounded generic-only service children

## Summary

Permit an explicitly declared bounded generic child driver independently of
model-attached MTP support. Whole-request-only drivers remain rejected.

## Changes

- EngineService accepts `supports_bounded_generic_speculative_children` alongside
  its existing generic spelling and child-submission checks.
- A generic-only fake driver admits without model work and produces one child
  result per `poll(max_ticks=1)`. Blocking and streaming outputs agree; model
  work stays on the sole driver thread with no MTP or whole-request calls.

## Validation

- `uv run pytest -o addopts='' -q
  tests/test_integration_engine_service_speculative_ownership.py`: 14 passed.
- No RED-first run; removing the capability branch makes the new generic-only
  driver fail admission under the existing MTP-only check.
- No shipped provider declares the new capability yet. This is partial R0011
  infrastructure, not a claim that Laguna or the submit/poll adapter migrated.
