# Reject failed eager graph suite payload reuse

## Summary

The eager/graph checker ignored the in-process suite's return code and could
read an old payload after a failed run. It now refuses a nonzero return before
reading the output. Existing files are preserved for diagnosis, but cannot
certify a failed run. This is a harness integrity repair, not a device parity
finding or a decision to retire the diagnostic.

## Changes

- `scripts/gguf_ar_eager_graph_equivalence.py`: check the suite return code
  after restoring `sys.argv` and before reading a payload.
- `tests/test_unit_gguf_ar_eager_graph_equivalence.py`: inject a failed suite
  with an existing payload, assert refusal and preserved output/argument state;
  also check successful replacement and restored argument state.
