# Promote gfx1151 C2 packed prefill

## Summary

Promoted bounded native packed prefill for gfx1151 after counterbalanced c17
serving evidence. The scheduler emits up to eight compatible prompt rows in one
work item and Qwen GGUF calls the already-qualified `prefill_batch_native`.
All misses fall back before mutation; gfx1100 remains scalar.

- Added strict same-length/full-prompt/native-greedy preflight and batched finish
  accounting in the Qwen GGUF runner.
- Added scheduler/capability tests, artifact, README, Concurrency2, changelog.
