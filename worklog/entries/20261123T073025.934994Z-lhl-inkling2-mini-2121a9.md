# Own packed Inkling DSpark draft projections

## Summary

The GGUF DSpark drafter can own its packed Q8_0 matrices and FP32 projection scratch while using the same recurrent runtime as the original checkpoint. Public generation and draft discovery are unchanged.

## Changes

- Separate draft weight binding from the original Safetensors loader. Build the same recurrent runtime from the validated GGUF weight view.
- Add a packed Q8_0 draft projection owner using the existing registry and HIP library. Keep other matrices on the existing dense projection path. Closing the owner releases draft weights and scratch, without closing the borrowed BLAS handle.
