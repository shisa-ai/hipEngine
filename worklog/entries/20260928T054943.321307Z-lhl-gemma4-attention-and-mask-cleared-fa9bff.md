# the attention kernels and the keep mask are both bit-exact across block widths

## Summary

`20260928T054834` cleared the dense linear funnel and left four candidates. Two
more are now cleared, both by direct measurement, and the remaining set is small
enough to enumerate honestly.

## The attention kernels are bit-identical

`gemma4_attention_prefill_bf16`'s docstring states the claim outright: *"At
`tokens == 1` this routes to the decode kernel; its output is bit-identical to
the block kernel's."* That is exactly a route selected by row count, so it is
the first thing to test rather than the last.

Driving the kernel directly with two query rows over five live keys, and
comparing row 0 against a one-query-row call of the same row:

| window | row_offset | row 0 bit-equal | relative L2 |
| --- | --- | --- | --- |
| 0 | 0 | **True** | 0.00000000 |
| 4 | 0 | **True** | 0.00000000 |
| 4 | 3 | **True** | 0.00000000 |

The sliding cases matter because `window` and `row_offset` are the one place the
kernel takes the block's position as an input, and because `_forward_block`
passes `window` but leaves `row_offset` at its default of 0. The claim holds
with the skip active and with a nonzero offset.

## The keep mask is correct at both widths

`_keep_mask(attention, start, rows)` builds `(rows, start + rows - key_begin)`
columns, so a two-row block's row 0 carries one more column than a one-row
block's. Read from the source, row 0's extra column is `key_positions <=
queries` against `key_positions == start + 1`, so it is masked. Rather than
trust the reading, it is checked: over window in {None, 4, 64, 1024} crossed
with start in {0, 1, 3, 7, 40} and rows in {1, 2, 3, 5}, row 0's wide-block mask
matches the one-row mask on the shared columns and keeps nothing past its own
position. Zero mismatches.

Four kernels tested in isolation are all bit-exact while the model diverges at
layer 0. That is a useful shape: it says the defect is in one of the four
untested pieces rather than in anything already looked at, and it argues for
probing them in the order above, cheapest first. The embedding and the norms
take a `rows` argument and are trivially probeable; the experts need a routing
and are the most work.

**The fixture's layer 0 is sliding and layer 1 is full, and both diverge**, so
whatever this is, it is not confined to the sliding path.
