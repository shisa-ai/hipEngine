# packet5 guarded GPU row fixtures for pack8 decode depths

## Summary

New guarded GPU fixture suite
`tests/test_gguf_q4_k_pack8_gemv_row_guard.py` for the Q4_K pack8 decode
GEMV at every depth the C1 singleton native verify now issues (rows
2-8). Each fixture:

1. surrounds the batch rows with sentinel guard rows (0xDEAD) before
   row 0 and after the last batch row and asserts they are untouched —
   the buffer-overrun guard the campaign asks for;
2. asserts bit-exact row independence: one rows-K batch launch produces
   byte-identical outputs to K single-row launches — the contract that
   makes chunked rowtile dispatch exact by construction;
3. validates every row against the CPU Q4_K GEMV oracle
   (`kernels/cpu_reference/ops.py::gguf_quant_gemv`).

## Changes

- `tests/test_gguf_q4_k_pack8_gemv_row_guard.py`: 7 fixtures (depths
  2-8), shape 512x256, HIP-guarded.

## Validation

- All 7 pass. One fixture bug found and fixed during bring-up: the
  sentinel-filled output buffer must be uploaded before the launch;
  stale device-pool memory otherwise masquerades as an overrun (the
  kernel was correct — outputs landed exactly in rows 1..depth).
- The row-independence result is the GPU-level proof backing the
  launcher's chunking-exactness comment (per-row Q8_1 quantization and
  per-row SiLU/GEMV association).
