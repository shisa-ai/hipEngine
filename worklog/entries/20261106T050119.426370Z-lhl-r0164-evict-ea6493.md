# Retain failed target graph eviction for retry

## Summary

Eviction closes an old graph before removing its cache reference, so a failed
release stays reachable for teardown or explicit retry.

## Changes

- Retain entry on close failure; successful close may remove its own aliases.
- Do not close the new graph if multiple keys alias it; remove only the old key.
- Normal successful bound and ordering behavior are unchanged.
