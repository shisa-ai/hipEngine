# Gemma 4 gfx1151 baseline shape matrix

## Summary

The gfx1151 campaign had a per-unit metric (512/128 prefill seconds) and a
README row, but no single record of the public path across shapes. This is that
record: five shapes on the public `LLM.generate()` path, separated prefill,
decode, first-token and public wall, with the artifact and harness provenance
needed to compare against llama.cpp and against later revisions.

Prefill throughput falls 37% from 128 prompt to 4096 (122.50 -> 77.22 tok/s)
while decode falls 20% (21.96 -> 17.58 tok/s), so a per-token cost grows with
prompt length and is the first thing to attribute for long-prompt work. At
512/128 the gap to llama.cpp HIP on the same host and artifact is **8.40x on
prefill and 1.95x on decode**.
