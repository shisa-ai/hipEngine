# Add evaluator-only DMS diagnostic injection

## Summary

Added the evaluator-only diagnostic selection layer required for policy and
oracle attribution experiments. It is explicitly injected by artifact path and
cannot alter ordinary `sidecar` or `no_evict` routing.

## Changes

- Add pure deterministic recency, seeded-random, and attention-mass oracle
  adapters with oldest-position tie handling, exact per-head budgets, protected
  window checks, overlap/discarded-mass/concentration helpers, and frozen
  prompt-mask decode retention.
- Add immutable atomic diagnostic artifacts bound to prompt token hash, canonical
  positions, physical-layer map, KV heads, window/ratio, selector kind/seed,
  source hash, mask digest, and decode-retention schedule.
- Add fail-closed runtime `diagnostic` mode. It validates and consumes the
  sealed prefill mask, records route/digest/count observability, releases the
  dense prefill pool before compact decode, and retains all decoded tokens for
  the declared diagnostic schedule.
- Wire the existing quality evaluator to select one injection artifact per
  sequence and record its hash; reject diagnostic mode without an injection
  directory or an injection directory without diagnostic mode.
- Preserve ordinary mode normalization and behavior.
