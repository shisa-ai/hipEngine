# DFlash2 host-side numpy drafter exactness vs reference model

## Summary

D1 drafter-exactness core: a torch-free NumPy host-side DFlash2 drafter that
reproduces the real z-lab/dflash reference model's greedy chain selection on
identical inputs. Pins the exact math the native D2 kernels must match.

## Changes

- hipengine/speculative/dflash2_drafter.py (new): DFlash2NumpyDrafter with
  project_target_hidden, per-layer forward (rmsnorm, grouped conv prepare/
  finish, DFlash2 attention, MLP), full forward, compute_logits, propose;
  bf16->fp32 bit-cast weight loader.
- hipengine/kernels/cpu_reference/dflash2.py: add dflash2_rope_tables (Qwen3
  block-repeat layout), dflash2_attention_forward (q/k head norms, rotate_half
  rope, GQA, bidirectional sliding window); relax selector vocab check to <=
  codebook vocab (candidates only gather rows < logits vocab).
- hipengine/loading/dflash.py: parse rope_theta from rope_parameters
  (config stores it there, not top-level -> was defaulting to 10k instead of
  1e7); add output_multiplier / final_logit_softcapping fields.
- scripts/gen_dflash2_drafter_golden.py (new): golden trace from the real
  DFlash2DraftModel (fp32) over deterministic synthetic inputs.
- tests/fixtures/cpu_reference/dflash2_drafter_golden.npz (new).
- tests/test_dflash2_drafter.py (new): RED test vs golden (hidden, logits,
  exact greedy path, candidate sets).
- tests/test_dflash_metadata.py: assert rope_theta == 1e7 for the snapshot.

## Validation

- Golden path [129,110,206,225,17,162,147] reproduced exactly by the numpy
  drafter; draft hidden allclose atol/rtol 2e-4; candidate sets match;
  logits within fp32 accumulation tolerance.
- Notable fixes found by the golden comparison: rope_theta was parsed as 10k
  (config keeps it under rope_parameters) and the Qwen3 rope layout is
  block-repeat cat([freqs, freqs]) with rotate_half splitting at head_dim/2
  (not interleaved). Both corrected against the reference.
- uv run pytest tests/test_dflash_metadata.py tests/test_dflash2_cpu_reference.py
  tests/test_dflash2_drafter.py tests/test_cpu_reference.py: green.
