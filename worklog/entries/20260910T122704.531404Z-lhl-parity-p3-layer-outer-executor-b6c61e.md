# P3: layer-outer packed prefill executor, one shared oracle

## Summary

Roadmap P3. New executor `_prefill_batch_native_layer_outer` runs multi-chunk
slot-local packed INT8 prefills layer-outer: every chunk of a layer completes
before the next layer, so one shared BF16 oracle pair per session is sound
(positions never overlap across rounds inside a layer). The 16-owner transient
peak the chunk-outer executor realizes collapses to one owner. Behind
`HIPENGINE_GGUF_PACKED_LAYER_OUTER` (default OFF until the remaining gates:
same-host wall A/B at 1K/2K/4K/8K, trace identity); the corrected chunk-outer
executor remains the fallback for every unsupported shape.

## Changes

- `hipengine/runtime/qwen35_gguf_runner.py`:
  - `_prefill_batch_native_layer_outer`: slot-stable multi-round execution
    with a global row space in the full-position hidden planes (which the
    layer_outer_shared_oracle plan already allocates), one embedding launch
    per round, per-(layer, round) rebind + packed-scratch materialization
    matching the chunk-outer temporal pattern, per-layer ping-pong swap,
    final-row-only sampling tail, one state sync before and one scatter after
    the layer loop.
  - Fails closed (NotImplementedError, no device work) on: non-slot-stable
    rounds, non-shared plans, insufficient hidden capacity; declines on the
    non-direct or non-contiguous KV routes.
  - The executor clears `_int8_prefill_oracle_per_layer` on every session
    before any layer work - packed execution cannot silently realize 16
    pairs while the plan reports one.
  - `_prefill_batch_native_impl` dispatch: flag + shape gates (no hidden
    seeds, no layer captures, no target-hidden sinks), NotImplementedError
    falls back to chunk-outer.
- `tests/test_gguf_packed_layer_outer_prefill.py` (new): 13 tests - the
  three decline gates, single-chunk rejection, dispatch/fallback routing,
  hidden-seed skip, the per-layer reset binding (observed at the sync
  checkpoint), shared-key binding, flag default-off and cache hygiene.
- `scripts/gguf_prefill_route_ab.py`: reports `executor_mode` per arm.

## Validation

W7900 GPU0, 27B Q4_K_M, int8_per_token_head + FP32 scales.

- Parity vs the scalar bulk control, packed entry, 8 decode tokens:
  - 2,048-row prompt (two full 1,024-row rounds): bitwise-identical logits,
    identical generated IDs, 731.9 tok/s packed vs 746.6 scalar.
  - 1,500-row prompt (1,024 + 476-row tail round): bitwise-identical logits,
    `executor_mode: layer_outer_packed`, 602.4 tok/s vs 603.3.
- Server allocation probe at 16,384 declared context, 2,048-row prompt,
  flag ON: **oracle observed peak 0.125 GiB / 1 owner** vs 2.0 GiB / 16
  owners chunk-outer (-1.875 GiB, -94%), clean teardown, request wall
  3.115 s vs 3.06 s (noise). All other domains unchanged.
- CPU bundles: new file 13 green; oracle-per-layer, packed-workspace
  stability, int8-direct, and the packed-ar/verify selection green.
