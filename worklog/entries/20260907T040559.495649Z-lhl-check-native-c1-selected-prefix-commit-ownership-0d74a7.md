# Check native C1 selected-prefix commit ownership

## Summary

Extend the actual native packed C1 diagnostic to check selected-prefix commit
ownership. All 70 GPU calls pass across all ten prompts; this is not full
numerical qualification.

## Changes

- CPU greedy chain oracle computes the accepted prefix from captured full logits
  and actual candidate tokens, reserving the correction/bonus budget as defined
  by `TargetVerifyBatch.accept_from_top1` (independent implementation).
- Optional `capture --check-commit` checks device accepted counts and commit
  positions before the actual commit, hashes the independently selected source
  Conv/GDN and hidden row, then compares destination bytes, size and pointer
  after the real commit. Includes the existing pre-acceptance isolation guard.
- No runtime/kernel, default-policy or dependency changes.
