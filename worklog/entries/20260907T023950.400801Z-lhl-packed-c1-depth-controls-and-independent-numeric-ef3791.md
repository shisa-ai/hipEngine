# Packed C1 depth controls and independent conditional-logit diagnostic

## Summary

Native C1 K1/K2 passes all ten canonical prompts at N=1/2/8: 115 packed calls
per K1 run and 83 per K2 run, exact against matching-capacity true AR, engaged
and budget-conformed. The legacy target constructor is forbidden.

N1/K3's actual packed service target also passes an independent conditional-
logit comparison against strict AR: 70 cycles, 267 active rows, mean/p95/p99/max
KL 4.56055e-5 / 2.22535e-4 / 8.43522e-4 / 0.00160136 and 100% top-1.
Every prompt/category scope passes; no row exceeds the 0.02 review threshold.
This is not full profile qualification or a performance claim. C1 stays closed
publicly and Qwen3.8 automatic stays K0.

## Changes

- Add `scripts/qwen38_packed_c1_logits.py` with `capture` and `reference` modes.
  Capture instruments the real staged adapter/packed target without replacing
  its execution or forcing alternate head math. It checks root, prefix length,
  position and logical/padded geometry, reads actual device candidate IDs,
  rejects stale/direct-top1 logits, checks all rows finite and saves active-row
  logits in local NPZ files. All 70 calls used `q6_rowtile_f32_logits`; logical
  R2/R3/R4 (clipped K3 cycles) all dispatched P6.
- Reference uses a separately loaded strict-profile LLM with identical verified
  model content, prefills ONLY the original prompt, then steps every committed
  generated-prefix token before scoring each candidate input. It must not bulk
  prefill the generated prefix, which changes the reference schedule. Full-logit
  comparison uses the repository's stable per-row metric implementation and
  calibrated thresholds. Every result states `full_profile_qualification=False`.
- Add CPU guards for instrumentation and teardown, stale/direct-top1 head, wrong
  root/prefix/position, invalid vocabulary and geometry, nonfinite values,
  logit shape, tail/top1 failure and prompt-versus-decode replay ordering.
- No production or kernel code changes. No new environment flag or dependency.
- Artifact: `benchmarks/results/2026-09-07-w7900-packed-c1-depth-and-logits-diagnostic.json`.
  NPZ/raw logs remain under `/tmp`, not in git.
