# Harden the paired-measurement gate against incomplete evidence; stop the scope grant leaking between in-process runs

## Summary

Review found that the paired benchmark's `deterministic_repeats` gate was
vacuous on incomplete input, and that the public correction overstated what was
measured. Both are fixed here, plus a state-leak bug the fix exposed.

## The gate could accept a truncated payload

`_determinism` only asked whether each prompt had more than one distinct token
hash. A payload containing **one** run gives every prompt exactly one hash, so
the check found no disagreement and reported deterministic repeats. Nothing
verified that every prompt was present, that each appeared `runs` times, that
rows were unique, or that the payload matched the command that produced it —
and `--from-raw` trusted whatever file it was pointed at.

Added `_evidence_completeness()`, a binding gate (`evidence_complete`) that
checks, against the resolved command and the prompt file:

- `schema == 1` and `kind == qwen36_dense_gguf_ar_mtp_suite`;
- `model.path` equals the command's model;
- `workload.prompt_file`, `prompt_ids`, `prompt_count`,
  `max_new_tokens_visible` and `candidate_budgets` match the protocol;
- `provenance` carries host, device, backend, arch and commit;
- for `true_ar` and every MTP budget: exactly `prompts x runs` rows, no
  duplicate `(prompt, run)`, every prompt present, every prompt covering runs
  `0..runs-1`, and every row carrying a token hash.

`deterministic_repeats` is now `evidence_complete AND no hash disagreement`, so
the truncated payload fails both gates. `--from-raw` runs the same check, so a
stale or mismatched raw file cannot be promoted into the artifact.

## The fix exposed a state leak

`main()` called `_grant_mtp_scope_in_process()`, which monkeypatches
`admission.resolve_qwen35_gguf_artifact_preset`, and **never restored it**. The
new `--from-raw` test reaches that path (the earlier refusal test returned
before it), so four admission/certification tests began failing when the files
ran together while passing in isolation. The grant is now a
`mtp_scope_granted()` context manager that restores the original resolver in a
`finally`, so `main()` no longer changes the interpreter it runs in.

## The public correction overstated the evidence

`benchmarks/README.md` and `benchmarks/CHANGELOG.md` said "Plain decode is
unaffected". The correction worklog says the opposite — there is no W7900 plain
census, so plain behaviour on that device is unmeasured. Both now state that the
W7900/XTX gap is localised to two UD local32 kernels and that no plain claim is
made.

## Artifact hygiene

`git ls-files benchmarks/results` is 159 MB, of which seven raw `rocprofv3` trace
CSVs are ~73 MB, against `AGENTS.md` "Never Committed". They are unreferenced by
any doc and every published number comes from the few-KB census summaries beside
them. They belong to other agents' units, so this is recorded in
`docs/REFACTOR.md` with a removal trigger rather than deleted here. This unit's
own artifacts are all 4-32 KB.

## Changes

- `scripts/ud_mtp_paired.py`: `expected_prompt_ids`, `_evidence_completeness`,
  `evidence_complete` binding gate, completeness-gated `deterministic_repeats`,
  `--from-raw` validation, `mtp_scope_granted()` context manager.
- `tests/test_ud_mtp_paired.py`: complete/truncated/missing-prompt/duplicate/
  wrong-model/wrong-budget/wrong-schema/missing-provenance cases, an
  `--from-raw` refusal test, and a guard that the committed artifact is complete
  evidence whose recorded command still matches `resolve_commands()`.
- `benchmarks/results/paired-ud-plain-mtp-c1-natural25-b3.json`: regenerated
  with `evidence_completeness` per pair.
- `benchmarks/README.md`, `benchmarks/CHANGELOG.md`: the plain-decode claim.
- `docs/REFACTOR.md`: the artifact-hygiene ledger entry.

## Validation

- `pytest tests/test_ud_mtp_paired.py tests/test_ud_mtp_certification.py
  tests/test_gguf_ud_admission.py` -> 127 passed, 7 skipped. Before the
  scope-grant fix the same command failed 4 tests, which is what identified the
  leak.
- All four pairs of the committed artifact report
  `evidence_completeness.complete=True` with 20 rows per group and
  `binding_passed=True`.
- Regenerating the artifact twice from the raw payloads is byte-identical, and
  matches the committed file.
- `python3 scripts/sync_benchmark_readme.py --check`, `python3
  scripts/worklog.py check`, `git diff --check` all pass.
