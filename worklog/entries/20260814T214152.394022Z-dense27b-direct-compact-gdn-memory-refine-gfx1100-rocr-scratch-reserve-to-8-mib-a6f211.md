# Refine gfx1100 ROCr scratch reserve to 8 MiB

## Summary

Refined the homogeneous-gfx1100 process-start default from
`HSA_SCRATCH_SINGLE_LIMIT=33554432` to `8388608`. The 8-MiB threshold lowers
clean XTX and W7900 whole-device process peaks another 22.17-22.31 MiB without
changing tracked ownership, output IDs, kernel math, or meaningful throughput. Cumulative
clean saving versus ROCr's 140-MiB default is 128.6-131.1 MiB. Memory parity
with llama.cpp Vulkan remains open.

## Changes

- Changed only the gfx1100 backend process-metadata default and its exact tests;
  existing user values still win and mixed recognized architectures still
  receive no backend-local default.
- Updated the retained benchmark artifact, benchmark/root rollups, changelog,
  campaign summary, environment reference, and benchmark protocol to the
  final 8-MiB policy and clean rerun matrix.
- Audited the remaining AOTriton scratch instead of treating it as reserve.
  Correctly selected monolithic v2 is memory-neutral versus v3. Splitting by KV
  group halves each live allocation to 150 MiB but adds 17.55% traced attention
  time and regresses profiled full prefill 0.623%; splitting by Q head adds
  137.28% traced attention time and regresses full prefill 6.241%. Both split
  paths remain rejected and production AOTriton is unchanged.

## Validation

- Explicit 8-MiB RX 7900 XTX 512/1K/4K/8K medians are
  **973.457/1008.193/987.573/819.468 tok/s** prefill and
  **33.521/34.480/31.382/29.369 tok/s** decode. Versus the committed 32-MiB
  default, prefill moves **+0.143/+0.230/+0.026/-0.100%**, decode moves
  **-0.014/-0.121/+0.026/+0.024%**, and clean process-delta peaks fall
  **22.168/22.199/22.203/22.309 MiB**. The 4K row was rerun standalone from the
  exact **0.060455-GiB** idle baseline after rejecting a monitor row with
  delayed teardown. Tracked peaks are byte-identical, logits are finite, and
  every final ID is 9707.
- W7900 dense 27B 4K/128 moves **882.470 -> 884.762 tok/s (+0.260%)** prefill,
  **26.556 -> 26.517 (-0.148%)** decode, and process-delta peak
  **16.670509 -> 16.648766 GiB (-22.266 MiB)** with unchanged tracked bytes,
  finite logits, and exact IDs.
- W7900 Qwen3.6-35B-A3B 512 cached prefill completes at **2537.407 tok/s** with
  unchanged **21.066345-GiB** tracked peak and clean teardown.
- Configured compact-peer verify: **3 passed**. Configured routing/liveness
  guard: **77 passed**; modeled 4K arena remains **372.375 MiB**.
- `uv run pytest -q tests/test_gfx1151_backend.py tests/test_hip_runtime.py`:
