# Promote exact Qwen4Exp fused GR sigmoid mean

## Summary

Promoted the exact fused GR sigmoid-materialization plus gated-mean owner for
rows <=256 in both named strict and production profiles. It removes one launch
per GR read, improves the measured 128-step decode window 7.46%, and passes the
complete strict-parent exact/state/task/lifecycle gate. Rows >256 retain the
unfused chain because the fused kernel loses at rows508.

## Changes

- Bound `HIPENGINE_QWEN4_EXP_GR_SIGMOID_MEAN_FUSED=1` in strict and production.
- Added the selected scope to both profile manifests.
- Registered a same-ABI `strict_unfused` fallback that materializes sigmoid and
  then invokes the original gated mean.
- Extended `scripts/qwen4exp_route_pair.py` with durable counterbalanced decode
  mode; decode timing excludes prefill and hashes each complete token sequence.
- Added the compact artifact and updated the campaign, kernel catalog, benchmark
  rollup/changelog, and refactor trigger.
