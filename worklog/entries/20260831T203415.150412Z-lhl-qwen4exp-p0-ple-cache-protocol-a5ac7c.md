# Add isolated Qwen4Exp PLE cache protocol

## Summary

Added explicit warm/cold cache modes scoped only to the 28.8-GB PLE tensor file
range. The protocol never uses global `drop_caches` and does not evict hot model
weights or unrelated processes.

## Changes

- `Qwen4ExpPLEMMapTable.advise_cache()` applies matching mmap and
  `posix_fadvise` WILLNEED/DONTNEED to the tensor offset/length.
- Canonical hipEngine mode records cache mode/scope/advice and reapplies cold
  advice before every warmup/measured request.
- Warm mode advises once, then uses the declared request warmup.
- Added file-scope and parser tests.

## Validation

11/11 focused residency/canonical tests pass. The file-scoped test verifies both
mapping and descriptor advice use exactly the PLE tensor range. No cache timing
claim has been made yet.
