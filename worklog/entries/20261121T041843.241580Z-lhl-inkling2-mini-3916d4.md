# Move Inkling 2 target attention and KV to HIP

## Summary

Move target attention and its per-visit FP32 KV cache to gfx1100. Keep the CPU attention path as a reference.

## Changes

- Use explicit `KVLiveSpans` for slot offsets, live counts, absolute positions, and eviction masks. Each visit owns a separate device bank; local visits overwrite old slots while full visits retain their prefix.
- Apply grouped-query attention, learned relative bias, and the zero-valued attention sink on device. The host still prepares query, relative bias, and the current key/value vectors.

## Validation

- Focused CPU and GPU tests passed. The GPU fixture checked a wrapped cache and a non-wrapped cache against an independent FP64 reference. The cached `rocprofv3 --kernel-trace` run confirmed 16 attention dispatches.
- The original-checkpoint public gfx1100 DSpark smoke passed for text (` Paris.`) and vision (` red.`) with the same token IDs and accepted candidate as the previous implementation. The default CPU bundle passed.
