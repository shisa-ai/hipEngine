# Report each request's own decode batch width in the response

## Summary

A response described the queue it arrived in and nothing about the decode it
received. Four concurrent plain requests executed as width-4 steps — the server's
own histogram moved from `{}` to `{"4": 2}` — while every response reported
`queue_group.request_count: 1`, `backend_groups[0].actual_group_rows: [1]`, and
`verifier_rows: 0`. Read literally, the metadata said each request decoded alone.

`generation_shape` is queue-scoped by contract, so the fix is not to redefine it
but to report the executed width next to it. The batch owner now keeps a
per-request width histogram on the lease, and a completed AR row reports it:

```json
"choices": [{"hipengine": {"diagnostics": {"decode_batch": {
  "execution_path": "qwen4exp_full_model_ar_batch",
  "steps": 2, "step_widths": {"4": 2}, "max_width": 4, "state_slots": 4}}}}]
```

Live agreement on this host: all four responses reported `{"4": 2}` /
`max_width: 4`, and the server-wide histogram reported `{"4": 2}` for the same
interval. `generation_shape` still reports one queue request per arrival, which
is true of the queue.

## Changes

- `hipengine/generation/qwen4_exp_ar_batch.py`: `_Lease` carries `step_widths`;
  `step()` increments it for every participating lease under the existing state
  lock; new `request_telemetry(request_id)` returns that request's histogram and
  `max_width` while the lease still exists.
- `hipengine/generation/qwen4_exp_gguf.py`: `_ar_batch_telemetry(row)` builds the
  completion telemetry for a non-MTP row before `_release_runner` discards the
  lease. A row that never held a slot, and an MTP row, report nothing extra.
- `tests/test_unit_qwen4exp_ar_batch_decode.py`: the two-row scheduler test now
  asserts both responses carry `step_widths {"2": 2}`, `max_width 2`, `steps 2`,
  and `execution_path`, so a future change cannot silently drop the field.
- `docs/API.md`: documents the field, that it is per request, that it is absent
  for a slot-less or MTP row, and that `generation_shape` stays queue-scoped.
- `benchmarks/results/2026-10-18-zbook-qwen4exp-per-request-decode-width.json`:
  the live artifact, 5 checks.
- `docs/QWEN4EXP-PRODUCTION-SERVING.md`: PS9 records the unit.
