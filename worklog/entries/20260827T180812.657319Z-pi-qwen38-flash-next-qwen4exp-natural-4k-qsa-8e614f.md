# Qualify natural 4K QSA retrieval

## Summary

Qualified the first natural, chat-formatted 4K QSA retrieval row. The model
retrieves the early-context code exactly; selected-index control matches the
pinned official Transformers equations, all QSA layers retain the needle, and
snapshot replay/rollback remain bit-exact.

## Changes

- Added `scripts/qwen4_exp_qsa_retrieval_gate.py`, a reproducible natural
  archive-retrieval, selected-index CPU oracle, replay/isolation, and teardown
  gate. Added two pure unit tests for prompt bounds and optional llama taps.
- Pinned current read-only Qwen4Exp references: Transformers `fc5c5bde8`, vLLM
  PR #53896 `2a4cd640f` / PLE PR #53899 `95dc96d1d`, SGLang model PR #36497
  `7c66045d7`, AMD PR #36601 `3003ddf15`, and PD-state PR #36651 `7bcf5ba35`.
- Recorded external Strix Halo targets separately from same-host evidence.
- Retained compact evidence at
  `benchmarks/results/2026-08-27-gfx1151-qwen38-flash-next-natural-4k-qsa.json`.

## Validation

- `uv run pytest -q tests/test_qwen4_exp_qsa_retrieval_gate.py -x`: 2 passed.
- Exact gate command is in the artifact; 4,096 prompt tokens, needle at token
  720, 304.944-second correctness-first prefill.
- Final generated answer is exactly `VIOLET-7391` after the model's reasoning
  block; 100 generated tokens including EOS.
- The needle block is selected in all 12 QSA layers. Final-layer selected
  positions match the independent CPU formula oracle 2,048/2,048.
- Repeat generation and an abandoned alternate-token branch followed by restore
  reproduce logits bit-for-bit.
- Peak tracked memory is 82,874,289,648 bytes; close returns to zero bytes and
  zero allocations.
- A preceding matched-special-token llama PR #27742 diagnostic measured KL
  `3.31e-12` and top-1 248068 exact. llama's fixed 2,051 output width above the
  complete-block boundary differs from official Transformers semantics, so
  llama selected IDs are diagnostic rather than binding there.
