# Attribute current native verifier families

## Summary

Completed R1 before writing the IU4 model leaf: captured cache-only
`rocprofv3` kernel and ROCTX marker traces for the current exact transactional
Qwen3.8-27B Q4_K_S native B1/B2/B3 target windows. Gate/up is substantial but
not dominant enough to support a large single-request system claim. At physical
M4 it owns 35.576 ms of 89.348 ms kernel time and 148.655 ms target wall;
streaming the current 6.417-GB qmicro family implies 180.4 GB/s. An impossible
221-GB/s S4 replacement with zero activation-pack cost bounds target speedup at
1.070x; deleting gate/up entirely bounds it at 1.314x.
