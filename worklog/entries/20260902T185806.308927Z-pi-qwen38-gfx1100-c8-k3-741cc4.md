# Refine C8 source Q5 to precision-preserving R32

## Summary

The source-faithful FP16-DS4 C8 Q5 candidate passed strict-teacher numerics and improved pooled task throughput, but failed the binding category gate because one `general_en_plan` acceptance decision changed. Replaced it with a precision-preserving K-major D4S4-FP32 design and narrowed runtime ownership to R32, the only operation-positive shape. The new route is still default-off pending tracked-clean marker and task gates.

## Changes

- Replaced the C8 source producer with K-major 160-byte D4S4 records whose quantized bytes and FP32 scale/sum metadata independently byte-match the retained raw producer; the generic I128/J128 DS4 path remains intact.
- Replaced C8 LDS weight metadata with FP32 scale/min values, registered truthful `q8_1_d4s4_f32/bf16_kmajor` and `mmq_i64_j16_j32_k256_q8_1_d4s4_f32_kmajor_*` gfx1100 keys, and excluded both from gfx1151 aliasing.
- Scoped dynamic source dispatch to exactly R32. R24 and all shape/policy misses retain the production raw D4S4 owner, whose grouped T16 strict fallback is unchanged.
- Split producer and consumer libraries so the producer uses baseline arithmetic while the source-shaped consumer retains its separately staged fast-math build. Added CPU byte-packer, producer parity, registry, workspace, and route tests.
