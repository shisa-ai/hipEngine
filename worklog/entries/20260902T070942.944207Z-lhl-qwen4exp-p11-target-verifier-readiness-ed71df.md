# Qwen4Exp P11 target verifier readiness

## Summary

The P11 census ranks serial target verification first at 87.652 ms per row, but Qwen4Exp has no executable rows<=8 block-verifier candidate. Its multirow primitive is prompt-prefill-only and lacks per-row scoring and transactional accepted-prefix state. The mature Qwen3.5 verifier depends on a different state and graph ABI. Wiring either path into the public provider now would misstate correctness and economics.
