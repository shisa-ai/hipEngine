# Add GGUF dense-pair profile requalification adapter

## Summary

Added a calibration-envelope adapter for a shape-scoped dense GGUF gate/up+SiLU
route. It compares a registered exact variant with the current backend-package
candidate at identical strict teacher contexts while logits are resident,
requires three exact repeats, attributes every top-1 mismatch, and restores the
package policy after capture. Historical status is provenance only.

The adapter intentionally stops short of profile certification: its manifests
are evidentiary rather than runtime-resolved, and it does not fabricate exact
control telemetry, task verdicts, BF16-relative evidence, or performance.

## Changes

- Added `scripts/execution_profile_gguf_dense_pair_gate.py` with strict/current
  owner verification, registry checks, shape-only policy replacement, full
  prompt+heldout capture, calibrated evaluator output, repeat hashes, prompt and
  model/source provenance, strict/candidate evidence manifests, and fail-closed
  qualification blockers.
- Added pure tests proving policy override is non-mutating/model+shape scoped and
  ambiguous variants are rejected.
