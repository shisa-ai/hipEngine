# Verifier speed lanes: baseline + reduced-DAG opt-out on W7900/gfx1100

## Summary

Established a clean exact 8-prompt verifier baseline on this W7900/gfx1100 host and
quantified the retained reduced-DAG fusion contribution via the documented
opt-out. The current verifier stack is confirmed to be at its fused optimum:
the retained reduced-DAG slices are active and worth ~0.51 ms/cycle verify;
further #12 gains require deeper composite-kernel work, not another flag flip.

## Changes

- **Model infra on this host:** the documented benchmark model
  `/models/hipengine/Qwen3.6-35B-A3B-PARO-full4096-e5-packed-MTP-BF16` has broken
  symlinks (config.json / model.safetensors / tokenizer.json point to a HF repo
  absent on this host). Repaired the tokenizer.json symlink to the existing
  `PARO-packed` blob. The available `PARO-packed-MTP-BF16` model **diverges on the
  `translation` prompt even at D32** (AR=248045 vs MTP=74455 at position 23),
  so full 9-prompt D32 exactness cannot be reproduced here. Baseline/experiments
  use the 8 exact non-translation prompts (all `exact_ar_match=true`).
- **Baseline (8 prompts, B=1, decode_batched, graph off, packed model):**
  observed speedup **0.9515x**, actual 0.9366x, cycle wall **15.07 ms/cycle**
  (verify **13.48 ms** + proposal **1.58 ms**), AR 110.8 tok/s, MTP 103.7 tok/s,
  acceptance 0.588. Artifact: `/tmp/hipengine-mtp-b1-baseline-8p.json`.
- **Reduced-DAG opt-out** (`HIPENGINE_LINEAR_SHARED_DOWN_COMBINE_FUSED=0`,
  `HIPENGINE_FULL_SHARED_DOWN_COMBINE_FUSED=0`,
  `HIPENGINE_LINEAR_SHARED_SILU_ROTATE_FUSED=0`,
  `HIPENGINE_LINEAR_AB_DUAL_SEPARATE=0`): observed **0.9205x** (was 0.9515x),
  wall **15.59 ms** (was 15.07), verify **13.99 ms** (was 13.48), all 8 exact.
  Confirms the retained fusions contribute ~0.51 ms/cycle verify.
  Artifact: `/tmp/hipengine-mtp-b1-reduceddag-optout.json`.
- **#13 adaptive-budget oracle test (8 prompts, packed model):** per-prompt
  oracle map (`code_python=B3, code_cpp=B2, qa_factual=B2, creative_short=B3,
  others B1`) gives **0.9318x** observed, wall **17.69 ms/cycle**, verify
  **15.46 ms/cycle**, all 8 exact. This **regresses vs fixed B=1** (0.9515x,
  15.07 ms, 13.48 ms) on this host — unlike the docs' full4096-model oracle
  (1.041x). Adaptive budget is a no-hold on this stack/model.
  Artifact: `/tmp/hipengine-mtp-oracle-budget-8p.json`.
- **#14 overlap:** the `HIPENGINE_MTP_OVERLAP_VERIFY_COMMIT_PROPOSER` prototype
  was removed from the tree (no flag exists). Prior naive overlap no-held
  (proposal/update grew 1.243->1.438 ms). Proposer share is only ~1.58 ms/cycle
  (~10% of wall), so overlap upside is inherently small. No testable
  implementation remains; effectively closed.
- **#15 D64 exactness:** deep resident-state drift correctness (translation
  token-34 fork), compounded on this host by the packed model diverging at D32
  translation. Not tractable in this session; blocks #13 promotion.
- **Code assessment of remaining #12 levers:** verifier MoE rotate fusions
  (`HIPENGINE_MOE_FUSED_ROTATE`, `HIPENGINE_SELECTED_MOE_STAGED_ROTATE`,
  `HIPENGINE_SELECTED_MOE_DOWN_STAGED`) are all default-off documented no-holds
  (in-LDS rotation blowup / economics regression). The GGUF fused-MoE-FNN path
  does not apply to this PARO/AWQ verifier. Current B=1 verifier profile:
  832.8 launches/pass, 9.38 ms kernel/pass, top families w4_dual_gemv 1.44,
  moe_gate_up_dual 1.21, w4_single 1.08, gdn_decode 1.04, LM-head w8a16 0.81,
  moe_paro_rotate_in 0.80, moe_down 0.77 ms/pass.

## Validation

- Baseline and opt-out are both `all_exact_ar_match=true` on the 8-prompt subset
  (excluded `translation`, which diverges on the packed model).
- Exact commands recorded in artifacts; same host, same model, same config
  (B=1 decode_batched graph-off), same-suite protocol.

## Next

- #12 (reduced-DAG): fusions confirmed active and contributing (~0.51 ms/cycle
  verify); stack at fused optimum; deeper composite kernels are open deep work.
- #13 (adaptive budget): oracle **regresses** on this host (0.9318x vs 0.9515x
  fixed B=1); no-hold. Promotion additionally blocked by #15.
- #14 (overlap): prototype removed, no testable flag, small proposer share;
  closed as no-hold.

available `PARO-packed` model diverges on `translation` at D32; the documented

row requires the full model + full 9-prompt exact suite.
