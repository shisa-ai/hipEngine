# Cover every prompt in the mixed economics role

## Summary

The economics capture's initial prompt stride advanced by batch width. At
widths 2/4/8 over 18 prompts, it placed only half the prompts in the explicit
MTP role even with 18 waves per cell. Advance one prompt per cell instead;
matched AR/mixed arms still receive identical groups.

## Changes

- Use a unit prompt stride in `wave_plan` and update its deterministic offset
  expectations. Add a regression asserting every prompt takes the MTP role at
  each width and repetition when the cell count equals the suite size.
