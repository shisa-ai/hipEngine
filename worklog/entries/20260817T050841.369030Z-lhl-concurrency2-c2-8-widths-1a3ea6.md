# Qualify shared-slot physical c4/c8

## Summary

Promoted `GGUF_SHARED_SLOT_AR_PHYSICAL_WIDTHS` from `(1, 2)` to `(1, 2, 4, 8)` on gfx1100 after a complete byte-exact hardware gate. Logical c8 now lowers to one physical c8 bucket (and c4 to c4), recovering most of the c2-cap throughput cost measured in the old-protocol apples-to-apples run (c8 0.298x old). The packed AR decode path was already row-generic to 8 lanes; only the registered-width evidence was missing.
