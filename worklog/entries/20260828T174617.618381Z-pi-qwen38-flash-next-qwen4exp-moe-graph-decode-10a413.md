# Replay exact Qwen4Exp MoE layer graphs

## Summary

Promoted request-owned, self-validating per-layer MoE graph replay as the
Qwen4Exp gfx1151 default. Counterbalanced c1 decode improves 6.511→11.515 tok/s
(1.769x) with exact full logits/IDs and physical c2/lifecycle.

## Changes

- Added optional graph ownership to Qwen4Exp `run_qwen4_exp_moe` and decode
  layer composition; every layer key binds its own weights and shared request
  scratch.
- gfx1151 capability `QWEN4_EXP_MOE_GRAPH=True`; env `=0` is eager fallback.
- Capture includes only stateless router/selected/shared MoE/combine. GDN, QSA,
  PLE, GR, KV/index state, head, and sampler remain eager.
- Cache closes before request scratch/state. Capture or parity failure is
  fail-closed eager.
- Corrected the performance diagnosis: selected Q4/Q5 were already one host
  launch per layer across all 10 rows; the graph contracts their internal
  chains, while future mul_mat_id work targets workgroup/grid dataflow.

## Validation

- Counterbalanced full-logit packet: eager 4.915090 s / 6.510562 tok/s;
  graph 2.778950 s / 11.515142 tok/s (-43.46%, 1.7687x).
- Three graph repeats, 192 full-logit positions and all IDs SHA/exact.
- 48 captures, 7,632 replays, 7,680 eager controls, zero rejects.
- Physical c2 serial/c2 IDs exact, six stream chunks, +550,283,960 tracked
  bytes, shutdown 0 bytes/allocations.
- 19 generic graph/backend/Qwen4Exp serving tests pass.
- Instrumented wall/stream/post-stream host medians are 193.91/193.74/0.18 ms:
  logits readback/NumPy is not the former inferred 55-ms gap.
