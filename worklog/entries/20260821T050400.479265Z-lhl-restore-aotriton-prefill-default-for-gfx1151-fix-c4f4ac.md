# Restore AOTriton prefill default for gfx1151 (fix mid/long-context GGUF prefill regression)

## Summary

Commit `f76a76697` ("gfx1151 route all full-attention prefill to native (no
aotriton crossover)") set `GGUF_AOTRITON_PREFILL = False` in
`hipengine/kernels/hip_gfx1151/__init__.py` based on a 2026-08-20 slice
measurement (64..2048) claiming native was ~2-5% faster with no crossover. That
measurement did not cover mid/long context. Empirically the native bulk-prefill
full-attention path collapses as context grows and even hangs/fails at 2K+,
while AOTriton holds flat. This entry restores AOTriton as the gfx1151 GGUF
prefill default.

## Changes

- `hipengine/kernels/hip_gfx1151/__init__.py`: `GGUF_AOTRITON_PREFILL = False`
  -> `True` (the retained 4K prefill ~1430 tok/s predates the False default).
- `hipengine/runtime/qwen35_gguf_runner.py`: updated the
  `_gguf_aotriton_prefill_allowed` docstring that rationalized the False
  default (it is now wrong). Sub-512 rows still use native via the retained
  512-token crossover; `HIPENGINE_GGUF_AOTRITON_PREFILL_ENABLE` remains an
  explicit override.

## Validation

Measured on gfx1151 (Radeon 8060S, therock hermetic env, HIP 7.15.0), 35B-A3B
GGUF Q4_K_M, `qwen35_readme_sweep.py` bulk prefill, 1 warmup + measured runs:

Native (old default) vs AOTriton (new default), Qwen3.6-35B-A3B-UD-Q4_K_M:

| shape | native | aotriton | note |
| --- | --- | --- | --- |
| 512/128 | 1094 | 1274 | aotriton +16% |
| 1K/128 | 828 | 1318 | aotriton +59% |
| 2K/128 | 362 | 1333 | native ~3.7x slower, decode unstable |
| 4K/128 | 234 | 1310 | aotriton +5.7x |

Native 1K/2K/4K combined run did not even write its JSON (hung/failed at 2K);
a fresh native 2K-only run gave 362 tok/s prefill with unstable decode (~20
tok/s vs ~55). AOTriton completed cleanly through 4K with decode ~54-55 tok/s.

Ornith-1.5-35B-A3B-Q4_K_M after the flip (new default, no env override):
512/128 prefill 957 tok/s, 4K/128 prefill 976 tok/s (was ~220 under the old
default), decode ~50 tok/s, peak 20.59 GiB, final token ids stable (9707).

Correctness: generated final token ids stable across all runs; `pytest
tests/test_aotriton_discovery.py tests/test_kernel_registry.py` -> 17 passed.

Decode and memory are non-regressive with the flip.
