# Make MTP budget sweep physically truthful

## Summary

The first T1.4 packet exposed a harness ownership bug: labeled B1/B2/B3/B4
runs all executed physical B3 (2.829 drafts/cycle and identical draft counts).
`LLM(speculative_candidate_budget=...)` did not construct the staged adapter;
`HIPENGINE_GGUF_MTP_CANDIDATE_BUDGET` did. No result from that packet is used as
a budget comparison.

## Changes

- The harness now scopes `HIPENGINE_GGUF_MTP_CANDIDATE_BUDGET` from
  `--candidate-budget` before model/adapter construction and rejects a
  conflicting caller environment.
- Added per-response physical budget conformance: generated drafts must be <=
  requested budget x cycles. Overall pass binds every measured cell.
- Added focused tests for conformance/pass/fail behavior.

## Validation

  -> 9 passed (existing Starlette warning).
- The invalid first packet is retained only as diagnostic evidence of the
  harness bug; no performance claim.
- `git diff --check` passes.
