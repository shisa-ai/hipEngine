  the legacy target.

  mode compares authoritative IDs only and reports `usage_exact=null`; it does
  not synthesize public usage. Persist both source admission decisions and
  candidate/oracle outputs alongside traces.
- CPU validator rejects missing/reversed transitions, new requests, storage
  changes, missing packed execution, singleton loops, target errors, and legacy C1.
