# Reject grouped gfx1100 Q6 root rows8 grid

## Summary

Reject and remove the exact grouped-grid F32 R8 root candidate. The isolated
actual-weight leaf is positive, but its same-build C8 marker worsens the binding
operation-complete target and complete walls. The retained repeated-R8
composition remains default.

## Changes

- Remove the grouped F32 HIP symbol, wrapper, registry key, runtime routing,
  candidate environment read, and candidate-only tests.
- Close/remove the temporary candidate entry in `docs/REFACTOR.md` and record
  the rejection in `docs/KERNELS.md`.
- Preserve the bounded evidence in
  `benchmarks/results/2026-09-02-w7900-q4km-k3-q6-grouped-root-rows8-rejected.json`.

## Validation

- Candidate source commit `5da420e8e2bfd8adee391a02430c5cb958589264`
  was tracked-clean; both marker processes used the same cached build.
- Actual Qwen3.8 `output.weight` R24 leaf: float-bit exact, zero mismatches,
  finite, **38/40** paired wins; three R8 **10.395442 ms** versus grouped R24
  **10.321635 ms**, **1.007151x**.
- Same-build C8 marker preserves generated IDs and acceptance `[3, 3, 2]`.
  It reduces root launches **3→1** and root wall **8.358→8.312 ms (-0.55%)**,
  but target wall worsens **169.861→170.989 ms (+0.66%)**, target device-union
  worsens **143.122→145.156 ms (+1.42%)**, and complete wall worsens
  **1.3359→1.3440 s (+0.60%)**.
- The marker gate therefore fails. No complete C5-C8 suite was spent.
- After removal, retained root wrapper/registry/planner focused tests pass and
  source files compile; the candidate string is absent from product/test paths.

## Next

Do not retry launch-only grouping for the F32 root; its kernel-body savings are
too small. Profile another operation-complete target family with first-order
headroom before adding a new candidate.
