# Measure dynamic Inkling convolution and verify HTTP isolation

## Summary

The dynamic convolution handoff reduced warmed public latency in both run orders on W7900. A separate Strix Halo HTTP test verified request isolation across overlapping clients, a local cache wrap, and a client disconnect followed by a replacement request. The replacement did not emit text until after the long request completed; this is not evidence of continuous batching or Loom throughput parity.

## Changes

- No runtime changes. Both checks used `71452e522`, `fast`, FP32 KV, greedy decoding, no draft and no prefix reuse.
