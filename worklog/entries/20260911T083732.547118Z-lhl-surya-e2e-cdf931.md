# Surya OCR 2 end-to-end inference (milestones 3-5)

## Summary

The full OCR pipeline now runs torch-free end to end and matches the
torch fp32 oracle at every stage: image preprocessing, vision tower,
feature injection, mRoPE, cached decode, and public API output.
Committed under docs/MODEL-SURYA.md milestones 3 (vision), 4
(generation + public path), and the coverage extension.

## Changes

- hipengine/kernels/cpu_reference/surya.py: vision tower (patch embed,
  bilinear align_corners=True pos-table resample from the 48x48 table,
  12 pre-LN bidirectional blocks with full-dim 2D rope + tanh-GELU MLP,
  per-patch-LN -> erf-GELU merger); TextState.image_pads_consumed for
  chunked image prefill feature offsets.
- hipengine/loading/surya.py (torch-free): model/spec/weight loading;
  tokenizer (the shipped tokenizer.json is a CHARACTER-level
  WordLevel tokenizer with intact Qwen specials — loaded directly via
  the tokenizers lib); chat rendering with image-pad expansion;
  smart_resize with the ceil-up min-pixels branch (192x320 -> 224x352
  validated); block-major patchify with temporal duplication; raster
  mRoPE over the merged grid (transformers quirk kept for parity);
  run_surya_ocr convenience entry.
- hipengine/generation/surya.py: SuryaOCRGenerator registered under
  (surya_ocr2, cpu_reference, fp32) — TextGenerator protocol for
  text-only prompts, generate_multimodal_detailed + supports_vision
  for OCR; greedy-only (sampling raises by construction).
- plugins wired: hipengine/models/__init__.py + generation
  register_builtin_generators.
- scripts/surya_oracle_torch.py: new rect case (192x320 page,
  grid (1,14,22), 77 image tokens) -> oracle_rect.npz; torch greedy
  reference captured to oracle_greedy.json.
