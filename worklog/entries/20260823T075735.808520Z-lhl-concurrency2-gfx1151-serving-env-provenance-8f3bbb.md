# Record gfx1151 serving environment provenance

## Summary

Made the F1 serving harness record the effective environment inherited by the
server process. This closes the provenance gap that left the retained gfx1151
C2 rows ambiguous between explicit FP32 recurrent state and Q4_K_S's current
FP16-state package default.

## Changes

- Added a bounded effective-server environment manifest to every harness
  artifact, including architecture, execution profile, recurrent-state mode,
  physical-width override, queue count, compiler-version file, device selectors,
  and the route variables synthesized by the harness.
- Derived the manifest from `_server_command_and_env()` so recorded values match
  the child server environment after queue/compiler/device overrides rather than
  merely echoing the parent shell.
- Added a focused test covering explicit strict-state and architecture axes,
  queue count, compiler identity, HIP-only device selection, and generated native
  packed-route policy.
