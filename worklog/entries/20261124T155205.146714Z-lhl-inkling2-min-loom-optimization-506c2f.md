# Inkling2 GGUF decode is host-bound; resident attention slower at rows=1

## Summary

Warm fast-profile decode of the UD-Q4_K_M GGUF artifact (48 greedy tokens, cProfile, device routes
on) confirms the decode loop is dominated by host-side work, not GPU kernels. Rewiring scalar decode
to the device-resident attention path (unsqueezing rows to 2-D) produced token-identical output but
was ~14% *slower*, so it was reverted; do not retry that shape without a persistent per-visit plan.

Key measurements (median of 3 warm runs, 48-token greedy, max_sequence_length=512):

- Baseline (resident attention gated to ndim==2): 2.633–2.638 s total (~55 ms/token).
- Resident-for-scalar patch: 3.063–3.066 s/run, tokens bit-identical to baseline. Per-visit Python
  plan construction (`_attention_plan` partials, controller staging) outweighs the saved numpy/transfer work.
- cProfile (3.09 s over 48 tokens): `stream_synchronize` 0.69 s; `_project_groups` 0.82 s cumulative;
  numpy `_rms`/`_clip`/`_mean` family ~0.5 s; `_attention` 1.06 s cumulative; `_prepare_layer` 2.12 s
  cumulative; `project_experts_device_routes` self time negligible (0.022 s) — the device-route path works.

Implications:

- The tok/s ceiling is Python dispatch + round-trip synchronization, not kernels; only structural
  residency (cached per-visit plan descriptors, or traversal below Python) can move it.
- `_rms`/`_clip` micro-optimizations are off the table for now: `tests/test_unit_inkling2_reference.py`
  pins `_rms` bitwise to `np.mean(x*x)` semantics (`test_rms_preserves_numpy_mean_reduction_bits`).
  A dot-product rewrite matched within 2.4e-7 but failed those pins; do not "optimize" it without
  updating the pinned contract explicitly.
- Speculative-decode `stage_controllers` path and `_resident_block` remain the plausible structural
  routes; `_resident_block` is still uncalled and needs its own bring-up session.
- `rel @ rel_logits_proj` host matmul is small; device-token-selection for sampling is unnecessary
  (logits download is not on the critical path).

## Changes

- None. The experimental scalar→resident rewiring in `hipengine/runtime/inkling2_mini_reference.py`
  was implemented, A/B tested, and reverted in full; the tree is clean at fe305feff.

## Validation

- Token-level A/B (identical ids across baseline and patched builds, 48 greedy tokens).
- Timing A/B: 3 repetitions each side, values above; no overlap between the two distributions.
- `pytest tests/test_unit_inkling2_reference.py tests/test_unit_inkling2_mini.py
  tests/test_unit_inkling2_gguf_runtime.py tests/test_unit_inkling2_gguf.py` → 57 passed after revert.

## Next

Before re-attempting resident scalar decode: (1) cache `_attention_plan` per visit with a position-keyed
or split descriptor (the current plan embeds `plan.position` for the log-scale clip, so it is not
reusable as-is), or move the traversal below Python (graph/C++). Re-measure with the 3-rep A/B harness
before keeping any variant. Until then, campaign metric stands at 18.08 tok/s (unchanged).
