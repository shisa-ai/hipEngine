# YuE2 M6 product session and end-to-end gate

## Summary

M6 is complete except for the held-out task-quality suite. The YuE2 session is a
registered product path (`yue2` model plugin, `Yue2Session` over one resident AR
runtime) and `scripts/yue2_e2e_gate.py` validates it end to end, torch-free, on
both recorded conditioning and a live request.

Recorded 12-case replay (zbook / gfx1151, gfx1151, 4 ODE steps): **12/12** cases
reproduce the reference's own latent frame count and sample count exactly - 21 000
latent frames, 40 319 232 samples, every case finite and non-silent (peaks
0.770-1.035) - in 3320 s (148 s shortest, 370 s longest; the reference's recorded
runs take 150-370 s per case). Replaying `english-full-s1234` twice gives
bit-identical latents.

Live greedy request (`cot=off`, 96-token budget, 32 steps): 96 semantic tokens ->
96 latent frames -> 3.84 s of audio in 16.4 s, with identical latent and audio
identities on a repeat (16.2 s). Neither run imports torch; the gate fails if it
ever does.

## Changes

- `hipengine/runtime/yue2_session.py`: `Yue2Session` (plan -> semantic -> solve ->
  decode) with single-flight and lifecycle guards, `SongResult` with canonical and
  tensor identities, and `decode` normalizing the solver's `[frames, latent_dim]`
  layout to the decoder's channel-first one.
- `hipengine/runtime/yue2_ar.py`: `Yue2ArRuntime` now keeps `self.weights`, which
  the session's provenance block reads for the request identity.
- `hipengine/models/__init__.py`: imports `hipengine.models.yue2`, so the plugin
  actually registers (it previously existed but was never imported).
- `scripts/yue2_e2e_gate.py`: the gate. `--skip-replay` / `--skip-live` run the
  phases independently; the replay is driven from the committed fixtures and the
  live phase from a greedy in-script request.
- `tests/test_unit_yue2_product.py`: 15 unit tests over the session, its
  identities, the layout normalization, the lifecycle guards, plugin resolution and
  a fake-runtime end-to-end run that asserts torch is never imported.

## Validation

- `python3 scripts/yue2_e2e_gate.py --skip-live --steps 4 --json
  benchmarks/results/yue2_e2e_gate_20260916.json` -> `12/12 cases ... PASS`,
  determinism bit-identical, `torch imported: False`.
- `python3 scripts/yue2_e2e_gate.py --skip-replay --live-steps 32 --json
  benchmarks/results/yue2_e2e_live_gate_20260916.json` -> live pass, repeat
  identical.
- 213 YuE2 unit tests pass (15 new); 26 registry/import tests pass.
- Two real defects found by the gate, both invisible to the unit tests because
  those use fake runtimes: the session's `decode` passed `[frames, latent_dim]`
  straight to the decoder (which expects `[1, latent_dim, frames]`), and
  `Yue2ArRuntime` had no `weights` attribute for the provenance line. The
  fake-runtime tests now carry a weight identity so that path is exercised.
- `benchmarks/README.md`, `benchmarks/CHANGELOG.md`, `docs/MODEL-YUE2.md` rolled
  up; `sync_benchmark_readme.py --check` clean.
