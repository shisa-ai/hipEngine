# Disqualify the convolution state at the re-entry

## Summary

The convolution state is not the re-entry defect. The host's undo journal belongs to speculative decoding's provisional blocks, a plain prefill traversal runs with no journal, and the convolution writes at an explicit position so replaying the same positions overwrites the same slots.

## Changes

- No code change; the hypothesis was checked against the host traversal before any run.

## Validation

- `_traverse` never creates a journal. `Inkling2UndoJournal` is created only in `provisional_block` and cleared in its `finally`.
- `_prepare_layer` passes `undo=self._undo` to the convolution calls, which is `None` for prefill, so the host's prefill convolution runs unjournaled exactly as the block's does.
- The convolution applies at `position=session.position`, and the re-entry replays the same positions, so the ring-buffer writes are idempotent.
