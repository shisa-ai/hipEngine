### `FETCH_SIZE` is an L2 counter, and the arithmetic proves it

`20260928T122800` reports the prefill phase moving 95,106 MB of `FETCH_SIZE`. That
counter is not DRAM traffic, and the record already contains the disproof:

**Decode's own census reports 12,992 MB per token at 35.35 ms per token, which is
367 GB/s.** The Radeon 8060S is LPDDR5X-8000 on a 256-bit bus -- **256 GB/s peak** --
so 367 GB/s of DRAM traffic is impossible. The same 256 GB/s is what the handoff's
decode floor assumes when it calls 3255.7 MB over 35.35 ms "36.0 percent of DRAM
peak". `FETCH_SIZE` therefore counts L2-to-L1 fetches, which are served from cache at
a rate DRAM cannot reach.

**The consequence: the 95 GB prefill figure is a cache-pressure measure, not a
traffic floor, and reading it as 138.7 GB/s against 256 GB/s peak -- 54 percent -- is
impossible.** The kernel-to-kernel ordering it produces is still meaningful, because
the same counter is applied to every kernel. The bandwidth interpretation is not.

### The actual floor

At 512 prompt tokens with top-8 routing there are 4096 expert-row assignments across
128 experts, so **every expert is touched** and the expert weight set is read once.
The minimum DRAM traffic for the prefill is therefore the whole model, once:

```
15.83 GB / 0.6858 s  =  23.1 GB/s  =  9.0 percent of the 256 GB/s peak
```

llama.cpp at 1012.98 tok/s does the same work in 563 ms, which is 28.1 GB/s. **Both
engines are an order of magnitude below DRAM peak, so the prefill gap is not a
bandwidth gap and cannot be closed by moving fewer bytes.** It is a compute or latency
efficiency gap: the expert MMQ kernels at 512 rows run at a few percent of the
integer-dot-product peak, and llama.cpp does the same arithmetic 1.36x faster.

This also means the `FETCH_SIZE` amplification -- the two expert kernels reporting
66.6 GB of fetches against a 13.2 GB weight set, 3.8x and 7.4x -- is **L2-to-L1
re-reads served by cache, not DRAM re-reads.** Whether they cost anything is a
question about L2 bandwidth and latency, not about DRAM.
