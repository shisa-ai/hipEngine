# Add exact device-position Qwen4Exp QSA append

## Summary

Added the first exact dynamic-control primitive for P8: c1 QSA raw index-key
append now has a registered sibling that reads request-owned device position.
Normal scalar/row append remains the strict fallback/default.

## Changes

- Added raw-pointer device-position paged scatter and wrapper/registry entry.
- Added `Qwen4ExpQSAIndexDeviceState.append_device_position()`; it deliberately
  leaves the host count mirror to the graph owner.
- Added default-false dense-QSA graph controls for device position and a fixed
  context bucket. Normal runtime behavior is unchanged.
- Updated the kernel catalog and RED/registry tests.
