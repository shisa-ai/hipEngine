# Remove unused PARO prompt suffix work and parallelize exact attention scores

## Summary

The public profile in `677eb0c92` identifies serial provider attention as the
largest long-context cost. Remove unused non-final prompt suffixes and evaluate
an exact parallel-score attention schedule; keep target arithmetic, rollback,
default speculative depth and numerical policy unchanged.

## Changes

- Add a prompt-specific KV append sharing the existing full-step prefix through
  completed K/V writes. Non-final prompt rows stop there. The true final row
  still produces the live hidden and full-vocabulary device candidate.
- Do not redefine `need_result=False`: accepted-token repair must still produce
  hidden consumed by a following previous-hidden advance.
- Add registered three-pass `f32_bf16_staged` attention with caller-owned FP32
  score workspace: independent per-KV score reductions, serial increasing-KV
  softmax, increasing-KV value sums. Preserve the parent as strict reference and
  short-context schedule. Use staged attention from context 128; this crossover
  is scheduling-only and is covered on both sides and at unrelated lengths.
- Independently reviewed prompt prefix and attention bodies. Prompt review found
  no runtime defect but requested borrowed-head and unsynchronized coverage;
  both were added. Attention review found integer/extent validation, workspace
  alias/lifetime and degenerate-input gaps; fixes and tests are complete.
- No external kernel was ported. No feature flag was added.
- Audit classified an existing output-span comment as a runtime flag branch.
  Recorded `NOT-DEBT/keep`: slotted diagnostic storage is not a new switch, and
  the shared optional span list is already documented as default-off because
  its per-cycle growth is audit evidence rather than production telemetry.
