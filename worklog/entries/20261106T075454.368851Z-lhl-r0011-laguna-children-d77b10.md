# Implement request-private bounded Laguna DFlash children

## Summary

Laguna DFlash exposes a request-private bounded child through the production
Laguna generator and submit/poll adapter. Each advance prefills one prompt token
or runs one B4 speculative cycle. No model work happens during child admission.

## Changes

- Each child owns and closes its target session, drafter and cycle independently.
- Preserve the direct blocking/streaming provider API and shared direct owner.
- Correct the provider's prompt preparation to unpack the production target's
  `(prompt_ids, timing)` return; its old fake target hid this contract mismatch.
- Exercise the actual provider through EngineService with separate sessions for
  batched requests, blocking/stream agreement and driver-thread session creation.
- Cover partial setup/prefill failures and cancellation without resetting a peer.
- No RED-first run: implementation preceded the targeted tests during the
  interface migration. Tests explicitly cover bounded work and private ownership;
  this does not establish a pre-change regression reproduction.
