# Screen Qwen3.8 exact Q6 root top-1 decode

## Summary

Reject serial-AR routing to the existing exact producer-owned planar-Q6 root
top-1 route. On the 994.629-MiB actual Qwen3.8 `output.weight`, producer tile
maxima plus the tile reducer change **4.591176 -> 4.603906 ms (0.99723x,
4/15 wins)** versus the retained full-logit producer plus generic argmax. The
candidate preserves every FP32 logit and winner bit but projects a **0.0158%**
selected-kernel-wall regression. Production remains unchanged.

## Changes

- Screened the already-admitted planar-qmicro Q6T16 top-1 stage-1 and tile
  stage-2 kernels; no device body, registry, runtime route, payload, or tracked
  source was changed.
- Compared the exact candidate both to the current 128-thread generic argmax
  path and to the existing full-logit control-publish path. The candidate keeps
  the same 1,042,944,000-byte sole root payload and complete FP32 logits but
  would require 124,184 bytes of tile-value/index workspace if promoted.
- Added durable negative evidence at
  `benchmarks/results/2026-08-16-gfx1151-qwen38-27b-q6-root-top1-rejected.json`.

## Validation

- Actual immutable `output.weight` is Q6_K K5,120/N248,320, with both source
  and resident payload exactly **1,042,944,000 bytes / 994.629 MiB**. The leaf
  used five warmups, 15 counterbalanced samples, and burst four under cached
  gfx1151 builds.
- Current full-logit plus generic argmax: **4.591176 ms** median. Equivalent
  full-logit control publication: **4.593898 ms**. Producer tile maxima plus
  tile stage-2: **4.603906 ms**, losing **11/15** pairs against current and
  **9/15** against control publication.
- All three paths produce bit-identical FP32 logits (SHA-256
  `532ecbd5...be55d1`), top-1 ID **163553**, and selected FP32 value. Outputs
  are finite; max absolute error and KL are zero; tracked ownership returns
  **0 -> 0 bytes**.
- Raw leaf:
  `/tmp/qwen38-task22-q6-root-top1/leaf.json` (SHA-256
  `71c7366b...3d895d`, 3,463 bytes). Harness:
  `/tmp/qwen38-task22-q6-root-top1-leaf.py` (SHA-256
  `858e8efe...a95d4`, 15,881 bytes).
