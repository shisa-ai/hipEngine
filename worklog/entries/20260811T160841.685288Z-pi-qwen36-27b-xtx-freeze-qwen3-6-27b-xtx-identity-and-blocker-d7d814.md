# Freeze Qwen3.6-27B XTX identity and blocker

## Summary

Froze the physical RX 7900 XTX identity and preserved the package-default
Qwen3.6-27B Q4_K_M admission blocker before changing residency. HIP GPU1,
Vulkan1, and sysfs `card0` all resolve to PCI `0000:10:00.0`, unique ID
`0xcc4d02090dc9c3ff`, and 25,753,026,560 bytes VRAM. Idle use was 64,950,272
bytes with no material competing GPU process.

Both AR and dense-MTP entry probes fail during target weight materialization at
`blk.49.ffn_gate.weight.pack8.qweight`. The failed 44,564,480-byte upload starts
after 24,462,066,048 tracked bytes / 1,336 live allocations; sysfs reaches
25,741,647,872 bytes in the higher MTP sample. Exception cleanup returns tracked
ownership to exactly zero and sysfs returns to 64,913,408 bytes after two
seconds. No partial-model performance number was produced.
