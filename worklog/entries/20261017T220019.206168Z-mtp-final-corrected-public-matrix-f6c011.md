# Record the corrected four-model public MTP matrix

## Summary

The recorded public acceptance matrix is complete for Qwen3.8 Q4_K_S/Q4_K_M,
Qwen3.6 MoE Q4_K_M, and Gemma4 Q4_K_XL. It covers explicit and alias routing,
AR/MTP generation, sampled repeatability, thinking controls, minimum output,
