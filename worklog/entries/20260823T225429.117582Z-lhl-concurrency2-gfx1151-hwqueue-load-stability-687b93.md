# Complete gfx1151 queue load stability matrix

## Summary

Completed the gfx1151 Qwen3.8-27B Q4_K_S FP16-state hardware-queue
arrival/stability matrix. Five queue policies, two counterbalanced blocks, and
all nine canonical production-load workloads produce 10 children, 90 workload
executions, and 2,100 request records. Every policy passes exact generated
control/accounting, declared native routes, bounded stream queues, overload
accounting, ownership, memory recovery, final drain, and GPU/process health.
No MES lockup, timeout, or surviving KFD process occurred.

There is no generic queue performance winner. Normalized exact throughput versus
queue2 is q1/q4/q8/unset -0.57%/+0.47%/-0.67%/-0.09% across 18 matched
workload-block rows. All policies are SLO-clean for static c1/c8 and idle
recovery; ragged, fixed/Poisson, cancellation, overload, and soak are
product-SLO blocked for every policy. Queue2 remains the current control without
promotion.
