# Prime MTP from completed resumable INT8 prefill hidden rows

## Summary

The public compact-INT8 server selected MTP for a 4097-token prompt but ran
zero cycles with `prompt_hidden_rows_unavailable`. Resumable layer-outer
prefill never forwarded its final hidden rows to the provider. It now carries
the sink through suspended layer segments and publishes complete final trunk
rows before sampling reuses the hidden buffers.

Developed in an isolated worktree because the prefix worker owns unrelated
changes in the shared runner. No kernel arithmetic, prefill scheduling budget,
or public storage default changes.

## Changes

- `_GGUFResumablePrefillState` owns the optional per-session hidden sinks.
  Resumable setup validates prompt extent/hidden width and threads the sink
  into the checkpoint. Continuations keep the original sink identity.
- After the final layer, consume every chunk's final trunk rows in prompt
  order and finish with the sink's request id and total extent. Intermediate
  layer boundaries publish no incomplete activations.
- The generation owner opens MTP priming once, carries it through segments,
  finishes only on model completion, and aborts priming on failure.
- Regression tests cover full-row publication and scheduler begin/carry/finish.
