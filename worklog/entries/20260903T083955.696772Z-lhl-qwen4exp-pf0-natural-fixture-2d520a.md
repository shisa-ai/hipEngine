# PF-0: natural-text route-covering fixture

## Summary

Landed the PF-0 natural-text route-covering fixture. It fixes the
`route_vacuous_for_scope` defect of the 18-prompt admission suite (11.1%
coverage, section 6.2 Rule B) while avoiding the synthetic repetition of the
canonical p512/p1024/p4096 fixture (e.g. `code-p512` holds only 104 unique
tokens in 512). The new fixture carries three contiguous natural excerpts per
canonical category (code, general_en, general_ja, mixed_ja_en); every case
clears the `rows >= 64` Q8 MMQ dispatch floor, giving 100% route-engagement
coverage. No measurement claim; this unit only creates the fixture.

## Changes

- `benchmarks/fixtures/natural_sources/` (new): exact chat-prompt body
  excerpts per case (`code-1..3.txt`, `general_en-1..3.txt`,
  `general_ja-1..3.txt`, `mixed_ja_en-1..3.txt`) plus `PROVENANCE.md`
  recording origin, license, normalization rules, and raw-source SHA-256s.
  Sources: CPython `Lib/dataclasses.py` (PSF), Project Gutenberg #205 Walden
  (public domain), Aozora Bunko card 773 『こころ』 by Natsume Sōseki (public
  domain), ruby/ruby `README.ja.md` (Ruby/BSD-2 dual).
- `scripts/build_qwen4exp_natural_ar_fixture.py` (new): renders the excerpts
  through `scripts.gguf_mtp_bench.build_chat_prompt(reasoning='off')` into the
  canonical exact-token fixture schema and writes
  `benchmarks/fixtures/qwen4exp_natural_ar_pf0.json` with per-case token IDs,
  SHA-256 hashes, unique-token ratios, and source hashes. Refuses any case
  below the 512-token floor.
- `scripts/qwen4exp_route_coverage_finding.py`: added a `--single-fixture`
  / `--single-output` mode that records coverage for one fixture without
  requiring paired gate artifacts; used to produce the PF-0 coverage
  artifact.
- `tests/test_qwen4exp_natural_ar_fixture.py` (new): validates the fixture
  (schema, categories, per-case hashes, >= 512 tokens, unique-token ratios)
  and that the coverage artifact classifies it `route_covering`. Written
  before the coverage artifact was generated so the artifact check failed
  first (RED) and passed after running the coverage script (GREEN). Skips
  cleanly when the fixture is absent on no-fixture runners.
- `benchmarks/fixtures/qwen4exp_natural_ar_pf0.json` (new): the fixture
  itself, 12 cases, 535-877 prompt tokens, unique-token ratios recorded.
- `docs/QWEN3.8-FLASH-NEXT-HALO-BOX-CAMPAIGN.md`: PF-0 row marked Done;
  status line updated.
