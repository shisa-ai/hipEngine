# Implement dynamic admission D1 static eligibility

## Summary

Implemented D1's typed static eligibility seam without changing automatic c2+
policy or arithmetic. `SpeculativeMTPStaticEligibility` distinguishes
`permanent_ar` from `speculative_capable` and carries only request-local evidence
bounds/identity, automatic eligibility, and strict fallback. It does not contain
actual resident `C_due` or selected cycle K.

Two independent frontend-C1 eligible children may now group to queue C2 K0 yet
still enter ordinary EngineService/Generation-2. The actual resident `WorkItem`
remains the sole C/K owner. Plans distinguish provider-free `pure_k0` from
provider-synchronized `transitional_k0`, preserve stable reasons, and expose a
bounded recent-plan telemetry trail.

Mixed permanent-AR/spec-capable due work is also safe. If the composed runner
cannot execute `(K,0)`, the same loop records mixed transitional/pure K0,
retries only the eligible subset as one disjoint speculative frontier, and
decodes the AR subset exactly once in the same fairness tick.

## Changes

- Added exported typed static eligibility/state records to the speculative
  serving contract and included them in model-plugin plan payloads.
- Replaced the temporary singleton-only SamplingParams/GenerationRequest bool
  and GGUF request set with one typed static eligibility object/map.
- Preserved typed intent through queue K0 routing and EngineService submission;
  permanent AR continues through the plain provider-free path.
- Added `SpecK0Class` to immutable plans and telemetry and classified planner
  output as not-K0, pure K0, or transitional K0.
- Added resident recent-plan observability and disjoint mixed-intent execution
  under the existing fairness loop.
- Added RED/GREEN tests for static eligible/permanent states, queue C2 intent,
  K0 classes, mixed fallback, request propagation, and GGUF adapter ownership.
- Added provisional D1 artifact pending clean-commit reruns.

## Validation

- D0 RED failed exactly on missing `static_eligibility`; host/fake GREEN passes.
- Focused bundle: 168 tests passed across LLM, EngineService/Loop, speculative
  contracts/policy/transactions, GGUF/PARO seams, slot-local journal, and serving
  capability; six focused server routing nodes passed.
- Candidate-source public C2: two independent automatic children preserve typed
  intent into resident width2, fail closed before proposal, record two
  `transitional_k0` rows, match AR, re-engage C1 MTP afterward, and drain.
- Candidate-source mixed GPU: one spec-capable plus one permanent-AR row records
  transitional/pure K0, then executes disjoint C1 MTP and one AR decode. Both
  outputs match independent controls and final ownership is zero.
- No performance, profile, or automatic c2+ promotion claim is made.
