# Screen direct resident verifier linear state route

## Summary

Add a default-off packed-target route that reads initial Conv/GDN state directly
from the resident batch owner's canonical slot slabs. It skips only the 384-pair
resident→packed import observed at C8; captured-row kernels remain read-only on
the initial slab, and the existing GPU-selected row commit remains the exact
post-accept owner.

## Changes

- Add `HIPENGINE_GGUF_VERIFY_DIRECT_RESIDENT_LINEAR_STATE=1` as a default-off
  candidate for packed target verification.
- Reuse the existing generic resident-slot resolver with an explicit
  target-candidate allowance; packed AR capability ownership remains unchanged.
- Remap packed verifier `state_indices` to resident slot indices, skip only
  initial linear-state copies, and bind linear decode scratch to the resident
  owner. Packed KV and every selected-row commit/fallback stay unchanged.
- Add focused policy, slot-map, and no-materialization tests and a removal
  trigger in `docs/REFACTOR.md`.
