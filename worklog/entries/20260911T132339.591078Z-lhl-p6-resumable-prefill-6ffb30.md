# P6 resumable layer-outer INT8 prefill checkpoint

## Summary

Roadmap P6 / F5, reviewer packet items 1 and 2. The compact INT8
(`kv_attention_source == "int8_direct"`) prefill path did no model work on any
scheduler chunk except the last: `_prefill_native_chunk` called
`_disable_incremental_prefill`, which only advanced Python bookkeeping until
`final_chunk`, then ran the whole prompt in one `_prefill_native_row` call. An
internal slab is not a service yield unless control returns to the service
driver, so a long prompt blocked admission, cancellation, and interleaved
decode for its whole duration.

The layer-outer packed executor already makes every layer boundary a consistent
state (all rounds of a layer complete, that layer's K/V in the direct INT8
store, the shared BF16 oracle transient). That makes the cross-poll checkpoint
two fields: the next layer index and the ping-pong parity (`next_layer % 2`).
This unit adds that checkpoint and a bounded per-poll layer segment, so the
int8_direct prefill now does real GPU work on every scheduler chunk and returns
control between them.

Key design note (measured against the scheduler, not assumed): the layer-outer
executor needs the prompt's whole round plan, and the scheduler owns chunk
boundaries (`take_prefill` advances its own cursor), so the resumable entry
plans the rounds itself with `_plan_packed_ar_prefill_chunks` over the session
bulk-prefill row capacity - the same plan the one-shot packed entry builds -
rather than depending on the scheduler's chunk sizes. The generator spreads the
layers over the polls it expects to have left and passes `layer_budget=None` on
the final chunk so the remainder always completes there.

## Changes

- `hipengine/runtime/qwen35_gguf_runner.py`
  - `_GGUFResumablePrefillState`: cross-poll checkpoint (prompts, sessions,
    round plan, packed workspace, layer types, `next_layer`, sampling flags).
    `phase` derives the ping-pong parity from `next_layer`.
  - `_prefill_batch_native_layer_outer` takes `resume_state` / `layer_budget`
    and delegates to the new segment executor. The setup (round plan, packed
    workspace, initial sync, embeddings) runs only on the first segment.
  - `_prefill_batch_native_layer_outer_segment`: runs `[layer_start, layer_end)`
    of the layer loop, returns the advanced checkpoint while layers remain, and
    runs the sampling tail plus packed-decode scatter only on the segment that
    reaches the last layer. The layer loop was moved here verbatim from the
    one-shot executor so both share one code path.
  - `prefill_batch_native_layer_outer_resumable`: guarded serving entry. Plans
    the rounds, invalidates live packed decode graphs, flushes deferred packed
    decode state, and releases the transient BF16 oracle on every segment
    boundary via the extracted `_release_int8_prefill_oracles_after_call`.
- `hipengine/generation/qwen35_gguf.py`
  - `_prefill_resumable_int8_chunk`: scheduler-facing helper. Computes the
    layer budget from the remaining tokens, the current chunk size, and the
    remaining layers; stores the checkpoint on the row; finishes the row
    through `_finish_native_prefill` on the completing segment; fails closed to
    the existing full-prompt route when the executor declines.
  - `_GGUFResidentLoopRow.resumable_prefill` plus a `_RESUMABLE_PREFILL_DONE`
    marker, so a row whose first token already emitted no-ops on the
    scheduler's remaining bookkeeping chunks instead of tripping the
    "prefilled more than once" guard.
- `tests/test_gguf_resumable_layer_outer_prefill.py` (new): 13 CPU tests over a
  faked device surface.

## Validation

- `python -m pytest tests/test_gguf_resumable_layer_outer_prefill.py -q` - 13
  passed. Covers: a budgeted segment runs exactly that many layers and returns
  a checkpoint; a resume continues from `next_layer` without re-running the
  initial sync or the embedding launches; the tail and packed-decode scatter run
  only on the completing segment; a budget beyond the remaining layers does not
  overrun the model; the public entry releases the oracle on every segment and
  after a mid-segment failure; the entry declines a single-round prompt; the
  generator budget spreads eight layers over four polls and finishes on the
  final chunk; the wiring declines when the layer-outer flag is off, on prefix
  reuse, and on executor decline; a finished row ignores later chunks.
- `python -m pytest tests/test_gguf_resumable_layer_outer_prefill.py
  tests/test_gguf_packed_layer_outer_prefill.py
  tests/test_gguf_int8_prefill_oracle_per_layer.py
  tests/test_gguf_int8_prefill_direct.py
  tests/test_gguf_packed_workspace_stability.py tests/test_server_api.py -q` -
  all passed (the refactored one-shot layer-outer path is unchanged).

  suspended state. The hidden planes are dedicated session buffers, but the
  packed verify workspace (linear conv/recurrent state) is shared with packed

  the suspended-prefill owner must be accounted in the P2 allocation model.
