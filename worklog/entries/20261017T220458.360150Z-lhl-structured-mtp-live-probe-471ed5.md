unit-tested; the first GPU execution is running and is not qualification evidence
until its saved responses have been reviewed. Task 19 remains open.

## Changes

- `scripts/qwen4exp_controlled_mtp_http_gate.py` tests JSON Schema, required and
  automatic weather calls, direct schema answers with tools available, and hard
  thinking with schema. Each has both speculative spellings, greedy/sampled
  decoding, logprobs on/off and blocking/SSE requests.
- Require actual MTP counters, execution path and sampling algorithm, canonical
  token accounting, schema content, tool name/arguments and finish reasons.
  Reassemble fragmented tool calls and reasoning. Compare blocking/SSE output,
  IDs, selected probabilities and usage without comparing random tool-call IDs.
- Non-tool logprob cases validate visible UTF-8 bytes and finite probabilities.
  Tool cases validate parsed calls, not tool-logprob alignment; that limitation
  must not be reported as logprob qualification. Reasoning presence is checked,
  but this initial probe does not yet check the hard-cap counter itself.
- Write full responses incrementally with source commit and probe hash. Support
  failed-only replay and exact case selection. A partial replay is not a fresh
  complete-matrix pass. Constant schema content is a functional grammar test,
  not model task quality or a performance/acceptance optimization.
