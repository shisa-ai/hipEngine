# UD-U1 commit 2: role-manifest fingerprints, artifact presets, certified operation coverage, aggregating preflight

## Summary

New cold-path CPU module `hipengine/loading/qwen35_gguf_admission.py`
(UD-U1 of `docs/UD-QUANTS.md`): admission binds to the actual
artifact+role/shape/type manifest, not the `general.file_type` stamp or a
dtype histogram, and preflights every requested operation over every planned
slot with aggregated refusals. Pure policy metadata — no device allocation, no
backend import, no kernel launch, no torch, no backend/quant branches in
engine or dispatch code; per-tensor kernel quant keys stay `gguf_*` and the
preset key is a model/session admission identity, not a fifth registry axis.

## Changes

- `Qwen35GGUFRoleManifest` + `build_qwen35_gguf_role_manifest`: canonical
  `(role, layer scope, shape, GGML type)` records over the AR map plus the
  trailing NextN block map (structural `strict=False` for UD fingerprints);
  canonical `role\tscope\tshape\ttype` sha256 fingerprint.
- Pinned UD preset identities (computed from the real artifacts; payload
  sha256 identities in `docs/UD-QUANTS-U0-IDENTITY.json`):
  - UD K_M → `gguf_ud_q4_k_m`, fingerprint
    `5535c5bd7a3e84c6381de70bf8ca5c6f4bcd804dabf8435b85c8418038c8619f`
  - UD K_S → `gguf_ud_q4_k_s`, fingerprint
    `91130e1698bb7fc24c89f94e8b1043dd788769682b56c6514d70b6d2cdea068c`
  - Both AR-only (`("ar",)`); unknown manifests resolve to None and stay on
    the plain stamp-based lane unchanged.
- Certified cold-path coverage records `CERTIFIED_OPERATION_COVERAGE` built
  from the plain-lane consumers: operations `ar_decode_c1`, `ar_decode_rows`,
  `ar_decode_native_rows`, `ar_prefill`, `embedding_lookup`,
  `lm_head_f32_logits`, `mtp_nextn_draft`; role classes projection /
  recurrent_alpha_beta / norm / gdn_scalar / conv1d / moe_router /
  moe_experts / token_embedding / lm_head; each record names rows scope,
  input/output dtype, the four-axis `(layer, quant, variant)` consumer family,
  and a strict fallback.
- `preflight_qwen35_gguf_artifact`: plans every slot (capturing planner
  refusals instead of raising on the first one), qualifies residents per
  requested operation, aggregates every unsupported slot/mode into
  `Qwen35GGUFAdmissionReport` (with `Qwen35GGUFAdmissionError(ValueError)`);
  unknown requested operations fail closed; `mtp_nextn_draft` is scope-refused
  without an explicitly certified MTP scope; `decode_repack=None` resolves
  through the shared loader env gate.
- Role-specific hazard coverage pinned in tests against the real artifacts:
  raw Q8_0 alpha/beta (UD), sole-T16 alpha/beta with no raw allocation, and
  dense-F32 alpha/beta (plain 27B) all refuse `ar_decode_native_rows` — only a
  dense-BF16 resident is a valid BF16-pointer owner for
  `dense_gemv_out_bf16`; dense-BF16 embeddings have deliberately NO certified
  record (the consumer drops rows and would silently singleton a multirow
  gather); `test_unknown_requested_operations_fail_closed`;
  `test_ud_quant_key_does_not_inherit_execution_profiles` (no automatic
  profile inheritance for the UD preset keys).
