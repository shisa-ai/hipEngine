# Retire Maple grouped prefill rollback

## Summary

Remove R0372's grouped-prefill opt-out, conditional metadata builds and runtime
prefill gather branches. Keep the same grouped arithmetic enabled by default;
preserve gather primitives for batched decode and low-level numerical oracles.

## Changes

- The old removal note waited on a target and later campaign, not an observed
  capability failure. No script needs a runtime gather comparison; benchmark
  callers only recorded the env setting. Remove those inert metadata fields and
  the env reference with the selector.
- RED: five host checks fail under the old `=0` setting: three native-prefill
  shapes reach gather instead of grouped kernels, and both runner loaders skip
  the metadata library. Tests bind metadata pointers, chunk row counts, original
  output lanes and grouped call order at 1, 7 and 257 rows.
- Native prefill now always builds stable expert metadata and uses grouped dual
  gate/up and down kernels. Batched decode still uses registered row/gather
  primitives; no kernel, registry or numerical operation changes.
- Remove the closed R0372 ledger section rather than creating another deferred
  decision. Its original timing/target history remains in the immutable sweep
  source and historical artifacts; this unit makes no performance claim.
