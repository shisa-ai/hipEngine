# R0195 committed device-state parity gate

## Summary

Extended the gfx1100 R0195 physical-target device gate from exact token-ID parity to
exact **committed device-state** parity. On the nextn-bearing Qwen3.8-27B-Q4_K_M
artifact, the padded production route and the unpadded strict route now provably
commit bit-identical conv/recurrent state, not just identical emitted tokens.

The key localization: the packed `verify_state`
(`engine._text_generator._runner._resident_batch_owner._packed_ws_state.verify_state`,
a `_GGUFPackedTargetState`) is a **verification scratch** holding the full padded
physical group including unaccepted candidate rows. The accept/commit path
(`prepare_external_verify_state_commit`, `qwen35_gguf_runner.py`) copies only the
selected rows into the session's canonical scratch
(`_resident_state_storage.canonical.scratch`, a `_FullStackScratch`). That committed
scratch is the exactness target.

## Changes

- `tests/test_live_gguf_r0195_physical_target.py`: added `_find_committed_state()`
  (navigates to the batch owner's `canonical.scratch`, with the lazy `_state_storage()`
  fallback) and `_hash_committed_state()` (SHA-256 of raw conv/recurrent bytes for every
  linear-attention layer; dtype-agnostic). `_worker` now emits `committed_state_hashes`.
  The exact-output test (parametrized C1/C2) asserts both `generated_token_ids` and
  `committed_state_hashes` are equal between production and strict. Module docstring
  updated to state the committed-state contract.

## Validation

Measured on gfx1100 (W7900), subprocess-per-case, model
`/models/gguf/Qwen3.8-27B-Q4_K_M.gguf`:

- Attribution probe (production C2 vs strict C2, 4 prompts): `token_ids` match;
  `verify_state` realized slots 0/1 conv+recurrent differ on all 48 linear layers
  (unused slots 2/3 match) — expected scratch content, not a defect.
- Committed-state probe: `owner.canonical.scratch` and every per-session
  `canonical.scratch` conv+recurrent **match on all 48 layers** (0 mismatches;
  ~151 MiB readback per holder). Confirms the padded accept/commit path is exact.
- Gate: `uv run pytest tests/test_live_gguf_r0195_physical_target.py -v` →
  **4 passed in 432.55s** (C1 exact+state, C2 exact+state, C4 named capability miss,
  wider-group 8-request capacity).
