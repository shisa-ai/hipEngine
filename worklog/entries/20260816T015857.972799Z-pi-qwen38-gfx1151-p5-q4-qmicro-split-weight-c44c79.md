# Screen Qwen3.8 Q4 qmicro split-weight decode

## Summary

Reject qmicro Q4T16 payload compaction for the dominant Qwen3.8 serial-c1
split-weight gate/up family. Although the candidate reduces resident Q4 bytes
**2.70%** and preserves BF16 bits, cooperative compressed-metadata expansion
regresses the three-layer family **1.423347 -> 1.486795 ms (0.95733x, 0/45
wins)** and projects **-21.991 ms / -1.7014%** selected 4K kernel wall.

## Changes

- Added a transient qmicro consumer that preserved the retained 128-thread
  split-weight K ownership, FMA order, wave reduction, BF16 round trip, and SiLU
  boundary while expanding each plane's 3-byte metadata records once per K256
  block into the existing 512-byte LDS class.
- Compared standard-Q4T16 and qmicro payloads on actual layer 0/8/63 gate/up
  pairs. Each raw source pair is **95.625 MiB**; resident bytes fall
  **103,055,360 -> 100,270,080** per pair.
- Removed the transient kernel, wrapper, and RED/GREEN fixture after rejection;
  no runtime selector, resident policy, or production source changed.
- Preserved compact evidence at
  `benchmarks/results/2026-08-16-gfx1151-qwen38-27b-q4-qmicro-split-weight-rejected.json`.

## Validation

- RED: focused test collection failed at the intentionally missing qmicro
  split-weight wrapper.
- GREEN: the new synthetic fixture passed **1/1** with BF16-bit identity against
  the retained standard-Q4T16 split-weight owner.
- The predeclared actual-weight leaf used four warmups, 15 counterbalanced pairs
  per layer, burst four, cached gfx1151 binaries, and more than 64 MiB between
  layout repeats. Layer speedups are **0.95581x/0.95761x/0.95856x**, all with
  **0/15 wins**.
- Actual outputs are BF16-bit exact (zero ULP, KL 0, 3/3 top-1), finite, and
  tracked ownership returns exactly **0 -> 0 bytes**. Raw leaf SHA-256 is
  `c364cbd81864c301ba01d9c6944c012ebd3ee86d9f30cd3d09b5a8b5317f24e5`.
- A scoped reverse-diff check confirms all transient production/test source is
  byte-identical to committed HEAD after teardown.

## Next

- Retain the standard-Q4T16 split-weight owner. Q4 payload compaction cannot
  close the remaining AR gap without a dataflow that avoids per-block metadata
  expansion; rerank a materially different operation-complete boundary.
