# Interleave Inkling NVFP4 weights and widened scales

## Summary

Keep the separately stored widened scales. Interleaving each BF16 scale with its eight packed NVFP4 weight bytes did not justify the added model-load time.

## Changes

- The trial used the same device bytes and the same projection arithmetic. The branch does not include the interleaved layout.
