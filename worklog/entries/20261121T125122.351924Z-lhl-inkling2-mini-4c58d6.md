# Keep gated Inkling attention output on device

## Summary

For single-row target attention, keep the output on the device through gate multiplication, output projection, and short convolution. Download the result once.

## Changes

- Stage the existing host-computed sigmoid gain with the attention input. Multiply in FP32 and reuse the selected projection, convolution, and cache kernels. Packed verification rows still use the separate attention exchange.
- Verify bitwise gate multiplication on both the tiled and split paths. Projection scratch remains locked through the download.
