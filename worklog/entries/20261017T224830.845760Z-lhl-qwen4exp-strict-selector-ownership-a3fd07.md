# Bind strict composition selectors instead of preserving caller overrides

## Summary

Strict and quarantined fallback binding now disable all eight F16-composition
selectors, even if a caller enabled them before binding. This aligns those route
switches with the strict manifest; it does not introduce new arithmetic.

## Changes

- Replace publication-history tracking with unconditional profile ownership in
  `_bind_f16_routes`. Production UD still enables the same selectors.
- Use the existing warning/error conflict policy. A/B harnesses must set overrides
  after binding and record a modified candidate, not claim the original manifest
  qualifies arbitrary overrides.
- Replace the test that required the unsafe behavior with parameterized strict UD
  and explicit-production Q4_K_M fallback tests across all eight selectors.
- Remove the redundant process-global set `_f16_routes_published`.
