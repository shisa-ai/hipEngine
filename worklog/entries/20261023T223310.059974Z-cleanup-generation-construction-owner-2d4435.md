# Own unpublished generation resources through construction

## Summary

Added explicit temporary ownership for generation construction. Factory results stay reachable until a successful handoff to the driver, service and public LLM cache. Failed configuration, preparation, attachment or service probing closes the acquired owners without replacing the original exception.

## Changes

- Add `generation/construction.py:ConstructionOwner`, shared by LLM setup, runner preparation and service startup.
- Replace the provider-only special-case unwind with the same ownership contract; successful attachment transfers ownership to the target.
- Close native runners when driver preparation fails, without calling `close()` on a partial driver. Preserve the original configuration order and ResidentPreparationError boundary.
- Join an unpublished service after a startup timeout and make completed driver close idempotent, so outer unwinding does not release it twice.
- Add public-construction regression tests with synthetic registry generators, including context/width handoff, retry, attachment, prepare/capability failure, failing cleanup and startup timeout.
