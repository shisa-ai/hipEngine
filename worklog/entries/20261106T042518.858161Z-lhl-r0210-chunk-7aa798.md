# Bind single-chunk packed workspace leases with local offsets

## Summary

Packed workspaces can now bind a lease wholly inside an appended chunk without
allocating duplicate private planes. Pool authority retains global lease pages;
packed page tables and copy segments use chunk-local offsets with matching bases.

## Changes

- Pool resolves one-chunk backing and local offsets; mixed chunks return no view.
- Packed allocation consumes this view before falling back to root-only legacy
  adapters. Existing mixed-chunk private path and release of growth leases remain.
- No kernel arithmetic or request admission changes.

## Validation

- 190 pool/workspace/layout/growth/owner tests pass, `/tmp/r0210-chunk.log`.
- Explicit appended-chunk fixture binds nonzero local offsets and verifies a copy
  crossing a page boundary with no private malloc. Pool fixture checks original
  and appended chunks, mixed-chunk refusal and empty input error.
- Mechanical addressing adapter followed by regression fixtures, not RED-first.
- Public interruption/refill/completed-stream regression and balanced close pass,
  `/tmp/r0210-chunk-public.log`; audit passes, `/tmp/r0210-chunk-audit.log`.
  Fixtures own new appended-chunk branch evidence, not this common public route.

## Next

- R0210 remains open for no-pool allocation owners and mixed-chunk page-pointer
  consumers. Preserve fallback while implementing those independent dependencies.
