# Measure Qwen3.8 C1 acceptance by category and draft position

## Summary

Added denominator-explicit acceptance rollups to the canonical GGUF MTP
C1-C8 server benchmark so the Qwen3.8 C1 acceptance gap can be measured by
category and draft position instead of only as one aggregate. The artifact now
separates raw accepted/proposed-token acceptance, unconditional position
survival, and acceptance conditional on all preceding draft positions.

## Changes

- Added validated extraction of request-local
  `specdec2_mtp2_candidate_counts` / `specdec2_mtp2_accepted_counts` from the
  retained resident-owner rows.
- Added all/train/heldout, per-category, and per-width rollups with explicit
  denominator strings.
- Advanced `gguf_mtp_c1c8_server_bench` output schema from 1 to 2 and attached
  the acceptance block without changing the measured serving path.
- Added synthetic tests for aggregate, scope, category, variable-depth, and
  malformed-count behavior.
