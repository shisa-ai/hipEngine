# Execute bounded native serving prompt chunks

## Summary

Native serving now executes the prompt rows in each scheduler prefill work item.
Previously it only counted partial chunks, then replayed the entire prompt in
one final call. Partial requests can now be cancelled after real prompt work
and the released owner can be reset for a subsequent request.

## Changes

- Call the existing `prefill_append` primitive per scheduler work item. Keep
  compact outputs and grammar logits; expose `next_result` only after the full
  prompt is ready. Advance the host prompt counter after successful model work.
- Add CPU tests for exact incremental positions/input history and actual
  submit/poll cancellation after the first chunk, followed by clean recovery.
- Update the c2 isolation harness to compare identical chunk schedules between
  isolated and interleaved requests. Its prior expectation of no model work for
  partial cancellation described the bug, not cooperative prefill. The trace
  gate now requires those real partial rows and rejects missing cancellation
  work; the numerical gate for different chunk schedules remains separate.
- Update affected fake runners and the grammar test's prefill interception.
