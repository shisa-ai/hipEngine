# Surya full-page OCR output quality gate: labels and bboxes vs drawn geometry

## Summary

Every Surya GPU gate so far asserted that lanes *agree* (GPU ids == CPU
reference ids == torch ids). None asserted the output is the right answer for
the page that was drawn. For a full-size page the decoded text is complete,
valid layout JSON, so that check is available and cheap.

Added assertions to `test_gpu_full_page_layout_matches_oracle`: after the
existing parity check, parse the GPU-decoded text and verify it describes the
geometry `_make_synthetic_page_full` actually renders.

The output being checked:

```
[{"label": "Section-Header", "bbox": "54 50 389 94", "count": 20},
 {"label": "Text",           "bbox": "54 134 699 261", "count": 240},
 {"label": "Text",           "bbox": "54 300 651 393", "count": 160},
 {"label": "Caption",        "bbox": "54 458 369 485", "count": 30},
 {"label": "Table",          "bbox": "71 500 370 610", "count": 70}]
```

against a page with a 40 pt heading at (60, 50), a rule at y=105, prose from
y=140, a "Table 1: Regional breakdown" caption at y=458 and four table rows
from y=498. The header box (y 50..94) and caption/table boxes line up with the
drawn elements.

## Changes

- `tests/test_surya_gpu.py::test_gpu_full_page_layout_matches_oracle`: after the
  ID-parity assertion, parse `tokenizer.decode(generated)` and assert
  - it is a non-empty JSON list;
  - every record has `label`/`bbox`/`count` and an in-range, ordered bbox;
  - the label sequence is exactly `Section-Header, Text, Text, Caption, Table`;
  - the header box top/bottom match the drawn heading (50 / 94, ±12 / ±15);
  - the caption top is 440..480 and the table top is not above the caption.
- `docs/MODEL-SURYA.md`: new status row for the quality check and a paragraph
  in the correctness-gates section.

The assertions are deliberately structural plus a few geometry correspondences,
not exact-bbox equality: the point is to catch a wrong or malformed answer, not
to pin the model's pixel rounding.

## Validation

- The gate passes on gfx1151.
- Liveness checked by temporarily asserting a wrong final label
  (`... "Caption", "WRONG"`): fails with
  `AssertionError: unexpected layout labels: ['Section-Header', 'Text', 'Text', 'Caption', 'Table']`,
  then restored.
- `HIPENGINE_HIP_ARCH=gfx1151 python3 -m pytest` on the eight Surya modules
  (model contract, oracle fixtures, text decoder, vision, e2e, public API,
  generation contract, GPU) → 91 passed.
