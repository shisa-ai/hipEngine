# Reject packed-nibble Q4 register cache and volatile metadata

## Summary

Test ten-word packed-nibble Q4 cache after full-float cache loss. Fully unrolled
consumption allocates256 VGPR and loses0.404x. Trace-directed volatile metadata
revision spills1208 bytes and loses0.136x. Both exact; remove all candidate code.

## Changes

- Pack eight nibbles per thread/K-block into uint32, ten words for K2560.
  Preserve original scale*q-min and per-output arithmetic. Non-K2560 falls back.
- Try volatile metadata only after the256-VGPR trace disproves source-level
  cache-size assumptions. It worsens code generation; removed.
- Record bounded recipes, raw hashes, actual-weight/captured-count timings and
  profiler evidence; campaign/rollups updated.
