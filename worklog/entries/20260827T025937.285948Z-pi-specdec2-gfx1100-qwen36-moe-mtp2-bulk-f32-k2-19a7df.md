# Compose fast bulk K2 with strict K1

## Summary

Composed the first 35B target arithmetic candidate that is both fast in live
feedback and numerically plausible across every required shape: bulk N2 graph
with F32 residual + post-norm for K2, and the incumbent BF16 bulk N2 graph for
K1. The selection is candidate-depth-only and applies uniformly to all
requests. Automatic remains K0 pending the clean binding packet.

## Changes

- Production profile binder enables `HIPENGINE_GGUF_VERIFY_F32_RESIDUAL=1` and
  `HIPENGINE_GGUF_VERIFY_F32_POST_NORM=1`; strict disables both.
- Production graph policy identity now names bulk-F32 K2 plus strict K1.
- Native complete cycle temporarily disables/restores both F32 flags around K1
  capture/launch, including exception-safe restoration. K1/K2 graph caches are
  already distinct by row shape.
- Quality harness mirrors the exact selected arithmetic and graph/eager route.
- Removed exploratory K2-only/AR-tail and serial-K1 surfaces from the selected
  policy; terminal K1 remains bounded zero-accept when one output remains.
- Updated refactor debt: this narrow candidate must become a typed registered
  variant or be removed after qualification.

## Validation

- K2-only native quality narrowly fails `general_ja` mean (`0.001054`) despite
  100% top-1; not retained.
- Native F32 residual+post-norm passes quality but performance screen is only
  `1.0133x`; rejected.
- Fast bulk prefix-4/8 candidates fail quality; rejected.
- Fast bulk full residual+post-norm K2 screen passes every category and K2
  shape: 255 rows, mean/p95/p99/max KL approximately
  `0.000468/0.001902/0.010140/0.016425`, top-1 `99.608%`.
- All-F32 K1 fails mean KL (`0.001304`), while incumbent BF16 K1 previously
  passes; this motivates depth composition rather than a tolerance change.
- Ten sequential live prompts with homogeneous bulk graph and depth-specific
  K1 arithmetic complete all 24 outputs without invalid tokens or fallback.
- Focused native-cycle/adapter/profile/quality tests -> 54 passed; compileall,
  Ruff, worklog, and diff checks pass.
