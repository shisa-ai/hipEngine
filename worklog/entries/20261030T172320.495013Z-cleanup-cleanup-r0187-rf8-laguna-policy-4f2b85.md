# Move gfx1151 Laguna policy declarations out of backend registration

## Summary

RF-8 first move-only boundary: the 144 immutable `LAGUNA_*` capability/policy
declarations moved from `hipengine/kernels/hip_gfx1151/__init__.py` into the
new owning module `hipengine/kernels/hip_gfx1151/policy_laguna.py`. Backend
registration, wrapper functions, kernel bodies, registry implementation,
`hipengine/kernels/policy.py` geometry types, and every declaration value are
unchanged. The package keeps all historical attribute paths through explicit
compatibility exports, not a whole-module proxy.

## Changes

- Added `hipengine/kernels/hip_gfx1151/policy_laguna.py` (735 lines): all 144
  `LAGUNA_*` declarations with their provenance comments and an `__all__`.
  The module imports no kernels, touches no registry, and selects no variant.
- Removed those declarations from `hipengine/kernels/hip_gfx1151/__init__.py`
  (4130 -> 3717 lines). The moved block was self-contained: no Laguna
  declaration referenced a non-Laguna module-level name, and no function,
  wrapper, or registration path referenced a Laguna declaration.
- Added a 158-line explicit compatibility block that re-binds every moved name
  as `NAME = _policy_laguna.NAME`. The removal condition is documented at the
  block: delete it once no caller imports these names from the package and the
  gfx1100/gfx1151 capability-ledger check reads assigned names from the owning
  policy modules. The module-level assignments also keep
  `test_gfx1151_capability_ledger_covers_gfx1100_only_live_reads` stable while
  it derives the gfx1151 assigned-name set from this initializer.
- Preserved the package's existing `__all__` membership exactly. Fifteen Laguna
  declarations were not listed there before the move and are still not listed;
  no public star-import surface was added or removed.
- Added `tests/test_unit_gfx1151_policy_laguna_boundary.py`: owning-module
  inventory/data contract, package identity re-exports, replacement stability,
  and peer-backend isolation.
