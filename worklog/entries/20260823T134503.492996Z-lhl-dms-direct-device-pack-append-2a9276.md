# Add direct device DMS pack and append

## Summary

Added the direct raw-pointer storage seam needed by integrated DMS serving.
External decisions and dense-source K/V can now pack and append into the
compact device owner without K/V or decision upload through host staging. Host
control metadata synchronizes once at the prefill/decode lifecycle barrier; no
host K/V payload mirror is created.

## Changes

- Added persistent per-layer device base/capacity/live metadata to
  `DMSDevicePayloadStore` and backend-aware gfx1100/gfx1151 registry resolution.
- Added direct `pack_layer_device` / `append_layer_device` raw-pointer methods,
  with existing host composition routed through the same kernels.
- Added `DMSCompactBackend.device_streaming_pack_layer` and
  `finalize_device_streaming_pack`, including post-pack extent/ledger shrink and
  device metadata republish.
- Added direct per-layer decode append and one-barrier host-control finalization.
- Added an integrated external-projector -> direct pack -> shrink -> append gate
  proving metadata/payload parity against the strict host parent.

## Validation

- Direct pipeline plus affected device/runtime bundle: 39 passed on gfx1151.
- Direct decisions equal the CPU source, host/device live/position/eviction and
  extent metadata match after pack and append, and device state has empty
  `k_payload`/`v_payload` dictionaries.
- Ruff, py_compile, worklog, and diff checks pass.
