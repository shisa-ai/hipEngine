## Process lessons (cost real GPU time today)

1. The C1-C8 bench refuses to run unless the tree is tracked-clean
   (`git status --porcelain --untracked-files=no`; untracked files are fine). I was
   editing `benchmarks/README.md` exactly when a queued arm launched, so the
   capability-8 arm died in seconds. Queued arms now wait for a clean tree as well
   as for the previous pid.
2. Fan-out waits are wrong for one GPU: two arms waiting on the same predecessor pid
   start together and contaminate each other. Arms must be chained pid->pid
   (bg-53 -> bg-55 -> bg-56).
3. `pgrep -f` against a script name matches a sibling `bash -c` wrapper's command
   line, so cross-task waits on it can deadlock forever. Use `kill -0 <pid>`.
