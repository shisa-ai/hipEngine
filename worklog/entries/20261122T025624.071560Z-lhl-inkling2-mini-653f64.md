# Reuse packed NVFP4 expert blocks across prompt routes

## Summary

Reuse each raw GGUF NVFP4 block across up to four routed prompt rows for the same expert. Each row keeps its own FP32 accumulation and post-dot scale. Decode remains on the ordinary selected path where no weights can be shared.

## Changes

- Build fixed-width records with the original expert and route IDs, reusing Inkling's existing host tile builder. Scatter each result back into the original route position before ordered mixing. Gate/up and down can both use tiles without changing the device weight format, making an extra weight copy, or introducing another transfer.
- Use the registered individual-route variant when routes do not share a tile, the candidate is missing, or the list does not fit one selected launch.
