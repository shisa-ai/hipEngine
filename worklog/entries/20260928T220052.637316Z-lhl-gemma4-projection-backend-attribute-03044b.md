# the MoE compact read .backend off a projection that is allowed to be a raw pointer

## Summary

`Gemma4Projection` is `int | Gemma4GGUFDeviceWeight` (`gemma4_types.py:20`), so a
projection is allowed to be a raw device pointer. The parallel-compaction
selection added by `0707b3cd3` read `gate_up_proj.backend` unconditionally, so
every caller passing a raw pointer raised `AttributeError: 'int' object has no
attribute 'backend'`. Six tests in the default unit tier were dead, including
`test_layer_incremental_decode_matches_a_dense_prefill` -- the contract test for
generation, and the one that would have caught the decode-routing defect fixed
in `9858c23dc`.

## Changes

`gate_up_proj.backend` becomes `getattr(gate_up_proj, "backend", None)`, and the
mode resolves only when a backend is present. That is not a silent downgrade:
it is the answer `resolve_laguna_group_compact_mode` already gives a backend
that declares no capability (`_BASELINE_GROUP_COMPACT_MODE = "serial"`), and the
mode remains the profile's to set by name.

Measured that production is unaffected rather than assuming it. Instrumenting
`gemma4_experts_forward_bf16` through the public surface and running a 40-token
prefill:

```
PRODUCTION: [(('Gemma4GGUFDeviceWeight', 'hip_gfx1151'), 30)]
```

Every one of the 30 layers passes the weight object, so the new branch never
fires there and the parallel path is unchanged.

## Validation

RED, with the one line reverted:

```
uv run --offline pytest tests/test_unit_gemma4_gpu_kernels.py -k layer_incremental_decode
# -> 1 failed, 61 deselected
```

GREEN, with the fix, and the two sweeps around it:

```
uv run --offline pytest tests/test_unit_gemma4_gpu_kernels.py -q   # exit 0
uv run --offline pytest tests/ -q -k gemma4                        # exit 0
```

No new test: the six revived tests already pass raw pointers, so they are the
regression guard, and they are RED without this change.

## What is not claimed

The raw-pointer path now selects serial compaction rather than resolving a
capability. That is correct for a caller that supplies no backend, but it does
mean such a caller cannot reach the parallel compactor. No production path is
in that position today; if one appears, it needs to pass the backend in rather
than have this function guess it.
