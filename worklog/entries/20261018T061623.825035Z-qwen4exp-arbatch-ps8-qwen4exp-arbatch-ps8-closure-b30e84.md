# Qwen4Exp AR batch PS8 closure: opt-in widths 1-4 qualified, task review recorded

## Summary

PS8 (task #21, concurrent request batching) is closed for the opt-in AR batch
path at physical widths 1-4 and at most 2048 positions. Every PS8 acceptance
item now has direct evidence: physical request widths proven from the server's
own width histogram plus dispatch-manifest binding, the calibrated numerical
gate at three widths, repeat/state/lifecycle gates, live C1/C2/C4 HTTP
lifecycle, queueing and admission reuse, cancellation with a surviving peer, and
concurrent AR plus MTP.

The free-output task review found no semantic failure. Two answers are recorded
as completion-unverified rather than failed: they cover every requested point
but exhaust the review budget before EOS. Token identity was never used as a
correctness criterion.

The path remains default-off. No default, capacity, dispatch, or MTP route
changed in this unit, and no performance claim is made.
