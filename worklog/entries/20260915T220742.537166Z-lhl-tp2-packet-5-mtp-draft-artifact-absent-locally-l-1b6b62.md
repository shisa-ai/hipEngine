## Preliminary economics (inferred from measured rates, not measured)

At the W7900's measured effective decode bandwidth (~2.9 TB/s class, see
`docs/ROOFLINE.md`): one drafter pass ≈ 3.6 GB ≈ 1.2-1.5 ms; one multi-row
target verification pass over all 65 layers ≈ one full AR weight read
(~15 GB per rank pair ≈ 5.5-6 ms, amortized across all K=8 rows). Cycle ≈
7-7.5 ms for up to 8 committed tokens vs 9.4 ms AR per token (TP2 measured
24.15 ms/step on the W7900+7900XTX pair; per-rank AR ≈ 9.4 ms). Even one
committed token per cycle wins; at ≥50% acceptance this is a multi-x lever —
the largest found since the graph schedule. DFlash2 has no recurrent GDN
draft state to roll back (it reuses target FKV), which simplifies Packet 5's
transactional-snapshot contract relative to a NextN-MTP draft.
