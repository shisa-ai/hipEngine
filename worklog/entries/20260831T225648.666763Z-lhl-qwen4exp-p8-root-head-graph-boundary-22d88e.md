# Add Qwen4Exp root and head graph boundaries

## Summary

Extended the P8 probe across device token embedding/repeat and final GR mix,
full-vocabulary head, and device argmax. Generated token IDs now feed the next
replay, while PLE input remains explicitly static/host-staged.

## Changes

- Added `--include-root-head`, valid only for all 48 physical layers.
- Capture device token embedding/repeat before PLE/layers and final head/argmax
  after them; hash full logits and token state.
- Made the no-inject final GR zero-fill stream-aware via `memset_async` under a
  non-default capture stream; default-stream behavior is unchanged.
- Mark `ple_input_dynamic=false` in the result schema.

`hipMemset`; the stream-aware exact zero-fill resolves it. GR/probe tests report

generated-token feedback with exploratory eager/graph medians 166.230/62.111

unchanged across replays.
