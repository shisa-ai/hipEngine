# Transfer Laguna DFlash IQ3 tile4 to gfx1151

## Summary

Started the highest-priority candidate from the cumulative-performance audit:
transfer the exact Laguna IQ3 selected-down tile4 kernel from its complete
gfx1100 explicit-DFlash gate to the actual gfx1151 public DFlash provider.
Ordinary Laguna AR must remain on tile1; promotion scope is only the explicit,
source-identified B4 DFlash target verifier.

## Changes

- Added RED/GREEN for gfx1151 peer registration, backend capability,
  public-provider tile4 selection/telemetry, env rollback, and ordinary-AR
  tile1 isolation.
- The device body and wrapper already live in-tree under
  `hip_gfx1100/quant/gguf_iq_gemv.{hip,py}` and the gfx1151 package compiles
  shared gfx11 bodies natively. The one tile4 registry key is deliberately in
  `_GFX1151_ALIAS_EXCLUSIONS`; removing that exclusion is the kernel transfer.
- Public DFlash currently calls the ordinary no-argument target session opener,
  whose `iq3_selected_down_tile` default is 1. The intended plumbing is a
  backend capability consumed only by `LagunaDFlashTextProvider`, passed as an
  explicit session-open argument; ordinary target-only generation stays tile1.
- Implemented that route with
  `HIPENGINE_LAGUNA_DFLASH_IQ3_SELECTED_DOWN_TILE=1` as rollback; invalid values
  fail closed. Updated kernel/env/refactor documentation.
