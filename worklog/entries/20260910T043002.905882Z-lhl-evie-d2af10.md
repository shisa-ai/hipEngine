# EVIE cluster8 recurrence: exact and promoted to default

## Summary

Task #17 resolved by retraction of its premise. The
`qwen35_gdn_prefill_recurrent_normalized_cluster8_f32` kernel is
algebraically exact for EVIE's GDN block: its baked kOutputScale
(0.08838834764831845) is exactly 1/sqrt(128), the q-normalization scale
that EVIE applies to q before the recurrence. The kernel factors that
scalar through the recurrence to the output (exact by linearity). The
prior "max err 0.39 on scale 0.43, not numerically equivalent" finding
was a comparison harness that fed the already-scaled q into cluster8,
double-applying the scale. With the runtime feeding unscaled
l2-normalized q (l2norm kernel scale argument 1.0 in cluster8 mode):

- single-layer vs k2: max 2.98e-08 (reduction order only)
- end-to-end strict fp32 vs torch oracle: doc 4.4e-05, query 2.6e-06,
  MaxSim delta 1.0e-05, bit-repeatable
- fp16 production: 2460 -> 2163 ms (8p+8q, -12.1%)
- strict fp32: 14692 -> 7717 ms (-47.5%)
