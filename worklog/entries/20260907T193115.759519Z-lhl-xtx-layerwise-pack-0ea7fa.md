# Layerwise DMS compact pack against the dense BF16 pool

## Summary

Memory review target 1, implemented and measured. The DMS compact pack is
now layerwise: the destination store allocates each compact layer's payload
planes lazily on first touch (`_ensure_layer` at every per-layer accessor,
with rollback of a partially allocated layer), and after each layer's pack
kernel retires the dense BF16 source planes for that physical layer are
freed (`Qwen35GGUFKVChunkBacking.release_full_attention_layer` prunes the
backing so the later chunk free never double-frees). The resident scratch's
plane references are refreshed after each release. Partial compact-store
construction now closes the backend on failure (the review target 6c
exception-cleanup gap) before propagating.

process), continuing the day's ladder:
