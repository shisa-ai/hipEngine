# Enforce Gemma 4 MTP stop controls and probe verdicts

## Summary

The completion review found that accepted draft tokens could pass EOS, MTP ignored the target's additional stop tokens and unsupported request controls, and the probe returned success even when IDs differed. These control and reporting defects are corrected. The multi-category probe exposed a separate production-attention verifier mismatch; this entry does not claim general token identity or a 2x decode gain.

## Changes

- Stop at the first committed explicit/model stop token, including accepted drafts. Honor EOS overrides and `ignore_eos` with the same semantics as plain generation. Rewind and account for the retained prefix only.
- Share plain generation's request validator, retaining MTP's supported greedy top-k=1 case. Unsupported controls now raise rather than silently changing their meaning.
- Count actual verifier rows, including short final cycles.
- Make the public probe require token IDs, fail on mismatches or invalid lengths, and compute rates from emitted tokens. Label its timing as whole-call, including prefill, not isolated decode.
- Add JSON output with model/draft provenance and full category/heldout suite input. Keep plain-first call order to test inherited-state isolation.
- Extend CPU coverage to all budgets 1–8, stop positions, EOS overrides, unsupported controls, missing IDs, wrong IDs with identical text, early stopping, and invalid timing.
