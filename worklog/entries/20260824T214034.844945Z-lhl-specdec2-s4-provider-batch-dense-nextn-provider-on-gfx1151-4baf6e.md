# Batch dense NextN provider on gfx1151

## Summary

Add the physical dense-NextN and target-frontier foundation required by
SPECDEC2 S4. One shared resident NextN owner now holds independent request slots
and executes every shared proposal or accepted-state-repair depth through one
row-batched backbone. Compatible target roots/candidates execute in one packed
target verifier call. Ragged tails retain a bounded singleton fallback instead
of padding inactive logical candidates.

This is a functional primitive unit, not S4 closure or a promotion. Candidate
IDs still cross the host boundary before target lowering, and the later S4 unit
must retain device candidates, qualify commit payloads/lifecycle, and publish
clean same-host evidence before any default changes.

## Changes

- Give `Qwen35GGUFNextNExecutor` one multi-slot resident scratch/session owner
  with request-to-slot cursor ownership and exact checkpoint restore.
- Add physically row-batched embedding, NextN fusion, full-attention backbone,
  output norm/head, and independent result materialization.
- Add state-only packed execution so accepted provider repair does not score a
  discarded vocabulary row.
- Preserve proposal hidden rows by request/depth and batch all common ragged
  depths; execute only a one-row tail when no peer remains.
- Lower C2/C4 chains into one packed target-verifier call, accept independently,
  and commit each selected target row while retaining reversible provider
  checkpoints.
- Keep a refill-capable provider group attached across K0, retirement, and late
  admission; initialize it before the first AR transition and do not consume the
  prefill-produced root before Generation-2 publishes it.
- Expose an explicit gfx1151 physical-C4 package capability and physical
  proposal/target telemetry without changing gfx1100.
- Generalize the established c1 exact gate to C={1,2,4} while retaining its c1
  command and artifact shape.
- Keep logical session cursors separate from the scratch metadata convention so
  a checkpoint after packed or serial work restores the same next input.
- Add focused unit coverage for C4 shared-depth execution, ragged K=(1,2),
  logical checkpoint cursors, and shared full-accept/rejected-root repair.
