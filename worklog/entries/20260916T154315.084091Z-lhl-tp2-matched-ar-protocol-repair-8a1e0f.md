# TP2 matched-AR protocol repair: natural-length diagnostic, independent reps, matched windows

## Summary

Review found the matched TP1-vs-TP2 AR harness (commit `66d3ea506`) materially
failed its own declared cell. Six protocol defects are repaired on CPU before
any further GPU measurement: the cell is now an explicit **natural-length
diagnostic** (`C1-natural`) rather than a claimed context-128 cell; each arm is
an independent per-rep execution with reuse rejection; both arms report one
externally measured whole-generation window with capture and destruction
separately and explicitly aligned sampled outputs; accounting gates on graph
effectiveness, context semantics, token-ID hashes, suite completeness, finite
logits, rep completeness and provenance; ratios are suppressed on accounting
failure; and unmeasured numerical/category/determinism/reset/provenance gates
preclude qualification. The previous unit's control-vs-control byte-identity
requirement is withdrawn as an invented promotion bar; it is now a recorded
diagnostic. No GPU performance run was made; the TP1-d1 XTX memory-fault
blocker is unchanged.

## Changes

- `scripts/tp2_matched_ar_baseline.py` (repaired):
  - `CELL_C1_NATURAL` declares `context: "natural"`; the validator requires
    `context_tokens == prompt_tokens` for natural length and **fails** a
    fixed-length cell as unimplemented, so no run can be labelled context-128.
  - Per-rep independent execution: each arm runs in its own subprocess with a
    fresh `run_id`; `validate_rep` and `compute_ratios` reject reused/stale
    execution ids and incomplete reps. A blocked arm is recorded, never faked.
  - Matched external window: `total_generation_ms` (prefill + decode, with
    capture and graph destruction reported separately) replaces the previous
    `sum(trace.total_s)` vs outer-wall mismatch; `adjusted_ms` must be positive
    and finite. TP2 session capture is measured explicitly (not reported as 0).
  - Sampled-output alignment: `sampled_output_ids` + `sampled_output_sha256`
    and a separate `prefill_sample_id`; both arms produce 128 sampled decode
    outputs. TP2's final sampled output is recovered from `argmax(last logits)`.
  - Accounting now gates on `graph_effective`, natural-context consistency,
    `finite_all_decode_logits`, sampled hashes, and rep completeness. Suite
    loading requires the heldout file and heldout-only rows (missing heldout is
    a failure, not a skip) and dedups by id.
  - Ratios are `None` on any accounting failure. Unmeasured qualification gates
    (`numeric_logits_measured`, `category_measured`, `determinism_measured`,
    `reset_measured`, `provenance_complete`) set `qualified=False` and
    `all_gates_passed=False` while a sound protocol still yields a diagnostic
    ratio. Provenance records model full sha256, per-arm command/log/device,
    TP2 device identities and resolved route.
  - Docstring states the force-full-logits TP1 arm is a matched-transfer
    **diagnostic**, not the optimized TP1 product baseline.
- `scripts/gguf_true_ar_category_bench.py`: per-prompt metrics now carry
  `context_tokens`, `total_generation_ms`, `capture_ms`, `destroy_ms`,
  `graph_effective`, `finite_all_decode_logits`, `prefill_sample_id`,
  `sampled_output_ids`, `sampled_output_sha256`. `finite_all_decode_logits`
  tracks finiteness on every step when `--logits-every-decode-step` is set;
  graph destruction is timed inside the decode window.
- `scripts/tp2_teacher_coverage_broad.py`: `cross_teacher_check` byte identity
  is now diagnostic-only (envelope + same-schedule determinism control);
  `evaluate_gates` no longer fails on `byte_identical=False`.
- `tests/test_unit_scripts_tp2_matched_ar_baseline.py` (rewritten, 30 tests):
  pure accounting/rep/ratio/suite cases plus `main()` negative tests that
  monkeypatch the arm runner and assert no ratio and no qualification on a
  blocked arm, accounting failure, reused execution ids, and missing heldout.
- `tests/test_unit_scripts_tp2_teacher_harness.py`: the byte-identity tests now
  assert the difference is recorded as a diagnostic and does not fail the gate.
- `benchmarks/results/2026-09-16-w7900-tp2-matched-ar-c1-blocked.json`: added an
  `annotations` array (existing fields unchanged) recording the invalid-protocol
  reasons: not a context-128 cell, single-reused-rep + unmatched-window ratio,
  the withdrawn byte-identity bar, the diagnostic-only TP1 arm, and the standing
  TP1-d1 fault blocker.
- `benchmarks/CHANGELOG.md`: new dated correction entry. `benchmarks/HARNESSES.md`:
  row updated to the `C1-natural` diagnostic scope.
