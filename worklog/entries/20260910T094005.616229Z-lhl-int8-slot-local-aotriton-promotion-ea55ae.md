# Admit slot-local AOTriton on the repaired route and promote it to default

## Summary

Roadmap P1 executed: the slot-local transient-oracle AOTriton admission
(`HIPENGINE_GGUF_INT8_PREFILL_SLOT_LOCAL_AOTRITON`) is qualified on the
repaired route and promoted to default ON, with `=0` as the explicit rollback.
The multi-chunk packed prefill collapse is eliminated: 677-746 tok/s flat from
1K to 8K rows (10.07x at 8 chunks), against the scalar parent's 692 tok/s at
8,192.

## Decisions

- **Promote now.** Roadmap P1: "If it wins, promote in its qualified scope and
  keep the strict fallback." Every P1 gate condition is met: applicable
  numerical packet (both slab-identity shapes), deterministic repeats, exact
  ownership (state gate), expected kernel identity in trace, and same-host
  wall improvement at 1K/2K/4K/8K. The admitted family is the same AOTriton
  the direct arm already runs by default above the 512-row crossover, so this
  removes an inconsistency rather than introducing a new kernel.
- **The 2026-09-09 gate failure is fully reinterpreted.** Its `finite:false`
  on every prompt was two harness defects (INT8 payload read as BF16;
  always-fingerprinted never-populated `hidden_seed_fp32`), and its 1,024-row
  prompts were single-chunk on the 35B model (4,096-row scratch), so the
  multi-chunk corruption it was blamed on never engaged. The repaired
  qualification runs the 27B with two-slab and tail-slab prompts.
- **Clean provenance via worktree.** The census lane's uncommitted README
  edit and artifact dirty the shared tree (the provenance check counts
  untracked files), so the qualifying runs execute from
  `/tmp/hipengine-gate-clean` at the commit under test.
