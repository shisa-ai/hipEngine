# Repair deferred C1 static intent and validate product-route K3

## Summary

Post-withdrawal, the product server route could not engage native packed C1 at
ANY depth: the realized width-miss deferral rebuilt its route decision without
the request-time `static_eligibility` override and `static_intent_allowed`, so
the resident owner's fail-closed physical admission refused every deferred C1
explicit request into pre-mutation K0 (`c1 singleton shape refused`). The
screening opt-in was unreachable for C1 because it lives downstream of the
dropped eligibility. Fixed in `555fc7ef3`; first valid native packed C1/K3
product-route economics measured 1.6334x same-run AR with 10/10 ar_exact.

## Changes

- `hipengine/server/api.py` `_resolve_realized_generation_route`: the
  `physical_group_deferred_to_resident_owner` branch now propagates the
  evidence-backed static eligibility (`static_eligibility`,
  `static_eligibility_fingerprint`, `k0_class`) and grants
  `static_intent_allowed` from an explicit plan key or, for the re-resolved
  raw decision payload (`_realized_model_serving_plan` returns
  `SpeculativeMTPServingDecision.as_dict()` without the intent key), derives
  it from the eligible override. An explicit plan-layer False stays
  authoritative. Automatic/K0 routes never enter this branch; the adapter
  still re-checks the width/depth policy, singleton shape, and claims.
- `tests/test_server_api.py`: two focused tests pin the deferred static-intent
  contract (declared key preserved; derived from eligible payload when the
  re-resolved decision lacks the key) and the out-of-scope refusal.
- `campaign-artifacts/c1-k-sweep/`: resumable K0-K7 sweep driver
  (`run_c1_k_sweep.sh`, verdict-gated, 900 s watchdog per run) and
  `rollup_c1_k_sweep.py` for the balanced-pair economics artifact.
- Context: the C1 K2/K3 evidence rows were withdrawn in `ccf67ca6a`; the
  deferral branch predates the static-intent mechanism, so withdrawal silently
  closed the explicit C1 route. This repair reopens the route for explicit
  requests only (listed (1,2)/(1,3) cells, or screening opt-in for K1/K4-K7);
  it does not re-register public evidence and automatic stays K0.
