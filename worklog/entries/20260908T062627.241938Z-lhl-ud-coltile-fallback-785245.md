# Coltile geometry fallback for raw-Q5/Q6 prefill

## Summary

The user's suspicion from the prefill assignment was correct: the public
prefill path selected `rowbatch32`, not the backend-declared `coltile`
geometry. The rowbatch-size fallback added in ca4e01581 inherited the slab
size but not the variant; `_raw_k_prefill_variant` still defaulted to
`"rowbatch"` and only the Laguna runner read the backend's
`GGUF_RAW_K_PREFILL_VARIANT`. Confirmed by the route-gap kernel census
(`gguf_k_prefill_out_rowbatch_kernel<*,*,5,32>` serving Q5_K), then fixed and
A/B measured.

## Changes

`hipengine/runtime/gguf_linear.py`: `_raw_k_prefill_variant` ContextVar
default becomes `None` (accessor keeps the historical `"rowbatch"` for unset
owners), and `launch_gguf_linear` applies the backend package's
`GGUF_RAW_K_PREFILL_VARIANT` when no execution owner selected a geometry -
the exact symmetric fallback the row slab already had.

  family, bit-exact vs the per-row prefill kernel per
  tests/test_gguf_k_rowtile_gemv.py. No arithmetic change; E2E acceptance
  green with the coltile route active.

  test_qwen35_gguf_materialize.py, tests/test_gguf_e2e_acceptance.py all
  green.
- Pre-existing failure noticed, NOT from this change (fails on the clean
