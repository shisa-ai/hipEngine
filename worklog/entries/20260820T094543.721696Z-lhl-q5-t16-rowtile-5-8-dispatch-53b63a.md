# Q5T16 rows 5-8 true rowtile model dispatch promotion

## Summary

With the Q5T16 true rowtile primitive certified to rows 5-8 (previous unit),
the model-step dispatch now routes rows 5-8 Q5 to the true rowtile instead of
the padded-WMMA projection. This is the reachability change that makes the
measured c5-c8 improvement real.

## Changes

- `hipengine/kernels/hip_gfx1100/__init__.py`:
  `GGUF_T16_NATIVE_ROWTILE_MAX_ROWS_BY_QUANT["gguf_q5_k_t16_v1"]` 4 -> 8, so
  `_native_batch_decode_dispatch` in `gguf_linear.py` rewrites rows 5-8 to
  `t16_gemv_rowtile_bf16_bf16_out`. gfx1151 package unchanged (requires
  independent measurement).
- `tests/test_gguf_gemv_decode_dispatch.py`: added
  `test_native_batch_decode_q5_t16_rows_5_8_route_to_true_rowtile` asserting
  rows 5,6,7,8 rewrite to `_Q5_T16_ROWTILE` under the native batch decode
  session; extended `_fake_weight` with a `tiles` allocation for the t16 ABI.
