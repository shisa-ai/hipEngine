# R0523 c4 race: rocprof bench trace - all rows=4 GPU kernels deterministic; owner is host-side sequencing

## Summary

rocprofv3 kernel-trace of the ACTUAL bench server (rocprof wrapper patched into the
standalone bench's own _server_command_and_env) named every kernel on the packed c4
decode path. The bench uses the native-row path with the INDEXED GDN kernels. Every
rows=4 GPU kernel was then inspected and is deterministic. No GPU arithmetic kernel is
the R0523 owner; the intermittent corruption must come from host-side state sequencing
or a cross-kernel ordering effect. Owner still unpinned after ~34 iterations. No
production behavior changed; all hooks env-gated (off by default) and uncommitted.

## Changes

- Env-gated rocprof wrapper (HIPENGINE_R0523_ROCPROF) added to the standalone bench's
  _server_command_and_env (and, redundantly, to scripts/server_f1_concurrency_bench.py).
  Diagnostic only; revert before any production commit.
