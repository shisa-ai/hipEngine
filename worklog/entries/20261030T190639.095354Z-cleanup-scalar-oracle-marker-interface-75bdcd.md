# Keep independent target oracle and explicit marker-free profiling

## Summary

Keep the independent scalar target-row oracle as supported diagnostic
infrastructure. Adopt the already documented explicit child-mode/kernel-trace
procedure for profiling without marker attribution. These are interface
retention decisions, not implementations waiting for retirement.

## Changes

- R0281-TARGET-ORACLE: `Qwen35GGUFResidentSession.step_rows()` and
  `verify_rows()` remain owned by `qwen35_gguf_runner.py`. The scalar path
  supplies independent row-order, layer-boundary and full-logit references;
  it is not a duplicate optimized implementation to remove. Unsupported
  branched, inactive and tree topologies must still fail before row mutation.
  `tests/test_unit_gguf_target_rows_oracle.py` pins this contract;
  `tests/test_live_qwen35_gguf_target_rows.py` uses independent sessions and
  checks full logits/boundaries. No faster implementation replaces its own
  independent oracle.
- R0392: keep shared ROCTX discovery and each wrapper's explicit
  missing-library error for marker-attributed work. For unscoped kernel
  traces, use the wrapper-specific child entry under
  `rocprofv3 --kernel-trace` and `scripts/gguf_kernel_trace_rollup.py`, as
  already documented in `docs/RDNA3-TUNING-GUIDE.md`. There is no silent
  fallback and no new generic `--child` spelling: wrappers that use
  `--child-mode` retain that interface. Marker windows and unscoped traces
  are distinct measurement contracts.
- Remove only these two disposition headings from `docs/REFACTOR.md`.
  No runtime, profiler, arithmetic, registry, flag or default changes.

## Validation

- `uv run pytest -o addopts='' -q` over the target-row oracle, live target-row
  file, MTP2 seam, ROCTX discovery, decode profiler and MTP verifier profiler:
  247 passed, 9 skipped. The skipped tests require local HIP/model fixtures;
  this CPU run makes no numerical claim about those rows.
- Source review confirms live scalar callers, not an unused compatibility
  shim. Profiler tests cover absent/present libraries, explicit overrides,
  child forwarding, dependency paths, trace-marker matching and cold import.
- `python3 scripts/docs/check_all.py` and `python3 audit/audit.py check`
  passed after removing the headings. The audit budget was unchanged.

## Next

- No remaining work in these two retention decisions. Numerical/native
  correctness gates and public request lifecycle remain requirements of any
  later implementation change; retaining the oracle does not claim all
  artifact-specific live tests ran.
