# Default GGUF resident bench to public session selectors

## Summary

The resident benchmark now resolves its default launch selectors from the
public session's WMMA helper and GEMV constant. The historical profile option
is no longer required to measure those defaults.

## Changes

- Replace the benchmark's independent `PUBLIC_AR_PROFILE_KWARGS` map with
  `_resident_session_wmma_prefill_default()` and `_GGUF_PUBLIC_USE_GEMV_DECODE`
  from the existing public-generation owner. No product code/default changes.
  The diagnostic WMMA environment override is read at call time; the low-level
  WMMA/GEMV environment defaults no longer choose the ordinary bench route.
- Preserve explicit `--no-use-wmma-prefill` / `--no-use-gemv-decode` diagnostics.
  Keep `--public-ar-profile` as a compatibility assertion for archived commands,
  rejecting explicit conflicts, and `--no-public-ar-profile` as the explicit
  low-level/env-default replay route.
- Preserve protocol field names, report the resolved default policy in
  `public_ar_profile` / `public_ar_profile_applied`, and add
  `requested_public_ar_profile` to distinguish omitted/explicit old flags.
  Effective WMMA and GEMV reports decide `shipping_ar_route_mismatch` even when
  the alias was passed. Unknown effective values do not assert parity.
- Remove the benchmark-default debt row and stale cross-reference. Update
  CLI help, JSON notes, warning and the rowgate probe's usage text. Prior
  measurements remain in their immutable worklogs and archived commands.
- RED/GREEN tests cover default and diagnostic selection, live env resolution,
  invalid values, alias conflicts and effective mismatch. Synthetic CLI tests
  exercise parsing/forwarding/reporting for per-run and persistent modes.
