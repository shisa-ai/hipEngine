# Record shared scratch incompatibility for resident streams

## Summary

Rejected an uncommitted resident scalar-stream candidate after real generation exposed shared-buffer corruption. Keep the existing packed default and serial comparison; an explicit scalar-stream request now fails with the missing disjoint-buffer capability instead of silently executing serially.

## Changes

- `resident_slot_view()` explicitly shares temporary execution and scalar sample buffers, with scheduler serialization as its contract. Launching several such views concurrently is incompatible with that contract.
- Removed the uncommitted candidate and its prototype test from the repository. The rejected test is preserved at `/tmp/r0281-rejected-resident-stream-test.py` for diagnostics only.
- Add a pre-allocation capability error for explicit `ar_stream_decode=True` with `ar_packed_decode=False` at resident-runner construction. Packed requests retain their packed route; compatibility independent sessions retain their existing stream implementation.
