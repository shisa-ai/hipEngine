# Verify raw UD dense runtime caller ABI

## Summary

768 CPU-only checks exercise actual `launch_gguf_linear` calls for the six
raw IQ/Q3 formats integrated into UD model residency. The combined caller,
materializer and existing dispatch/cache bundle passes 966 tests. No runtime
or kernel implementation changed; no GPU work overlaps background context
captures.

## Changes

`tests/test_gguf_ud_linear_callers.py` checks IQ4_XS, IQ4_NL, IQ3_S, Q3_K,
IQ3_XXS and IQ2_S on both gfx1100/gfx1151 backend declarations, BF16/F32
outputs and rows 1/2/3/4/5/6/7/8/9/12/16/28/32/511/512/513. Both explicit
WMMA settings retain the raw fallback. GEMV decode is explicitly enabled.

A real `_spec_for_tensor` plan supplies full FFN-down metadata `(N,K) =
(5120,17408)` and only a raw allocation. The resolver verifies the real
registered leaf exists before substituting a capture function. Assertions
check registry key, decode/prefill variant, all raw-pointer arguments,
dimensions, library/runtime/stream forwarding and raw-only allocation access.
Resolver monkeypatch and dispatch-cache cleanup are scoped to each test.
This tests the host call ABI, not device math or runner tile/chunk semantics.

## Validation

- Initial test stopped on an overly specific allocation-access count: the
  dispatcher consults the same raw owner three times. The contract now checks
  nonempty raw-only accesses rather than imposing one metadata lookup.
- Mutation RED: a temporary copy changed only the launched output pointer
  from `0x333000` to `0x333100`. Its first case failed at the exact captured
  argument assertion (`/tmp/ud-linear-caller-mutation.log`); the production
  implementation was not edited to manufacture RED.
- Changed test: 768 passed in 11.32s. Existing narrow bundle: 198 passed in
  2.82s. Combined run below verifies cache/registry isolation in one process:

```bash
.venv/bin/python -m pytest -o addopts='' -q \
  tests/test_gguf_ud_linear_callers.py tests/test_gguf_ud_km.py \
  tests/test_gguf_linear_dispatch_cache.py tests/test_gguf_linear_dispatch.py
```

966 passed in 13.39s. No HIP runtime or leaf launch is required by the new test.
