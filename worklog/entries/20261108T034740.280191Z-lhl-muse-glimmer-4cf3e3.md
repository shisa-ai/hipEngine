# Muse Glimmer long-context attention scaling: win grows to 20% at 128K, 43% at 512K; compute-bound, LDS dead at all ctx

## Summary

Lead reframed #27: an agentic/coding model runs long-to-max context normally,
so analyze whether improved attention keeps paying at 256K/512K. Answer: yes —
the win grows linearly with context because attention K/V reads scale with
context while the weight GEMVs are constant per token. Measured the isolated
decode-attention kernel from 8K to 512K and confirmed it is compute/latency-
bound, not DRAM-bound, at every context.

## Changes

- No production change. Re-applied the LDS K/V-tiling variant only to run the
  decisive isolated microbenchmark, then reverted it (working tree clean).
  Analysis driver: /tmp/glimmer_attn_scale.py (allocates KV, times the kernel;
  no full-model prefill).

## Validation

- Model geometry: 52 layers (13 NoPE full-attention + 39 SWA window-2048),
  32 Q / 2 KV heads, dim 128; context_length=131072 (128K max), rope base 5e5;
  GPU L2 = 2 MB. 256K/512K are beyond the trained window (extrapolation).
- Isolated full-attn per layer (baseline kernel), scales linearly: 32K=0.573,
  64K=1.148, 128K=2.207, 256K=4.438, 512K=8.858 ms. Ratio to the 220 GB/s DRAM
  floor is constant ~3.6x across 32K-512K.
- LDS variant in isolation is neutral/worse at EVERY context (32K 0.586 vs
  0.573; 128K 2.284 vs 2.207; 512K 9.353 vs 8.858 ms). Removing the 4x
  redundant per-wave reads never helps => the kernel is compute/latency-bound
  (serial per-key wave reductions + online softmax), not bandwidth-bound, even
  when K/V far exceeds L2. The bandwidth/LDS approach is a dead end at all contexts.
- Full-model decode projection (weights 77.6 ms + attention + glue 3 ms), if
  attention is brought to its DRAM floor: 32K 11.18->12.04 tok/s (+7%); 128K
  8.95->11.21 (+20%); 256K 7.06->10.27 (+31%); 512K 4.97->8.79 (+43%). At 512K
  attention is ~60% of the step.

## Next

- The right lever is a lane-per-key restructure of the shared decode/verify
  attention kernel (parallelize keys across lanes to drop the per-key wave_sum
  reduction), targeting the compute bound. Payoff grows with context: ~20% at
  the 128K model max, more beyond. Recommend funding it for long-context agentic
  use. The 3.6x->1x floor gap is the ceiling; actual gain depends on how close
  the restructure gets to the bandwidth floor.
