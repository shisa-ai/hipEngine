# Q4 shared-B inactive-wave exact optimization

## Summary

Made the retained gfx1100 Q4 T16 cooperative shared-B row64 owner skip WMMA arithmetic for waves whose complete R16 tile lies outside the logical row count. The change is exact because those waves previously loaded zero rows and could not publish output. Full row64 groups continue through the unchanged parent kernel; only partial tail groups select the new sibling.

This also exposed a promising arithmetic-changing C8/R32 route: the optimized shared-B leaf beats grouped-R8 on four wide Q4 roles and improves one-prompt target wall in both counterbalanced pairs. That route remains default-off/uncommitted because it still needs the complete production numerical and task gates.
