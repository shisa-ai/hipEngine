# Reuse DMS model verification across resident sessions

## Summary

DMS session recreation no longer rereads an unchanged model to verify its SHA-256. Sidecar verification and model/metadata fingerprint comparison remain in place. This is a setup-work repair, not a kernel or arithmetic change; no throughput result is promoted.

## Changes

- Added a process-local 16-entry digest cache keyed by resolved path, device, inode, size, nanosecond mtime, and nanosecond ctime. Rewrites, replacement, truncation and deletion invalidate reuse. A version change during hashing raises instead of caching the digest.
- Sidecars remain uncached. Model files must remain immutable during inference; this cache is not a security boundary against a privileged writer or filesystems that cannot expose reliable change metadata.
