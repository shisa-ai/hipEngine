# Key resident Q5 dispatch memo on the raw sidecar pointer

## Summary

`test_h8a_source_selected_shared_session_dispatch_and_unshared_fallback`
failed on its second launch. Inside one `Q5F32OrderedPrefillSession` carrying a
resident plane for raw pointer A, a weight at raw pointer B resolved to the
resident wrapper and then raised
`RuntimeError: resident Q5 dispatch has no exact raw-pointer plane`.

Cause: the memo key in `launch_gguf_linear` computed its `raw_weight_ptr`
element as `None` whenever `spec.allocation_names` did not declare `"raw"`.
That attribute is declared on five concrete spec types and no common base, so
for any other spec the pointer element was constant `None` and the key could
not separate two raw pointers. The first launch (pointer A, resident plane
present) memoized the resident selection; the second launch (pointer B, no
plane) hit that entry and reused the resident wrapper, which fails closed on
the missing plane. The resident decision itself is correctly pointer-keyed in
`_raw_k_f32_ordered_prefill_dispatch`; only the memo key was wrong.

Fix: derive the memo's `raw_weight_ptr` from the actual sidecar pointer the
dispatch reads (`weight.allocation("raw").tensor.ptr`) instead of from the
declared-allocation proxy, and derive `has_raw_weight_sidecar` from it. A
missing `raw` allocation still yields `None`, so no-raw specs are unchanged.
Resident selection can no longer be reused across a pointer that has no plane.

## Changes

- `hipengine/runtime/gguf_linear.py`: in `launch_gguf_linear`, replace the
  `allocation_names`-gated `raw_weight_ptr` with the real `allocation("raw")`
  pointer captured in the existing `try/except KeyError`, and set
  `has_raw_weight_sidecar` from it. No other dispatch input changed; the
  resident fast path and raw-pointer plane ownership are untouched.
- `tests/test_unit_gguf_linear_dispatch_cache.py`: add
  `test_dispatch_cache_keys_on_the_raw_sidecar_pointer`, a CPU RED that pins
  the memo key on the raw sidecar pointer for a spec that does not declare
  `allocation_names`. Extend the `_fake_weight` helper with an optional
  `raw_ptr` (default unchanged at 10).
