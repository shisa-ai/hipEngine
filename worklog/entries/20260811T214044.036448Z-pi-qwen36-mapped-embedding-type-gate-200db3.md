# Fail closed mapped-host embedding auto placement

## Summary

The XTX campaign's focused shared-gfx1100 bundle found that package-wide mapped-host auto placement incorrectly deferred the Qwen3.6-35B Q3_K_M model's Q6_K root token table, then rejected it because the mapped kernel supports Q4_K only. The retained Qwen3.6-27B Q4_K path was correct. Auto placement now consults the package-declared GGML tensor types and keeps unsupported roots on their prior device owner; explicit host requests remain strict.

## Changes

- Declared `Q4_K` as the gfx1100 mapped-host token-embedding type contract.
- Read the root `token_embd.weight` GGML type during the existing load-time model-info inspection and fail auto placement closed to device for unsupported types.
- Added a unit RED/GREEN assertion that Q4_K selects mapped host while Q6_K selects device.
