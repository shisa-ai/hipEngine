# Trim source distributions and gate upload file sizes

## Summary

Trimmed the source archive from 199,038,956 to 17,885,776 bytes in the local
packaging check. The rebuilt wheel preserves the direct-source wheel contents.
CI rejects oversized distribution batches before either artifact is uploaded.

- Hatch sdist only-include retains hipengine, scripts, build inputs, README,
