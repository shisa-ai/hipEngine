# Planar-qmicro Q6T16 true col8 rowtile rows 5-8

## Summary

Second kernel unit (concurrency priority 2). The planar-qmicro Q6T16
`q6_k_t16_qmicro_planar_gemv_rowtile_col8_kernel` was already templated on
`ROW_TILE` with each row accumulating independently (exact per-row K order /
wave tree / BF16 boundary), but the C++ export routed rows 2-4 to the true col8
rowtile and rows 5+ to the per-row `launch_q6_t16_qmicro_planar` fallback (the
"misleading same-variant direct-per-row fallback"). Rows 7/8 additionally fell
to padded WMMA at the model dispatch. This unit extends the true col8 rowtile
to rows 2-8 and deletes the disguised per-row fallback for rows 5-8.

## Changes

- `hipengine/kernels/hip_gfx1100/quant/gguf_q6_k_t16_gemv.hip`:
  `launch_q6_t16_qmicro_planar_rowtile_col8` guard rows>4 -> rows>8 and adds
  switch cases 5,6,7,8; the export `...rowtile_col8_bf16_bf16_out` now routes
  rows 2-8 to the true rowtile (was rows 2-4, else per-row).
- `hipengine/kernels/hip_gfx1100/quant/gguf_q6_k_t16_gemv.py`: planar col8
  rowtile wrapper row gate (2,6) -> (2,8), docstring updated.

  `GGUF_T16_NATIVE_ROWTILE_MAX_ROWS_BY_QUANT["gguf_q6_k_t16_qmicro_planar_v1"]`
  = 8 so `_native_batch_decode_dispatch` rewrites rows 5-8 to the true rowtile

  with the per-row planar decode as bit-exact reference (the legacy raw col8
  rowtile caps at rows 6); `test_gguf_gemv_decode_dispatch.py` added a Q6
  planar rows 5-8 -> rowtile routing test.
