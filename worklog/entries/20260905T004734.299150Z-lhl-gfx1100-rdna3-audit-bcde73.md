# Create gfx1100 RDNA3 audit handoff

## Summary

Created the self-contained W7900 handoff requested after the 2026-09-05 RDNA3
audit. The plan turns the architecture-local hypotheses into seven ordered work
packets with exact promotion/rejection boundaries: singleton-indexed GDN, Q5
selected-down tile8, Q8 c4/c8 rowtiles, C8 Q4/Q5/Q6 pair reuse, Q6 LM-head
partitioning, shared runtime transfers, and a W7900-owned MTP width/depth table.

A source recheck found an important reachability detail for the handoff. At the
base revision, the Qwen3.8 qmicro-planar FP32 rowtile wrapper accepts rows
through 8, but `_hipengine_max_rows` remains 4. Therefore the gfx1100 package's
nominal LM-head chunk value 6 and any proposed value 8 are capped to 4 by
`_verify_lm_head_rowtile_max_rows()`. The W7900 agent must gate primitive
metadata, registry resolution, actual launch shape, and package policy together;
a constant-only change would not exercise the candidate.
