# Revalidate canonical Gemma and Qwen3.6 MTP correctness and throughput

## Summary

Re-ran the retained Gemma gfx1151 protocol at 128 generated tokens and compared the current public Qwen3.6 K2 route against true AR with complete cycle telemetry. The current Gemma result reproduces the retained artifact. The current public MoE fallback is AR-identical but slower because it uses serial-exact target verification. A same-protocol native override is faster in the target phase but reproduces the first divergence at token 35 on both cold and warm pairs.

- Gemma: `HIPENGINE_HIP_ARCH=gfx1151 GPU_MAX_HW_QUEUES=2 .venv/bin/python scripts/gemma4_mtp_probe.py --artifact /models/gguf/gemma-4-26B-A4B-it-GGUF/gemma-4-26B-A4B-it-UD-Q4_K_XL.gguf --draft /models/gguf/gemma-4-26B-A4B-it-GGUF/MTP/mtp-gemma-4-26B-A4B-it-Q8_0.gguf --suite benchmarks/prompts/mtpbench-code-general-ja.jsonl --suite benchmarks/prompts/gdn-prefill-category-heldouts.jsonl --tokens 128 --samples 2 --budget 4 --json /tmp/mtp-repair/gemma-current-128.json`.
- Qwen public fallback server: `HIPENGINE_HIP_ARCH=gfx1151 .venv/bin/python -m hipengine.server --model /models/gguf/Qwen3.6-35B-A3B-UD-Q4_K_M.gguf --backend hip_gfx1151 --max-context-tokens 32768 --max-active-requests 4 --prefix-cache off --no-startup-chat-smoke --no-startup-scratch-probe --host 127.0.0.1 --port 18999 --log-color never`, followed by `.venv/bin/python /tmp/mtp_http_record.py --model Qwen3.6-35B-A3B-UD-Q4_K_M.gguf --output /tmp/mtp-repair/qwen-current-public-k2.json --tokens 128 --pairs 2`.

## Results

### Gemma 4 retained-protocol rerun

- 36 rows: 18 prompts × 2 samples; all requests emitted 128 tokens and passed.
- 28/36 rows were token-identical; the same eight prompt/sample rows diverged within the production numerical envelope as the retained artifact.
- Current mean whole-call AR throughput: **45.441 tok/s**.
- Current mean whole-call MTP throughput: **69.400 tok/s**.
- Current mean speedup: **1.5275×**.
- Retained artifact means: **45.457 tok/s AR**, **69.428 tok/s MTP**, **1.5277×**.
- Current and retained artifact both report `passed: true`, with the same divergence IDs and positions. Current provenance records Gemma fingerprint `f28cfd664022342bce241e6236474be472a6133a1fbbf9c6c48f8db9153f0e99` and draft fingerprint `d1a1c31a0af001d83777ca084e8b0b6a02ab1c16bfa77666cac61eebc5b9feec`.
- Raw rerun: `/tmp/mtp-repair/gemma-current-128.json`. Retained baseline: `benchmarks/results/2026-10-15-gemma4-gfx1151-mtp-budget4.json`.

### Qwen3.6 public K2 fallback

- Prompt protocol: the existing 512-token repeated-word prompt from `/tmp/mtp_http_record.py`, 128 generated tokens, temperature 0, true AR controls, two alternating-order pairs.
- AR: 2.7411 s cold and 2.7407 s warm.
- Public MTP serial-exact fallback: 5.2421 s cold and 3.6685 s warm.
- Both MTP runs used 51 cycles and emitted 128 tokens; phase telemetry per warm run was proposal 259.8 ms, target 2,853.1 ms, provider update 20.0 ms.
- Token IDs matched AR on both pairs; first divergence was `null`.
- Raw result: `/tmp/mtp-repair/qwen-current-public-k2.json`.

### Qwen3.6 native override hypothesis test

- Same prompt, output length, pair ordering, and recorder protocol as the public fallback measurement.
- Native override MTP: 4.4281 s cold and 2.8358 s warm; 48 cycles; target phase 2,294.1 ms cold and 2,290.0 ms warm; proposal 22.8/14.8 ms; provider update 20.2/21.0 ms.
- Both native MTP runs diverged from AR at token index **35**.
- This reproduces the earlier native graph/eager finding under the canonical long-output comparison. The exact verifier is therefore not a mere performance fallback: it is currently required for Qwen3.6 MoE correctness.
- Raw result: `/tmp/mtp-repair/qwen-native-override-k2.json`.

## Decision

No default change was made. Gemma remains current and matches its retained result. Qwen3.6 gfx1151 MoE remains explicit-MTP-capable through serial exact and automatic AR by policy; the native MoE capability stays disabled until its cumulative state divergence is repaired and revalidated with this same protocol.
