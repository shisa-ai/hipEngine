# R1: gfx1151 INT8 K/V revalidation on current Q4_K_S head (512/8)

## Summary

Executed R1 from `docs/QWEN38-27B-GFX1151-CAMPAIGN.md` Section 12 on the
current merged tree (`ff7293098`): revalidated gfx1151 INT8 K/V on the current
Q4_K_S head (the prior K0-K3 closure was on Q4_K_M `7e78da5...`), using the
protocol-faithful native mixed-KV suite with `--require-no-bf16-mirror` and the
512 -> 1K -> 4K shape stop rule. Both natively-supported INT8 representations
reject at the first shape (512/8). The new-representation-signal angle (FP8 vs
our INT8 scale scheme) is not runnable because gfx1151 has no FP8 K/V kernels.

## Changes

- Ran `scripts/qwen35_native_mixed_kv_suite.py` on
  `/models/gguf/Qwen3.8-27B-Q4_K_S.gguf` (Q4_K_S, the current topline head;
  prior rejection was Q4_K_M), engine gguf, backend hip_gfx1151, 512/8,
  `--require-no-bf16-mirror`, KL<=0.05 / top1>=0.90, 11 prompts (10 natural +
  mixed_v1), 9 positions, fp32/fp16 scales per representation.
- pure `int8_per_token_head` (fp32 scale, all 16 full-attn layers INT8):
  `rejected_correctness` at 512/8 — layout audit keeps a persistent 48 MiB BF16
  mirror (`bf16_mirror_bytes=50331648`, `bf16_mirror_requirement_passed=False`),
  so the candidate logits are byte-identical to BF16 and the KL/top-1 rows are
  meaningless. This is a no-mirror gate failure, not a numerics signal.
- `tail4_hadamard_group32` (fp16 scale, layers 0-11 BF16 / 12-15 INT8):
  `rejected_correctness` at 512/8 — zero mirror (layout gate passes), KL tiny
  (mean 2e-6..3.3e-5, max 8e-6..2e-4), but top-1 agreement on
  `general_en_explain` = 0.889 < 0.90 floor (1/9 positions), all other 10
  prompts top-1 = 1.000.
- Per the shape stop rule a representation stops after the first failed shape;
  1K/8 and 4K/16 were not run for either representation.

  Raw JSON: `/tmp/qwen38-r1/native-512-int8-perhead.json` and
  `/tmp/qwen38-r1/native-512-hadamard.json`.

## Result / decision

- The native INT8 K/V lane on gfx1151 remains closed on the current Q4_K_S
  head: no natively-supported representation passes 512/8 under the no-mirror
  + KL/top-1 contract. Consistent with the Q4_K_M closure.
- R1's remaining open angle is the FP8 (E4M3) vs INT8 scale-scheme comparison,
  which requires building an FP8 K/V path on gfx1151 (no such kernel exists).
  That is a distinct kernel-development unit, not a re-run of the existing
  INT8 gates. Decode-traffic framing (R1 angle 2): moot for promotion since no
  representation clears quality; a decode-traffic-only argument would require
  an FP8 path anyway.
