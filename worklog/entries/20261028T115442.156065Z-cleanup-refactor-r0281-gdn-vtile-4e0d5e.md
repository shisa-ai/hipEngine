# Retire temporary GDN chain tile environment override

## Summary

Removed the temporary `HIPENGINE_GDN_CHAIN_TLOOP_VTILE` override from the shared
HIP chain-GDN launch wrapper. Divisible value widths still select tile-4 and
other widths tile-1. The serial-c1 exact route and device kernel bodies are
unchanged. The narrower layer/state comparators and explicit exact route
already supersede the original D64 drift-bisection use; this cleanup does not
claim to repair fast-route D64 arithmetic or improve performance.

## Changes

- Delete only the environment read/parse and its branch condition; retain both
  template instantiations, geometry checks and exact-route early return.
- Add an environment-reader RED/GREEN guard and HIP-availability-guarded GPU
  cases for grouped and interleaved heads, FP16/BF16 scalar inputs, rows 1/2/3/5,
  key widths 64/128/192 and value widths 7/8/31/128. The CPU oracle expands
  Q/K heads explicitly before evaluating the recurrence.
- Remove R0281 original row 6268 from the active ledger; record retirement in
  `docs/ENVS.md`, current MTP notes and the durable sweep inventory. Historical
  measurements remain in their dated records.
