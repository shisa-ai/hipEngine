# Audit codebase simplification and refactor priorities

## Summary

Reviewed the active refactor ledger, architecture/plugin invariants, tracked
source organization, environment/capability resolution, benchmark tooling,
artifact footprint, large functions/classes, and already-rejected runtime
experiments. The central finding is that required strict fallbacks are not the
main source of complexity. The largest avoidable costs are experiment selectors
inside production methods, repeatedly resolved policy, research scripts shipped
as a product package, raw evidence mixed with compact artifacts, and historical
ledger prose remaining active indefinitely.

## Measured inventory

- `hipengine/`: 304,814 tracked Python lines at the reviewed commit.
- Major product monoliths: `qwen35_gguf_runner.py` 29,324 lines;
  `qwen35_paro_runner.py` 14,260; `qwen35_paro.py` 11,892;
  `server/api.py` 16,733 with a roughly 4,410-line `create_app()`.
- Policy surface: 225 direct environment-read expressions across 38 product
  modules; 308 backend-capability lookups; 144 registry-resolution calls;
  gfx1151 package initializer 2,411 lines / 256 top-level policy assignments.
- Research/tool surface: 577 tracked scripts / 289,396 Python lines, currently
  included in the wheel. A conservative live-code/test/current-doc scan found
  405 scripts without a textual owner; this is a review queue, not deletion
  proof.
- Evidence surface: 5,158 tracked files / 225.7 MiB under
  `benchmarks/results/`, including multi-megabyte raw captures.
- Prior active ledger: 3,951 lines / 398,544 bytes / 176 H2 entries; 154 cleanup
  rows under 120 labels, including stale duplicate rows and closed history.

## Changes

- Added a dated, evidence-backed simplification review to `docs/REFACTOR.md`.
  It defines 12 prioritized architecture/organization units, a protected keep
  set for strict and unsupported-route fallbacks, an eight-group verified
  deletion queue, target module boundaries, sequencing rules, and completion
  signals.
- Identified immediate cleanup candidates without deleting production code in
  this review: DFlash2 debug/reduced-block plumbing; rejected GGUF rolling slots,
  final-state fastpath, and AR stream prefill; PARO suffix row chunks; unrouted
  WMMA64 and unwrapped Laguna kernel bodies; post-decision llama-compat flag
  collapse; and one-off script consolidation.
- Removed three stale duplicate cleanup-table rows while keeping their newer,
  more complete entries.
- Repaired `tests/test_laguna_h8b_source_default.py`: the immutable H8B artifact
  still pins its historical REFACTOR hash, but the live kernel/source RED no
  longer hashes the entire mutable ledger. Current H8B ownership remains
  asserted semantically and through the immutable artifact.
