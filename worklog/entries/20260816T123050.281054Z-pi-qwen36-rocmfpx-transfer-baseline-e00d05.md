# Establish repaired Qwen3.6 transfer-campaign baseline

## Summary

Established fresh repaired-runtime c4/c8 baselines for the exact local
Qwen3.6-35B-A3B packed-PARO checkpoint before screening the five ranked
ROCmFPX-transfer ideas. Both native batches reproduce independent serial c1
generated tokens exactly. This is diagnostic evidence, not a retained
cross-format speed row: the checkpoint remains implementation-correct but
quality-traded relative to the local Q4_K_M baseline.
