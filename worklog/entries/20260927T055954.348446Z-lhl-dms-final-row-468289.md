# Keep final verified DMS row in place until commit

## Summary

After the final serial verification step, the accept-summary kernel does not
mutate target KV. Keep that final state in place rather than copying a snapshot
that full acceptance would immediately restore. Initial and intermediate
snapshots remain available for failure rollback and partial acceptance.

## Changes

- Add an optional final-row capture hook to the journal interface. DMS keeps
  the final KV state in place while still capturing resident hidden/recurrent
  state. Other journals retain their existing capture behavior.
- Reject additional capture after the final-row marker. Clear the marker at
  cycle start, rollback, and retirement. No arithmetic or kernel changes.
- Add regression tests using the INT8 host-backed DMS store with eviction:
  full acceptance, partial acceptance, explicit rollback, and close with an
  open cycle all preserve the expected exact state.
