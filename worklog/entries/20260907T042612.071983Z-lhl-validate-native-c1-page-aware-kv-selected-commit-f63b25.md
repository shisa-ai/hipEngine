# Validate native C1 page-aware KV selected commit

## Summary

Add independent logical-to-physical BF16 KV ownership checks to the native C1
commit diagnostic. All 70 GPU calls pass across ten prompts; no public-path promotion.

## Changes

- New `scripts/qwen38_packed_c1_kv.py` computes per-logical-row addresses from
  resident allocation block IDs/chunk origin or private resident slot stride,
  and packed slot-major page IDs. Does not call runtime copy planners.
- Hash old live rows before/after commit and compare each newly committed row
  to its CPU-selected packed source. Validate destination pointer/size and page
  ownership. Ignore uncommitted speculative suffix. BF16 storage only.
- Extend `--check-commit` with the KV check and per-call record.
