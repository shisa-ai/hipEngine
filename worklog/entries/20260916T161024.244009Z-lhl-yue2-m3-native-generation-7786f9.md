# YuE2 M3 native generation session

## Summary

M3 turns the M2 AR runtime into a staged, torch-free generation session and
gates it against free reference generations.

`hipengine/runtime/yue2_session.py` is the new orchestration layer: it owns the
ABC and semantic loops, request-local random streams, CFG branch assembly,
phase masks, EOS/budget truncation, cancellation, and JSON round-trips of the
plan/result types. `scripts/yue2_session_gate.py` then replays three greedy
reference trajectories - generated at temperature zero by the new
`scripts/yue2_oracle.py greedy` command - through the torch-free session and
reports token agreement, first divergence, prefix identity, and truncation
class per case.

Greedy decoding is RNG-free, so this gate isolates prompt assembly, masking,
penalties, CFG arithmetic, and loop control from sampling noise: agreement is a
rate only because the HIP kernels are not bit-identical to the reference.

## Changes

- `hipengine/runtime/yue2_session.py` (new): `Yue2ArSession` with `plan`,
  `generate_semantic`, `run`, `reset`, `close`; `SymbolicPlan` and
  `SemanticResult` dataclasses with validated `save`/`load` JSON round-trips;
  `generate_tokens`, the reference-order decode loop (CFG combine, mask,
  penalty, temperature, top-k/top-p, greedy/temperature-0 path, EOS, budget
  truncation, cancellation, `on_token`). Each phase resets the runtime first and
  draws from its own request-local stream, so a cancelled or failed request
  cannot leak into the next one.
- `hipengine/runtime/yue2_ar.py`: `context_length(branch)` accessor (the next
  append position of a branch) used by the session's decode bookkeeping.
- `scripts/yue2_oracle.py`: `greedy` command (free AR generation at temperature
  zero, AR stages only - no NAR/VAE, so the fixture is cheap to regenerate) plus
  a fail-closed `_check_greedy` validator branch and the `greedy` fixture
  family.
- `tests/fixtures/yue2/greedy/`: three cases - `english-melody-s1234`,
  `english-full-s1234`, `mandarin-off-s1234` - covering the symbolic (melody,
  full) and `off`/`legacy_off` paths, a CFG scale of 1.01 with a negative
  branch, a naturally terminated ABC phase, and a budget-truncated semantic
  phase. Regenerated fixtures are validated against the integrity index.
- `tests/test_unit_yue2_session.py` (new): 22 CPU tests over a deterministic
  fake runtime - EOS/budget exits, callback visibility, minimum-length masking,
  phase masks, semantic-domain masking, CFG combination order, seed replay and
  divergence, independent phase streams, cancellation before prefill and mid
  loop, argument validation, plan/result round-trips through disk, session
  reset, a no-torch-import guard, and the reload checks that reject a plan whose
  IDs leave the token domains, whose prefix does not embed its own ABC IDs, or
  which claims a symbolic stage in `off` mode, plus a semantic result carrying
  real-vocabulary tokens instead of raw codec IDs.
- `scripts/yue2_session_gate.py` (new): same-host gate that replays the greedy
  fixtures through the session and emits
  `benchmarks/results/yue2_session_gate_20260916.json`.
- `tests/test_unit_yue2_fixtures.py`: `greedy` joins the stable fixture
  families covered by the fail-closed validator test.

## Validation

- `python3 -m pytest tests/test_unit_yue2_session.py` - 22 passed.
- `python3 -m pytest tests/test_unit_yue2_fixtures.py` - 11 passed (including
  the corrupted-tree negative cases and the new `greedy` family).
- `python3 scripts/yue2_oracle.py --compact tests/fixtures/yue2 validate` -
  "fixture tree is intact" after re-freezing the integrity index.
- `python3 scripts/yue2_session_gate.py --json
  benchmarks/results/yue2_session_gate_20260916.json` on gfx1151 (Radeon 8060S,
  the same host that produced the oracle fixtures) - see Numbers. The gate was
  run twice end to end (before and after the provenance block was added) and the
  two runs agree on every recorded quantity: identical assembled prefixes,
  identical agreement counts and ratios, identical first-divergence steps, and
  identical mismatch gaps, so the gate is repeatable on this host. The unassisted
  wall clock moved 35.2/36.3/29.3 s -> 34.8/36.7/29.0 s between the two runs and
  is quoted as a diagnostic only.

## Numbers

Greedy trajectory gate, gfx1151 / Radeon 8060S, same host as the oracle
fixtures, torch-free HIP runtime vs pinned torch oracle. `Forced` drives the
runtime along the reference's tokens so both sides score the same context at
every step; `free` is the unassisted session. The semantic phase is
budget-truncated in every case; the ABC phase ends naturally for the two
symbolic cases.

| Case | Prefix | ABC forced | Semantic forced | Free first divergence |
| --- | --- | ---: | ---: | ---: |
| english-melody-s1234 | identical | 100.0% (581/581) | 96.9% (496/512) | 38 |
| english-full-s1234 | identical | 99.1% (649/655) | 97.9% (501/512) | 18 |
| mandarin-off-s1234 | identical | no ABC stage | 96.1% (492/512) | 17 |

First-mismatch attribution at the first forced disagreement: `gap` is how far
the reference's own token scored below my top-1 (the quantity that matters),
and `top-1 margin` is my own confidence at that step.

| Case | ABC | Semantic |
| --- | --- | --- |
| english-melody-s1234 | no mismatch | step 38, gap 1.25e-01, top-1 margin 1.25e-01 |
| english-full-s1234 | step 128, gap 3.55e-02, top-1 margin 3.55e-02 | step 12, gap 1.25e-01, top-1 margin 1.25e-01 |
| mandarin-off-s1234 | no mismatch | step 17, gap 6.25e-02, top-1 margin 6.25e-02 |

The free semantic comparison is context-aligned only where the ABC stage itself
matched (`english-melody-s1234`, whose ABC trajectory is identical) or is absent
(`mandarin-off-s1234`); `english-full-s1234`'s ABC trajectory diverged, so its free
semantic row compares continuations of different prefixes and is diagnostic only.

Unassisted session wall clock: `english-melody-s1234` 34.8 s, `english-full-s1234` 36.7 s, `mandarin-off-s1234` 29.0 s (diagnostic; no same-protocol baseline is claimed here).
