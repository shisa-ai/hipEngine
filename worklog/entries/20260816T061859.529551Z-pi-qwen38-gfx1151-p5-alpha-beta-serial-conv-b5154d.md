# Retain gfx1151 serial alpha beta plus Conv

## Summary

Retain an exact gfx1151 rows1 mixed grid for dense-F32 alpha/beta plus the
independent in-place Conv channel blocks. The active 4K trace removes **48
launches/token (774 -> 726)**, improves the operation span **0.85271 -> 0.65549
ms/token (-23.128%)**, selected kernel wall **-0.096%**, and profiled host decode
**-0.173%**. Counterbalanced 512/128 graph AR improves **12.28434 -> 12.30966
tok/s (+0.206%)** with exact outputs/state/logits, unchanged peaks, and no bytes.

## Changes

- Generalized the retained alpha/beta plus snapshot-Conv body with a compile-time
  snapshot policy, preserving the old verifier specialization and adding one
  rows1 in-place serial entry point.
- Registered `linear_attn_alpha_beta+conv_decode/f32/
  bf16_k5120_n48_c10240_k4_c1`, aliased it into gfx1151, and admitted only
  `(1, 5120, 48, 10240, 4)` through backend capability data.
- Added a fail-closed runtime resolver that requires both dense-F32 weights, the
  exact shape, backend registry key, and capability. Every miss retains the
  dense-F32 pair plus ordinary Conv; no backend or quant branch enters engine or
  model code.
- Added RED/GREEN wrapper, registration, capability, routing/fallback, rows1
  GPU-bit, state, and CPU KL/top-1 tests; published the compact artifact and
  updated campaign, kernel catalog, benchmark rollup, and changelog.
