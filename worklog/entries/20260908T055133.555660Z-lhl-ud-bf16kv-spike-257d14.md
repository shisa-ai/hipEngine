# First spike on matched-KV rate-limiter precision divergence

## Summary

The user authorized a bounded first spike and requested a handoff if it did
not yield a clear correction. This spike found a strong causal lead but no
production correction: substituting only teacher incoming recurrent state at
K_M rate-limiter step 1 reduces KL from 0.030410558805 to 0.000223932315
(99.2636% reduction). Convolution-history substitution alone worsens the row.
The regression control worsens under teacher-state substitution, so this is
not a general corrective candidate. Production code/defaults are unchanged.

Follows [the output-margin diagnostic](20260908T024558.203885Z-lhl-ud-rate-limiter-row-83722b.md).
Primary-coder handoff is the intended stopping point for this unit.

### Causal state intervention

After replaying each HIP prefix, the diagnostic restores the captured own
incoming recurrent/convolution buffers at the selected position and replaces
one family or both with the teacher's corresponding incoming state. All 48
linear-attention layers participate. Prefix KV remains HIP's; only the current
KV slots are overwritten during re-execution. An own-state repeat after all
interventions must reproduce the original full logits bitwise, and does so
on both prompts. Private-position rewind is confined to this diagnostic script.

| Incoming state used | Rate-limiter step 1 KL | general_en_plan step 2 KL |
| --- | --- | --- |
| Original HIP state | 0.030410558805 | 0.000436148795 |
| Teacher recurrent state only | 0.000223932315 | 0.000819110840 |
| Teacher convolution history only | 0.047395647475 | 0.000699639634 |
| Both teacher state families | 0.001789566343 | 0.001247894246 |
| Original state restored | 0.030410558805 | 0.000436148795 |

All these rows retain teacher top-1. The recurrent-only intervention changes
rate-limiter's logit(` and`)−logit(`<|im_end|>`) margin from
3.187547684 to 2.312490463, versus teacher
2.240633011. This isolates substantial sensitivity to carried
recurrent state for the target. It does not prove a particular update is
incorrect or that importing teacher states is an implementable correction.
The convolution-only and control results demonstrate interacting numerical
errors; do not generalize a one-row improvement into a default change.

### Same-input arithmetic checks

Teacher state storage is `[head,value,key]`, while HIP is `[head,key,value]`.
This comes from the pinned teacher `gated_delta_net.cu` and in-tree GDN
indexing. The initial local replay omitted this transpose and failed; fixing
the diagnostic layout, without changing either engine, yields:

- Teacher-input F64 GDN replay, 288 rows: maximum core relative RMS
  1.46525558e-07, gated-output 2.04065696e-07.
- HIP-input convolution replay, 288 rows: max relative RMS
  5.42718135e-08.
- HIP-input GDN gated-output replay: max relative RMS
  1.70769029e-05; next-state replay on 192 transitions:
  3.77117342e-05 maximum. Alpha/beta outputs were not captured;
  this reference reconstructs decoded-weight F64 projections followed by BF16
  rounding. The largest discrepancy is rate-limiter step 1, layer 41. GPU
  reduction order and the stored A-log roundtrip are not emulated, so this
  small discrepancy does not establish a kernel fault.
- All 384 HIP residual additions match their BF16 reference exactly.
  Post-attention norm matches exactly on 373 rows; max relative RMS
  is 0.000240246793. Remaining differences are compatible with reduction/rounding
  effects; this is a diagnostic check, not a strict-byte parity certification.

Matched-teacher layer data puts rate-limiter step 1 layer-output relative RMS
at 0.056769325 after layer 26 and 0.102858885 after full-attention layer 27. Incoming
state drift is already present at earlier layers/steps. These boundaries are
useful places to inspect, not proven faulty layers. For example, layer 49's
local GDN output relative RMS is 0.315746635; substituting only HIP state
into otherwise identical teacher inputs produces 0.266096670. Local state
sensitivity cannot be added across layers or interpreted as a KL percentage.
