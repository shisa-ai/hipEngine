# Carry Q8T16 broad rowtile as an explicit packed invocation input

## Summary

Commit `f9c747ae0` scoped the production floor to the packed-AR route, but a
bound owner's route read still consulted the process-global
`q8_t16_rowtile_all_session` value. That left implicit mutable owner transport:
another runner's packed scope could retarget a production verifier, native-row
or prefill call.

This checkpoint replaces the session read with an explicit invocation input.
The packed step resolves `_q8_t16_rowtile_all_owner_for_packed_rows(rows)` once
and passes the resulting `bool` into
`_run_linear_attention_decode_slot_rows_exact` (and its indexed/scalar
fallbacks) and `_run_full_attention_decode_batch_layer_rows` (and its
decode-batch selector plan and output projection). The FFN row path carries the
same value through `_run_post_attention_ffn_rows` →
`run_post_attention_ffn_rows` / `run_post_attention_moe_rows` →
`ops.moe_rows_compact_wmma`.

`_q8_t16_rowtile_all_owner_for_rows(rows)` now returns the outside-packed
default only: `False` for a bound owner, `None` for an unbound owner. It never
reads the session. The `q8_t16_rowtile_all_session` context manager remains only
as the unbound fallback; the packed step sets it to the floor only when the
owner is unbound, and leaves it inactive for a bound owner. An omitted
invocation input resolves the outside default; an explicit `True`/`False` from
the packed step is carried unchanged. No new global, ContextVar or ambient scope
was added.

The pair-specific package floor is unchanged: the packed step still sets
`q8_t16_pair_rowtile_min_rows_session`, and the pair planner checks it before
the broad policy.

## Changes

- `runtime/gguf_linear.py`: removed the `q8_t16_rowtile_all_session_value`
  getter; the session is no longer exposed as a bound-owner input.
- `runtime/qwen35_gguf_runner.py`: `_q8_t16_rowtile_all_owner_for_rows` is the
  outside-packed default; `_owner_rowtile_all(runner, rows, requested)` resolves
  an explicit invocation input or the outside default. The packed step resolves
  the floor once and passes `q8_t16_rowtile_all` into the linear-attention slot
  rows, full-attention decode batch, output projection and FFN row seams. The
  linear indexed/alpha-beta/norm/attn-only, full output, and FFN compact-WMMA
  seams accept and propagate the value. The session is set only for an unbound
  owner.
- `runtime/qwen35_gguf_layer_ffn.py`: `run_post_attention_ffn_rows`,
  `run_post_attention_moe_rows` and the `moe_rows_compact_wmma` call accept and
  carry `q8_t16_rowtile_all`.
- Tests: `test_unit_qwen35_moe_owner_transport.py` adds the two-production-
  runner interleaving case (A's legacy session active; B's verifier/prefill/
  native defaults stay `False`; strict stays `False`; A's packed invocation
  stays explicit `True`; unbound stays `None`), the route-scoping case, and an
  actual per-call selector test at `_run_attention_norm_rows`.
  `test_unit_qwen35_gguf_full_attention_decode_batch.py` asserts the explicit
  packed input reaches the actual decode-batch selector plan.

## Public failure and repair

The first live public paired comparison
(`/tmp/r0137-moe-paired-strict-production.json`) failed on AR width 4. The
failure was an implementation defect, not an output mismatch:
`_run_linear_attention_attn_rows_indexed_exact` was called with
`q8_t16_rowtile_all=...`, but its real method signature did not declare the
keyword, and its body referenced the resulting undefined local name. The
unit tests missed it because the transport test patched a permissive fake
`**kwargs` seam instead of binding the real method.

Repair, scoped to that one seam:

- `_run_linear_attention_attn_rows_indexed_exact` now declares
  `q8_t16_rowtile_all: bool | None = None` and resolves it at the method seam
  with `_owner_rowtile_all(self, rows, q8_t16_rowtile_all)` before the first
  leaf call. An explicit packed value is carried unchanged; an omitted input
  resolves the outside-packed owner default (`False` bound, `None` unbound).
- RED regression `test_indexed_linear_attention_seam_carries_invocation_input`
  invokes the real indexed method with an instance-patched leaf at
  `_run_attention_norm_rows`, and asserts the explicit `True` reaches it and an
  omitted call resolves `False`. Before the repair it failed with
  `TypeError: ... got an unexpected keyword argument 'q8_t16_rowtile_all'`.
- Contract check `test_rowtile_seams_accept_the_keyword_on_real_signatures`
  binds `q8_t16_rowtile_all` (and the triple launch's `rowtile_all`) with
  `inspect.signature(...).bind_partial` on every real seam callable. It failed
  on the same method before the repair.
- Audit of all 62 `q8_t16_rowtile_all` / `rowtile_all` call sites in
  `qwen35_gguf_runner.py`, `qwen35_gguf_layer_ffn.py` and `gguf_linear.py`:
  every keyword set binds against the resolved real callable signature
  (module functions, runner methods, layer-FFN entry points, selector
  dataclasses, and the `ops.moe_rows_compact_wmma` real target). No remaining
  seam relies on a permissive `**kwargs`.
