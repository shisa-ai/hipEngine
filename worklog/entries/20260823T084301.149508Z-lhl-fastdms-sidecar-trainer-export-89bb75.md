# Train and export external DMS sidecars

## Summary

Added a deterministic offline PyTorch trainer/exporter for the external linear
DMS sidecar. Only the 327,744 sidecar parameters are trainable for the real
Qwen3.8 geometry; no base-model weight, gradient, or optimizer state is loaded.

## Changes

- Streams verified label shards, reconstructs exact BF16 hidden rows, and trains
  per-compact-layer/per-KV-head logits with BCE plus a compression-budget
  penalty on eligible rows only.
- Uses deterministic epoch/shard/token ordering, deterministic PyTorch
  algorithms, clipped gradients, and sidecar-only AdamW state.
- Adds resumable identity-bound checkpoints that reject changed label hashes,
  geometry, seeds, or optimizer/training configuration.
- Reports validation BCE/accuracy/precision/recall and predicted/label eviction
  rates globally and by layer/head, category, and context bucket.
- Exports byte-stable BF16 safetensors with canonical `weight`/`bias` tensors,
  strict schema-v2 metadata, model/sidecar/data/trainer/FastDMS hashes, and a
  compact training summary. No raw capture or model artifact enters Git.
- Updated `KVCACHE.md` with the trainer/optimizer ownership contract.

## Validation

- RED: the trainer test failed collection before the offline script existed.
- Two focused system-PyTorch tests pass: identical-seed runs reduce loss,
  produce byte-identical sidecars, pass the strict schema-v2 loader, expose all
  validation slices, and resume from epoch 2 to epoch 4 with matching identity.
- Fixture validation accuracy reaches 97.27%; the first-to-final train loss falls
  `0.53159 -> 0.06656`.
- Exact Qwen3.8 shape smoke on gfx1151 trains `[16,4,5120]` plus `[16,4]` in
  1.512 seconds with 327,744 model/optimizer parameters, 655,490 optimizer-state
  elements, and 165,984,256 peak PyTorch bytes. Export is 655,640 bytes,
  sidecar SHA-256
  `9eb6dce767c5aa8198a8149d218dcfbcd505c79ac097770a0f2c265fd892b50e`.
- The exact model and physical layer map pass the strict loader; schema-v2
  fingerprint is
  `ca7e4f0a81ff09ec1fcc6e227191ad2e48760973c9cd002632f7084836985955`.
- This all-positive four-token mechanical fixture is explicitly not a real
  trained candidate or quality result. Its source tree was intentionally dirty
  and its recorded `a205029d...` trainer commit predates this unit; retained
