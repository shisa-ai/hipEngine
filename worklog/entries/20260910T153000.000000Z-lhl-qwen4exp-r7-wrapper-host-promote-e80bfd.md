# R7 wrapper-host route: first decode TG promotion since R2e

## Summary

R7 wrapper-host route: first decode TG promotion since R2e, out of the
two routes left open by R10's measured result.
## Arc

R10's measured result left two decode routes: kernel efficiency (R11 GEMV
pair - closed, rejected at gates) or wrapper host work. R7 ran the
wrapper-host screen to attribution:

1. **API-trace screen** (`18076ed3d`): rocprofv3 hip-api trace around 64
   decode steps. Serving path already uses device-argmax
   (`capture_logits=False` + `token_id_resident=True`); blocking hipMemcpy
   durations are stream-wait dominated, not host cost; per-step surface
   447 kernel launches + 20 graph launches + ~15 copies.

2. **Mechanism identification** (`0c50bc876`): Python-boundary probe with
   traceback. 24 x 8-byte blocking H2D per step (median 23.1us, ~0.55ms
   genuine + overlap loss), all from
   `Qwen4ExpAttentionDeviceState.set_position` called per QSA layer
   (12 layers x position+context, unique state indices - no call-site dedup
   possible). All 24 carry the same value; position advances by 1/step.

3. **Gated candidate** (`82edb5cfd`): shared interleaved [position,context]
   int64 region (192B); `step()` prepares all 12 states with ONE H2D and
   passes `position_prepared=True` (pre-existing mechanism flag) so per-layer
   `set_position` is skipped. Gates: bit-exact (identical token digest, all
   fixture cases, 3 reps/arm); TG A/B median -0.77ms/token (~1.3%); copy
   surface 27 -> 4. Prefill paths unchanged (set_position on views is
   per-slice correct).

4. **Promotion** (`b7e9f19b9`): default ON, opt-out `=0`. First profile
   change since the R2e seven-promotion state.

5. **Post-promotion retention v7** (`e3a13c610`): fresh three-engine packet
   at the promoted default. hipEngine TG 19.70/19.26/18.48 ->
   20.02/19.53/19.14 tok/s (+1.6/+1.4/+3.6%). Packet hipEngine PP dropped
   at p1024/p4096 (-5.8/-9.1%) - discriminated as environmental by a direct
   interleaved same-process PP A/B (all deltas within +/-0.85%, median
   ~0.1%) and comparator corroboration (halo-box-hip, untouched binary,
   dropped PP simultaneously with 21% CV; vulkan stable). halo-box-hip noisy
   PP window recorded as packet caveat.
