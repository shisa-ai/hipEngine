# Close Qwen4Exp P0 PLE cache modes

## Summary

Closed the last P0 checklist item with explicit file-scoped warm and isolated
cold PLE modes. Cold never drops global caches or evicts unrelated weights.

## Changes

- Added compact warm/cold artifact and campaign/changelog evidence.
- Warm benchmark mode advises once and uses request warmup.
- Cold closes/remaps the PLE mapping and applies DONTNEED to exactly the tensor
  offset/length before every warmup/measured request.

## Validation

An initial advice-only run was neutral, correctly treated as unproven because a
live mapping retained cache reuse. After remap repair, matched code-p512 is
**91.676 warm vs 56.214 cold pp/s**, cold/warm **0.613x**. Both arms have three
stable measured samples, deterministic equal output hashes, recorded successful
file/mapping advice, and zero teardown. The PLE range is offset 682,453,280,
length 28,800,138,240 bytes in GGUF part 2.
