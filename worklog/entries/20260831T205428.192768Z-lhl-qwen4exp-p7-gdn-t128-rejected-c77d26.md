# Reject Qwen4Exp GDN t128 decode

## Summary

Rejected and removed an exact t128 GDN decode sibling. Threads 128-255 only
contribute zeros at production 128x128 heads, but skipping that reduction half
does not improve the memory-dominated recurrence.

## Changes

- Candidate kernel/wrapper/selector/test removed before commit.
- Added rejection artifact and campaign/changelog decision.

## Validation

Output and recurrent state are array-exact. Thirty cached samples measure
strict **0.06633 ms** versus t128 **0.06754 ms (0.982x)**, with a worse tail.

## Next

P7 requires persistent transposed-state ownership and one-time Q/K
normalization; do not continue thread-count tuning.
