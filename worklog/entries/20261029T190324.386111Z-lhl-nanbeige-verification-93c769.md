# Nanbeige completed-answer and context verification

## Summary

Verify the repaired dense Llama route on zbook / Radeon 8060S gfx1151 with
Nanbeige 4.3 33B FP8 snapshot `0140c157bc44507929a742c220865b0870052552`.
Weights execute as resident BF16 with BF16 KV. Verification exposed a template
rendering defect and a missing attention-kernel barrier; both are repaired without
changing the intended arithmetic or defaults. Timings are diagnostic, not a
promotion claim.

## Changes

- Add `scripts/llama_dense_verify.py`: public `LLM.generate_detailed` calls in
  default and strict modes, two repeats, context 8704 and output cap 256.
  Thinking is explicitly disabled to test completed answers rather than a
  truncated reasoning prefix. Record exact input/output IDs, full answer text,
  finish reason, finite-logit checks and per-step logit hashes.
- Fixed before execution: arithmetic, Python function, Japanese capital, and
  unified-memory explanation prompts; retrieval at 1023, 1025, 4097 and 8193
  input tokens, with a fixed access code in the middle. No capacity search.
- Pass checks: all calls finish with stop, required content appears where
  specified, same-mode repeats have identical IDs and logits. Cross-mode ID
  equality is diagnostic, not a rejection criterion. Human inspection still
  owns explanation/code quality; substring checks alone do not establish it.
- Timing wraps actual runner calls reached by public generation, synchronizing
  before/after each. Model loading and one short warmup per profile are outside
  timing; first long-shape scratch allocation is included. Decode spans exclude
  sampling/host overhead and count generated IDs minus one. These are not
  end-to-end serving throughput claims or a calibrated numerical envelope.

## Validation

  revision `8f497e0992fb7513f7f78a6f6b6f1056c375e961`.
- `uv run pytest tests/test_unit_llama_dense_verify.py -q --tb=short`: passed.
  Tests check exact context lengths, retrieval-key placement, decode accounting,
  finite-logit rejection and restoration of instrumented methods on failure.
- Run: `uv run python scripts/llama_dense_verify.py --model
  "$HOME/.cache/huggingface/hub/models--primitive-ai--Nanbeige4.3-33B-FP8/snapshots/0140c157bc44507929a742c220865b0870052552"
