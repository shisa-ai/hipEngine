# Reject production Q4 R36 fused rowtiles

## Summary

Rejected and removed the production-profile Q4 C8 active-R32/padded-R36 fused
rowtile composition. It passes the complete numerical gate and wins C5-C7, but
loses C8 by 3.63% in both process orders and fails every C8 performance scope.

## Changes

- Removed gfx1100 R32/R36 production-Q4 capabilities and candidate-specific
  dispatch/evaluator tests; the package no longer responds to the existing
  production-Q4 selector for this backend.
- Restored the numerical evaluator and its tests to their pre-candidate gfx1151
  scope. Fused WMMA remains the unchanged gfx1100 owner and strict fallback.
- Preserved the passing intermediate numerical capture and compact final
  rejection artifact; updated the kernel catalog and benchmark changelog.

## Validation

- Actual layer-0 R36 K5120/N17408 leaf: **1.411936 ms** fused WMMA versus
  **0.949660 ms** 8/8/8/8/4 rowtiles (**1.4868x**); BF16 max/p99 delta
  **0.0009766/0.0000610**.
- Tracked-clean C8/K3 R32 full-vocabulary T2 gate: 240 rows, three deterministic
  repeats, mean/p99/max KL **0.0000708/0.000665/0.002777**, top-1 **239/240**;
  all category/shape/transition scopes and teardown pass.
- Tracked-clean commit `1e4f492da`, complete C5-C8 category+heldout product
  suite, process order candidate/rollback/rollback/candidate: pooled deltas
  **+1.02%/+0.44%/+0.38%/−3.63%**.
- Both C8 process-order pairs lose (**−3.66%/−3.60%**); C8 categories and
  heldout lose **2.57–4.03%**. All four packets pass, all 520 cross-arm
  generated rows match, every cell engages/conforms, and every process drains.
  Acceptance counts differ on some T2 cells and remain diagnostic.
