# Freeze Qwen3.6-27B four-shape memory baseline

## Summary

Froze the package-default Qwen3.6-27B sole-T16 RX 7900 XTX baseline across 512/128, 1K/128, 4K/128, and a fresh 8K/128 row. Current hipEngine tracked/whole-device peaks are 15.605/16.095, 15.720/16.320, 16.368/17.119, and 16.626/17.382 GiB. The lower clean llama.cpp memory floors are 15.690, 15.700, 15.912, and 16.166 GiB, leaving hipEngine gaps of 0.406/0.621/1.206/1.216 GiB.

The growth is not one leak. From 512 to 4K, liveness-aliased prefill session buffers add 0.541 GiB while BF16 full-attention KV adds 0.219 GiB. From 4K to 8K, the 4096-row prefill arena is effectively capped: 0.250 of 0.258 GiB tracked growth is expected BF16 KV. Fixed sole-T16 weights remain 15.280 GiB. Whole-device peak exceeds tracked ownership by about 0.49/0.60/0.75/0.76 GiB and still needs allocator/library attribution.
