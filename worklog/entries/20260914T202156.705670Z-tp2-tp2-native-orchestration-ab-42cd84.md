# A/B the staged exchange's native orchestration against the Python loop

## Summary

The bounded native experiment the review asked for is done, and it changes the
transport verdict. Driving the identical batched protocol from a native C++ loop
costs **20.8 us per reduction against the Python loop's 40.9 us, a 1.97x
reduction in transport cost**, with the chain's dependency verified exactly at
every timed depth. The 0% fixed-share projection moves from 1.18x to **1.33x**,
which clears the design's 1.3x target, and the native arm is within the break-even
budget in every row. The measurement also confirms the review's warning about
phase transferability: the exposed wait *grows* in native code.

## Changes

- `benchmarks/micro/runners/hip_staged_exchange.hip` — standalone native runner for
  the exact batched protocol: both device-to-host copies submitted before either
  stream is waited on, two host waits per reduction, host sum written back to both
  slots, both return copies submitted with no wait, one drain per chain.
  Preallocated device buffers, pinned host slots and sum scratch; one
  `hipSetDevice` per operation instead of the Python runtime's get/set/restore.
  Its untimed pass verifies the chain with a bounded recurrence
  (`sum / world + 1`, expected `6 * (j + 1) + depth`) over the whole vector at the
  same depth it times, and exits non-zero if the check is not exact.
- `scripts/tp_staged_exchange_native_ab.py` — driver that builds the runner, runs
  the same depth ladder and payload as the Python arm, computes the same ladder
  slope, and reports both arms plus the term-by-term phase comparison. Refuses to
  compile when `--require-cached` is set, so a profiled run cannot build inside
  the profiler.
- `scripts/tp_break_even.py` — new `native_staged_exchange_batched` mode read from
  the A/B artifact by `read_native_ab_marginal`, which rejects any artifact whose
  timed depths did not verify their chain. The chain-artifact reader refuses this
  mode, so the native marginal cannot be sourced from the wrong file.
- Tests: `tests/test_unit_scripts_tp_staged_exchange_native_ab.py` (ladder math,
  runner parsing, failure reporting, cache refusal, and a source check that the
  protocol's completion boundaries are still present) plus native-artifact reader
  cases in `tests/test_unit_scripts_tp_break_even.py`.
- Rollup, changelog and campaign doc updated with the new row and the corrected
  claims.

## Validation

- Command: `uv run python3 scripts/tp_staged_exchange_native_ab.py --json
  benchmarks/results/2026-09-14-w7900-tp2-staged-exchange-native-ab.json` on the
  W7900 + XTX host, same session as the Python arm's artifact.
- Ladder (native, count 5120, 20 KB, iterations 30, warmup 10):
  d1 28.6 us, d4 107.2, d16 390.5, d32 710.3, d64 1377.8, d128 2673.5 us ->
  **20.83 us per step** against the Python arm's **40.95 us per step** (1.97x).
  Every depth reported `exact: true` for the bounded recurrence.
- Term comparison at depth 128 (us per reduction): device-to-host submit
  4.71 -> 1.66, device scoping 9.96 -> folded into the native submit, device-to-host
  wait **8.88 -> 14.95**, host-to-device submit 5.80 -> 1.89, device scoping
  5.83 -> folded, host sum 6.58 -> 2.01; accounted 41.95 -> 20.50 with 2.31 -> 0.31
  unaccounted against loop wall 44.26 -> 20.81.
- Projections from `tp2_break_even_native_staged_exchange.json`: 0% 1.326x,
  10% 1.238x, 20% 1.161x, 30% 1.093x; headroom 3.61x of the break-even budget at
  0% fixed share. Conditional, `certified: false`.
- `uv run pytest tests/test_unit_scripts_tp_staged_exchange_native_ab.py
  tests/test_unit_scripts_tp_break_even.py tests/test_unit_scripts_tp_collective_bench.py
  tests/test_integration_benchmark_readme_sync.py`: 140 passed.
  `scripts/sync_benchmark_readme.py --check`: synchronized.

## Not done

- The native runner is not engine code. It measures what the protocol costs when
  driven natively, not what `hipengine` does today; no serving path uses it yet.
- No TP1-versus-shard segment measurement, so the compute side of the break-even
  is still an assumption and the fixed-cost share is unmeasured.
- The native arm's 20.8 us is a transport cost, not a certified model-level win.
