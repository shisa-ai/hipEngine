# Isolate prefix benchmark engine loads in subprocesses

## Summary

R0075 is resolved by removing same-process engine reload from the prefix
benchmark, not by claiming a fix for the historical runtime reload fault.

## Changes

- Runs requiring multiple engine loads launch one subprocess per arm and merge
  artifacts in planned order. Single-mode in-process repetitions reuse one load.
- Preserve child exit failures, relative invocation paths and per-arm SSE output.
  Invalidate owned old arm artifacts before spawn; reject missing new output.
- Accept the retired multi-mode flag only with a notice; it cannot restore the
  unsafe path. Reject invalid repetition counts before loading.
- Replace test-only environment controls with explicit fixture configuration.

  tests/test_unit_prefix_cache_session_lane.py -q -o addopts=''`: 45 passed.
