# Bind benchmark provenance to host identity

## Summary

Made physical host identity part of canonical benchmark provenance so machines
with the same GPU architecture/device label cannot be conflated. This follows
the correction that the current production-numerics captures ran on `zbook`
and are independent of results from the other gfx1151 host.

## Changes

- Bumped newly collected canonical provenance to schema version 2 and added the
  required non-empty `host_name` field from `socket.gethostname()` (or an
  explicit collector override).
- Kept schema-version-1 validation and JSON-schema compatibility for historical
  artifacts; version 2 conditionally requires `host_name`.
- Added RED/GREEN collector and schema coverage with a deterministic host stub.

## Validation

- RED: focused provenance tests failed because `socket`/schema v2 did not yet
  exist.
- GREEN: `tests/test_benchmark_provenance.py` passes `8/8`.
- Compatibility bundle `tests/test_benchmark_matrix.py`,
  `tests/test_exact_token_benchmark.py`, and
  `tests/test_agentic_a5_pressure_soak_artifact.py` passes `14/14`.
- Python compilation and `git diff --check` pass.
