# Measure the TP1 segment breakdown the break-even projection assumes

## Summary

The second bounded experiment is the TP1 half of the segment measurement: a
rocprofv3 attribution of the decode step at the break-even's own protocol, on both
cards, replacing the projection's assumed fixed-cost share with measurement. The
result narrows the defensible part of the projection and names a term the model
omits.

Attention, GDN, sampler and copy kernels together are **1.578 ms/step (W7900) and
1.441 ms/step (XTX)** - 4.7% and 5.1% of each card's own token time, and 11.9% /
12.9% if every unnamed kernel is counted too. The projection swept 0-30% fixed
share; the 20% and 30% rows are above anything these measurements support. Weight
reads are **77% of the token time on both cards** (25.95 and 21.77 ms/step), and
their 1.19x cross-card ratio matches the cards' bandwidth ratio and their 1.20x
TP1 token-rate ratio, so the compute saving really is in the weight read.

The step also issues **~811 kernel launches**, and the trace shows 19.2 ms (W7900)
and 22.6 ms (XTX) of interior GPU gap per step, 15.3 and 16.2 ms of it with no HIP
API in flight. That is larger than every kernel family except the weight reads. It
is recorded as a *candidate* missing term rather than as the projection's host
cost, because this harness reads back every token (about 9 ms/step of hipMemcpy
API time) and the tok/s protocol amortizes that readback.

## Validation

- Command: `HIP_VISIBLE_DEVICES=<0|1> uv run python3
  scripts/gguf_c1_decode_attribution.py --prompt-rows 512 --decode-tokens 128
  --json ...` on the W7900 + XTX host. Cache was prebuilt outside the profiler
  (the warmup child) after the first attempt failed with a missing
  `gguf_t16_selected_gemv` artifact under `require_cached`.
- W7900: 127 measured steps, 811.7 launches/step, duty cycle 0.446, q4_k GEMV
  18.753 ms/step, q6_k GEMV 7.201, other 2.460, GDN 0.961, paged attention 0.598.
- XTX: 127 measured steps, 811.4 launches/step, q4_k GEMV 15.550 ms/step, q6_k
  GEMV 6.223, other 2.195, GDN 0.876, paged attention 0.548. Re-recorded after the
  device-identity fix; `observed_device` now reads `AMD Radeon RX 7900 XTX`.
- `uv run pytest tests/test_unit_gguf_c1_decode_attribution.py`: 40 passed.
