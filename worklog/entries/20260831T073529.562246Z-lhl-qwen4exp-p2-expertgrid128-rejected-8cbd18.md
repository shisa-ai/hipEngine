# Reject Qwen4Exp P2 expert-grid128

## Summary

Implemented and rejected an exact P2 mechanism that doubled the fixed expert
worker grid from 64 to 128 CTAs for the incumbent Q4 grouped gate/up and Q5_1
grouped down kernels. All outputs are BF16-bit exact, but combined and isolated
whole-model A/Bs are neutral or negative. The implementation and selector were
removed; expertgrid64 remains unchanged.

## Changes

- Temporarily added exact grid128 Q4 and Q5_1 HIP exports, wrappers, registry
  variants, and runner selectors for combined/Q4-only/Q5_1-only screens.
- Extended the existing Q4/Q5_1 GPU RED tests to require bit equality against
  strict and grid64 outputs.
- Removed all candidate code after the whole-model decision.
- Added compact rejection artifact
  `benchmarks/results/2026-08-31-gfx1151-qwen38-flash-next-p2-expertgrid128-rejected.json`
  and updated the campaign/changelog.

## Validation

- `uv run pytest -q tests/test_gguf_q4_k_selected_wmma_prefill.py tests/test_qwen4_exp_q5_1_selected.py`
  passed 20 tests with the candidate present; grid128 BF16 payloads equal the
  strict/grid64 owners.
- Same-residency p508, one warmup and five counterbalanced pairs per mode:
  - both Q4+Q5_1 grid128: ratio mean `1.001602`, 95% CI
    `[0.999321, 1.003884]`;
  - Q4-only: `1.002557`, `[0.998088, 1.007026]`;
  - Q5_1-only: `0.998066`, `[0.995000, 1.001132]`.
  Every mode shares the exact grid64 logits hash; no mode is a retainable win.
- One Q4-only diagnostic trace moves the early-Q4 bucket
  `922.458→919.830 ms` (-2.628 ms), but the separate-window complete kernel sum
  regresses `5569.886→5617.171 ms`; paired wall remains binding.
- Raw paired JSON/log and candidate trace CSV/analysis hashes are retained in
  the compact artifact.
- Candidate source, wrappers, selector, and test additions were removed before
  this decision commit; focused incumbent tests remain green from the prior
  baseline.

## Next

- More expert worker CTAs do not improve data reuse. The next P2 mechanism must
  change per-CTA reuse or output ownership—e.g. association-preserving output
  tiling across the measured multi-row expert groups—rather than only changing
  the Y-grid worker count.
