# Evaluate safe adaptive gfx1151 MTP budgets

## Summary

Completed `OI-2` on Radeon 8060S/gfx1151. The variable-budget transaction seam
is retained: one request can switch among independent B1/B2/B3 proposal and
target buckets at committed cycle boundaries without padded rows, stale state,
or ownership drift. The full transition schedule exercises all nine directed
edges; B1 covers reject/full, B2 reject/partial/full, and B3 reject/all partials/
full. Every generated trajectory and GPU/CPU acceptance decision is exact and
teardown returns to zero.

The first content-agnostic EMA controller is rejected and stays default-off. It
uses only per-depth conditional acceptance and complete per-budget cycle wall,
with bounded B1/B2/B3 exploration and 2% hysteresis. Primary adaptive is
**21.088624 tok/s** versus fixed B3 **21.211101 (-0.577%)**; train is -1.047%,
code -3.916%, and general English -7.769% versus each scope's best fixed
budget. Matched repeat is **20.831629 versus B3 21.197092 (-1.724%)**. Budget
choices, acceptance, and token IDs repeat exactly, so this is an economics
rejection, not a control/determinism failure.
