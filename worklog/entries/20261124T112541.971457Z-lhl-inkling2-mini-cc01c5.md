# Isolate the resident block error to the controller blend

## Summary

At the loop re-entry every input the block feeds its attention is bit-exact against the host: the two residual source rows, the attention query, the four messages and the restored hidden state. The branch output is nevertheless 3.379 off, and the controller blend is the only step at that visit with no host counterpart to compare against.

## Changes

- Instrumented the message visit to download its source rows, query, messages, branch output and hidden state, and captured the host's matching values through `_prepare_layer`.

## Validation

64 rows, fast profile, `hip_gfx1100`. Values at the loop re-entry:

| quantity | max abs vs host |
| --- | ---: |
| residual source row 0 | 1.907e-06 |
| residual source row 1 | 5.722e-06 |
| attention query | 0.000e+00 |
| four messages (query-major) | 9.537e-06 |
| restored hidden state | 6.104e-05 |
| branch output | 3.379e+00 |

- The message kernel writes query-major, not row-major. Comparing the block's `messages` as row-major reports 1.325e+01; as query-major it is 9.537e-06. The block's consumption offsets are query-major and correct.
- The arena is exactly the probe extent (17449984 bytes both) and the probe already accounts for the controller area, so sizing is not the defect.
- The resident layout is `[inputs][messages][weights]`, which matches `_controller_extent` and `_controller_kernels`; the weights offset `2 * len(plans) * rows * hidden` equals the staging size, and the blend's `raw + 2 * gate` scratch lands in the weights region after they are consumed.
- Two runs of the block in one process are bit-identical (0.000e+00 on the read, the branch and the source rows), so the block is deterministic within a process and the cross-process variation reported earlier is process state, not a race in the block.
- The reference capture ran with `stage_controllers` false and `resident_attention` present, so it used the same device kernels as the block rather than the host expression.
- The layer-7 branch does not compare: the host returns `h + branch` there, so its 2.285e+01 difference is the residual add and carries no information.
