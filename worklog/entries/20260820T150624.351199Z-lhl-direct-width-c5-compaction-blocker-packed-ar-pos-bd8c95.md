# Direct-width c5 compaction blocker (packed-AR position off-by-one)

## Summary

The direct-width lifecycle certification (reviewer #36) surfaced a genuine
blocker: **graph compaction/replay for direct physical width c5 fails with a
packed-AR position off-by-one**, so direct widths cannot yet pass the
lifecycle gate's graph-rebuild / row-permutation requirement and must NOT be
promoted (#29 blocked).

Command:
`HIPENGINE_GGUF_SHARED_SLOT_AR_PHYSICAL_WIDTHS=1,2,3,4,5,6,7,8
gguf_arbitrary_c_lifecycle.py --rows 5 --cancel-slots 1 3
--compact-after-middle-hole` → raises
`ValueError: packed AR positions (18, 20, 22) do not match session cursors (19, 21, 23)`
from `hipengine/runtime/qwen35_gguf_runner.py:19891`
(`step_batch_native` `positions` sanity check).

Every packed-AR expected position is exactly 1 behind the live session cursor,
uniformly across the 3 survivor rows. This is a stale-position capture/replay
bug on the compaction path for a direct (non-power-of-2) physical width, not a
numerical drift: the harness's steady-state (non-compaction) direct c5 run
passes every non-state gate (tokens exact, masks correct, declared-width-only,
no serial fallback, session reuse, cancellation finish, drain).

## Changes

- Committed direct-width certification infrastructure (env opt-in routing +
  harness width parameterization + c3 floor), commit `70669a4cb` and
  `897f6b9bc`.
- Added the width-set superset (1..8) but kept the advertised default
  (1,2,4,8) unchanged so the blocker does not affect production.
- No production default change: direct widths remain opt-in only.

## Validation

- Non-compaction direct c5 lifecycle (same env): tokens exact
  (`original_tokens_exact=True`, `newcomer_tokens_exact=True`), initial mask
  `['11111']` proves direct routing (not masked c8), hole/refill masks
  correct, `declared_widths_only=True`, `no_serial_fallback=True`,
  `session_reused=True`, `fallback_reasons={}`, drain clean. Only the known
  c1-vs-cN arithmetic state drift (`state_kv_accepted`) is non-binding without
  a requalification gate.
- Compaction direct c5: **fails** at the packed-AR position sanity check.
- Masked (1,2,4,8) compaction is the previously-certified canonical protocol
  and is unaffected (production default unchanged).
- Host-side unit tests for width resolver + direct-mask derivation pass.
