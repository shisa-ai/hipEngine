# Evaluate Qwen3.8 dense-27B native INT8 KV

## Summary

Close the campaign's independent Qwen3.8 K0-K3 lane below K4. Pure per-token/
head INT8, fixed tail-four Hadamard-group32, all-layer Hadamard-group32, and the
one immutable six-train-selected mixed map each fail a required native quality
shape. The final frozen map preserves 100% top-1 at native 1K/8 but rejects
because aggregate mean/max KL reaches **0.053384/5.173312** and `mixed_v1`
reaches **0.586860/5.173312**. The stop rule forbids reselecting from that
control or continuing to 4K. Temporary all-layer and model-specific frozen-map
runtime surfaces are removed; BF16 K/V remains the only supported campaign
route.

## Changes

- Began without a production change; pure INT8 and fixed tail-four reused
  existing native writers, prefill consumers, and decode consumers.
- Freeze K0 order as complete `512/8`, then `1024/8`, then `4096/16`; stop pure
  INT8 after any failed earlier shape because a later pass cannot erase it.
- Use a 32,786-token session capacity to bypass the historical <=8K diagnostic
  BF16 mirrors, force zero BF16 full-attention layers, and require all 16 layers
  to be native INT8 with zero mirror/oracle buffers after execution.
- Compare against same-model BF16 K/V with teacher-forced reference tokens.
  Require finite logits, mean KL <=0.05, minimum per-prompt top-1 >=90%, the
  complete layer partition, and exact teardown. Timing remains diagnostic.
- Implemented temporary all-layer and frozen-map policy/layout/graph surfaces
  only after their respective host screens passed. Both temporary surfaces and
  their tests were removed after native 1K rejection; the retained source tree
  is back to the `d4ddcecb1` production baseline.
- Preserve the bounded negative result at
  `benchmarks/results/2026-08-15-gfx1151-qwen38-27b-int8-kv-quality-rejected.json`.
