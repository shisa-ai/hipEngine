# Reject gfx1151 Q4T16 interleaved Q8_1x2

## Summary

Reject a byte-neutral interleaved primary+residual Q8_1x2 producer/consumer for
the current Q4T16 split-weight gate/up+SiLU owner. The candidate is BF16-bit
exact and all three actual layer medians are positive, but the **1.00177x**
family speedup wins only **24/45** pairs and projects **7.122 ms / 0.0685%** of
selected graph wall, 14.6x below the >=1% admission gate. Remove the transient
producer, consumer, wrappers, and test without a full-model run.

## Changes

- RED added a synthetic fixture comparing the missing interleaved route with the
  retained plane-major Q8_1x2 split-weight route.
- GREEN added a byte-neutral 72-byte K32 record that stores four primary plus
  four residual activation bytes in one aligned 64-bit record. The producer
  preserves both quantization reductions and FP16 scales; the consumer
  preserves every dp4a, accumulation, reduction, BF16 round trip, and SiLU
  boundary.
- Screened actual layer 0/8/63 gate/up pairs. Each source pair is **95.625 MiB**,
  exceeding 64 MiB and 2x the 32-MiB MALL. No resident or workspace bytes were
  added.
- Preserved the rejection at
  `benchmarks/results/2026-08-16-gfx1151-qwen38-27b-q4-q8x2-interleaved-rejected.json`
  and restored all transient code/test changes.

## Validation

- RED failed collection at the intended missing producer import. GREEN passes
  `test_t16_q4_dense_dual_q8_1x2_interleaved_is_bit_exact` on gfx1151.
- Layer 0/8/63 medians improve **0.473514 -> 0.473343 ms**,
  **0.474269 -> 0.473277 ms**, and **0.475522 -> 0.474169 ms**. The combined
  family is **1.423306 -> 1.420789 ms (1.001771x)** with only **24/45** wins.
- All outputs are finite and BF16-bit exact: zero mismatches, KL 0, and 3/3
  top-1. Tracked memory returns exactly 0 -> 0 bytes.
- The broad lineage command is blocked by the pre-existing missing external
  checkout `/home/lhl/amd-gpu-tuning/reference/atlas`; this is an in-tree
  micro-layout experiment with no external parent source.

## Next

- Keep the plane-major split-weight owner. Pairing the two tiny activation loads
  cannot materially move a family already streaming Q4 weights near the device
  bandwidth roof; rerank a different operation-complete boundary.
