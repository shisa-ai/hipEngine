# DE-2 shared gate/up pair dispatch disposition

## Summary

The DE-2 shared-expert gate/up fusion target is correctly priced by the 2026-10-07 real-name graph attribution at 1.2939 ms/step for gate+up and 2.0621 ms/step for the full shared expert. No runtime change is retained: the existing Q8_0 dual GEMV writes a concatenated output buffer, while the current Qwen4Exp path requires separate gate and up F32 buffers for the subsequent SiLU kernel. Wiring it through the current pair API would therefore violate the output ABI. The candidate remains blocked on a dedicated separate-output pair owner plus GPU correctness/performance evidence.

## Changes

- Investigated `hipengine/runtime/qwen4_exp_runner.py`, `hipengine/runtime/gguf_linear.py`, and the Q8_0 GEMV registrations.
- Confirmed the shared gate/up shape is raw Q8_0, c1, K=2560, N=640/640, F32 input/output.
- Confirmed no implementation or default dispatch change was retained after the opt-in experiment was reverted for lack of a measured GPU result and because the existing dual owner has the wrong output ABI.
- Existing unrelated edits in `scripts/qwen4exp_layer2_profile_gate.py` and `tests/test_unit_qwen4exp_layer2_profile_gate.py` were left untouched.
