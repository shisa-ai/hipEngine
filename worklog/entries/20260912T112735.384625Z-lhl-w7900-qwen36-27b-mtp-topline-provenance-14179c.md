# Correct the published W7900 Qwen3.6-27B MTP topline cell

## Summary

The public topline row for W7900 Qwen3.6-27B Dense published a `With MTP` cell
of 32.1 tok/s. That value is 32.076, a Generation-2 single-request C1/K3 D24
measurement whose scoreboard row the current file no longer carries. The cell
now cites the current scoreboard row, the public production/BF16 resident-C2
K2 D24 automatic route at 34.341 tok/s. No measurement was taken and no rate
changed; this is a provenance correction to a published table.

- `benchmarks/README.md`: the `Qwen3.6-27B Dense` topline row's `With MTP` cell
  moves 32.1 to 34.3, which is 34.341 rounded to the one-decimal convention the
  rest of that table uses. `Last updated` moves 2026-09-11 to 2026-09-12.
- `README.md`: regenerated with `scripts/sync_benchmark_readme.py --write`, so
  the exported block is byte-identical to the source rather than hand-edited.
- `benchmarks/CHANGELOG.md`: dated entry recording old to new, the reason the
  percent delta is not reported, and the artifact.
