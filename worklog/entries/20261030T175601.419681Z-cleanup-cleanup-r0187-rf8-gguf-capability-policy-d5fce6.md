# Separate gfx1151 GGUF and capability policy declarations

## Summary

RF-8 second move-only boundary: the remaining local data declarations moved
out of `hipengine/kernels/hip_gfx1151/__init__.py` into two cohesive owning
modules. `policy_gguf.py` owns the 217 GGUF quant/layout/prefill/decode policy
declarations; `policy_capability.py` owns the 12 backend identity/capability
declarations (`BACKEND`, `STAGED_F32_VARIANT`, `TARGET_ARCH`,
`GGUF_CONSUMER_LAYERS`, the four `QWEN4_EXP_*` defaults, and the four `PARO_*`
defaults). Values, provenance comments, declaration order, geometry identities,
wrapper functions, registration tables, registry keys, and every historical
package import path are unchanged.

## Changes

- Added `hipengine/kernels/hip_gfx1151/policy_gguf.py` (1427 lines): 217 GGUF
  declarations with their provenance comments, the three private GGUF helpers
  (`_IQ_DENSE_W4A16_VARIANT`, `_IQ_DENSE_INTEGER_MMQ_VARIANT`,
  `_GGUF_Q5_T16_ROWTILE_COL8_SHAPES`), and an explicit `__all__` of the 214
  public names. It imports the three `QWEN35_*_GEOMETRY` identities from
  `hipengine/kernels/policy.py`; it defines no second geometry type and imports
  no kernel body or registry handle.
- Added `hipengine/kernels/hip_gfx1151/policy_capability.py` (87 lines): the 12
  identity/capability declarations with their provenance comments and an
  explicit `__all__`. `TARGET_ARCH` is still computed with
  `hip_target_arch_for_backend(BACKEND)`.
- Removed those 229 declarations from `hipengine/kernels/hip_gfx1151/__init__.py`
  (3717 -> 2730 lines). The six remaining non-Laguna declarations are the
  registration data/behavior that stays local: `_SOURCE_BACKEND`,
  `_GFX1151_ALIAS_EXCLUSIONS`, `_GFX1151_OVERRIDES`, `_GFX1100_MODULES`,
  `register_backend_kernels`, and `__all__`.
- Added explicit compatibility aliases for all 229 moved names
  (`NAME = _policy_capability.NAME` or `NAME = _policy_gguf.NAME`). This is not
  a module proxy. The removal condition is documented at the block: delete it
  once no caller imports these names from the package and the gfx1100/gfx1151
  capability-ledger check derives assigned names from the owning policy
  modules. The aliases also keep
  `test_gfx1151_capability_ledger_covers_gfx1100_only_live_reads` stable while
  it reads this initializer's source.
- Preserved the package `__all__` exactly (292 names). The move added no
  star-import name and removed none. Names that were not listed before remain
  unlisted.
- Added `tests/test_unit_gfx1151_policy_capability_gguf_boundary.py`: owning-
  module inventory and data-only contracts, geometry identity, explicit
  re-export identity (including private helpers), package-level capability
  lookup and deliberate reassignment, the initializer-source assignment
  assumption used by the capability ledger, replacement stability, and peer
  isolation. The package import is deferred to a fixture so this test file
  does not add another collector-order trigger for the pre-existing
  `hip_gfx1151`-before-`gguf_linear` dispatch coupling.
