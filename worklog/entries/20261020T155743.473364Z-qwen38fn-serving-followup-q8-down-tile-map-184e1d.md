# Q8_0 down current tile map

## Summary

The strict-Q4 prefill route could pass the group-prefix compact row total to the
Q8_0 grouped WMMA down owner as its `wmma_total_rows`. For a 1023-row chunk with
top-k 10 that value is 10230, not a 16-row tile count, and the guarded wrapper
raised `ValueError: invalid grouped block-scale shape or risk capacity`.

`_run_qwen4_exp_q8_wmma_down` now rebuilds the current 16-row tile map from the
invocation's compact expert starts. It passes the static tile upper bound used by
the exact iu8 routes instead of reading the map count back, so the Q8_0 down
route no longer performs a D2H readback or stream synchronize. The map kernel
initializes the capacity window to `-1`; the grouped WMMA kernels skip negative
tile ids, so the static bound is safe.

## Changes

- `hipengine/runtime/qwen4_exp_runner.py`: added
  `_qwen4_exp_q8_static_tile_count` and `_run_qwen4_exp_q8_wmma_down`; the Q8_0
  selected WMMA down branch calls the helper. The helper computes
  `active + (compact - active) // 16`, validates it against the scratch tile
  capacity, launches `qwen35_moe_wmma_tile_map` with that capacity, and passes
  `static_tiles * 16` to the resolved owner. It does not read
  `scratch.group_wmma_total` and does not fall back to another owner.
- `tests/test_unit_qwen4exp_q8_wmma_down_tile_map.py`: CPU regression and
  static-bound tests, including the exact stale guarded-wrapper arguments.
