# Audit and harden fp16 recurrent-state GDN port

## Summary

Audited the complete R2 FP32-to-FP16 recurrent-state device/runtime/evidence
chain (`5895c8879` through `b5e812c93`). The typed device conversion is sound:
all templated state accesses use typed read/write helpers, accumulation remains
FP32, and explicit `float` instantiations preserve the strict bodies. The review
nevertheless found missing c8 leaf coverage, mutable-env allocation ABI risk, an
unsupported prefill-score combination that did not fail closed, incomplete
registry provenance, stale kernel documentation, and a correctness-evidence
scope mismatch: the retained strict-teacher artifact covers c1 only and predates
the packed segmented-prefill/indexed-cN kernels.

## Changes

- Freeze `HIPENGINE_GGUF_FP16_RECURRENT_STATE` on
  `Qwen35GGUFFullStackRunner.fp16_recurrent_state` before allocation/plan
  construction; all live dtype-sensitive allocations and dispatch helpers now
  consume that frozen value rather than rereading mutable process environment.
- Fail closed when FP16 state is combined with the FP32-only prefill-score
  diagnostic; size its temporary state buffer by the frozen state dtype.
- Register scalar, fused GDN+cast, chain, compact-peer prefill, and decode-order
  FP16-state leaves. The fused Q5T16 owner now resolves the explicit
  `bf16_lowp_f32_bf16_out_fp16state` registry variant and errors on a miss instead
  of directly swapping a function after resolving the FP32 key.
- Remove the duplicate indexed-singleton capability lookup and add an explicit
  state-dtype argument to the batch-plan resolver, preserving env-based calls
  only as a test/diagnostic compatibility surface.
- Add the FP16-state env to packed-AR provenance and update `docs/KERNELS.md`,
  which incorrectly still said recurrent state remained FP32.
- Extend the indexed RED to rows=8 so the gfx1151 shared-statecache24 body
  actually executes; add frozen-mode/explicit-plan and FP16 registry tests.
- Record the focused model-shape leaf audit in
  `benchmarks/results/2026-08-20-gfx1151-qwen38-27b-r2-fp16-indexed-audit.json`.
