# Lead decisions for R0030 R0067 R0080 R0211/R0212

## Summary

The lead decided four open `docs/REFACTOR.md` items on 2026-11-07. All four entries
are closed.

- **R0080 (candidate-budget alias):** remove now, error loudly. The reader for
  `HIPENGINE_GGUF_MTP_CANDIDATE_BUDGET` is gone. Setting it, alone or together with
  `HIPENGINE_SPECULATIVE_CANDIDATE_BUDGET`, raises a `ValueError` naming the
  replacement (server CLI: argparse exit 2 with the same message), so an old
  configuration is never silently ignored. An explicit CLI/constructor depth still
  bypasses environment resolution.
- **R0211/R0212 (prefill/decode scheduling policy):** keep `HIPENGINE_PREFILL_DECODE_POLICY`
  / `--prefill-decode-policy` (`protect_decode`, `protect_ttft`, `fair`) as a
  supported production control, with the current scoped defaults (generic
  `protect_decode`, the gfx1100/gfx1151 Q4_K_M package `fair`). No migration
  to `token_budget`.
- **R0067 (dense prefix retention):** keep the capacity-sized snapshot default and
  the current state-byte ceilings. `HIPENGINE_GGUF_PREFIX_RETAINED_SNAPSHOTS` and
  `HIPENGINE_GGUF_PREFIX_RETAINED_STATE_BYTES` remain documented operator controls.
- **R0030 (Qwen4Exp warp router):** keep strict expert-selection semantics. The
  proposal to quantize ranking logits with deterministic ties is declined. Tile4
  strict, the diagnostic warp variant and `router_producer_variant` remain
  unchanged. Reopening needs a new campaign decision, not a kernel retry.
