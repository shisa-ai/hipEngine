# Transport safety repair: validate before issue, and tear down partial init

## Summary

Review found that the real RCCL transport issues mismatched operations before
validating them and leaks resources on partial initialization. Both are
confirmed here and fixed, and the reason they survived review is fixed too: the
real wrapper had **no CPU-only test at all**. Every failure-path test drove
`MockTransport`, a different implementation, so the production code's ordering
and teardown were never exercised without two GPUs.

**Defect 1: validation happened after issue.** `_enqueue` called
`self._binding.all_reduce(...)` immediately and recorded the request afterwards,
and cross-rank shape comparison happened in `group_end()` *after*
`self._binding.group_end()` had already committed the group. The mock specifies
"validation before issue", so the two implementations disagreed about the one
property that matters: with real communicators a mismatched operation is queued,
and the peer waits for a collective that will never arrive.

Fixed: `_enqueue` records the request and compares it against every other rank's
request at the same position *before* issuing. A mismatch poisons the transport,
**aborts every communicator** so queued work cannot block a later wait, and
raises `TransportStateError` with the rank, position, and both shapes.

**Defect 2: partial initialization leaked.** `__init__` creates the streams and
then the communicators. When one rank's `comm_init_rank` failed, the constructor
raised without destroying the communicators that had come up or the streams - and
because the constructor never returned, no caller could call `close()`.
`_create_streams` had the same shape: a failure partway left the earlier streams
alive. Fixed with `_teardown_streams()` and `_destroy_partial_comms()`, called on
every failure path in the constructor; `close()` now reuses `_teardown_streams`
and skips communicators that were already aborted, since aborting twice is not a
defined RCCL operation.

**A third instance of the same class, found while writing the guard.**
`copy_host_to_device`, `copy_host_array_to_device`, and `copy_device_to_host`
still used whatever device was current instead of the buffer's owning device, so
a rank-bound caller would upload into device 0. They now select the owning device
when the buffer is attributed and keep the old path when it is not.

## Changes

- `hipengine/distributed/rccl.py`: pre-issue peer comparison
  (`_compare_against_peers`, `_request_shape`), `_abort_communicators` on shape
  and completeness failures, `_teardown_streams`, `_destroy_partial_comms`,
  idempotent abort, and the constructor teardown path.
- `hipengine/core/memory.py`: device selection in the host<->device copies.
- `tests/test_unit_distributed_rccl.py` (new, 9 tests): the real wrapper driven
  through a fake binding and fake runtime - mismatch rejected before RCCL sees
  it, mismatch kind rejected, poison aborts queued work, incomplete group fails
  without hanging, partial init destroys comms and streams, stream failure leaves
  no communicators, happy path, and a coverage declaration mapping each failure
  mode to its real-wrapper test.
- `tests/test_gpu_distributed_transport.py`: a mismatched group on real
  communicators fails fast (0.18 s, no hang) and reports the poisoned group.
- `tests/test_unit_core_device_ownership.py`: a table over the whole
  buffer-taking surface of `core.memory`, asserting each entry point accepts an
  unattributed buffer and selects the owning device when attributed, with
  `copy_device_to_device` declared as attribution-requiring and `host_buffer_ptr`
  declared host-side.

## Validation

- `uv run pytest tests/test_unit_distributed_rccl.py` - 9 passed. The four
  defect tests were RED first (`DID NOT RAISE` for both mismatches, and
  `destroyed == []` for the leak).
- `uv run pytest tests/test_gpu_distributed_transport.py --suite gpu` - 5
  passed, including the real two-rank all-reduce, so the restructured issue path
  still works on hardware.
- `uv run pytest tests/test_unit_core_device_ownership.py` - 20 passed.
- Bundle: 139 passed across the RCCL, mock transport, device-ownership, shard,
  KV, and break-even suites.
