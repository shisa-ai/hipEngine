# Bind gfx1151 MoE router and Q8 rowtile to each owner

## Summary

The Qwen3.5 MoE gfx1151 profile binder used the process environment as its
transport: it wrote `HIPENGINE_GGUF_ROUTER_F32W_COOP`,
`HIPENGINE_GGUF_ROUTER_F32W_PERSISTENT_COUNTER` and
`HIPENGINE_GGUF_Q8_T16_ROWTILE_ALL` from `_apply_profile_policy`. Two owners in
one process retargeted each other, and the strict rowtile `0` overrode the
resident runner's own packed-decode rowtile session because the ambient value
was read first.

The profile now binds explicit construction-owned values on the generator
(`target_router_f32w_coop`, `target_router_f32w_persistent_counter`,
`target_q8_t16_rowtile_all`). Every runner, resident session, NextN executor and
draft-provider constructor carries them. The router is consumed through the
runner's resolved `FfnFlags` thunks.

The Q8T16 broad-rowtile decision is an explicit launch-plan input:
`launch_gguf_linear` and `launch_gguf_linear_pair` accept
`q8_t16_rowtile_all=`, and `launch_gguf_linear_triple` already accepted
`rowtile_all=`. The runner resolves
`_q8_t16_rowtile_all_owner_for_rows(rows)` and passes it at every single, pair
and triple launch on the packed-decode, verifier, native-row and prefill paths,
including the attention-layer and full-attention bulk/decode-batch modules
through their owner-bound selector plans. There is no new mutable owner scope: a
bound owner passes its value explicitly, and `None` keeps the existing
ambient/session diagnostic resolution. The process environment is no longer
rewritten.

The production floor is route-scoped, matching the old session lifetime. The
old production binder removed `HIPENGINE_GGUF_Q8_T16_ROWTILE_ALL`, and the only
place a floor was active was the packed-AR step's
`q8_t16_rowtile_all_session(...)`. The strict binder wrote `0`, which overrode
that session, so strict was exact on every route. Outside the packed-AR step the
verifier, native-row and prefill calls saw no session and no ambient input, so
they selected the exact route. The replacement keeps that shape: the packed step
sets the session from `_q8_t16_rowtile_all_owner_for_packed_rows(rows)` (the
production floor), while `_q8_t16_rowtile_all_owner_for_rows(rows)` returns the
session value inside that step and `False` outside it for a bound owner. An
unbound owner returns `None`, so the ambient/session resolver remains its
input. Prefill launches now receive the same route-resolved value instead of
falling through to ambient.

No arithmetic, selected variant, default or capability changed: strict runs the
base F32 router and the exact Q8T16 route; production runs the cooperative
persistent F32 router and the gfx1151 package rowtile floor (rows >= 4). The
independent Q8T16 pair package floor (rows >= 8) is unchanged and is not the
broad-policy input.

  the generator. The constants stay exported as the ambient input names.

  every shared-runner, shared-session, direct-session, native-batch, MTP

### Consumer inventory

- Router: the only consumers are the `FfnFlags` thunks used by
  `run_post_attention_moe_c1` and the unfused selected-FFN helper. They read the
  runner's resolved policy; an unbound runner reads ambient per call.
- Broad rowtile: `_use_q8_t16_all_rowtile` is called by the single dispatch
  (`launch_gguf_linear`) and the triple plan; `_use_q8_t16_pair_rowtile` is
  called by `_resolve_gguf_linear_pair_plan`. Those are the only three readers.
  The pair-specific env and pair min-rows floor remain independent package
  inputs.
- Actual launch paths covered: linear-attention attention chain (verifier),
  full-attention attention chain (verifier), linear-attention indexed rows
  (packed decode), linear-attention native rows, full-attention native rows,
  full-attention bulk prefill (selector plan), full-attention decode batch
  (selector plan), linear-attention prefill, and the attention-layer alpha/beta,
  qkv/gate, ssm_out and output projections. The production floor is selected
  only inside the packed-AR session; every other path resolves the exact route
  for a bound owner.
- Unbound/direct diagnostics still use `HIPENGINE_GGUF_Q8_T16_ROWTILE_ALL` and
  `q8_t16_rowtile_all_session`; `None` is the only path that reads them.
