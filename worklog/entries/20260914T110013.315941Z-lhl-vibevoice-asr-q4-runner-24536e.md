# VibeVoice Q4 loader + integration design for the quant runner

## Summary

Q4_K_M loader for the VibeVoice Qwen2 backbone plus the validated
integration design for the quant runner; the runner wiring itself is
the remaining work.

## Changes

- `hipengine/loading/vibevoice_asr_gguf.py`:
  `load_vibevoice_qwen2_q4(path)` reads the merged Q4 GGUF - spec from
  `vibevoice.text.*` KV, per-layer Q4_K/Q6_K block buffers for the six
  GEMM weights (raw GGUF byte layout, validated: 3584x2016, 512x2016,
  18944x2016, 3584x10656 - all match the kernels' row_bytes math),
  bf16 norms/biases, dequantized+re-rounded token_embd, bf16 output
  (untied lm_head).

## Validation

- Loader runs clean on /tmp/vibevoice-asr-q4km.gguf: 28 layers, 339
  backbone buffers, spec geometry exact.
- Q4_K in-feature divisibility (all /256) holds for 3584/512/18944.
