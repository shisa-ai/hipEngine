# Audit hybrid-04 Vulkan configuration axes

## Summary

Completed a same-binary hybrid-04 Vulkan configuration subaudit under auto
clocks. Graphics queue helps decode while repack and fit are neutral.

## Changes

- Measured queue off/on, no-repack, and fit on at exact code-p512 using the
  canonical payload/response validators, BF16 K/V, and fixed 8192/8192/2048
  context/batch/ubatch.
- Each isolated startup arm used one warmup and three measured repetitions.

- Queue off/on medians: 212.08/25.59 vs 209.60/25.96 pp/tok/s, a queue-on
  decode gain of 1.43% with a prefill loss of 1.19%.
- No-repack differs from queue-on baseline by +0.40%/-0.03%; fit-on differs by
  +0.17%/+0.02%. Both are neutral.
- All 16 warmup/measured outputs share hash `9f803aa...b3e3f2`.
