# Validate published UD K_M public generation smoke

## Validation

Host: zbook, Radeon 8060S / gfx1151. Fresh process, automatic quant selection,
no named execution profile, max sequence length 64, single prompt, greedy
8-token completion, ignore EOS. Model is the previously hash-verified published
`/models/gguf/Qwen3.8-27B-UD-Q4_K_M.gguf`.

```bash
HIPENGINE_COMPILER_VERSION_FILE=/tmp/ud-hipcc-version.txt .venv/bin/python -u - <<'PY'
import sys
from hipengine import LLM, SamplingParams
llm=LLM('/models/gguf/Qwen3.8-27B-UD-Q4_K_M.gguf',backend='hip_gfx1151',max_sequence_length=64)
print(llm.generate('The capital of France is',SamplingParams(max_tokens=8,temperature=0,ignore_eos=True)))
print('torch loaded:', 'torch' in sys.modules)
PY
```

Output:

```text
[' Paris.\nThe capital of Germany is']
torch loaded: False
```

The completion equals the separately executed eager c1 smoke from
`20260907T035440.022336Z-lhl-ud-km-c1-integration-c5bbd6.md`. This is not an
independent generated-text oracle. Log:
`/tmp/kendex-pi-bg/bg-4-1788753437528.log` (exit 0).
No timing result or performance claim; no benchmark rollup change.
