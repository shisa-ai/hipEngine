# Bind Flash-Next decode to shared thinking-budget state

## Summary

Flash-Next now binds the shared thinking-budget state to direct and
scheduler-owned AR token selection. Hard-close tokens run through ordinary
model decode/KV updates instead of being appended to the final text. This
implements the runtime portion of PS3; answer-reserve lowering and the final
live positive matrix are still open.

## Changes

- Allocate independent `RowSamplingState` instances for requests with a
  tokenized thinking cap. Keep the compact argmax route unchanged without one.
- Capture logits for controlled requests, resolve tokenizer EOS, and reuse
  shared hard/soft close, reasoning EOS suppression, and post-thinking queues.
- Split grammar masking from consumption so a thinking-controlled token must
  also satisfy the output grammar before publication. Existing grammar-only
  selection keeps the same ordering.
- Enrich direct, resident and streaming finish details from the actual state,
  including close pressure, phase, forced-close flag and token counts.
- No HIP kernel or model arithmetic changed. Raw MTP/hint behavior is unchanged;
  hard-policy MTP still names its AR fallback rather than pretending to enforce
  controls through raw-target verification.
