# Qwen3.8 B1 verifier owner map measured

## Summary

B1 item 1 of docs/QWEN38-GFX1151-BUILD-CAMPAIGN.md: mapped the packed target
verifier's actual kernel owners at R10-R28 and the mechanism-A transfer
surface. Host-only; no GPU run; no performance claim.

## Method

Launch-based attribution: for each physical target-pass telemetry window
(specdec2_mtp2_target_pass_start/end_ns from the sha-pinned M3 C5/C7 raw
telemetry), collect hipLaunchKernel API calls inside the window by
Correlation_Id and sum the matched kernel durations from the sha-pinned
rocprof kernel trace. Completion-based window selection undercounts because
kernels drain ~500 ms past the 45 ms enqueue window. The census reconciles
with the committed M3 wide-closure kernel totals within 1.65% at C5/C7.

## Measured facts

Per-pass kernel medians (current head, production route): R20 540.6 ms,
R28 702.0 ms. Family owners: q6_k_t16_qmicro_planar_gemv_bf16 per-row direct
GEMV 209.4/292.7 ms (6.49 ms median per launch), gguf_q4_t16_dense
wmma-prefill ~132 + shared_b ~24 ms, q6_k_t16_gemv 90.0/125.6 ms,
qk_t16_selected_direct (Q5) 67.3/92.9 ms, lm-head rowtile_col8 re-sweep
23.9/33.4 ms. None of the retained Y2/Y3 prefill owners is selected by the
verifier at these rows today.

## Derived (labeled)

A+B projection at R28 replacing Q6 planar/std + Q5 + lm-head with the F3
per-tensor prefill-owner leaves while keeping Q4/GDN: ~265 ms, inside the B0
corrected C7 budget (289.4 ms). Q4 (~156 ms) becomes the largest remaining
family and is already near its prefill-owner cost.
