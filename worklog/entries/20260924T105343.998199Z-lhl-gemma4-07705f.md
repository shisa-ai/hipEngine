# Gemma 4 evaluator freeze: teacher-forced baseline + production KL/top-1 gate

## Summary

Closed the G0 sub-item that was "deferred to immediately before the first
changed-arithmetic candidate": the teacher-forced evaluator now exists, is
frozen against the incumbent tree, and has passed its own determinism gate.
Both remaining measured-order candidates (q4_k decode re-route, multi-block
attention split) were blocked on this.

`scripts/gemma4_teacher_forced_gate.py` implements the shared-chain probe the
row-count standard requires:

- `capture` teacher-forces the frozen campaign prompt chain (the same
  1024-token ids as the llama.cpp comparator — `chain_sha256` reproduces
  `9730ebf8…`) on the current default path and stores every position's
  full-vocabulary next-token distribution as float32.
- `gate` recomputes the same chain on a candidate path and judges
  per-row KL(baseline || candidate) in float64 plus top-1 agreement against
  the binding production limits from `docs/EXECUTION-PROFILES.md`:
  mean ≤ 1e-3, p95 ≤ 5e-3, p99 ≤ 2e-2, max ≤ 5e-2, top-1 ≥ 99%, nearest-rank
  percentiles (the harness convention). Exit code 1 on any failed limit.

Frozen baseline (incumbent, commit `6224cc057`):

- npz: `/mnt/nvme1/gemma4-eval/teacher-forced-6224cc0576fb.npz`
  (1023 rows × 262144 vocab, 1023 MiB, sha256 `a79a3146c1d56792…`),
  kept outside the repository at a pinned path; the manifest
  `benchmarks/results/2026-09-24-gemma4-26b-a4b-teacher-forced-freeze.json`
  carries path, hashes, thresholds, threshold source, command and provenance.
  `git_dirty` is honestly `true` with exactly the evaluator's own two
  untracked files listed — no runtime-path code differed from the commit.
- Row count 1023 sits inside the 500–1000-row band the standard requires for
  promotion evidence (a ~60-row screen would only ever pass on zero flips).

Determinism self-gate (capture twice on the same tree, gate the second against
the first): KL mean/p95/p99/max all `0.0`, top-1 `100%`, zero flips, exit 0.
So a non-zero gate result from here on measures the candidate, not the probe.
