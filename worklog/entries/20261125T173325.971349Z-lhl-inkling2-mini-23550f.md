# Read Inkling prompt blocks of 1,024 rows

## Summary

`fast` and `production` read a prompt in 256-row blocks, the width chosen when the grouped
expert kernel did not exist. With that kernel the width matters for two reasons. It groups a
block's routes by expert and pads each expert's rows to 64: at 256 rows each of the 128 experts has
about 16 rows, so three of every four rows the kernel computes are padding. And every visit pays
its host work once per block.

**First token by block width** (W7900, omitted profile, on the tree of
[50e23ad1a](20261125T171057.976897Z-lhl-inkling2-mini-851bcb.md) with this change; two output tokens,
median of three repetitions after one warm one, each width in a model of its own):

| Block width | 575 prompt tokens | 2,057 prompt tokens | 4,096 prompt tokens |
| ---: | ---: | ---: | ---: |
| 256 rows | 0.937 s | 3.130 s | |
| 512 rows | 0.820 s | 2.596 s | |
| 1,024 rows | 0.631 and 0.636 s | 2.380 and 2.381 s | 4.729 s |
| 2,048 rows | 0.639 s | 2.330 s | 4.570 s |
| 4,096 rows | 0.638 s | 2.205 s | 4.497 s |

The two output tokens are the same at every width and depth. The step from 256 to 1,024 rows is
the large one; beyond it a wider block helps 2% to 7% at 2,057 and 4,096 tokens and nothing at 575.
`fast_prefill_block_width` is now 1,024: at 575 prompt tokens the first token comes 33% sooner and
at 2,057 24% sooner than at 256 rows. At 1,024 rows the prompt rates are 911 tok/s at 575 tokens,
864 at 2,057 and 866 at 4,096.

A wider block is a longer step for the other streams of a multi-request server: a block of 1,024
rows takes about 0.63 s on the W7900, against 0.14 for 256 rows. The server's prefill chunk and
round budget follow the width. That trade is taken for the single-stream rate, which every row
above measures; the four-stream path is step 6 of the campaign plan.

## Changes

- `Inkling2GGUFGenerator.fast_prefill_block_width` is 1,024; `strict` keeps 64 rows. The gate reads
  the width from the class, so its candidates follow.
- Three tests follow the width. The device-routed block test now expects every block of at least
  192 rows, the full ones and a wide enough tail.
