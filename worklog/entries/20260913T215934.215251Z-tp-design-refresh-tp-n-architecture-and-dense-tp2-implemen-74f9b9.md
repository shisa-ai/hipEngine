# Refresh TP=N architecture and dense TP2 implementation plan

## Summary

Reviewed the dense Qwen3.8 TP2 proposal against the current source and expanded
its reusable infrastructure into a single-host TP=N design. Keep column/row
sharding, replicated hidden activations, RCCL first, and incremental MLP then
attention/state integration. No runtime implementation, hardware qualification,
or performance claim is made. Reviewed September 14 local time (Asia/Tokyo).
