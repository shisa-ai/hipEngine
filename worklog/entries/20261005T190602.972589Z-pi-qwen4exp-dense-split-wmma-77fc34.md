# Screen genuine split-operand Q8 dense WMMA against live F32 coltile

## Summary

T1/T2 candidate: split both the raw-Q8 dequantized F32 weight and the F32
activation into F16 high plus a scaled F16 residual (2048x), then accumulate
high-high and the two cross products separately in F32. Omit only the
second-order low-low term. This is a genuine precision-recovery candidate,
not the historical identical-operand `WMMA_REP=3` timing probe. Full model
promotion still requires the unchanged production numerical/control/task gate.

The live early-layer baseline is raw F32 coltile, not wide F32-input/F16
operands. Production dense-wide is scoped to layers13-47; layers0-12 retain
the exact pipelined coltile owner. DP-3's historical cost rejection compared
against wide F32-input/F16-operand timing and cannot reject this denominator.
First bounded tile: 64 output columns x 128 token rows, BK64, 256 threads;
doubled operand LDS is 55,296 bytes, below 64 KiB. Promoted GR-up stays unchanged.

## Changes

- Add a registered measurement-only split64x128 sibling to the existing
  wide family, retaining all current instantiations and strict raw-Q8 fallback.
- Add RED-first guarded numerical fixtures covering non-F16-exact Q8 weights,
  cancellation, zero scales, signed-code extrema, tails, deterministic repeats,
  and CPU-reference KL/top-1 smoke. No profile or threshold changes.
