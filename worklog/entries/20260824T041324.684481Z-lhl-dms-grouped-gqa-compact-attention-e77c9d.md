# Share compact DMS K/V scans across GQA query heads

## Summary

Retained a production-profile grouped-GQA compact DMS split-K producer on
`gfx1151`. Qwen3.8 has six query heads per KV head; the parent kernel scanned
each compact K/V stream six times. The new producer assigns one split workgroup
per KV head, preserves each query head's dot/softmax/value order, and shares the
K/V scan across the group. Frozen policy/sidecar bytes and compact ownership are
unchanged.

## Changes

- Added grouped split producer support for GQA groups up to eight; larger groups
  keep the original per-query-head producer and the CPU reference remains the
  strict registry fallback.
- Added a production group-6 parent-output digest fixture.
- Added a cached-capable long-context microbenchmark harness.
- Screened and rejected shared-barrier and 512-row split variants; neither
  remains in source.
