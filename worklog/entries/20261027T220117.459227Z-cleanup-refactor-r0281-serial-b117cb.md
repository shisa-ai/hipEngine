# Move Laguna serial prefill orchestration to the oracle helper

## Summary

multi-token serial oracle now lives in a benchmark helper; production
prefill retains its chunked route and one-token scalar primitive.

## Changes

- Add `scripts/laguna_serial_prefill.py::serial_prefill()`, advancing the
  existing `forward_token()` primitive and passing final-row capture only
  on the last prompt token. Validate nonempty input and one-row captures.
- Remove `use_bulk` from `LagunaGGUFResidentSession.prefill()`. A one-token
  prompt still calls `forward_token()`; multi-token prompts still use the
  unchanged chunk loop and final projection.

  controls to the independent helper. Remove redundant `use_bulk=True`
  arguments from all live Laguna harnesses, without changing their input,
  capture, reset, timing or result ownership.

  Required primitives and correctness oracles remain implemented.
