# Report non-finite long-context controls as invalid

## Summary

The prefill campaign captured all three production repeats and the retrieval
rows, then report generation raised `KeyError: 'kl_mean'`. One strict round-off
control contains non-finite logits, so the evaluator correctly omits its KL
metrics. The long-context decision now records this as an invalid measurement
instead of crashing or discarding the control. Finite-input decision rules and
thresholds are unchanged.

## Changes

- Reject empty, non-finite or incomplete numerical summaries before computing
  the control floor. Report candidate and control finiteness separately; retain
  retrieval, repeat and optional batch-control results.
- Keep the failed control in the evidence. No seed, prompt, scope, comparator
  or numerical threshold changes in this repair.
