# Add production-owner C2 graph profiler child

## Summary

Added the missing task #47 measurement child for one marked physical-cN decode
transition through the actual Generation-2 public path. Unlike the earlier
standalone resident-session profiler, this child calls `LLM.generate_detailed`,
so prompt children enter `EngineService` and the long-lived
`Qwen35GGUFResidentModelRunner._step_native_rows` owner. It marks a configurable
later cN transition after graph capture/replay has had time to become active and
records the exact physical-group plan, execution manifest, route/fallback
counts, output IDs, and final drain.

## Changes

- Added `scripts/gguf_continuous_owner_profile_child.py` with warm/cache and
  profiler modes, a width/index-scoped ROCTX range, public cN generation, owner
  method instrumentation, synchronized marker wall, and JSON output.
- Added pure host tests for the marker identity and the c8/p512/d32/transition-3
  defaults.
- The child does not parse or interpret profiler timelines; task #47's retained
  artifact will join its marker with kernel/HIP API/memory-copy CSVs separately.
