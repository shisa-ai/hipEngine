# Screen Qwen3.8 fixed-5120 wave norm decode

## Summary

Retain fixed c1/hidden-5,120 standalone RMSNorm and unrounded add+RMSNorm as
the default gfx1151 dense-H5120 Q4_K_M route. Across all 128 actual Qwen3.8
weights, the exact package improves **1.23268 -> 0.35870 ms/token (3.4365x,
15/15)**. Complete 512/1K/4K graph AR improves
**1.458%/1.368%/1.380%**, and natural ten-prompt AR improves **1.362%** with
every train, heldout, and category scope positive. All outputs, trajectories,
acceptance decisions, and bytes remain exact.

## Changes

- Added local256 fixed-H5120 standalone/add norm kernels. Each thread caches 20
  FP32 values, preserves the generic per-thread sum and complete local256 FP32
  reduction tree, derives the first three tree levels from immutable shared
  partials, and finishes the remaining five levels with wave32 shuffles.
- Added validated wrappers and four-axis registry variants
  `rmsnorm/add_rmsnorm + gguf_f32_weight + bf16_out_fixed5120_wave256`.
- Added a gfx1151 dense-H5120/MOSTLY_Q4_K_M rows1 capability. Rows>1, Q8,
  output norm, other geometries, and peer backends retain generic fallbacks.
- Added RED/GREEN kernel, registry, policy, and runtime-selection tests. No env
  flag, sidecar, workspace, persistent allocation, or graph node was added.
- Published
  `benchmarks/results/2026-08-16-gfx1151-qwen38-27b-fixed5120-norm-decode.json`
  and updated the benchmark/campaign/kernel rollups.

## Validation

- RED: the new fixed-H5120 preload contract failed on absent wrappers, and the
  backend/runtime policy tests failed because no dense-H5120 route existed.
  GREEN: **81/81** affected fixed1024/fixed5120, gguf-ops, gfx1151 backend, and
  runtime-policy tests pass.
- Synthetic GPU gate is generic-kernel BF16 identity plus CPU-reference KL <=
  0.05 and top-1 >=90%. Actual 64 attention and 64 post-attention norm weights
  have **0/327,680** BF16 mismatches for standalone, add norm, and residual.
- Actual leaf: standalone **0.60341 -> 0.17357 ms (3.4764x)**, add norm
  **0.63016 -> 0.18538 ms (3.3993x)**, combined **1.23268 -> 0.35870 ms
