# Extend segmented GDN with direct BF16 rows

## Summary

Extended the ordinary segmented lowp GDN row-journal owner with a direct BF16
handoff matching the scalar fused GDN+cast boundary. The kernel primitive is
bit-exact at synthetic and real Qwen head geometry. Model integration is not
retained: despite kernel parity, replacing the packed MoE C2 scalar GDN rows
reproduced the known failed production trajectory (general-English mean/max KL
`0.003333/0.111938`), so the selected model fallback remains unchanged.

## Changes

- Add nullable direct-BF16 output to the segmented kernel and preserve existing
  typed-null FP32/FP16 wrappers.
- Extend the state-row wrapper ABI with a BF16 destination.
- Strengthen the RED/GREEN gate against the actual scalar fused GDN+cast owner
  at 1K/2V and Qwen 16K/32V geometry.

## Validation

- Two geometry cases pass bit-exact output BF16, every FP32 state row, and final
  segment states versus scalar fused GDN.
- Ruff and diff checks pass.
- Rejected model integration artifact:
  `/tmp/gfx1100-moe-c2-fused-segment-gdn-en-quality.json`.
