# Unify resident MTP output accounting

## Summary

R0081 removes the resident MTP scalar timing mirror. Usage and response
summaries read the per-request diagnostics block; legacy provider telemetry
remains readable.

## Changes

- One AR-in-plan counter replaces the dual-counter sum. Depth-zero cycle
  attribution calls the same AR-step function, without a zero-token bookkeeping
  call. Public output-accounting field names retain their meanings.
- Streaming and blocking resident outputs publish draft counts in diagnostics.
  Server usage and summaries prioritize that record over legacy timing.
- Live benchmark consumers now read the public summary or per-row execution
  blocks before legacy timing fields.
