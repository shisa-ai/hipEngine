# EVIE GDN full f16-out (wall retraction)

## Summary

The previously recorded "GDN in_proj_qkv must keep the f32-output epilogue"
wall was a misattribution: with clean, verified state the FULL f16-out GDN
(in_proj_qkv unsplit single GEMM, z/b/a, out_proj) passes the oracle fixture
deterministically. The earlier collapse (query cos 0.015 at the 2.76 s run)
came from the stale-edit era, not numerics. Removing the f32-out path
(`_gemm32` deleted): 2.99 s -> 2.69 s (doc 2.00 s, query 0.70 s).

- `hipengine/runtime/evie.py`: in_proj_qkv on the plain f16-out `_gemm`;
  dead `_gemm32` removed. New `out_stride` param on `_gemm` (column-

  `_gemm16_out` staging.
