# Fix Gemma attention reduction geometry and name the LDS limit

## Summary

Independent review identified a reduction error for non-power-of-two attention
head widths and a concrete shared-memory limit at long contexts. The first was
reproduced on physical GPU1 (RX 7900 XTX): zero Q/K and unit V with three keys
and head width six returned 1.5 instead of the analytic answer 1.0.

The existing kernel's halving reduction requires a power-of-two block size.
The launcher now rounds up to a power of two, capped at its existing 256-thread
limit. Launch geometry and arithmetic for existing power-of-two widths,
including the real 26B artifact, are unchanged. This repairs an incorrect
shape; it is not an arithmetic optimization or performance promotion.

The kernel keeps one score per live key in LDS. Python launch planning and
runner construction now reject geometry requiring more than gfx1100's 65536
bytes of shared memory before building or launching the kernel. The C launcher
has the same bound. For head width 512 this kernel supports at most 15616 keys;
16384 keys cannot execute without a different, tiled attention implementation.
This is a named resource capability miss, not an evidence gate. Default context
8192 continues to run.

## Changes

- `gemma4_attention.hip`: power-of-two launch width and LDS byte guard.
- `gemma4_attention.py`: shared-memory planning helper and early error.
- `runtime/gemma4.py`: validate configured context geometry before runner
  allocations, rather than failing after many successful decode steps.
- `tests/test_gpu_gemma4_attention_geometry.py`: analytic F32/BF16 unit-value
  tests at head widths 6, 48, 64, 96, 192, 256, 512 and live-key counts 3, 8192,
  15616. This includes the actual LDS boundary, not just the default context.
- `tests/test_unit_gemma4_attention_geometry.py`: byte planning below/at/above
  the limit, unrelated context 8192, and pre-build/pre-allocation failures.
- Audit triage records the real resource boundary and the separate missing
  server tool parser. No audit budget was raised.
