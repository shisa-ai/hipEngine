# Validate v0.8.3 release and repair live test fixtures

## Summary

Release checks exercise the candidate runtime on both AMD hosts. The missing
Gemma gfx1151 INT8 registration is repaired and verified through public generation.
No tag or PyPI publication has occurred.

## Changes

- Give three Gemma live modules a documented HIPENGINE_TEST_GEMMA4_MODEL_DIR
  fixture override, preserving their original default and HIP/model guards.
- Use automatic backend selection for the two public Gemma MTP tests instead
  of forcing gfx1100 on a gfx1151 host.
- Initialize the synthetic Flash-Next snapshot fixture's optional shared cursor
  fields to None, as the real constructor does. Do not change runtime behavior.
- Triage the fixture-only environment setting as NOT-DEBT/keep.
- Register lazy Gemma INT8 attention consumers under both supported AMD backend
  keys. Previously the helper checked for gfx1151 but registered only gfx1100;
  the isolated public test failed too. No kernel arithmetic changed.

  from uv's cache. Retrying with dependency access built the editable package.

  20,653 passed, 6,472 skipped, one failure. The failure was the incomplete
  synthetic snapshot fixture, not a device execution. Its repaired file plus
  prefill-metadata unit coverage passes all eight cases. CLI and serve help pass.
- gfx1151 targeted GPU run: 31 passed, 12 skipped. GDN DPP detection, Gemma

  artifacts and are not counted as executed validation.

- Documentation, audit and diff checks pass after these repairs. No shared
