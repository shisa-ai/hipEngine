# Prevent root-base packed bindings across backing chunks

## Summary

Packed kernels bind root plane bases plus page offsets. Global workspace leases
can include appended noncontiguous chunks, so not every successful lease is a
valid backing for those consumers. Preserve executable private fallback until
page-pointer migration is implemented.

## Changes

- Add pool-owned root-backing fit query, independent of page-map authority.
- Before binding packed root planes, validate leased pages; release any new growth
  lease on mismatch and use the existing budgeted private fallback.
- Preserve eager lease ownership, contiguous arena support and no-pool behavior.
