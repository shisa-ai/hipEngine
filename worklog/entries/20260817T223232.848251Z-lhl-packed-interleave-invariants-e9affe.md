# Shared-buffer lifecycle invariants; lane NaN under churn remains open

## Summary

Canonical-gate iteration after 285dd42f1 peeled two more invariant bugs
and validated four fixes, but the deterministic continuous_fixed failure
remains: the shifted (kv_base_row=512) long-prompt row produces one NaN
logit lane ~30 decode tokens in under membership churn, which argmax
renders as 0x7FFFFFFF. static_c1/static_c8 (no churn) pass; packed decode
on/off both fail; state buffers, pool accounting, lane context counts,
block tables, and the private-chunk KV are all verified clean at the
failure instant, so the NaN originates inside the packed model step for
that lane and requires a per-layer bisect driver to localize.

## Changes

- _ensure_verify_lm_head_buffers growth now invalidates binding decode
  graphs (packed + c1 via _device_kv_graph_handles, owner + views) and
  synchronizes before freeing.
- _invalidate_live_packed_decode_graphs covers c1 graphs pinned in
  _device_kv_graph_handles across owner and views; c1 replay falls back
  to the eager step when its graph was closed by growth.
- The already-discarded flush path clears the import-reuse tokens
  (_packed_decode_session_ids/_positions).
- _sync_packed_decode_initial_state can_reuse additionally requires a
  consistent recorded session tuple so no path can skip the KV re-import
  across a private-slot reuse.
