# E7 — GDN alpha/beta reaches the fused owner (Q8_0→F32 load expansion)

## Summary

Iteration 23 of `ud-gfx1151-opt2/run-20260923-opt2` executes campaign
experiment **E7 (H10)**. The split was real: the plain artifact stores
`ssm_alpha`/`ssm_beta` as F32 (48×5120) and satisfies the fused
alpha/beta+conv decode owner's `quant_key == "f32"` + `raw` contract,
while the UD artifact re-quantizes the same tensors to Q8_0 (identical
shape), so the planner landed them on the Q8_0 T16 tiled layout (no
`raw` allocation, `quant_key = "gguf_q8_0_t16_v1"`) and
`_try_launch_dense_f32_alpha_beta_conv_decode` declined both checks on
every decode step. The fused key itself was never the blocker:
`is_registered(KernelKey("hip_gfx1151", "linear_attn_alpha_beta+conv_decode",
"f32", "bf16_k5120_n48_c10240_k4_c1"))` returns True (gfx1151 mirrors the
gfx1100 registration; the key is not in `_GFX1151_ALIAS_EXCLUSIONS`) and
the admitted shape set contains exactly `(1, 5120, 48, 10240, 4)`.

The lever (option (a) of the campaign's two): a **load-time Q8_0→F32
expansion**, exact in weight value — an fp16 scale times an int8 value is
representable in F32. Eligibility is keyed strictly on stored dtype plus
slot suffix (`.ssm_alpha`/`.ssm_beta`), never on artifact identity.
