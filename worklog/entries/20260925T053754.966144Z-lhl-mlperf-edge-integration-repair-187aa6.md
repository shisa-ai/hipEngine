# Repair MLPerf Edge tool protocol and streaming integration

## Summary

The repeated 27-turn MLPerf Edge integration diagnostic passes on host `gfx1151`
(Ryzen AI Max+ 395 / Radeon 8060S): all turns return one structured `bash` call with
valid JSON arguments. No empty, errored, missing, dropped or length-limited
outputs; no raw tool markup in content; no negative response-timing windows.
This is not a BFCL accuracy pass, full workload result or decode-speed comparison.
The earlier failed attempt remains in its original artifact and raw directory.

## Changes

- Align the server's host sampling constraint and required-call prefix with its
  XML function prompt. Keep the legacy JSON constraint for explicit internal
  users and the compatibility parser for old JSON output. Automatic XML calls
  may follow explanatory text; parallel calls require explicit opt-in.
- Recognize XML prefixes without forcing closure inside opaque parameter values.
  Disable generic outer-tag repair and close-tag stop sequences for XML: the
  stop sequence removed `</tool_call>` before the stream/final parser saw it.
- Stream single-choice XML content and string-typed argument fragments as they
  arrive; buffer non-string parameters until decoding is possible. Check final
  parsed names/arguments against emitted calls before success. Invalid or
  truncated live calls return SSE errors, not successful empty stops. Legacy
  JSON and other buffered response paths retain compatibility behavior.
- Remove the now-unused strict JSON schema-prefix helper. No new flags, kernel
  changes, arithmetic changes or runtime dependencies.
- Retain a separate patch against Endpoints `e71b928f8a72fd0c9d850dc5ddd8fd7760356354`:
  COMPLETE uses coordinator arrival, matching first/subsequent receive events.
  Workload, scorer, token denominator and metric formulas are unchanged. Patch:
  `benchmarks/mlperf-edge/coordinator-timestamps.patch`. Applied only to the
  dedicated campaign checkout, not an external reference repository.
- Update API behavior and campaign/run records. No subagents were used.
