# Add complete native DP-2 operation screen

## Summary

`--native-owner` replays natural adjacent Q8 consumers through the actual
runner helper, not prebound GEMMs. The host-wall boundary charges admission,
normal dispatch, casts, both GEMMs, scope teardown, event recording/completion
and final device synchronization. Allocation, byte validation, engagement
instrumentation and the surrounding model remain outside timing. No kernel,
runtime default or profile binding changes.

## Changes

- Preserve the existing primitive replay and identify its excluded admission
  and dispatch costs explicitly in the artifact.
- Reuse the runner's existing bounded workspace; allocate only diagnostic
  outputs. Run the helper with the two natural resident weights and source,
  preserving actual stream/runtime/registry selection.
- Suppress recursive capture during replay. Native replay still traverses the
  original launcher through a lightweight diagnostic wrapper in both arms.
- Select the existing native opt-in before timing. One warmup plus an even
  number of measured alternating pairs supplies both arm-order strata.
- Check every timed output and F16 staging byte against the natural outputs
  and NumPy conversion, and check source/weight immutability. A separate
  untimed native census requires two casts in the parent, one cast/two accepted
  consumers in the candidate. Every replay and final teardown checks ownership.
- Default native coverage is four categories at p1024/p4096, layers13/24/46,
  both adjacent ordered roles. P512 is not admitted by this mode.
