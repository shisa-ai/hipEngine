# Route incompatible explicit SPECDEC2 requests to K0

## Summary

Make the product route obey the normative pre-mutation fallback contract for
supported-engine requests whose sampling/stop/thinking semantics are not
qualified for raw-greedy MTP. Explicit `speculative_mtp=true` now selects true AR
K0 instead of returning HTTP 400, and reports the exact compatibility blockers,
policy cell, reason, and selected depth.

## Changes

- Add an internal `speculative_mtp_k0` request route resolved after queue grouping.
- Map sampling blockers to default AR with `unsupported_sampling_k0`, selected K0,
  blocker list, realized C, output horizon, and evidence.
- Preserve hard errors only for server-disabled or model/backend-unsupported MTP.
- Update non-greedy and hard-thinking API tests to require successful AR fallback
  with no MTP invocation.

## Validation

Focused completion and chat API tests pass under FastAPI. They cover temperature
and thinking-budget blockers, successful output, stable route metadata, one AR
call, and zero MTP calls.
