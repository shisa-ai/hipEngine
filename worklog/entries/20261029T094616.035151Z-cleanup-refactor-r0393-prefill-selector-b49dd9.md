# Unify resident prefill diagnostic across direct and pooled paths

## Summary

Fix the remaining R0393 prefill selector gap: direct streaming and fallback AR
sessions still pinned a separate constant although resident pools used the
call-time diagnostic resolver. Keep the default WMMA route unchanged.

## Changes

- Remove `_GGUF_PUBLIC_USE_WMMA_PREFILL`. Direct/shared-runner streaming and the
  fallback scope resolve `_resident_session_wmma_prefill_default()` when used.
- Treat an explicit empty/whitespace diagnostic value as malformed rather than
  silently defaulting. Truthy/falsy spellings and unset behavior are unchanged.
- Preserve explicit per-call route choices, GEMV decode preferences, pool key
  partitioning and the separate dense speculative MTP policy. Simplify duplicate
  direct/shared streaming kwargs without changing runtime ownership.
- Update env reference and the prefill paragraph in the composite ledger row.
  Other R0393 subitems remain open; no kernel/arithmetic/default change.
