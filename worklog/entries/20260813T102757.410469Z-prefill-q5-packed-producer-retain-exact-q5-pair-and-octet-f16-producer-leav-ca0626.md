# Retain exact Q5 pair and octet F16 producer leaves

## Summary

Added exact pair- and natural-octet-owned Q5T16 source-F16 producers. The pair
owner traverses each shared low/high payload byte once for two columns; the
octet owner consumes the complete Q5 K256xN8 packed unit. Both are registered
runtime-unwired primitives with scalar ownership retained as the production
fallback. The octet leaf is uniformly fastest and advances to complete-chain
screening.

## Changes

- Added local64 pair and local256 octet HIP producers, Python wrappers,
  diagnostic rocBLAS composites, and four-axis dequant/linear registry keys.
- Added RED-first registry, backend-scope, nonzero-tile source-F16 byte, and
  composite-owner tests. No model/session policy was changed.
- Updated the kernel catalog, benchmark changelog/rollup, and compact evidence
  artifact
  `benchmarks/results/2026-08-13-qwen36-27b-q5-packed-column-f16-producers-retained.json`.
- Added no resident payload, persistent allocation, or workspace; the scalar
  Q5T16 producer remains the registered production fallback.

## Validation

- The focused RED failed five assertions because pair/octet symbols, wrappers,
  composites, and keys did not exist; GREEN passes those exact assertions.
- Changed test file passes **21/21** on RX 7900 XTX. Focused W7900 Q5
  packed-column registry/byte checks pass **3/3**. Ruff and diff hygiene pass.
- Actual K6,144/N5,120 Q5T16 producer screen at 1024/1280-column production
  tiles: pair improves scalar **1.490-1.538x** and octet **1.738-1.827x** across
  both boards. Every **248/248** candidate pair wins and every source-F16 byte
  matches scalar.
- Cached W7900 rocprof names both candidates. Pair is local64/VGPR24/LDS512/
  scratch0; octet is local256/VGPR48/LDS512/scratch0, with plausible measured
  durations.
- Kernel lineage reports only the four known unrelated external parent drifts;
  these packed-column producers are net-new in-tree dataflows.
