# Confine packed growth leases to one backing chunk

## Summary

Packed growth leases request single-chunk placement through the pool's existing
confinement allocator. This avoids mixed-chunk placement when another chunk has
sufficient free pages.

## Changes

- Add optional `within_one_chunk` workspace-lease placement, leaving existing
  callers unchanged. Packed growth selects it on actual GlobalDeviceKVPool.
- Reuse request allocation's confinement implementation, not a parallel allocator.
- No math or default width change. Private fallback remains when placement fails.

- 191 pool/workspace/layout/growth/owner tests pass, `/tmp/r0210-confine.log`.
- New fragmented-root fixture selects appended storage and releases both leases
  before pool close. Existing fallback/charge/failure fixtures pass.
- Test-first was not used for this placement adapter; existing confinement logic
  is reused and followed by an explicit workspace regression fixture.
- Public cancellation/refill/close passed for previous backing-binding unit
