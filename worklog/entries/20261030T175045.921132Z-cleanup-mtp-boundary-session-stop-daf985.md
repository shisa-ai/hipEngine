# Stop GPU validation after a failed boundary child

## Summary

Corrects the failure-containment claim in
`20261030T173642.945103Z-cleanup-mtp-boundary-subprocess-670239.md`.
The first process wrapper prevented its own health child after failure, but a
normal pytest assertion still allowed later suite cases to touch the same
possibly unhealthy device. Failure or timeout now exits the test session
before any later GPU case. Successful crossing and health checks still run in
separate retired processes, and missing input remains a normal skip.

## Changes

- Use `pytest.exit(..., returncode=1)` for failed, signalled or timed-out
  children, rather than an assertion or `pytest.fail` that the suite can
  continue past.
- Add a real nested-pytest regression proving a later GPU stand-in is not
  executed; keep CPU exit/skip/timeout ordering tests.
