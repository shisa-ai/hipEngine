# Audit RDNA3 tuning lessons against live paths

## Summary

Compared the new RDNA3 guide against the live gfx1100/gfx1151 policy tables,
registry aliases and exclusions, GGUF packed-prefill and serving loops, current
kernel catalog, retained/rejected benchmark artifacts, refactor ledger, and Git
history. No unqualified global compiler, wave, cache, or launch switch is safe
to enable: the apparent generic candidates all have architecture-, shape-, or
profile-local counterevidence.

The clearest missed application is narrower than a kernel rewrite. The retained
gfx1151 Qwen3.8 B1/B5 wide K3 verifier owners now make one physical C8 group
slightly faster than its same-protocol AR control, but the production capability
is still a scalar maximum of four. That representation cannot admit the measured
profitable width set `{1,2,3,4,8}` without also admitting C5-C7, which remain
slower than AR. The next gate should replace the scalar maximum with a
profile-owned explicit width/depth policy and qualify static plus dynamic C8
lifecycle behavior; it must not simply raise the cap to eight.

Two architecture-independent runtime opportunities remain concrete but
unmeasured on the current tree: avoid output-norm/LM-head/sampling work for
intermediate packed-prefill chunk tails, and avoid constructing new Python
thread pools on every streamed AR/MTP cycle. Both need focused profiler and
correctness gates before implementation or promotion.

## Next

1. **gfx1151 Qwen3.8 C8 MTP reachability (measured opportunity):** replace the
   scalar physical-width maximum with a profile-owned explicit width/depth set,
   leave C5-C7 on whole-batch AR, and run the complete C8 static, retirement,
   admission, cancellation, isolation, quality, and same-protocol economics
   packet. Current B5 evidence is C8 `50.893` MTP versus `50.605` AR
   (`1.0057x`); C5-C7 are only `0.981/0.953/0.964x` AR.
2. **Packed-prefill final-row mask (confirmed redundant work, benefit
   unmeasured):** `prefill_batch_native()` reports `intermediate_tail_samples`
   but passes `sample_output=True` to every bounded round. Add a per-slot final
   mask, decouple hidden-seed capture from sampling where required, and skip
   intermediate output norm, full LM-head, and sampler work while preserving
   target-hidden sinks and MTP catch-up.
3. **W7900 packed-AR transfer bundle (hardware-local hypotheses):** independently
   gate singleton-indexed GDN first, then Q5 tile8, Q8 c4/c8 rowtiles, C8 selected
   Q4/Q5/Q6 duplicate-expert reuse, and the Q6 LM-head partition. The existing
   gfx1151 evidence makes these worth measuring, not safe to enable. Keep every
   segmented/per-row fallback.
4. **Persistent stream workers (source-confirmed churn, benefit unmeasured):**
   profile executor construction in streamed packed AR, MTP draft, and MTP
   verify. If material, own a bounded executor at the model loop and close it
   with the loop; preserve context/environment isolation and HIP stream
   lifecycle.
5. Do not reopen unchanged gfx1100 LCP-1 convolution, gfx1100 four-wave Q8T16,
   wave64, blanket non-temporal loads, prefill `-mcumode`, or gfx1151 PM4 as
   generic wins. Their premises are rejected or architecture-local.
