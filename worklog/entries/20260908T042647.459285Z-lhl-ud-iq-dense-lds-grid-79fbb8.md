# IQ dense decode: LDS codebook grid staging

## Summary

Third unit of the raw-IQ dense pass, and the first decode win that clears this
host's noise floor. The small IQ codebook grids are staged in LDS once per
workgroup and read with `ds_read` in the inner loop, instead of being indexed
in `__device__ __constant__` memory where a lane-varying index compiles to one
global byte load per decoded element. IQ3_S +10.5/+10.4% and IQ3_XXS
+7.9/+8.0% across two independent interleaved runs. Bit-exact.

## Changes

`hipengine/kernels/hip_gfx1100/quant/gguf_iq_dense.hip`: a `GRID_BYTES`-sized
`__shared__` staging buffer, cooperatively filled before the main loop, for
`iq3_grid` (2048 B, IQ3_S), `iq3_xxs_grid` (1024 B, IQ3_XXS) and
`IQ2_XS_GRID_PACKED` (1024 B, IQ2_XS). Phase-B lookups read the staged copy.
The scalar `weight<Q>()` helper keeps the global tables: it serves the Q3_K
embedding and IQ4_NL paths, which have no staged copy.

**Why this does not repeat the rejected B1 trade.** The previous unit rejected
replacing `iq4_values[16]` with packed immediates because it removed 16 loads
by adding ~112 VALU, and this kernel is VALU-issue bound at full occupancy.
LDS staging is a 1:1 operand swap onto a different pipe. Measured, VALU falls
too: IQ3_S 463->429, IQ3_XXS 429->376, IQ2_XS 562->518, because LDS addressing
is cheaper than 64-bit global addressing. Global loads per inner body fall
IQ3_S 66->55, IQ3_XXS 34->19, IQ2_XS 34->19.

## Measurements

Interleaved A/B, min-of-7 x 30 reps, rows=1, two independent runs:

| Family | run 1 | run 2 |
| --- | --- | --- |
| IQ3_S | 61.6 -> 68.1 (+10.5%) | 63.7 -> 70.4 (+10.4%) |
| IQ3_XXS | 78.2 -> 84.4 (+7.9%) | 75.9 -> 82.0 (+8.0%) |
| IQ2_XS | 45.9 -> 48.2 (+5.0%) | 45.3 -> 49.9 (+10.1%) |
| controls (unstaged) | +1.1 / -2.7 / -4.5% | +0.7 / +0.9 / -2.3% |

The controls are quants this edit does not touch, so they read the noise floor
directly: +/-5% in run 1, +/-1% in run 2. IQ3_S and IQ3_XXS clear it in both.
IQ2_XS is directionally consistent but its magnitude is unsettled.

## Rejected

Staging `iq2_s_grid` (8192 B) for IQ2_S: occupancy 16 -> 12 waves/SIMD,
measured **-10.6%**. The footprint costs more than the 16 removed loads
return. The exclusion and its number are recorded in the kernel source so the
next reader does not retry it.
