# Bind campaign expert-grid choices to owners

## Summary

inputs to the measured runner's expert-grid policy. Runtime fallback and profile
publication are unchanged.

## Changes

- Q4 pair arms bind `ExpertGridPolicy(True, True)` alongside their grouped
  chain prerequisites. The empty compatibility `Q4_PAIR_ENV` record contains
  no process writes; the control records the forced typed policy explicitly.
- PF13 requires the effective runner policy's Q5_1 axis, freezes that policy for
  the arm, and reports its published/effective values. An opposing process or
  synthetic environment value cannot override explicit owner policy.
- Tests cover both arms, precondition failure before mutation, exception
  restoration, effective control records and CPU main-function engagement.
  Public tests count actual Q4 pair/bundle and Q5_1 M1/parent launches through
  `LLM.generate_detailed()`, with repeatability and memory teardown checks.
