# The prefix-reuse gate passes all eight suites against a same-route reference

## Summary

The prefix-reuse gate passes on all eight suites: four natural categories and four
heldout suites, 1,024 teacher-forced rows, 2 top-1 flips, 0 semantic-boundary
mismatches. This closes the `docs/REFACTOR.md` item "Dense27B prefix oracle
disagreement after prefix/MTP integration", whose prescribed next step was exactly
this run: matched teacher rows, real category and heldout prompts, then the
calibrated production envelope.

Against the section 6.1 envelope (mean <= 1e-3, p95 <= 5e-3, p99 <= 2e-2,
max <= 5e-2, top-1 >= 0.99) every scope clears every term, with the worst scope
`heldout-general_en` still at least 2.5x inside each bound. Top-1 is 99.2% or
better per scope and 1,022/1,024 = 99.8% overall.

**The localization.** The failure this run retires was a comparison artifact. The
gate's reference is built by a prefix prefill, and the packed wave and the
single-session path persist different final-state arithmetic, so a reference built
through the single-session path makes the comparison a cross-route comparison.
`--reference-prefill-mode` now defaults to `packed` (`prefill_batch_native`), which
shares the candidate's and the served engine's route family; `native` and the
plugin's certified bulk scheduler remain available as diagnostics. The flag's own
help text states this, and the same conclusion was reached here from a controlled
reference-mode series before the packet ran.

The superseded artifact recorded `general_ja` as `passed: false` with
`kl_mean` 0.6811212740489249, `kl_max` 1.7583460667891433 and
`top1_agreement` 0.75, over **4** teacher-forced rows. It is now
`kl_mean` 0.0001940 (-99.97%), `kl_max` 0.0050300 (-99.71%) and top-1 1.00, over
**128** rows. The new number is both lower and better supported: the retired
failure was a 4-sample mean.

The two remaining flips are one each in `code` and `general_en`, the same two
scopes that flipped in the two-scope screening run of the same packet, so the
residual is reproducible rather than run noise. Both scopes remain far inside the
envelope.
