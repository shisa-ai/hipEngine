# Admit one SPECDEC2-PERF P5 target route

## Summary

Close SPECDEC2-PERF P5 with complete cached physical target profiles and exactly
one admitted, default-off P6 candidate. Warm full-width R6/R8/R12/R16 target
markers are **408.531/422.635/467.386/498.811 ms**; kernel sums are
**398.379/412.163/453.689/487.006 ms**. R16 target wall is **0.590x** two R8,
so wider physical target work continues to amortize the fixed trunk even though
acceptance economics block product performance.

The profile exposes a precise route mismatch. Standard Q4T16 uses the four-wave
shared-B kernel designed for 256 rows at R6-R16. It stages/dequantizes each
weight slab once, but 256/240-VGPR hot Q4 kernels do not spill; the transferable
llama.cpp lesson is row-width/ownership, not a literal spill fix. The already
registered exact single-wave parent wins four actual Qwen3.8 shapes. Hybrid
routing projects the 212-call standard-Q4 owner
**182.25-182.94 -> 159.22-159.82 ms (1.145x)** and saves **23.0-23.1 ms** per
target/cycle (**4.6-5.6% target**, **4.0-5.2% cycle**), meeting general
admission. No kernel body or arithmetic changes in P5.
