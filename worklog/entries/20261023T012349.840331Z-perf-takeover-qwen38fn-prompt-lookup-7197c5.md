# Implement request-local prompt lookup proposals

## Summary

Implement authorized task 11 after the subset-head commit `e632625ee`.
The target verifier and sampler remain authoritative. Baseline outputs and
raw timings are preserved in the subset-head artifact and under
`/tmp/qwen38fn-draft-head-20261023/`.

## Changes

- Read Gufo `src/models/qwen38_flash_next/prompt_lookup.hpp` at
  `f020bd3a037d58aa42138ca11fa895524e43cdd6`. A bounded child implements
  the request-local CPU matcher and tests: three-token keys, longest suffix
  among 16 newest matches, 12-token greedy/24-token sampled minimum, first-step
  suppression, sampled prompt-only source, and verified-copy resume.
- Main adds a draft-only forced-candidate chain that maintains the same hidden
  recurrence and cursor but skips vocabulary heads. Acceptance, target
  verification, full-match catchup and rollback keep their existing contracts.
- The ordinary provider owns one lookup per request. The mixed scheduler
  checkpoints small lookup decision state and restores it on transaction abort;
  no draft proposal is ever inserted into the committed source index.
