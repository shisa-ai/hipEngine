# Reject low-pressure planar Q6 root col4

## Summary

Rejected and fully removed a low-pressure planar-Q6 F32 R8/col4 root sibling.
It halves per-thread output accumulators versus retained col8 while preserving
each column's input traversal, arithmetic, DPP reduction, ordered wave sum, and
F32 store. It is bit exact but slower because it doubles root block traffic.

## Changes

- Temporarily generalized the planar-Q6 rowtile's compile-time column count and
  added a dedicated F32 R8/col4 launcher/wrapper.
- Removed all candidate source after the actual root leaf gate. No route,
  registry entry, environment policy, or test remains.
- Added a compact rejection artifact; no benchmark scoreboard row changed.

## Validation

- Actual Qwen3.8 `output.weight`, K5120/N248320, R8, 40 alternating HIP-event
  pairs and three launches/sample: output is F32-bit exact and finite, but col4
  is **3.4764→4.0748 ms (0.853x), 0/40 wins** versus retained col8.
- Lower accumulator pressure does not offset twice as many blocks over 248,320
  columns. Rejected before marker or full-suite spend.
- Final source matches `5456373c3`; only this worklog and
  `benchmarks/results/2026-09-02-w7900-q4km-k3-q6-root-col4-rejected.json`
  remain.

## Next

- Keep DPP R8/col8 root ownership. Straightforward Q6 row grouping, output
  pairing, root launch grouping, and low-pressure column geometries are now
  bounded and closed; move to a different family or state/control mechanism.
