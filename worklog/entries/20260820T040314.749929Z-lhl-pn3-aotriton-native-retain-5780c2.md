# gfx1151: route full-attention prefill to native (no aotriton crossover)

## Summary

Measured the native-vs-AOTriton full-attention prefill crossover on gfx1151
(8060S, 35B-A3B): **native `causal_gqa_gate_bf16` wins at every prefill length
64-2048 (~2-5% faster on the serialized full-attention slice, never slower,
no crossover)**. Retained: gfx1151 now routes ALL full-attention prefill to the
native kernel via a backend capability; gfx1100 keeps the measured 512-crossover
policy unchanged.

## Measurement (2026-08-20, 8060S)

Crossover sweep (aotriton-forced threshold=1 vs native-forced threshold=2**30,
in-situ device_sync around `_run_full_attention_prefill_layer_aotriton`,
10 full-attention layers, serialized per-layer ms):

| length | aotriton | native | native pct |
| --- | --- | --- | --- |
| 64   | 15.10 | 14.30 | -5.3% |
| 128  | 28.64 | 28.00 | -2.2% |
| 256  | 55.84 | 53.88 | -3.5% |
| 512  | 108.95 | 103.98 | -4.6% |
| 1024 | 213.50 | 206.63 | -3.2% |
| 2048 | 431.48 | 416.96 | -3.4% |

Whole-prefill 512 counter-rotated A/B: median aotriton 4458 ms vs native 4424 ms
(-0.8%, within ~2.5% run spread). The isolated attention-slice signal is the
consistent one.

Why: AOTriton's tiled flash attention is tuned for larger GPUs (gfx1100's
96 CU / 48 MiB MALL). On the 40-CU 8060S the simpler native scan wins and drops
the aotriton wrapper overhead (bf16 query conversion, head-major KV copy,
stream bridge).

## Correctness

- AR-equivalence native vs aotriton at 1024 tok: top1 agree (220=220),
  KL(aot||nat)=0.040.
- Calibration: run-noise floor KL(nat||nat)=0.034; KL(nat||aot)=0.046; both
  < 0.05 gate -> routing is correctness-neutral within the existing prefill
  noise band.
- The native kernel is the SAME kernel already validated below the 512
  threshold (benchmark suites 56-214 tok run native).
- mtpbench (56-214 tok) is unaffected (native before and after).

## Implementation

- `hipengine/kernels/hip_gfx1151/__init__.py`: `GGUF_AOTRITON_PREFILL = False`
  (+ `__all__` entry). gfx1100 leaves it undefined -> `backend_package_capability`
  default True (unchanged).
- `hipengine/runtime/qwen35_gguf_runner.py`: `_gguf_aotriton_prefill_allowed(backend)`
  (env `HIPENGINE_GGUF_AOTRITON_PREFILL_ENABLE` override) consulted in the
  `use_aotriton` gate of `_run_full_attention_prefill_layer_aotriton`.
