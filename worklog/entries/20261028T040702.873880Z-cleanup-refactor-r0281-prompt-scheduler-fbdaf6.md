# Remove stale prompt-list scheduling tasks

## Summary

Remove stale persistent-serving tasks from the prompt-list row and consolidate
its remaining direct-generator compatibility decision into R0281-AR-LOOP.

## Changes

- Public `SubmitPollTextGenerator` retains the resident runner and engine loop
  across calls; the server shares that submission/cancellation owner.
  `Qwen35GGUFResidentModelRunner` implements prefix reuse, sampled model ticks
  and ragged packed full-prompt prefill. `GlobalDeviceKVPool` and device pools
  implement shared-prefix ownership, growth and idle shrink. Those are not
  pending implementation tasks. Native sampler coverage and unsupported
  chunk/prefix-suffix packed shapes remain separate contracts.
- `_generate_greedy_batch()` is still a direct fallback when native batch is
  enabled but prepared packed/stream execution is not selected. Its call-local
  scheduler compacts physical slots and prefills admitted rows individually.
  Include it in the existing deferred direct-loop interface decision rather
  than introducing another persistent scheduler or a duplicate debt entry.
- Preserve `native_batch_decode`'s resident session-route preparation dependency
  when eventually extracting direct loops. Extend the existing resident bypass
  sentinel to reject both loops with this field enabled.
- No runtime/default/arithmetic changes. Characterization test only: no RED
  implementation failure is expected for already implemented ownership.
