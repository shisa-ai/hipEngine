# Build reproducible Vulkan owner instrumentation

## Summary

Implement the reproducible Framework capture/join controller and metadata-only
Vulkan owner instrumentation without modifying the read-only reference tree.
Real p512/p4096 capture smokes establish100% owner coverage and same-engine
greedy prefix parity. Full baseline refresh remains pending.

## Changes

- Owned build helper consumes the pinned b212548e0 compile database/link
  commands and recompiles only model/Vulkan host objects under /tmp.
  Original shader objects are linked read-only. Output/dependency paths cannot
  write into the reference tree; source anchors and commit pin fail closed.
- RAII graph scopes tag allocated tensor pointers and source weight names via
  stderr, without changing graph names/operands/op parameters. Innermost scopes
  own their work; root covers boundary work. Vulkan query entries include
  every fused node pointer, allowing missing/mixed families to be explicit.
- Shared taxonomy normalizes MoE to complete FFN (routed plus shared) because
  HIP decode graphs include shared projections. HIP prefill nested shared
  linears and Vulkan shared weights are moved together into MoE; original
  Vulkan source_owner tags remain. GR up stays GR read; down/inject linear.
- Controller modes: capture-vulkan (and uninstrumented reference-only),
  capture-hipengine, baselines, join with Markdown output. Capture excludes
  load/warmup by request-bounded section indices; no assumed ubatch count.
  Baselines are serial, logger-off, full12-case36-sample per engine, with
  resumable completed stages and frozen model/host/fixture/source/binary hashes.
- parse_perf_text reuses the existing parser for byte-range-independent graph
  sections. Temporal pointer metadata is snapshotted per timing section.
