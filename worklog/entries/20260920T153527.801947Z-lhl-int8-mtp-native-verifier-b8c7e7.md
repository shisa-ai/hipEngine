# Wire dense INT8 KV into native MTP verification

## Summary

Dense uniform per-token/head INT8 KV now works through the native GGUF C1
transactional verifier, including target graph execution and real NextN
generation. This is a runtime implementation checkpoint, not public serving
promotion, packed c>N support, DMS support, or a speedup claim.

## Changes

- `qwen35_gguf_runner.py`: layer-aware shared verifier spans preserve INT8 scale
  planes; the staged full-attention chain uses the new registered shared-table
  INT8 producer and existing quantizing append leaves. Unsupported storage
  shapes keep the existing row-wise numerical fallback.
- Eager INT8 verification creates per-row device metadata even at short
  context. Batched projections and FFN remain shared; each row attends only its
  causal prefix after quantized append.
- `gguf_native_spec_cycle.py`: uniform INT8 native attention is admitted to
  graph capture. Scale-plane, page-table, and mirror addresses participate in
  binding invalidation. Nonuniform/key-only/grouped layouts and compact-DMS
  graphs remain explicit unsupported contracts.
- Dense policy capacity bounds now cover INT8 alongside BF16 instead of
  returning the old BF16-only fallback cap.
- Added fake-runtime admission/span/binding tests and a live INT8-only full-model
  gate. The latter disables legacy BF16 mirrors explicitly without inventing an
  artifact qualification record, uses actual INT8 scales/payloads, and compares
  against the same INT8 AR target.
- GPU primitive tests retain the original AR-batch parametrization for the
  existing ownership-trace artifact generator; new verifier/FP16 cases are
  separate test functions sharing the same test body.
