# Reject trained linear DMS policy at 32K development

## Summary

Rejected the fully trained memoryless linear DMS threshold policy on the reused
v2 32K development suite. Exact long labels and continued optimization improve
classifier quality substantially, but static thresholds do not control unseen
sequence budgets and the same Japanese critical trajectory still violates the
binding quality gate. The fresh v3 final corpus remains sealed.

## Changes

- Completed four-category, full-prefix, stride-one exact CR2/window256 labels:
  131,072 sequence tokens, 64 layer shards, manifest SHA
  `2a47af1139e9f7ad19dc08081f7fd428b2ad77fe41c12457fb7df37032b3cdfc`.
- Fine-tuned the 327,744-parameter sidecar from the retained short weights for 20
  epochs with one row in 16 reserved in every calibration shard.
- Applied train-only per-layer/head calibration: 64 biases changed and 327,680
  weights preserved; candidate SHA `d2fe336e...f23d8b`.
- Added compact benchmark evidence and updated DMS/benchmark status.

## Validation

- Epoch-20 internal validation over 520,192 decisions: accuracy 0.835995, BCE
  0.366034, precision 0.834760, recall 0.837427. Cumulative trainer time was
  583.07 s; train-only calibration took 637.08 s.
- Calibration-source live CR spans 1.8777–2.0767x.
- Reused v2 32K d8 development: code/general_en/mixed_ja_en pass; general_ja
  rejects at max KL 0.140074 and 0.875 top-1. Aggregate top-1 is 0.96875, but the
  per-category/max-KL gate binds. Unseen live CR drifts to 2.3052–3.4947x.
- Exact compact no-evict evidence remains the control that localizes failure to
  policy selection rather than compact attention math.
- Final tracked allocation is zero. v3 final rows were not consumed.

## Next

- Implement metadata-bound exact-budget prefill ranking: preserve the protected
  window and evict exactly the CR2 historical count per layer/head using learned
  logits and deterministic ties.
- Reuse v2 for development; expose v3 only after a candidate passes v2.
- If exact-budget linear ranking still fails, escalate to a nonlinear/low-rank or
  task-aware objective without tuning against the Japanese failure token.
