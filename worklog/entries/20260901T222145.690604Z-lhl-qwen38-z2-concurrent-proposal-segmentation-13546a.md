# Harden concurrent Laurent proposal segmentation

## Summary

Made verbose proposal parsing safe for the C2 capture. Two concurrent requests
may emit both `new prompt` markers before either draft call, so assigning calls
to the latest marker is incorrect. The parser now records slot/task ownership
and resolves each call through its candidate `seq_id`, which matches the server
slot ID.

## Changes

- Parse slot and task IDs from prompt markers.
- Attach request task and prompt-token metadata to draft calls.
- Add an interleaved two-slot RED/GREEN test.

## Validation

- RED: interleaved calls were both assigned to request 1.
- GREEN: all four parser tests pass and calls resolve to requests 0/1.
- Focused campaign guard and worklog validation run before commit.
