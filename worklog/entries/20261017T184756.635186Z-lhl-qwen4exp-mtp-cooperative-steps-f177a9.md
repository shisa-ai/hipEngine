# Extract request-owned MTP cycle stepping

## Summary

Extract the unchanged Flash-Next proposal/verification loop into a lazy iterator
that returns one committed root or cycle at a time. This is the second PS1
prerequisite, not the serving integration: direct generation consumes the same
iterator, while public MTP streaming remains buffered until the service owns
incremental output.

## Changes

- Added immutable `Qwen4ExpMTPProgress` and `iter_generate`. Creating an iterator
  does no model work. Each yield owns new committed IDs; terminal completion
  returns the existing `GenerationOutput` and counters exactly once.
- Permit explicit request-owned target/draft and an already-prefilled/primed
  state without swapping the provider's shared owner references. Default direct
  calls preserve the original prefill, proposal depth, target verification,
  bonus-row, cursor trim and telemetry algorithm.
- Added local CPU serial/batched fakes, explicit expected IDs/acceptance/cursors,
  injected-owner, EOS/zero-token and cancellation tests. Parent review adds
  interleaved independent-owner coverage and a direct-iterator greedy admission
  guard before any model mutation.
