# Qwen4Exp X-10 routed F16 leave-one-out

## Summary

The routed-F16 component is performance-positive in the first bounded X-10 leave-one-out ablation and should remain in the production composition. Disabling it is slower at every canonical shape/category while preserving output bits in this diagnostic A/B.

## Changes

- Added `benchmarks/results/2026-10-15-qwen4exp-x10-routed-f16-ab/` with the raw counterbalanced artifact and README.
- No production manifest or selector changed.

## Validation

- 12 canonical cases, five counterbalanced pairs per case, 60 measured pairs.
- Bound and override arms repeat-exact; cross-route logits exact for every case.
- Override/bound throughput ratios range from 0.4236 to 0.4781. p4096 ratios are 0.4266-0.4313; p512 ratios are 0.465-0.478.
- The routed-F16 component remains selected. The disabled override is rejected as a performance candidate.

## Next

Continue X-10 with the next interaction-relevant component only after preserving the same counterbalanced protocol and complete quality/task review. This single ablation does not close final-stack qualification.
