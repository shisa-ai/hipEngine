# EVIE text attention f16

## Summary

Text full-attention layers (8 per encode, GQA 16q/4kv) now run the f16
matrix-core path: q/k/v gathered into per-head-contiguous f16 planes (GQA
repeat fused into the gather), strided-batched f16 GEMMs, the shared f16
scale+softmax kernel, f32 scatter. 2.69 s -> 2.66 s (doc 1.98 s, query
0.68 s). Small headline delta — text FA was only ~17 ms/page — but it also
removes the last fp32-sgemm attention and slightly trims the query path.

## Changes

- `evie_ops.hip`: `hipengine_evie_gather_repeat_f16` (GQA repeat gather).
- `hipengine/runtime/evie.py`: fp16 branch in `_attention` (text), same
  pattern as the vision path; fp32 pointer-array branch retained for the
  strict path.

## Validation

- Standalone GQA attention parity: err 2.0e-3 vs numpy (f16 noise).
- Fixture parity: query cos 0.9999986, doc cos 0.9999498, maxsim 5.9108
  vs 5.9114 (-0.01%).
- Strict fp32: tests/test_evie_gpu_runtime.py 3/3.
- Best of 3: 2657.6 ms (doc 1977.6, query 679.6).

## Notes
