# Screen Inkling prefill route tiling and partial tiles

## Summary

On W7900, widening the NVFP4 expert prefill tile from four to eight routes slowed every tested shape despite reducing the number of tiles in the larger batches. Specializing the four-route kernel by the number of valid routes sped up all tested leaf shapes instead. Both candidates matched the shipping projections bit-for-bit.

## Changes

- Scratch only. The eight-route arm changes only the tile width and record builder. The partial-tile arm keeps the four-route ABI and skips inactive accumulators using one template specialization per valid route count. Keep the shipping four-route kernel pending public and Strix Halo checks.
