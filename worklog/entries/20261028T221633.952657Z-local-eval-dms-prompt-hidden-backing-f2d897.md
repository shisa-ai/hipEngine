# Bound DMS hidden backing to the actual prompt

## Summary

Layer-outer external DMS prefill sizes its hidden/token backing to the actual
prompt before either pass. Logical context, resolved chunk policy, attention
scratch, oracle capacity and compact decode reservation stay unchanged.
The repair targets an observed allocation overlap without lowering context
or the output allowance.

## Changes

- Add a DMS-only prompt bound to the workspace allocator. Release obsolete
  backing before replacement and preserve published hidden rows.
- Prepare backing before public prefill contexts capture scratch pointers.
  Keep the inner two-pass entry idempotent for direct callers.
- Free hidden A if allocation of hidden B fails in the two-plane helper.
- Add CPU regression coverage for both alias modes, nonaligned prompts,
  growth/shrink, unchanged geometry and output reservation, invalid/shared
  inputs, wrapper lifetimes, published hidden rows and allocation failures.
