# Remove rejected DFlash2 reduced-block plumbing

## Summary

Closed the first verified deletion unit from the 2026-08-21 refactor review.
DFlash2 now always executes its trained block geometry. The CLI candidate budget
still truncates the prefix sent to target verification, so the retained B3/B5/B7
sweep behavior is unchanged; only the rejected attempt to shorten the drafter's
non-causal within-block forward was removed.

## Changes

- Removed `DF2_FWD_BS` and `DF2_CYCLE_DEBUG` from
  `scripts/dflash2_gguf_cycle.py`.
- Collapsed `DFlash2NativeDrafter.forward(bs=...)`, `select(rows=...)`, and
  `last_candidates(rows=...)` to fixed `config.block_size` /
  `config.block_size - 1` contracts. Internal attention/layer execution no
  longer carries a variable block-width argument.
- Both native cycle drivers always compute the full trained draft block, then
  truncate `path[:block_size - 1]` for the requested target-verification budget.
- Added a host-only signature/source RED so the rejected env/API surface cannot
  silently return.
- Removed the completed entries from `docs/REFACTOR.md` and updated the DFlash2
  campaign decision to state that the reduced-geometry experiment plumbing is
  gone. The rejection evidence remains in the immutable prior worklog and
  benchmark artifacts.
