# Screen dense matrix prefill and inventory Inkling GGUF layouts

## Summary

Keep the current dense prefill path. The existing FP16-operand matrix kernel changes arithmetic and did not produce a consistent latency win. In parallel, the downloaded mainline GGUF header confirmed that the Inkling Q4-labelled build still needs native NVFP4 expert support as well as GGUF dense and expert projections.

## Changes

- No runtime or default changes. The matrix pilot replaced only BF16-weight projections with matching input geometry and at least 16 activation rows. It used the existing FP32-output matrix kernel, which rounds operands to FP16 internally.
