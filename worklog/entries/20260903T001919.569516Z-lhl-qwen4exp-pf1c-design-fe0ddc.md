## Design

1. **Coltile family (48 attention-gate roles, out in {2560, 6144}, in 2560 or
   10240): extend the existing production MMQ128 guarded chain to these
   shapes.** The `QWEN4EXP_Q8_MMQ_PREFILL_POLICY.min_rows` table is the
   admission surface; adding the missing `(hidden, out)` keys routes these
   projections through the already-admitted d4x3 guarded arithmetic (same
   production-gate class, already qualified for seven shapes) instead of the
   23x-scalar coltile chain. Cost: policy-table rows + the same
   execution-profile gate (the harness from PF-1d applies verbatim with a
   policy that carries the extra shapes). No new kernel code. The strict
   coltile chain stays the registered fallback.
2. **Selected Q8_0 down (dense-FFN layers 2/4/30/46/47, grid out=2560 x
   rows=512x10): a Q8_0 selected WMMA variant mirroring
   `gguf_q4_k_selected_dual_wmma_iu8_prefill_kernel`.** That production kernel
   already implements the full mechanism: compact row maps
   (`expert_start_compact/wmma`, `tile_expert`), 128-column blocks, and
   **three-plane IU8 residual activation quantization** (ds4 class) — the same
   residual-plane scheme as the dense MMQ chain, corroborating that 3 planes
   is where production numerics settled twice independently. A Q8_0 variant
   is simpler than Q4_K (int8 weights load directly for iu8 WMMA with fp16
   scales). Cost: new kernel + compact-map plumbing + gate; the scalar
   selected GEMV stays the strict fallback.

Also noted: the in-flight d4x2 gate verdict feeds lever 1's numerics
expectations (same arithmetic family).
