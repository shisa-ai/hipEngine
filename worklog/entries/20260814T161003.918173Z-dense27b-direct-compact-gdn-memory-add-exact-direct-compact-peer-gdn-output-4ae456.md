# Add exact direct compact-peer GDN output

## Summary

Added a registered gfx1100 direct compact-peer GDN prefill output primitive for dense Qwen3.6. It preserves the retained compact prepare / wave32-XOR recurrent / BF16 RMSNorm-gate result exactly while requiring no materialized normalized Q, K, V, or FP32 recurrent-output plane. Runtime selection and scratch planning remain unchanged pending full-engine screening.

## Changes

- Added an exact 128-thread compact-peer scale preparation kernel, raw-`conv_out` wave32-XOR recurrence that safely overwrites each consumed value element, and a strided BF16 RMSNorm-gate finalizer.
- Added one raw-pointer C/Python composite wrapper and the distinct `gdn_prefill_output/gguf_qwen35/f32_direct_compact_peer_bf16` registry key; retained all split-chain keys as the required unfused fallback.
- Extended the live compact-peer oracle to compare the direct output and FP32 recurrent state bit-for-bit against the retained peer-wave32 control.
- Updated `docs/KERNELS.md` with the stable family and fallback contract. The lineage audit showed only the already-known external parent drift; no external code was ported.
