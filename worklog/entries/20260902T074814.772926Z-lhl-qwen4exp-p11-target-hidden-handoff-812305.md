# Qwen4Exp P11 target-hidden handoff

## Summary

Rejected promotion of the T0 shared-runtime target-hidden D2D handoff. Compact mode now suppresses target hidden readback after prompt priming and copies `last_target_hidden` directly into draft-owned hidden storage. Outputs remain exact, but aggregate wall improves only 1.0091x and two categories regress because the candidate-packet readback still synchronizes queued proposal work.

## Changes

- Added an optional target-hidden device pointer to the draft proposal boundary.
- Compact public MTP uses D2D hidden handoff when target and draft share a runtime; default full-output mode retains host hidden capture.
- Added telemetry that distinguishes `device_to_device` from `host` handoff and a focused provider RED contract.

## Validation

- Five focused provider/runner tests pass; compact provider control proves target `capture_hidden_seed=False`, D2D pointer forwarding, exact IDs, and handoff telemetry.
- Warmed four-category same-session AB/BA under `auto`: host/full-output `W=6,590.224 ms`; D2D/packet `C=6,530.592 ms`; `s=1.0091`. Code/general-Japanese are 1.1116x/1.0244x, but general-English/mixed are 0.9292x/0.9847x. Exact IDs and zero lifecycle pass; category non-regression fails.
- Cached B2/tg3 trace reports D2D handoff for all four categories, 34,010 dispatches, and 12 each argmax stage1/stage2; raw SHA-256 `d2de44f98de58fe71801d69f00009fee11f52e7322427a27d0d9549d59c24e09`.
- Arithmetic class T0; target-step `O=87.652 ms/row` includes model compute and prior hidden export. Packet D2H owns synchronization of queued proposal work. Prompt priming still exports hidden rows. Default host-hidden/full-output remains strict fallback.
