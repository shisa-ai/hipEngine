# Migrate GGUF graph lifetime storage to explicit owner methods

## Summary

Finished the RF-6 graph/KV-pin storage migration. Every production capture,
close and enumeration site now resolves the session's explicit
`Qwen35GGUFGraphLifetime` owner through `graph_lifetime_of` and calls
`register`/`unregister` or the ordered enumeration methods. The owner's
registries are private, and the resident session no longer exposes mutable
`_decode_graphs`, `_device_kv_graph_handles` or
`_decode_graph_submission_contexts` containers.

There is no ambient fallback to the old attributes. A session or packed owner
without an attached lifetime raises a named `TypeError` at the call site.

This is one move-only cleanup unit. It does not close RF-6: bulk attention
orchestration, full-stack verification and the PARO reusable-boundary decision
remain.

## Changes

- `hipengine/runtime/qwen35_gguf_graph_lifetime.py`
  - Renamed the public dataclass fields to private `_decode_graphs`,
    `_kv_pins` and `_submission_contexts`.
  - Added idempotent `register`/`unregister`, ordered `decode_graphs()` and
    `pinned_graphs()` enumeration, and `register_submission_context` /
    `submission_context_names`.
  - Added `graph_lifetime_of(host)`: the only coupling from capture/close code
    to the owner. It accepts a real session's `_graph_lifetime()` resolver or a
    test-attached owner and raises a named `TypeError` when neither exists.
- `hipengine/runtime/gguf_decode_graph.py` and
  `hipengine/runtime/gguf_packed_decode_graph.py`
  - Capture registers through `graph_lifetime_of(...).register(handle)`.
  - Close unregisters through the same helper before releasing device-KV pins,
    preserving the previous close -> unpin order.
- `hipengine/runtime/gguf_native_spec_cycle.py`
  - Native target capture registers through the owner.
  - `Qwen35GGUFNativeB2TargetGraph.close` unregisters through the owner before
    its existing unpin and cache cleanup, preserving order.
- `hipengine/generation/qwen35_gguf.py`
  - `_graph_handles_for_sessions` enumerates the owner's decode graphs followed
    by its pinned handles, identity-deduped, matching the previous order.
- `hipengine/runtime/qwen35_gguf_runner.py`
  - Removed all three compatibility properties. `resident_slot_view` installs a
    fresh owner and no longer resets old containers.
  - Session methods use `graph_lifetime_of(self)`.
- `scripts/pm4_packed_graph_bench.py` registers its PM4 timestamp context via
  the owner instead of assigning into the retired dictionary.
- Tests attach a real `Qwen35GGUFGraphLifetime` to fake sessions and exercise
  the same protocol production uses. Added regressions for native target graph
  close/unpin ordering and generator graph enumeration.

## Compatibility removal list

None. The two remaining production callers (`gguf_native_spec_cycle.py` and
`generation/qwen35_gguf.py`) are migrated and the runner properties are gone.
