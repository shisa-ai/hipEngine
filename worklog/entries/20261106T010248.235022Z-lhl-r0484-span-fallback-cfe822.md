# Implement span-aware Surya unfused decode fallback

## Summary

Implement a strict scalar span-aware Surya decode fallback for geometry outside
the fused head-width/GQA envelope. Keep R0484 open for public model validation
and its independent sparse-work optimization.

## Changes

- Separate QK, row softmax and AV device launches consume logical-slot visibility
  and page mapping. Empty visible rows return zero. Masked K/V are not read.
- Runtime unsupported-fused geometry uses the new chain on its normal path.
  Preserve the dense rocBLAS chain as a diagnostic parent oracle only.
- Device fixtures compare against float64 CPU spans on dense/permuted pages,
  eviction, empty/partial/causal contexts and nonstandard 6/2/32 head geometry.
  Masked payloads are poisoned with NaN. No performance improvement claimed.
- Own source; no external kernel copied. Lineage inventory run before edits;
  no Surya source manifest entry exists. Some unrelated external repositories
  are absent; `/tmp/r0484-lineage.log` records those warnings.
