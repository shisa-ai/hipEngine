# Verify mixed raw UD FFN fallback ownership

## Summary

120 CPU-only mixed raw IQ/Q3 FFN caller tests pass. The runner's real
`_run_post_attention_ffn_rows` method reaches the strict unfused chain with
correct pointer ownership and call order. This does not establish GPU math,
profile admission, or complete published-file FFN coverage.

## Changes

`tests/test_gguf_ud_ffn_callers.py` covers six gate/up/down type combinations
observed by reading both published model indexes: IQ4_XS/Q3_K/IQ4_XS,
Q3_K/IQ4_XS/IQ3_S, IQ3_S/Q3_K/IQ4_XS, IQ3_XXS/IQ3_S/IQ3_S,
Q3_K/IQ3_XXS/IQ3_S and IQ4_XS/IQ4_NL/IQ4_XS. Metadata uses hidden width5120
and FFN width17408; no model payload or HIP call is required. Both backend
declarations and rows1/2/4/7/8/16/32/511/512/513 are covered.

Pair and singleton resolution are real. Registered singleton leaves are
verified before replacing numerical execution with event captures. Norm,
SiLU and add leaves are captured separately. The decode-policy selector is
set to the unfused policy; down-residual decode fusion is disabled. Assertions
check norm/residual owners, distinct gate/up planes separated by rows*17408*2
bytes, ordered SiLU operands, down input/output, final residual destination,
stream/runtime forwarding and exact event order. Missing optional decode
sidecars use the real allocation API's KeyError behavior, not fake buffers.
