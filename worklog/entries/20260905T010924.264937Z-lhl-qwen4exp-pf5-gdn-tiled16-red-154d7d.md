# Declare PF-5 GDN tile-16 T0 RED

## Summary

Open PF-5 lever 2 against the fresh p4096 operation-role trace. The 15 active
production-profile GDN columnwarp kernels total 513.212 ms, plus 42.512 ms in
the unchanged norm/gate tail. The current `<4,4>` owner already keeps each
output column's recurrent-state shard in registers for the full sequence, but
every column warp independently reloads the same raw Q/K vectors, repeats the
same Q/K normalization reductions, and recomputes the same beta/decay scalars.

The candidate adapts halo-box PR11's token-tile-16 cooperative staging
mechanism, not its arithmetic. One 16-warp block will stage 16 raw Q/K token
rows and compute each token's q_scale/k_scale/beta/decay exactly once. Each
column warp keeps the parent's per-lane `r=0..3` sums, XOR shuffle tree,
recurrent update order, and output expression.

- **Arithmetic class:** T0, bit-exact to
  `qwen4exp_gdn_columnwarps_prefill` for core output and final FP32 state.
- **Envelope:** Qwen4Exp GDN prefill, Hk=16, Hv=32, Dk=Dv=128, rows >= 16;
  other shapes and profiles remain unchanged.
- **Fallbacks:** `qwen4exp_gdn_columnwarps_prefill` is the immediate production
  rollback; registered `qwen4exp_sigmoid_strict_prefill` remains the strict
  serial fallback. The norm/gate tail remains a separate primitive.
- Dispatch and arithmetic are independent of prompt content, token IDs,
  expert IDs, and candidate IDs.
