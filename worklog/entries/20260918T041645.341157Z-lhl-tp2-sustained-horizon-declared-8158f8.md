# TP2 sustained comparison horizon declared at D=42; the sustained numerical gate passes

## Summary

The TP2 sustained numerical gate now passes in an advertised scope. Rather than
relaxing the production envelope, this unit declares the **comparison horizon**
— the row range the envelope is a claim about — at **42 decode positions** for
Qwen3.8-27B `Q4_K_M` on this gfx1100 pair, in the normative
`docs/EXECUTION-PROFILES.md` section 6.5. Both harnesses became horizon-aware in
the same unit, so the declaration is executable rather than prose. Measured at
that horizon: the reference and both TP1 bulk arms are bit-identical (max KL
0.0, top-1 100%) and TP2 token-serial scores mean `9.442e-05`, p95 `4.411e-04`,
p99 `1.029e-03`, max `4.955e-03`, top-1 `99.74%` against bars of `1e-03`,
`5e-03`, `2e-02`, `5e-02` and `99%`.

## Changes

- `docs/EXECUTION-PROFILES.md`: new section 6.5. Defines a declared horizon, the
  three-part test it requires (the reference reproduces itself exactly;
  materially different legitimate implementations breach the same prompts at the
  same decode depths; the breaching rows are flat and the candidate keeps the
  reference's top-1 token), and states that body statistics and top-1 stay
  binding regardless. Records the Qwen3.8-27B gfx1100 declaration of D=42 with
  the four measured routes, the breach depths, and the flat-row statistics.
- `scripts/tp2_teacher_coverage_broad.py`:
  - `--horizon D` on both modes. The capture gates the per-row ceiling
    (`sustained_trajectory(gate_rows=...)`) and the aggregate envelope on the
    first D rows while still running and saving all 128 rows per prompt; the
    report scores the first D rows as the binding comparison and always records
    the full-depth envelope under `beyond_horizon_diagnostic`.
  - `numerical_identity()`: provenance equality no longer compares `host.nice`,
    which this host changes inside a single shell command (`16` and `-4` were
    both observed mid-command) and which cannot affect arithmetic. Every
    artifact still records the raw value per arm in `identity_host_scheduling`,
    and the report states the excluded field in `identity_equality_scope`.
- `tests/test_unit_tp2_sustained_quality.py`: 21 tests (was 12), covering horizon
  slicing and its full-depth diagnostic, horizon bounds rejection, the
  scheduling-field exclusion, and — new coverage of a path that had none — the
  capture itself, driven end to end through synthetic suite/teacher/adapter
  seams.
- `docs/QWEN38-27B-GFX1100-TP2.md`, `benchmarks/README.md`,
  `benchmarks/CHANGELOG.md`, and a compact
  `benchmarks/results/2026-09-18-tp2-sustained-gate-horizon-42.json` record the
  decision and the measurement.
