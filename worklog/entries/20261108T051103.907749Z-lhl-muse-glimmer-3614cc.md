# Muse Glimmer DFlash long-context integrated analysis + ordered priority list (verify attention first)

## Summary

Integrated the reviewer's phase-tagged DFlash profile (b132140d0) with my
isolated attention microbenchmark into one analysis and an ordered priority
list, recorded in campaign MUSE-GLIMMER.md §11. DFlash is fixed for correctness
(drafter SWA-window fix 81cc8cc5f, neutral-penalty sampler fix 45433fe8b) but
its speedup collapses with context: 1.93x at 512 -> 1.10x at 126K. The cause is
verify attention, which runs the decode kernel once per draft row with no K/V
sharing (5.15x the AR step's attention at 126K: 161.5 vs 32.4 ms/cycle).
