# Decode Inkling NVFP4 levels without a lookup load

## Summary

Construct the NVFP4 level directly from its nibble instead of indexing a float table. Preserve every decoded value and signed zero.

## Changes

- Leave E4M3 scale decoding, products, fused multiply-adds, and the reduction tree unchanged. The compiled gfx1100 assembly no longer references the level table.

## Validation

- `epyc` / Radeon Pro W7900 (`gfx1100`), original `thinkingmachines/Inkling-2-Mini` revision `ed40e7da625f594fc9c4990f5f66be24873c22d7`, `inkling2_mixed`, FP32 KV, single-request ordinary greedy decode. Baseline `10f838488`.
- `bash /tmp/hipengine-inkling2-verify.sh bitnibble`: warm median 15.5526 to 15.6605 tok/s at five input / 24 output tokens (three runs per arm with no overlap). The synthetic 512-input / 128-output case measured 13.4400 and 13.4816 tok/s, one run per arm, with identical output IDs. This single matched pair does not establish a precise gain.
- Warm trace per token: NVFP4 expert kernels 10.669 to 10.248 ms; MXFP8 unchanged at 0.992 ms. A GPU probe matched the original table bit for bit for all 16 codes. All 54 focused tests passed; public text and single-image packed DSpark matched ordinary and baseline IDs and counts. DSpark throughput was not remeasured.
