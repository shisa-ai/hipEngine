# Task 5: pool-backed packed KV - layout rebind stage

## Summary

Task #5 unifies packed-AR KV backing onto the GlobalDeviceKVPool /
KVBackendSpec contract (design recorded on task #5, 2026-08-18;
CONCURRENCY2.md 630-700/791-794/1021-1022). Stages S1a and S1b landed as
af5d00098 (pool `lease_workspace`/`release_workspace`: pinned, non-request,
close-guarded, stats-visible) and 29a786afc (`_GGUFPackedTargetState.page_ids`
+ `copy_segments()`; all five dense `physical_base` copy sites converted to
two-sided page-aligned walks, identity mapping = behavior-identical).

This entry covers stage S1c: layout block tables now bind to the packed
state's physical page IDs instead of assuming identity geometry.

## Changes

- `_rebind_packed_verify_layout_pages(layout, packed_state)` rewrites the
  layout's slot-local identity block table through `packed_state.page_ids`
  (state slot stride, not layout stride), preserving `-1` rows for inactive
  slots. Identity mappings return the original layout object, so the
  production private-chunk path is unchanged.
- Rebind applied at all four layout->workspace flows: packed target verify,
  packed AR prefill, packed decode step (`qwen35_gguf_runner.py`), and packed
  decode graph capture (`gguf_packed_decode_graph.py`).
- `_packed_decode_metadata_device_eligible` needs no change: a non-identity
  rebound table fails its identity comparison and falls back to host upload.
  Grown-workspace geometry (state `blocks_per_slot` > layout's) is handled by
  striding through `page_ids` with the state stride and validated with tests.

## Validation

- RED first: five new tests in `tests/test_gguf_packed_verify_layout.py`
  failed with AttributeError pre-implementation.
- GREEN: identity fast path returns the same object; arena page mapping
  matches `copy_segments` physical starts; wider-state stride honored
  (including identity pages with wider stride); narrow state rejected on both
  slot_count and blocks_per_slot; device-metadata gate rejects non-identity
  rebound layouts.
- Full `test_gguf_packed_verify_layout.py` + `test_gguf_packed_decode_graph.py`
  + `test_gguf_packed_workspace_stability.py` + `test_gguf_packed_execution_manifest.py`
  + `test_kvcache_global_device_pool.py` pass.
- Production behavior is byte-identical (identity page_ids -> same layout
  object), so no GPU re-qualification was required for this stage.
