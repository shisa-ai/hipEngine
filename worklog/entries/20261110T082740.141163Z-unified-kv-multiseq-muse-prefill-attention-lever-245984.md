of synchronized session.prefill at 32K/131K; trace walls match the

32K->131K scaling: attention 13.3x (near-quadratic), projections 4.0x
(linear). The 0.85x inversion vs llama.cpp at 131K is the attention kernel,
not the projections. Effective attention throughput ~15.4 TFLOP/s on the
full-attention layers (~26% of the ~59 TFLOP/s bf16 WMMA peak).

Chunk size is NOT an attention lever: total blocks = N/8 regardless of
chunking, each scanning its own causal range; the bring-up note already
found chunk 2048 adds only ~2% at 4K (projection amortization).

## Hypothesis under test (arithmetic-neutral)

The mt kernel stages K/V tiles at row stride HEAD_DIM=128 halves (256 B).
The QK k_frag read `k_tile[lane16*128 + dt*16 + k]` puts all 16 lanes on the
same LDS bank group (256 B stride % 128 B bank window = 0): a 16-way bank
conflict on every K-fragment load, 128 loads per wave-tile. Padded row
stride (128+2 halves) makes the lane pattern conflict-free. Pure layout
change: identical arithmetic, bit-identical output expected — no
reassociation gate needed if parity holds.
