# Qwen4Exp exact Q5 logical256 physical128 decode

## Summary

Promoted an exact Qwen4Exp selected-Q5_1 decode owner that maps two logical
partials to each of 128 physical threads while preserving the strict 256-slot
reduction tree. Counterbalanced graph decode improves 11.380 to 12.140 tok/s
(+6.27%) on zbook/gfx1151 with exact full logits and generated IDs.

## Changes

- Added and registered `selected_gemv_logical256_t128_bf16_bf16_out` with the
  original K assignment, shared strides 128/64/32, and wave32 tail.
- Made it the unconditional selected-Q5_1 runtime default; retained the strict
  256-thread owner as a registered fallback.
- Added CPU-dequant/strict BF16-bit RED coverage and current benchmark evidence.

## Validation

- `HIPENGINE_HIP_ARCH=gfx1151 uv run pytest -q tests/test_qwen4_exp_q5_1_selected.py -x`
  — 3 passed.
- Counterbalanced one-residency `S/C/C/S/S/C`, p1 + 8 warm + 32 measured:
  median 2.812039 to 2.635829 s, 11.379642 to 12.140393 tok/s; every full-logit
  SHA and generated ID exact.
- `rocprofv3 --kernel-trace` recorded the expected
  `q5_1_selected_gemv_logical256_t128_bf16_bf16_kernel`; 1,806-launch Q5
  cycle-wall fell 692.930331 to 410.363776 ms (-40.78%).

  `benchmarks/results/2026-08-29-gfx1151-qwen38-flash-next-exact-q5-logical256-t128-decode.json`.
