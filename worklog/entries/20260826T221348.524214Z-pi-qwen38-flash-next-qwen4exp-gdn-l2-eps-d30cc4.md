# Make Qwen4Exp GDN L2 normalization finite

## Summary

Aligned fused Qwen4Exp GDN Q/K L2 normalization with the upstream `eps=1e-6`
contract so zero or tiny heads stay finite.

## Changes

- Added epsilon before both Q and K reciprocal square roots; retained the
  separate `1/sqrt(head_dim)` query attention scale.
- Strengthened the production-geometry oracle with one exactly zero Q/K head
  and updated both direct and composed-runner references to upstream epsilon.
- Preserved GGUF tiled-head ownership: the converter reorders V/Z/A/B/decay
  rows, so the fused runtime's modulo K-head mapping remains intentional.
