# Correct c8 roofline interpretation and rank profiling

## Summary

Correct the uncommitted Concurrency2 c=N/roofline draft before it could turn a
scaling observation into an unsupported global bottleneck claim. The W7900 roof
is 864 GB/s GDDR6, not 3.5 TB/s, but correcting that number alone is insufficient:
c1→c8 scaling proves amortization/utilization, not whether complete decode is
bandwidth-, compute/issue-, occupancy-, or host/dispatch-limited.

## Changes

- Remove the invalid c1-c32 product throughput table derived from the
  provenance-free eager D2 diagnostic; retain only the clean direct graph packet
  as current c1/c8 model-step evidence.
- Add corrected illustrative byte bounds: a 15.3-GB proxy implies 17.7 ms at
  theoretical VRAM peak and 20.8–23.5 ms at a generic 650–735 GB/s stream; c8 is
  28% of that theoretical aggregate roof or 33–37% of the generic sustained
  range. Explicitly state that proxy bytes are not measured transactions and
  cannot classify the limiter.
- Correct arithmetic-intensity interpretation (Q4 T16 row8 useful AI ≈27.7
  FLOP/byte) and explain why mixed quant families, dequant VALU issue, VOPD,
  occupancy, cache behavior, GDN recurrence, and dispatch require per-family
  classification. The 2.30-TB/s 96-MB Infinity Cache is not a 15.3-GB model
  weight roof.
- Add the current opportunity ledger: 63.53-ms wall, 54.05-ms diagnostic kernel
  sum, dense projection 43.25 ms (Q4 pair 12.89, planar-Q6 10.76, Q4 singleton
  10.69, Q5 4.30), GDN/state 8.17, and ≤9.48 ms unreconciled wall. The
  wall-minus-kernel value is an upper bound, not a host-overhead measurement.
- Add a five-stage #37 measurement ladder: wall reconciliation, actual family
  bytes/effective bandwidth, issue+occupancy counters, c1/c4/c8 family slopes,
  then full correctness/model/server confirmation.
- Add a conditional optimization queue ranked by recoverable full-wall
  milliseconds: dense projections first; measured dispatch/sync residual or
  GDN next depending on profiling; small remainder later. Planar-Q6 VGPR136 is
  an occupancy hypothesis, not a predetermined rewrite. Row16 stays conditional
  and row32 rejected.
- Reconcile stale current-state text: gfx1100 Qwen3.8 physical c1-c8 is package-
